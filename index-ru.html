FastMediaSorter v2

Профессиональная организация медиафайлов для Android
Версия 2.x • Open Source

✨ Ключевые возможности

  • Управление локальным хранилищем
  • Поддержка сетевых SMB/CIFS ресурсов
  • Поддержка протоколов SFTP и FTP
  • Поддержка облачных хранилищ (Google Drive, Dropbox, OneDrive)
  • Поддержка чтения книг EPUB
  • Продвинутый видеоплеер на ExoPlayer
  • Высокопроизводительный просмотр изображений (Coil)
  • Пакетные операции с файлами (копирование/перемещение/удаление)
  • Система избранного
  • Режим слайд-шоу с настраиваемыми интервалами
  • Фоновая музыка для слайд-шоу
  • Аудиоплеер с фоновым фото
  • Интерфейс «Сейчас играет»: мини-панель + шторка с очередью
  • Поддержка бинарных файлов (ZIP, APK, миниатюры)
  • Полная поддержка клавиатуры и мыши
  • Тексты песен (Lyrics) с автопоиском
  • Редактор изображений (фильтры, поворот)
  • Поддержка скрытых файлов
  • Кэширование миниатюр (по умолчанию 2 ГБ, до 16 ГБ)
  • Пагинация для больших папок (1000+ файлов)
  • Авто-перевод (OCR) для изображений/PDF
  • Поддержка виджетов для домашнего экрана (Ярлык ресурса и Продолжить просмотр)
  • Предопределённые виртуальные ресурсы: Вся музыка, Все видео, Все фото
  • Поддержка аппаратных кнопок (руль, гарнитура, медиа-клавиши)
  • Clean Architecture + паттерн MVVM
  • Продвинутые сенсорные жесты

💡 Сценарии использования

🖼️

Цифровая Фоторамка на Планшете

Превратите любой Android-планшет в красивую всегда включённую цифровую фоторамку. Стриминг с домашнего ПК (SMB) или облака — без занятия локальной памяти. Добавьте музыку, настройте интервал, наслаждайтесь.

🚗

Музыка в Автомобиле (Android-магнитола)

Установите на Android-автомагнитолу. Виртуальный ресурс Вся музыка — мгновенный доступ ко всей коллекции без настройки. Кнопки руля работают через фоновый аудиосервис — без касания экрана.

🍿

Домашний Кинотеатр и VR

Смотрите сериалы с ПК или облака на телефоне/VR. Не нужно копировать — просто нажмите Play, и следующая серия запустится сама. На Android-шлемах (Meta Quest, Pico): гигантский виртуальный кинотеатр, иммерсивный музыкальный плеер с поддержкой аппаратных кнопок или фоторамка размером в стену с фоновой музыкой — всё стримится напрямую из домашней сети.

🧹

Порядок в Загрузках

Наведите порядок в загрузках на устройстве или удалённом ПК. Настройте кнопки и раскидывайте файлы по папкам одним касанием.

📷

Автобэкап Фото на ПК по Расписанию

Автоматически копируйте новые фото с камеры на домашний компьютер по Wi-Fi (SMB). Настройте расписание — и резервная копия сохранится ночью без вашего участия.

⏱️

Автоочистка Загрузок по Расписанию

Автоматически удаляйте устаревшие или уже разобранные файлы из Загрузок по расписанию. Порядок в хранилище без ручного труда.
