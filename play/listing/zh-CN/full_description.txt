Fast Media Sorter 是一款 Android 文件整理工具。打开源文件夹，每个文件只看一眼，然后把它送到该去的地方 - 一个文件一个决定，直到文件夹清空。

整理正是这款应用存在的意义：

• 两端的文件夹都由你选择 - DCIM、下载、聊天媒体、存储卡、USB 驱动器、SMB/CIFS、FTP 或 SFTP 共享、Google Drive、OneDrive 或 Dropbox。
• 决定后继续 - 复制、移动、重命名或删除，随即进入下一个文件。
• 支持所有文件类型，不限于媒体 - 照片、视频、音乐、PDF、EPUB、文本和压缩包。
• 跨文件夹与跨协议的批量操作，包括云到云传输，带进度和预计剩余时间。
• 定时操作 - 在两个文件夹之间设置一次传输，之后它自行运行。
• 回收站提供 5 分钟恢复窗口，另有缩略图、进阶排序与筛选、多选和拖动排序。
• 以二维码分享网络文件夹，另一台设备扫码即可加入。

应用为何请求访问所有文件：

整理必须能触及你选定的文件夹，而不只是应用自己的私有存储 - 一个无法写入目标文件夹的文件整理工具，等于什么都做不了。这正是请求「所有文件」权限的原因，主要工作流程正建立在该权限之上。这不会让任何数据离开你的设备：应用没有账户，也没有遥测。

应用为何请求位置权限：

位置权限是可选的，只有需要它的功能才会使用：把坐标写入你用内置相机拍摄的照片和视频，在启动器桌面上绘制指南针、速度、海拔和地图小工具，并填充网络监视器的 GNSS 与 Wi-Fi 部分。它从不在后台读取，而地图小工具会通过网络加载地图图像以显示你的位置。拒绝授权，拍摄的内容便不带坐标，这些小工具则保持闲置。

由于必须先看到文件才能做决定，查看器和播放器都已内置：

• 图片查看器 - 旋转、色彩滤镜、裁剪、绘制批注、OCR 文字提取和 AR 风格翻译浮层，并可保存压缩副本。
• 基于 ExoPlayer（Media3）的视频播放器 - 画中画、睡眠定时、逐文件续播、3D 立体与 360° 识别。
• 音乐播放器 - 后台播放、歌词搜索、专辑封面、可视化效果和 Chromecast 输出。
• PDF 与 EPUB 阅读器 - 文字转语音、主题、搜索和就地翻译。
• 文本编辑器 - 自动识别字符集、Markdown 渲染、语法高亮。
• 幻灯片 - 背景音乐、逐项间隔、视频播完为止、可配置转场。
• 内置相机 - 依设备匹配镜头、变焦范围和照片尺寸，直接拍入你选定的文件夹。
• 直播电视与广播 - 数千个网络频道，支持搜索、主题筛选、收藏置顶、电台图像和正在播放信息。

面向每块屏幕和每种输入方式：

• 完整的键盘、电视遥控器 / D-pad 和游戏手柄导航。
• 主屏幕小部件 - 打开资源、继续阅读、随机音乐、相机照片。
• 用于后台音频的快捷设置磁贴。可搜索每一项设置。
• Wear OS - 独立的手表应用：浏览存储在手表上的媒体，收听网络广播和电视，三个磁贴和三个表盘复杂功能，另有计算器、网络监视器和录音机。网络共享和文件由手机应用送达。

免费、开源且注重隐私 - 应用源代码以 Apache License 2.0 发布，本地、SMB、FTP 和 SFTP 浏览，以及图片、视频、音频、PDF 和 EPUB 查看器均可完全离线运行，无需任何账户。
