# S3368: startup baseline profile for the wear module (ART human-readable format, classes only).
#
# Research artifact 02: the artifact shipped no profile and the first cold start after an install ran
# interpreted/JIT-only, which is most of the class-load cost measured in artifact 01. These rules ask
# AOT compilation for the classes the startup trace actually loads before the first frame.
#
# Deliberately absent: the SMB/FTP/SFTP data sources, the connection tests, and the thumbnail
# pipeline (data/network/**, data/thumbnail/**) - S3368 phase 02 deferred them off the startup path,
# and profiling them would pull their cost into every install's compile pass.
