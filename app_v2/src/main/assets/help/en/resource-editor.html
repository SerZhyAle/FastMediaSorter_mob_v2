Edit Resource

What this is for

Edit Resource changes a resource you already added: its name and icon, the address or path it points to, which files it shows and how it behaves. Open it from the resource list by holding a resource or with the edit button in its row. The same screen sets up a new internet stream and saves a copy of a resource.

In this order

  1. Start with the name 6. Names must be unique: if yours is taken, the app says so and offers Use suggested name 7.
  2. Open Connection Settings 8 to correct the path, the address and port, the sign-in or the stream address. For a network or cloud resource, check the new values with Test Connection 9; Retry 10 repeats the last action after a failure.
  3. Decide what the resource shows: Content Scanning Conditions 11 and the file types in Media Types 12. Resource Profile 13 fills in a ready set in one tap.
  4. Use Destination Settings 14 to use the resource for Quick Sort or to make it read-only, and Advanced Settings 15 for a comment, a PIN and the slideshow interval.
  5. Pick an icon 3 if you want the resource to stand out in the list.
  6. Press Save Changes 5; it stays off until something valid has changed. Save as Copy 4 keeps the original and stores your edits as a new resource, and Reset Changes 2 brings back the saved values.
  7. Statistics 16 tell you when the resource was created and opened, and Add to Home Screen 17 puts a shortcut to it on your home screen.

The elements

Toolbar and actions

1BackCloses the editor without saving your changes.

The arrow in the toolbar, the Back button of the device and the Esc key all leave the screen at once. Nothing is saved on the way out, so press Save Changes first if you want to keep your edits.

Shortcut
Esc
2Reset ChangesPuts every field back to the values saved with the resource.

The button shows up only after you change something. It restores all fields, the icon and the profile to how they were when the editor opened, and clears the last connection test result.

Undo
Your edits since opening the editor are lost and cannot be brought back. Saved values are not touched.
3Pick resource iconChooses the picture that stands for this resource in lists.

Opens the Choose an icon sheet; the button itself shows the icon the resource has now. The new icon is stored when you press Save Changes. If you change the profile and have not chosen an icon by hand in this session, the icon follows the profile on its own.

4Save as CopyStores your edits as a new resource and leaves the original as it is.

Available when you edit an existing resource. The copy gets a free name based on the original one, and the editor stays on the original afterwards. It is greyed out while the form has errors or a test or save is running.

5Save ChangesSaves your changes to the resource.

The button is off until the form is valid and something has actually changed. After saving you see Resource saved successfully and the screen closes. Ctrl+S does the same as the button; if there is nothing to save, a short note says so.

Shortcut
Ctrl + S

Name and connection

6Resource NameThe name the resource has in your lists.

Names are compared without regard to upper and lower case, so Photos and photos count as the same. When the name is already in use, a red note says so and the suggestions appear below; the name of the resource you are editing is never treated as a duplicate of itself.

7Use suggested nameReplaces a taken name with the first suggestion.

The button appears only when the name you typed is already used by another resource. Its text carries the suggested name, and one tap puts it into the field.

8Connection SettingsWhere the resource points to: a folder, a server, a cloud folder or a stream.

A collapsible section whose fields depend on the type. A local resource shows Folder Path. A network resource shows Host / IP Address, Port, Username, Password and Server Path (optional). A cloud resource shows Cloud Folder ID, and a stream shows its URL (http, https, rtsp). Collections such as Recent Media have no path, so the section is not shown for them. After you change the path, the address or the port, a warning says that a rescan or re-check is needed.

While a password field is on screen, the screen can be hidden from screenshots and the recent apps view, depending on the Secure sensitive screens setting.

9Test ConnectionChecks the connection settings before you save them.

Shown for network and cloud resources. The app first checks that the form is filled in correctly, then connects and shows the result in a coloured line: green for success, with a count of what it found, a warning colour for a partial result and red for a failure. Nothing is saved by the test.

10RetryRepeats the last action after a failure.

The button appears under a failed connection test. It runs again whatever you did last: the test, Save Changes or Save as Copy.

What the resource shows and how it behaves

11Content Scanning ConditionsDecides which files of the resource the app looks at.

A collapsible section. Scan subdirectories looks for media in nested folders, and Show subfolders as items needs it. All Files mode lets you browse and manage every file, not only media; Show hidden files needs it. Disable thumbnails shows extension icons instead of previews, and Remember file list keeps a copy of the list for faster opening. Only the choices that fit the resource type are shown.

12Media TypesChooses which kinds of files the resource shows.

Tick Videos, Audio, Images, GIFs, Text, PDF, EPUB and Office documents. The boxes are locked while All Files mode is on. The section does not appear for resources that have no file types, such as a stream.

13Resource ProfileApplies a ready set of media settings in one tap.

The button shows the current profile and opens Resource Profile: Custom, Audio Library, Video Library, Photo Storage, Documents and File Manager Mode. A profile sets the media types, All Files mode and, for Audio Library, Remember file list at once. Custom changes nothing, so use the checkboxes to tune by hand afterwards.

14Destination SettingsMarks the resource for Quick Sort and can make it read-only.

Use as destination folder puts the resource on your Quick Sort list so you can send files to it. Read-only mode blocks copy, move and delete in it. Both together is a bad mix, because a read-only place cannot receive files, so a warning appears.

15Advanced SettingsOptional extras: a comment, a PIN and the slideshow interval.

Comment is a note for yourself. PIN Code (4-6 digits) protects the resource: the app asks for it before it opens the editor again, among other things. Slideshow Interval sets the seconds between pictures when this resource is played as a slideshow. Only the fields that fit the resource type are shown.

Information

16StatisticsFacts about the resource: size, dates and speed.

Shown only while you edit an existing resource. It lists the number of files and subfolders, when the resource was created and last opened, for network resources the last sync, and the read and write speed once they have been measured. A successful connection test refreshes the numbers.

17Add to Home ScreenPuts a shortcut to this resource on your home screen.

The shortcut uses the same icon as the editor shows. Android asks you to confirm it. If your launcher cannot place shortcuts, a message says so. The button sits inside the Statistics section.

18Warning noteA short reminder that appears when your edits need attention.

It can say that a read-only place cannot be a destination, that a changed path or address needs a rescan, or that another resource already has the same path. Each warning also opens in a window once, and the note stays until the cause is gone.

Choose an icon (icon picker)

19Icon set tabsSwitches between the icon sets: Music, Video, Image, Documents and Other.

The sheet opens on the set that suits your resource, based on its profile and type. Swipe the tab strip sideways if it does not fit the screen.

20IconsTapping an icon chooses it at once.

The icon in use is marked with a ring. One tap on another icon closes the sheet and puts it on the button in the editor; it is stored when you press Save Changes. To leave without a change, swipe the sheet down.
