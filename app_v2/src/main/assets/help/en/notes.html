Notes

What this is for

All your text notes in one list, newest first, with search. A new note is one tap away and opens straight in the text editor; every note is a plain text file in the Notes folder of Documents, so the file browser and other apps see it too.

In this order

  1. Tap New note 6 to start writing. The editor opens on an empty note; type, then save, and the note appears at the top of the list.
  2. Tap a note in the list 3 to open it in the editor. Each row shows the first line as the title, the next line below it and the time of the last change.
  3. To find a note, type in the search field 2. Only the notes whose text contains what you typed stay in the list.
  4. The button at the end of a row 4 shares the note's text or deletes the note. Deleting asks first.
  5. The back arrow 1 closes the screen. When there are no notes yet, a hint 5 says how to write the first one.

The elements

Title bar

1Back arrowLeaves the screen and returns to where you came from.

Nothing is lost: every note is already a file, and the list is read again the next time you open the screen.

Search and the list

2Search notesNarrows the list to the notes whose text contains what you type.

The search looks at the whole text of each note, not only its first line, and ignores upper and lower case. Clear the field to see every note again.

3List of notesEvery note of the Notes folder, newest first.

The first line of a note is its title and the next line is shown under it, so most notes need no name. Tap a row to open the note in the text editor; a long press opens the same actions as the button at the end of the row.

4More actions for this noteShares the note's text or deletes the note.

Share sends the text to any app that accepts text, such as a messenger or email. Delete asks for confirmation and then removes the file from the device.

5No notes yet. Tap New note to write the first one.Shown while there are no notes, or none matches the search.

Tap New note to write the first one.

Writing

6New noteCreates a new note and opens it in the text editor.

The note is named after the current date and time and saved in the Notes folder of Documents. Until you save it in the editor no file is written.
