Notes

What this is for

All your text notes in one list, newest first, with search. A new note is one tap away and opens straight in the text editor; every note is a plain text file in the Notes folder of Documents, so the file browser and other apps see it too.

In this order

  1. Tap New note 6 to start writing. The editor opens on an empty note; type, then save, and the note appears at the top of the list.
  2. Tap a note in the list 3 to open it in the editor. Each row shows the first line as the title, the next line below it and the time of the last change.
  3. To find a note, type in the search field 2. Only the notes whose text contains what you typed stay in the list.
  4. The button at the end of a row 4 sends the note's text through Send to.. or deletes the note. Deleting asks first.
  5. The back arrow 1 closes the screen. When there are no notes yet, a hint 5 says how to write the first one.
  6. To keep the notes on your other devices too, open My devices, open the menu of your exchange server and turn on Sync notes through the exchange server. The notes are encrypted for your own devices only; whoever runs the server sees only how many notes there are, their sizes and times. Once it is on, the title shows the sync state and Sync now 7 runs a sync at once.
  7. A note changed on two devices at the same time is kept twice, so no text is lost. A note that is too large to sync carries a mark 8 and stays on this device.

The elements

Title bar

1Back arrowLeaves the screen and returns to where you came from.

Nothing is lost: every note is already a file, and the list is read again the next time you open the screen.

Search and the list

2Search notesNarrows the list to the notes whose text contains what you type.

The search looks at the whole text of each note, not only its first line, and ignores upper and lower case. Clear the field to see every note again.

3List of notesEvery note of the Notes folder, newest first.

The first line of a note is its title and the next line is shown under it, so most notes need no name. Tap a row to open the note in the text editor; a long press opens the same actions as the button at the end of the row.

4More actions for this noteSends the note's text through Send to.. or deletes the note.

Send to.. offers the recipients you set up for the whole app, including any app that accepts text, such as a messenger or email. Delete asks for confirmation and then removes the file from the device.

5No notes yet. Tap New note to write the first one.Shown while there are no notes, or none matches the search.

Tap New note to write the first one.

Writing

6New noteCreates a new note and opens it in the text editor.

The note is named after the current date and time and saved in the Notes folder of Documents. Until you save it in the editor no file is written.

Sync with your other devices

7Sync nowSyncs the notes with your other devices at once.

It appears in the screen menu once Sync notes through the exchange server is on for one of your servers. The notes are encrypted for your own devices only, and whoever runs the server sees only how many notes there are, their sizes and times. Notes are also synced when you open the screen, return from the editor, connect to the server and whenever another device changes a note. A note changed on two devices at the same time is kept twice. If the server cannot be reached, the notes stay on this device and the title says so.

8Too large to syncMarks a note that is too large to sync.

Such a note stays on this device and is not sent. Shorten it, or split it into two notes, and it syncs with the next sync.
