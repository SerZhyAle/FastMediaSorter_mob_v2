Counter

What this is for

A tally counter for anything you count by hand: people through a gate, laps, items on a shelf. Every tap adds or removes one, the total is kept when you leave, and each finished count goes into a dated history.

In this order

  1. If the count should begin somewhere other than 0, press Starting number 7 first and type it. That number also becomes the current count.
  2. Press the big +1 key 4 each time you count one. The total 1 goes up at once. -1 3 takes one back, but never below 0.
  3. For bigger jumps, turn on the switch 5: a row of keys from +3 to +1000 6 appears.
  4. The line under the total 2 shows the starting number and when this count began.
  5. When a count is finished, press Reset 8. The total returns to the starting number and the finished count is saved in the history 9.
  6. Clear 10 empties the history when you no longer need it.

The elements

The count

1CountThe current total, in large digits.

The total is saved after every press, so it is still there when you leave the screen, switch to another app or restart the phone. It can go from 0 up to 999,999,999. A screen reader announces each change.

2Starting number and start timeReminds you what a reset returns to and since when you have been counting.

The first line reads Starting number and its value. The second line, Counting since and a date and time, appears after the first press following a reset; until then nothing has been counted, so there is no start time.

3Subtract oneTakes one away from the total.

Use it when you counted one too many. The key is grayed out at 0, because the total never goes negative.

4Add oneAdds one to the total with a single large key.

The key is large on purpose, so you can press it without looking. It has the focus when the screen opens, so on a keyboard or a remote you can press Enter or the center button at once. The first press after a reset also records the moment the count began.

Bigger steps

5More buttons: +3 to +1000Shows or hides the row of keys for bigger jumps.

When you count in tens or hundreds, one at a time is slow. The switch keeps those keys out of the way until you need them, and the app remembers your choice.

6Extra step keysAdd 3, 5, 10, 50, 100 or 1000 to the total with one press.

Six keys, +3, +5, +10, +50, +100 and +1000, each adding that number. They are shown only while the switch above is on. The total stops at 999,999,999.

Starting number, reset and history

7Starting numberSets the number the counter begins from and returns to after a reset.

A window asks for a whole number from 0. A new starting number also becomes the current count at once. If you were in the middle of a count, it is not saved in the history, so press Reset first when you want to keep it.

Undo
The count in progress is replaced by the starting number and is not archived. There is no undo.
8ResetFinishes the current count and starts over from the starting number.

A window asks first and tells you which number the counter will return to. The finished count goes to the top of the history with the time it began and the time it ended. If nothing was counted since the last reset, nothing is archived.

Undo
The total goes back to the starting number. The finished count is kept in the history, so you can read it there, but you cannot put it back on the counter.
9HistoryThe finished counts, newest first.

Each row shows the total and the period it was counted over, from the first press to the reset. The list holds the last 100 counts; older ones drop off. While it is empty it says there are no finished counts yet.

10ClearDeletes every finished count from the history.

A window asks first. The key is grayed out while the history is empty. The count on the screen is not touched.

Undo
The history is removed for good and cannot be restored.

Windows that ask for a decision

11Starting number fieldWhere you type the starting number.

The field opens with the current starting number selected, so you can type over it. Confirm with OK or with the Done key of the keyboard. An empty entry, a number below 0 or one above 999,999,999 keeps the window open and shows a message asking for a whole number from 0.

12OKAccepts the starting number.

The counter jumps to the new number and the start time is cleared until the next press.

13Reset the counter?Asks you to confirm before the count is finished.

It says the counter returns to the starting number and that the current count is saved to history. Press Reset to go ahead or Cancel to keep counting.

14Clear the counter history?Asks you to confirm before the history is deleted.

Press Clear to delete every finished count, or Cancel to keep them.

Undo
Cleared counts cannot be restored.
15CancelCloses the window and changes nothing.

It is on every window of this screen: the starting number stays as it was, the counter keeps its total and the history keeps its rows.
