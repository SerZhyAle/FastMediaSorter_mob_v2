Duplicates

What this is for

Duplicates finds files with identical content in the resources you pick, so you can free the space the extra copies take. Open it from the file browser, in the More actions: resource menu, with Find Duplicates, or with Find and Delete Duplicates to have the extra copies removed straight after the scan.

In this order

  1. Open the screen from the file browser: More actions: resource, then Find Duplicates. The resource you came from is already ticked in the list 2 and stands first.
  2. Tick the other resources to search too, or untick the ones you do not need. Start Scan 3 stays off while none is ticked.
  3. Press Start Scan 3. If a network or cloud resource is ticked, a window warns that the scan can take long and use a lot of traffic; confirm to go on.
  4. Watch the progress 4. Cancel 5 stops the search and nothing is deleted.
  5. Read the summary 6: how many groups of identical files were found and how much space they waste. Open a group 8 to see its copies.
  6. The app has already ticked every copy except the oldest one in each group 9. Untick any you want to keep, or tick more.
  7. Press Delete Selected 10 and confirm. The files are deleted and the screen closes.

The elements

Choosing what to scan

1BackCloses the screen; nothing is deleted by leaving.

The arrow in the toolbar, the Back button of the device and the Esc key all close the screen at once. The results of a finished scan are not kept, so a new visit starts from the beginning.

Shortcut
Esc
2Select resources to scan for duplicatesThe resources that will be searched, as chips you can tick.

Each chip carries the name of a resource and its type. A tick means the resource takes part in the scan; tap a chip to switch it. Several resources can be scanned together, so a copy of a photo in two different resources is found as well. If you opened the screen from a resource's menu, that resource is ticked and listed first.

3Start ScanStarts the search for files with identical content.

The button is off until at least one resource is ticked. Files are compared by their content, not by name: first by size, then by a short piece from the start, and only the files that still match are compared completely. Empty files are ignored. For network or cloud resources a window first warns that the scan may take a long time and a lot of traffic; press OK to continue. When you came through Find and Delete Duplicates, the pre-ticked copies are deleted as soon as the scan ends, without a further question - use Find Duplicates when you want to look first.

While the scan runs

4Scan progressShows what the scan is doing and how far it has come.

The stage appears in capital letters: LISTING while the files are collected, QUICK_HASH while the starts of equal-sized files are compared, and FULL_HASH while the remaining candidates are compared completely. Below it a counter shows the number of files processed out of the total.

5CancelStops the scan and brings you back to the list of resources.

Nothing is deleted by cancelling. You can change the ticked resources and start again.

Results and deletion

6Result summaryHow many groups of identical files were found and how much space is wasted.

The line reads, for example, Found 12 groups, then Wasted space and a size. Wasted space counts every copy except one per group, so it is the amount you can free.

7Duplicate groupsOne row per set of identical files.

Each group is a set of files with the same content. A group always holds at least two files. Scroll the list to go through all groups.

8Group headerNames the group and opens or closes its copies.

The title is the name of one file of the group, and the line under it gives the size of one file and the number of files. Tap the header to expand the group and see where each copy lies; all groups start collapsed.

9File row with checkboxOne copy: its name, its full path and a checkbox that marks it for deletion.

Tap the row or its checkbox to tick or untick the copy. A ticked copy is deleted when you press Delete Selected. Dragging a finger down along the checkboxes of one group ticks a whole range at once and never unticks. The app does not stop you from ticking every copy of a group, so keep at least one copy unticked. The row cannot open the file; use the path to find it in the file browser.

10Delete SelectedDeletes all ticked copies after you confirm.

The button appears as soon as at least one copy is ticked and shows how many files will go and how much space they take. A confirmation window with Delete and Cancel repeats the number and says the deletion cannot be undone. After deleting, a short message tells you the files are gone and the screen closes.

Undo
The selected files are lost. They stay in a hidden .trash folder of their resource only when Use trash folder (.trash) is switched on in Settings and the files are local ones that can be moved there; network and cloud files, and everything with the trash off, are deleted for good. Restoring from a backup is then the only way back.
11No duplicates found.Tells you that no identical files were found.

It appears when the scan has finished and there are no groups: nothing to delete in the chosen resources. Go back and pick other resources to search more.
