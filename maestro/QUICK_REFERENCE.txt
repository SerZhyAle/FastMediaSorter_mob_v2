## ⚡ Commands Cheat Sheet

```powershell

.\run-maestro-smoke-tests.ps1 -Test app_launch  # Single test
```

```yaml
# Basic structure
appId: com.sza.fastmediasorter
---
- launchApp                         # Launch app
- tapOn:
    text: "Button Text"             # Tap by text
    optional: true                  # Don't fail if not found
- assertVisible:
    id: "com.sza.fastmediasorter:id/element_id"

- backPress                         # Press back button
```

## 🐛 Common Issues

| Issue | Fix |
|-------|-----|
| "Element not found" | Add `optional: true` or update element ID |
| "No devices found" | Run `adb kill-server` then `adb devices` |
| "App crashes" | Clear data: `adb shell pm clear com.sza.fastmediasorter` |
| "Element not visible" | Add `waitForAnimationToEnd` before assertion |
| "Test timeout" | Increase timeout: `timeout: 10000` |
