# Задача: Сокращение списка возможностей и расширение сценариев использования (Standard / VR)

## Описание задачи
Текущий список возможностей приложения в `docs/FEATURES.md` (и его переводах) содержит более 60 пунктов. Многие из них описывают очень мелкие или технические функции (например, «Случайный выбор файлов», «Aspect ratio» и т. д.), что перегружает страницу и снижает фокус внимания.
Необходимо:
1. **Сократить список возможностей (Prune Features)**:
   - Объединить и удалить мелкие и неважные пункты в `docs/FEATURES.md`, `docs/FEATURES_RU.md` и `docs/FEATURES_UK.md`.
   - Оставить только ключевые, важные возможности (около 20–25 пунктов в сумме).
   - Убедиться, что структура разделов (от `0` до `16`) сохранена, но сами списки стали гораздо лаконичнее и информативнее.
2. **Расширить список сценариев использования (Increase Usage Scenarios)**:
   - Добавить 4 новых сценария на главные страницы (`index.html`, `index-ru.html`, `index-uk.html`), отражающих последние реализованные функции в Standard- и VR-сборках:
     - **Home-Screen Smart Widgets (Умные виджеты экрана)**: использование иконочных 1×1 виджетов (запись голоса, съёмка в ресурс, OCR с камеры) и настраиваемых панелей.
     - **OpenXR VR Immersive Cinema (Иммерсивный кинотеатр VR)**: виртуальный экран для 2D-видео, воспроизведение 3D-форматов (SBS/OU, VR180, 360°), Quest 3 Passthrough снимки.
     - **Text-to-Math Quick Calculation (Быстрые вычисления из текста)**: калькулятор для вычисления математических выражений, скопированных или распознанных через OCR/PDF/Lyrics.
     - **Cloud Markdown & Code Notes (Облачные заметки Markdown и код)**: создание и редактирование заметок `.txt`/`.md` напрямую на серверах SMB/SFTP/FTP/Cloud с подсветкой синтаксиса и Markdown-рендерингом.
   - Добавить подробные текстовые руководства по этим сценариям в `docs/HOW_TO.md`, `docs/HOW_TO_RU.md` и `docs/HOW_TO_UK.md`.
   - Обновить JS-код фильтрации сценариев на главной странице (`index.html`, `index-ru.html`, `index-uk.html`) для поддержки новых сценариев.

## UI/UX Решения
- **Отображение сценариев**: Новые сценарии добавляются в виде интерактивных карточек (с раскрывающимся `details` списком) в общую сетку сценариев.
- **Интеграция с фильтрами**: Новые сценарии должны корректно фильтроваться по кнопкам на панели. Для этого в JS будут добавлены соответствующие маппинги.
- **Поддерживаемые сборки**: Явно указать поддерживаемые сборки (Standard, VR, Legacy) на карточках сценариев с помощью существующих CSS-классов бейджей.
