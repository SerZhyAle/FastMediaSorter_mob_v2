## Описание проблемы

Критические пользовательские сценарии (добавление ресурса, OAuth, сканирование, редактирование) не покрыты автоматизированными UI-тестами. Регрессии обнаруживаются вручную после релиза.

## Цель

---

## Требования

### Критические сценарии для покрытия

1. **Добавление ресурса**
   - Добавить локальный ресурс → проверить появление в списке
   - Добавить SMB ресурс → проверить подключение
   - Добавить облачный ресурс (mock OAuth) → проверить сохранение

2. **OAuth Flow**
   - Успешная авторизация Google Drive → токен сохранён
   - Успешная авторизация OneDrive → токен сохранён
   - Отмена OAuth → корректное возвращение в приложение
   - Повторная авторизация при истёкшем токене

3. **Сканирование**
   - Запуск сканирования локальной папки → файлы появляются
   - Пустая папка → соответствующее сообщение
   - Отмена сканирования → корректная остановка

4. **Редактирование ресурса**
   - Изменить имя ресурса → сохраняется
   - Изменить путь → обновляется список файлов
   - Копирование ресурса → новый ресурс создан

5. **Welcome Screen**
   - Полный проход по всем страницам → переход в Main
   - Skip → переход в Main
   - Permissions grant flow
