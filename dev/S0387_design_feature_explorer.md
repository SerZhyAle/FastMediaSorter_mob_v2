## 2. Детализация Четырех Вариантов

### Вариант 1. Сгруппированный интерактивный рубрикатор (Category Explorer)
- **Интерфейс:** Внутри `.explorer-panel` рендерится горизонтальный список вкладок 7 крупных рубрик.
- **Логика:** При клике на рубрику отображаются фичи этой рубрики. Ключевые фичи выводятся в виде плиток с видимым описанием, остальные — списком `<details>` ниже.

### Вариант 2. Интерактивная карта возможностей (Media Dashboard)
- **Интерфейс:** Сетка из 4 больших колонок. Внутри каждой колонки — плоский список названий фич с иконками тегов.
- **Детальная шторка (Drawer):** При клике на название фичи сбоку (или снизу на мобильных) выезжает оверлей `.detail-drawer` с описанием и ссылками на сценарии.
- **CSS:** `.detail-drawer { position: fixed; right: 0; top: 0; width: 450px; height: 100%; transform: translateX(100%); transition: transform 0.3s ease; }` с прозрачным размытым бэкграундом.

### Вариант 3. Двухуровневый переключатель («Ключевые» / «Полный список»)
- **Интерфейс:** Переключатель «✨ Главное» / «📋 Все функции».
- **Главное:** Сетка карточек с открытым текстом для 15 ключевых функций.
- **Все функции:** Компактная древовидная структура (Категория -> Список фич мелким шрифтом без карточек).

### Вариант 4. Фильтр возможностей по сценариям использования (Scenario Filter)
- **Интерфейс:** Выпадающий список или строка тегов сценариев (Фоторамка, В авто, Кинотеатр, Настройка SMB, Автобэкап, Органайзер, Офлайн-папка, Документы из облака, OCR-перевод, NAS для TV, Очистка дубликатов, Chromecast).
- **Связь с карточками сценариев:** Клик по карточке сценария в верхней части сайта плавно скроллит к Feature Explorer, переключает вариант на «Фильтр сценариев» и применяет выбранный фильтр.
- **Сброс:** Отображается плашка `.filter-pill-active` с крестиком для очистки фильтра.

## 3. Таблица UI/UX Решений (UI/UX Gate)

| Параметр | Поведение в Портретном режиме (мобильные) | Поведение в Альбомном режиме (десктоп) |
|---|---|---|
| **Переключатель вариантов** | Горизонтальный scroll-bar кнопок. | Ряд кнопок в одну строчку. |
| **Drawer (Вариант 2)** | Выезжает снизу на 75% высоты экрана. | Выезжает справа (ширина 400px). |
| **Колонки Карты (Вариант 2)** | Складываются вертикально (1 колонка). | Горизонтальная сетка (4 колонки). |
| **Анимации** | Легкие CSS-transitions (transform, opacity). | Легкие CSS-transitions (transform, opacity). |
| **Доступность** | Переходы поддерживают фокус, закрытие по тапу вне шторки или по кнопке `ESC`. | Закрытие по клику на оверлей или по кнопке `ESC`. |
