# Постановка задачи: S0387 - Четыре варианта дашборда возможностей

## 1. Цель
Реализовать 4 концепции представления списка возможностей на главных страницах сайта проекта (`index.html`, `index-ru.html`, `index-uk.html`), добавив интерактивный переключатель (switcher), позволяющий пользователю переключаться между ними в реальном времени. Это позволит владельцу проекта визуально оценить каждый вариант в браузере и выбрать оптимальный.

## 2. Предлагаемые варианты интерфейса (согласно S0387)

1. **Вариант 1: Category Explorer (Рубрикатор категорий)**
   - Панель вкладок категорий (горизонтальная лента с прокруткой на мобильных, вертикальная колонка или горизонтальная сетка на десктопах).
   - Внутри выбранной категории крупные карточки для 2-3 ключевых фич и компактный аккордеон для остальных.

2. **Вариант 2: Media Dashboard (Карта медиа)**
   - 4 фиксированных блока: Источники (Sources), Обработка (Processing), Просмотр (Viewers), Среды (Platforms).
   - Клик на фичу открывает боковую шторку (drawer) или модальное окно с детальным описанием и ссылками на инструкции.

3. **Вариант 3: Ключевые / Все функции (Two-level Toggle)**
   - Крупный переключатель: «✨ Главное» (12-16 ключевых карточек, открытых сразу) и «📋 Все функции» (компактный текстовый список по категориям).

4. **Вариант 4: Scenario Filter (Фильтр по сценариям)**
   - При клике на карточку сценария вверху страницы происходит плавный скролл к блоку возможностей, и список фильтруется только по фичам этого сценария.
   - Отображается плавающий индикатор активного фильтра с кнопкой сброса.

## 3. UI/UX Решения и неопределенности (UI/UX Gate)

### 3.1 Размещение переключателя вариантов
- **Решение:** Добавить аккуратный ряд вкладок/кнопок над Feature Explorer со стилем glassmorphic: `Вариант интерфейса: [Рубрикатор] [Карта медиа] [Главное/Все] [Фильтр сценариев]`.
- На мобильных устройствах этот ряд кнопок будет прокручиваемым по горизонтали (`overflow-x: auto`).

### 3.2 Локализация текстов интерфейса
- Все элементы управления, плашки сценариев и кнопок должны иметь переводы на EN (`index.html`), RU (`index-ru.html`) и UK (`index-uk.html`).

### 3.3 Адаптивность и Стили
- Все новые стили добавляются в `styles.css`.
- Ограничение: Использовать только Vanilla CSS с переменными, обеспечивая плавность анимаций (transitions).
- На мобильных устройствах сетки перестраиваются в одну колонку, боковая шторка (для Варианта 2) выезжает снизу, а не справа.

- Разработать правила сопоставления фич со сценариями для Варианта 4.
