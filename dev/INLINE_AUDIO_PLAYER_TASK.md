# Задача: Inline Audio Player в списке файлов (Browse Screen)

## Описание
В режиме просмотра "только аудио" (Audio Only Mode) в списке файлов, для каждого трека необходимо добавить возможность прослушивания прямо из списка, без открытия полноэкранного плеера.

## Требования

### 1. UI Изменения (item_media_file.xml)
*   Добавить кнопку **Play/Pause** в элемент списка.
*   **Состояния кнопки:**
    1.  **Play (Default):** Обычная иконка Play.
    2.  **Playing (Vinyl):** Иконка "виниловой пластинки", которая **анимированно вращается**.
    3.  **Pause:** Иконка Pause (отображается при нажатии на вращающуюся пластинку).
*   Кнопка должна быть видна только в режиме "Audio Only".

### 2. Логика воспроизведения
*   **Play:** По клику на кнопку Play начинается воспроизведение выбранного трека.
    *   Плеер (`PlayerActivity`) **НЕ открывается**.
    *   Список остается текущим.
    *   Предыдущий играющий трек (если был) останавливается.
*   **Pause:** По клику на вращающуюся пластинку воспроизведение ставится на паузу, иконка меняется на Pause.
*   **Resume:** По клику на Pause воспроизведение продолжается.
*   **Stop:** При полной остановке или окончании списка состояние сбрасывается.

### 3. Автоматизация и навигация
*   **Auto-play Next:** По окончании трека автоматически начинается воспроизведение следующего файла в списке.
*   **Looping:** Если список закончился, воспроизведение начинается с **первого** файла (циклический список).
*   **Auto-scroll:** Список должен автоматически прокручиваться так, чтобы текущий проигрываемый трек всегда был **по центру экрана** (приблизительно).

## Уточненные требования (Решения)

1.  **Расположение кнопки:**
    *   **Справа**, после всех существующих кнопок (последняя в ряду).

2.  **Ресурсы:**
    *   Использовать существующий векторный ресурс `ic_vinyl_record.xml`.
    *   Анимация: вращение (rotate) программно.

3.  **Фоновое воспроизведение:**
    *   **Нет**. При выходе с экрана Browse музыка должна останавливаться. (Service пока не нужен).

4.  **Взаимодействие с элементом:**
    *   Клик по самому айтому (background) открывает **полный плеер** (существующее поведение).
    *   Клик по кнопке Play/Vinyl запускает **inline-воспроизведение**.

## Техническая реализация (Draft)

*   **Adapter:** `MediaFileAdapter` должен уметь обновлять состояние (Play/Pause/Idle) для конкретного item без полной перерисовки всего списка (использовать Payloads).
*   **ViewModel:** `BrowseViewModel` должен управлять `MediaPlayer` или взаимодействовать с существующим `MediaService`, но в "тихом" режиме (без отправки intent на открытие Activity).
*   **Scroll:** Использовать `LinearLayoutManager.scrollToPositionWithOffset` или `SmoothScroller` для центрирования.
