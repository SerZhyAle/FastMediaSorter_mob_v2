# Техническое Задание: Отображение случайных фотографий при воспроизведении музыки

## 1. Цель
Реализовать режим плеера, при котором во время воспроизведения аудиофайлов вместо статичной заглушки отображаются фотографии из выбранной пользователем папки (ресурса).

## 2. Логика Работы

### 2.1. Сценарий Активации
Функция активируется **только** если воспроизведение начато с **Аудиофайла**.
- Если старт с **Изображения** -> Работает стандартное Слайдшоу (с опцией "Музыка на фоне").
- Если старт с **Видео** -> Проигрывается видео (фото не показываются).
- Если старт с **Аудио** -> **Применяется новая опция "Фото при воспроизведении"**.

### 2.2. Принцип отображения
- **Аудио (Плейлист):** Воспроизводится по порядку (или как настроено в плеере), циклично (после последнего трека переход к первому).
- **Фото (Визуализация):**
    - Берутся из указанного в настройках ресурса.
    - Выбираются **случайным образом** (Random).
    - **Интервал смены:** Привязан к треку. **1 Песня = 1 Фотография**.
    - Смена фотографии происходит автоматически при переходе к следующему аудиофайлу.
    - *Временной интервал (таймер) не используется.*

### 2.3. Фильтрация контента
- Из выбранного для фона ресурса берутся **только статические изображения**.
- Видеофайлы, находящиеся в ресурсе для фона, **игнорируются**.

## 3. Пользовательский Интерфейс (UI)

### 3.1. Настройки (Settings -> Media -> Audio)
Добавить секцию конфигурации:
1.  **Toggle "Показывать фото при воспроизведении"** (Enable Photos during Audio).
2.  **Selector "Ресурс с фотографиями"** (Photo Source) - выбор папки.

### 3.2. Экран Плеера
Внешний вид должен соответствовать текущей реализации режима просмотра/слайдшоу:
- **Фон (Основная область):** Отображаемая фотография на полный экран.
- **Верхняя часть:** Путь/Имя текущего **файла фотографии**.
- **Нижний левый угол:** Название текущей **песни (аудиофайла)**.
- **Управление:**
    - Нажатие на название песни/область информации -> Пауза / Воспроизведение.
    - Стандартные жесты/кнопки плеера (Next/Prev) переключают песню (и, следовательно, фото).

## 4. Техническая Реализация

### 4.1. База Данных
- Добавить в настройки (`Settings`):
    - `enablePhotosDuringAudio: Boolean`
    - `audioBackgroundPhotosResourceId: String?` (или ID ресурса)

### 4.2. Плеер (PlayerActivity)
- При инициализации плеера определить тип стартового медиа.
- Если тип Audio и настройка включена:
    - Загрузить список файлов из `audioBackgroundPhotosResourceId`.
    - Отфильтровать только Image.
    - Перемешать (Shuffle).
    - При `onMediaItemTransition` (или смене трека) -> загружать следующее фото из перемешанного списка в `binding.imageView`.
    - Метаданные (текст сверху) обновлять данными Фото.
    - Метаданные (текст снизу/Overlay) обновлять данными Аудио.

- *Приоритет:* Определяется типом стартового файла. (Утверждено)
