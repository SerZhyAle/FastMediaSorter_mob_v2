# Дизайн-документ: Обоснование и Сценарий видео для Google Play Console

## 1. Структура обоснований (Основано на правилах Google 2024)

### FOREGROUND_SERVICE_DATA_SYNC
1.  **Категория**: "Other" (Фоновая синхронизация ресурсов).
    -   **Описание**: Приложение позволяет пользователям добавлять сетевые (SMB, FTP, SFTP) и облачные (Google Drive, Dropbox, OneDrive) ресурсы. Фоновая синхронизация необходима для периодического обновления метаданных файлов, подсчета количества элементов и проверки изменений без участия пользователя, чтобы при открытии приложения список файлов был актуальным.
2.  **Категория**: "Importing, exporting" (Запланированные файловые операции).
    -   **Описание**: Пользователь может запланировать массовые операции перемещения или копирования файлов (например, автоматический бэкап фото с телефона на домашний сервер NAS). Эти операции могут занимать длительное время и должны продолжаться, даже если приложение свернуто, чтобы гарантировать целостность данных.

### FOREGROUND_SERVICE_MEDIA_PLAYBACK
1.  **Категория**: "Media playback".
    -   **Описание**: Основная функция приложения — воспроизведение аудио и видео. Использование FGS медиа-плейбека позволяет музыке продолжать играть при выключенном экране или переключении на другие приложения, предоставляя управление через системную панель уведомлений.
2.  **Категория**: "Picture-in-Picture".
    -   **Описание**: Приложение поддерживает режим "Картинка в картинке" (PiP) для видео. Это позволяет пользователю продолжать просмотр видео в маленьком окне при использовании других приложений.

## 2. Сценарий видео (Video Script)

### Видео 1: DATA_SYNC (Запланированные операции и Синхронизация)
1.  **Начало**: Экран MainActivity, переход в Настройки -> Операции с файлами -> Запланированные операции.
2.  **Действие**: Создание новой операции: Перемещение из локальной папки "Camera" в сетевую папку (SMB).
3.  **Запуск**: Нажатие кнопки "Запустить сейчас".
4.  **Фон**: Сворачивание приложения (Home button).
5.  **Доказательство**: Опускание шторки уведомлений, демонстрация активного уведомления с прогресс-баром "Выполняется операция...".
6.  **Завершение**: Возврат в приложение, показ лога успешного завершения.

### Видео 2: MEDIA_PLAYBACK (Аудио и PiP)
1.  **Аудио**: Запуск проигрывания MP3 файла. Сворачивание приложения. Демонстрация управления в шторке.
2.  **PiP**: Запуск видео, нажатие кнопки Home (или кнопки PiP в плеере). Видео переходит в маленькое окно поверх рабочего стола.

## 3. Технические детали реализации
- Использование `WorkManager` с `setForeground()` для Data Sync.
- Использование `MediaSessionService` (Media3) для Audio.
- Для PiP: `onUserLeaveHint()` в `PlayerActivity` вызывает `enterPictureInPictureMode()`.
