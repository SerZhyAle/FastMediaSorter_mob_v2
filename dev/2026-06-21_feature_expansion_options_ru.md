# Варианты расширения функционала FastMediaSorter v2

Дата: 2026-06-21
Основа: сводка по внешним аналогам и ранее собранный market research.
Назначение: внутренний продуктовый документ для выбора следующих spec/task направлений.

## Короткий вывод

У FastMediaSorter уже сильная база по протоколам, операциям с файлами, просмотру, плееру, OCR, переводу и работе с NAS/cloud. Наиболее перспективное усиление продукта лежит не в добавлении ещё одного источника данных, а в надстройке над уже существующим движком:

- умная организация библиотеки;
- автоматизация бэкапа и синхронизации;
- приватность и защищённые пользовательские сценарии;
- ускорение массовой сортировки и отбора медиа.

Ниже перечислены наиболее реалистичные направления расширения функционала с примерной сложностью и предварительным приоритетом.

## Шкалы оценки

- Сложность:
  - Низкая - можно делать поверх уже существующих экранов и моделей без тяжёлой архитектурной перестройки.
  - Средняя - потребуется новая UI-логика, новые настройки, локальные модели данных или индексация.
  - Высокая - понадобится несколько подсистем, фоновые задачи, миграции данных, новый UX и расширенная валидация.
  - Очень высокая - потребуются тяжёлые алгоритмы, optional modules, ML/vision или сложная многоповерхностная интеграция.

- Предварительный приоритет:
  - P1 - самый сильный баланс ценности и реализуемости.
  - P2 - хорошее усиление продукта после P1.
  - P3 - стратегическое или нишевое направление, не первое в очереди.

## Кандидаты на расширение

## Самые сильные кандидаты на ближайший цикл

Если выбирать не всё сразу, а короткий список того, что даст лучший эффект на единицу усилий, то первыми выглядят такие направления:

1. Smart albums и saved filters.
2. Теги, рейтинги и review labels.
3. Global smart search.
4. Near-duplicate и burst review.
5. Background backup profiles.
6. Privacy-aware export/share presets.

## Рекомендуемый порядок реализации

### Волна 1 - максимальная ценность без тяжёлого ML

- Smart albums и saved filters.
- Теги, рейтинги и review labels.
- Calendar view.
- Global smart search по локально доступным данным.
- Privacy-aware export/share presets.

### Волна 2 - сильное усиление core-сценариев

- Near-duplicate и burst review.
- Background backup profiles.
- One-way album sync / camera mirror.
- Tree navigation.
- Best-shot workflow.

### Волна 3 - стратегические и дорогие направления

- Secure private vault.
- Map view.
- Dual-pane browser mode.
- People view / face clustering.
- Semantic image search.
- Shared albums / controlled share links.

## Практические spec-кандидаты

Из этого документа проще всего сразу выделить следующие будущие spec-и:

1. Smart albums + saved filters + pinning.
2. Tags/ratings/review labels + batch metadata actions.
3. Near-duplicate and burst review.
4. Background backup profiles for local/network/cloud targets.
5. Privacy-aware export/share presets.
6. Secure private vault.

## Замечания

- Оценки сложности предварительные и даны без детального AS-IS аудита по каждому направлению.
- Направления с ML, лицами и semantic search лучше изначально проектировать как optional/downloadable components.
- Наиболее естественное развитие текущего продукта - не превращать его в клон облачной галереи, а усилить его как local-first / NAS-first media organizer with power-user workflows.
