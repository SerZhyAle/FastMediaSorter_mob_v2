================================================================================
SCOPE OF EVERY PROMPT — standing context injected into each turn
================================================================================
Purpose: inventory of the non-user text Claude receives on every request, so the
user can judge token cost and relevance. Generated from a live turn on
2026-04-23. Token figures are approximate (1 tok ~ 3.5-4 chars EN / 2-3 chars RU).

Total standing overhead per turn: ~10,000-11,500 tokens BEFORE the user message
and BEFORE any tool output (reduced from ~12k by the 2026-04-23 CLAUDE.md
shrink — see bottom "HISTORY" section). Most of it is cached (Anthropic prompt
cache, 5-min TTL), so repeated turns within a session are cheap; cold turns
pay full price.

================================================================================
WHAT IS **NOT** IN EVERY PROMPT
================================================================================
  - Conversation history (grows per turn, compressed automatically near limit)
  - Tool results (appear only in the turn they return)
  - Skill bodies (loaded only when the skill is invoked)
  - Deferred-tool schemas (fetched on demand via ToolSearch)
  - Memory-file contents (only MEMORY.md index; full files read on demand)
  - Files under dev/, docs/, src/ (read on demand)

================================================================================
COST IMPLICATIONS (rough)
================================================================================
  - Warm turn (cached, within 5 min): ~standing context is $0-cheap; you pay
    mostly for the new user msg + new tool output + new assistant reply.
  - Cold turn (cache miss, first after >5 min idle): full ~12k tokens re-read
    from scratch.
  - Practical advice: batching related questions in one session keeps cache
    warm. Long idle gaps between messages pay the cache-miss tax.
