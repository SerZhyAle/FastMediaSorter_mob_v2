# Translation Overlay Improvements (Dec 14, 2025)

## Проблема
По скриншотам и логам обнаружены 3 проблемы при переводе с русского на английский:

1. **OCR артефакты** - Tesseract распознавал шум как текстовые блоки (`\ I and 7 AI |`)
2. **Неправильное позиционирование** - блоки делились на части с неверными координатами
3. **Слишком большой текст** - размер шрифта не адаптировался под английский

## Решения

### 1. Фильтрация OCR блоков (TranslationManager.kt)

Добавлена интеллектуальная фильтрация **до перевода**:

```kotlin
// Критерии фильтрации:
1. Confidence < 30% → отбрасывается
2. Длина < 3 символов → отбрасывается  
3. > 50% спецсимволов (|, _, ^, --) → отбрасывается
4. Размер бокса < 20x10 px → отбрасывается
```

**Результат:** блоки-артефакты (`\ I and 7 AI |`, `т |`, `^ |`) фильтруются автоматически.

### 2. Улучшенный рендеринг (TranslationOverlayView.kt)

#### Language-agnostic дизайн

Все параметры одинаково работают для **любого направления перевода**:
- ✅ ru → en
- ✅ en → ru  
- ✅ uk → en
- ✅ любой другой язык

#### Оптимизация параметров

**Было:**
```kotlin
minTextSize = 8sp   // слишком мелко для английского
maxTextSize = 20sp
textSize = boxHeight * 0.55  // недостаточно для заполнения
padding = 2sp (fixed)
letterSpacing = 0 (default)
```

**Стало:**
```kotlin
minTextSize = 10sp  // лучше читаемость латиницы
maxTextSize = 24sp  // больше для крупных блоков
textSize = boxHeight * (0.6 + lengthFactor * 0.1)  // адаптивно
padding = 2-4sp (adaptive)  // зависит от размера бокса
letterSpacing = 0.02f  // для кириллицы и латиницы
```

#### Улучшенное позиционирование

1. **Адаптивный размер шрифта:**
   - Базовый: 60% высоты бокса
   - Коррекция по длине текста: короткий текст → чуть крупнее
   - Уменьшение при многострочности: до 60% от начального (min 10sp)

2. **Точное вертикальное центрирование:**
   ```kotlin
   textStartY = scaledTop + (finalBoxHeight - staticLayout.height) / 2
   ```
   Всегда центрируется, независимо от размера текста.

3. **Адаптивные отступы:**
   ```kotlin
   padding = 2sp + (boxHeight / 100).coerceIn(0, 2sp)
   ```
   Больше бокс → больше отступы.

#### Интерактивность

**Поднятие блока наверх (z-order):**
- ✅ Работает на любом языке
- ✅ Tap detection через `scaledRects`
- ✅ Перемещение блока в конец списка → top of z-order

```kotlin
override fun onTouchEvent(event: MotionEvent): Boolean {
    if (event.action == MotionEvent.ACTION_DOWN) {
        for (i in translatedBlocks.indices.reversed()) {
            if (scaledRects[i].contains(x, y)) {
                val block = translatedBlocks.removeAt(i)
                translatedBlocks.add(block)  // → top
                invalidate()
                return true
            }
        }
    }
}
```
