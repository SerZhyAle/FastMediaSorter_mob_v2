## 1. Decentralized Sync

### Objective

Sync files freely without internet dependence.

### Tactical Initiatives

- [ ] **Mesh Network**:
  - implement Wi-Fi Direct and Bluetooth Low Energy discovery.
  - create a protocol for decentralized file table exchange.
- [ ] **Resilient Transfer**:
  - break files into chunks for reliable transfer over unstable connections.

## 2. AR / VR Experience

### Objective

Immerse users in their media.

### Tactical Initiatives

- [ ] **AR Gallery**:
  - use ARCore to project photo walls on real-world surfaces.
- [ ] **VR Viewer**:
  - support Cardboard/Daydream SDKs for 360-degree content.
