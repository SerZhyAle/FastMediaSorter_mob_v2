# План разработки: Фотографии во время воспроизведения музыки
Каждый шаг должен сопровождаться сборкой (Build) и фиксацией изменений (Commit).

## Шаг 1: Слой данных и Настройки
**Цель:** Добавить поддержку новых настроек в модель данных и репозиторий.

**Prompt:**
```markdown
Задача: Обновить слой данных для поддержки функции "Фото во время музыки".

1.  Измени `AppSettings.kt`: добавь поля:
    *   `val enablePhotosDuringAudio: Boolean = false`
    *   `val audioBackgroundPhotosResourceId: String? = null`
2.  Обнови мапперы и репозиторий (`SettingsRepositoryImpl`, `DataStore` или Room Entity), чтобы эти поля сохранялись и восстанавливались.
3.  Выполни миграцию базы данных/DataStore, если требуется (увеличь версию схемы или обеспечь обратную совместимость).
4.  Проверь сборку проекта (`assembleDebug`).
```

## Шаг 2: UI Настроек (Audio Settings)
**Цель:** Добавить элементы управления в экран "Настройки -> Медиа -> Аудио".

**Prompt:**
```markdown
Задача: Добавить UI для настройки "Фото во время музыки" в `AudioSettingsFragment`.

1.  В `fragment_settings_audio.xml`:
    *   Добавь `MaterialSwitch` с текстом "Показывать фото при воспроизведении".
    *   Добавь кнопку/поле (Selector) "Ресурс с фотографиями", которое видно только если свич включен.
2.  В `AudioSettingsFragment.kt` (и ViewModel):
    *   Привяжи свич к `settings.enablePhotosDuringAudio`.
    *   При нажатии на выбор ресурса открывай диалог выбора папки (аналогично тому, как это сделано для слайдшоу).
    *   Сохраняй выбранный ID ресурса в `settings.audioBackgroundPhotosResourceId`.
3.  Проверь сборку проекта.
```

## Шаг 3: Логика Плеера (Загрузка данных)
**Цель:** Научить плеер загружать список фото, если воспроизводится аудио.

**Prompt:**
```markdown
Задача: Реализовать логику загрузки фото фона в `PlayerViewModel`.

1.  В `PlayerViewModel` добавь логику проверки при старте:
    *   Если текущий медиа-файл - Аудио И `settings.enablePhotosDuringAudio == true`:
        *   Загрузи список изображений из `settings.audioBackgroundPhotosResourceId`.
        *   Отфильтруй только статические изображения (исключи видео).
        *   Перемешай список (Shuffle).
        *   Сохрани этот список в состояние (`StateFlow`).
2.  Добавь логику: "1 Песня = 1 Фото".
    *   При смене трека (`onMediaItemTransition`) обновляй текущий индекс фото (следующий по кругу из перемешанного списка).
3.  Проверь сборку проекта.
```

## Шаг 4: UI Плеера (Отображение)
**Цель:** Показывать загруженные фото в Activity плеера.

**Prompt:**
```markdown
Задача: Отображать фото-фон в `PlayerActivity`.

1.  В `PlayerActivity` подпишись на обновление "текущего фото фона" из ViewModel.
2.  Если фото доступно (режим аудио + фото включен):
    *   Загружай фото в основной `ImageView` (используя Glide).
    *   Обеспечь, чтобы фото показывалось как фон (под контролами).
    *   Обнови отображение названия файла (сверху) - должно быть имя файла фото? (Или оставить пустым? В ТЗ: "Путь/Имя текущего файла фотографии").
3.  Убедись, что клик по центру/инфо ставит аудио на паузу (стандартное поведение).
4.  Проверь сборку и работу фичи.
```
