При создании локального/сетевого/облачного ресурса пусть выпадающим списком спрашивает о поддержке типов файлов. Так например, ресурс может быть "Аудиотекой, Видеотекой, Фотохранилищем, Документы, Все файлы". И в зависимости от выбора, при добавлении ресурса, будет устанавливать фильтры по выбранному типу.

Если ресурс типовой ("Аудиотекой, Видеотекой, Фотохранилище, Документы, Все файлы"), то окно Browse  вбудущем будет для него уникальное. Как сейчас реализовано для аудиотеки.

Если у ресурса стоит признак "Запоминать список файлов ля этого ресурса":

- Для аудиотеки (без галочки "НЕ Загружать миниатюры") мы будет загружать миниатюры из встроенных обложек
 Будем при сканировании загружать имя исполнителя, наименование трека, длительность для демонстрации вместе с именем файла прямо в списке. Кроме того по ним можно сортировать и отбирать файлы.

- Для Видеотеки - длительность, разрешение.

- Для Фотохранилища - разрешение, дата съемки (если есть в EXIF)

- Для Документов - посмотрим.
