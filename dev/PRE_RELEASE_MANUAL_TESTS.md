# FastMediaSorter v2 — Полный предрелизный сценарий ручного тестирования

**Дата создания**: 2026-03-01  
**Автор**: Pre-release QA  
**Flavor**: `standard` (единственный, покрывающий все функции)  
**Цель**: Полный проход всех функций приложения вручную с сохранением лога из каждого блока

## Перед стартом: подготовка ресурсов

Все ресурсы должны быть настроены ДО начала тестирования. Ниже — минимальный набор:

| Ресурс | Тип | Требования |
|---|---|---|
| `LOCAL – DCIM` | Local | 30+ медиафайлов (фото + видео + аудио) |
| `LOCAL – Android/media` | Local | Папка Telegram или WhatsApp (для теста запрещённого soft-delete) |
| `LOCAL – Docs` | Local | 2-3 PDF, TXT, EPUB файла |
| `LOCAL – Dest` | Local | Пустая папка назначения на устройстве |
| `SMB` | Network SMB | Читаемый + записываемый шар с 10+ медиафайлами |
| `SFTP` | Network SFTP | SSH-сервер, доступные медиафайлы |
| `FTP` | Network FTP | FTP-сервер, доступные медиафайлы |
| `Google Drive` | Cloud | Авторизован, папка с 5+ фото |
| `OneDrive` | Cloud | Авторизован, папка с 5+ фото |
| `Dropbox` | Cloud | Авторизован, папка с 5+ фото |

**Сбор лога (после каждого БЛОКА):**  
`Settings → General → System → "Current Session Log"` → нажать → Copy to clipboard  
→ Вставить в файл `temp/manual_test_log_BLOCK_N.txt`  

Отдельная кнопка для экспорта файла: `Settings → General → Files & Data → "Export Debug Logs"`

## БЛОК 0 — Базовая конфигурация приложения

**Цель:** Убедиться, что настройки сохраняются и применяются корректно.

### 0.1 Общие настройки

- [ ] `Settings → General → Language`: сменить язык → вернуться → убедиться, что UI обновился → вернуть исходный.
- [ ] `Settings → General → Files & Data → "Export All Settings to File"` → нажать → убедиться, что файл `Downloads/FastMediaSorter_export.xml` создан (видно всплывающую подсказку с путём).
- [ ] `Settings → General → Files & Data → "Import Settings from File"` → убедиться, что кнопка доступна и открывается file-picker (или файл автоматически найден в Downloads).
- [ ] Тема приложения следует системной (нет отдельного переключателя): переключить Dark/Light в системных настройках Android → убедиться, что приложение меняет тему корректно.
- [ ] Тема reader'а: открыть TXT или EPUB → внутри viewer найти переключатель темы (Light / Dark / Sepia) → убедиться что все три варианта применяются.

### 0.2 Настройки просмотра

**Примечание:** Вкладки «Browse» не существует. Thumbnails — в `Settings → Media`; сортировка и вид (list/grid) — per-session кнопки прямо в Browse.

- [ ] `Settings → Media → "Disable thumbnails"` → включить → открыть любой ресурс → убедиться, что thumbnails не отображаются → выключить обратно.
- [ ] В Browse нажать кнопку **Sort** → выбрать «Date ↓ (newest first)» → убедиться, что список пересортировался.
- [ ] В Browse переключить вид **List → Grid → List** (кнопки в toolbar) → убедиться, что вид меняется.
- [ ] `Settings → Media → "Show video thumbnails"` → включить → открыть папку с видео → убедиться, что превью первого кадра появляются.

### 0.3 Защита ресурса PIN-кодом

**Примечание:** Нет глобального PIN-кода для приложения. PIN защищает конкретный ресурс (папку/подключение).

- [ ] Главный экран → долгое нажатие на любой ресурс → «Edit resource» → поле **"PIN Code (Optional)"** → ввести 4–6 цифр → Save.
- [ ] Открыть защищённый ресурс → убедиться: появляется диалог **"Access PIN"** → ввести PIN → Browse открылся.
- [ ] Снять PIN: Edit resource → очистить поле PIN → Save → ресурс открывается без PIN.

**→ СОХРАНИТЬ ЛОГ: `LOG_BLOCK_0_CONFIG.txt`**

## БЛОК 1 — LOCAL ресурс: базовые операции с файлами

**Источник:** `LOCAL – DCIM`  
**Назначение:** `LOCAL – Dest`

### 1.1 Просмотр (Browse)

- [ ] Главный экран → долгое нажатие на `LOCAL – DCIM` → открыть Browse.
- [ ] Убедиться: файлы загрузились, счётчик соответствует реальному числу файлов.
- [ ] Переключить вид: **List → Grid → List**. В Grid: проверить количество колонок с thumbnails и без.
- [ ] Thumbnails off → Grid: убедиться, что ячейки широкие (1-2 колонки), текст не обрезан.
- [ ] Нажать кнопку **Refresh** → файлы перегрузились, список актуален.
- [ ] Открыть **подпапку** (если есть) → убедиться в навигации вглубь → вернуться Back.

### 1.2 Фильтрация и сортировка

- [ ] **Sort** → по имени (A→Z) → проверить порядок → Sort → по дате (новые сверху).
- [ ] **Filter** → имя содержит "IMG" → применить → убедиться: показаны только содержащие "IMG" → Clear filter → все файлы вернулись.
- [ ] **Filter** → размер > 1 МБ → применить → проверить что мелкие файлы скрыты.
- [ ] Убедиться: внизу появляется предупреждение "Фильтр активен".

### 1.3 Копирование (без перезагрузки)

- [ ] Выбрать 3 файла (долгое нажатие + тапы).
- [ ] Нажать **Copy → выбрать `LOCAL – Dest`**.
- [ ] Дождаться завершения. Toast "Copied 3 files".
- [ ] **КРИТИЧНО:** Убедиться, что файлы остались в списке источника.
- [ ] **КРИТИЧНО:** Лог НЕ содержит `reloadFiles` или `loadResource` после операции.
- [ ] Открыть `LOCAL – Dest` → 3 файла появились.

### 1.4 Перемещение (мгновенное удаление из списка)

- [ ] Выбрать 2 файла в `LOCAL – DCIM`.
- [ ] Нажать **Move → `LOCAL – Dest`**.
- [ ] **КРИТИЧНО:** 2 файла исчезли из списка МГНОВЕННО (без перезагрузки всего списка).
- [ ] Лог содержит `removeFiles: Removed 2 files`, НЕ `reloadFiles`.
- [ ] В `LOCAL – Dest` — 2 файла добавились.

### 1.5 Переименование

- [ ] Выбрать 1 файл → **Rename** → ввести "test_pre_release_01.jpg" → Apply.
- [ ] Убедиться: файл переименован в списке.
- [ ] Лог: операция rename отражена.

### 1.6 Удаление — soft-delete (в корзину)

- [ ] Включить soft-delete в настройках, если не включён.
- [ ] Выбрать 1 файл из обычной локальной папки → **Delete** → Confirm.
- [ ] Файл исчез из списка мгновенно.
- [ ] Проверить файлом-менеджером: файл в `.trash_<timestamp>/` рядом с оригинальной папкой.
- [ ] Лог: `softDelete=true`.

### 1.7 Отмена (Undo)

- [ ] После операции Delete/Move — нажать **Undo** (кнопка или жест).
- [ ] Файл вернулся на место.
- [ ] Лог: `undo` операция.

### 1.8 Удаление папки Android/media (ЗАЩИТА)

- [ ] Открыть `LOCAL – Android/media` (Telegram).
- [ ] Выбрать любой файл → **Delete** → Confirm.
- [ ] **КРИТИЧНО:** Файл удалён ЖЁСТКО (hard delete, без корзины). Нет EPERM ошибок в логе.
- [ ] Лог: `softDelete=false`, `DeletePathPolicy: isProtectedAndroidMediaPath=true`.

### 1.9 Удаление со множественным выбором (overwrite policy)

- [ ] Скопировать 2 файла в `LOCAL – Dest` ещё раз (те же файлы → конфликт имён).
- [ ] Убедиться: появился диалог выбора политики перезаписи (skip / overwrite / rename).
- [ ] Выбрать **Rename** → оба файла скопировались с суффиксом.

**→ СОХРАНИТЬ ЛОГ: `LOG_BLOCK_1_LOCAL.txt`**

## Анализ логов: ключевые слова

### ✅ ХОРОШО — должно быть:
```
removeFiles: Removed N files          ← после Move/Delete
softDelete=false                      ← для SMB, SFTP, FTP, Android/media
DeletePathPolicy: isProtectedAndroid  ← при удалении из Telegram/WhatsApp
Grid calculation - showThumbnails=false, spanCount=1-2
SMB Connection Recovery               ← если были разрывы, но восстановилось
Copy operation completed successfully
```

### ❌ ПЛОХО — не должно быть (после Copy):
```
reloadFiles
loadResource          ← вызван после Copy — баг
MediaStore changed, reloading files   ← после Copy/Delete — потенциальный баг
```

### 🔴 КРИТИЧЕСКИЕ ОШИБКИ — немедленно фиксировать:
```
FTP authentication failed
connection pool exhausted
socket timeout                        ← частые — баг
NullPointerException
EPERM                                 ← ошибка доступа к .trash
Failed to remove files
OutOfMemoryError
```
