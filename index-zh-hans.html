安装

Android - 设备外壳

您 Android 设备的完整外壳。

主屏幕、媒体、直播流、应用、手表和文件 - 一站式集成。

Fast Media Sorter & Organizer 接管您的主屏幕，成为一切操作的起点：设备外壳、媒体播放器、直播流、应用启动、系统自带应用的替代品、手表端的伴侣应用、设备监控，以及支持本地存储、SMB/NAS、SFTP/FTP 和云盘的完整文件管理器。

打开您的第一个文件夹

最安全的第一步只是查看本地文件夹。在您选择复制或移动之前，文件不会发生任何改变。

Google Play GitHub Releases IzzyOnDroid
  1. 安装适合的版本并打开应用。
  2. 如果 Android 请求文件访问权限，请予以允许。
  3. 点击“添加资源”，选择一个本地文件夹，并在整理前查看其内容。
重要

整理功能需要文件访问权限。移动前请先检查您的选择；若需要可撤回的操作，请先使用复制。

完整功能目录

替代十几款应用

Fast Media Sorter 集媒体浏览器、查看器、播放器、文件管理器和整理工具于一体。您无需为视频、音乐、图库、阅读、网络文件夹、云存储和日常文件操作分别安装不同的应用，只需使用一套集合、一组熟悉的操作即可完成。下方列出的应用仅作为功能的参照对象，并非比较排名。

查看与播放

  • 视频播放器 (MX Player、VLC) - 视频、蓝光 TS/.m2ts、画中画、逐帧截图、Chromecast 投屏。
  • 音频播放器 (Poweramp、AIMP) - 后台播放、歌词、MIDI、睡眠定时器、可视化效果、通知栏控制。
  • 图库 / 图片查看器 (QuickPic、Google Photos) - 图片与 GIF、裁剪、滤镜、旋转。
  • PDF / EPUB 阅读器 (Adobe Reader、Moon+ Reader) - 电子书、章节目录、主题、朗读（TTS）。
  • 幻灯片 / 电子相框 - 配有背景音乐的循环照片播放，附带电子相框小组件。
  • 电视媒体中心 (Kodi、Nova Video Player) - 支持方向键、键盘、鼠标、手柄，以及电视遥控器友好的浏览与播放。
  • VR 媒体播放器 (Pigasus、Skybox VR) - 立体 SBS/OU、VR180、360°、虚拟影院大屏幕。VR 版
  • 网络电台 / IPTV 播放器 (TuneIn、Online Radio、RadioDroid、VLC network) - “直播流”界面可播放 http/https 电台、HLS/DASH 及 RTSP 源；内嵌迷你播放器显示 ICY 正在播放信息；提供精选电台目录。

拍摄与创作

  • 相机 (系统自带相机) - 直接将照片和视频保存到您选择的本地、网络或云文件夹。
  • 录音机 - 语音备忘录，附带快速录音小组件。
  • 绘图编辑器 - 画布、画笔、形状、文字，可自定义画笔颜色和粗细。
  • 文档 / 文本扫描器 (Google Lens、CamScanner) - 通过相机进行设备端 OCR 识别，支持区域裁剪。

文件管理

  • 文件管理器 (Total Commander、ES File Explorer、Files by Google) - 本地、网络和云端文件一站式管理。
  • FTP/SFTP/SMB 客户端 (AndFTP、Solid Explorer) - 支持 SSH 密钥和主机密钥锁定的网络资源。
  • 云端客户端 (Google Drive、Dropbox、OneDrive) - 将云盘作为媒体来源。
  • 重复文件查找 (Duplicate Files Fixer) - 三阶段引擎：大小 -> 哈希 -> SHA-256。
  • 回收站 (Dumpster) - 软删除，一键恢复。
  • 压缩包解压 (ZArchiver) - 支持 ZIP 解压，包括带密码保护的压缩包。基础功能
  • 下载管理器 (1DM、ADM) - 粘贴链接，直接保存到您选择的文件夹。
  • 任务计划 - 定时执行文件操作。

文本与实用工具

  • 文本 / Markdown 编辑器 - 编辑 .txt/.md 文件，支持语法高亮和自动保存。
  • 翻译工具 (Google 翻译离线版) - 完全离线翻译。
  • 计算器 - 内置功能，可直接对所选文本中的表达式求值。基础功能
  • 投屏到电视 (Google Home) - 支持 Chromecast 投射视频和音频。
  • 主屏幕小组件包 - 提供录音机、相机 OCR、计划任务、正在播放和电子相框的快速启动与状态小组件。
  • 设置备份工具 - 导出和恢复应用设置、资源、收藏、计划任务、密码和登录信息。仅限应用设置

诚实说明：计算器和压缩工具功能较为基础（从文本求值 / ZIP 解压），并非完整替代品。设置备份仅涵盖应用自身的设置，而非整机备份。VR 播放器仅限 VR 版使用。

Windows 文件夹共享（电脑伴侣）

标准版 / Photos / Legacy

直接从 Windows 电脑将文件夹共享给应用：免费的 Fast Media Sorter for Windows 会为此运行一个安全的 SFTP 服务器 - 配对只需导入一个配置文件，无需手动输入主机、端口或密钥。

详情
  • 在电脑上安装 Fast Media Sorter for Windows：GitHub 发布页、winget install SerZhyAle.FastMediaSorter，或在 Microsoft Store 中搜索“FastMediaSorter LITE”（以其旧名称发布）。
  • 在电脑上选择要共享的文件夹 - 服务器、密钥和自启动均会自动配置。
  • 在手机上：添加资源 > SFTP/FTP > 从伴侣应用导入，然后打开导出的 .fmscfg 文件。
  • 电脑端详细指南：如何为 Android 发布文件夹。
