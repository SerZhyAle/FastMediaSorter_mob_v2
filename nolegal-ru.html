Только sideload • Нет в Google Play и Meta Horizon Store

Эта страница описывает сборку noLegal приложения Fast Media Sorter - личную версию только для sideload. Она построена поверх VR-версии и добавляет возможности, которые нельзя распространять через Google Play или Meta Horizon Store из-за лицензий на перераспространение, политик магазинов, патентных ограничений или тяжёлого рантайма на устройстве.

Эта страница не рекламируется с основного сайта, но подписанный sideload-APK доступен ниже для тех, кто целенаправленно его ищет - здесь также показано, что сборка умеет и почему эти возможности остаются вне опубликованных флейворов.

В основе это та же полноценная оболочка Android-устройства, что и основное приложение: оболочка устройства, медиаплеер, трансляции, запуск программ, замена штатных программ, спутник на часах, мониторинг устройства и полный файловый менеджер.

Как noLegal соотносится с другими сборками

Fast Media Sorter выходит в виде вложенных сборок. Каждый уровень - надмножество предыдущего: noLegal = VR + возможности только для sideload, а сама VR уже содержит всё из Standard.

Standard

Мобильные · ТВ · Авто · публикуется в Google Play

Полное ядро сортировки медиа: просмотр локально / SMB / SFTP / FTP / облако, плеер и слайдшоу, чтение EPUB, перевод через OCR, пакетные операции с файлами, компаньон для Wear OS.

Meta Quest / XR · sideload

noLegal

Только sideload · нет ни в одном магазине

Всё из VR-версии плюс возможности ниже - они держатся вне каждого опубликованного флейвора, потому что их зависимости, разрешения или вес рантайма несовместимы с распространением через магазины.

Возможности только noLegal

Каждая возможность ниже реализована и изолирована в исходниках noLegal. Для каждой блок «Почему не в магазинах» называет конкретную причину.

1 Универсальный загрузчик медиа (yt-dlp + Chaquopy)

Загружает медиа с 1800+ сайтов (YouTube, Instagram, TikTok, Facebook, Threads, X и других) через Python-библиотеку yt-dlp, работающую на устройстве через Chaquopy. Cookie авторизации, сохранённые после входа через WebView, автоматически передаются в yt-dlp - повторный вход не нужен.

  • Instagram: отдельные посты, целые карусели, Reels и Stories (с cookie авторизации).
  • TikTok: видео без водяного знака через явный фильтр формата, с откатом к лучшему доступному.
  • Facebook: публичные видео с cookie авторизации.
  • Карусели / плейлисты раскрываются в пакет, где каждый элемент снова входит в цепочку извлечения.
  • Первый в цепочке извлечения; при неприменимости откатывается к NewPipe и WebView-экстрактору.
  • ABI: только arm64-v8a и x86_64 (доступность wheel для Python 3.12).

Почему не в магазинах: Chaquopy поставляется по некоммерческой / open-source community-лицензии; зависимость yt-dlp mutagen под GPL-2.0; пакет добавляет ~12-16 МБ на каждый ABI-срез и несовместим с требованием Google Play о страницах 16 КБ на Android 15.

2 Нативные экстракторы сайтов (ArtStation, DeviantArt, Vimeo, Dailymotion, Telegram)

Экстракторы на чистом Kotlin, которые получают прямые ссылки на медиа без рендеринга браузера, обычно меньше чем за секунду. Для своих площадок они идут впереди yt-dlp; yt-dlp остаётся запасным.

  • ArtStation: внутренний JSON-API проектов для получения оригинального изображения или клипа.
  • DeviantArt: разбор начального состояния страницы, с откатом на oEmbed при ошибке разбора.
  • Vimeo: чтение JSON-конфига плеера для выбора самого высокого прогрессивного MP4 или HLS.
  • Dailymotion: извлекает временный HLS-поток и сразу загружает (токены быстро истекают).
  • Публичные посты Telegram: разбор публичной embed-страницы для фото и видео; одно вложение скачивается напрямую, альбом возвращает пакет. Приватные / invite-ссылки отклоняются.
  • Без новых зависимостей - Kotlin и уже включённая в APK библиотека JSON.

Почему не в магазинах: часть неопубликованной поверхности извлечения noLegal; идёт в связке с цепочкой yt-dlp, которая и так блокирует публикацию в магазинах.

3 Установка APK из браузера файлов

Нажмите на любой файл .apk в браузере, чтобы получить действие «Установить», которое запускает системный установщик - пользователь всегда видит и подтверждает стандартный диалог установки.

  • Проверяет разрешение на установку пакетов и направляет в системные настройки, если его нет.
  • Сообщает об успехе, отмене или ошибке установки через тост.
  • Установка прямо из Google Drive / Dropbox / OneDrive: файл тихо скачивается в кэш под своим реальным именем, затем открывается системный установщик.
  • Браузер помечает APK-плитки компактным VR-значком, если пакет заявляет поддержку Quest / VR.

Почему не в магазинах: разрешение REQUEST_INSTALL_PACKAGES вызывает проверку высокого риска в Google Play и отклоняется для обычных файловых менеджеров без MDM / корпоративного контекста.

4 Восстановление извлечения YouTube и YouTube Music

Надёжная загрузка по ссылкам YouTube и YouTube Music: NewPipe и yt-dlp работают вместе, так что несовпадения форматов больше не ломают загрузку.

  • Когда yt-dlp ловит ошибку формата YouTube (PoToken / JS-челлендж), цепочка откатывается к стратегии NewPipe (Innertube).
  • YouTube - известный ресурс авторизации: появляется выбор аккаунта, применяются сохранённые cookie.
  • Канонизация URL переписывает ссылки music.youtube.com и shorts в обычную форму watch, которую резолверы принимают надёжно.
  • Выбор только-аудио формата для YouTube Music; передача чанками с диапазонами для Shorts и длинных видео.

Почему не в магазинах: построено на том же стеке извлечения yt-dlp / NewPipe, который исключён из опубликованных сборок.

5 Офлайн-OCR PaddleOCR (PP-OCRv5 + Paddle-Lite)

Движок офлайн-OCR на глубоком обучении, выбираемый в настройках рядом с Tesseract. Он справляется с реальными фото - перспективные искажения, тени, блики, шумный фон - заметно лучше Tesseract, полностью на устройстве, без сетевых вызовов во время распознавания.

  • Конвейер: детекция текста → классификация ориентации строки → распознавание (PP-OCRv5 mobile).
  • Нативный рантайм Paddle-Lite, выровнен под страницы 16 КБ для Android 15; ABI только arm64-v8a.
  • Модели лениво скачиваются при первом использовании по HTTPS и проверяются по SHA-256 перед активацией; при сбое загрузки или несовпадении хэша происходит откат к Tesseract для этого вызова.
  • Изоляция на этапе компиляции: весь код PaddleOCR живёт в исходниках noLegal; опубликованные APK не содержат ни байта Paddle-Lite.

Почему не в магазинах: ~20+ МБ нативных библиотек arm64 и тяжёлый прогрев предиктора несовместимы с бюджетом размера и рантайма опубликованных флейворов.

6 Встроенный просмотр Office-документов (только чтение)

Открывает Office-документы прямо в плеере как предпросмотр только для чтения вместо постоянной передачи во внешнее приложение.

  • Поддержка Word (.docx / .odt), таблиц (.xlsx / .ods), презентаций (.pptx / .odp) и RTF.
  • Встроенный движок без зависимостей: контейнеры OOXML / ODF распаковываются и разбираются в нормализованный HTML, который рендерится в изолированном WebView; для RTF - стриппер управляющих слов.
  • Паритет с поверхностью PDF / EPUB: полный экран, печать, перевод, OCR, навигация свайпом / клавиатурой и зоны касания. Редактирование намеренно недоступно.
  • Бинарные форматы .doc / .xls / .ppt вне области; при невозможности отрисовки появляется явный диалог отката (открыть в другом / поделиться / отмена).
  • Изоляция на этапе компиляции: движок поставляется только в исходниках noLegal.

Почему не в магазинах: держится внутри неопубликованной поверхности noLegal, чтобы в опубликованных сборках не было шва встроенного просмотрщика.
