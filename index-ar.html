غلاف متكامل لجهاز أندرويد الخاص بك.

الشاشة الرئيسية والوسائط والبث والتطبيقات والساعة والملفات - كلها في مكان واحد.

يستولي Fast Media Sorter & Organizer على الشاشة الرئيسية ليصبح نقطة الانطلاق لكل شيء: غلاف للجهاز، مشغل وسائط، بث مباشر، تشغيل التطبيقات، بديل لتطبيقات الجهاز الافتراضية، مرافق على الساعة، مراقبة الجهاز، ومدير ملفات كامل للتخزين المحلي وSMB/NAS وSFTP/FTP ومحركات الأقراص السحابية.

الفهرس الكامل للميزات

يحل محل أكثر من عشرة تطبيقات

يجمع Fast Media Sorter بين متصفح وسائط وعارض ومشغل ومدير ملفات ومنظم في تطبيق واحد. بدلًا من استخدام تطبيقات منفصلة للفيديو والموسيقى والمعارض والقراءة ومجلدات الشبكة والتخزين السحابي وأعمال الملفات اليومية، تستخدم مجموعة واحدة بمجموعة إجراءات مألوفة واحدة. التطبيقات أدناه هي مجرد نقاط مرجعية معروفة للقدرات، وليست تصنيفًا مقارنًا.

العرض والتشغيل

  • مشغل الفيديو (MX Player, VLC) - الفيديو، ملفات بلوراي TS/.m2ts، صورة داخل صورة، لقطات شاشة للإطارات، البث عبر Chromecast.
  • مشغل الصوت (Poweramp, AIMP) - التشغيل في الخلفية، كلمات الأغاني، MIDI، مؤقت النوم، المؤثرات المرئية، عناصر تحكم الإشعارات.
  • معرض / عارض الصور (QuickPic, Google Photos) - الصور وملفات GIF، القص، الفلاتر، التدوير.
  • قارئ PDF / EPUB (Adobe Reader, Moon+ Reader) - الكتب، خرائط الفصول، المظاهر، القراءة بصوت عالٍ (TTS).
  • عرض الشرائح / إطار الصور - صور متعاقبة مع موسيقى خلفية، بالإضافة إلى ودجت إطار الصور.
  • مركز وسائط للتلفاز (Kodi, Nova Video Player) - تصفح وتشغيل متوافقان مع لوحة الاتجاهات ولوحة المفاتيح والفأرة ووحدة التحكم وجهاز التحكم عن بعد للتلفاز.
  • مشغل وسائط VR (Pigasus, Skybox VR) - ستيريو SBS/OU، VR180، 360°، شاشة سينما افتراضية. إصدار VR
  • راديو إنترنت / مشغل IPTV (TuneIn, Online Radio, RadioDroid, VLC network) - تشغل شاشة البث راديو http/https ومصادر HLS/DASH وRTSP؛ مشغل مصغر مدمج يعرض معلومات ICY للتشغيل الحالي؛ فهرس محطات منسق.

الالتقاط والإنشاء

  • الكاميرا (كاميرا الجهاز الافتراضية) - صور وفيديو مباشرة إلى مجلد محلي أو شبكي أو سحابي تختاره.
  • مسجل الصوت - ملاحظات صوتية بالإضافة إلى ودجت للتسجيل السريع.
  • محرر الرسم - لوحة رسم، فرش، أشكال، نص، لون وحجم مخصصان للفرشاة.
  • ماسح المستندات / النصوص (Google Lens, CamScanner) - تعرف ضوئي على الحروف (OCR) على الجهاز من الكاميرا مع اقتصاص المنطقة.

إدارة الملفات

  • مدير الملفات (Total Commander, ES File Explorer, Files by Google) - الملفات المحلية والشبكية والسحابية في مكان واحد.
  • عميل FTP/SFTP/SMB (AndFTP, Solid Explorer) - مصادر شبكية مع مفاتيح SSH وتثبيت مفتاح المضيف.
  • عملاء السحابة (Google Drive, Dropbox, OneDrive) - محركات أقراص سحابية كمصادر وسائط.
  • كاشف التكرارات (Duplicate Files Fixer) - محرك من 3 مراحل الحجم -> التجزئة -> SHA-256.
  • سلة المحذوفات (Dumpster) - حذف مؤقت مع استعادة بلمسة واحدة.
  • مستخرج الأرشيف (ZArchiver) - استخراج ملفات ZIP، بما في ذلك المحمية بكلمة مرور. أساسي
  • مدير التنزيلات (1DM, ADM) - الصق رابطًا واحفظه مباشرة في مجلد تختاره.
  • جدولة المهام - عمليات ملفات مجدولة.

النصوص والأدوات

  • محرر النصوص / Markdown - تحرير ملفات .txt/.md مع تلوين الصياغة والحفظ التلقائي.
  • المترجم (Google Translate offline) - ترجمة كاملة دون اتصال بالإنترنت.
  • الآلة الحاسبة - حساب مدمج للتعبيرات من النص المحدد. أساسية
  • البث إلى التلفاز (Google Home) - Chromecast للفيديو والصوت معًا.
  • حزمة ودجت للشاشة الرئيسية - ودجت للتشغيل السريع والحالة للمسجل وOCR الكاميرا والمهام المجدولة والتشغيل الحالي وإطار الصور.
  • أداة نسخ إعدادات احتياطي - تصدير واستعادة إعداد التطبيق والمصادر والمفضلة والجداول وكلمات المرور وبيانات تسجيل الدخول. إعداد التطبيق فقط

ملاحظات صريحة: الآلة الحاسبة وأداة الأرشفة أساسيتان (حساب من النص / استخراج ZIP)، وليستا بديلين كاملين. النسخ الاحتياطي للإعدادات يغطي إعداد التطبيق نفسه فقط، وليس نسخًا احتياطيًا كاملًا للجهاز. مشغل VR متاح في إصدار VR فقط.

مشاركة مجلد Windows (مرافق الكمبيوتر)

Standard / Photos / Legacy

شارك مجلدًا من كمبيوتر Windows مباشرة إلى التطبيق: يشغّل Fast Media Sorter for Windows المجاني خادم SFTP آمنًا لذلك - يتم الاقتران باستيراد ملف إعداد واحد، دون إدخال يدوي للمضيف/المنفذ/المفتاح.

التفاصيل
  • ثبّت Fast Media Sorter for Windows على الكمبيوتر: إصدار GitHub، أو winget install SerZhyAle.FastMediaSorter، أو "FastMediaSorter LITE" في Microsoft Store (منشور باسمه السابق).
  • اختر المجلدات المراد مشاركتها على الكمبيوتر - يتم إعداد الخادم والمفاتيح والتشغيل التلقائي تلقائيًا.
  • على الهاتف: إضافة مورد > SFTP/FTP > استيراد من المرافق، ثم افتح ملف .fmscfg المصدَّر.
  • دليل الكمبيوتر خطوة بخطوة: كيفية نشر المجلدات لأندرويد.

فتح الدليل بوابة Wear OS على الويب

ربط الساعة بمشاركات الشبكة

Wear OS (FastMedia Wear)

اربط ساعتك الذكية مباشرة بـ NAS أو مشاركات Windows أو خوادم FTP أو SFTP عبر Wi-Fi للتصفح والتشغيل المستقلين.

التفاصيل
  • اتصال Wi-Fi مباشر بـ SMB وFTP وSFTP (كلمة مرور أو مفتاح SSH خاص).
  • اختبر حالة الاتصال مباشرة على معصمك قبل الحفظ.
  • مزامنة بلمسة واحدة من تطبيق الهاتف المرافق لاستيراد جميع المشاركات الموجودة.
