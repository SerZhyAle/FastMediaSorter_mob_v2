FastMediaSorter v2

Професійна організація медіафайлів для Android
Версія 2.x • Open Source

✨ Ключові можливості

  • Управління локальним сховищем
  • Підтримка мережевих SMB/CIFS ресурсів
  • Підтримка протоколів SFTP і FTP
  • Підтримка хмарних сховищ (Google Drive, Dropbox, OneDrive)
  • Підтримка читання книг EPUB
  • Просунутий відеоплеєр на ExoPlayer
  • Високопродуктивний перегляд зображень (Coil)
  • Пакетні операції з файлами (копіювання/переміщення/видалення)
  • Система обраного
  • Режим слайд-шоу з налаштовуваними інтервалами
  • Фонова музика для слайд-шоу
  • Аудіоплеєр з фоновим фото
  • Інтерфейс «Зараз грає»: міні-панель + шторка з чергою
  • Підтримка бінарних файлів (ZIP, APK, мініатюри)
  • Повна підтримка клавіатури та миші
  • Тексти пісень (Lyrics) з автопошуком
  • Редактор зображень (фільтри, поворот)
  • Підтримка прихованих файлів
  • Кешування мініатюр (за замовчуванням 2 ГБ, до 16 ГБ)
  • Пагінація для великих папок (1000+ файлів)
  • Авто-переклад (OCR) для зображень/PDF
  • Підтримка віджетів для домашнього екрана (Ярлик ресурсу та Продовжити перегляд)
  • Передвизначені віртуальні ресурси: Вся музика, Всі відео, Всі фото
  • Підтримка апаратних кнопок (кермо, гарнітура, медіа-клавіші)
  • Clean Architecture + патерн MVVM
  • Продвинуті сенсорні жести

💡 Сценарії використання

🖼️

Цифрова Фоторамка на Планшеті

Перетворіть будь-який Android-планшет на красиву завжди ввімкнену цифрову фоторамку. Стримінг з домашнього ПК (SMB) або хмари — без зайняття локальної пам'яті. Додайте музику, налаштуйте інтервал.

🚗

Музика в Авто (Android-магнітола)

Встановіть на Android-автомагнітолу. Віртуальний ресурс Вся музика — миттєвий доступ до всієї колекції без налаштування. Кнопки керма працюють через фоновий аудіосервіс — без дотику до екрана.

🍿

Домашній Кінотеатр та VR

Дивіться серіали з ПК або хмари на телефоні/VR. Не треба копіювати — просто натисніть Play, і наступна серія запуститься сама.

🧹

Порядок у Завантаженнях

Наведіть лад у завантаженнях на пристрої або віддаленому ПК. Налаштуйте кнопки та розкладайте файли по папках одним дотиком.

📷

Автобекап Фото на ПК за Розкладом

Автоматично копіюйте нові фото з камери на домашній комп'ютер через Wi-Fi (SMB). Налаштуйте розклад — резервна копія збережеться вночі без вашої участі.

⏱️

Автоочищення Завантажень за Розкладом

Автоматично видаляйте застарілі або вже розібрані файли з Завантажень за розкладом. Порядок у сховищі без ручної роботи.
