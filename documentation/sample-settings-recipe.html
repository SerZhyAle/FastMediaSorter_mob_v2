How to Customize Playback and Sorting Defaults

Fine-tune FastMediaSorter to match your exact media sorting style. Learn how to configure default sorting orders, grid thumbnail densities, and background audio behaviors.

✓ Before You Begin: Ingredients & Prerequisites
  • ✓ FastMediaSorter v2 installed on phone, tablet, or Android TV.
  • ✓ Access to the Settings screen via the gear icon.
1

Open Settings and Search for Options

Tap the gear icon in the top toolbar to open the centralized settings hub. Use the live search bar to quickly jump to any configuration option.

2

Configure Default Sorting Behavior

Under Browsing & Sorting, pick your preferred default sort key: Date Taken, Modification Date, File Size, or Natural Name ordering.

💡 Natural Number Sorting

Natural sorting ensures that 'Track 2' correctly precedes 'Track 10' in your album listings.
