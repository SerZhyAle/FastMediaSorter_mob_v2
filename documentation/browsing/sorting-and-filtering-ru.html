Сортировка, фильтрация и быстрый поиск

Настройте порядок в ресурсе, отфильтруйте файлы по дате, размеру и типу с сохранением параметров для конкретной папки или мгновенно найдите нужный файл через живой поиск — прямо на верхней панели файлового браузера.

Почему вам это понравится

Папка, разросшаяся до сотен фотографий, загрузок или записей, перестаёт быть удобной, как только в ней трудно что-то найти. FastMediaSorter позволяет быстро навести порядок: отсортировать файлы по имени, дате, размеру или в произвольном порядке перетаскиванием, а также отфильтровать лишнее прямо в файловом браузере.

Никакие операции на этой странице не затрагивают сами файлы. Сортировка, фильтрация и поиск влияют исключительно на порядок и видимость элементов на экране; файлы на диске остаются нетронутыми.

✓ Перед началом: Что вам понадобится
  • ✓ Установленный FastMediaSorter с открытым ресурсом в файловом браузере.
  • ✓ Режимы сортировки, случайное перемешивание, ручной порядок, фильтры и мгновенный поиск доступны во всех редакциях: Standard, noLegal, Lite, Photos, Legacy, VR и FOSS.
  • ✓ Папка с несколькими файлами — на пустом ресурсе возможности сортировки и фильтрации не столь наглядны.
1

Выбор порядка сортировки файлов

Откройте ресурс в файловом браузере и нажмите кнопку сортировки на верхней панели — она показывает текущий порядок (например, «Дата ↓»). Нажмите Сортировка и выберите критерий: по имени, дате, размеру, типу или (для специализированных папок) по исполнителю, названию трека, длительности или дате съёмки фото.

FastMediaSorter индивидуально запоминает выбранный режим сортировки для каждого ресурса, поэтому при следующем открытии папка встретит вас в привычном порядке.

2

Случайное перемешивание списка

Выберите пункт Случайно в меню сортировки, и файлы выстроятся в новом случайном порядке. Хотите перемешать список ещё раз? Просто нажмите на пункт Случайно повторно — FastMediaSorter мгновенно сгенерирует новый вариант порядка прямо в памяти без повторного считывания папки с диска.

3

Ручной порядок файлов перетаскиванием

Выберите вариант Ручной порядок, чтобы выстроить файлы именно так, как вам хочется. Зажмите строку файла долгим нажатием и перетащите её на нужную позицию; в режиме ручного порядка на каждой строке отображается аккуратная иконка-маркер для перетаскивания.

Приложение сохраняет созданную вами последовательность для данной папки, поэтому порядок остаётся неизменным при всех последующих открытиях.

4

Быстрая фильтрация списка файлов

Нажмите значок фильтра на верхней панели, чтобы открыть диалог Фильтр. Задайте диапазон дат создания/изменения, ограничение по размеру в мегабайтах или отметьте нужные типы медиа — фото, видео, музыка, GIF, документы и др. Нажмите Применить фильтр, и список моментально сократится до подходящих файлов.

Настройки фильтра привязываются именно к текущему ресурсу и не влияют на другие папки. При возвращении в этот ресурс приложение напомнит, что фильтр был автоматически восстановлен.

5

Наглядная сводка активных фильтров

Когда активен фильтр, под панелью инструментов отображается текстовая строка с его кратким описанием понятными словами, а на самой кнопке фильтра появляется бейдж с числом активных условий. Нажмите кнопку фильтра для редактирования параметров или кнопку Сбросить фильтр в диалоге для полного отключения.

6

Понятное объяснение пустого списка

Если после применения фильтров список оказался пуст, FastMediaSorter открыто объясняет причину. Если файлы скрыты настройкой Максимальный размер файла, браузер прямо называет этот параметр и сообщает, сколько именно файлов скрыто, с подсказкой увеличить лимит в Настройках.

7

Мгновенный живой поиск по имени

Нажмите значок поиска, и в верхней панели появится строка ввода. Введите первые буквы имени файла — список начнёт фильтроваться прямо по ходу набора текста в реальном времени в памяти устройства. Нажмите крестик в строке поиска, чтобы очистить поле и вернуть полный список.

Что вы получите

Вы можете организовать файлы в любой папке оптимальным образом: отсортировать по параметрам, перемешать случайным образом, выстроить вручную перетаскиванием, отфильтровать по типу, размеру или дате, а также найти любой файл за пару секунд через живой поиск.

Советы и решение проблем

  • Хотите задать единую сортировку для всех новых папок? Укажите режим по умолчанию в «Настройках» → вкладка «Плеер» → блок «Порядок сортировки, слайд-шоу и воспроизведения» → пункт «Режим сортировки по умолчанию».
  • Сортировка работает одинаково в сетке и списке. Все режимы сортировки и фильтрации идентично работают как для карточек-миниатюр, так и для строк с подробными сведениями — см. Просмотр медиаколлекций.
  • Большая папка долго сортируется при первом открытии? Ознакомьтесь с рецептом Кэширование миниатюр и индексация.
  • Фильтрация по имени файла? Строка поиска работает совместно с фильтрами — введите имя, и поиск сохранится вместе с выбранными ограничениями по дате и размеру.
