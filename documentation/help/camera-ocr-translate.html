Camera OCR translation

What this is for

Take a photo of a printed text - a sign, a menu, a page - and the app reads it and translates it into the language you choose. You get the translation and the original text on one screen, and can save both as a text file.

In this order

  1. Open Camera OCR translation from the programs menu, the quick-access panel or the launcher desktop; it is switched on in Settings, on the Management tab, in the group Additional programs and scenarios. The screen opens the in-app camera at once, so photograph the text. The first time, the text recognition engines may need to be downloaded. A screenshot sent here skips the camera. If you leave the camera without a photo, the screen closes.
  2. Crop state: the photo appears 1 under a frame 2. Drag an edge or a corner of the frame to cover only the text you need, or leave the frame alone to use the whole photo. Retry 3 throws the photo away and opens the camera again.
  3. Check the languages under the photo: the button on the left 4 is the language of the text, and AUTO lets the app detect it; the button on the right 6 is the language to translate into, and the arrow 5 shows the direction. Each opens a searchable list. When translation is off, only the first button is left.
  4. Press Apply 7. The cropped photo is saved to the phone's Camera folder, and the loading state 8 shows the progress while the text is read and translated.
  5. Result state: the translation 9 is on top and the original text 10 below it. Press and hold a word to select text and search it in Google or send a number to the calculator.
  6. Settings 11 changes the languages or switches the translation off and runs the recognition again on the same photo. Save as .txt 12 writes the text to a file, Next photo 13 takes another picture, and Close 14 leaves.
  7. Empty state: if no text was found, the message 15 asks for a clearer photo. Next photo 16 tries again, and Close 17 leaves.

The elements

Crop state

1Photo to readThe photo you just took, ready to be cropped.

It fills the space above the buttons, fitted to the screen. Only the part inside the frame is read.

2Crop selection frameThe frame that marks the part of the photo to read.

Grab an edge or a corner to resize the frame, and drag inside it to move it; the rest of the photo is dimmed. If you do not touch the frame at all, the whole photo is used. With a keyboard or a D-pad, Enter switches resize mode on and off and the arrow keys nudge the frame.

Shortcut
Enter / D-pad center
3RetryThrows the photo away and opens the camera again.

Use it when the text is blurred or cut off. The current photo is not kept.

Undo
The discarded photo is lost and cannot be brought back; take a new one.
4OCR languageSets the language of the text in the photo.

The label shows a flag and a code, for example AUTO, which means that the app works the language out by itself. A tap opens a list with a search field; type a part of the name and tap the language. Pick a language yourself when AUTO guesses wrong. The choice is saved for the next time.

5Direction arrowShows that the text is translated from the left language into the right one.

It is only a sign and cannot be pressed. It is shown, together with the right-hand button, only when translation is available: translation is on in Settings and Only OCR is off.

6Translation languageSets the language the text is translated into.

It appears only when translation is available. A tap opens the same kind of searchable list. The first translation into a language may ask to download a model of about 30 MB; the app asks before it downloads. The choice is saved for the next time.

7ApplyStarts reading and translating the framed part of the photo.

The part inside the frame, or the whole photo when you did not touch the frame, is cut out and saved as a picture in the Camera folder of the phone (in Downloads when that folder refuses the write). Then the recognition begins and the loading state takes over.

Loading state

8Progress screenShows that the photo is being processed.

A spinner and a line of text say what is happening: first Processing photo.., then Extracting text and translating.. with a request to wait when a translation is made. The screen ignores touches meanwhile. If a translation model is missing, the app first asks whether to download it.

Result state

9TranslationThe translated text, large and on top.

It is shown only when a translation was made; with Only OCR on, the card is not there. Scroll inside the card if the text is long. Press and hold to select text: the selection menu offers Search in Google and, when the calculator is switched on, Calculator.

10Original textThe text exactly as it was read from the photo.

Use it to check what the recognition read, or as the result itself when translation is off. It scrolls and can be selected in the same way as the translation. Recognition is not perfect on blurred or decorative letters, so compare it with the photo when a word looks strange.

11SettingsOpens the dialog with the languages and the Only OCR switch.

Change the languages without taking a new photo. A different language of the text reads the same photo again, and a different target language only translates the text that is already there. The dialog is described in the last group.

12Save as .txtSaves the result as a text file.

The file goes to the Documents folder of the phone, or to Downloads when Documents refuses it, and a message tells the folder and the file name. With a translation, the file holds two parts marked TRANSLATION and ORIGINAL; without one, only the recognized text. Every save makes a new file with its own name.

13Next photoOpens the camera for another photo.

The results on the screen stay until the new photo is taken and processed. If you leave the camera without a photo, you come back to the current result.

14CloseLeaves the screen.

The result is not stored by itself. Save the text first if you need it; the cropped photo is already in the Camera folder of the phone.

Undo
The recognized text and the translation are lost on close; take a new photo to get them again.

Empty state

15No text found in imageTells that no text was found in the photo.

The screen shows the message No text found in image and advises to make sure that the photo contains clear text. Common causes are a blurred shot, too little light or a frame that missed the text.

16Next photoOpens the camera to try again.

It takes a new photo and leads through the crop step again. The languages you chose are kept.

17CloseLeaves the screen without a result.

Nothing is saved except the cropped photo, which was already put into the Camera folder at the crop step.

Settings dialog

18Original LanguageThe language of the text, used to read the photo again.

A tap opens the searchable list. Changing it reads the same photo again with the new language and translates the result. The row is grayed out and cannot be used when the photo is no longer kept, for example after the screen was restarted by the system.

19Translate ToThe language the text is translated into.

A tap opens the searchable list. Changing only this row translates the text that is already read, without reading the photo again. The row is grayed out when translation is off in Settings or Only OCR is on.

20Only OCR (no translation)Skips the translation and shows only the recognized text.

With it on, the translation card and the target language disappear and the original text is the whole result. Switch it off to get the translation again. The choice is saved for the next time.

21CancelCloses the dialog and changes nothing.

The languages and the Only OCR switch keep the values they had before.

22ApplySaves the choices and updates the result.

The choices become the settings of the app. The text is read again or translated again, as needed, and the screen shows the new result.
