My devices

What this is for

My devices holds the exchange servers that link all your own devices - phone, computer, watch, TV box. Once this phone is signed in to one, it can see the folders and broadcasts your other devices share, and they can see yours; the server only passes them along.

In this order

  1. Open My devices from Settings, on the General tab (the row is there in editions with network sources). With no server yet, a short message 2 says so; press Add server 5 to begin.
  2. In the sign-in window, bring in the server's connection string by pasting, scanning or choosing a file 21, then check the address 22 and type your login 23 and password 24. If the other device gave you a pairing code, tick 25 and enter the code instead of the password, then press Sign in 26.
  3. Read What the server can see 4 once, so you know what the server learns and what stays encrypted on your devices.
  4. Each server you add becomes a card in the list 3: its address, your login and the state of the link, such as Connected with the number of devices.
  5. Tap a card to see the devices of that account 18. To bring a new device in without typing the password there, issue a pairing code 20; to remove a device you no longer use, press Revoke 19.
  6. The three dots on a card (9 to 17) hold the rest: change the address, make this server the outgoing one, connect a watch, pass the server on, sign out, and more.
  7. The three buttons at the bottom (6, 7, 8) open pages of the project website about adding a server, the server itself and connecting a watch.

The elements

The list of servers

1My devicesThe title bar of the screen, with the way back.

The arrow returns to the previous screen. Here a device is any phone, computer, watch or TV box that is signed in to the same account on an exchange server, and one account can sit on one server only. This screen lists those servers; the devices themselves are shown when you tap a card.

2Empty list messageTells you that there is no exchange server yet.

It shows only while the list has no cards. It says that adding a server lets you see the resources and broadcasts of all your devices; Add server below is the way to do it.

3Server cardsOne card per exchange server you are signed in to.

A card shows the server's address, your login on it and a status line: Checking the connection.., Connected with the number of devices, or a short note about what is wrong - for example that the server does not answer or that this phone was signed out. Cards marked Outgoing are the server through which this phone publishes its folders and broadcasts. Tap a card to open the list of devices in that account; the three dots on the card open its menu.

4What the server can seeA plain statement of what the exchange server learns and what it cannot read.

The server sees the names of your account, devices, folders and broadcasts, which devices are online, and how much is sent and when. It cannot open what goes through it: folders and their files, broadcasts and the clipboard are encrypted on your device and opened only on your other devices or by people you gave access to. To look inside, whoever runs the server would have to add a device of their own to your account, and it would appear in your list of devices.

5Add serverSigns this phone in to an exchange server.

It opens the Sign in to an exchange server window. You need the server's connection string, or its address, and a login with a password or a pairing code. Nothing is saved until you press Sign in and the server accepts you. Afterwards the server appears as a card in the list.

Pages of the project website

6About adding a serverOpens a page of the project website about adding a server.

The page walks through the pairing code and the connection string. It opens in your browser.

7About the exchange serverOpens a page of the project website about the exchange server.

It explains who runs a server, how it connects your devices without opening a router, and what it sees and keeps. It opens in your browser.

8About connecting a watchOpens a page of the project website about connecting a watch.

The button shows only in editions that have the Wear companion, the same editions in which a card menu offers Connect watch. The page opens in your browser.

Server card menu (three dots)

9Change addressChanges the address of a server without signing in again.

A small window shows the address as host and port. If the server has announced a different address, the window mentions it and offers Use the announced address. Save moves your sign-in to the new address. If an entry with that address and login already exists, or the sign-in could not be moved, nothing is changed and a message says so.

10Make outgoingChanges the server through which this phone shares to this one.

This phone publishes its folders and broadcasts through one server at a time, and that server is chosen by itself: the first server you sign in to becomes outgoing, and removing it passes the role to the next one. This item is only for changing it. Choosing this server moves publishing here, a live broadcast included, and marks the card Outgoing. If the previous server could not be reached, publishing stops on this phone anyway and a message says that the share may stay listed there for a while. The item is hidden on the card that is already outgoing.

11Connect watchSigns your watch in to this server.

The phone hands the watch a one-time code, so you type no password on the watch. Keep the watch near, unlocked and connected. The item appears only in editions with the Wear companion, and a message says if the companion is off, no watch is connected, or the watch did not answer.

12Pass the server onShows a code that tells another device where this server is.

A window shows a QR code and a text. Send passes the text to another app and Copy puts it on the clipboard. The text carries the address and the certificate of the server, never your login or password, so the other device still needs its own sign-in.

13Attach everything automaticallyAdds every new folder of this account to this phone without asking.

With the check mark on, a folder that one of your devices starts sharing appears in your resources by itself. It is off until you turn it on. Tap the item again to turn it off.

14Sign in againOpens the sign-in window with this server already filled in.

Use it when the card says that you were signed out or the sign-in was revoked, or on a new phone after a backup restore. The address, the server's certificate and your login are filled in; you type the password once. The same entry is renewed, so nothing is duplicated.

15Change passwordChanges the password of your account on this server.

You enter the current password and the new one twice. After the change every other device of this account signs out and asks for the new password; this phone stays signed in. A forgotten password cannot be recovered, so keep it somewhere safe.

16Sign out on this deviceTakes this phone out of the account.

It asks first. This phone leaves the account and forgets the sign-in. Resources attached from this server stay in the list and show as unavailable until you add the server again. If the server cannot be reached, a message says that the phone stays in the account's device list until another device revokes it.

Undo
The sign-in on this phone is forgotten. To come back, sign in again with the password or a pairing code; the account and its other devices are not touched.
17Delete my accountDeletes your account from the server for good.

You enter the account password to confirm, and the window opens on the safe button. The server erases the account at once: all its devices, published folders and broadcasts, sign-ins and the clipboard. Folders you added stay in your list but show as no longer published. A button in the window opens a page of the project website on how it works.

Undo
This cannot be undone. The account, its device list and everything published through it are gone from the server; only signing up again with a new invitation brings back an account, and it starts empty.

Devices of an account (tap a card)

18Device listThe devices that belong to this account, and whether each is online.

A window titled with the server's address lists every device in the account: its name, the program it runs, and Online or Offline in words. This phone is shown as This phone. A device that has paused sharing is marked so. Close shuts the window.

19RevokeCuts a device off from the account.

Every device except this phone has a Revoke button. It asks first and names the device. The device loses access and can come back only by signing in again. This phone has no such button; it leaves with Sign out on this device.

Undo
The device is removed from the account at once. To bring it back, sign in again on that device with the password or a pairing code.
20Issue a pairing codeMakes a one-time code for signing in another device.

The code appears below the button together with the time it is valid until. Enter it on the other device instead of the password; it works once, so ask for a new one if it was not used. It is handy on a TV box or any device where typing a strong password is hard.

Sign in to an exchange server window

21Paste a server stringFills in the server from a connection string.

Paste the text you were given, press Paste to take it from the clipboard, Scan QR to read a code with the camera, or Choose file to open a file of the kind the server makes. The string holds the server's address and the fingerprint of its certificate, never a login or a password, and it fills in what it can. If it is an invitation, the window turns into creating a new account: the password is asked twice and the button reads Create account.

22Address (host:port)Where the server is, as host and port.

Filled in by the connection string, or typed by hand as host:port. A wrong form is pointed out before anything is sent. Changing the address after reading a string drops the certificate that came with it.

23LoginYour login on that server.

A login is 3 to 64 Latin letters, digits, dots, hyphens or underscores. It is only an account name; the server's owner gives it to you or you choose it when you accept an invitation.

24PasswordYour password on that server.

It is sent to the server once and not kept by the phone: the phone keeps a device sign-in instead. If you ticked the pairing code box, this field becomes the Pairing code field.

25I have a pairing code instead of the passwordLets you use a pairing code in place of the password.

Tick it when another of your devices issued a one-time code. The Password field becomes Pairing code. The code works once and for a short time only.

26Sign inTries the sign-in.

While the server answers, the window shows progress. If the server presents a certificate this phone does not know, a window asks you to check its fingerprint against the one the server shows and then Trust it or Cancel; do not trust a fingerprint that does not match. On success the window closes and the server appears as a card.
