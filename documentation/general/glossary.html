Glossary of Terms

A (8 terms)

All apps

#
ui_component 📱 Phone Editions: standard, noLegal

All apps is the launcher's full list of the apps installed on the device, opened from the launcher menu.

ℹ️
Distinction: Not the programs menu, which lists FastMediaSorter's own programs. The Russian and Ukrainian screens translate it as 'all programs', which is a known clash.
Translations: RU: Все приложения UK: Усі застосунки
See also: app launcher taskbar

All Documents

#
Entity 📱 Phone 🥽 VR Editions: standard, noLegal, legacy, vr, foss

All Documents is a virtual resource that lists every document found on this device, such as PDF, EPUB, text and Office files, in one place.

ℹ️
Distinction: Not the reader: All Documents is the list you browse, while the reader is the screen that opens one document. A text note created here is saved in the device's Documents folder.
Translations: RU: Все документы UK: Усі документи
See also: virtual resource reader text note

All Files

#
Entity 📱 Phone 🥽 VR All 7 Editions

All Files is a ready-made resource that shows every kind of file on the device, not only media, and it works once All Files mode is allowed in Settings.

ℹ️
Distinction: Not a virtual resource for one kind of media such as All Documents: All Files browses the device storage like a file manager, and how much it can reach depends on the storage access Android grants to your edition.
Translations: RU: Все файлы UK: Усі файли
See also: virtual resource file file browser edition

All Images

#
Entity 📱 Phone 🥽 VR All 7 Editions

All Images is a virtual resource that lists every picture found on this device, such as JPG, PNG, GIF or WebP files, in one place.

ℹ️
Distinction: Not 'Camera Photos': Camera Photos holds only what the device camera took, while All Images includes every picture from every folder on the device.
Translations: RU: Все изображения UK: Усі зображення
See also: virtual resource Camera Photos image viewer

All Music

#
Entity 📱 Phone 🥽 VR Editions: standard, noLegal, lite, legacy, vr, foss

All Music is a virtual resource that lists every audio file found on this device, such as MP3 or FLAC tracks, in one place.

ℹ️
Distinction: Not a 'playlist' and not the audio player: it is only the collection of local audio files, and it does not include network or cloud folders.
Translations: RU: Вся музыка UK: Вся музика
See also: virtual resource audio player playlist

All Videos

#
Entity 📱 Phone 🥽 VR Editions: standard, noLegal, lite, legacy, vr, foss

All Videos is a virtual resource that lists every video file found on this device in one place.

ℹ️
Distinction: Not the video player: All Videos is the collection you browse, while the video player is the screen that plays one video from it.
Translations: RU: Всё видео UK: Усі відео
See also: virtual resource video player

app

#
Entity 📱 Phone 🥽 VR All 7 Editions

An app is any application installed on the Android device, such as a browser or a messenger, that the launcher can list and start.

ℹ️
Distinction: Not a 'program': programs are the extra tools built into FastMediaSorter, such as Calculator, while apps are separate installed applications. The Russian and Ukrainian screens sometimes translate both with the same word.
Translations: RU: приложение UK: застосунок
See also: program All apps launcher watch app

audio player

#
Navigation 📱 Phone ⌚ Wear OS 🥽 VR Editions: standard, noLegal, lite, legacy, vr, foss

The audio player is the player screen when it plays music or other audio, with the cover picture, the track controls and the queue.

ℹ️
Distinction: Not 'Now Playing', which is the smaller view of the track already playing. Not All Music, which is the collection of audio files.
Translations: RU: аудиоплеер UK: аудіоплеєр
See also: player Now Playing queue All Music

B (1 terms)

badge

#
ui_component 📱 Phone 🥽 VR All 7 Editions

A badge is a small label drawn on top of a thumbnail or row, such as GIF, VR or Pinned, that tells you something about the item at a glance.

ℹ️
Distinction: Not a button in general, although the VR badge can be tapped to try opening VR again. The word 'badge' itself never appears on screen, so describe what the badge says.
Translations: RU: метка UK: мітка
See also: channel immersive mode media file

C (14 terms)

Calculator

#
Navigation 📱 Phone ⌚ Wear OS All 7 Editions

Calculator is a built-in program for everyday sums that you switch on in Settings and open from the programs menu, a widget or the watch.

ℹ️
Distinction: Not the Android system calculator app: it stays inside FastMediaSorter.
Translations: RU: Калькулятор UK: Калькулятор
See also: program widget

camera

#
Navigation 📱 Phone All 7 Editions

The camera is the app's built-in way to take photos and record videos and save them straight into a resource or folder you choose.

ℹ️
Distinction: Not the Android camera app, and not 'Camera Photos', which is the virtual resource listing what the device camera took. 'Quick capture' is a widget that jumps straight into shooting.
Translations: RU: камера UK: камера
See also: Camera Photos Camera OCR drawing editor

Camera OCR

#
Navigation 📱 Phone Editions: standard, noLegal, legacy, vr

Camera OCR is a program that takes a photo, finds the text in it and shows a translation next to the original words.

ℹ️
Distinction: Not general OCR inside the player, which works on photos and documents you already have. The programs menu and Settings call it 'Camera OCR translation'.
Translations: RU: Камера-перевод UK: Камера-переклад
See also: OCR camera program widget

Camera Photos

#
Entity 📱 Phone 🥽 VR All 7 Editions

Camera Photos is a virtual resource that shows the photos and videos taken by this device's camera.

ℹ️
Distinction: Not 'All Images': it holds only camera shots, not every picture on the device. A home-screen widget with the same name opens it.
Translations: RU: Фото с камеры UK: Фото з камери
See also: virtual resource All Images camera widget

car head unit

#
hardware_platform 📱 Phone All 7 Editions

A car head unit is the Android screen built into the dashboard of a car, where the app can play media with large, easy buttons.

ℹ️
Distinction: Not a phone mounted in the car: it is the car's own Android screen, and the Car head unit device profile sets the app up for it.
Translations: RU: автомагнитола UK: автомагнітола
See also: device profile D-pad TV

catalog

#
network_stream 📱 Phone ⌚ Wear OS Editions: standard, noLegal, legacy, vr

The catalog is the built-in list of internet radio and TV channels that the app downloads so you can add them to Streams without typing any web addresses.

ℹ️
Distinction: Not your own channel list: channels you added by hand stay when the catalog is updated or cleared. Spell it 'catalog', never 'catalogue'.
Alternative / Legacy terms: catalogue
Translations: RU: каталог UK: каталог
See also: Streams channel stream playlist

channel

#
Entity 📱 Phone Editions: standard, noLegal, legacy, vr

A channel is one saved radio, TV or video station in the Streams list, with its own name, logo and web address.

ℹ️
Distinction: Not the 'stream' itself: the channel is the saved entry you pin, edit or remove, and the stream is what it plays. Not an audio channel such as the left and right sides of stereo sound.
Translations: RU: канал UK: канал
See also: stream Streams catalog streams panel

Chromecast

#
network_stream 📱 Phone ⌚ Wear OS Editions: standard, noLegal, lite, photos, legacy

Chromecast is the technology from Google for sending a video, photo or song from the app to a TV so it plays there instead of on the phone.

ℹ️
Distinction: Not Live Broadcast, which sends your microphone or camera to other devices. Casting is missing from the VR and FOSS editions.
Translations: RU: Chromecast UK: Chromecast
See also: TV video player stream

cloud provider

#
network_stream 📱 Phone Editions: standard, noLegal, photos, legacy, vr

A cloud provider is the online service whose storage you connect to the app: Google Drive, OneDrive or Dropbox.

ℹ️
Distinction: Not the storage itself: you pick a cloud provider, sign in, and then choose folders from its cloud storage.
Translations: RU: облачный сервис UK: хмарний сервіс
See also: cloud storage Google Drive OneDrive Dropbox

cloud storage

#
network_stream 📱 Phone Editions: standard, noLegal, photos, legacy, vr

Cloud storage is online space from a service such as Google Drive, OneDrive or Dropbox, where your files are kept on the internet instead of on a device.

ℹ️
Distinction: Not a network folder on your own home network. A resource that points into cloud storage needs you to sign in to the service first.
Translations: RU: облачное хранилище UK: хмарне сховище
See also: cloud provider Google Drive Dropbox OneDrive resource

color theme

#
ui_component 📱 Phone 🥽 VR All 7 Editions

The color theme sets the overall look of the app, such as light, dark or automatic.

ℹ️
Distinction: Not the page theme of the reader (light, dark or sepia) and not the separate 'color scheme' of the watch. Always spell it 'color', never 'colour'.
Alternative / Legacy terms: colour => color, coloured => colored, grey => gray
Translations: RU: цветовая тема UK: колірна тема
See also: Settings device profile

command bar

#
ui_component 📱 Phone 🥽 VR All 7 Editions

The command bar is the row of buttons across the top of the main screen, such as Add, Filter, Refresh, Settings and Start Player; when the screen is too narrow it first hides the button labels and then moves the buttons that still do not fit into the three-dots menu.

ℹ️
Distinction: Not the command panel: the command panel belongs to the player and acts on the open file, while the command bar belongs to the main screen.
Translations: RU: панель команд главного экрана UK: панель команд головного екрана
See also: main screen three-dots menu command panel resource-type tabs

command panel

#
ui_component 📱 Phone 🥽 VR All 7 Editions

The command panel is the set of buttons in the player for acting on the current file, such as copy, move and delete.

ℹ️
Distinction: Not the three-dots menu and not Quick Sort alone. A setting decides whether it opens by itself when the player starts.
Translations: RU: панель команд UK: панель команд
See also: player panel Quick Sort touch zones

complication

#
hardware_platform ⌚ Wear OS Editions: standard, noLegal

A complication is a small spot on the watch face that shows live information from the watch app, such as the last resource, the number of favorites or the track now playing, and opens it with a tap.

ℹ️
Distinction: Not a 'tile', which is a whole screen you swipe to. The word comes from Wear OS and appears only in the watch face editor, never in the app's own screens.
Translations: RU: усложнение UK: ускладнення
See also: tile watch Now Playing Favorites

D (6 terms)

D-pad

#
hardware_platform 📱 Phone All 7 Editions

The D-pad is the four-arrow pad with a center button on a TV remote, game controller or keyboard that moves the selection around the screen.

ℹ️
Distinction: Not touch gestures: everything on screen can also be reached with the D-pad, which matters on TVs and in cars.
Translations: RU: D-pad UK: D-pad
See also: TV car head unit

desktop

#
Navigation 📱 Phone Editions: standard, noLegal

The desktop is the launcher's main page, a grid where you place app icons, resources, channels, gadgets and sections, with separate layouts for the upright and the sideways screen.

ℹ️
Distinction: Not the home screen of another launcher and not a computer desktop: it exists only while the FastMediaSorter launcher is in use.
Translations: RU: рабочий стол UK: робочий стіл
See also: launcher gadget section taskbar shortcut home screen

destination

#
Entity 📱 Phone 🥽 VR All 7 Editions

A destination is a resource you have marked for Quick Sort, so that one tap can copy or move the current file into it.

ℹ️
Distinction: Not every resource: only resources marked for Quick Sort become destinations, up to 30 of them, each with its own number and color. In copy and move dialogs 'destination' also means simply the place a file is going to.
Translations: RU: назначение UK: призначення
See also: Quick Sort resource command panel

device profile

#
Entity 📱 Phone 🥽 VR All 7 Editions

A device profile is a preset for the kind of device you use, such as a personal smartphone, a TV box, a car head unit or a photo frame, that sets sensible defaults for the whole app.

ℹ️
Distinction: Not a 'resource profile', which affects one resource only.
Translations: RU: профиль устройства UK: профіль пристрою
See also: resource profile TV car head unit VR headset

drawing editor

#
Navigation 📱 Phone All 7 Editions

The drawing editor is the screen where you draw or write by hand on a photo, a screenshot or a blank page and save the result as a picture.

ℹ️
Distinction: Not the crop or rotate tools of the image viewer. The menu item that opens it is simply called 'Drawing'.
Translations: RU: редактор рисования UK: редактор малювання
See also: image viewer camera

Dropbox

#
network_stream 📱 Phone Editions: standard, noLegal, photos, legacy, vr

Dropbox is a cloud storage service that the app can open as a resource after you sign in to your Dropbox account.

ℹ️
Distinction: Not Google Drive or OneDrive: each service needs its own sign-in.
Translations: RU: Dropbox UK: Dropbox
See also: cloud storage cloud provider

E (3 terms)

edge gesture

#
ui_component 📱 Phone Editions: standard, noLegal

An edge gesture is a short swipe that starts on a band at the left or right edge of the screen and runs a chosen action, such as a screenshot, over any app.

ℹ️
Distinction: Not the system back gesture and not the launcher navigation gestures. The setting that switches the edge bands on is called Gesture overlay.
Translations: RU: краевой жест UK: крайовий жест
See also: screenshot quick-access panel screen recording

edition

#
distribution_edition 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

An edition is one of the separately published versions of FastMediaSorter, each made for a certain kind of device or store and with its own set of features.

ℹ️
Distinction: Never call it a 'flavor' or 'build flavor' in user documentation. An edition is not a version number, which changes with every update.
Alternative / Legacy terms: flavor, flavour
Translations: RU: редакция UK: редакція
See also: Standard edition noLegal edition Lite edition Photos edition Legacy edition VR edition FOSS edition

extension

#
Entity 📱 Phone Editions: standard, noLegal, legacy, vr

An extension is an optional part of the app, such as text recognition or an extra audio decoder, that you download only when you want it and can delete again to free space.

ℹ️
Distinction: Not a separate app from a store and not a paid add-on: an extension is downloaded from the app's own Downloadable Extensions screen and is free.
Alternative / Legacy terms: plug-in, plugin
Translations: RU: расширение UK: розширення
See also: Settings OCR edition

F (7 terms)

Fast Media Sorter for Windows

#
network_stream 📱 Phone Editions: standard, noLegal, photos, legacy, vr, foss

Fast Media Sorter for Windows is a separate program for Windows PCs that shares chosen PC folders with the phone app in a couple of clicks, paired by scanning a QR code.

ℹ️
Distinction: Not 'Wear Companion' for the watch, although both are called 'companion' on some screens. The folders it shares arrive in the app as SFTP resources.
Translations: RU: Fast Media Sorter for Windows UK: Fast Media Sorter for Windows
See also: SFTP network resource Wear Companion

Favorites

#
Entity 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

Favorites is your own list of the files and channels you marked with a star (a heart on the watch), so you can open them again quickly from one place.

ℹ️
Distinction: Not 'Quick Sort': marking a favorite does not copy or move anything, it only bookmarks the item. Spell it 'favorite', never the British 'favourite'.
Alternative / Legacy terms: favourite => favorite
Translations: RU: Избранное UK: Обране
See also: file channel Quick Sort widget tile complication

file

#
Entity 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

A file is a single item stored in a folder, such as one photo, song, video or document.

ℹ️
Distinction: Not always a 'media file': 'file' covers anything stored on a disk, while 'media file' means only the kinds of files the app can show or play.
Translations: RU: файл UK: файл
See also: media file folder Favorites

file browser

#
Navigation 📱 Phone 🥽 VR All 7 Editions

The file browser is the screen that opens when you open a resource and shows its files and subfolders so you can view, select, copy, move or delete them.

ℹ️
Distinction: Never call it an 'explorer' or a 'file explorer'. A web 'browser' such as Chrome is a different thing, and qualified names such as 'video file browser' are allowed when the media type matters.
Alternative / Legacy terms: explorer
Translations: RU: браузер файлов UK: браузер файлів
See also: main screen resource player grid view list view three-dots menu

folder

#
Entity 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

A folder is a place on a disk, memory card or server where files are kept, and it exists whether or not the app knows about it.

ℹ️
Distinction: Not a 'resource': a resource is the app's saved entry that points to a folder. Use 'folder' only for the real directory itself, such as creating a new folder or picking one in the system folder window.
Translations: RU: папка UK: папка
See also: resource local folder network folder file

FOSS edition

#
distribution_edition 📱 Phone Editions: foss

The FOSS edition is the open-source edition published in F-Droid, built without any closed-source parts, so it has no cloud storage, Streams, OCR, translation, Chromecast or watch companion.

ℹ️
Distinction: Not a trial edition: it is complete within those limits. When writing about its open-source terms, spell 'license', never 'licence'.
Alternative / Legacy terms: licence => license
Translations: RU: редакция FOSS UK: редакція FOSS
See also: edition Standard edition

FTP

#
network_stream 📱 Phone ⌚ Wear OS Editions: standard, noLegal, photos, legacy, vr, foss

FTP is an older, unencrypted way to reach folders on a server, still used by many routers and home servers.

ℹ️
Distinction: Not 'SFTP', which is the encrypted and safer choice when the server supports it. The resource type list shows both together as 'SFTP / FTP'.
Translations: RU: FTP UK: FTP
See also: SFTP SMB network resource

G (3 terms)

gadget

#
ui_component 📱 Phone Editions: standard, noLegal

A gadget is a small live block on the launcher desktop, such as a clock, weather, compass, battery or map, that shows fresh information and reacts to taps.

ℹ️
Distinction: Not a 'widget': a widget is placed on the Android home screen of any launcher, while a gadget belongs to the FastMediaSorter desktop.
Translations: RU: гаджет UK: ґаджет
See also: desktop launcher widget section Now Playing

Google Drive

#
network_stream 📱 Phone Editions: standard, noLegal, photos, legacy, vr

Google Drive is the cloud storage from Google, which the app can open as a resource after you sign in with your Google account.

ℹ️
Distinction: Not only a place for resources: the app can also save a copy of its settings and resources to Google Drive. The Russian and Ukrainian screens write it as 'Google Диск'.
Translations: RU: Google Диск UK: Google Диск
See also: cloud storage cloud provider

grid view

#
ui_component 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

Grid view shows files, resources or channels as picture tiles arranged in rows and columns.

ℹ️
Distinction: Not 'list view', which shows one item per line with more text. The file browser can be set to open in grid view by default.
Translations: RU: сетка UK: сітка
See also: list view file browser resource list

H (1 terms)

home screen

#
Navigation 📱 Phone All 7 Editions

The home screen is the Android start screen you see after unlocking the device, run by whichever launcher app is set as home.

ℹ️
Distinction: Not the app's 'main screen', and not the launcher 'desktop' unless FastMediaSorter is set as the home screen. Home-screen widgets and shortcuts are placed here.
Translations: RU: домашний экран UK: домашній екран
See also: launcher desktop widget shortcut main screen

I (3 terms)

image viewer

#
Navigation 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

The image viewer is the player screen when it shows a photo or picture, where you can zoom, rotate, crop or start a slideshow.

ℹ️
Distinction: Not a separate app: it is the same player showing an image, and 'Default image viewer' is the Android setting that lets the app open pictures coming from other apps. Not All Images, which is the collection.
Translations: RU: просмотр изображений UK: перегляд зображень
See also: player All Images slideshow drawing editor

immersive browser

#
Navigation 🥽 VR Editions: noLegal, vr

The immersive browser is the in-headset screen that shows your files as a 3D grid of tiles inside the immersive scene, so you can find and open something without leaving VR.

ℹ️
Distinction: Not the file browser, which is the flat, two-dimensional screen used outside a headset. The controller ray points and clicks instead of a touch.
Translations: RU: immersive-браузер UK: immersive-браузер
See also: immersive mode VR headset file browser

immersive mode

#
Navigation 🥽 VR Editions: noLegal, vr

Immersive mode is the headset view that surrounds you with a 3D or 360-degree photo or video instead of showing it in a flat window.

ℹ️
Distinction: Not full-screen mode on a phone. When immersive mode cannot start, the file plays in 'flat mode' instead.
Translations: RU: immersive-режим UK: immersive-режим
See also: VR headset Meta Quest video player VR edition

L (6 terms)

launcher

#
Navigation 📱 Phone Editions: standard, noLegal

The launcher is the part of FastMediaSorter that can replace the device's home screen with its own desktop, taskbar and app list, or show that desktop inside the app.

ℹ️
Distinction: Not every 'launcher' on screen: in messages such as 'Your launcher does not support home-screen shortcuts' the word means whichever home-screen app the device uses. Turning launcher mode off brings back the previous home screen.
Translations: RU: лаунчер UK: лаунчер
See also: desktop taskbar gadget section All apps home screen quick-access panel

Legacy edition

#
distribution_edition 📱 Phone Editions: legacy

The Legacy edition is an edition for older Android devices, starting from Android 6, with most Standard features but without the launcher and the watch companion.

ℹ️
Distinction: Not an outdated or abandoned release: it is published together with the other editions.
Translations: RU: редакция Legacy UK: редакція Legacy
See also: edition Standard edition

list view

#
ui_component 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

List view shows files, resources or channels one per line, with the name and details next to a small picture.

ℹ️
Distinction: Not 'grid view', which shows larger picture tiles in rows and columns.
Translations: RU: список UK: список
See also: grid view file browser resource list

Lite edition

#
distribution_edition 📱 Phone Editions: lite

The Lite edition is a lighter edition that plays local photos, videos and music only, without network folders, cloud storage, documents or Streams.

ℹ️
Distinction: Not the Photos edition, which keeps network folders and cloud storage but drops video and audio.
Translations: RU: редакция Lite UK: редакція Lite
See also: edition Photos edition Standard edition

Live Broadcast

#
network_stream 📱 Phone ⌚ Wear OS Editions: standard, noLegal, legacy

Live Broadcast is a program that sends what the microphone of your phone, and optionally its camera, picks up live over the local network so that other devices can listen or watch.

ℹ️
Distinction: Not a 'stream' you receive: Live Broadcast sends your own sound or picture out. The Russian and Ukrainian screens name it with a different word from the one used for streams.
Translations: RU: Вещание UK: Мовлення
See also: stream Streams program widget

local folder

#
Entity 📱 Phone 🥽 VR All 7 Editions

A local folder is a folder stored on this device itself or on its memory card, as opposed to one on another computer or online.

ℹ️
Distinction: Not a 'network folder' or 'cloud storage', which live on another machine or on the internet. The resource type list also shows local folders simply as 'Local'.
Translations: RU: локальная папка UK: локальна папка
See also: folder resource network folder cloud storage

M (3 terms)

main screen

#
Navigation 📱 Phone 🥽 VR All 7 Editions

The main screen is the first screen of the app, where your resources are listed and where you add, open and manage them.

ℹ️
Distinction: Not the Android 'home screen' and not the launcher 'desktop'.
Translations: RU: главный экран UK: головний екран
See also: resource list resource file browser home screen desktop programs panel streams panel

media file

#
Entity 📱 Phone ⌚ Wear OS 🥽 VR All 7 Editions

A media file is a file the app can show or play, such as a photo, GIF, video, audio track or document.

ℹ️
Distinction: Not every 'file': other files in a folder, such as installers or archives, are not media files and stay hidden unless All Files mode is used.
Translations: RU: медиафайл UK: медіафайл
See also: file All Files player

Meta Quest

#
hardware_platform 🥽 VR Editions: noLegal, vr

Meta Quest is a family of VR headsets made by Meta, such as Quest 3, on which the VR edition of the app runs.

ℹ️
Distinction: Not the only supported headset: Android XR headsets work too, so say 'VR headset' when the brand does not matter.
Translations: RU: Meta Quest UK: Meta Quest
See also: VR headset VR edition immersive mode

N (5 terms)

network folder

#
network_stream 📱 Phone ⌚ Wear OS Editions: standard, noLegal, photos, legacy, vr, foss

A network folder is a shared folder on another computer, a NAS or a router on your home or office network that the app opens over SMB.

ℹ️
Distinction: Not a folder on this device and not cloud storage. People often say 'network share' or 'shared folder'.
Translations: RU: сетевая папка UK: мережева папка
See also: SMB network resource folder resource

Network Monitor

#
Navigation 📱 Phone ⌚ Wear OS Editions: standard, noLegal
