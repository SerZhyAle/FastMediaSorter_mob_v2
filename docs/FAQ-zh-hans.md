## 常规问题

### FastMediaSorter 是什么？
FastMediaSorter v2 是一款面向 Android 设备的完整外壳：它接管主屏幕、播放你的媒体、打开直播流、启动你的应用、与手表通信、监控设备状态，并管理你拥有的每一个文件 - 无论是在本地文件夹、网络驱动器（SMB/SFTP/FTP），还是云存储（Google Drive、OneDrive、Dropbox）中。

### 它是免费的吗？
是的！FastMediaSorter v2 完全免费且开源。

### 我需要什么 Android 版本？
Standard、Lite 和 Photos 需要 Android 8.0（API 26）或更高版本。**Legacy** 版本支持 Android 6.0（API 23）或更高版本。**XR / noLegal** 还需要受支持的头显硬件和当前的旁加载运行环境。

### 需要联网吗？
本地文件**不需要**。网络驱动器和云存储**需要**。

### 应用有小组件吗？
有！FastMediaSorter v2 提供多种主屏幕小组件 - 长按主屏幕 → Widgets → FastMediaSorter 即可找到它们。包括资源快捷方式、幻灯片放映启动器等等。

### 应用能替代我的主屏幕吗？
可以，在 **Standard** 和 **noLegal** 版本中。在 **设置 → 通用** 中开启 **Make this app the home screen**，然后在 Android 询问使用哪个主屏幕时选择 FastMediaSorter。你会得到一个带有文件夹快捷方式的桌面、时钟和天气等小组件、一个应用网格和一个任务栏。关闭该设置，或选择 **Exit launcher mode**，Android 就会恢复你之前的主屏幕 - 你的桌面布局会保留到下次使用。完整操作步骤见 [HOW_TO](HOW_TO-zh-hans.md#how-to-use-the-app-as-your-home-screen)。

### 如何让应用不再作为我的主屏幕？
三种方式，遇到哪种就用哪种：

- 在桌面上打开开始菜单，选择 **Exit launcher mode**，然后确认。
- 在 **设置 → 通用** 中重新关闭 **Make this app the home screen**。
- 打开 Android 自身的主屏幕应用列表：**Settings → General → System launcher settings → System → Change home screen**，选择你想要的启动器。

无论哪种方式，你的桌面布局都会被保留，所以再次开启该模式时会和你离开时一样。

### 为什么我的平板重启后回到了原来的主屏幕？
这是因为该设备的固件把它改回去了，并不是应用丢失了设置。一些廉价的车载收音机和内置 Android 盒子每次开机都会把主屏幕重置为出厂设置，无论你选过什么 - 没有应用能覆盖这一点。重启后重新把 FastMediaSorter 选为主屏幕应用；如果设备提供 **Always** 而不是 **Just once**，请选择 **Always**。如果仍然无法保持，那说明该设备根本不允许替换主屏幕。

### 我能把自己的文件夹和播放列表放到桌面上吗？
可以 - 桌面就是为此而生的。长按一个空白方格，选择 **Add an item..**，然后选择你想要的内容：你的某个文件夹、一个电台、一个应用、一个联系人，或者时钟、天气这样的小组件。新的图格会落在你长按的那个方格上，对于文件夹，你还可以选择它是打开浏览、幻灯片放映还是播放模式。之后想调整位置，从同一个长按菜单中选择 **Edit the desktop**。完整操作步骤见 [HOW_TO](HOW_TO-zh-hans.md#how-to-use-the-app-as-your-home-screen)。

## 文件操作

### 删除的文件去哪了？
删除的文件会移动到同一位置的 `.trash/` 文件夹（软删除）。在你执行以下操作之前，它们不会被永久删除：
- 在 设置 → 管理 → File deletion and trash 中点按 **"Empty Trash"**，或者
- 手动删除 `.trash/` 文件夹

### 我能撤销删除/移动吗？
**可以！** 操作完成后的几秒内，点按 **"Undo" 按钮**（或右下角触控区域）。

> ⚠️ **注意：** 网络文件的删除不支持撤销（它们会立即被硬删除）。

### Copy 和 Move 有什么区别？
- **Copy：** 创建一个副本，原文件保留在原位
- **Move：** 迁移文件，从原位置移除

### 什么是 All Files mode？
**All Files mode** 让你可以把应用当作一个跨所有目录的全功能文件浏览器来使用。在此模式下，应用会绕过标准的媒体筛选器，显示所有文件（包括 ZIP、RAR、APK、EXE、PDF 等）。你可以执行标准的文件操作，例如复制、移动、重命名、分享和删除。对于不受支持的二进制文件，会自动打开一个底部面板，方便你管理该文件或用外部应用打开它。

### 如何查找并删除重复文件？
打开一个文件夹，点按溢出菜单，选择 **Find Duplicates** 自行查看匹配结果，或选择 **Find and Delete Duplicates** 立即删除它们。还有一个 **Delete by Size..**，可基于文件大小快速清理。自动选项会跳过确认，所以如果想在删除前再三确认，请先使用 **Find Duplicates**。匹配基于内容 - 先比较大小，再快速哈希，最后完整的 SHA-256 校验 - 因此改过名的副本依然能被找到。

## 网络与云

### 如何连接到我家的 NAS（网络驱动器）？
1. 点按 **"+"** → **Network** → **SMB / Network Drive**
2. **方式 A - 自动：** 点按 **"Scan Network"** 自动发现网络中的可用设备
3. **方式 B - 手动：** 输入服务器地址：`\\192.168.1.100\share` 或 `smb://192.168.1.100/share`
4. 输入用户名和密码
5. 点按 "Connect"

**常见问题及解决方法：**

| 问题 | 解决方法 |
|---------|------------|
| "Connection refused" | 打开 Windows 防火墙 → 允许入站的 **TCP 端口 445**。或临时关闭防火墙进行测试 |
| "Wrong password" | 尝试把用户名留空（访客访问）。如果使用微软账号，请把你的**完整邮箱地址**作为用户名输入 |
| "Host not found" | 确保手机和电脑在**同一个 Wi-Fi 路由器**上。AP 隔离（一种路由器安全设置）会阻止设备间通信 - 请在路由器设置中关闭它 |
| 扫描没有结果 | 关闭手机上的 VPN。在 Windows 中启用**网络发现**（控制面板 → 网络和共享中心 → 高级共享设置）。然后尝试手动输入 IP |
| 浏览非常慢 | 编辑该资源 → 运行 **Speed Test**。如果低于 5 Mbps，将手机切换到 5 GHz Wi-Fi 频段。对慢速连接禁用视频缩略图 |
| 在 Wi-Fi 上正常但在移动数据下不行 | 这是预期行为 - SMB 只是一种局域网协议，无法通过移动数据工作 |

→ 完整操作步骤：[SMB 设置指南](howto/scenario-smb-setup.md)

### 如何连接到 Google Drive？
1. 点按 **"+"** → **Cloud** → **Google Drive**
2. 点按 "Sign in with Google"
3. 出现提示时授予权限
4. 你的 Drive 文件夹就会出现

**注意：** 文件不会自动下载 - 它们按需串流播放。

### 如何连接到 OneDrive？
1. 点按 **"+"** → **Cloud** → **OneDrive**
2. 点按 "Sign in with Microsoft"
3. 出现提示时授予权限
4. 你的 OneDrive 文件夹就会出现

### 如何连接到 Dropbox？
1. 点按 **"+"** → **Cloud** → **Dropbox**
2. 点按 "Sign in with Dropbox"
3. 出现提示时授予权限
4. 你的 Dropbox 文件夹就会出现

### 我能使用 SFTP 或 FTP 吗？
**可以！** 添加文件夹时选择 **SFTP** 或 **FTP**：
- **SFTP：** 更安全，需要 SSH 服务器（端口 22）
- **FTP：** 安全性较低，较老的协议（端口 21）

### 我能把电脑上的文件夹共享给应用吗？
**可以** - Fast Media Sorter for Windows 会通过 SFTP 发布选定的电脑文件夹，并显示一个二维码 / `.fmscfg` 配置文件。在手机上，在 Add Resource 界面使用 **Import from companion** 或 **Scan QR code**。参见电脑端指南：[如何将电脑文件夹发布到 Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)。适用于 Standard、Photos、Legacy、XR/noLegal。

### 为什么网络文件的缩略图加载不出来？
网络文件的缩略图为节省带宽而**按需生成**。请慢慢滚动，或稍等几秒让它们显示出来。

如果缩略图一直无法加载：
- 确认连接是活跃的：点按该资源 → 如果文件夹能打开，说明连接正常
- 编辑该资源 → 确保 **"Load thumbnails"** 已启用
- 对于非常慢的连接：完全禁用缩略图以避免超时（编辑资源 → 禁用缩略图）

### 连接总是断开/文件在播放中途打不开
- 检查手机的 Wi-Fi 是否稳定（没有在 2.4 和 5 GHz 频段之间来回切换）
- 有些路由器会断开空闲的 SMB 会话 - 编辑该资源 → 如果可用，启用 **"Reconnect on error"**
- 对于通过 SMB 播放视频：运行 Speed Test（编辑资源 → Speed Test）。1080p 视频至少需要 10 Mbps

## 快速分类与目标文件夹

### 什么是 "Quick Sort" 文件夹？
Quick Sort 文件夹是预先配置好的目标文件夹，用于快速整理文件。你最多可以为 30 个文件夹分配编号按钮。

### 如何设置 Quick Sort？
**方法 1：** 设置 → 管理 → Quick Sort destinations，然后点按 **"Add to Quick Sort"**  
**方法 2：** 编辑任意文件夹 → 启用 "Mark for Quick Sort"

### 查看文件时如何使用 Quick Sort？
1. 全屏打开一张照片/视频
2. 点按命令面板上的**编号按钮**（0-9），或
3. 点按**左下角**（COPY 区域）或**底部居中**（MOVE 区域）

### 我能用数字键代替点按吗？
可以 - 连接一个硬件键盘、手柄或电视遥控器，你的 Quick Sort 按钮会自动获得编号（0-9）。按下对应的数字即可立即将文件复制或移动到该目标，效果和点按按钮一样。

### Quick Sort 按钮没有显示
请确认你已先添加至少一个目标文件夹：设置 → 管理 → Quick Sort destinations，然后 **"Add to Quick Sort"**。只有配置了至少一个目标后，按钮才会出现。

### 我不小心把文件发到了错误的文件夹
立即点按 **Undo**（命令面板右下角） - 每次操作后有几秒钟的可用时间。如果错过了这个窗口，请前往目标文件夹手动把文件移回去。

## 触控区域

### 什么是 "触控区域"？
触控区域是屏幕上不可见的区域，点按后会触发相应操作。屏幕被划分为 3x3 网格：

```
┌─────────┬─────────┬─────────┐
│  BACK   │  COPY   │ RENAME  │
├─────────┼─────────┼─────────┤
│  PREV   │  MOVE   │  NEXT   │
├─────────┼─────────┼─────────┤
│ COMMAND │ DELETE  │  PLAY   │
└─────────┴─────────┴─────────┘
```

### 如何查看触控区域？
设置 → 播放器 → **"Always show touch zones overlay"**

### 我能禁用触控区域吗？
可以，改用**命令面板按钮**即可。触控区域是可选的。

## 屏幕与语音录制

### 左侧边缘手势条是什么？
这是一个快速捕获菜单，从屏幕左边缘斜向滑动即可打开。在 **设置 → 管理 → Edge screen gestures → Gesture overlay** 中开启它。从菜单中你可以截屏、快速拍照、裁剪并分享当前图片、打开某个应用或面板快捷方式，或开始屏幕、视频或语音录制 - 全程无需离开当前正在看的内容。适用于 Standard 和 XR/noLegal。

### 如何快速录制一段语音备忘录？
三种方式：溢出菜单中的 **Voice recording** 项、**Quick Recorder** 主屏幕小组件，或边缘手势的 **Start audio recording** 操作。无论用哪种方式启动，屏幕上都会一直保留一个悬浮的 **Stop** 控件 - 即使切换到其他应用也在 - 直到你点按它保存为止。

## 输入与控制

### 支持物理键盘和手柄吗？
**支持！** 所有界面都可使用完整的键盘、鼠标和手柄输入。在任意界面按 **F1** 即可查看该界面当前生效的按键绑定。

### 如何重新映射控制/更改按键绑定？
设置 → **管理** → **Controls & Keybindings** - 将任意操作重新分配到不同的按键、按钮或手柄输入。应用内置 70 个默认绑定；点按 **Reset** 即可恢复。冲突会自动高亮显示。

### 如何从网址下载媒体文件？
通过 Android **分享面板**（来自浏览器、聊天应用或任意应用）将任意 `http(s)` 链接分享给 FastMediaSorter。FastMediaSorter 会下载该文件，并提供保存到你任意已配置资源的选项。

## 性能与存储

### 如何按名称查找特定文件？
在浏览界面中使用**筛选**面板：点按工具栏中的筛选图标，在名称栏中输入文件名的任意一部分 - 列表会立即更新。不需要单独的搜索栏；筛选功能已完全覆盖这个场景。

### 为什么 5000+ 文件时应用会变慢？
应用使用**分页**来分批加载文件。对于非常大的合集：
- 为该文件夹启用 "Disable thumbnails"
- 使用筛选缩小结果范围
- 按日期排序（最新优先） - 这样会优先加载最近的文件，避免一开始就扫描整个文件夹

### 应用崩溃或卡死
1. 强制关闭并重新打开应用
2. 如果在特定文件夹中崩溃：该文件夹可能包含损坏的文件 - 尝试逐个打开文件以找出问题所在
3. 清除缓存：设置 → 通用 → **"Clear Cache"** - 这能解决更新后的大多数稳定性问题
4. 如果仍然崩溃：通过 GitHub Issues 报告（链接在本页底部） - 请附上崩溃发生时你正在做什么的说明

### 缩略图缓存占用多少存储空间？
**默认：** 2 GB（可在设置中配置）

### 如何清除缓存？
设置 → 通用 → **"Clear Cache"**

## 安全与隐私

### 我能给文件夹设置密码保护吗？
**可以！** 编辑文件夹 → 设置 **PIN Code**（4-6 位数字）

### 我的数据会被收集吗？
**不会。** FastMediaSorter 不会收集或发送任何个人数据。

### 启动器桌面上的联系人快捷方式需要访问我的通讯录吗？
**不需要。** 把一个联系人固定到启动器桌面完全不需要通讯录权限。你在 Android 自带的联系人选择器中选取联系人，应用只读取那一条记录一次，并把它作为快照保存在该图格上 - 它永远无法浏览你的通讯录。拨号时使用的是你在选择器中选定的号码，因此该图格拨打的正是那个号码。

也确实存在一个可选的**通讯录**权限组，可在 **设置 → 通用 → Permissions & Access** 中按需申请。拒绝它不会改变上述任何行为 - 快捷方式仍会以同样的无权限方式工作。

### 应用会在我的照片中保存 GPS 位置吗？
只有在你开启的情况下才会。在 **设置 → 管理 → Photography** 中启用拍照功能，然后在下方开启 **Geotag photos** - 应用会立即请求位置权限，而不是等到按下快门时才请求。带有地理标记的照片，其文件信息界面会显示拍摄日期，以及来自照片 EXIF 数据的 GPS 位置，作为一个可点按的链接，打开你的地图应用或浏览器。

### 我能查看自己如何使用这款应用吗？
可以 - 这是可选功能，默认关闭：在 **设置 → 通用** 中开启 **Statistics collection**，即可打开一个本地使用仪表盘：已整理的文件数、释放的空间、播放时长等，并按媒体类型细分。数据不会自动发送；只有当你主动选择 **Send to author** 或 **Export** 时，才会分享一份摘要。

## 自动翻译

### 翻译是如何工作的？
两个步骤，都在你的设备本地完成：
- **Tesseract** 识别图片中的文字，支持所有受支持的语言（英语、俄语、乌克兰语、保加利亚语、白俄罗斯语）。
- 然后由 **Google ML Kit** 翻译识别出的内容。

### "Auto" 源语言选项是做什么的？
"Auto" 会先用英语模型识别文字，再判断识别结果所属的语言以进行翻译。对于西里尔字母文本，请明确选择源语言（例如**俄语**或**乌克兰语**） - 否则字母会被当作形似的拉丁字母来识别。

### 离线能用吗？
**可以。** 你只需要联网一次，下载源语言的文字识别模型和你语言对的翻译模型。

### 为什么翻译有时会比较慢？
第一次使用某种语言时会加载其文字模型，而较大或较精细的图片需要更长的识别时间。之后使用同一种语言会更快启动。

### 什么是镜头式翻译模式？
**镜头式模式**会把译文以叠加层的形式显示在原图之上，类似 Google Lens。这样你可以在原始上下文和位置中看到译文。可在 **设置 → 媒体 → 其他**（"Lens-style overlay" 开关）中启用。

**标准模式**会在图片下方的独立文本视图中显示译文。

## 幻灯片背景音乐

### 如何为幻灯片添加背景音乐？
1. 添加一个包含音频文件的文件夹作为资源
2. 进入 **设置 → 媒体 → 图片**
3. 启用 **"Play music during slideshow"**
4. 从下拉列表中选择你的音乐资源
5. 开始任意幻灯片放映 - 音乐会自动播放！

### 我能使用来自网络驱动器或云存储的音乐吗？
**可以！** 应用会自动处理网络文件，在播放前将其下载到缓存中。支持 SMB、SFTP、FTP、Google Drive、OneDrive 和 Dropbox。

### 幻灯片放映期间如何切换曲目？
点按幻灯片放映期间显示的**曲目名称**，即可从你的音乐资源中跳到另一首随机曲目。

### 所有版本都支持吗？
**几乎都支持。** 幻灯片音乐需要音频支持：
- **Standard**、**Legacy**、**XR / noLegal** - 完整的音频支持，包括可在后台持续播放
- **Lite** - 可播放本地音频文件和歌词，但没有后台播放服务，应用退到后台时声音会停止
- **Photos** - 完全不支持音频，因此没有幻灯片音乐

## 网络直播流

### FastMediaSorter 能播放网络电台吗？
可以。**Streams** 界面能播放 http/https 音频流（mp3/aac）、带 ICY 正在播放元数据的 Icecast/Shoutcast 电台、HLS（.m3u8）和 DASH 点播，以及 RTSP 来源。适用于 Standard、Legacy 和 XR / noLegal。Lite 和 Photos 完全没有 Streams 界面 - 这个功能在那里是完全不存在的，而不仅仅是部分协议受限。

### 如何打开 Streams 界面？
在主窗口下拉菜单中点按 **Streams**（Streams 启用后可见）。你也可以通过主开关所在的 **Settings > Media > Streams** 进入。

### 如何添加一个电台？
在 Streams 界面中，点按工具栏末端的 **⋮**，选择 **Add stream**，粘贴电台网址。点按 Save。该电台会立即出现在列表中。

### 我能导入播放列表吗？
可以 - 点按 **⋮ > Import from URL**，输入一个远程 `.m3u` 地址。同一个菜单中还有 **Update FastMediaSorter catalog**，用于获取精选列表（带主题和语言筛选标签），也可从 **Settings > Extensions** 或欢迎引导界面进入。

### 某个流播放不了，该怎么办？
如果一个流播放失败，会弹出带有 **Retry**、**Remove** 和 **Cancel** 选项的对话框。跨协议的 301 重定向会自动处理。如果主机已失效或非常慢，目录导入会很快超时而不是一直卡住。

### 离开 Streams 界面后电台还会继续播放吗？
取决于 **Settings > Player > Background audio playback**。开启后台音频时，播放会继续。关闭时，离开界面会停止该流，并提供 Stop / Keep playing 的选择 - 与本地音频播放器的行为相同。

### 我能看到流的实时缩略图吗？
把 Streams 工具栏的切换开关调到 **Grid** 视图 - 每个频道都会显示为一个带有最新捕获画面的图块，方便你一眼看出正在播放的内容。即使关闭并重新打开应用，该图块依然可见，等该流再次上线后会用新的截图刷新。

### 我能把流投屏到电视上吗？
可以，对于视频流 - 在播放器中点按 **Cast**，选择同一 Wi-Fi 网络上的 Chromecast。RTSP 流无法投屏；该按钮只会在 Chromecast 接收端支持的格式上出现。

## Wear OS

### FastMediaSorter 支持 Wear OS 智能手表吗？
**支持！** FastMediaSorter v2 包含一个 Wear OS 伴侣应用，它已经从一个简单的本地文件查看器成长为你媒体内容真正的第二块屏幕。

### 我在手表上能做什么？
- **浏览与播放** - 你配对手机上的文件夹和收藏，或手表自身的本地存储，以带搜索、筛选和排序的缩略图网格呈现。音频和视频支持随机播放、表圈音量控制，以及一个在关屏状态下仍能保持声音继续的模式。
- **双向移动文件** - 直接从手机把照片、视频或曲目发送到手表（就在分享面板中操作），或者把手表上的文件复制回你选择的手机文件夹。
- **在手腕上录制语音备忘录** - 它会一直留在手表上，直到你把它发送到手机，因此录制过程中不会丢失任何内容。
- **播放直播流** - 你 Streams 目录中的电台和视频直接从手表自己的频道列表播放，收藏的频道置顶显示。
- **无需打开应用即可一瞥** - 在表盘的滑动面板中添加一个 FastMediaSorter 图块以便快速查看，或将它的复杂功能添加到兼容的表盘上。
- **内置小工具** - 计算器、网络监视器和迷你游戏各自拥有独立的手表界面。

你在手机上更改的设置会同步到手表，反之亦然，所以你只需要设置一次。

**注意：** 手表本身从不会自行打开云资源 - 它没有自己的云客户端，手机也不会把云文件夹传递给它；只有当你在手机上打开某个云文件，并在“发送到..”中选择你的手表时，云文件才会到达手表。在手表应用的完整版本中（直接安装的 APK），手表确实会自行通过 Wi-Fi 连接 SMB、FTP 和 SFTP 共享 - 也就是你从手机发送给它的那些网络资源。Google Play 版本的手表应用是一个较小的首个版本（计算器、秒表、迷你游戏和设置），尚不支持浏览媒体。

## EPUB 电子书

### 如何启用 EPUB 支持？
设置 → 媒体 → **文档** → **"Support EPUB e-books"**

**注意：** 启用后请重启应用以使更改生效。

### 如何阅读一本 EPUB 电子书？
1. 添加一个包含 .epub 文件的文件夹作为资源
2. 打开该文件夹 - 你会看到带有 "E" 徽标的 EPUB 文件
3. 点按任意 EPUB 文件在阅读器中打开它

### 我能在章节之间导航吗？
**可以！** 使用：
- 底部的**上一个/下一个按钮**
- **左右滑动**切换章节
- **目录按钮**（📋 图标）打开目录

### 我能调整字体大小吗？
**可以！** 阅读时，使用底部的 **-A/+A 按钮**减小/增大字体大小（6-144px 范围）。设置会按书本单独保存。

### 我能在 EPUB 中搜索文本吗？
**可以！** 点按**搜索按钮** <img src="icons/doc/ic_search.png" alt="" width="18" height="18" style="vertical-align:text-bottom"> 打开搜索面板。输入你的查询内容，用上一个/下一个按钮在匹配结果间导航。

### 支持网络/云文件吗？
**支持！** 从 SMB/SFTP/FTP/云存储打开 EPUB 文件时，会自动下载到缓存。

### 会记住我的阅读位置吗？
**会！** 应用会保存你最后阅读的章节。重新打开这本书时，会从你离开的地方继续。

### 深色/浅色主题呢？
EPUB 查看器会自动适配你的应用主题（设置 → 通用 → Color theme）。

## 计划操作

### 什么是计划操作？
基于时间的自动化规则，可在你的任意资源（本地文件夹、NAS、云）之间按重复计划运行 Copy、Move 或 Delete 操作 - 即使应用已关闭也能运行。

### 在哪里设置计划操作？
设置 → **管理** → **Scheduled operations by schedule**。点按 **"+"** 添加一条新规则。

### 应用关闭时它还会运行吗？
**会。** 操作是通过 Android **WorkManager** 调度的，无论应用是否打开，它都会在后台运行这些操作。

### 为什么计划操作没有在准确的时间运行？
Android 可能会为了优化电池而将 WorkManager 任务推迟几分钟。为了获得更可靠的定时，请为应用授予**电池优化**豁免（设置 → 通用 → Battery Optimization）。最小间隔为 15 分钟。

### 计划操作运行了但复制了 0 个文件
这通常是正常的 - 说明所有文件在目标位置已经存在（该操作默认使用“跳过已存在”）。如需验证：查看操作日志，对比 "skipped" 数量和 "copied" 数量。

如果你原本期望复制新文件却没有发生：
- 确认 **Source** 设置为正确的资源（例如 "Camera Photos" 虚拟资源 - 而不是可能有误的手动路径）
- 检查目标资源（SMB / 云）在预定时间是否可访问 - 如果当时 Wi-Fi 是关闭的，该次运行会被跳过并在下次重试

### 我能查看处理过的内容吗？
**可以。** 在 Scheduled Operations 区域中点按 **"View Log"**，即可查看每次运行的带时间戳历史记录，包括逐个文件的结果。

## 天气模块

### 天气数据来自哪里？
桌面天气模块使用 **Open-Meteo.com** - 一个免费、无需密钥的天气服务。天气数据来自 Open-Meteo.com（CC-BY 4.0）。

### 应用会追踪我的位置吗？
**不会。** 地点是你自己输入的，不会请求任何位置权限。该模块大约每 20 分钟刷新一次，在没有网络时会显示带有 "Last known" 标记的上一次读数。点按它会打开设备上的天气应用。
