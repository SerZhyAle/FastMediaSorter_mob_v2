## 常规问题

### FastMediaSorter 是什么？
FastMediaSorter 集成媒体播放与本地、网络、云端文件管理。桌面启动器、直播和手表联动取决于版本。文件访问需要授权；替换主屏幕必须由您在 Android 中明确选择。

### 它是免费的吗？
是的！FastMediaSorter v2 完全免费且开源。

### 我需要什么 Android 版本？
以下为当前源码配置的最低安装版本。沉浸式 VR/XR 还需兼容头显与运行环境；**noLegal 并非仅供头显使用**。源码中存在某个变体不代表已有公开 APK。

- standard / noLegal / lite / photos: Android 8.0 / API 26
- legacy / foss: Android 6.0 / API 23
- vr: Android 10 / API 29
- xr: Android 8.0 / API 26
- Wear OS app: API 28
- WFF v4 watchface: Wear OS 6 / API 36

[Android / SDK (EN)](TECHNICAL_REQUIREMENTS.html)

### 需要联网吗？
本地文件不需要互联网。局域网 SMB/SFTP/FTP 需要能访问服务器的网络，不需要公网。云服务与互联网直播需要互联网；功能取决于版本。

### 应用有小组件吗？
有！FastMediaSorter v2 提供多种主屏幕小组件 - 长按主屏幕 → Widgets → FastMediaSorter 即可找到它们。包括资源快捷方式、幻灯片放映启动器等等。

### 应用能替代我的主屏幕吗？
在 **Standard/noLegal** 中选择 **设置 → 常规 → 主启动窗口 → 设备主屏幕**，再在 Android 中指定 FastMediaSorter 为主屏幕应用。**桌面作为主窗口**不会替换系统启动器。

[版本功能矩阵（EN）](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/blob/main/docs/FLAVOR_MATRIX.md)

### 如何让应用不再作为我的主屏幕？
在开始菜单选择**退出启动器模式**、选择其他启动窗口，或在 Android 默认应用设置中选择其他主屏幕应用。桌面布局保留；系统设置路径因设备而异。

[版本功能矩阵（EN）](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/blob/main/docs/FLAVOR_MATRIX.md)

### 为什么我的平板重启后回到了原来的主屏幕？
检查 Android 默认主屏幕与应用启动窗口；若提供选项，请选择**始终**。固件、更新或默认设置重置可能改变选择，单次重启不能证明原因。反馈时提供机型与 Android 版本。

### 我能把自己的文件夹和播放列表放到桌面上吗？
可以 - 桌面就是为此而生的。长按一个空白方格，选择 **Add an item..**，然后选择你想要的内容：你的某个文件夹、一个电台、一个应用、一个联系人，或者时钟、天气这样的小组件。新的图格会落在你长按的那个方格上，对于文件夹，你还可以选择它是打开浏览、幻灯片放映还是播放模式。之后想调整位置，从同一个长按菜单中选择 **Edit the desktop**。完整操作步骤见 [HOW_TO](HOW_TO-zh-hans.html#how-to-use-the-app-as-your-home-screen)。

## 文件操作

### 删除的文件去哪了？
启用回收站后，支持的普通本地路径使用 `.trash/`。**永久删除**、`content://`、SMB/SFTP/FTP/云端及受保护的 `/Android/media/` 路径不使用此软删除策略。清空回收站不可逆，并非所有删除都能恢复。

### 我能撤销删除/移动吗？
仅在应用提供时立即点击可见的**撤销**。可用性取决于操作、界面和路径。永久或网络/document-tree 删除不能经本地回收站撤销，网络/云端文件传输也不一定可逆。撤销不能代替备份。

### Copy 和 Move 有什么区别？
- **Copy：** 创建一个副本，原文件保留在原位
- **Move：** 迁移文件，从原位置移除

### 什么是 All Files mode？
全部文件模式移除**可访问资源内**的媒体类型过滤，不绕过 Android 权限。其他格式可作为文件管理或用兼容外部应用打开；显示 APK/EXE/压缩包不表示能运行或解压。

### 如何查找并删除重复文件？
打开一个文件夹，点按溢出菜单，选择 **Find Duplicates** 自行查看匹配结果，或选择 **Find and Delete Duplicates** 立即删除它们。还有一个 **Delete by Size..**，可基于文件大小快速清理。自动选项会跳过确认，所以如果想在删除前再三确认，请先使用 **Find Duplicates**。匹配基于内容 - 先比较大小，再快速哈希，最后完整的 SHA-256 校验 - 因此改过名的副本依然能被找到。

## 网络与云

### 如何连接到我家的 NAS（网络驱动器）？
1. 点按 **"+"** → **Network** → **SMB / Network Drive**
2. **方式 A - 自动：** 点按 **"Scan Network"** 自动发现网络中的可用设备
3. **方式 B - 手动：** 输入服务器地址：`\\192.168.1.100\share` 或 `smb://192.168.1.100/share`
4. 输入用户名和密码
5. 点按 "Connect"

使用获授权的 NAS/Windows 账户和可访问 SMB 共享。TCP **445** 仅允许可信私有网络及所需子网；**不要关闭防火墙或把 SMB 暴露到公网**。检查共享权限、地址、VPN 路由及访客网络隔离。正确配置的私有 VPN 也可通过移动数据访问。

[SMB 设置指南](howto/scenario-smb-setup.html)

### 如何连接到 Google Drive？
1. 点按 **"+"** → **Cloud** → **Google Drive**
2. 点按 "Sign in with Google"
3. 出现提示时授予权限
4. 你的 Drive 文件夹就会出现

文件按需打开，但查看、缩略图或播放可能下载数据到应用缓存。这不是整个 Drive 的自动同步。

### 如何连接到 OneDrive？
1. 点按 **"+"** → **Cloud** → **OneDrive**
2. 点按 "Sign in with Microsoft"
3. 出现提示时授予权限
4. 你的 OneDrive 文件夹就会出现

### 如何连接到 Dropbox？
1. 点按 **"+"** → **Cloud** → **Dropbox**
2. 点按 "Sign in with Dropbox"
3. 出现提示时授予权限
4. 你的 Dropbox 文件夹就会出现

### 我能使用 SFTP 或 FTP 吗？
**可以！** 添加文件夹时选择 **SFTP** 或 **FTP**：
- **SFTP：** 更安全，需要 SSH 服务器（端口 22）
- **FTP：** 安全性较低，较老的协议（端口 21）

### 我能把电脑上的文件夹共享给应用吗？
**可以** - Fast Media Sorter for Windows 会通过 SFTP 发布选定的电脑文件夹，并显示一个二维码 / `.fmscfg` 配置文件。在手机上，在 Add Resource 界面使用 **Import from companion** 或 **Scan QR code**。参见电脑端指南：[如何将电脑文件夹发布到 Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)。适用于 Standard、Photos、Legacy、XR/noLegal。

[版本功能矩阵（EN）](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/blob/main/docs/FLAVOR_MATRIX.md)

### 为什么网络文件的缩略图加载不出来？
网络文件的缩略图为节省带宽而**按需生成**。请慢慢滚动，或稍等几秒让它们显示出来。

如果缩略图一直无法加载：
- 确认连接是活跃的：点按该资源 → 如果文件夹能打开，说明连接正常
- 编辑该资源 → 确保 **"Load thumbnails"** 已启用
- 对于非常慢的连接：完全禁用缩略图以避免超时（编辑资源 → 禁用缩略图）

### 连接总是断开/文件在播放中途打不开
检查 Wi-Fi、服务器、凭据与 VPN 路由。测试资源速度并减少慢连接的缩略图。带宽取决于码率与编码，不仅是分辨率；**10 Mbps 不是所有 1080p 的通用要求**。

## 快速分类与目标文件夹

### 什么是 "Quick Sort" 文件夹？
Quick Sort 文件夹是预先配置好的目标文件夹，用于快速整理文件。你最多可以为 10 个文件夹分配编号按钮。

### 如何设置 Quick Sort？
**方法 1：** 设置 → 管理 → Quick Sort destinations，然后点按 **"Add to Quick Sort"**  
**方法 2：** 编辑任意文件夹 → 启用 "Mark for Quick Sort"

### 查看文件时如何使用 Quick Sort？
打开文件，在命令面板选择目标。确认前检查是**复制**还是**移动**。触摸区域因媒体和模式而异，左下角并非总是复制。

### 我能用数字键代替点按吗？
可以 - 连接一个硬件键盘、手柄或电视遥控器，你的 Quick Sort 按钮会自动获得编号（0-9）。按下对应的数字即可立即将文件复制或移动到该目标，效果和点按按钮一样。

### Quick Sort 按钮没有显示
请确认你已先添加至少一个目标文件夹：设置 → 管理 → Quick Sort destinations，然后 **"Add to Quick Sort"**。只有配置了至少一个目标后，按钮才会出现。

### 我不小心把文件发到了错误的文件夹
若提供**撤销**请立即使用；否则检查源与目标后手动移回。复制保留原文件；验证结果前不要删除任一副本。

## 触控区域

### 什么是 "触控区域"？
区域取决于媒体和模式：图片可用 3×3，音视频保留播放控件且中心为暂停/继续。命令面板模式为三列；文档使用滑动翻页而无点击区域。开启覆盖层查看当前映射。

### 如何查看触控区域？
设置 → 播放器 → **"Always show touch zones overlay"**

### 我能禁用触控区域吗？
可关闭九宫格并使用命令面板，但**不会禁用所有手势**：三列模式仍保留导航和媒体控制，文档仍有翻页手势。

## 屏幕与语音录制

### 左侧边缘手势条是什么？
这是一个快速捕获菜单，从屏幕左边缘斜向滑动即可打开。在 **设置 → 管理 → Edge screen gestures → Gesture overlay** 中开启它。从菜单中你可以截屏、快速拍照、裁剪并分享当前图片、打开某个应用或面板快捷方式，或开始屏幕、视频或语音录制 - 全程无需离开当前正在看的内容。适用于 Standard 和 XR/noLegal。

### 如何快速录制一段语音备忘录？
三种方式：溢出菜单中的 **Voice recording** 项、**Quick Recorder** 主屏幕小组件，或边缘手势的 **Start audio recording** 操作。无论用哪种方式启动，屏幕上都会一直保留一个悬浮的 **Stop** 控件 - 即使切换到其他应用也在 - 直到你点按它保存为止。

## 输入与控制

### 支持物理键盘和手柄吗？
键盘、鼠标与手柄支持取决于界面和设备。**F1** 在支持的界面显示绑定帮助，不保证所有按键在每个对话框均可用。

### 如何重新映射控制/更改按键绑定？
在**设置 → 管理 → 控制与按键绑定**修改支持的动作。**Reset** 恢复默认，冲突会标记。以当前列表为准，不应依赖固定的 70 个动作。

### 如何从网址下载媒体文件？
通过 Android 分享支持的 `http(s)` URL。直接文件链接不等同网页、需登录视频或 DRM 流。下载与可写目标取决于版本、URL 及权限。

## 性能与存储

### 如何按名称查找特定文件？
在浏览界面中使用**筛选**面板：点按工具栏中的筛选图标，在名称栏中输入文件名的任意一部分 - 列表会立即更新。不需要单独的搜索栏；筛选功能已完全覆盖这个场景。

### 为什么 5000+ 文件时应用会变慢？
大文件夹需要列举文件、读取元数据和缩略图。缩小资源范围、过滤并减少缩略图。按日期排序**不保证**免于扫描整个文件夹；性能取决于来源和格式。

### 应用崩溃或卡死
重开应用，检查空间、权限和连接。清缓存可修复过期缩略图，不是通用崩溃修复。反馈版本/变体、Android、资源与复现步骤；日志中删除凭据和私人路径。

### 缩略图缓存占用多少存储空间？
**默认：** 2 GB（可在设置中配置）

### 如何清除缓存？
设置 → 通用 → **"Clear Cache"**

## 安全与隐私

### 我能给文件夹设置密码保护吗？
资源 **PIN** 限制应用内访问，**不加密文件**，也不阻止其他应用或获授权服务器用户访问。应用外保护应使用设备/存储加密。

### 我的数据会被收集吗？
应用不会自动向作者发送使用统计；可选统计在导出/发送前保留本地。云、直播和天气会向所选服务商发送功能所需请求。详情参见隐私政策。

[隐私政策 (EN)](PRIVACY_POLICY.html)

### 启动器桌面上的联系人快捷方式需要访问我的通讯录吗？
**不需要。** 把一个联系人固定到启动器桌面完全不需要通讯录权限。你在 Android 自带的联系人选择器中选取联系人，应用只读取那一条记录一次，并把它作为快照保存在该图格上 - 它永远无法浏览你的通讯录。拨号时使用的是你在选择器中选定的号码，因此该图格拨打的正是那个号码。

也确实存在一个可选的**通讯录**权限组，可在 **设置 → 通用 → Permissions & Access** 中按需申请。拒绝它不会改变上述任何行为 - 快捷方式仍会以同样的无权限方式工作。

### 应用会在我的照片中保存 GPS 位置吗？
只有在你开启的情况下才会。在 **设置 → 管理 → Photography** 中启用拍照功能，然后在下方开启 **Geotag photos** - 应用会立即请求位置权限，而不是等到按下快门时才请求。带有地理标记的照片，其文件信息界面会显示拍摄日期，以及来自照片 EXIF 数据的 GPS 位置，作为一个可点按的链接，打开你的地图应用或浏览器。

### 我能查看自己如何使用这款应用吗？
可以 - 这是可选功能，默认关闭：在 **设置 → 通用** 中开启 **Statistics collection**，即可打开一个本地使用仪表盘：已整理的文件数、释放的空间、播放时长等，并按媒体类型细分。数据不会自动发送；只有当你主动选择 **Send to author** 或 **Export** 时，才会分享一份摘要。

## 自动翻译

### 翻译是如何工作的？
两个步骤，都在你的设备本地完成：
- **Tesseract** 识别图片中的文字，支持所有受支持的语言（英语、俄语、乌克兰语、保加利亚语、白俄罗斯语）。
- 然后由 **Google ML Kit** 翻译识别出的内容。

可用性取决于版本和设备类别。此处 ML Kit 翻译仅用于手机、平板、Chromebook 和桌面类设备，不用于 TV、车载、手表或 XR。独立 OCR 要求 API 26+、至少 3 GB RAM 且未被系统标为 low-RAM。

### "Auto" 源语言选项是做什么的？
"Auto" 会先用英语模型识别文字，再判断识别结果所属的语言以进行翻译。对于西里尔字母文本，请明确选择源语言（例如**俄语**或**乌克兰语**） - 否则字母会被当作形似的拉丁字母来识别。

### 离线能用吗？
**可以。** 你只需要联网一次，下载源语言的文字识别模型和你语言对的翻译模型。

### 为什么翻译有时会比较慢？
第一次使用某种语言时会加载其文字模型，而较大或较精细的图片需要更长的识别时间。之后使用同一种语言会更快启动。

### 如何把译文直接显示在原文上方？
覆盖模式在图片上显示翻译块；标准模式单独显示文本。在支持的设备上选择 **设置 → 媒体 → 翻译、文字识别（OCR） → 翻译结果以块的形式呈现**。

## 幻灯片背景音乐

### 如何为幻灯片添加背景音乐？
1. 添加一个包含音频文件的文件夹作为资源
2. 进入 **设置 → 媒体 → 图片**
3. 启用 **"Play music during slideshow"**
4. 从下拉列表中选择你的音乐资源
5. 开始任意幻灯片放映 - 音乐会自动播放！

### 我能使用来自网络驱动器或云存储的音乐吗？
**可以！** 应用会自动处理网络文件，在播放前将其下载到缓存中。支持 SMB、SFTP、FTP、Google Drive、OneDrive 和 Dropbox。

### 幻灯片放映期间如何切换曲目？
点按幻灯片放映期间显示的**曲目名称**，即可从你的音乐资源中跳到另一首随机曲目。

### 所有版本都支持吗？
Standard、noLegal、Legacy、VR、XR、FOSS 支持音频和持续后台播放。Lite 支持本地音频但无持续后台服务；Photos 无音频。网络/云来源还取决于版本。

## 网络直播流

### FastMediaSorter 能播放网络电台吗？
**直播**支持 HTTP(S)/ICY 电台、HLS/DASH 和 RTSP，取决于来源与编码。适用于 **Standard、noLegal、Legacy、VR、XR**，不适用于 **Lite、Photos、FOSS**。粘贴 URL 不能绕过不兼容服务或 DRM。

[版本功能矩阵（EN）](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/blob/main/docs/FLAVOR_MATRIX.md)

### 如何打开 Streams 界面？
在主窗口下拉菜单中点按 **Streams**（Streams 启用后可见）。你也可以通过主开关所在的 **Settings > Media > Streams** 进入。

### 如何添加一个电台？
在 Streams 界面中，点按工具栏末端的 **⋮**，选择 **Add stream**，粘贴电台网址。点按 Save。该电台会立即出现在列表中。

### 我能导入播放列表吗？
可以 - 点按 **⋮ > Import from URL**，输入一个远程 `.m3u` 地址。同一个菜单中还有 **Update FastMediaSorter catalog**，用于获取精选列表（带主题和语言筛选标签），也可从 **Settings > Extensions** 或欢迎引导界面进入。

### 某个流播放不了，该怎么办？
如果一个流播放失败，会弹出带有 **Retry**、**Remove** 和 **Cancel** 选项的对话框。跨协议的 301 重定向会自动处理。如果主机已失效或非常慢，目录导入会很快超时而不是一直卡住。

### 离开 Streams 界面后电台还会继续播放吗？
支持并启用持续后台音频时，退出按停止/继续/询问设置处理；关闭该模式时，界面离开前台即停止音频。请检查设置 → 播放器。

### 我能看到流的实时缩略图吗？
把 Streams 工具栏的切换开关调到 **Grid** 视图 - 每个频道都会显示为一个带有最新捕获画面的图块，方便你一眼看出正在播放的内容。即使关闭并重新打开应用，该图块依然可见，等该流再次上线后会用新的截图刷新。

### 我能把流投屏到电视上吗？
可以，对于视频流 - 在播放器中点按 **Cast**，选择同一 Wi-Fi 网络上的 Chromecast。RTSP 流无法投屏；该按钮只会在 Chromecast 接收端支持的格式上出现。

## EPUB 电子书

### 如何启用 EPUB 支持？
设置 → 媒体 → **文档** → **"Support EPUB e-books"**

**注意：** 启用后请重启应用以使更改生效。

### 如何阅读一本 EPUB 电子书？
1. 添加一个包含 .epub 文件的文件夹作为资源
2. 打开该文件夹 - 你会看到带有 "E" 徽标的 EPUB 文件
3. 点按任意 EPUB 文件在阅读器中打开它

### 我能在章节之间导航吗？
**可以！** 使用：
- 底部的**上一个/下一个按钮**
- **左右滑动**切换章节
- **目录按钮**（📋 图标）打开目录

### 我能调整字体大小吗？
**可以！** 阅读时，使用底部的 **-A/+A 按钮**减小/增大字体大小（6-144px 范围）。设置会按书本单独保存。

### 我能在 EPUB 中搜索文本吗？
**可以！** 点按**搜索按钮** <img src="icons/doc/ic_search.png" alt="" width="18" height="18" style="vertical-align:text-bottom"> 打开搜索面板。输入你的查询内容，用上一个/下一个按钮在匹配结果间导航。

### 支持网络/云文件吗？
**支持！** 从 SMB/SFTP/FTP/云存储打开 EPUB 文件时，会自动下载到缓存。

### 会记住我的阅读位置吗？
**会！** 应用会保存你最后阅读的章节。重新打开这本书时，会从你离开的地方继续。

### 深色/浅色主题呢？
EPUB 查看器会自动适配你的应用主题（设置 → 通用 → Color theme）。

## 计划操作

### 什么是计划操作？
计划规则对可访问资源执行支持的复制、移动或删除。权限、凭据及两端可用性仍必需。先用**复制**测试；计划删除不一定可撤销。

### 在哪里设置计划操作？
设置 → **管理** → **Scheduled operations by schedule**。点按 **"+"** 添加一条新规则。

### 应用关闭时它还会运行吗？
离开应用后 WorkManager 可运行，但 Android **强行停止**、关机或权限/条件不满足时不保证执行。强停后重开并检查规则和日志。

### 为什么计划操作没有在准确的时间运行？
WorkManager 不是精确闹钟；电池、网络和设备限制可能延迟超过几分钟。最小间隔 **15 分钟**；电池优化豁免不保证准时。

### 计划操作运行了但复制了 0 个文件
查看日志：零复制可能为跳过已有文件、无匹配、资源不可用或权限失败。检查源、过滤、目标和凭据；零文件并不总表示成功。

### 我能查看处理过的内容吗？
**可以。** 在 Scheduled Operations 区域中点按 **"View Log"**，即可查看每次运行的带时间戳历史记录，包括逐个文件的结果。

## 天气模块

### 天气数据来自哪里？
桌面天气模块使用 **Open-Meteo.com** - 一个免费、无需密钥的天气服务。天气数据来自 Open-Meteo.com（CC-BY 4.0）。

### 应用会追踪我的位置吗？
**天气模块**使用输入地点，不自动 GPS 跟踪；刷新会将地点发送给天气服务。可选照片地理标记是另一功能，启用时需要位置权限。
