# 🔧 Руководство по устранению неполадок

Частые проблемы и решения для FastMediaSorter v2.

---

## Проблемы с подключением

### ❌ "Не удается подключиться к серверу SMB"

**Возможные причины:**
1. **Неверная сеть** - Телефон должен быть в той же сети Wi-Fi, что и NAS
2. **Неверный формат адреса** - Попробуйте оба формата:
   - `\\192.168.1.100\share`
   - `smb://192.168.1.100/share`
3. **Блокировка брандмауэром** - Проверьте настройки брандмауэра NAS
4. **Несоответствие версии SMB** - Некоторые NAS всё ещё требуют совместимость с SMB v2/v3; обновите сервер, если он открывает только устаревшие настройки SMB

**Решение:**
- Сначала проверьте подключение с ПК
- Проверьте журналы NAS на наличие попыток подключения
- Попробуйте IP-адрес вместо имени хоста
- Проверьте имя пользователя/пароль

---

### ❌ "Тайм-аут подключения SFTP"

**Возможные причины:**
1. Неверный порт (по умолчанию: 22)
2. Сервер SSH не запущен
3. Блокировка брандмауэром

**Решение:**
```
1. Сначала проверьте с помощью SSH-клиента на ПК:
   ssh username@192.168.1.100
2. Проверьте, запущена ли служба SSH
3. Проверьте порт в Настройках
```

---

### ❌ "Ошибка входа в Google Drive"

**Решение:**
1. Очистите данные приложения: Настройки → Приложения → FastMediaSorter → Очистить данные
2. Переустановите приложение
3. Проверьте настройки аккаунта Google → Безопасность → Сторонние приложения

---

### ❌ "Ошибка входа в OneDrive"

**Решение:**
1. Проверьте статус учётной записи Microsoft
2. Очистите данные приложения: Настройки → Приложения → FastMediaSorter → Очистить данные
3. Проверьте настройки учётной записи Microsoft → Конфиденциальность → Приложения и службы

---

### ❌ "Ошибка входа в Dropbox"

**Решение:**
1. Проверьте статус учётной записи Dropbox
2. Очистите данные приложения: Настройки → Приложения → FastMediaSorter → Очистить данные
3. Проверьте настройки учётной записи Dropbox → Безопасность → Подключенные приложения

---

## Проблемы с производительностью

### ❌ "Приложение работает медленно / тормозит"

**Для больших папок (5000+ файлов):**
1. Настройки → Редактировать папку → Включить **"Отключить миниатюры"**
2. Используйте **фильтры**, чтобы уменьшить количество видимых файлов
3. Закройте другие приложения, чтобы освободить ОЗУ

**Для сетевых папок:**
1. Проверьте уровень сигнала Wi-Fi
2. Уменьшите размер кэша миниатюр
3. Включите **"Сканировать подкаталоги"** = ВЫКЛ, если не требуется

---

### ❌ "Миниатюры не загружаются"

**Локальные файлы:**
- Проверьте разрешения на доступ к хранилищу
- Очистите кэш миниатюр
- Перезапустите приложение

**Сетевые файлы:**
- Прокручивайте медленнее (миниатюры загружаются по требованию)
- Проверьте скорость сети
- Увеличьте размер кэша в Настройках

---

## Ошибки операций с файлами

### ❌ "Копирование не удалось: Отказано в доступе"

**Локальные файлы:**
- Предоставьте разрешения на доступ к хранилищу: Настройки → Приложения → Разрешения
- Проверьте, доступна ли папка только для чтения
- Попробуйте переместить в другое место

**Сетевые файлы:**
- Проверьте, есть ли у пользователя права на запись
- Проверьте настройки общего доступа на NAS

---

### ❌ "Невозможно удалить файл"

**Возможные причины:**
1. Файл открыт в другом приложении
2. Нет прав на запись
3. Файл защищен системой

**Решение:**
- Закройте другие приложения
- Проверьте разрешения папки
- Для сети: проверьте, есть ли у пользователя права на удаление

---

### ❌ "Операция перемещения не удалась"

**Перемещение между протоколами** (например, Локально → SMB):
- Это фактически **копирование + удаление**
- Требуется свободное место на целевом устройстве
- Может занять больше времени для больших файлов

**Решение:**
- Проверьте доступное место
- Используйте Копирование вместо Перемещения для безопасности
- Дождитесь завершения полной операции

---

## Сбои приложения

### ❌ "Приложение вылетает при открытии плеера"

**Частые причины:**
1. Поврежденный видеофайл
2. Неподдерживаемый кодек
3. Файл слишком большой (>4GB)

**Решение:**
- Попробуйте воспроизвести файл в другом приложении для проверки
- Проверьте формат файла (поддерживаются: MP4, MKV, MOV)
- Очистите кэш приложения

---

### ❌ "Медиафайл не воспроизводится или нет звука"

**Проблема:** Видео загружается, но показывает чёрный экран, или воспроизводится без звука.

**Решение:**
1. Нажмите кнопку **ⓘ (Инфо)** в верхней панели
2. Нажмите **"Открыть во внешнем плеере"**
3. Выберите специализированный плеер (например, VLC, MX Player)

Это использует функцию *Secondary Player* для передачи неподдерживаемых кодеков другим приложениям.

---

### ❌ "Приложение вылетает при запуске"

**Решение:**
1. Очистите кэш приложения: Настройки → Приложения → FastMediaSorter → Очистить кэш
2. Если не помогает: Очистите данные приложения (⚠️ настройки будут потеряны)
3. Переустановите приложение в качестве крайней меры

---

## Проблемы с интерфейсом / отображением

### ❌ "Сенсорные зоны не работают"

**Проверьте, включено ли:**
Настройки → Воспроизведение → **"Показывать подсказку зон при первом запуске"** = ВКЛ

**Сделать видимым:**
Настройки → Воспроизведение → **"Всегда показывать наложение зон"** = ВКЛ

---

### ❌ "Кнопки панели команд слишком маленькие"

**Решение:**
Настройки → Воспроизведение → **"Компактный режим"** = ВЫКЛ

Это увеличивает размер всех кнопок и интервалы вдвое.

---

### ❌ "Тёмная тема не работает"

Приложение следует **системной теме**:
- Настройки Android → Экран → Тёмная тема = ВКЛ

## Проблемы с данными

### ❌ "Избранное исчезло"

Избранное хранится **локально**:
- Очистили данные приложения? → Избранное потеряно
- Новое устройство? → Нужно отметить заново

**Предотвращение:**
- Используйте Настройки → Резервное копирование для сохранения настроек
- Избранное НЕ включено в резервную копию (будущая функция)

---

### ❌ "Папка корзины продолжает расти"

Удаленные файлы попадают в папку `.trash/` и остаются там до ручной очистки.

**Решение:**
1. Настройки → Операции → **Удаление файлов и корзина**
2. Или вручную удалите папки `.trash/`

---

## Проблемы с переводом и EPUB
    
### ❌ "Перевод не работает или завис"

**Возможные причины:**
1. **Отсутствуют модели:** Приложению не удалось загрузить модели OCR.
2. **Нет интернета:** Для первого запуска требуется интернет для загрузки моделей.
3. **Память заполнена:** Нет места для моделей (~50 МБ).

**Решение:**
1. Проверьте подключение к интернету.
2. Перейдите в **Настройки** → **Медиа** → **Перевод, OCR и Google Объектив**
3. Выключите и снова включите "Включить перевод".
4. Попробуйте переключить **Исходный язык** на "Авто".

---

### ❌ "Книга EPUB не открывается"

**Возможные причины:**
1. **Защита DRM:** Приложение поддерживает только EPUB без DRM.
2. **Поврежденный файл:** Файл может быть неполным.
3. **Очень большой файл:** Файлы >100 МБ в медленной сети могут вызывать тайм-аут.

**Решение:**
1. Проверьте, открывается ли файл в других читалках.
2. Если файл в сети/облаке, попробуйте сначала скачать его вручную.
3. Убедитесь, что расширение файла именно `.epub`.

---

## Проблемы с контентом

### ❌ "Не вижу текстовые или PDF файлы"

**Решение:**
1. Проверьте **Настройки** → **Медиа** → **Просмотр текста, PDF и EPUB**
2. Убедитесь, что **"Поддержка текстовых файлов"** и **"Поддержка PDF файлов"** включены.
3. Проверьте **Фильтры** на главном экране (иконка воронки).
4. **Пересканируйте** папку (свайп вниз для обновления).

---

## Известные ограничения

- ⚠️ **Нет поддержки RAW фото** (CR2, NEF, ARW)
- ⚠️ **Отмена сетевых операций недоступна** (файлы удаляются безвозвратно)
- ⚠️ **Dropbox/OneDrive не полные** (только база)
- ⚠️ **Нет синхронизации между устройствами** (избранное локально)
