# 🔧 সমস্যা সমাধান গাইড

FastMediaSorter v2-এর জন্য বর্তমান সমস্যা সমাধান গাইড। সমস্যাটি যদি নির্বাচিত বিল্ড পাথের (Standard, Lite, Photos, Legacy, বা XR / noLegal) উপর নির্ভর করে, তাহলে [FLAVOR_MATRIX.md](FLAVOR_MATRIX.md)-এর ক্যানোনিকাল ফ্লেভার ম্যাট্রিক্স ব্যবহার করুন।

## সংযোগ সংক্রান্ত সমস্যা

### ❌ "Cannot connect to SMB server"

**সম্ভাব্য কারণ:**
1. **ভুল নেটওয়ার্ক** - ফোনকে অবশ্যই NAS-এর মতো একই Wi-Fi-তে থাকতে হবে
2. **ভুল ঠিকানা ফরম্যাট** - উভয় ফরম্যাট চেষ্টা করুন:
   - `\\192.168.1.100\share`
   - `smb://192.168.1.100/share`
3. **ফায়ারওয়াল ব্লক করছে** - NAS ফায়ারওয়াল সেটিংস পরীক্ষা করুন
4. **SMB সংস্করণ অমিল** - কিছু NAS-এ এখনও SMB v2/v3 সামঞ্জস্যতা প্রয়োজন হয়; সার্ভারটি শুধু লিগ্যাসি SMB সেটিংস প্রকাশ করলে সার্ভার আপডেট করুন

**সমাধান:**
- প্রথমে পিসি থেকে সংযোগ পরীক্ষা করুন
- সংযোগের চেষ্টার জন্য NAS লগ পরীক্ষা করুন
- হোস্টনেমের বদলে IP ঠিকানা চেষ্টা করুন
- ব্যবহারকারীর নাম/পাসওয়ার্ড যাচাই করুন

### ❌ "SFTP connection timeout"

**সম্ভাব্য কারণ:**
1. ভুল পোর্ট (ডিফল্ট: 22)
2. SSH সার্ভার চালু নেই
3. ফায়ারওয়াল ব্লক করছে

**সমাধান:**
```
1. Test with SSH client on PC first:
   ssh username@192.168.1.100
2. Check if SSH service is running
3. Verify port in Settings
```

### ❌ "Google Drive sign-in failed"

**সমাধান:**
1. অ্যাপ ডেটা ক্লিয়ার করুন: Settings → Apps → FastMediaSorter → Clear Data
2. অ্যাপটি পুনরায় ইনস্টল করুন
3. Google অ্যাকাউন্ট সেটিংস পরীক্ষা করুন → Security → Third-party apps

---

### ❌ "OneDrive sign-in failed"

**সমাধান:**

2. অ্যাপ ডেটা ক্লিয়ার করুন: Settings → Apps → FastMediaSorter → Clear Data
3. Microsoft অ্যাকাউন্ট সেটিংস পরীক্ষা করুন → Privacy → Apps and services

---

### ❌ "Dropbox sign-in failed"

**সমাধান:**
1. Dropbox অ্যাকাউন্টের অবস্থা পরীক্ষা করুন
2. অ্যাপ ডেটা ক্লিয়ার করুন: Settings → Apps → FastMediaSorter → Clear Data
3. Dropbox অ্যাকাউন্ট সেটিংস পরীক্ষা করুন → Security → Connected apps

## পারফরম্যান্স সংক্রান্ত সমস্যা

### ❌ "App is slow / laggy"

**বড় ফোল্ডারের জন্য (৫০০০+ ফাইল):**
1. **Edit folder** (প্রতি-রিসোর্স) → **"Disable thumbnails"** চালু করুন
2. দৃশ্যমান ফাইল কমাতে **ফিল্টার** ব্যবহার করুন
3. RAM খালি করতে অন্যান্য অ্যাপ বন্ধ করুন

**নেটওয়ার্ক ফোল্ডারের জন্য:**
1. Wi-Fi সিগন্যালের শক্তি পরীক্ষা করুন
2. থাম্বনেইল ক্যাশের আকার কমান
3. প্রয়োজন না হলে **"Scan subdirectories"** = OFF করুন

---

### ❌ "Thumbnails not loading"

**লোকাল ফাইল:**
- স্টোরেজ অনুমতি পরীক্ষা করুন
- থাম্বনেইল ক্যাশ ক্লিয়ার করুন
- অ্যাপ পুনরায় চালু করুন

**নেটওয়ার্ক ফাইল:**
- ধীরে স্ক্রল করুন (থাম্বনেইল চাহিদা অনুযায়ী লোড হয়)
- নেটওয়ার্কের গতি পরীক্ষা করুন
- Settings-এ ক্যাশের আকার বাড়ান

## ফাইল অপারেশন ত্রুটি

### ❌ "Copy failed: Permission denied"

**লোকাল ফাইল:**
- স্টোরেজ অনুমতি দিন: Settings → Apps → Permissions
- ফোল্ডারটি read-only কিনা পরীক্ষা করুন
- ভিন্ন লোকেশনে সরানোর চেষ্টা করুন

**নেটওয়ার্ক ফাইল:**
- ব্যবহারকারীর write অনুমতি আছে কিনা পরীক্ষা করুন
- NAS-এ শেয়ার সেটিংস যাচাই করুন

---

### ❌ "Cannot delete file"

**সম্ভাব্য কারণ:**
1. ফাইলটি অন্য একটি অ্যাপে খোলা আছে
2. write অনুমতি নেই
3. ফাইলটি সিস্টেম-সুরক্ষিত

**সমাধান:**
- অন্যান্য অ্যাপ বন্ধ করুন
- ফোল্ডারের অনুমতি পরীক্ষা করুন
- নেটওয়ার্কের জন্য: ব্যবহারকারীর delete অধিকার আছে কিনা যাচাই করুন

---

### ❌ "Move operation failed"

**ক্রস-প্রোটোকল মুভ** (যেমন, Local → SMB):
- এগুলো আসলে **কপি + ডিলিট**
- টার্গেটে খালি জায়গা প্রয়োজন
- বড় ফাইলের জন্য বেশি সময় লাগতে পারে

**সমাধান:**
- উপলব্ধ জায়গা পরীক্ষা করুন
- নিরাপত্তার জন্য Move-এর বদলে Copy ব্যবহার করুন
- সম্পূর্ণ অপারেশন শেষ হওয়া পর্যন্ত অপেক্ষা করুন

## অ্যাপ ক্র্যাশ

### ❌ "App crashes when opening player"

**সাধারণ কারণ:**
1. ভিডিও ফাইল করাপ্ট
2. অসমর্থিত কোডেক
3. ফাইল খুব বড় (>4GB)

**সমাধান:**
- যাচাই করতে ভিন্ন একটি অ্যাপে ফাইলটি চালানোর চেষ্টা করুন
- ফাইল ফরম্যাট পরীক্ষা করুন (সমর্থিত: MP4, MKV, MOV)
- অ্যাপ ক্যাশ ক্লিয়ার করুন

---

### ❌ "Media file not playing or no sound"

**সমস্যা:** ভিডিও লোড হয় কিন্তু কালো স্ক্রিন দেখায়, অথবা শব্দ ছাড়া চলে।

**সমাধান:**
1. উপরের টুলবারে **ⓘ (Info)** বাটনে ট্যাপ করুন
2. **"Open in External Player"** ট্যাপ করুন
3. একটি বিশেষায়িত প্লেয়ার নির্বাচন করুন (যেমন, VLC, MX Player)

এটি অসমর্থিত কোডেক অন্য অ্যাপে হস্তান্তর করতে *Secondary Player* বৈশিষ্ট্য ব্যবহার করে।

---

### ❌ "App crashes on startup"

**সমাধান:**
1. অ্যাপ ক্যাশ ক্লিয়ার করুন: Settings → Apps → FastMediaSorter → Clear Cache
2. সমস্যা থেকেই গেলে: অ্যাপ ডেটা ক্লিয়ার করুন (⚠️ সেটিংস হারিয়ে যাবে)
3. শেষ উপায় হিসেবে অ্যাপ পুনরায় ইনস্টল করুন

---

## UI / ডিসপ্লে সংক্রান্ত সমস্যা

এটি সব বাটন ও স্পেসিংয়ের আকার দ্বিগুণ করে দেয়।

## ডেটা সংক্রান্ত সমস্যা

### ❌ "Favorites disappeared"

Favorites **লোকালি** সংরক্ষিত হয়:
- অ্যাপ ডেটা ক্লিয়ার করেছেন? → Favorites হারিয়ে যাবে
- নতুন ডিভাইস? → পুনরায় চিহ্নিত করতে হবে

**প্রতিরোধ:**
- **Settings → General → Backups, restore and settings export** ব্যবহার করুন
- Favorites ডিভাইসের সাথে লোকাল; নতুন ফোনে গেলে, সেগুলো পুনরায় চিহ্নিত করুন অথবা আপনার বিল্ডে উপলব্ধ অ্যাপ ব্যাকআপ/রিস্টোর প্রবাহ ব্যবহার করুন

---

### ❌ "Trash folder keeps growing"

মুছে ফেলা ফাইল `.trash/` ফোল্ডারে যায় এবং ম্যানুয়ালি খালি না করা পর্যন্ত সেখানেই থাকে।

**সমাধান:**
1. Settings → Management → **File deletion and trash**
2. অথবা ম্যানুয়ালি `.trash/` ফোল্ডার মুছে ফেলুন

## অনুবাদ ও EPUB সংক্রান্ত সমস্যা
    
### ❌ "Translation not working or stuck"

**সম্ভাব্য কারণ:**
1. **মডেল অনুপস্থিত:** অ্যাপ OCR মডেল ডাউনলোড করতে ব্যর্থ হয়েছে।
2. **ইন্টারনেট নেই:** মডেল ডাউনলোড করতে প্রথম রানে ইন্টারনেট প্রয়োজন।
3. **স্টোরেজ পূর্ণ:** মডেলের জন্য জায়গা নেই (~৫০ MB)।

**সমাধান:**
1. ইন্টারনেট সংযোগ পরীক্ষা করুন।
2. **Settings** → **Media** → **Other**-এ যান
3. "Enable Translation" OFF করে আবার ON করুন।
4. **Source Language** "Auto"-তে পরিবর্তন করে দেখুন।

---

### ❌ "EPUB book not opening"

**সম্ভাব্য কারণ:**
1. **DRM সুরক্ষা:** অ্যাপ শুধু DRM-মুক্ত EPUB সমর্থন করে।
2. **ফাইল করাপ্ট:** ফাইলটি অসম্পূর্ণ হতে পারে।
3. **অতিরিক্ত বড় ফাইল:** ধীর নেটওয়ার্কে >100MB ফাইল টাইমআউট হতে পারে।

**সমাধান:**
1. অন্য রিডারে ফাইলটি খোলে কিনা যাচাই করুন।
2. নেটওয়ার্ক/ক্লাউডে থাকলে, প্রথমে ম্যানুয়ালি ডাউনলোড করার চেষ্টা করুন।
3. ফাইল এক্সটেনশন ঠিক `.epub` কিনা নিশ্চিত করুন।

## Internet Streams সংক্রান্ত সমস্যা

### স্ট্রিম শুরু হয় না / এক সেকেন্ড চলে থেমে যায়

**সম্ভাব্য কারণ:**
1. URL-টি মৃত অথবা ভিন্ন প্রোটোকলে রিডাইরেক্ট করছে।
2. সার্ভারটির প্রমাণীকরণ প্রয়োজন (সমর্থিত নয়)।
3. VPN বা কর্পোরেট নেটওয়ার্ক দ্বারা Cleartext http:// ব্লক করা হয়েছে।

**সমাধান:**
- আবার চেষ্টা করতে stream-unavailable ডায়ালগে **Retry** ট্যাপ করুন।
- ব্রাউজারে URL-টি যাচাই করুন।
- পরীক্ষা করতে সাময়িকভাবে VPN বন্ধ করুন।
- স্ট্রিমটি রিডাইরেক্ট হয়ে এখনও ব্যর্থ হলে, **Remove** ট্যাপ করুন এবং সংশোধিত URL পুনরায় যোগ করুন।

### Catalog import স্পিনার থামে না / হ্যাং হয়ে যায়

ক্যাটালগ ডাউনলোডের জন্য অ্যাপ একটি দ্রুত টাইমআউট প্রয়োগ করে। স্পিনারটি ~১৫ সেকেন্ডের বেশি হ্যাং করলে, হোস্টটি সম্ভবত পৌঁছানো যাচ্ছে না। আপনার ইন্টারনেট সংযোগ পরীক্ষা করুন এবং আবার চেষ্টা করুন। ডায়ালগটি টাইমআউটে স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যাবে - এটি অনির্দিষ্টকালের জন্য হ্যাং হয়ে থাকবে না।

### HLS / DASH / RTSP 'unsupported' বার্তা দেখায়

**Standard**, **Legacy**, এবং **XR / noLegal**-এ তিনটি প্রোটোকলই সমর্থিত, তাই এই বার্তাটি বিল্ডের দিকে নয়, স্ট্রিম বা এর কোডেকের দিকে ইঙ্গিত করে। **Lite** এবং **Photos**-এ কোনো Streams স্ক্রিনই নেই, তাই সেখানে প্রথম থেকেই কোনো স্ট্রিম যোগ করা যায় না।

### মেনু বা সেটিংসে Streams অপশন দেখা যাচ্ছে না

- **Standard / Legacy / XR / noLegal**-এ: **Settings > Media > Streams**-এ যান এবং নিশ্চিত করুন **Enable Streams** চালু আছে। Streams চালু থাকলেই শুধু ড্রপডাউন আইটেমটি দেখা যায়।
- **Photos**-এ: এই ফ্লেভারে Streams বৈশিষ্ট্য নির্মিত নেই।
- **Lite**-এও: এই ফ্লেভারে Streams বৈশিষ্ট্য নির্মিত নেই - চালু করার কোনো টগল নেই এবং খোলার কোনো স্ক্রিনও নেই।

### ICY now-playing মেটাডেটা দেখা যাচ্ছে না

ICY মেটাডেটার জন্য এমন একটি Icecast/Shoutcast স্ট্রিম প্রয়োজন যা `Icy-MetaData: 1` হেডার পাঠায়। ICY হেডার ছাড়া সাধারণ http mp3 স্ট্রিম নিচের মিনি-কন্ট্রোলে কোনো স্টেশন/ট্র্যাক তথ্য দেখায় না। এটি একটি সার্ভার-সাইড সীমাবদ্ধতা।

## কনটেন্ট সংক্রান্ত সমস্যা

### ❌ "Cannot see Text or PDF files"

**সমাধান:**
1. **Settings** → **Media** → **Documents** পরীক্ষা করুন
2. নিশ্চিত করুন **"Support Text Files"** এবং **"Support PDF Files"** চালু আছে।
3. সেগুলো নির্বাচিত আছে কিনা নিশ্চিত করতে প্রধান স্ক্রিনে **Filters** (ফানেল আইকন) পরীক্ষা করুন।
4. ফোল্ডারটি **Rescan** করুন (pull-to-refresh)।
