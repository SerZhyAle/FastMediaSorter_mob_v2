## Примітка: Доступність функцій за версіями

Деякі функції доступні лише в певних версіях програми. Дивіться таблицю нижче:

| Функція | Standard | Lite | Photos | Legacy | XR / noLegal |
|---------|----------|------|--------|--------|--------------|
| Мережеві папки (SMB, SFTP, FTP) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Хмарні сховища (Google Drive, OneDrive, Dropbox) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Відтворення аудіо та текст пісень | ✓ | ✗ | ✗ | ✓ | ✓ |
| Перегляд документів (PDF, Текст) | ✓ | ✗ | ✗ | ✓ | ✓ |
| Читалка EPUB | ✓ | ✗ | ✗ | ✓ | ✓ |
| Переклад та OCR | ✓ | ✗ | ✗ | ✓ | ✓ |
| Редагування зображень | ✓ | ✓ | ✓ | ✓ | ✓ |
| Трансляції (інтернет-радіо, HLS/DASH, RTSP) | ✓ | ✓ (лише аудіо) | ✗ | ✓ | ✓ |

Якщо функція позначена як "✗", обирайте **Standard** або **XR / noLegal** відповідно до апаратури та каналу розповсюдження.

## Групи сценаріїв

Ці блоки навмисно різноманітніші за базовий довідник нижче. Кожен сценарій поєднує швидкий шлях, контекст, обмеження та ситуації, де FastMediaSorter особливо сильний.

## Домашній медіацентр, TV і сценарії для вітальні

## Перетворіть NAS на медіаполицю для вітальні

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Швидкий шлях**

1. Додайте NAS як SMB-ресурс.
2. Запустіть **Scan Network**, якщо не хочете вводити IP вручну.
3. Відкрийте ресурс із TV box, планшета або телефона.
4. Почніть переглядати відео, фото чи документи просто з NAS.

**Розбір сценарію**

- Тримайте один SMB-ресурс для всієї сімейної медіатеки й розділяйте дочірні папки за призначенням: фільми, сімейні фото, скани, інструкції.
- Один раз запустіть **Test Connection** під час налаштування, щоб ресурс був стабільним ще до використання з дивана.
- Якщо NAS використовується з TV box, одразу додайте Bluetooth-клавіатуру або пульт для швидкої навігації.
- Якщо перегляд здається повільним, спершу відкрийте налаштування ресурсу й запустіть вбудовану перевірку швидкості.

**Коли це особливо корисно**

- Вам потрібне одне центральне джерело медіа замість копіювання тих самих файлів на кілька пристроїв.
- Ви хочете, щоб одна бібліотека працювала і для слайд-шоу, і для читання документів, і для відтворення.

**Уникайте цього**

- Не починайте з відладки hostname. Спершу використайте IP-адресу, а оптимізуйте пізніше.
- Не очікуйте SMB у flavor Legacy.

## Запустіть слайд-шоу з фоновою музикою для кімнати

**Доступно в:** Standard, Legacy, Photos, XR / noLegal

**Швидкий шлях**

1. Додайте одне джерело зображень і одне джерело музики.
2. У **Налаштування → Медіа → Зображення** увімкніть **Музика під час слайдшоу**.
3. Виберіть музичний ресурс.
4. Відкрийте папку з фото та натисніть **Play**.

**Розбір сценарію**

- Для найплавніших переходів використовуйте локальну папку із зображеннями або швидкий NAS.
- Тримайте окремий музичний ресурс зі спокійними треками, якщо хочете передбачуваний фон.
- Якщо в папці є і зображення, і відео, пам'ятайте: музика автоматично стає на паузу, коли починається відео.

**Коли це особливо корисно**

- Ви хочете перетворити TV box, планшет або старий телефон на цифрову рамку для кімнати.
- Вам потрібен один setup для показу сімейних фото, подієвих добірок або тревел-альбомів без ручного складання черги.

**Уникайте цього**

- Не використовуйте дуже повільний мережевий ресурс одночасно і для зображень, і для музики, якщо важлива плавність.

## Дивіться SBS 3D-відео у VR-режимі

**Доступно в:** Standard, Legacy

**Швидкий шлях**

1. Відкрийте SBS 3D-відео.
2. Перейдіть у fullscreen.
3. Відкрийте **Налаштування відтворення**.
4. Перемкніть **3D Video** у **Auto-detect** або **Side-by-Side (SBS)**.

**Розбір сценарію**

- Для звичайних SBS-файлів починайте з Auto-detect.
- Якщо картинка виглядає подвоєною, вручну ввімкніть **Side-by-Side (SBS)**.
- Для простих phone VR viewers спершу підтвердьте стереорежим і лише потім вставляйте телефон у гарнітуру.

**Коли це особливо корисно**

- У вас є архівні SBS-відео з подорожей, концертів або хобі, і ви хочете переглядати їх без окремого VR-плеєра.

**Уникайте цього**

- Не очікуйте, що Over-Under поводитиметься так само, як SBS.
- Не вважайте будь-яке широке відео тривимірним, доки не перевірите це вручну.

## Іммерсивний кінотеатр OpenXR VR

**Доступно в:** Тільки VR

**Швидкий шлях**

1. Запустіть FastMediaSorter на вашому шоломі Meta Quest або пристрої Android XR.
2. Виберіть будь-який медіафайл (3D або 2D) у локальній, мережевій або хмарній папці.
3. Для 3D/360° стереоконтенту використовуйте плаваючий значок **Точка входу VR** для переходу в іммерсивний режим.
4. Для стандартних 2D-файлів запустіть відтворення на гігантському віртуальному екрані в просторі кінотеатру.

**Розбір сценарію**

- Відкрийте відеофайл формату Side-by-Side (SBS) або Over-Under (OU) й увімкніть автовизначення, щоб глибина 3D відображалася коректно.
- Використовуйте жести відстеження рук (**Quest Hand Tracking**) або промені контролерів для керування плеєром без фізичних кнопок.
- Робіть знімки змішаної реальності Passthrough або стереоскриншоти обох очей під час перебування у VR.

**Коли це особливо корисно**

- Ви хочете дивитися стереоскопічні 3D-фільми або переглядати VR180/360° фотографії з подорожей із якісним рендерингом для кожного ока.
- Ви хочете дивитися звичайні плоскі відеофайли на симульованому гігантському екрані кінотеатру у віртуальній кімнаті.

**Уникайте цього**

- Не використовуйте плоскі версії збірки (Standard/Lite/Legacy) у надії отримати повноцінний трекінг шолома; для цього потрібна спеціальна VR-збірка з підтримкою OpenXR.

## Подорожі, читання та документи

## Підготуйте папку для подорожі без стабільного інтернету

**Доступно в:** Standard, Lite, Photos, Legacy

**Швидкий шлях**

1. Створіть або виберіть одну локальну папку для подорожі.
2. Скопіюйте туди потрібні медіа, PDF, EPUB і нотатки ще до виходу з Wi-Fi.
3. Один раз відкрийте цю папку у FastMediaSorter, щоб підготувалися мініатюри й останні позиції.
4. Використовуйте папку офлайн у дорозі.

**Розбір сценарію**

- Тримайте travel-набір в одній локальній папці, навіть якщо оригінали зазвичай живуть на NAS або в хмарі.
- Навмисно змішуйте формати: посадкові PDF, EPUB для читання, скриншоти й офлайн-музику можна тримати поруч.
- Використовуйте фільтр, якщо хочете швидко перемикатися між зображеннями, документами й аудіо без інтернету.

**Коли це особливо корисно**

- Літаки, поїзди, готелі й сільські зони, де хмарний стримінг ненадійний.
- Ситуації, де потрібен один офлайн-пакет замість пошуку по кількох застосунках.

**Уникайте цього**

- Не залишайте перевірку офлайн-відкриття файлів на останню хвилину.

## Читайте хмарні документи й EPUB у дорозі

**Доступно в:** Standard для хмари, Standard/Lite/Photos/Legacy для локального читання

**Швидкий шлях**

1. Додайте хмарного провайдера через **Cloud Storage**.
2. Відкрийте папку з PDF або EPUB.
3. Натисніть файл прямо в хмарному ресурсі.
4. Пізніше продовжуйте читання з останньої збереженої позиції.

**Розбір сценарію**

- Це зручно, коли робочі документи вже лежать у Google Drive, OneDrive або Dropbox, і вам не потрібен окремий reader workflow.
- PDF краще підходить для квитків, інструкцій і сканів із фіксованою версткою.
- EPUB зручніший для довгого читання, де важливіші розмір шрифту й навігація по розділах, ніж жорстка розкладка сторінки.

**Коли це особливо корисно**

- Ви перемикаєтеся між робочими документами й особистим читанням, не виходячи з застосунку.
- Ви тримаєте дорожні або клієнтські файли в хмарі, але хочете більш читальний інтерфейс.

**Уникайте цього**

- Не очікуйте хмарне читання в Lite, Photos або Legacy.
- Не вважайте повільний мобільний інтернет гарантованим рішенням для дуже великих файлів.

## Перекладайте вивіски, скани та скриншоти через OCR

**Доступно в:** Standard, Legacy, XR / noLegal

**Швидкий шлях**

1. Відкрийте зображення, PDF або текстовий файл.
2. Покажіть панель команд.
3. Натисніть **Translate**.
4. Під час першого запуску підтвердьте завантаження моделі, якщо це потрібно.

**Розбір сценарію**

- Для латиниці застосунок зазвичай починає з ML Kit заради швидкості.
- Для матеріалів із кирилицею застосунок може переключитися на Tesseract заради кращої якості розпізнавання.
- Скриншоти, чеки, меню та скани працюють особливо добре, якщо вихідний текст достатньо чіткий.

**Коли це особливо корисно**

- Ви в подорожі, читаєте іноземні інструкції або розбираєте скриншоти з чатів і застосунків.
- Вам потрібен переклад прямо поверх контенту, а не окремий ланцюжок copy-paste в інший інструмент.

**Уникайте цього**

- Не оцінюйте якість OCR за розмитим нічним фото або невдало обрізаним сканом.

## Передавайте мережеві файли у спеціалізовані програми

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Швидкий шлях**

1. Відкрийте файл із SMB, SFTP або FTP.
2. Натисніть **ⓘ Info**.
3. Натисніть **Download and Open**.
4. Виберіть потрібну програму в Android chooser.

**Розбір сценарію**

- Цей сценарій корисний, коли FastMediaSorter найзручніший як браузер віддаленого сховища, а інша програма краще підходить для конкретного формату.
- Типові handoff-кейси: офісні документи, складні PDF, відео з важкими кодеками й нішеві медіаформати.
- Завантажена копія залишається в `Downloads`, тому до неї можна повернутися, навіть якщо віддалене джерело пізніше стане недоступним.

**Коли це особливо корисно**

- Вам потрібен один центр для віддалених файлів, але без відмови від найкращих спеціалізованих інструментів.

**Уникайте цього**

- Не очікуйте такого самого flow для хмарних файлів прямо зараз.

## Швидкі обчислення з тексту та OCR

**Доступно в:** Standard, Legacy, VR

**Швидкий шлях**

1. Відкрийте будь-який PDF-документ, EPUB-книгу, текстовий файл або запустіть переклад OCR на зображенні.
2. Виділіть довгим натисканням будь-який блок тексту, що містить числа або математичні вирази.
3. У плаваючому меню дій з текстом натисніть кнопку **Калькулятор**.
4. Калькулятор миттєво обчислить математичну формулу у плаваючому вікні.

**Розбір сценарію**

- Виберіть рядок тексту, що містить числа зі знаками операцій (наприклад, `(45 + 12) * 3`) у PDF або в результатах OCR-перекладу.
- Використовуйте вбудовані наукові функції калькулятора (тригонометрію, корені, степені, логарифми) для складних обчислень.
- Калькулятор зберігає історію обчислень між сеансами й підтримує регістри пам'яті (M+/M-/MR/MC) для швидкого відстеження даних.

**Коли це особливо корисно**

- Ви читаєте технічну документацію, скан скриншота або книгу й вам потрібно швидко розв'язати формули чи підсумувати ціни/числа без переключення в окремий застосунок калькулятора.

**Уникайте цього**

- Не намагайтеся обчислювати суто буквені рядки; парсер розпізнає лише коректні числа, дужки та математичні оператори.

## Хмарні нотатки Markdown та код

**Доступно в:** Standard для хмари, Standard/Lite/Photos/Legacy локально та в мережі

**Швидкий шлях**

1. Перейдіть у будь-яку локальну папку, мережевий ресурс (SMB), FTP/SFTP або хмарний диск (Google Drive).
2. Натисніть кнопку **Нова нотатка (📝)** на панелі інструментів папки.
3. Введіть текст у вбудованому редакторі. Застосунок автоматично підсвітить розмітку Markdown і синтаксис коду.
4. Натисніть **Зберегти** (або дочекайтеся автозбереження) для запису змін прямо на віддалений диск.

**Розбір сценарію**

- Ведіть файл журналу `.md` на Google Диску або домашньому NAS і редагуйте його з будь-якого пристрою напряму.
- Створюйте нові нотатки в ключових папках з автоматичним розв'язанням конфліктів імен (наприклад, `Нотатка_1.txt`, `Нотатка_2.txt`).
- Переглядайте відрендерений Markdown у режимі читання або експортуйте нотатки у зовнішні сервіси, такі як Google Keep.

**Коли це особливо корисно**

- Ви хочете вести прості текстові нотатки, списки задач або зберігати фрагменти коду прямо на центральних мережевих чи хмарних дисках без проміжного скачування файлів.

**Уникайте цього**

- Не очікуйте можливості створення файлів у хмарних сховищах на збірках Lite або Legacy.

## Захоплення екрана краєвими жестами

**Доступно в:** Standard, XR/noLegal

**Швидкий шлях**

1. Перейдіть у **Налаштування → Операції → Жести з лівого краю екрана → Оверлей жестів** і увімкніть його.
2. Під час перегляду будь-якого файлу проведіть пальцем від лівого краю - відкриється меню захоплення.
3. Оберіть дію - панель закриється, дія виконається.

**Що вміє панель**

- Зробити **скриншот** поточного екрана - переглянути, відредагувати, поділитися, надіслати в інший застосунок або запустити OCR-переклад, плюс варіант тихого захоплення.
- **Сфотографувати** камерою, а потім надіслати, відредагувати знімок або запустити OCR-переклад, не виходячи з застосунку.
- Почати запис **екрана**, **відео** або **аудіо/голосу** - детальніше в розділах [Запис відео з екрана](#як-записати-відео-з-екрана) та [Запис голосової нотатки](#як-записати-голосову-нотатку).
- **Відкрити застосунок або панель**, якими ви часто користуєтесь.
- **Обрізати та поділитися** фрагментом поточного зображення.

**Корисно знати**

- Поки панель увімкнена, свайп від лівого краю відкриває меню захоплення, а не гортає сторінку.
- Панель розрахована на захоплення однією рукою під час перегляду - вимкніть її, якщо вам важливий свайп-гортання від лівого краю.
- Android щоразу підтверджує захоплення чи запис - навіть для тихого скриншота. Це системний захист, застосунок його не вимикає.

**Коли це допомагає**

- Потрібен скриншот, швидке фото чи запис, не відриваючись від переглянутого файлу.

## Підключення мережевого диска (SMB)

**Що потрібно:**

- NAS або ПК з Windows зі спільною папкою
- Обидва пристрої в одній мережі Wi-Fi
- Ім'я користувача та пароль

**Доступно в:** Версіях Standard, Photos, Legacy

**Кроки:**

1. Натисніть кнопку **"+"** на головному екрані
2. Виберіть **"Мережева папка (SMB)"**
3. Заповніть дані:
   - **Авто-виявлення (New):**
     1. Натисніть **"Сканувати мережу"**
     2. Зачекайте появи пристроїв у списку
     3. Виберіть пристрій зі списку
     4. IP-адреса заповниться автоматично

   - **Ручне введення:**

     ```
     Сервер/Шлях: \\192.168.1.100\photos
     Ім'я користувача: john
     Пароль: ****
     Ім'я для відображення: Home NAS (необов'язково)
     ```

4. Натисніть **"Тест з'єднання"** для перевірки
5. Натисніть **"Зберегти"**

**Формати адреси сервера:**

- Windows: `\\192.168.1.100\share`
- Linux/Mac: `smb://192.168.1.100/share`
- З портом: `smb://192.168.1.100:445/share`

**Поради:**

- Використовуйте IP-адресу (а не ім'я хоста) для надійності
- Увімкніть SMB v2/v3 на NAS для безпеки
- Порт SMB за замовчуванням: 445

→ Див. [TROUBLESHOOTING_UK.md](TROUBLESHOOTING_UK.md)

## Підключення SFTP/FTP сервера

**Що потрібно:**

- Сервер з увімкненим SSH (SFTP) або FTP
- Відкритий порт 22 (SFTP) або 21 (FTP)

**Кроки:**

   ```
   Хост: 192.168.1.100

   Ім'я користувача: username
   Пароль: ****
   Віддалений шлях: /home/user/photos (необов'язково)
   ```

5. Натисніть **"Підключитися"**

**Додатково:**

- **Аутентифікація за SSH-ключем:** Наразі не підтримується (тільки пароль)
- **Власний порт:** Змініть номер порту, якщо сервер використовує нестандартний

## Перевірка швидкості мережі

**Підтримується для:** SMB, SFTP, FTP, Cloud (Google Drive)

**Автоматична перевірка:**
При додаванні нового мережевого ресурсу програма автоматично запускає тест швидкості у фоновому режимі. Результати (швидкість читання/запису) зберігаються в налаштуваннях ресурсу.

**Ручна перевірка:**

1. Перейдіть в **Керування ресурсами**
2. Редагуйте мережевий ресурс (значок олівця)
3. Прокрутіть вниз
4. Натисніть кнопку **"Швидкість"**
5. Зачекайте ~15 секунд ("Аналіз швидкості..")
6. Результати:
   - **Швидкість читання (Мбіт/с)**
   - **Швидкість запису (Мбіт/с)**
   - **Рекомендовані потоки** (для оптимальної продуктивності)

## Використання сенсорних зон

**Що таке сенсорні зони?**

Екран розділений на 9 невидимих областей для швидких дій:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПІЯ  │ ПЕРЕЙМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  ПОПЕР. │ ПЕРЕМ.  │  НАСТ.  │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ КОМАНДИ │ ВИДАЛИТИ│  ГРАТИ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. **НАЗАД** - Повернутися до списку
2. **КОПІЯ** - Копіювати файл
3. **ПЕРЕЙМ.** - Перейменувати файл
4. **ПОПЕР.** - Попередній файл
5. **ПЕРЕМ.** - Перемістити файл
6. **НАСТ.** - Наступний файл
7. **КОМАНДИ** - Відкрити меню
8. **ВИДАЛИТИ** - Видалити файл
9. **ГРАТИ** - Старт/Стоп слайд-шоу

**Увімкнути накладання (рекомендується для новачків):**

1. Налаштування → Відтворення
2. Увімкніть **"Завжди показувати сітку сенсорних зон"**
3. Тепер ви побачите напівпрозору сітку

**Спробуйте:**

1. Відкрийте будь-яке фото
2. **Натисніть верхній правий кут** → Наступний файл
3. **Натисніть верхній лівий кут** → Попередній файл
4. **Натисніть середній правий кут** → Видалити файл
5. **Натисніть середній лівий кут** → Копіювати файл

**Вимкнути, якщо не потрібно:**
Налаштування → Відтворення → "Завжди показувати сітку сенсорних зон" = ВИМК

Потім використовуйте **кнопки панелі команд**.

## Перегляд 3D відео (VR)

**Версії**: Standard, Legacy

**Що потрібно**: 3D відеофайл у форматі SBS (Side-by-Side) та, за бажанням, VR-окуляри для смартфона (наприклад, Google Cardboard).

**Кроки:**

1. Відкрийте 3D відеофайл у FastMediaSorter.
2. Натисніть кнопку **повноекранного режиму**.
3. Натисніть **Налаштування відтворення** (значок шестерні) в елементах керування плеєром.
4. Прокрутіть до розділу **3D Відео**.
5. Оберіть режим стерео:
   - **Автовизначення** - додаток аналізує співвідношення сторін та вбудовані метадані для автоматичного визначення SBS.
   - **Пліч-о-пліч (SBS)** - вручну ввімкнути стерео Side-by-Side незалежно від результату визначення.
   - **Зверху-знизу (OU)** - вручну ввімкнути стерео Over-Under (верх/низ) незалежно від результату визначення.
   - **Моно (вимкнено)** - вимкнути стерео (звичайний перегляд).
6. Натисніть **Застосувати** - плеєр миттєво перейде в обраний режим.
7. Для VR-перегляду вставте смартфон в VR-окуляри та насолоджуйтесь стереоскопічним 3D.

**Поради:**

- Авто-визначення надійно працює для стандартних SBS файлів (співвідношення сторін ≈ 32:9 і ширше).
- Якщо відео виглядає розтягнутим або подвоєним - перейдіть у режим **Пліч-о-пліч (SBS)** вручну.

- Музика відтворюється випадковим чином з вибраного музичного ресурсу
- Коли трек закінчується, автоматично починається наступний випадковий трек
- Музика продовжує грати під час переходів між зображеннями
- Музика зупиняється при виході зі слайд-шоу або паузі

**Примітки:**

- Музика відтворюється тільки для **зображень та GIF** (не для відео/аудіо)
- Коли слайд-шоу показує відео, музика автоматично призупиняється
- Музика відновлюється при поверненні до зображень
- Працює з локальними та мережевими джерелами музики (SMB, SFTP, FTP)

**Налаштування вибору музики:**

- Додайте кілька музичних файлів у папку музичного ресурсу
- Додаток буде випадковим чином перемішувати всі аудіофайли
- Організуйте музику в підпапки, якщо для музичного ресурсу увімкнено опцію "Включити підпапки"

**Вирішення проблем:**

- Якщо музика не відтворюється: Перевірте, що музичний ресурс містить хоча б один аудіофайл
- Якщо музика переривається в мережі: Використовуйте локальну папку або швидше мережеве з'єднання
- Для музики по SMB: Переконайтеся, що SMB-ресурс використовує протокол `file://` (див. [TROUBLESHOOTING_UK.md](TROUBLESHOOTING_UK.md))

**Можливості:**

- **Пошук:** Пошук тексту всередині книги

   - `- A` / `+ A`: зменшити/збільшити шрифт
   - `Пошук` (🔍): пошук тексту
   - `Зміст` (📋): відкрити список розділів
4. **Жести свайпу:** перемикання розділів

**Примітка:** Працює як з локальними файлами, так і з мережевими потоками (SMB/SFTP/Cloud). Великі книги (>50МБ) у повільних мережах можуть завантажуватися кілька секунд.

## Відкриття мережевих файлів у зовнішніх програмах

**Доступно для:** Файлів SMB, SFTP, FTP

**Сценарій використання:** Ви хочете відкрити документ, фото або відео з мережевого диска в спеціалізованій зовнішній програмі (наприклад, MS Office, Adobe Acrobat, VLC Player).

**Кроки:**

1. **Перейдіть до файлу** на мережевому ресурсі
2. **Натисніть на файл**, щоб відкрити його в плеєрі/переглядачі

4. **Натисніть "Завантажити і відкрити"**
5. **Дочекайтеся завантаження** - діалог прогресу покаже відсотки
6. **Оберіть програму** зі списку Android

**Що відбувається:**

- Файл завантажується в папку `Downloads`
- Прогрес відображається в діалозі (0-100%)
- Після завершення Android покаже вибір програми
- Можна відкрити файл в будь-якій сумісній програмі

**Підтримувані протоколи:**

- ✅ SMB/CIFS мережеві папки
- ✅ SFTP сервери
- ✅ FTP сервери
- ❌ Хмарні сховища (поки не реалізовано)

**Поради:**

- Завантажені файли залишаються в папці `Downloads`
- Ви можете видалити їх вручну пізніше через файловий менеджер
- Працює з усіма типами файлів (зображення, відео, документи)
- Для великих файлів завантаження може зайняти кілька хвилин

**Приклади використання:**

- Редагування мережевого документа в MS Word
- Відтворення мережевого відео в VLC Player
- Перегляд мережевого PDF в Adobe Acrobat
- Відправка мережевого фото через месенджери

## Автоматичний переклад

Автоматичний переклад тексту із зображень, PDF та текстових файлів за допомогою **Гібридної системи OCR** (Google ML Kit + Tesseract).

**Ключові особливості:**

- **Гібридний рушій:** Використовує Google ML Kit для швидкого розпізнавання латиниці та **Tesseract** для якісного розпізнавання кирилиці (Українська, Російська).
- **Офлайн:** Працює повністю на пристрої (після початкового завантаження моделей).
- **Розумне накладання:** Перекладений текст накладається поверх оригіналу зручними для читання абзацами.

**Налаштування:**

1. **Налаштування** → вкладка **Медіа** → **Інше**
2. Увімкніть **"Увімкнути переклад"**
3. Виберіть **Source Language** (Вихідна мова):
   - **"Auto" (Рекомендовано):** Автоматично вибирає найкращий рушій (Tesseract для кирилиці, ML Kit для інших).
   - **Конкретна мова:** Примусово використовує модель (наприклад, "Ukrainian" увімкне Tesseract).
4. Виберіть **Target Language** (Цільова мова, наприклад, English).

**Як використовувати:**

1. Відкрийте **Зображення**, **PDF** або **Текстовий** файл.
2. Натисніть на екран, щоб показати **Панель команд** (Command Panel).
3. Натисніть кнопку **"Перекласти"** (іконка A→文).
4. **Перший запуск:**
   - Для ML Kit: Підтвердіть завантаження мовної моделі (~30МБ).
   - Для Tesseract (Кирилиця): Підтвердіть завантаження даних OCR (~15МБ).
5. Перекладений текст з'явиться поверх вмісту.

**Примітка:** Ініціалізація Tesseract (для кирилиці) може зайняти на 1-2 секунди більше часу, ніж ML Kit.

## Розумні віджети домашнього екрана

**Доступно в:** Standard, Legacy, VR

**Швидкий шлях**

1. Перейдіть на домашній екран Android, затисніть його та виберіть пункт **Віджети**.
2. Перетягніть потрібний віджет **FastMediaSorter** (наприклад, іконку 1×1 «Швидкий диктофон» або «Camera OCR») на екран.

4. Натискайте віджет для миттєвого виконання задачі прямо з робочого столу.

**Розбір сценарію**

- Використовуйте віджети 1×1 як швидкі ярлики для миттєвого виконання фонових дій (наприклад, одне натискання починає запис голосу, повторне - зберігає її в ресурс на NAS).

**Коли це особливо корисно**

- Вам потрібні швидкі ярлики на робочому столі для щоденної зйомки (чеки, квитанції, голосові нотатки) без відкриття основного інтерфейсу застосунку.

**Уникайте цього**

- Не намагайтеся додавати віджети, якщо лаунчер вашого Android-пристрою блокує створення кастомних віджетів сторонніми застосунками.

## Використання FMS на Android TV-приставці

FastMediaSorter працює на будь-якій Android TV-приставці або сет-топ-боксі (Xiaomi Mi Box, Nvidia Shield, Amazon Fire TV, дженерик Android-бокси). Тачскрін не потрібен - додаток повністю керується з пульта ДК або Bluetooth-клавіатури.

**Що вам потрібно:**

- Android TV-приставка на Android 8.0+ (версії Standard/Lite/Photos) або Android 6.0+ (версія Legacy)
- Пульт ДК з D-pad або Bluetooth-клавіатура
- Опціонально: домашній NAS (SMB), USB-накопичувач або SD-карта з медіа

**Навігація з пульта ДК:**

| Кнопка | Дія |
|--------|-----|
| D-pad Вгору/Вниз/Вліво/Вправо | Переміщення фокусу між елементами |
| OK / Enter | Відкрити елемент або підтвердити |
| Back | Повернутися на попередній екран |
| Backspace | Перейти на папку вище в браузері файлів |
| Червона | Видалити вибраний файл(и) |
| Зелена | Копіювати вибраний файл(и) |
| Жовта | Перемістити вибраний файл(и) |
| Синя | Перейменувати вибраний файл |
| Channel Up / Channel Down | Попередній / наступний файл у плеєрі |

**Кроки:**

1. Встановіть додаток із Google Play або sideload APK. Рекомендується версія Standard.
2. На головному екрані натисніть **OK** на кнопці (+) для додавання ресурсу.
3. Виберіть **Локальна папка** для USB/SD або **Мережева папка** для підключення до NAS через SMB.
4. Після додавання ресурсу перейдіть у нього за допомогою D-pad + OK для перегляду файлів.
5. Відкрийте будь-яке відео, зображення або аудіофайл - плеєр повністю керується з пульта.
6. Для запуску слайд-шоу відкрийте папку із зображеннями та перейдіть до кнопки **Слайд-шоу** на панелі команд.
7. Для додавання фонової музики до слайд-шоу перейдіть у **Налаштування → Медіа → Зображення**, увімкніть **Музика під час слайдшоу** та виберіть музичний ресурс.

**Поради:**

- Утримуйте D-pad Вгору/Вниз для прискореного прокручування довгих списків файлів.
- Натисніть **F1** на Bluetooth-клавіатурі для відкриття підказок по гарячих клавішах на будь-якому екрані.
- Кольорові кнопки пульта можна перепризначити у **Налаштування → Операції → Керування та клавіші**.

## Слухайте інтернет-радіо або дивіться IPTV через Трансляції

**Доступно в:** Standard, Legacy, XR/noLegal; Lite (лише прогресивне аудіо)

**Швидкий шлях**

1. Налаштування > Медіа > Трансляції > увімкніть **Увімкнути трансляції**.
2. Відкрийте **Трансляції** через головне меню або кнопку-ярлик у налаштуваннях.
3. Натисніть **«+»** та введіть URL радіостанції або відеопотоку (http/https, .m3u8, rtsp://).
4. Або імпортуйте .m3u-плейлист за URL-посиланням на плейлист.
5. Або завантажте кураторський каталог FastMediaSorter через екран Розширень / онбординг.

**Розбір сценарію**

- Аудіо-потоки (радіо) грають безпосередньо зі списку; внизу з'являється прилипаючий міні-банер із назвою станції та поточним треком (ICY-метадані).
- Відео та RTSP відкриваються в повноекранному плеєрі. Кнопка «Назад» повертає до списку зі збереженою позицією прокрутки.
- Закріпіть улюблені джерела вгорі за допомогою іконки шпильки - незалежно від глобальних Вибраних.
- Перемкніть перегляд на **Сітку** на панелі інструментів Трансляцій, щоб побачити канали плитками з останнім захопленим кадром - зручно для швидкого перегляду відеопотоків. Вибір (список чи сітка) запам'ятовується під час наступного відкриття Трансляцій.
- Якщо потік підтримує трансляцію і телефон у тій самій Wi-Fi мережі, натисніть **Cast** у плеєрі, щоб надіслати його на Chromecast. RTSP-потоки транслювати не можна.
- Фільтруйте список за категорією та/або мовою (з підтримкою прапорців). Кнопка фільтра отримує індикатор-точку, коли фільтр активний.
- Якщо потік недоступний - з'являється діалог «Повторити / Видалити / Скасувати».

**Фонове відтворення**

- При вимкненому фоновому відтворенні аудіо зупиняється при виході зі екрана Трансляцій (з тим самим вибором «Зупинити / Продовжити», що і в звичайному плеєрі).
- Налаштування фонового відтворення: Налаштування > Відтворення > **Фонове відтворення аудіо**.

**Особливо корисно для автомагнітол**

- FastMediaSorter замінює окремий застосунок для інтернет-радіо на Android-магнітолі. Кнопки керма (Play/Pause, Next) керують потоком без торкання екрана.

**Уникайте цього**

- Не очікуйте HLS/DASH/RTSP у версії Lite - лише прогресивне аудіо.
- Трансляції повністю відсутні у версії Photos.
- DRM, YouTube, Twitch та закриті платформи не підтримуються.

## Як записати відео з екрана

**Доступно в:** Standard, XR/noLegal

**Кроки:**

1. Запустіть запис із меню на головному екрані (**«Відеозапис екрана»**), з панелі Quick Launch або дією **«Почати запис екрана»** в меню жестів.
2. Підтвердьте системний запит Android - поділитися всім екраном чи лише цим застосунком. Він з'являється щоразу під час запису, і його не можна пропустити.
3. У кутку екрана з'явиться невелика плашка **«Триває запис екрана»** з паузою/продовженням і зупинкою. Зупинити можна й із сповіщення.
4. Натисніть **«Стоп»**, коли закінчите.

**Що відбувається:**

- Запис захоплює все, що показується на екрані, включно з іншими застосунками, разом зі звуком.
- Готове відео зберігається в папку Movies на пристрої.

**Примітка:** Системний запит Android - це захисний механізм для будь-якого запису екрана, застосунок не може його вимкнути.

## Як записати голосову нотатку

**Доступно в:** Standard, XR/noLegal

**Кроки:**

1. Почніть запис через пункт **«Запис із диктофона»** в меню, віджет **«Швидкий диктофон»** на головному екрані або дію **«Почати запис аудіо»** в меню жестів.
2. Говоріть - індикатор **«Запис..»** (або плаваюча плашка поверх поточного застосунку) показує, що запис триває.
3. Натисніть **«Зупинити і зберегти»** (або ще раз торкніться віджета/жесту), щоб закінчити.

**Що відбувається:**

- Запис зберігається в папку для диктофона, обрану в Налаштуваннях, або в папку Recordings на пристрої, якщо нічого не обрано.
- Запис через віджет або жест працює навіть під час роботи в іншому застосунку - плаваючий елемент керування залишається зверху, щоб зупинити запис, не перемикаючись назад.

**Де задати папку збереження:** Налаштування → Операції → Диктофон.

## Як користуватися вбудованою камерою

**Доступно в:** Standard, Lite, Photos (лише фото), Legacy, XR/noLegal

**Кроки:**

1. В Огляді відкрийте панель інструментів або меню і натисніть **«Зйомка камерою»** (фото) або **«Записати відео»**.
2. За потреби перемкніться між **«Фото»** і **«Відео»** прямо на екрані камери.
3. Налаштуйте зум пресетом (0.5x/1x/2x..) або повзунком під ним - вони синхронізовані.
4. При слабкому освітленні увімкніть **«Нічний режим»** для світлішого фото.
5. Натисніть кнопку затвора (або запису), щоб зняти. Результат збережеться прямо в ресурс - локальний або мережевий, - який ви переглядали.

**Поради:**

- Дія **«Почати запис відео»** в меню жестів відкриває камеру одразу в режимі відео і починає запис, щойно готовий попередній перегляд - швидко, але цей спосіб зберігає запис у папку Movies на пристрої, а не в переглянутий ресурс.
- Увімкніть **«Геотегування фото»** біля налаштувань камери, щоб вбудовувати GPS-координати в кожен знятий JPEG - поки ви не увімкнете це самі, нічого не зберігається. В **Інформації про файл** з'являться дата зйомки і точка з EXIF GPS - як посилання, що відкривається в картах або браузері.

**Де шукати налаштування камери:** Налаштування → Операції → Фотографування.

## Як знайти і видалити дублікати файлів

**Кроки:**

1. Відкрийте папку в Огляді, потім відкрийте **меню** (⋮) на панелі інструментів.
2. Натисніть **«Знайти дублікати»**, щоб перевірити збіги самостійно, або **«Знайти та видалити дублікати»**, щоб видалити їх одразу.
3. Для **«Знайти дублікати»** застосунок заздалегідь позначає всі копії, крім найстарішої в кожній групі - підправте вибір, потім натисніть **«Видалити вибране»** і підтвердьте.
4. **«Знайти та видалити дублікати»** видаляє ті самі позначені копії одразу після сканування, без підтвердження - спершу скористайтеся «Знайти дублікати», якщо хочете перевірити список перед видаленням.

**Очищення за розміром:**

1. У тому самому меню натисніть **«Видалення за розміром..»**.
2. Виберіть **«Менше ніж»** або **«Більше ніж»**, вкажіть розмір і натисніть **«Аналізувати»**.
3. Перевірте кількість файлів і обсяг, який звільниться, потім натисніть **«Видалити файли»** для підтвердження.

**Примітки:**

- Сканування порівнює файли за вмістом у три проходи - розмір, швидкий хеш, потім повна перевірка SHA-256, - тож перейменовані дублікати теж знаходяться.
- Видалення за розміром показує, скільки місця звільниться, ще до видалення; для мережевих і хмарних джерел кошик не використовується, тож таке видалення одразу остаточне.

## Як переглянути статистику використання

**Кроки:**

1. Перейдіть у **Налаштування → Загальні → Збір статистики** і увімкніть перемикач.
2. Натисніть **«Статистика»** (з'являється прямо під перемикачем), щоб відкрити панель.

**Що ви побачите:**

- Картки-зведення: відсортовано файлів, звільнено місця, час у програвачі.
- Розбивку за типами медіа (фото, відео, аудіо, документи..).
- Згортні розділи з деталями: операції, зйомка, перегляд, редагування, джерела та загальне використання.

**Поділитися звітом:**

- **«Надіслати автору»** відкриває поштовий застосунок зі зведенням у вкладенні, адресованим розробнику.
- **«Експорт»** ділиться тим самим зведенням через звичайне меню «Поділитися» Android, щоб зберегти його чи надіслати куди завгодно.

**Примітка:** Все залишається на вашому пристрої, поки ви самі не надішлете чи не експортуєте дані - подробиці про приватність дивіться в FAQ.
