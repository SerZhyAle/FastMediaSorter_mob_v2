## Примітка: Доступність функцій за версіями

Деякі функції доступні лише в певних версіях програми. Дивіться таблицю нижче:

| Функція | Standard | Lite | Photos | Legacy |
|---------|----------|------|--------|--------|
| Мережеві папки (SMB, SFTP, FTP) | ✓ | ✓ | ✓ | ✗ |
| Хмарні сховища (Google Drive, OneDrive, Dropbox) | ✓ | ✗ | ✗ | ✗ |
| Відтворення аудіо та текст пісень | ✓ | ✗ | ✗ | ✓ |
| Перегляд документів (PDF, Текст) | ✓ | ✓ | ✓ | ✓ |
| Читалка EPUB | ✓ | ✓ | ✓ | ✓ |
| Переклад та OCR | ✓ | ✓ | ✓ | ✓ |
| Редагування зображень | ✓ | ✓ | ✓ | ✓ |

Якщо функція позначена як "✗", ви можете завантажити версію **Standard** для отримання всіх можливостей.

## Підключення мережевого диска (SMB)

**Що потрібно:**

- NAS або ПК з Windows зі спільною папкою
- Обидва пристрої в одній мережі Wi-Fi
- Ім'я користувача та пароль

**Доступно в:** Версіях Standard, Lite, Photos, Legacy

**Кроки:**

1. Натисніть кнопку **"+"** на головному екрані
2. Виберіть **"Мережева папка (SMB)"**
3. Заповніть дані:
   - **Авто-виявлення (New):**
     1. Натисніть **"Сканувати мережу"**
     2. Зачекайте появи пристроїв у списку
     3. Виберіть пристрій зі списку
     4. IP-адреса заповниться автоматично

   - **Ручне введення:**

     ```
     Сервер/Шлях: \\192.168.1.100\photos
     Ім'я користувача: john
     Пароль: ****
     Ім'я для відображення: Home NAS (необов'язково)
     ```

4. Натисніть **"Тест з'єднання"** для перевірки
5. Натисніть **"Зберегти"**

**Формати адреси сервера:**

- Windows: `\\192.168.1.100\share`
- Linux/Mac: `smb://192.168.1.100/share`
- З портом: `smb://192.168.1.100:445/share`

**Поради:**

- Використовуйте IP-адресу (а не ім'я хоста) для надійності
- Увімкніть SMB v2/v3 на NAS для безпеки
- Порт SMB за замовчуванням: 445

**Вирішення проблем:**
→ Див. [TROUBLESHOOTING.md#smb-connection](TROUBLESHOOTING.md)

## Підключення SFTP/FTP сервера

**Що потрібно:**

- Сервер з увімкненим SSH (SFTP) або FTP
- Відкритий порт 22 (SFTP) або 21 (FTP)
- Ім'я користувача та пароль (або ключ для SFTP)

**Кроки:**

1. Натисніть кнопку **"+"** на головному екрані
2. Виберіть **"SFTP / FTP"**
3. Виберіть протокол: **SFTP** або **FTP**
4. Заповніть дані:

   ```
   Хост: 192.168.1.100
   Порт: 22 (SFTP) / 21 (FTP)
   Ім'я користувача: username
   Пароль: ****
   Віддалений шлях: /home/user/photos (необов'язково)
   ```

5. Натисніть **"Підключитися"**

**Додатково:**

- **Аутентифікація за SSH-ключем:** Наразі не підтримується (тільки пароль)
- **Власний порт:** Змініть номер порту, якщо сервер використовує нестандартний

**Вирішення проблем:**
→ Див. [TROUBLESHOOTING.md#sftp-timeout](TROUBLESHOOTING.md)

## Підключення хмарного сховища

**Підтримувані провайдери:**

- Google Drive
- OneDrive
- Dropbox

**Кроки:**

1. Натисніть кнопку **"+"** на головному екрані
2. Виберіть **"Cloud Storage"** (Хмарне сховище)
3. Виберіть провайдера: **Google Drive**, **OneDrive** або **Dropbox**
4. Натисніть кнопку **"Увійти..."**
5. Дотримуйтесь інструкцій аутентифікації у браузері/додатку
6. Надайте необхідні права доступу
7. **Виберіть папки** для синхронізації
8. Натисніть **"Готово"**

**Примітки:**

- Файли **стрімляться**, а не завантажуються
- Потрібне підключення до Інтернету
- Зміни синхронізуються автоматично
- Можна відключити в будь-який час: Редагувати папку → Видалити

**Конфіденційність:**

- Пароль не зберігається (використовуються токени OAuth)
- Токени можна відкликати в налаштуваннях безпеки хмарного провайдера

## Перевірка швидкості мережі

**Підтримується для:** SMB, SFTP, FTP, Cloud (Google Drive)

**Автоматична перевірка:**
При додаванні нового мережевого ресурсу програма автоматично запускає тест швидкості у фоновому режимі. Результати (швидкість читання/запису) зберігаються в налаштуваннях ресурсу.

**Ручна перевірка:**

1. Перейдіть в **Керування ресурсами**
2. Редагуйте мережевий ресурс (значок олівця)
3. Прокрутіть вниз
4. Натисніть кнопку **"Швидкість"**
5. Зачекайте ~15 секунд ("Аналіз швидкості...")
6. Результати:
   - **Швидкість читання (Мбіт/с)**
   - **Швидкість запису (Мбіт/с)**
   - **Рекомендовані потоки** (для оптимальної продуктивності)

## Налаштування папок Quick Sort

**Спосіб 1: Через Налаштування**

1. **Налаштування** → вкладка **Quick Sort**
2. Натисніть **"Додати до Quick Sort"**
3. Виберіть існуючу папку зі списку
4. Папці присвоюється номер (0-9) та колір
5. Повторіть для до 30 папок

**Спосіб 2: Через налаштування папки**

1. Головний екран → **Довге натискання на папці**
2. Натисніть **"Редагувати"** (іконка олівця)
3. Увімкніть **"Позначити для Quick Sort"**
4. Натисніть **"Зберегти"**

**Використання Quick Sort:**

Під час перегляду файлів:

- Натисніть **цифрову кнопку** (0-9) на панелі команд
- АБО натисніть **лівий нижній кут** (зона COPY)
- АБО натисніть **нижній центральний кут** (зона MOVE)

Файл миттєво копіюється/переміщується в цю папку!

## Використання сенсорних зон

**Що таке сенсорні зони?**

Екран розділений на 9 невидимих областей для швидких дій:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПІЯ  │ ПЕРЕЙМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  ПОПЕР. │ ПЕРЕМ.  │  НАСТ.  │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ КОМАНДИ │ ВИДАЛИТИ│  ГРАТИ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. **НАЗАД** - Повернутися до списку
2. **КОПІЯ** - Копіювати файл
3. **ПЕРЕЙМ.** - Перейменувати файл
4. **ПОПЕР.** - Попередній файл
5. **ПЕРЕМ.** - Перемістити файл
6. **НАСТ.** - Наступний файл
7. **КОМАНДИ** - Відкрити меню
8. **ВИДАЛИТИ** - Видалити файл
9. **ГРАТИ** - Старт/Стоп слайд-шоу

**Увімкнути накладання (рекомендується для новачків):**

1. Налаштування → Відтворення
2. Увімкніть **"Завжди показувати зони натискання"**
3. Тепер ви побачите напівпрозору сітку

**Спробуйте:**

1. Відкрийте будь-яке фото
2. **Натисніть верхній правий кут** → Наступний файл
3. **Натисніть верхній лівий кут** → Попередній файл
4. **Натисніть середній правий кут** → Видалити файл
5. **Натисніть середній лівий кут** → Копіювати файл

**Вимкнути, якщо не потрібно:**
Налаштування → Відтворення → "Завжди показувати зони натискання" = ВИМК

Потім використовуйте **кнопки панелі команд**.

## Редагування фото

**Підтримувані операції:**

- Поворот (90°, 180°, 270°)
- Віддзеркалення (горизонтально, вертикально)
- Фільтри (Ч/Б, Сепія, Негатив)
- Налаштування (Яскравість, Контраст, Насиченість)

**Кроки:**

1. **Відкрийте фото** у повноекранному режимі
2. Натисніть кнопку **"Редагувати"** (або зону зліва посередині)
3. **Виберіть операцію:**
   - Поворот: Іконка повороту
   - Віддзеркалення: Іконка віддзеркалення
   - Фільтр: Виберіть зі списку
   - Налаштування: Використовуйте повзунки
4. Натисніть **"Зберегти"**

**Примітки:**

- Оригінальний файл **перезаписується** (скасування неможливе!)
- Працює для **локальних та мережевих файлів**
- Підтримка: JPG, PNG, WEBP

## Створення слайд-шоу

**Кроки:**

1. **Відкрийте будь-яку папку** з фото
2. Натисніть **перше фото** для перегляду
3. Натисніть кнопку **"Play"** (або зону справа внизу)
4. Слайд-шоу почнеться автоматично

**Налаштування швидкості:**

1. **Редагувати налаштування папки:**
   - Головний екран → Довге натискання на папці → Редагувати
2. Змініть **"Інтервал слайд-шоу":**
   - Швидко: 2 секунди
   - Нормально: 5 секунд
   - Повільно: 10 секунд
3. Натисніть **"Зберегти"**

**Керування під час слайд-шоу:**

- **Натискання на екран** → Пауза/Продовжити
- **Свайп вліво/вправо** → Пропуск файлів
- **Натисніть "Стоп"** → Вихід

## Створення слайд-шоу з фоновою музикою

**Вимоги:**

- Хоча б одна папка/ресурс з аудіофайлами (MP3, FLAC тощо)
- **Доступно в:** Тільки версія Standard

**Налаштування:**

1. **Налаштування** → вкладка **Аудіо**
2. Увімкніть **"Увімкнути фонову музику для слайд-шоу"**
3. Натисніть кнопку **"Вибрати джерело музики"**
4. Виберіть ресурс, що містить ваші музичні файли
5. Натисніть **"Зберегти"** або закрийте налаштування

**Відтворення слайд-шоу з музикою:**

1. **Відкрийте будь-яку папку** з фото/зображеннями
2. Натисніть **перше фото** для перегляду
3. Натисніть кнопку **"Play"** (або зону справа внизу)
4. Слайд-шоу почнеться з відтворенням фонової музики

**Як це працює:**

- Музика відтворюється випадковим чином з вибраного музичного ресурсу
- Коли трек закінчується, автоматично починається наступний випадковий трек
- Музика продовжує грати під час переходів між зображеннями
- Музика зупиняється при виході зі слайд-шоу або паузі

**Примітки:**

- Музика відтворюється тільки для **зображень та GIF** (не для відео/аудіо)
- Коли слайд-шоу показує відео, музика автоматично призупиняється
- Музика відновлюється при поверненні до зображень
- Працює з локальними та мережевими джерелами музики (SMB, SFTP, FTP)

**Налаштування вибору музики:**

- Додайте кілька музичних файлів у папку музичного ресурсу
- Додаток буде випадковим чином перемішувати всі аудіофайли
- Організуйте музику в підпапки, якщо для музичного ресурсу увімкнено опцію "Включити підпапки"

**Вирішення проблем:**

- Якщо музика не відтворюється: Перевірте, що музичний ресурс містить хоча б один аудіофайл
- Якщо музика переривається в мережі: Використовуйте локальну папку або швидше мережеве з'єднання
- Для музики по SMB: Переконайтеся, що SMB-ресурс використовує протокол `file://` (див. TROUBLESHOOTING.md)

## Захист папки PIN-кодом

**Кроки:**

1. Головний екран → **Довге натискання на папці**
2. Натисніть **"Редагувати"** (іконка олівця)
3. Прокрутіть до поля **"PIN-код"**
4. Введіть **4-6 значний PIN** (наприклад, 1234)
5. Натисніть **"Зберегти"**

**Тепер:**

- Відкриття папки вимагає PIN
- Запобігає несанкціонованому доступу
- Застосовується до перегляду та редагування

**Видалити PIN:**

- Редагувати папку → Очистити поле PIN → Зберегти

**Забули PIN?**

- Можливості відновлення немає (для безпеки)
- Доведеться видалити папку з програми та додати заново

## Очищення кошика

Видалені файли потрапляють у папки `.trash/` і залишаються там до ручного очищення.

**Спосіб 1: Очистити весь кошик**

1. **Налаштування** → вкладка **Quick Sort**
2. Натисніть **"Очистити Кошик"**
3. Підтвердіть видалення
4. Всі папки `.trash/` у всіх ресурсах будуть очищені

**Спосіб 2: Для однієї папки**

1. Використовуйте файловий менеджер
2. Перейдіть у папку (наприклад, `/storage/emulated/0/DCIM/Camera`)
3. Знайдіть підпапку `.trash/`
4. Видаліть вручну

**Увага:** Це **безповоротне видалення**! Файли не можна буде відновити.

## Резервне копіювання налаштувань

**Експорт налаштувань:**

1. **Налаштування** → вкладка **Загальні**
2. Натисніть **"Бекап та Відновлення"**
3. Натисніть **"Експорт налаштувань"**
4. Виберіть місце (наприклад, Завантаження)
5. Файл збережеться як `fastmediasorter_backup.xml`

**Відновлення налаштувань:**

1. **Налаштування** → вкладка **Загальні**
2. Натисніть **"Бекап та Відновлення"**
3. Натисніть **"Імпорт налаштувань"**
4. Виберіть файл бекапу
5. Натисніть **"Відновити"**
6. Програма перезапуститься з відновленими налаштуваннями

**Що включено:**
✅ Папки Quick Sort
✅ Налаштування відображення
✅ Інтервали слайд-шоу
✅ Мережеві облікові дані (зашифровано)
✅ Вибране
✅ Налаштування безпечного режиму

**НЕ включено:**
❌ Кеш мініатюр
❌ Вміст кошика

## Перегляд текстових та PDF файлів

**1. Увімкнути підтримку:**

1. **Налаштування** → **Документи**
2. Увімкніть **"Підтримка текстових файлів"** та **"Підтримка PDF файлів"**
3. **Перескануйте** папки, щоб знайти нові файли.

**2. Фільтр за типом медіа:**

1. Натисніть іконку **Фільтра** (лійка) на головному екрані.
2. Виберіть типи файлів:
   - Зображення
   - Відео
   - Аудіо
   - GIF
   - **Текст** (Нове)
   - **PDF** (Нове)
3. Натисніть **"Застосувати"**.

**3. Текстовий переглядач:**

- Відкриває **.txt, .md, .log, .json, .xml**.
- **Прокрутка** для читання.
- **Копіювання:** Довге натискання для виділення тексту.

**4. PDF Переглядач (Нові функції):**

- Відкриває **.pdf** файли.
- **Панель керування (Знизу):**
  - **Назад/Вперед:** Великі кнопки по краях.
  - **Зум +:** Збільшити.
  - **Зум -:** Зменшити.
- **Жести:**
  - **Свайп ВГОРУ:** Наступна сторінка.
  - **Свайп ВНИЗ:** Попередня сторінка.
  - **Щипок:** Масштабування.
  - **Подвійний тап:** Скидання масштабу.
- **Переміщення:** Перетягуйте збільшену сторінку пальцем.

## Як читати електронні книги (EPUB)

**Вимоги:**

- **Налаштування** → **Документи** → **Підтримка EPUB** має бути увімкнено (увімкнено за замовчуванням)
- Підтримуваний формат: `.epub` (без DRM)

**Можливості:**

- **Навігація по розділах:** Свайп вліво/вправо або кнопки на панелі команд
- **Зміст:** Натисніть іконку списку (📋) для переходу до розділу
- **Розмір шрифту:** налаштовується (14px - 32px)
- **Пошук:** Пошук тексту всередині книги
- **Теми:** Автоматично адаптується під Світлу/Темну тему

**Керування:**

1. **Відкрийте файл EPUB** зі списку
2. **Торкніться екрану** для відображення панелі команд
3. **Нижня панель керування:**
   - `Попер.` / `Наст.`: навігація по розділах
   - `- A` / `+ A`: зменшити/збільшити шрифт
   - `Пошук` (🔍): пошук тексту
   - `Зміст` (📋): відкрити список розділів
4. **Жести свайпу:** перемикання розділів

**Примітка:** Працює як з локальними файлами, так і з мережевими потоками (SMB/SFTP/Cloud). Великі книги (>50МБ) у повільних мережах можуть завантажуватися кілька секунд.

## Відкриття мережевих файлів у зовнішніх програмах

**Доступно для:** Файлів SMB, SFTP, FTP

**Сценарій використання:** Ви хочете відкрити документ, фото або відео з мережевого диска в спеціалізованій зовнішній програмі (наприклад, MS Office, Adobe Acrobat, VLC Player).

**Кроки:**

1. **Перейдіть до файлу** на мережевому ресурсі
2. **Натисніть на файл**, щоб відкрити його в плеєрі/переглядачі
3. **Натисніть кнопку ⓘ (Інфо)** у верхній панелі
4. **Натисніть "Завантажити і відкрити"**
5. **Дочекайтеся завантаження** - діалог прогресу покаже відсотки
6. **Оберіть програму** зі списку Android

**Що відбувається:**

- Файл завантажується в папку `Downloads`
- Прогрес відображається в діалозі (0-100%)
- Після завершення Android покаже вибір програми
- Можна відкрити файл в будь-якій сумісній програмі

**Підтримувані протоколи:**

- ✅ SMB/CIFS мережеві папки
- ✅ SFTP сервери
- ✅ FTP сервери
- ❌ Хмарні сховища (поки не реалізовано)

**Поради:**

- Завантажені файли залишаються в папці `Downloads`
- Ви можете видалити їх вручну пізніше через файловий менеджер
- Працює з усіма типами файлів (зображення, відео, документи)
- Для великих файлів завантаження може зайняти кілька хвилин

**Приклади використання:**

- Редагування мережевого документа в MS Word
- Відтворення мережевого відео в VLC Player
- Перегляд мережевого PDF в Adobe Acrobat
- Відправка мережевого фото через месенджери

## Як переглянути текст пісні (Лірика)

**Вимоги:**

- Аудіофайл (MP3, FLAC та ін.) з метаданими Виконавця та Назви.
- Потрібне **Інтернет-з'єднання** (використовує api.lyrics.ovh).

**Кроки:**

1. **Запустіть аудіофайл** у повноекранному плеєрі.
2. Натисніть кнопку **"Лірика"** на верхній панелі команд (або в меню команд).
   - *Примітка: Кнопка видима лише для аудіофайлів.*
3. Дочекайтеся завершення пошуку.
4. Текст пісні відобразиться у діалоговому вікні з прокруткою.

**Алгоритм пошуку:**

1. Додаток шукає за тегами **Виконавець + Назва**.
2. Якщо теги відсутні, намагається отримати дані з **Імені файлу**.

## Автоматичний переклад

Автоматичний переклад тексту із зображень, PDF та текстових файлів за допомогою **Гібридної системи OCR** (Google ML Kit + Tesseract).

**Ключові особливості:**

- **Гібридний рушій:** Використовує Google ML Kit для швидкого розпізнавання латиниці та **Tesseract** для якісного розпізнавання кирилиці (Українська, Російська).
- **Офлайн:** Працює повністю на пристрої (після початкового завантаження моделей).
- **Розумне накладання:** Перекладений текст накладається поверх оригіналу зручними для читання абзацами.

**Налаштування:**

1. **Налаштування** → **Документи**
2. Увімкніть **"Enable Translation"** (Увімкнути переклад)
3. Виберіть **Source Language** (Вихідна мова):
   - **"Auto" (Рекомендовано):** Автоматично вибирає найкращий рушій (Tesseract для кирилиці, ML Kit для інших).
   - **Конкретна мова:** Примусово використовує модель (наприклад, "Ukrainian" увімкне Tesseract).
4. Виберіть **Target Language** (Цільова мова, наприклад, English).

**Як використовувати:**

1. Відкрийте **Зображення**, **PDF** або **Текстовий** файл.
2. Натисніть на екран, щоб показати **Панель команд** (Command Panel).
3. Натисніть кнопку **"Перекласти"** (іконка A→文).
4. **Перший запуск:**
   - Для ML Kit: Підтвердіть завантаження мовної моделі (~30МБ).
   - Для Tesseract (Кирилиця): Підтвердіть завантаження даних OCR (~15МБ).
5. Перекладений текст з'явиться поверх вмісту.

**Примітка:** Ініціалізація Tesseract (для кирилиці) може зайняти на 1-2 секунди більше часу, ніж ML Kit.
