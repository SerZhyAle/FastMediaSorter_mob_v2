## Примітка: Доступність функцій за версіями

Деякі функції доступні лише в певних версіях програми. Таблиця нижче виведена з [FLAVOR_MATRIX.md](FLAVOR_MATRIX.md), який генерується з самої збірки; XR / noLegal залишені однією колонкою, бо залежать від апаратури шолома та sideload-правил збірки.

| Функція | Standard | Lite | Photos | Legacy | XR / noLegal |
|---------|----------|------|--------|--------|--------------|
| Мережеві папки (SMB, SFTP, FTP) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Хмарні сховища (Google Drive, OneDrive, Dropbox) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Відтворення аудіо та текст пісень | ✓ | ✓ | ✗ | ✓ | ✓ |
| Фонове відтворення аудіо | ✓ | ✗ | ✗ | ✓ | ✓ |
| Трансляції (інтернет-радіо, HLS/DASH, RTSP) | ✓ | ✗ | ✗ | ✓ | ✓ |
| Перегляд документів (PDF, Текст) | ✓ | ✗ | ✗ | ✓ | ✓ |
| Читалка EPUB | ✓ | ✗ | ✗ | ✓ | ✓ |
| Переклад та OCR | ✓ | ✗ | ✗ | ✓ | ✓ |
| Редагування зображень | ✓ | ✓ | ✓ | ✓ | ✓ |
| Режим домашнього екрана (лаунчер) | ✓ | ✗ | ✗ | ✗ | ✓ |

Режим домашнього екрана - єдиний рядок, де об'єднана остання колонка розходиться: він є в sideload-збірці noLegal, але відсутній у збірці VR/XR, де шолом сам надає власне домашнє середовище.

Для аудіо два рядки, бо це два різні рішення збірки: **Lite відтворює локальні аудіофайли**, включно з текстом пісень, але зупиняється, коли програма йде з активного вікна - служби фонового відтворення там немає. Екрана «Трансляції» у Lite немає взагалі, тому радіо та HLS/DASH/RTSP там не обмежені, а відсутні.

Якщо функція позначена як "✗", обирайте **Standard** або **XR / noLegal** відповідно до апаратури та каналу розповсюдження.

## Домашній медіацентр, TV і сценарії для вітальні

## Перетворіть NAS на медіаполицю для вітальні

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Швидкий шлях**

1. Додайте NAS як SMB-ресурс.
2. Запустіть **Scan Network**, якщо не хочете вводити IP вручну.
3. Відкрийте ресурс із TV box, планшета або телефона.
4. Почніть переглядати відео, фото чи документи просто з NAS.

**Розбір сценарію**

- Тримайте один SMB-ресурс для всієї сімейної медіатеки й розділяйте дочірні папки за призначенням: фільми, сімейні фото, скани, інструкції.
- Один раз запустіть **Test Connection** під час налаштування, щоб ресурс був стабільним ще до використання з дивана.
- Якщо NAS використовується з TV box, одразу додайте Bluetooth-клавіатуру або пульт для швидкої навігації.
- Якщо перегляд здається повільним, спершу відкрийте налаштування ресурсу й запустіть вбудовану перевірку швидкості.

**Коли це особливо корисно**

- Вам потрібне одне центральне джерело медіа замість копіювання тих самих файлів на кілька пристроїв.
- Ви хочете, щоб одна бібліотека працювала і для слайд-шоу, і для читання документів, і для відтворення.

**Уникайте цього**

- Не починайте з відладки hostname. Спершу використайте IP-адресу, а оптимізуйте пізніше.
- Не очікуйте SMB у збірці Lite - у ній узагалі немає мережевих джерел.

## Запустіть слайд-шоу з фоновою музикою для кімнати

**Доступно в:** Standard, Lite, Legacy, XR / noLegal (у Photos немає підтримки аудіо)

**Швидкий шлях**

1. Додайте одне джерело зображень і одне джерело музики.
2. У **Налаштування → Медіа → Зображення** увімкніть **Музика під час слайдшоу**.
3. Виберіть музичний ресурс.
4. Відкрийте папку з фото та натисніть **Play**.

**Розбір сценарію**

- Для найплавніших переходів використовуйте локальну папку із зображеннями або швидкий NAS.
- Тримайте окремий музичний ресурс зі спокійними треками, якщо хочете передбачуваний фон.
- Якщо в папці є і зображення, і відео, пам'ятайте: музика автоматично стає на паузу, коли починається відео.

**Коли це особливо корисно**

- Ви хочете перетворити TV box, планшет або старий телефон на цифрову рамку для кімнати.
- Вам потрібен один setup для показу сімейних фото, подієвих добірок або тревел-альбомів без ручного складання черги.

**Уникайте цього**

- Не використовуйте дуже повільний мережевий ресурс одночасно і для зображень, і для музики, якщо важлива плавність.

## Іммерсивний кінотеатр OpenXR VR

**Доступно в:** Standard, Lite, Legacy, `vr`, noLegal (single-eye 3D); `vr` і noLegal (повне занурення в шоломі - обидві збірки несуть іммерсивний вигляд, і він відкривається, коли застосунок бачить OpenXR-шолом і увімкнено загальний перемикач VR)

**Швидкий шлях - увімкнути, налаштувати, дивитися 3D**

1. **Single-eye 3D (на будь-якому флейворі, вмикати не потрібно):** відкрийте будь-який файл SBS/OU/180°/360° - формат визначиться автоматично і обріжеться до одного ока, щоб нормально виглядати на звичайному плоскому екрані. Керується через **Налаштування > Відтворення > "Показувати 3D-контент з одного ока"** (увімкнено за замовчуванням). Щоб задати формат вручну замість автовизначення, відкрийте діалог Control у плеєрі на збірці `vr`/XR-noLegal і виберіть режим на вкладці 3D - **Auto-detect**, **Side-by-Side (SBS)**, **Over-Under (OU)** або **Mono (Disabled)**; вибір запам'ятовується для цього файлу.
2. **Повне занурення на Quest (збірка `vr` або XR/noLegal):** у шоломі торкніться бейджа VR у плеєрі, поки відкритий 3D-файл, виберіть **Open in VR Cinema** в меню файлу в Browse, або відкрийте **Settings > Media** і торкніться **Test Immersive**, щоб спробувати приклад. Будь-який з трьох способів відкриває per-eye OpenXR-вигляд цього контенту.
3. **Дивіться:** усередині іммерсивного вигляду керування зібране на смузі HUD - смуга позиції, яку ви тягнете променем контролера, щоб перемотати (поруч показані час від початку і загальний), і ті перемикачі, що застосовні до цього файлу: звукова доріжка лише за кількох доріжок, субтитри лише коли вони є, глибина стерео лише для стереовмісту. По краях смуги - **СХОВАТИ** і **ВИХІД**; схована смуга зникає повністю, а натискання тригера повертає її, не зачіпаючи те, що під нею. Стік перемотує кроками по 10 секунд; утримуючи **grip** і штовхаючи стік, ви переходите між файлами - наступний і попередній ідуть усім списком ресурсу, а не одним відкритим файлом. За першого входу в іммерсивний режим після встановлення шолом показує легенду з усіма призначеннями контролера; будь-яке натискання закриває її, а кнопка **ДОПОМОГА** на смузі повертає її будь-якої миті.

**Розбір сценарію**

- Single-eye 3D взагалі не потребує шолома - це найпростіший спосіб переглянути старі записи SBS/OU на телефоні чи планшеті.
- Для повного занурення потрібен шолом Quest чи інший OpenXR-шолом і збірка, яка його несе, - `vr` або XR/noLegal sideload (див. [Встановлення VR через sideload](VR_SIDELOAD_UK.md)).
- Фото та відео 360°/180° усередині іммерсивного вигляду рендеряться як сфера/півсфера навколо вас; плоскі 2D-файли просто відтворюються плоско.

**Коли це особливо корисно**

- Ви хочете переглянути архівні записи SBS/OU/360°/180° без окремого VR-плеєра.
- У вас є Quest, і ви хочете спробувати повне занурення на своїх файлах уже сьогодні, приймаючи, що навігація поки лише вперед/назад.

**Уникайте цього**

- Не очікуйте, що збірка `vr` для Meta Horizon Store / Google Play вже входить в іммерсивний режим - ця частина ще в розробці.
- Перемотка, вибір доріжки і субтитрів, глибина стерео - усе це на смузі HUD у шоломі. Файлових операцій там немає: копіювати, перемістити чи видалити повертайтеся до плоскої панелі.

## Подорожі, читання та документи

## Підготуйте папку для подорожі без стабільного інтернету

**Доступно в:** Standard, Lite, Photos, Legacy, XR / noLegal (для читання PDF і EPUB потрібні Standard, Legacy або XR / noLegal)

**Швидкий шлях**

1. Створіть або виберіть одну локальну папку для подорожі.
2. Скопіюйте туди потрібні медіа, PDF, EPUB і нотатки ще до виходу з Wi-Fi.
3. Один раз відкрийте цю папку у FastMediaSorter, щоб підготувалися мініатюри й останні позиції.
4. Використовуйте папку офлайн у дорозі.

**Розбір сценарію**

- Тримайте travel-набір в одній локальній папці, навіть якщо оригінали зазвичай живуть на NAS або в хмарі.
- Навмисно змішуйте формати: посадкові PDF, EPUB для читання, скриншоти й офлайн-музику можна тримати поруч.
- Використовуйте фільтр, якщо хочете швидко перемикатися між зображеннями, документами й аудіо без інтернету.

**Коли це особливо корисно**

- Літаки, поїзди, готелі й сільські зони, де хмарний стримінг ненадійний.
- Ситуації, де потрібен один офлайн-пакет замість пошуку по кількох застосунках.

**Уникайте цього**

- Не залишайте перевірку офлайн-відкриття файлів на останню хвилину.

## Читайте хмарні документи й EPUB у дорозі

**Доступно в:** Standard, Legacy, XR / noLegal - у Lite і Photos документи та EPUB не відкриваються взагалі; у Lite додатково немає хмарних сховищ

**Швидкий шлях**

1. Додайте хмарного провайдера через **Cloud Storage**.
2. Відкрийте папку з PDF або EPUB.
3. Натисніть файл прямо в хмарному ресурсі.
4. Пізніше продовжуйте читання з останньої збереженої позиції.

**Розбір сценарію**

- Це зручно, коли робочі документи вже лежать у Google Drive, OneDrive або Dropbox, і вам не потрібен окремий reader workflow.
- PDF краще підходить для квитків, інструкцій і сканів із фіксованою версткою.
- EPUB зручніший для довгого читання, де важливіші розмір шрифту й навігація по розділах, ніж жорстка розкладка сторінки.

**Коли це особливо корисно**

- Ви перемикаєтеся між робочими документами й особистим читанням, не виходячи з застосунку.
- Ви тримаєте дорожні або клієнтські файли в хмарі, але хочете більш читальний інтерфейс.

**Уникайте цього**

- Не очікуйте хмарне читання в Lite - у цій збірці немає ні хмари, ні підтримки документів. У Photos і Legacy хмара є, але документи відкриває лише Legacy.
- Не вважайте повільний мобільний інтернет гарантованим рішенням для дуже великих файлів.

## Перекладайте вивіски, скани та скриншоти через OCR

**Доступно в:** Standard, Legacy, XR / noLegal

**Швидкий шлях**

1. Відкрийте зображення, PDF або текстовий файл.
2. Покажіть панель команд.
3. Натисніть **Translate**.
4. Під час першого запуску підтвердьте завантаження моделі, якщо це потрібно.

**Розбір сценарію**

- Для латиниці застосунок зазвичай починає з ML Kit заради швидкості.
- Для матеріалів із кирилицею застосунок може переключитися на Tesseract заради кращої якості розпізнавання.
- Скриншоти, чеки, меню та скани працюють особливо добре, якщо вихідний текст достатньо чіткий.

**Коли це особливо корисно**

- Ви в подорожі, читаєте іноземні інструкції або розбираєте скриншоти з чатів і застосунків.
- Вам потрібен переклад прямо поверх контенту, а не окремий ланцюжок copy-paste в інший інструмент.

**Уникайте цього**

- Не оцінюйте якість OCR за розмитим нічним фото або невдало обрізаним сканом.

## Передавайте мережеві файли у спеціалізовані програми

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Швидкий шлях**

1. Відкрийте файл із SMB, SFTP або FTP.
2. Натисніть **ⓘ Info**.
3. Натисніть **Download and Open**.
4. Виберіть потрібну програму в Android chooser.

**Розбір сценарію**

- Цей сценарій корисний, коли FastMediaSorter найзручніший як браузер віддаленого сховища, а інша програма краще підходить для конкретного формату.
- Типові handoff-кейси: офісні документи, складні PDF, відео з важкими кодеками й нішеві медіаформати.
- Завантажена копія залишається в `Downloads`, тому до неї можна повернутися, навіть якщо віддалене джерело пізніше стане недоступним.

**Коли це особливо корисно**

- Вам потрібен один центр для віддалених файлів, але без відмови від найкращих спеціалізованих інструментів.

**Уникайте цього**

- Не очікуйте такого самого flow для хмарних файлів прямо зараз.

## Швидкі обчислення з тексту та OCR

**Доступно в:** Standard, Legacy, XR / noLegal

**Швидкий шлях**

1. Відкрийте будь-який PDF-документ, EPUB-книгу, текстовий файл або запустіть переклад OCR на зображенні.
2. Виділіть довгим натисканням будь-який блок тексту, що містить числа або математичні вирази.
3. У плаваючому меню дій з текстом натисніть кнопку **Калькулятор**.
4. Калькулятор миттєво обчислить математичну формулу у плаваючому вікні.

**Розбір сценарію**

- Виберіть рядок тексту, що містить числа зі знаками операцій (наприклад, `(45 + 12) * 3`) у PDF або в результатах OCR-перекладу.
- Використовуйте вбудовані наукові функції калькулятора (тригонометрію, корені, степені, логарифми) для складних обчислень.
- Калькулятор зберігає історію обчислень між сеансами й підтримує регістри пам'яті (M+/M-/MR/MC) для швидкого відстеження даних.

**Коли це особливо корисно**

- Ви читаєте технічну документацію, скан скриншота або книгу й вам потрібно швидко розв'язати формули чи підсумувати ціни/числа без переключення в окремий застосунок калькулятора.

**Уникайте цього**

- Не намагайтеся обчислювати суто буквені рядки; парсер розпізнає лише коректні числа, дужки та математичні оператори.

## Хмарні нотатки Markdown та код

**Доступно в:** Standard, Photos, Legacy, XR / noLegal (локально, мережею та в хмарі); Lite (лише локальні папки)

**Швидкий шлях**

1. Перейдіть у будь-яку локальну папку, мережевий ресурс (SMB), FTP/SFTP або хмарний диск (Google Drive).
2. Натисніть кнопку **Нова нотатка (📝)** на панелі інструментів папки.
3. Введіть текст у вбудованому редакторі. Застосунок автоматично підсвітить розмітку Markdown і синтаксис коду.
4. Натисніть **Зберегти** (або дочекайтеся автозбереження) для запису змін прямо на віддалений диск.

**Розбір сценарію**

- Ведіть файл журналу `.md` на Google Диску або домашньому NAS і редагуйте його з будь-якого пристрою напряму.
- Створюйте нові нотатки в ключових папках з автоматичним розв'язанням конфліктів імен (наприклад, `Нотатка_1.txt`, `Нотатка_2.txt`).
- Переглядайте відрендерений Markdown у режимі читання або експортуйте нотатки у зовнішні сервіси, такі як Google Keep.

**Коли це особливо корисно**

- Ви хочете вести прості текстові нотатки, списки задач або зберігати фрагменти коду прямо на центральних мережевих чи хмарних дисках без проміжного скачування файлів.

**Уникайте цього**

- Не очікуйте створення файлів у хмарних сховищах на збірці Lite - у ній немає ні хмари, ні мережевих джерел.

## Сортуйте сімейний фотоархів через Quick Sort

**Доступно в:** Standard, Lite, Photos, Legacy, XR / noLegal

**Швидкий шлях**

1. Додайте цільові папки в **Quick Sort**.
2. Відкрийте вихідну папку з несортованими сімейними фото.
3. Використовуйте цифрові кнопки або touch zones під час перегляду.
4. Одразу відправляйте вдалі кадри в папки призначення.

**Розбір сценарію**

- Створюйте папки за результатом, а не лише за датою: `Best`, `Print`, `Send to family`, `Archive`.
- Переглядайте у fullscreen, щоб швидко приймати рішення й копіювати або переміщати без повернення до списку файлів.
- Якщо архів розбирають кілька людей, заздалегідь домовтеся про єдину схему папок призначення.

**Коли це особливо корисно**

- У вас накопичився backlog після днів народження, подорожей, шкільних подій або старих імпортів із телефона.
- Вам потрібен швидкий triage flow замість ручного перетягування файлів у файловому менеджері.

**Уникайте цього**

- Не починайте сортування, поки папки призначення названі нечітко.
- Не використовуйте Move одразу, якщо ще не впевнені, які папки стануть довгостроковим архівом.

## Захоплення екрана краєвими жестами

**Доступно в:** Standard, XR/noLegal

**Швидкий шлях**

1. Перейдіть у **Налаштування → Операції → Жести з країв екрана → Оверлей жестів** і увімкніть його.
2. Під час перегляду будь-якого файлу проведіть пальцем від лівого краю - відкриється меню захоплення.
3. Оберіть дію - панель закриється, дія виконається.

**Що вміє панель**

- Зробити **скриншот** поточного екрана - переглянути, відредагувати, поділитися, надіслати в інший застосунок або запустити OCR-переклад, плюс варіант тихого захоплення.
- **Сфотографувати** камерою, а потім надіслати, відредагувати знімок або запустити OCR-переклад, не виходячи з застосунку.
- Почати запис **екрана**, **відео** або **аудіо/голосу** - детальніше в розділах [Запис відео з екрана](#як-записати-відео-з-екрана) та [Запис голосової нотатки](#як-записати-голосову-нотатку).
- **Відкрити застосунок або панель**, якими ви часто користуєтесь.
- **Обрізати та поділитися** фрагментом поточного зображення.

**Корисно знати**

- Поки панель увімкнена, свайп від лівого краю відкриває меню захоплення, а не гортає сторінку.
- Панель розрахована на захоплення однією рукою під час перегляду - вимкніть її, якщо вам важливий свайп-гортання від лівого краю.
- Android щоразу підтверджує захоплення чи запис - навіть для тихого скриншота. Це системний захист, застосунок його не вимикає.

**Коли це допомагає**

- Потрібен скриншот, швидке фото чи запис, не відриваючись від переглянутого файлу.

## Підключення мережевого диска (SMB)

**Що потрібно:**

- NAS або ПК з Windows зі спільною папкою
- Обидва пристрої в одній мережі Wi-Fi
- Ім'я користувача та пароль

**Доступно в:** Версіях Standard, Photos, Legacy, XR / noLegal

**Кроки:**

1. Натисніть кнопку **"+"** на головному екрані
2. Виберіть **"Мережева папка (SMB)"**
3. Заповніть дані:
   - **Авто-виявлення (New):**
     1. Натисніть **"Сканувати мережу"**
     2. Зачекайте появи пристроїв у списку
     3. Виберіть пристрій зі списку
     4. IP-адреса заповниться автоматично

   - **Ручне введення:**

     ```
     Сервер/Шлях: \\192.168.1.100\photos
     Ім'я користувача: john
     Пароль: ****
     Ім'я для відображення: Home NAS (необов'язково)
     ```

4. Натисніть **"Тест з'єднання"** для перевірки
5. Натисніть **"Зберегти"**

**Формати адреси сервера:**

- Windows: `\\192.168.1.100\share`
- Linux/Mac: `smb://192.168.1.100/share`
- З портом: `smb://192.168.1.100:445/share`

**Поради:**

- Використовуйте IP-адресу (а не ім'я хоста) для надійності
- Увімкніть SMB v2/v3 на NAS для безпеки
- Порт SMB за замовчуванням: 445

**Вирішення проблем:**
→ Див. [TROUBLESHOOTING_UK.md](TROUBLESHOOTING_UK.md)

## Підключення SFTP/FTP сервера

**Що потрібно:**

- Сервер з увімкненим SSH (SFTP) або FTP
- Відкритий порт 22 (SFTP) або 21 (FTP)
- Ім'я користувача та пароль (або ключ для SFTP)

**Кроки:**

1. Натисніть кнопку **"+"** на головному екрані
2. Виберіть **"SFTP / FTP"**
3. Виберіть протокол: **SFTP** або **FTP**
4. Заповніть дані:

   ```
   Хост: 192.168.1.100
   Порт: 22 (SFTP) / 21 (FTP)
   Ім'я користувача: username
   Пароль: ****
   Віддалений шлях: /home/user/photos (необов'язково)
   ```

5. Натисніть **"Підключитися"**

**Додатково:**

- **Аутентифікація за SSH-ключем:** Наразі не підтримується (тільки пароль)
- **Власний порт:** Змініть номер порту, якщо сервер використовує нестандартний

## Імпорт теки з компаньйона Windows

**Що це:** компаньйон - функція [Fast Media Sorter for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/) (раніше FastMediaSorter LITE), безплатного сортувальника медіа від того ж автора. Вона відкриває обрані теки ПК по SFTP та експортує готове підключення - без ручного налаштування сервера і без введення хоста/порту/ключа на телефоні. Перенести на телефон можна, **відсканувавши QR-код** на екрані ПК або **імпортувавши файл `.fmscfg`**.

**Доступно у:** Standard, Photos, Legacy, XR/noLegal (для сканування штрихкоду потрібна камера; спосіб із файлом працює всюди, включно з VR)

> Хочете покрокову версію зі скриншотами? Див. посібник-сценарій [Відкрийте папки ПК скануванням коду](howto/scenario-companion-share-uk.md).

**Де взяти Fast Media Sorter for Windows:**

- Сайт: [serzhyale.github.io/FastMediaSorter_Lite](https://serzhyale.github.io/FastMediaSorter_Lite/)
- Публікація тек (інструкція): [Як опублікувати теки ПК для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)
- GitHub: [останній реліз](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases/latest) (інсталятор або портативний ZIP)
- winget: `winget install SerZhyAle.FastMediaSorter`
- Microsoft Store: пошук «FastMediaSorter LITE» (у Store програма під колишньою назвою)

**На ПК:**

1. Встановіть і запустіть **Fast Media Sorter for Windows**, відкрийте вкладку **Share** у налаштуваннях.
2. Оберіть теку(и) для доступу - програма сама підніме SFTP-сервер, створить ключі й налаштує автозапуск.
3. Вона покаже на екрані **QR-код**. Також можна натиснути **Save .fmscfg**, якщо зручніше файл.

**На телефоні - спосіб A, сканування коду (найшвидший):**

1. **Натисніть кнопку "+"** на головному екрані.
2. Натисніть **«Імпорт за штрихкодом»** - вона поруч із чотирма картками типів ресурсу і в шапці форми SFTP.
3. Наведіть камеру на QR-код на ПК (у темній кімнаті натисніть **Ліхтарик**) і підтвердіть діалог **«Імпорт доступу»**.
4. Готово - для кожної спільної теки з'явиться ресурс лише для читання, ключ сервера буде закріплено автоматично.

**На телефоні - спосіб B, імпорт файлу:**

1. На ПК натисніть **Save .fmscfg** і передайте файл на телефон (email, Telegram або спільна папка).
2. **Натисніть "+"** -> **«SFTP / FTP»** -> **«Імпорт із файлу»** та вкажіть файл `.fmscfg`. Якщо файл надійшов вкладенням у Telegram/email, просто натисніть на вкладення.
3. Підтвердіть діалог **«Імпорт доступу»** - з'являться ресурси лише для читання.

**Важливо:** і QR-код, і файл конфігурації містять пароль доступу - поводьтеся з ними як із ключем, не публікуйте скриншот і файл. Пункт **«Імпорт за штрихкодом»** прихований на пристроях без камери та на VR-гарнітурах - там використовуйте спосіб B.

## Перевірка швидкості мережі

**Підтримується для:** SMB, SFTP, FTP, Cloud (Google Drive)

**Автоматична перевірка:**
При додаванні нового мережевого ресурсу програма автоматично запускає тест швидкості у фоновому режимі. Результати (швидкість читання/запису) зберігаються в налаштуваннях ресурсу.

**Ручна перевірка:**

1. Перейдіть в **Керування ресурсами**
2. Редагуйте мережевий ресурс (значок олівця)
3. Прокрутіть вниз
4. Натисніть кнопку **"Швидкість"**
5. Зачекайте ~15 секунд ("Аналіз швидкості..")
6. Результати:
   - **Швидкість читання (Мбіт/с)**
   - **Швидкість запису (Мбіт/с)**
   - **Рекомендовані потоки** (для оптимальної продуктивності)

1. **Налаштування** → вкладка **Операції** → **Призначення швидкого сортування**

3. Виберіть існуючу папку зі списку
4. Папці присвоюється номер (0-9) та колір
5. Повторіть для до 30 папок

**Спосіб 2: Через налаштування папки**

1. Головний екран → **Довге натискання на папці**
2. Натисніть **"Редагувати"** (іконка олівця)
3. Увімкніть **"Позначити для Quick Sort"**
4. Натисніть **"Зберегти"**

**Використання Quick Sort:**

Під час перегляду файлів:

- Натисніть **цифрову кнопку** (0-9) на панелі команд
- АБО натисніть **лівий нижній кут** (зона COPY)
- АБО натисніть **нижній центральний кут** (зона MOVE)

Файл миттєво копіюється/переміщується в цю папку!

**З клавіатурою або пультом ТБ:** підключіть пристрій - кнопки призначення отримають цифрову позначку. Натисніть відповідну цифру, щоб миттєво надіслати файл у цю папку, без дотику до екрана.

## Використання сенсорних зон

**Що таке сенсорні зони?**

Екран розділений на 9 невидимих областей для швидких дій:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПІЯ  │ ПЕРЕЙМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  ПОПЕР. │ ПЕРЕМ.  │  НАСТ.  │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ КОМАНДИ │ ВИДАЛИТИ│  ГРАТИ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. **НАЗАД** - Повернутися до списку
2. **КОПІЯ** - Копіювати файл
3. **ПЕРЕЙМ.** - Перейменувати файл
4. **ПОПЕР.** - Попередній файл
5. **ПЕРЕМ.** - Перемістити файл
6. **НАСТ.** - Наступний файл
7. **КОМАНДИ** - Відкрити меню
8. **ВИДАЛИТИ** - Видалити файл
9. **ГРАТИ** - Старт/Стоп слайд-шоу

**Увімкнути накладання (рекомендується для новачків):**

1. Налаштування → Відтворення
2. Увімкніть **"Завжди показувати сітку сенсорних зон"**
3. Тепер ви побачите напівпрозору сітку

**Спробуйте:**

1. Відкрийте будь-яке фото
2. **Натисніть верхній правий кут** → Наступний файл
3. **Натисніть верхній лівий кут** → Попередній файл
4. **Натисніть середній правий кут** → Видалити файл
5. **Натисніть середній лівий кут** → Копіювати файл

**Вимкнути, якщо не потрібно:**
Налаштування → Відтворення → "Завжди показувати сітку сенсорних зон" = ВИМК

Потім використовуйте **кнопки панелі команд**.

## Створення слайд-шоу з фоновою музикою

**Вимоги:**

- Хоча б одна папка/ресурс з аудіофайлами (MP3, FLAC тощо)
- **Доступно в:** Standard, Lite, Legacy, XR / noLegal (у Photos немає підтримки аудіо)

**Налаштування:**

1. **Налаштування** → вкладка **Медіа** → **Зображення**
2. Увімкніть **"Музика під час слайдшоу"**
3. Натисніть кнопку **"Вибрати джерело музики"**
4. Виберіть ресурс, що містить ваші музичні файли
5. Натисніть **"Зберегти"** або закрийте налаштування

**Відтворення слайд-шоу з музикою:**

1. **Відкрийте будь-яку папку** з фото/зображеннями
2. Натисніть **перше фото** для перегляду
3. Натисніть кнопку **"Play"** (або зону справа внизу)
4. Слайд-шоу почнеться з відтворенням фонової музики

**Як це працює:**

- Музика відтворюється випадковим чином з вибраного музичного ресурсу
- Коли трек закінчується, автоматично починається наступний випадковий трек
- Музика продовжує грати під час переходів між зображеннями
- Музика зупиняється при виході зі слайд-шоу або паузі

**Примітки:**

- Музика відтворюється тільки для **зображень та GIF** (не для відео/аудіо)
- Коли слайд-шоу показує відео, музика автоматично призупиняється
- Музика відновлюється при поверненні до зображень
- Працює з локальними та мережевими джерелами музики (SMB, SFTP, FTP)

**Налаштування вибору музики:**

- Додайте кілька музичних файлів у папку музичного ресурсу
- Додаток буде випадковим чином перемішувати всі аудіофайли
- Організуйте музику в підпапки, якщо для музичного ресурсу увімкнено опцію "Включити підпапки"

**Вирішення проблем:**

- Якщо музика не відтворюється: Перевірте, що музичний ресурс містить хоча б один аудіофайл
- Якщо музика переривається в мережі: Використовуйте локальну папку або швидше мережеве з'єднання
- Для музики по SMB: Переконайтеся, що SMB-ресурс використовує протокол `file://` (див. [TROUBLESHOOTING_UK.md](TROUBLESHOOTING_UK.md))

## Як працювати з папками (виділення, копіювання, перенесення)

Коли субкаталоги показані у списку окремими елементами, рядок папки поводиться як рядок файлу.

**Увімкнути показ папок:** **Налаштування** → **Загальні** → **Показувати підтеки окремо**. Той самий перемикач є у кожного ресурсу в його редакторі.

**Кроки:**

1. Натисніть галочку біля рядка папки або зробіть довге натискання, щоб виділити одну папку. Одиночний тап так само відкриває папку.
2. Через меню **⋮** біля рядка або панель дій виберіть **Копіювати**, **Перенести**, **Перейменувати** чи **Видалити**.
3. Виберіть приймач. Файли та папки з одного виділення обробляються однією операцією.
4. У приймача створюється вся структура - кожна вкладена папка і файл усередині вихідної.

**Між різними типами ресурсів:** папку можна скопіювати або перенести між пристроєм, SMB, SFTP, FTP і хмарою - структура відтворюється на боці приймача.

**Що відхиляється і чому:** приймач усередині самої папки або її поточне розташування відхиляються до початку копіювання; каталог, вибраний системним діалогом і без звичайного файлового шляху, папки прийняти не може. Повідомлення називає причину, щоб ви вибрали інший приймач.

**Скасування:** операція над папкою показує прогрес і зупиняється на вимогу. Усе, що вже записано, залишається у приймача - перевірте папку перед повторним запуском. Під час перенесення елемент видаляється у джерела лише після успішного запису, тому втратити його неможливо.

**Відправлення у фон:** не обов'язково сидіти й дивитися на діалог прогресу. Закрийте його - перенесення продовжиться, залишаючись видимим у Browse як смуга внизу екрана з назвою операції, відсотком виконання і файлом, який обробляється зараз. Торкніться цієї смуги, щоб повернути повний діалог прогресу, разом зі скасуванням.

## Очищення кошика

Видалені файли потрапляють у папки `.trash/` і залишаються там до ручного очищення.

**Спосіб 1: Очистити весь кошик**

1. **Налаштування** → вкладка **Операції** → **Видалення файлів, кошик**
2. Натисніть **"Очистити кошик"**
3. Підтвердіть видалення
4. Всі папки `.trash/` у всіх ресурсах будуть очищені

**Спосіб 2: Для однієї папки**

1. Використовуйте файловий менеджер
2. Перейдіть у папку (наприклад, `/storage/emulated/0/DCIM/Camera`)
3. Знайдіть підпапку `.trash/`
4. Видаліть вручну

**Увага:** Це **безповоротне видалення**! Файли не можна буде відновити.

## Перегляд текстових та PDF файлів

**1. Увімкнути підтримку:**

1. **Налаштування** → вкладка **Медіа** → **Документи**
2. Увімкніть **"Підтримка текстових файлів (.txt, .md, .log, .json, .xml)"** та **"Підтримка PDF-документів"**
3. **Перескануйте** папки, щоб знайти нові файли.

**2. Фільтр за типом медіа:**

1. Натисніть іконку **Фільтра** (лійка) на головному екрані.
2. Виберіть типи файлів:
   - Зображення
   - Відео
   - Аудіо
   - GIF
   - **Текст** (Нове)
   - **PDF** (Нове)
3. Натисніть **"Застосувати"**.

**3. Текстовий переглядач:**

- Відкриває **.txt, .md, .log, .json, .xml**.
- **Прокрутка** для читання.
- **Копіювання:** Довге натискання для виділення тексту.

**4. PDF Переглядач (Нові функції):**

- Відкриває **.pdf** файли.
- **Панель керування (Знизу):**
  - **Назад/Вперед:** Великі кнопки по краях.
  - **Зум +:** Збільшити.
  - **Зум -:** Зменшити.
- **Жести:**
  - **Свайп ВГОРУ:** Наступна сторінка.
  - **Свайп ВНИЗ:** Попередня сторінка.
  - **Щипок:** Масштабування.
  - **Подвійний тап:** Скидання масштабу.
  - **Масштаб зберігається:** Наступна сторінка відкривається в тому самому масштабі й на тій самій ділянці, що й попередня; подвійний тап повертає сторінку цілком.
- **Переміщення:** Перетягуйте збільшену сторінку пальцем.
- **Виділення тексту довгим натисканням (Android 15+):** натисніть і утримуйте слово, щоб виділити його прямо з текстового шару сторінки - без OCR і без очікування. Якщо те саме слово трапляється на сторінці кілька разів, виділяється те, що під пальцем, а не перше. Перетягніть маркери, щоб розширити виділення, а потім скопіюйте або перекладіть його.

## Як читати електронні книги (EPUB)

**Вимоги:**

- **Налаштування** → вкладка **Медіа** → **Документи** → **Підтримка EPUB електронних книг** має бути увімкнено (увімкнено за замовчуванням)
- Підтримуваний формат: `.epub` (без DRM)

**Можливості:**

- **Навігація по розділах:** Свайп вліво/вправо або кнопки на панелі команд
- **Зміст:** Натисніть іконку списку (📋) для переходу до розділу
- **Розмір шрифту:** налаштовується (14px - 32px)
- **Пошук:** Пошук тексту всередині книги
- **Теми:** Автоматично адаптується під Світлу/Темну тему

**Керування:**

1. **Відкрийте файл EPUB** зі списку
2. **Торкніться екрану** для відображення панелі команд
3. **Нижня панель керування:**
   - `Попер.` / `Наст.`: навігація по розділах
   - `- A` / `+ A`: зменшити/збільшити шрифт
   - `Пошук` (🔍): пошук тексту
   - `Зміст` (📋): відкрити список розділів
4. **Жести свайпу:** перемикання розділів

**Примітка:** Працює як з локальними файлами, так і з мережевими потоками (SMB/SFTP/Cloud). Великі книги (>50МБ) у повільних мережах можуть завантажуватися кілька секунд.

## Відкриття мережевих файлів у зовнішніх програмах

**Доступно для:** Файлів SMB, SFTP, FTP

**Сценарій використання:** Ви хочете відкрити документ, фото або відео з мережевого диска в спеціалізованій зовнішній програмі (наприклад, MS Office, Adobe Acrobat, VLC Player).

**Кроки:**

1. **Перейдіть до файлу** на мережевому ресурсі
2. **Натисніть на файл**, щоб відкрити його в плеєрі/переглядачі
3. **Натисніть кнопку ⓘ (Інфо)** у верхній панелі
4. **Натисніть "Завантажити і відкрити"**
5. **Дочекайтеся завантаження** - діалог прогресу покаже відсотки
6. **Оберіть програму** зі списку Android

**Що відбувається:**

- Файл завантажується в папку `Downloads`
- Прогрес відображається в діалозі (0-100%)
- Після завершення Android покаже вибір програми
- Можна відкрити файл в будь-якій сумісній програмі

**Підтримувані протоколи:**

- ✅ SMB/CIFS мережеві папки
- ✅ SFTP сервери
- ✅ FTP сервери
- ❌ Хмарні сховища (поки не реалізовано)

**Поради:**

- Завантажені файли залишаються в папці `Downloads`
- Ви можете видалити їх вручну пізніше через файловий менеджер
- Працює з усіма типами файлів (зображення, відео, документи)
- Для великих файлів завантаження може зайняти кілька хвилин

**Приклади використання:**

- Редагування мережевого документа в MS Word
- Відтворення мережевого відео в VLC Player
- Перегляд мережевого PDF в Adobe Acrobat
- Відправка мережевого фото через месенджери

## Як переглянути текст пісні (Лірика)

- Аудіофайл (MP3, FLAC та ін.) з метаданими Виконавця та Назви.

## Автоматичний переклад

Автоматичний переклад тексту із зображень, PDF та текстових файлів за допомогою **Гібридної системи OCR** (Google ML Kit + Tesseract).

**Ключові особливості:**

- **Гібридний рушій:** Використовує Google ML Kit для швидкого розпізнавання латиниці та **Tesseract** для якісного розпізнавання кирилиці (Українська, Російська).
- **Офлайн:** Працює повністю на пристрої (після початкового завантаження моделей).
- **Розумне накладання:** Перекладений текст накладається поверх оригіналу зручними для читання абзацами.

**Налаштування:**

1. **Налаштування** → вкладка **Медіа** → **Інше**
2. Увімкніть **"Увімкнути переклад"**
3. Виберіть **Source Language** (Вихідна мова):
   - **"Auto" (Рекомендовано):** Автоматично вибирає найкращий рушій (Tesseract для кирилиці, ML Kit для інших).
   - **Конкретна мова:** Примусово використовує модель (наприклад, "Ukrainian" увімкне Tesseract).
4. Виберіть **Target Language** (Цільова мова, наприклад, English).

**Як використовувати:**

1. Відкрийте **Зображення**, **PDF** або **Текстовий** файл.
2. Натисніть на екран, щоб показати **Панель команд** (Command Panel).
3. Натисніть кнопку **"Перекласти"** (іконка A→文).
4. **Перший запуск:**
   - Для ML Kit: Підтвердіть завантаження мовної моделі (~30МБ).
   - Для Tesseract (Кирилиця): Підтвердіть завантаження даних OCR (~15МБ).
5. Перекладений текст з'явиться поверх вмісту.

**Примітка:** Ініціалізація Tesseract (для кирилиці) може зайняти на 1-2 секунди більше часу, ніж ML Kit.

## Розумні віджети домашнього екрана

**Доступно в:** у всіх версіях - набір віджетів є в кожній збірці; кожен віджет слідує своїй можливості, тому віджет запису голосу потребує збірки з підтримкою мікрофона (не Lite і не Photos), а віджети фоторамки та ресурсів працюють усюди

**Швидкий шлях**

1. Перейдіть на домашній екран Android, затисніть його та виберіть пункт **Віджети**.
2. Перетягніть потрібний віджет **FastMediaSorter** (наприклад, іконку 1×1 «Швидкий диктофон» або «Camera OCR») на екран.
3. Налаштуйте папку збереження та параметри захоплення, потім натисніть **Зберегти**.
4. Натискайте віджет для миттєвого виконання задачі прямо з робочого столу.

**Розбір сценарію**

- Використовуйте віджети 1×1 як швидкі ярлики для миттєвого виконання фонових дій (наприклад, одне натискання починає запис голосу, повторне - зберігає її в ресурс на NAS).
- Додайте віджет **Задачі за розкладом** для моніторингу фонового копіювання або запуску всіх задач однією кнопкою.
- Розмістіть віджет **Випадковий кадр** для показу змінюваних сімейних фотографій напряму з мережевої папки SMB.

**Коли це особливо корисно**

- Вам потрібні швидкі ярлики на робочому столі для щоденної зйомки (чеки, квитанції, голосові нотатки) без відкриття основного інтерфейсу застосунку.
- Вам потрібні наочні віджети для керування відтворенням або швидкого відстеження розкладу резервного копіювання.

**Уникайте цього**

- Не намагайтеся додавати віджети, якщо лаунчер вашого Android-пристрою блокує створення кастомних віджетів сторонніми застосунками.

## Як використовувати застосунок як домашній екран

FastMediaSorter може замінити домашній екран пристрою власним робочим столом - ваші теки, годинник, погода, застосунки і панель задач уздовж краю. Якщо ви колись працювали за робочим столом Windows, усе буде знайоме: речі лежать там, куди ви їх поклали, а кнопка «Пуск» відкриває меню. Це режим лаунчера, і він є лише у збірках **Standard** і **noLegal**.

**Увімкнення:**

1. Відкрийте **Налаштування → Загальні** й увімкніть **«Лаунчер: зробити застосунок домашнім екраном»**.
2. Android попросить підтвердження. На Android 10 і новіших це одне запитання - «Дозволити FastMediaSorter бути застосунком головного екрана?» - просто дозвольте. На старіших версіях звичний вибір з'явиться під час наступного натискання «Додому»: оберіть FastMediaSorter і натисніть **«Завжди»** або **«Лише один раз»**, якщо поки що хочете просто спробувати.
3. Натисніть «Додому». З'явиться робочий стіл, уже заповнений приблизно десятком корисних речей - годинник, погода, ваші теки, рядок пошуку - тож у перший день це не порожня сітка.

На щойно встановленому застосунку є коротший шлях: позначте **«Використовувати як домашній екран»** на першій сторінці привітання. Це не перериває налаштування системним діалогом - підтвердження Android з'явиться, коли ви вперше після цього відкриєте **Налаштування → Загальні**.

**Що є на робочому столі:**

| Тип комірки | Що вона робить |
|--------------|-----------------|
| Ярлик ресурсу | Відкриває додану вами теку - і ви обираєте, у якому режимі: перегляд, слайд-шоу чи відтворення |
| Гаджет | Годинник із секундами (тап відкриває будильники), погода у вашому місті, що грає просто зараз, перекладач і ще два десятки інших |
| Ярлик застосунку | Запускає будь-який встановлений застосунок; довге натискання показує його власні швидкі дії |
| Комірка контакту | Відкриває картку людини, телефонує їй, надсилає SMS або відкриває розмову в месенджері |
| Віджет застосунку | Ті самі віджети, які застосунок пропонує для домашнього екрана Android, тільки тут |

**Панель задач і меню «Пуск»:**

- Панель задач іде вздовж нижнього краю і містить кнопку «Пуск», нещодавно відкриті застосунки, закріплені вами та невеликий лоток із годинником, батареєю, мережею і сигналом SIM.
- Хочете її зверху? **Налаштування → Загальні → Налаштування системного лаунчера → Панель задач → Розташування панелі задач** перемикає між значеннями **«Знизу»** і **«Зверху»**. Меню «Пуск» іде за панеллю і розкривається згори вниз, коли панель нагорі.
- Кнопка «Пуск» відкриває меню: відкрити FastMediaSorter, ваші ресурси, додати ресурс, налаштування Android, налаштування застосунку, налаштування лаунчера, редагувати вміст стола, а наприкінці - перезавантаження, вимкнення і **«Вийти з режиму лаунчера»**. Перезавантаження і вимкнення спрацюють, лише якщо пристрій дозволяє таке звичайному застосунку - на більшості телефонів вони просто нічого не зроблять.

**Ваші застосунки:** сітка застосунків групує їх за секціями, у кожної - невеликий заголовок. Натисніть заголовок, щоб згорнути рідко потрібну секцію; згорнуті заголовки тиснуться один до одного, тож стіл стає коротшим, а не лишає дір. На щойно створеному столі з'являється ще й секція **GOOGLE** з тими застосунками Google, які у вас уже встановлені. Довге натискання на будь-якому застосунку в списку дає **«На робочий стіл»** і **«Закріпити на панелі задач»**.

**Як переставляти:**

- Натисніть і утримайте порожній квадрат робочого стола. З'являться чотири пункти: **«Додати елемент..»**, **«Редагувати стіл»**, **«Шпалери»**, **«Налаштування лаунчера»**. Нова комірка стане рівно на той квадрат, який ви натиснули.
- **«Додати елемент..»** відкриває вибір: застосунок, функція, одна з ваших тек, радіопотік, людина, системна дія, запланована операція, гаджет або дія. Серед гаджетів - картка «зараз грає» (показує, що грає на пристрої, і одним дотиком відкриває потрібний програвач) та комірка перекладача.
- **«Редагувати стіл»** вмикає режим редагування - те саме, що «Редагувати вміст стола» в меню «Пуск». У режимі редагування: тягніть комірку, щоб пересунути, тягніть кутовий маркер гаджета, щоб змінити розмір, натискайте **+**, щоб додати, і обирайте **«Прибрати з робочого столу»** на комірці, щоб її прибрати. Закінчивши, натисніть **«Готово»**.
- Користуєтеся пристроєм не самі? Увімкніть **«Заблокувати робочий стіл»** у налаштуваннях лаунчера - тоді довге натискання нічого не робить і розташування не зміниться випадково.
- Інші застосунки можуть закріплювати тут власні ярлики - так само, як на будь-якому іншому домашньому екрані.

**Портрет і ландшафт - два окремі робочі столи.** Те, що ви розклали вертикально, не з'явиться, коли ви повернете пристрій: у кожної орієнтації своє розташування і свої згорнуті секції. Застосунок скаже про це один раз - коли ви вперше повернете стіл, який уже встигли розкласти. Самі налаштування - розташування панелі задач, щільність, шпалери - спільні для обох.

**Щоб вміщалося більше або менше:** **Налаштування → Загальні → Налаштування системного лаунчера → Робочий стіл лаунчера → Щільність сітки** пропонує **«Вільна»**, **«Стандартна»**, **«Щільна»** і **«Дуже щільна»** - просторіші комірки або більше ярликів на екран.

**Повернення до попереднього домашнього екрана** - будь-яким із трьох способів:

- Відкрийте меню «Пуск», оберіть **«Вийти з режиму лаунчера»** і підтвердьте.
- Вимкніть **«Лаунчер: зробити застосунок домашнім екраном»** у **Налаштування → Загальні**.
- Або одразу відкрийте власний список домашніх застосунків Android: **Налаштування → Загальні → Налаштування системного лаунчера → Система → Змінити домашній екран**.

Розташування робочого стола зберігається в будь-якому разі, тож повторне увімкнення режиму поверне все точно таким, яким ви його залишили.

**Одне чесне попередження.** Деякі пристрої відмовляються запам'ятовувати вибір. Дешеві автомагнітоли та інші вбудовані Android-коробки за кожного увімкнення повертають свій заводський домашній екран, хоч би що ви обрали. Це прошивка пристрою перебиває ваш вибір, а не помилка застосунку, і обійти це не може жоден застосунок. Якщо ваш пристрій поводиться так, оберіть FastMediaSorter домашнім застосунком ще раз після перезавантаження - а якщо вибір усе одно не тримається, отже, пристрій цього просто не дозволяє.

## Використання FMS на Android TV-приставці

FastMediaSorter працює на будь-якій Android TV-приставці або сет-топ-боксі (Xiaomi Mi Box, Nvidia Shield, Amazon Fire TV, дженерик Android-бокси). Тачскрін не потрібен - додаток повністю керується з пульта ДК або Bluetooth-клавіатури.

**Що вам потрібно:**

- Android TV-приставка на Android 8.0+ (версії Standard/Lite/Photos) або Android 6.0+ (версія Legacy)
- Пульт ДК з D-pad або Bluetooth-клавіатура
- Опціонально: домашній NAS (SMB), USB-накопичувач або SD-карта з медіа

**Навігація з пульта ДК:**

| Кнопка | Дія |
|--------|-----|
| D-pad Вгору/Вниз/Вліво/Вправо | Переміщення фокусу між елементами |
| OK / Enter | Відкрити елемент або підтвердити |
| Back | Повернутися на попередній екран |
| Backspace | Перейти на папку вище в браузері файлів |
| Червона | Видалити вибраний файл(и) |
| Зелена | Копіювати вибраний файл(и) |
| Жовта | Перемістити вибраний файл(и) |
| Синя | Перейменувати вибраний файл |
| Channel Up / Channel Down | Попередній / наступний файл у плеєрі |

**Кроки:**

1. Встановіть додаток із Google Play або sideload APK. Рекомендується версія Standard.
2. На головному екрані натисніть **OK** на кнопці (+) для додавання ресурсу.
3. Виберіть **Локальна папка** для USB/SD або **Мережева папка** для підключення до NAS через SMB.
4. Після додавання ресурсу перейдіть у нього за допомогою D-pad + OK для перегляду файлів.
5. Відкрийте будь-яке відео, зображення або аудіофайл - плеєр повністю керується з пульта.
6. Для запуску слайд-шоу відкрийте папку із зображеннями та перейдіть до кнопки **Слайд-шоу** на панелі команд.
7. Для додавання фонової музики до слайд-шоу перейдіть у **Налаштування → Медіа → Зображення**, увімкніть **Музика під час слайдшоу** та виберіть музичний ресурс.

**Поради:**

- Утримуйте D-pad Вгору/Вниз для прискореного прокручування довгих списків файлів.
- Натисніть **F1** на Bluetooth-клавіатурі для відкриття підказок по гарячих клавішах на будь-якому екрані.
- Кольорові кнопки пульта можна перепризначити у **Налаштування → Операції → Керування та клавіші**.

## Слухайте інтернет-радіо або дивіться IPTV через Трансляції

**Доступно в:** Standard, Legacy, XR / noLegal - у Lite і Photos екран Трансляцій відсутній

**Швидкий шлях**

1. Налаштування > Медіа > Трансляції > увімкніть **Увімкнути трансляції**.
2. Відкрийте **Трансляції** через головне меню або кнопку-ярлик у налаштуваннях.
3. Натисніть **«⋮»** наприкінці панелі команд → **«Додати»** та введіть URL радіостанції або відеопотоку (http/https, .m3u8, rtsp://).
4. Або **«⋮»** → **«Імпорт за URL»** для .m3u-плейлиста.
5. Або **«⋮»** → **«Оновити каталог FastMediaSorter»**, чи через екран Розширень / онбординг.

**Розбір сценарію**

- Аудіо-потоки (радіо) грають безпосередньо зі списку; внизу з'являється прилипаючий міні-банер із назвою станції та поточним треком (ICY-метадані).
- Дві невеликі іконки праворуч від поля пошуку розділяють радіо та відео одним дотиком: натисніть значок аудіо або відео, щоб залишити лише цей тип, натисніть підсвічений значок ще раз - повернеться весь список.
- Відео та RTSP відкриваються в повноекранному плеєрі. Кнопка «Назад» повертає до списку зі збереженою позицією прокрутки.
- Закріпіть улюблені джерела вгорі за допомогою іконки шпильки - незалежно від глобальних Вибраних.
- Перемкніть перегляд на **Сітку** на панелі інструментів Трансляцій, щоб побачити канали плитками з останнім захопленим кадром - зручно для швидкого перегляду відеопотоків. Вибір (список чи сітка) запам'ятовується під час наступного відкриття Трансляцій.
- Якщо потік підтримує трансляцію і телефон у тій самій Wi-Fi мережі, натисніть **Cast** у плеєрі, щоб надіслати його на Chromecast. RTSP-потоки транслювати не можна.
- Фільтруйте список за категорією та/або мовою (з підтримкою прапорців). Кнопка фільтра отримує індикатор-точку, коли фільтр активний.
- Якщо потік недоступний - з'являється діалог «Повторити / Видалити / Скасувати».
- Трансляцію, додану вручну, можна надіслати на годинник Wear OS: відкрийте меню **⋮** біля рядка та натисніть **«Надіслати на годинник»** (команда видима при увімкненій опції Wear Companion). Надіслана станція переживає оновлення каталогу на годиннику; якщо її адреса згодом з'явиться в онлайн-каталозі, каталожний запис її замінить.

**Фонове відтворення**

- При вимкненому фоновому відтворенні аудіо зупиняється при виході зі екрана Трансляцій (з тим самим вибором «Зупинити / Продовжити», що і в звичайному плеєрі).
- Налаштування фонового відтворення: Налаштування > Відтворення > **Фонове відтворення аудіо**.

**Особливо корисно для автомагнітол**

- FastMediaSorter замінює окремий застосунок для інтернет-радіо на Android-магнітолі. Кнопки керма (Play/Pause, Next) керують потоком без торкання екрана.

**Уникайте цього**

- Не використовуйте збірки Lite і Photos для Трансляцій: у них немає входу в цей розділ, тому жоден протокол там не працює.
- DRM, YouTube, Twitch та закриті платформи не підтримуються.

## Як записати відео з екрана

**Доступно в:** Standard, XR/noLegal

**Кроки:**

1. Запустіть запис із меню на головному екрані (**«Відеозапис екрана»**), з панелі Quick Launch або дією **«Почати запис екрана»** в меню жестів.
2. Підтвердьте системний запит Android - поділитися всім екраном чи лише цим застосунком. Він з'являється щоразу під час запису, і його не можна пропустити.
3. У кутку екрана з'явиться невелика плашка **«Триває запис екрана»** з паузою/продовженням і зупинкою. Зупинити можна й із сповіщення.
4. Натисніть **«Стоп»**, коли закінчите.

**Що відбувається:**

- Запис захоплює все, що показується на екрані, включно з іншими застосунками, разом зі звуком.
- Готове відео зберігається в папку Movies на пристрої.

**Примітка:** Системний запит Android - це захисний механізм для будь-якого запису екрана, застосунок не може його вимкнути.

## Як записати голосову нотатку

**Доступно в:** Standard, Legacy, XR / noLegal

**Кроки:**

1. Почніть запис через пункт **«Запис із диктофона»** в меню, віджет **«Швидкий диктофон»** на головному екрані або дію **«Почати запис аудіо»** в меню жестів.
2. Говоріть - індикатор **«Запис..»** (або плаваюча плашка поверх поточного застосунку) показує, що запис триває.
3. Натисніть **«Зупинити і зберегти»** (або ще раз торкніться віджета/жесту), щоб закінчити.

**Що відбувається:**

- Запис зберігається в папку для диктофона, обрану в Налаштуваннях, або в папку Recordings на пристрої, якщо нічого не обрано.
- Запис через віджет або жест працює навіть під час роботи в іншому застосунку - плаваючий елемент керування залишається зверху, щоб зупинити запис, не перемикаючись назад.

**Де задати папку збереження:** Налаштування → Операції → Диктофон.

## Як користуватися вбудованою камерою

**Доступно в:** Standard, Lite, Photos (лише фото), Legacy, XR/noLegal

**Кроки:**

1. В Огляді відкрийте панель інструментів або меню і натисніть **«Зйомка камерою»** (фото) або **«Записати відео»**.
2. За потреби перемкніться між **«Фото»** і **«Відео»** прямо на екрані камери.
3. Налаштуйте зум пресетом (0.5x/1x/2x..) або повзунком під ним - вони синхронізовані.
4. Натисніть кнопку співвідношення сторін і виберіть форму кадру - **4:3**, **16:9** або **«На весь екран»**. Змінюється сам видошукач, тому кадр на екрані збігається з тим, що збережеться, а вибір запам'ятовується до наступного разу (типово 16:9).
5. Натисніть кнопку сценарію зйомки і виберіть, як знімати - звичайний, ніч, портрет, селфі, макро або спорт. Макро одразу переходить на окремий об'єктив ближнього фокуса, селфі розвертає камеру на фронтальну, спорт тримає витримку короткою, щоб рух завмер. У списку лише ті сценарії, які пристрій справді вміє, активний названий на кнопці, а ручна зміна об'єктива повертає камеру у звичайний режим.
6. Натисніть кнопку затвора (або запису), щоб зняти. Результат збережеться прямо в ресурс - локальний або мережевий, - який ви переглядали.

**Поради:**

- Дія **«Почати запис відео»** в меню жестів відкриває камеру одразу в режимі відео і починає запис, щойно готовий попередній перегляд - швидко, але цей спосіб зберігає запис у папку Movies на пристрої, а не в переглянутий ресурс.
- Увімкніть **«Геотегування фото»** біля налаштувань камери, щоб вбудовувати GPS-координати в кожен знятий JPEG - поки ви не увімкнете це самі, нічого не зберігається. В **Інформації про файл** з'являться дата зйомки і точка з EXIF GPS - як посилання, що відкривається в картах або браузері.

**Де шукати налаштування камери:** Налаштування → Операції → Фотографування.

## Як знайти і видалити дублікати файлів

**Кроки:**

1. Відкрийте папку в Огляді, потім відкрийте **меню** (⋮) на панелі інструментів.
2. Натисніть **«Знайти дублікати»**, щоб перевірити збіги самостійно, або **«Знайти та видалити дублікати»**, щоб видалити їх одразу.
3. Для **«Знайти дублікати»** застосунок заздалегідь позначає всі копії, крім найстарішої в кожній групі - підправте вибір, потім натисніть **«Видалити вибране»** і підтвердьте.
4. **«Знайти та видалити дублікати»** видаляє ті самі позначені копії одразу після сканування, без підтвердження - спершу скористайтеся «Знайти дублікати», якщо хочете перевірити список перед видаленням.

**Очищення за розміром:**

1. У тому самому меню натисніть **«Видалення за розміром..»**.
2. Виберіть **«Менше ніж»** або **«Більше ніж»**, вкажіть розмір і натисніть **«Аналізувати»**.
3. Перевірте кількість файлів і обсяг, який звільниться, потім натисніть **«Видалити файли»** для підтвердження.

**Примітки:**

- Сканування порівнює файли за вмістом у три проходи - розмір, швидкий хеш, потім повна перевірка SHA-256, - тож перейменовані дублікати теж знаходяться.
- Видалення за розміром показує, скільки місця звільниться, ще до видалення; для мережевих і хмарних джерел кошик не використовується, тож таке видалення одразу остаточне.

## Як переглянути статистику використання

**Кроки:**

1. Перейдіть у **Налаштування → Загальні → Збір статистики** і увімкніть перемикач.
2. Натисніть **«Статистика»** (з'являється прямо під перемикачем), щоб відкрити панель.

**Що ви побачите:**

- Картки-зведення: відсортовано файлів, звільнено місця, час у програвачі.
- Розбивку за типами медіа (фото, відео, аудіо, документи..).
- Згортні розділи з деталями: операції, зйомка, перегляд, редагування, джерела та загальне використання.

**Поділитися звітом:**

- **«Надіслати автору»** відкриває поштовий застосунок зі зведенням у вкладенні, адресованим розробнику.
- **«Експорт»** ділиться тим самим зведенням через звичайне меню «Поділитися» Android, щоб зберегти його чи надіслати куди завгодно.

**Примітка:** Все залишається на вашому пристрої, поки ви самі не надішлете чи не експортуєте дані - подробиці про приватність дивіться в FAQ.

## Як користуватися картою пам'яті або під'єднаним накопичувачем

Карта пам'яті або USB-накопичувач, під'єднаний до телефона, зберігає ресурси так само, як вбудована пам'ять.

**Кроки:**

1. Відкрийте **«Додати ресурс»** і почніть додавати локальну папку. Розділ **«Знімні носії»** з'являється, лише поки щось під'єднано, і перелічує кожен том з іменем та вільним місцем.
2. Натисніть на том. Якщо застосунок не може звернутися до нього за шляхом, він пояснить причину і відкриє системний вибір папки - виберіть там той самий том і надайте доступ до потрібної папки.
3. Ресурс з'явиться у списку зі значком знімного носія, тож ресурс на карті впізнається з першого погляду.

**Перенесення і копіювання:** цілі папки переносяться на карту й назад з усією структурою вкладеності - так само, як між пристроєм і мережевим ресурсом.

**Якщо місця бракує:** копіювання або перенесення, яке не вміщується, відхиляється до початку, і в повідомленні названо носій та обсяг нестачі - звільніть місце або виберіть інше призначення.

**Якщо носій вилучено:** його ресурси позначаються недоступними, а не видаляються. Під'єднайте карту знову - вони працюватимуть без повторного налаштування.

**На Android 6:** система не повідомляє застосункам про під'єднані томи, тому розділ знімних носіїв на таких пристроях залишається порожнім.

## Як обрати місце збереження знімків та завантажень

Фото з вбудованої камери, скриншоти, знімки кадру та файли автозавантаження - кожне пишеться в обрану вами папку, і ця папка не обов'язково має бути одним із ваших ресурсів.

**Кроки:**

1. Відкрийте налаштування того, що зберігаєте - зйомку, скриншот, знімок або автозавантаження.
2. Оберіть папку призначення. Відкриється системний вибір папки, тож можна вказати будь-яку локальну папку, навіть ту, яку ви ще не додавали в застосунок.
3. Ця папка стає місцем запису лише для цього налаштування. Вона не потрапляє до загального списку ресурсів, тож обрана для скриншотів службова папка не захаращує головний екран.

**Поради:**

- У кожного з чотирьох налаштувань своє власне призначення - скриншоти й фото з камери можуть потрапляти в геть різні місця.
- Спрямувати кілька з них в одну папку теж можна, якщо вам зручніше тримати все в одному місці.

### Імена файлів захоплення

Нові результати захоплення отримують ім'я за шаблоном `префікс_yyMMdd_HHmmss`. Сталі префікси - `photo`, `screenshot`, `audio`, `video`, `screen_video` і `video_frame`, тому з імені зрозуміле джерело файла. Якщо таке ім'я вже є в папці призначення, застосунок додає перед розширенням суфікс ` (2)`. Ім'я, введене вручну в камері, лишається перевизначенням і не змінюється.

## Як отримати файли з іншого застосунку

Меню «Поділитися» будь-якого застосунку може надіслати файли до FastMediaSorter, а той скопіює їх туди, куди ви скажете.

**Кроки:**

1. В іншому застосунку поділіться файлом чи файлами та оберіть **FastMediaSorter**.
2. На екрані прийому оберіть папку призначення.
3. Почніть копіювання.

**Не обов'язково чекати завершення.** Копіювання триває й після закриття екрана прийому: сповіщення показує прогрес під час роботи, а після завершення приходить сповіщення з результатом. Можна вийти із застосунку, заблокувати пристрій, зайнятися іншим - перенесення не прив'язане до відкритого екрана.

Доступно в збірках Standard, Lite, Photos та Legacy.

## Як користуватися вбудованими програмами

**Доступно в:** усіх флейворах - меню програм і панель є в будь-якій збірці, але кожна програма слідує своїй можливості: Мережевий монітор потребує Standard або noLegal, Wear-супутник - Standard, Legacy або noLegal, а міні-гри немає в XR і noLegal. Калькулятор, фронтальний ліхтарик і відомості про систему є в кожній збірці.

Крім перегляду та відтворення файлів застосунок несе набір невеликих вбудованих програм - калькулятор, екранну лампу, мережевий монітор, диктофон та інші. За замовчуванням вони вимкнені: кожна вмикається своїм налаштуванням, і більшість окремих перемикачів зібрано в **Налаштування → Операції**.

**Швидкий шлях**

1. Відкрийте **Налаштування → Операції** й увімкніть потрібне - наприклад **Калькулятор**, **Фронтальний ліхтарик**, **Мережевий монітор**, **Міні-гру** або **Відомості про систему**.
2. Відкрийте випадне меню головного вікна. Увімкнені програми перелічені там.
3. Натисніть на програму, щоб запустити її.

**Де з'являється програма**

Програма може пропонуватися на чотирьох поверхнях, і кожна поверхня бере склад і порядок з одного й того самого списку, тому вони ніколи не розходяться:

- **Меню програм** - випадне меню головного вікна та панель програм, що його повторює.
- **Панель запуску** - оверлей швидкого доступу.
- **Віджет на домашньому екрані** - лише для тих програм, у яких він є; закріплюється з власного вибору віджетів застосунку.
- **Робочий стіл лаунчера** - якщо застосунок працює як домашній екран, увімкнення програми додає її комірку автоматично.

**Що входить до набору**

У порядку відображення:

- **Швидка зйомка** - зняти фото одразу в застосунок.
- **Запис із диктофона** - записати голосову нотатку.
- **Калькулятор** - науковий калькулятор з історією та комірками пам'яті.
- **Мережевий монітор** - живі показання активного каналу, Wi-Fi, мобільної мережі, Bluetooth і геолокації.
- **Фото-OCR-переклад** - зняти текст і перекласти його.
- **Відеозапис екрана** - записати екран.
- **Завантажити за посиланням** - завантажити файл за вставленим посиланням.
- **Міні-гра** - невелика гра, вбудована в застосунок.
- **Відомості про систему** - звіт про пристрій, доступний без заходу в налаштування.
- **Wear-супутник** - екран годинника, у збірках з мостом до годинника.
- **Фронтальний ліхтарик** - перетворює сам екран на лампу: відкривається білим на повній яскравості вікна, вертикальний свайп змінює яскравість, маленька кнопка ліворуч угорі вибирає та запам'ятовує інший колір, одиночне натискання закриває. Торкається лише яскравість вікна, тому системне налаштування після закриття лишається попереднім.

Панель і лаунчер додатково несуть прямі дії камери - зняти фото та надіслати, зняти та відредагувати, зняти та перекласти, почати відеозапис, відкрити теку камери.

**Коли це допомагає**

- Потрібен калькулятор або ліхтарик, не виходячи із застосунку і не розшукуючи окрему програму на переповненому телефоні.
- Застосунок працює як домашній екран, і хочеться комірку в одне натискання для часто використовуваного інструмента.

**Чого не робити**

- Не шукайте фронтальний ліхтарик у випадному меню - він пропонується лише на панелі запуску та на робочому столі лаунчера.
- Не чекайте кожну програму в кожній збірці - список вище повний, а збірка без відповідної можливості просто не показує цей рядок.
