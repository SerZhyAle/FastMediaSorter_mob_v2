# ⚠️ Обмеження програми

У цьому документі описані поточні технічні обмеження, функціональні особливості та рекомендації щодо продуктивності FastMediaSorter v2.

---

## 📱 Системні вимоги
- **Версія Android:** Для Standard / Lite / Photos потрібен Android 8.0 (API 26) або новіший. Флейвор Legacy розширює підтримку до Android 6.0 (API 23) або новіший. Для VR / noLegal потрібне підтримуване XR-обладнання та поточний runtime-путь для вашої збірки.
- **Обладнання:** Продуктивність може відрізнятися залежно від процесора та обсягу оперативної пам'яті, особливо для великих колекцій (5000+ файлів).
- **Доступ до сховища:** Для повної функціональності на нових версіях Android потрібен дозвіл «Доступ до всіх файлів» (MANAGE_EXTERNAL_STORAGE).

---

## 🌐 Мережа та хмара

### Підтримка протоколів
- **SMB:** Найкраща продуктивність у локальній мережі Wi-Fi. Підтримуються SMB v2/v3 (v1 застарів, але може працювати в деяких конфігураціях).
- **Хмара (Google Drive, OneDrive, Dropbox):** Файли транслюються або кешуються за запитом. Фонова синхронізація для офлайн-використання відсутня.
- **Скасування операції:** Функція «Скасувати» для операцій переміщення/видалення **НЕДОСТУПНА** для мережевих та хмарних ресурсів. Видалені файли видаляються безповоротно (якщо сервер не надає власний кошик).

### Вимоги до інтернету
- **Локальні файли:** Працюють повністю офлайн.
- **Мережа/Хмара:** Потрібне активне підключення.
- **OCR/Переклад:** Потрібне одноразове підключення до інтернету для завантаження мовних моделей (~15-50 МБ залежно від мови).

## 📂 Підтримка файлів та медіа

### Формати та кодеки
- **Зображення:** Стандартні формати (JPG, PNG, WEBP, GIF). **RAW-формати (CR2, NEF тощо) НЕ підтримуються.**
- **Відео:** MP4, MKV, MOV. Якщо файл використовує непідтримуваний кодек (наприклад, HEVC на старих пристроях), ви можете побачити чорний екран. **Рішення:** Використовуйте опцію «Відкрити у зовнішньому плеєрі».
- **Текст:** Великі текстові файли (>100 МБ) можуть завантажуватися повільно у внутрішньому переглядачі.
- **EPUB:** Підтримуються лише EPUB-файли без захисту DRM. Зашифровані книги або книги із захистом DRM не відкриються.

### Великі колекції
- **Продуктивність:** У папках із 5000+ файлів може спостерігатися затримка прокручування під час генерації мініатюр.
- **Кеш мініатюр:** За замовчуванням обмежений 2 ГБ (налаштовується в налаштуваннях).

## 🛠️ Функціональні обмеження

### Обране
- **Тільки локально:** Обране зберігається в локальній базі даних на вашому пристрої. Воно не синхронізується із самими файлами або між різними пристроями.

### Система кошика
- **М'яке видалення:** Локальні файли переміщуються до прихованої папки `.trash/`. Це займає місце доти, доки ви вручну не виберете «Очистити кошик» у налаштуваннях.

### Додаток для Wear OS
- **Обмежений масштаб:** Супутній додаток для Wear OS наразі підтримує **тільки локальні медіафайли**. Мережеві та хмарні ресурси недоступні з годинника.
- **Продуктивність:** Обробка зображень і відео на годиннику значно повільніша, ніж на телефонах.

### VR-редакція

- **Обладнання:** Запускається тільки на Meta Quest 2/3/Pro та гарнітурах Android XR (`arm64-v8a` + OpenXR-рантайм). На телефоні без XR-рантайму додаток показує екран-заглушку і не стартує відтворення.
- **Дистрибуція:** Два канали — Meta Horizon Store / Google Play (флейвор `vr`, Store-clean: без GPL-екстракторів та yt-dlp) і ADB sideload (флейвор `noLegal`, все включено: VR + Python + yt-dlp + GPL-екстрактори, runtime-gate на пристроях без OpenXR).
- **Немає Wear OS companion:** у шоломів немає парного годинника.
- Повний перелік обмежень — у [VR Edition](VR_EDITION_UK.md).

## 🧩 Моделі AI та OCR
- **Рушії:** Додаток використовує гібридний рушій (ML Kit + Tesseract).
- **Затримки:** Ініціалізація Tesseract (для кирилиці) займає на 1-2 секунди більше часу, ніж ML Kit.
- **Точність:** Якість розпізнавання сильно залежить від чіткості зображення та освітлення.
