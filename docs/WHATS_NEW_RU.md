# Что нового в FastMediaSorter v2

**Текущий релиз: 2.60.5030.230** (май 2026)

> Изменения относительно версии 2.60.422.246

---

## Что нового

- **Переназначение клавиш** — новый экран в Настройках для переназначения любого управления; определение конфликтов, иерархический сброс; 70 встроенных привязок по умолчанию
- **Полная поддержка клавиатуры, мыши и геймпада** — все экраны (Обзор, Плеер, Настройки, диалоги); оверлей F1 с подсказками; навигация D-pad в списках
- **Захват фото в Обзоре** — сделать снимок камерой и сохранить его сразу в текущий ресурс
- **Случайное воспроизведение в Обзоре** — кнопка быстрого запуска для однотипных библиотек (аудио/видео); горячая клавиша Ctrl+P
- **Быстрый старт по иконке ресурса** — нажатие на значок типа ресурса мгновенно запускает воспроизведение или слайдшоу
- **Автозагрузка по ссылке** — поделиться любым http(s)-URL в приложение; медиафайл скачивается автоматически
- **Режим одного глаза для 3D** — новая настройка для обрезки стерео до одного глаза на обычных экранах (видео + изображения)
- **Реструктуризация Настроек** — «Files & Data» разделён на «Permissions» + «App Data»; «File Operations» → «Copy & Move»; Safe Mode перенесён в Operations

## Что исправлено

- Эффекты цвета/яркости видео (Hue/Brightness) не применялись при смене трека (исправление deferral-логики Media3)
- Сортировка RANDOM не перетасовывала список при повторных нажатиях
- Загрузка снятых фото на сетевые ресурсы (SMB / FTP / SFTP)
- Зависание ScheduledOperationsWorker при гонке WAKE_LOCK
- Падение при печати на Android 8 (API 26–27)
- Ошибки при SMB-сканировании теперь выводятся как Snackbar с количеством вместо тихого игнорирования
- WebView для EPUB создаётся лениво (предотвращает OOM на устройствах с малым объёмом памяти)
- ExoPlayer пересоздаётся каждые 4 трека для предотвращения OOM в длительных сессиях
- Выбор плеера по умолчанию: исправлена петля самовызова (приложение открывало собственный probe-файл)

## Плеер

- **Диалог «Управление»** — новый единый диалог (Громкость, Яркость, Скорость, Субтитры, 3D) для видео и аудио. Вертикальный список секций слева, изменения применяются сразу. Кнопки быстрой установки громкости 50%/MAX, кнопка Mute с визуальной подсветкой
- **Диапазон скорости** расширен до 3.0x (добавлены шаги 2.5x и 3.0x)
- **Цвет и яркость видео** — регулировка Hue и Brightness через Media3 GPU-эффекты, значения сохраняются между видеофайлами
- **Сохранить кадр** — снимок текущего кадра видео в PNG или JPG, сохраняется в выбранный ресурс (локальный или сетевой). Настройка формата и папки назначения — в Video Settings
- **Печать** — документы (PDF, TXT, изображения) можно отправить на печать прямо из плеера; сетевые и облачные файлы предварительно загружаются в кэш
- **Случайный файл** — кнопка (иконка кубика) для перехода на случайный файл в списке; видна в аудио- и фотобиблиотеках
- **Автоскрытие названия файла** — оверлей с именем скрывается автоматически: TEXT 5 с, PDF/EPUB 10 с, остальные 15 с. Таймер сбрасывается при паузе и зуме
- **File Info для видео** дополнено: соотношение сторон, аудиоканалы, битрейт. Для аудио: альбом и частота дискретизации
- **Детекция 3D-контента** по имени файла (SBS/OU/360) с уведомлением
- **Исправлена навигация «Назад»** в текстовом ридере — без пустого экрана

## SMB / Сеть

- **Адаптивный таймаут SMBJ** — 3 уровня (5с/10с/20с) в зависимости от скорости соединения; значительно меньше ложных обрывов на медленных NAS
- **Исправлена ошибка «Broken pipe»** — сброс кэшированного TCP-соединения перед повторным открытием файла
- **Watchdog 12с (open) + 15с (read)** в SMB: ExoPlayer больше не зависает в STATE\_BUFFERING при тихом обрыве сети
- **Исправлена классификация ошибок**: вложенные исключения распознаются правильно (было «нет сети» вместо «таймаут»)
- **Исправлено переполнение** при чтении файлов >2 ГБ через SMB

## Добавление ресурсов

- **Коллапсируемые секции** в форме добавления SMB/SFTP (Условия, Типы медиа, Дополнительно)
- **Quick Setup профиль** теперь сохраняется в базу данных (раньше не применялся)
- **Read-only SMB** — при добавлении ресурса только для чтения показывается информационное сообщение вместо ошибки
- **«Запомнить список файлов»** теперь есть в форме добавления, как и в редакторе

## Обзор файлов

- **Перетаскивание ресурсов** — ручная сортировка drag & drop; переход в режим MANUAL автоматически
- **Решаффл RANDOM** — повторное нажатие на RANDOM-сортировку даёт новый порядок файлов
- **Иконка кубика** для отображения активного RANDOM-режима
- **Исправление фильтра**: смена фильтра больше не сбрасывает уже загруженный SMB-список

## Аудио

- **Уведомление о воспроизведении** — название трека и обложка отображаются в системном уведомлении
- **Нажатие на уведомление** возвращает к плееру из фонового режима
- **Панель Now Playing** управляется отдельной настройкой; для аудио скрыта по умолчанию
- **Метаданные аудио** (Artist/Album/Title) кэшируются в базе данных и отображаются мгновенно при открытии

## Настройки

- **«Возобновлять при запуске»** — новая настройка в Playback Settings
- **Настройки кадра** — выбор ресурса-назначения и формата (PNG/JPG) в Video Settings
- **Исправлена навигация «Назад»** из Settings на главный экран
- **Исправлен** спиннер языка: больше не срабатывает при открытии экрана

## Производительность и стабильность

- **Адаптивная предзагрузка** для сетевых файлов — автоматический расчёт буфера по скорости соединения и размеру файла. Настройки: General Settings → Prefetch Cache
- **Stream Offload** — возможность скачать сетевой файл в локальный кэш с прогрессом и предложением очистки после просмотра
- **DTS/DTS-HD** — поддержка через кастомную сборку FFmpeg, программное декодирование на любом устройстве
