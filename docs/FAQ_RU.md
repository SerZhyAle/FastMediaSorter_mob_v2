# ❓ Часто задаваемые вопросы (FAQ)

---

## Общие вопросы

### Что такое FastMediaSorter?
FastMediaSorter v2 - это Android-приложение для быстрой организации фото, видео и аудио файлов из локальных папок, сетевых дисков (SMB/SFTP/FTP) и облачных хранилищ (Google Drive, OneDrive, Dropbox).

### Это бесплатно?
Да! FastMediaSorter v2 полностью бесплатен и имеет открытый исходный код.

### Какая версия Android требуется?
Android 8.0 (API 26) или новее. Версия **Legacy** поддерживает Android 6.0 (API 23) или новее.

### Нужен ли интернет?
**Нет** для локальных файлов. **Да** для сетевых дисков и облачных хранилищ.

### Есть ли в приложении виджеты?
Да! FastMediaSorter v2 предлагает **два типа виджетов**:
1. **Виджет "Ярлык ресурса"**: Быстро открывает любую из ваших добавленных папок (Локальные, Сетевые или Облачные) прямо с домашнего экрана.
2. **Виджет "Продолжить чтение"**: Запускает приложение и сразу начинает слайд-шоу - идеально для быстрых сеансов просмотра фото.

## Операции с файлами

### Куда попадают удалённые файлы?
Удаленные файлы перемещаются в папку `.trash/` в том же расположении (мягкое удаление). Они не удаляются окончательно, пока вы не:
- Нажмете **"Очистить корзину"** в Настройках → Быстрая сортировка, ИЛИ
- Вручную удалите папку `.trash/`

### Можно ли отменить удаление/перемещение?
**Да!** Нажмите кнопку **"Отмена"** (или нижнюю правую сенсорную зону) в течение нескольких секунд после операции.

> ⚠️ **Примечание:** Отмена недоступна для удаления сетевых файлов (они удаляются сразу и безвозвратно).

### В чем разница между Копированием и Перемещением?
- **Копирование:** Создает дубликат, оригинал остается на месте.
- **Перемещение:** Переносит файл, удаляя его из исходного места.

## Сеть и Облако

### Как подключиться к домашнему NAS (сетевому диску)?
1. Настройки → Добавить папку → **SMB/Сетевой диск**
2. **Вариант А - Автоматический:** Нажмите **"Сканировать сеть"**, чтобы автоматически обнаружить доступные устройства в вашей сети
3. **Вариант Б - Вручную:** Введите адрес сервера: `\\192.168.1.100\share` или `smb://192.168.1.100/share`
4. Введите имя пользователя и пароль
5. Нажмите "Подключиться"

**Частые проблемы и решения:**

| Проблема | Что попробовать |
|---------|----------------|
| "В соединении отказано" | Откройте Брандмауэр Windows → разрешите **TCP-порт 445** входящий. Или временно отключите брандмауэр для теста |
| "Неверный пароль" | Попробуйте оставить имя пользователя пустым (гостевой доступ). При учётной записи Microsoft вводите **полный email** как логин |
| "Хост не найден" | Убедитесь, что телефон и ПК подключены к **одному роутеру**. AP Isolation (функция безопасности роутера) может блокировать связь между устройствами - отключите её в настройках роутера |
| Сканирование ничего не нашло | Отключите VPN на телефоне. Включите **Сетевое обнаружение** в Windows (Панель управления → Центр управления сетями → Параметры общего доступа). Затем введите IP вручную |
| Очень медленный просмотр | Откройте редактирование ресурса → запустите **Тест скорости**. Если менее 5 Мбит/с - переключите телефон на диапазон 5 ГГц Wi-Fi. Отключите миниатюры видео для медленных соединений |
| Работает по Wi-Fi, но не по мобильному | Ожидаемо - SMB работает только в локальной сети, через мобильный интернет не работает |

→ Подробное руководство: [Настройка SMB](howto/scenario-smb-setup-ru.md)

### Как подключиться к Google Drive?
1. Настройки → Добавить папку → **Google Drive**
2. Нажмите "Войти через Google"
3. Предоставьте разрешения при запросе
4. Ваши папки Drive появятся в списке

**Примечание:** Файлы НЕ скачиваются автоматически - они транслируются по запросу.

### Как подключиться к OneDrive?
1. Настройки → Добавить папку → **OneDrive**
2. Нажмите "Войти через Microsoft"
3. Предоставьте разрешения при запросе
4. Ваши папки OneDrive появятся в списке

### Как подключиться к Dropbox?
1. Настройки → Добавить папку → **Dropbox**
2. Нажмите "Войти через Dropbox"
3. Предоставьте разрешения при запросе
4. Ваши папки Dropbox появятся в списке

### Можно ли использовать SFTP или FTP?
**Да!** Выберите **SFTP** или **FTP** при добавлении папки:
- **SFTP:** Безопасный, требует SSH-сервер (порт 22)
- **FTP:** Менее безопасный, старый протокол (порт 21)

### Почему миниатюры для сетевых файлов не загружаются?
Сетевые миниатюры генерируются **по запросу** для экономии трафика. Листайте медленнее или подождите несколько секунд.

Если миниатюры не появляются вообще:
- Проверьте, открывается ли папка - если да, соединение в порядке
- Откройте редактирование ресурса → убедитесь, что **"Загружать миниатюры"** включено
- При очень медленном соединении: отключите миниатюры полностью, чтобы избежать таймаутов (редактирование ресурса → отключить миниатюры)

### Соединение постоянно обрывается / файлы не открываются в середине воспроизведения
- Проверьте стабильность Wi-Fi - телефон не должен переключаться между диапазонами 2,4 и 5 ГГц
- Некоторые роутеры обрывают неактивные SMB-сессии - при редактировании ресурса включите **"Переподключаться при ошибке"** (если есть)
- Для воспроизведения видео через SMB: запустите Тест скорости (редактирование ресурса → Тест скорости). Для 1080p-видео нужно не менее 10 Мбит/с

## Быстрая сортировка и Назначения

### Что такое папки "Быстрой сортировки"?
Папки быстрой сортировки - это заранее настроенные целевые папки для быстрой сортировки файлов. Вы можете назначить до 30 папок с пронумерованными кнопками.

### Как настроить Быструю сортировку?
**Способ 1:** Настройки → Быстрая сортировка → "Добавить в быструю сортировку"  
**Способ 2:** Редактировать любую папку → Включить "Пометить для быстрой сортировки"

### Как использовать Быструю сортировку при просмотре?
1. Откройте фото/видео на весь экран
2. Нажмите **цифровую кнопку** (0-9) на панели команд, ИЛИ
3. Нажмите **нижний левый угол** (зона КОПИРОВАНИЯ) или **нижний центр** (зона ПЕРЕМЕЩЕНИЯ)

### Кнопки Быстрой сортировки не отображаются
Убедитесь, что добавлена хотя бы одна папка-назначение: Настройки → Быстрая сортировка → **"Добавить в быструю сортировку"**. Кнопки появляются только при наличии хотя бы одного назначения.

### Я случайно отправил файл не в ту папку
Нажмите **Отмена** сразу (нижний правый угол панели команд) - доступно несколько секунд после операции. Если время упущено - откройте папку-назначение и переместите файл обратно вручную.

## Сенсорные зоны (Touch Zones)

### Что такое "Сенсорные зоны"?
Сенсорные зоны - это невидимые области на экране, которые выполняют действия при нажатии. Экран разделен на сетку 3x3:

```
┌─────────┬─────────┬─────────┐
│  ПРЕД.  │ КОМАНДЫ │  СЛЕД.  │
├─────────┼─────────┼─────────┤
│  КОПИЯ  │  ИНФО   │ УДАЛИТЬ │
├─────────┼─────────┼─────────┤
│ ПЕРЕМЕСТ│  МЕНЮ   │  ИГРАТЬ │
└─────────┴─────────┴─────────┘
```

### Как увидеть Сенсорные зоны?
Настройки → Воспроизведение → Включить **"Всегда показывать зоны нажатия"**

### Можно ли отключить Сенсорные зоны?
Да, просто используйте **кнопки панели команд**. Сенсорные зоны опциональны.

## Управление и ввод

### Поддерживаются ли физические клавиатуры и геймпады?
**Да!** Полная поддержка клавиатуры, мыши и геймпада на всех экранах. Нажмите **F1** на любом экране, чтобы увидеть активные привязки для этой области.

### Как переназначить клавиши управления?
Настройки → **Input** → **Keybindings** - переназначьте любое действие на другую клавишу, кнопку или ввод геймпада. В приложении 70 встроенных привязок по умолчанию; нажмите **Reset** для восстановления. Конфликты подсвечиваются автоматически.

### Как скачать медиафайл по ссылке?
Поделитесь любой ссылкой `http(s)` в FastMediaSorter через «Поделиться» Android (из браузера, мессенджера или любого приложения). FastMediaSorter скачает файл и предложит сохранить его в один из ваших ресурсов.

## Производительность и Память

### Как найти файл по имени?
Используйте панель **Фильтр** в Browse: нажмите иконку фильтра на панели инструментов, введите часть имени файла в поле имени - список обновляется мгновенно. Отдельной строки поиска нет, фильтр полностью покрывает этот сценарий.

### Почему приложение тормозит с 5000+ файлов?
Приложение использует **пагинацию** для загрузки файлов частями. Для очень больших коллекций:
- Включите "Отключить миниатюры" для этой папки
- Используйте фильтры для сужения результатов
- Отсортируйте по дате (сначала новые) - так последние файлы загружаются первыми, без сканирования всей папки

### Приложение падает или зависает
1. Принудительно закройте и снова откройте приложение
2. Если падение происходит на конкретной папке: возможно, там есть повреждённый файл - попробуйте открывать файлы по одному, чтобы найти проблемный
3. Очистите кэш: Настройки → Общие → **"Очистить кэш"** - решает большинство проблем со стабильностью после обновлений
4. Если падения продолжаются: сообщите через GitHub Issues (ссылка внизу страницы) - опишите, что вы делали в момент сбоя

### Сколько места занимает кэш миниатюр?
**По умолчанию:** 2 ГБ (настраивается в Настройках)

### Как очистить кэш?
Настройки → Общие → **"Очистить кэш"**

## Автоматический перевод

### Как работает перевод?
Мы используем **Гибридную систему OCR**:
- **Google ML Kit:** Для быстрого и точного распознавания языков на основе латиницы (Английский, Немецкий и т.д.).
- **Tesseract:** Для высококачественного распознавания кириллицы (Русский, Украинский).

### Почему рекомендуется режим "Auto"?
Режим "Auto" автоматически определяет исходный язык и выбирает лучший движок. Это предотвращает ошибки, такие как путаница английской 'C' и русской 'С'.

### Работает ли это без интернета?
**Да.** Интернет нужен только один раз для загрузки языковых моделей (около 30МБ для ML Kit, 15МБ для Tesseract).

### Почему перевод иногда работает медленнее?
Если приложение обнаруживает кириллицу, оно инициализирует движок Tesseract, который мощнее, но требует на 1-2 секунды больше времени для запуска, чем ML Kit.

### Что такое режим перевода "в стиле линзы"?
**Режим линзы** отображает переводы в виде наложения поверх исходного изображения, аналогично Google Lens. Это позволяет видеть переведенный текст в исходном контексте и позиции. Вы можете включить его в Настройках → Документы → Перевод → "Наложение в стиле линзы".

**Стандартный режим** показывает переводы в отдельном текстовом поле под изображением.

## Фоновая музыка для слайд-шоу

### Как добавить фоновую музыку к слайд-шоу?
1. Добавьте папку с аудио файлами как ресурс
2. Перейдите в Настройки → раздел **Аудио**
3. Включите **"Фоновая музыка для слайд-шоу"**
4. Выберите ваш музыкальный ресурс из выпадающего списка
5. Запустите любое слайд-шоу - музыка будет играть автоматически!

### Можно ли использовать музыку с сетевых дисков или облачных хранилищ?
**Да!** Приложение автоматически обрабатывает сетевые файлы, загружая их в кэш перед воспроизведением. Это работает с SMB, SFTP, FTP, Google Drive, OneDrive и Dropbox.

### Как переключать треки во время слайд-шоу?
Нажмите на **название трека**, отображаемое во время слайд-шоу, чтобы переключиться на другой случайный трек из вашего музыкального ресурса.

### Работает ли это со всеми версиями?
**Нет.** Фоновая музыка доступна только в:
- **Standard** (полная поддержка аудио)
- **Legacy** (только локальное аудио)

Версии **Lite** и **Photos** не включают аудио функции.

## Wear OS

### Работает ли FastMediaSorter на умных часах Wear OS?
**Да!** FastMediaSorter v2 включает приложение-компаньон для Wear OS, которое позволяет просматривать и воспроизводить локальные медиафайлы прямо с ваших умных часов.

### Какие функции доступны на Wear OS?
Приложение для Wear OS в настоящее время поддерживает:
- Просмотр локальных папок
- Просмотр изображений
- Воспроизведение видео
- Воспроизведение аудио файлов
- Базовые элементы управления навигацией

**Примечание:** Функции сети и облака пока недоступны на Wear OS.

## Электронные книги EPUB

### Как включить поддержку EPUB?
Настройки → раздел **Документы** → Включите **"Поддержка EPUB"**

**Примечание:** Перезапустите приложение после включения для применения изменений.

### Как читать книгу EPUB?
1. Добавьте папку с .epub файлами как ресурс
2. Откройте папку - вы увидите EPUB файлы со значком "E"
3. Нажмите на любой EPUB файл для открытия в читалке

### Можно ли переключаться между главами?
**Да!** Используйте:
- **Кнопки Предыдущая/Следующая** внизу экрана
- **Свайп влево/вправо** для смены глав
- **Кнопка Оглавление** (иконка 📋) для открытия списка глав

### Можно ли настроить размер шрифта?
**Да!** Во время чтения используйте кнопки **-A/+A** внизу для уменьшения/увеличения шрифта (диапазон 14-32px). Настройки сохраняются для каждой книги.

### Можно ли искать текст в EPUB?
**Да!** Нажмите кнопку **Поиск** (🔍) для открытия панели поиска. Введите запрос и перемещайтесь по совпадениям кнопками Пред/След.

### Работает ли с сетевыми/облачными файлами?
**Да!** EPUB файлы автоматически загружаются в кэш при открытии с SMB/SFTP/FTP/облачных хранилищ.

### Запоминает ли место чтения?
**Да!** Приложение сохраняет последнюю главу, которую вы читали. При повторном открытии книги чтение продолжается с места остановки.

### Что насчет темной/светлой темы?
EPUB читалка автоматически адаптируется к теме приложения (Настройки → Внешний вид → Тема).

## Запланированные операции

### Что такое Запланированные операции?
Правила автоматизации на основе расписания, которые выполняют операции Копирования, Перемещения или Удаления между любыми ресурсами (локальные папки, сеть, облако) по повторяющемуся расписанию - даже когда приложение закрыто.

### Где настраивать Запланированные операции?
Настройки → **Операции** → раздел **Запланированные операции**. Нажмите **"+"** для добавления нового правила.

### Будет ли операция выполняться при закрытом приложении?
**Да.** Операции планируются через Android **WorkManager**, который запускает их в фоне независимо от состояния приложения.

### Почему запланированная операция не запустилась точно в срок?
Android может отложить задачи WorkManager на несколько минут для экономии батареи. Для более надёжного запуска предоставьте приложению исключение из оптимизации батареи (Настройки → Основные → Оптимизация батареи). Минимальный интервал - 15 минут.

### Операция выполнилась, но скопировала 0 файлов
Обычно это правильно - означает, что все файлы уже есть в папке-назначении (операция по умолчанию пропускает существующие). Проверьте журнал операции: посмотрите счётчик "пропущено" и "скопировано".

Если вы ожидали копирование новых файлов, но оно не произошло:
- Убедитесь, что в качестве **источника** выбрана правильная папка (рекомендуется виртуальный ресурс "Фото камеры", а не путь вручную)
- Проверьте, был ли доступен ресурс-назначение (SMB / облако) в запланированное время - если Wi-Fi был отключён, запуск пропускается и повторится в следующий раз

### Можно ли посмотреть, что было обработано?
**Да.** Нажмите **«Журнал»** в разделе Запланированных операций, чтобы увидеть историю каждого запуска с результатом по каждому файлу.
