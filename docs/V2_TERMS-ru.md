# Справочник терминов

## Основные термины

- **Resource** - подключённый источник файлов (Local/SMB/SFTP/FTP/Cloud)
- **Destination** - преднастроенная папка назначения для быстрой сортировки
- **Quick Sort** - copy/move в настроенные destinations одним нажатием
- **Favorites** - локально сохранённый список избранных файлов
- **Touch Zones** - интерактивные зоны 3×3 в режиме плеера
- **Soft Delete** - перенос локальных файлов в `.trash/` вместо мгновенного удаления
- **Лаунчер** - режим, в котором приложение заменяет домашний экран Android; кнопка «Домой» открывает рабочий стол приложения
- **Рабочий стол** - экран лаунчера с ячейками: ярлыками и гаджетами. Часть лаунчера, а не его синоним

## Дополнительные термины

- **Flavor** - вариант продукта (`standard`, `noLegal`, `lite`, `photos`, `legacy`, `vr`, `xr`, `foss`); [SDK](TECHNICAL_REQUIREMENTS_RU.html)
- **Browse** - экран списка/сетки файлов выбранного ресурса
- **Player** - полноэкранный просмотрщик медиа и документов

Практические инструкции: [HOW_TO_RU.html](HOW_TO_RU.html) и [FAQ_RU.html](FAQ_RU.html).
