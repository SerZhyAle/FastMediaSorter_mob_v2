# FastMediaSorter v2 - Полный список функций

*Последнее обновление: 2026-05-28*

Этот документ является каноническим перечнем всех пользовательских функций, реализованных в приложении. Он служит руководством по возможностям приложения и принципам работы каждой функции.

**Системные требования:** Android 8.0+ (API 26) для версий Standard, Lite и Photos. Версия Legacy поддерживает устройства от Android 6.0+ (API 23), сохраняя те же функции, но без облачных интеграций. Поддерживаемые устройства: смартфоны, планшеты, ТВ-приставки на Android TV и автомобильные магнитолы. Работает в Chrome OS через Google Play (ARC++).

## 1. Управление ресурсами и источниками

- **Поддержка различных типов ресурсов**: Подключение локальных папок, SMB (сетевые папки Windows/NAS), FTP, SFTP, Google Диск, Dropbox и OneDrive в едином интерфейсе.
- **Профили ресурсов (быстрая настройка)**: Настройка новых папок с помощью пресетов (Аудиотека, Видеотека, Фотоархив, Документы, Все файлы), которые автоматически применяют оптимальные параметры сортировки, фильтрации и отображения.
- **Виртуальная папка «Фото с камеры»**: Выделенная папка для просмотра всех фото и видео, снятых на камеру устройства.
- **Недавние и Загрузки**: Виртуальные папки, настроенные по умолчанию с параметром "Показывать все файлы", чтобы сразу отображать документы и другие немедийные форматы.
- **Синхронизация языка виртуальных ресурсов**: Названия по умолчанию (Все изображения, Все видео и т.д.) автоматически переводятся при смене языка приложения.
- **Индивидуальные настройки для каждой папки**: Настройка поддерживаемых типов медиа, сортировки, загрузки миниатюр, защиты ПИН-кодом и сканирования подпапок отдельно для каждого ресурса.
- **Порядок ресурсов**: Сортировка подключенных ресурсов на главном экране обычным перетаскиванием (drag-and-drop).
- **Тематические иконки ресурсов**: Назначаются автоматически по типу контента или выбираются вручную через панель инструментов.
- **Проверка соединения**: Проверка доступности сетевого или облачного ресурса перед его открытием.
- **Режим «Только чтение»**: Защита важных папок отключением функций редактирования, удаления и перемещения.
- **Защита ПИН-кодом**: Требование ввода ПИН-кода при каждом открытии указанного ресурса.
- **Менеджер сетевых учетных данных**: Зашифрованное хранилище паролей с отслеживанием даты последнего использования для аудита.
- **Сохранение и восстановление позиции просмотра**: Точное запоминание позиции прокрутки и последнего просмотренного файла; автоматическое открытие подпапки при возврате.
- **Кэширование списков файлов**: Сохранение структуры файлов в локальной базе данных для мгновенной загрузки крупных сетевых папок при повторном открытии.
- **Компактные операции с ресурсами**: Настройка сворачивает кнопки действий каждой планки ресурса в единое меню «⋮», уменьшая визуальный шум на небольших экранах и в портретной ориентации. В меню добавлен пункт «Обновить» для проверки доступности и обновления счётчика файлов одного ресурса без его открытия.

## 2. Просмотр медиа

- **Расширенные режимы сортировки**: Сортировка по имени, дате, размеру, типу, исполнителю, названию, длительности, дате съемки, в случайном или ручном порядке (по возрастанию/убыванию).
- **Память режима сортировки**: Выбранный режим автоматически сохраняется для каждого ресурса.
- **Расширенная панель фильтров**: Фильтрация элементов по подстроке в имени, диапазону дат, ограничениям размера или специфическим типам файлов.
- **Случайный выбор файла**: Специальная кнопка "кубик" в профилях Аудио и Фото для перехода к случайному файлу без включения режима полного перемешивания.
- **Множественный выбор**: Выделение файлов для пакетного копирования, перемещения, удаления или отправки (Share).
- **Показ подпапок как элементов**: Отображение подпапок прямо в списке файлов, либо отключение этой опции для "плоского" вида (рекурсивное сканирование).
- **Операции с подпапками**: Копирование, перемещение, переименование, удаление и создание подпапок прямо из браузера (для локальных, сетевых и облачных дисков).
- **Кнопка «Создать папку»** в тулбаре Browse - отображается для записываемых ресурсов с включёнными «каталогами как элементами»; создаёт папку в текущем подкаталоге.
- **Скрытые и все файлы**: Переключатель видимости скрытых системных файлов и режим обхода всех медиафильтров для управления архивами и бинарниками.
- **Передача Office-документов**: Открытие DOC, DOCX, RTF и ODT из FMS во внешнем приложении для документов, включая файлы из локальных, сетевых и облачных источников.
- **Умная загрузка миниатюр**: Превью для фото и кадров видео. Может быть отключена для экономии трафика в больших сетевых каталогах.
- **Быстрая заглушка для неподдерживаемого видео**: Форматы вроде AVI, не декодируемые по сети, сразу получают иконку файла вместо ожидания тайм-аута.
- **Автоматическое восстановление миниатюр**: Сбои извлечения превью во время активного стриминга устраняются автоматически после остановки воспроизведения.
- Миниатюры видео автоматически переключаются на более поздний кадр, если первый кадр оказался чёрным (чёрный лидер): проверяются отметки 5 с, 15 с и 30 с.
- **Оверлей метаданных**: Вывод EXIF, длительности, разрешения и размера файла прямо на элементах списка.
- **Отменяемое сканирование**: Сканирование крупных сетей показывает живой счетчик файлов с кнопкой мгновенной остановки "СТОП".
- **Встроенный мини-плеер**: Воспроизведение аудио прямо из списка ресурсов (в т.ч. сети и облака) без открытия полного плеера.
- **Полная поддержка клавиатуры**: Управление на всех экранах (Ввод, Esc, Стрелки, Backspace).
- **Классические ярлыки NC и цветные кнопки ТВ**: F5 (копировать), F6 (переместить), F7 (создать папку), F8 (удалить). Цветные кнопки пульта ТВ привязаны к этим же функциям.
- **Диалог справки F1**: Нажатие F1 на клавиатуре открывает список ярлыков для текущего экрана. Фокус ввода визуально выделяется кольцом.
- **Поддержка геймпадов**: Управление браузером и плеерами с геймпадов Xbox, DualSense и 8BitDo.
- **Сортировка перетаскиванием (drag-to-reorder)**: Произвольный порядок элементов в ручном режиме сортировки.
- **Переназначение кнопок ТВ-пульта**: Смена действий для цветных кнопок и переключения каналов в Настройках.
- **Ускорение прокрутки D-Pad**: Удержание кнопок Вверх/Вниз переключает построчную прокрутку на постраничную.
- **Детальный диалог свойств**: Показывает полные аудио метаданные для удаленных файлов, скачивая только первые ~64 КБ заголовка.
- **Многооконный режим**: Открывает Browse выбранного ресурса - или просмотрщик / плеер выбранного файла - в отдельном параллельном окне. Активируется там, где платформа сообщает о поддержке мультиоконности: ChromeOS / Chromebook (Googlebook), Samsung DeX, панели Android XR Home Space, панели VR Quest 3+. В таких средах включён по умолчанию; на телефонах и планшетах настройка по умолчанию выключена, но включается в Настройках.

## 3. Операции с файлами

- **Гибкое удаление**: Помещение файлов в Корзину с возможностью восстановления или их немедленное окончательное уничтожение. После удаления в Корзину файлы можно восстановить до 5 минут, затем фоновая задача удаляет их окончательно.
- **Переименование из отдельного плеера**: Смена имени файла прямо из автономного окна "Открыть с помощью" через системные API.
- **Отмена операций (Undo)**: Отмена последнего копирования, перемещения или удаления в один клик.
- **Безопасный режим**: Обязательные подтверждающие диалоги перед удалением или перемещением файлов на глобальном уровне.
- **Политика Корзины**: Выбор между перемещением удаленных локальных файлов в `.trash` или мгновенным удалением (освобождение места).
- **Политики перезаписи**: Настройка поведения при совпадении имен файлов (перезаписать, пропустить, переименовать с суффиксом).
- **Кросс-протокольные передачи**: Копирование и перемещение файлов между локальным диском, SMB, FTP, SFTP и облаками в любых комбинациях.
- **Поиск дубликатов файлов**: 3-этапный алгоритм (Размер -> Хэш части -> Полный SHA-256) гарантирует идеальное совпадение. Включает режимы обзора и авто-удаления.
- **Работа с ZIP-архивами**: Упаковка выбранных файлов в фоновый ZIP; извлечение архивов одним нажатием с прогресс-баром.
- **Выбор любой папки назначения**: Кнопка выбора локального каталога через системный диалог в обход преднастроенных кнопок.
- **Запись микрофона**: Запись аудио напрямую в текущую открытую папку (локальную, сеть или облако).
- **Захват камеры**: Съемка фото/видео через приложение камеры сразу в нужную сетевую или локальную директорию.
- **Прогресс-бар передачи**: Показывает байтовый процент, текущую скорость и сглаженное оставшееся время (ETA).
- **Взаимодействие плеера с файлами**: При перемещении или удалении играющего файла плеер корректно останавливается и переходит к следующему треку. При переименовании воспроизведение продолжается с новым именем.
- **Очередь файловых действий в плеере**: Перемещение, удаление и переименование принимаются сразу, выполняются по одному в фоне и больше не заставляют ждать, пока предыдущая операция ещё заканчивается.
- **Меню ⋮ для операций с файлами**: Необязательная настройка, сворачивающая кнопки копировать/переместить/переименовать/удалить в единую кнопку «⋮» на каждой строке файла; кнопка воспроизведения всегда остаётся отдельной.

## 4. Управление назначениями

- **Цветные кнопки назначений**: До 10 пользовательских кнопок в плеере для мгновенной сортировки файлов по заранее заданным папкам.
- **Авто-переход после копирования/перемещения**: Автоматическое открытие следующего файла сразу после завершения операции.
- **Сворачиваемая панель**: Скрытие панели перемещения для расширения области просмотра медиа.
- **Кнопка возврата «..»**: Возможность выбрать любую локальную папку без выхода из плеера.
- **Кнопка "Избранное"**: Добавление или удаление текущего файла из Избранного прямо в окне просмотра.
- **Преднастроенные Загрузки**: При установке системная папка Downloads автоматически добавляется первой кнопкой назначения.

## 5. Просмотр изображений

- **Обрезка по экрану**: Обрезка черных полос для заполнения дисплея, если ориентация картинки и экрана совпадают.
- **Динамический фон**: Математическая генерация размытого фона, подстраивающегося под цветовую палитру фотографии.
- **Вращение и отражение**: Поворот и зеркальное отражение картинки с деструктивным сохранением результата прямо в исходный файл.
- **Цветокоррекция и фильтры**: Настройка яркости, контраста и насыщенности, или применение фильтров Оттенки серого, Сепия и Негатив.
- **Встроенный OCR**: Распознавание текста с любой картинки (чеки, скриншоты) с помощью ML Kit и Tesseract.
- **Перевод в дополненной реальности (AR)**: Переведенные блоки текста накладываются точно поверх оригинальных надписей.
- **Переход в Google Объектив (Lens)**: Отдельная кнопка для передачи фото на анализ в Google Lens.
- **Кадрирование и сжатие**: Сохранение вырезанных фрагментов или создание легких копий (JPEG 70%, 1024px) через меню "Еще".
- **Рисование (аннотации)**: Инструменты кисть, прямоугольник, овал, ластик и текст с палитрой на 16 цветов и регулируемыми размером кисти, размером текста и прозрачностью. Сохранение поверх исходного файла или в новый файл, отмена последнего или всех изменений, отправка готового рисунка в Google Keep.
- **Создание нового рисунка из Browse**: Пустой холст `.jpg` можно запустить прямо из панели Browse в локальных, SMB, SFTP, FTP и облачных папках. Редактор открывается сразу с действиями Сохранить, Сохранить и закрыть, Сохранить и отправить, Поделиться и Отмена; для удалённых папок рисунок хранится локально до подтверждённого сохранения.
- **Иммерсивный режим**: Скрытие системных панелей при рисовании и кадрировании для освобождения экрана.

## 6. Просмотр GIF

- **Регулировка скорости**: Изменение скорости проигрывания GIF от 0.25× до 4× (скорость запоминается индивидуально).
- **Извлечение кадров**: Сохранение первого кадра как статичного изображения или полная распаковка анимации на отдельные картинки.

## 7. Видеоплеер

- **Сохранение позиции воспроизведения**: Восстановление точного момента, на котором было остановлено видео. (Очищается при досмотре до конца).
- **Режимы порядка**: Цикл списка, Остановка в конце, Случайный порядок и Повтор одного видео.
- **Восстановление прошлого сеанса**: При "холодном" старте приложение автоматически открывает сеть/облако, чтобы показать последнее активное видео.
- **Картинка-в-картинке (PiP)**: Сворачивание видео в плавающее окно при нажатии кнопки "Домой" (на Android 12+).
- **Настраиваемые сенсорные зоны**: Выбор областей экрана для переключения файлов, паузы и перемотки.
- **Единая панель управления**: Настройка громкости, аудиодорожки, субтитров, оттенка (HUE), яркости и скорости в одном окне.
- **Таймер сна**: Автоматическая пауза через 15-120 минут.
- **Сохранение кадра (скриншот)**: Захват текущего кадра видео как PNG-файла.
- **Определение 3D стерео**: Обнаружение Side-by-Side (SBS) и Over-Under (OU) видео. Функция обрезки до одного глаза для просмотра на плоских 2D дисплеях.
- **Распознавание метаданных 360°**: Поддержка Google Spatial Media в локальных файлах MP4.
- **Адаптивный буфер**: Замер скорости сети и опережающее кэширование. Предложение "Сохранить локальную копию" для проблемных соединений.
- **Переназначение управления**: Задание пользовательских действий для клавиатур, мышей и геймпадов в Настройках.
- **Оверлеи**: Вспомогательный счетчик FPS в плеере или VR; режим Черного экрана для слепого прослушивания видеофайлов.
- **Корректный роутинг VOB**: DVD .vob файлы обрабатываются без попыток распаковки через TS-схемы.
- **Переключатель поворота в плеере**: Быстрая блокировка или разблокировка авторотации прямо во время просмотра, без выхода из плеера.
- **Режим большие кнопки**: Переводит кнопки управления и верхнюю панель в полноширинный вид с двойной высотой - для автомагнитол и управления одной рукой.

## 8. VR Версия

- **Выделенная сборка**: VR-версия оснащена движком OpenXR для очков Meta Quest и других Android XR-шлемов.
- **Стереоскопическое воспроизведение**: Проигрывание 3D видео (SBS/OU, рыбий глаз VR180, равнопромежуточная 360°) и 3D-фотографий "из коробки".
- **Покадровый стерео-рендер**: Создание скриншотов с сохранением правильной перспективы.
- **Ручное переопределение форматов**: Диалог принудительного включения плоских или сферических форматов отображения.
- **Иммерсивный переключатель**: Мгновенное переключение видео из плоского окна в полномасштабный OpenXR-режим.
- **Точка входа в VR из плеера**: В XR-сборках на подходящих экранах плоского плеера появляется плавающий бейдж `VR` и запасной пункт overflow; при выключенном VR один раз показывается inline-подсказка с переходом в настройки.
- **VR Управление и HUD**: Работа с контроллерами, руками, клавиатурой или мышью. Информационный HUD, привязанный к повороту головы, с лучами прицеливания (raycast).
- **Воспроизведение видео в VR-кинозале**: Просмотр локального или подготовленного видео в режиме VR-кинозала на плоском экране внутри immersive-сцены.
- **Отслеживание рук (Hand Tracking)**: Автоматическое переключение на управление жестами щипка, когда контроллеры отложены в сторону.
- **Passthrough снимок**: Сохранение JPEG-фотографий с наружных камер смешанной реальности шлема (на Quest 3).

## 9. Аудиоплеер

- **Фоновое воспроизведение**: Постоянная фоновая служба (Foreground Service) с расширенным уведомлением.
- **Режимы порядка и кнопка Назад**: Сохранение цикла и шаффла. Настраиваемое поведение кнопки "Назад" (спрашивать/останавливать/продолжать).
- **Умные обложки**: Извлечение из ID3-тегов или скачивание из интернета (кэшируются локально).
- **Поиск и отображение текстов**: Вывод найденных текстов песен в полноэкранном не отвлекающем режиме.
- **Поиск в YouTube Music**: Вызов приложения YT Music с автоподстановкой названия текущего трека.
- **Отправка на Chromecast**: Стриминг аудио, изображений и локального видео на приемники Cast.
- **Визуальное сопровождение**: Трансляция случайных фото из заданной папки или аудиовизуализации (волны, полосы частот, пульсации).
- **Таймер сна и восстановление**: Плавная пауза перед сном; полное восстановление всей очереди воспроизведения после перезапуска приложения.
- **Панель «Сейчас играет»**: Мини-бар в браузере для вызова нижней шторки со списком очереди.

## 10. Слайдшоу

- **Таймер автоматической смены**: Интервалы от 1 секунды до 3600 секунд (настраивается глобально или для каждой папки индивидуально).
- **Случайный порядок**: Шаффл изображений и анимаций.
- **Фоновая музыка**: Назначение отдельной директории для непрерывного воспроизведения музыки в процессе слайдшоу.
- **Ожидание окончания видео/аудио**: Изображение не переключится, пока воспроизводящийся видеофайл не доиграет до конца.

## 11. Просмотр PDF

- **Режимы чтения**: Классическое листание страниц по горизонтали или непрерывная вертикальная прокрутка.
- **Панель навигации**: Выдвижная панель с превью страниц документа.
- **Темы**: Обычный режим, Ночной и Сепия.
- **OCR и Перевод**: Распознавание текста на странице и наложение перевода в стиле AR-линзы.
- **Чтение вслух (TTS)**: Озвучивание страницы с помощью системного синтезатора речи.
- **Печать**: Прямая передача PDF, текста или фото на принтер через системный интерфейс.

## 12. Просмотр EPUB

- **Навигация**: Панель с оглавлением и продвинутый поиск по всей книге.
- **Форматирование**: Переключение шрифтов (Обычный, С засечками, Моноширинный), регулировка межстрочного интервала и полей.
- **Темы**: Светлая, Темная, Сепия и Абсолютно Черная (OLED).
- **Сохранение позиции**: Фиксация точной позиции прокрутки для каждой главы.
- **Встроенный перевод и TTS**: Перевод выделенного текста или Чтение вслух (TTS) для целой главы.

## 13. Просмотр и редактор текста

- **Рендеринг**: Автоопределение кодировок (отсутствие кракозябр), отображение форматирования Markdown и подсветка синтаксиса кода.
- **Инструменты чтения**: Нумерация строк, темы экрана и изменение размера шрифта простым жестом (swipe).
- **Редактирование**: Правка текста, автосохранение и стек отмены/повтора (Undo/Redo) для локальных и сетевых документов.
- **Создание новой заметки из браузера**: кнопка «Новая заметка» в тулбаре браузера создаёт `.txt`-файл в текущей папке (локальной, SMB, SFTP, FTP или облачной) и сразу открывает его в редакторе. Сетевые заметки временно хранятся локально в Downloads/FastMediaSorter/notes/ до сохранения.
- **Диалог сохранения с переименованием**: кнопки «Сохранить», «Сохранить и закрыть», «Сохранить и отправить» показывают диалог подтверждения имени файла; конфликты имён разрешаются автоматически добавлением секундного суффикса.
- **Панель из 5 действий**: Сохранить, Сохранить и закрыть, Сохранить и отправить, Отправить в Keep, Отмена - с индикатором несохранённых изменений (красная подсветка панели).
- **Автоподгонка шрифта**: шрифт редактора начинается с максимального размера и автоматически уменьшается, чтобы контент умещался в область просмотра; жест горизонтального свайпа фиксирует выбранный размер вручную.
- **Панель поиска**: Встроенный поиск текста доступен как в самом приложении, так и в режиме автономного просмотрщика.

## 14. Перевод и OCR (Общая функция)

- **ML Kit и Tesseract**: Инструменты извлечения невыделяемого текста с картинок и PDF без выхода в сеть.
- **Автоопределение языка**: Самостоятельное вычисление исходного языка перед запуском перевода.
- **Офлайн-перевод**: Локальная обработка текста без интернета (при наличии скачанных языковых моделей).
- **AR оверлей**: Замена иностранного текста в PDF и на фото блоками перевода в тех же координатах.
- **Стилизация**: Настройка размера и семейства шрифта для результатов OCR.
- **Высококачественные модели Tesseract по запросу**: Динамическая загрузка больших качественных моделей (русского и украинского языков из репозитория `tessdata_best`) прямо из настроек. Файлы хранятся как пассивные данные в приватной папке приложения, проверяются по SHA-256 и не используют динамическую загрузку исполняемого кода; при ошибке OCR возвращается к встроенным стандартным моделям.

## 15. Сетевые источники

- **Ввод имён шар**: После сканирования хоста можно одним нажатием выбрать найденную SMB папку и продолжить заполнение ресурса; если ничего не найдено, сценарий показывает явную отмену, а ручной ввод остаётся доступным.
- **Поддержка SMB / FTP / SFTP**: Полноценный браузинг, передача и стриминг. В SFTP данные файлов читаются одним пакетом.
- **Автообнаружение**: Сканирование локальной подсети (порты 445, 21, 22) для поиска NAS.
- **Встроенный тест скорости**: Вычисление пиковой пропускной способности для рекомендации количества потоков копирования.
- **Параллелизм**: Разбивка передачи на 24 одновременных синхронных соединения.
- **Пул соединений SMB**: Кэширование аутентифицированных сессий (Connection pooling) и перехват разрывов соединений для бесшовного стриминга.
- **Периодическая синхронизация**: Фоновые задачи WorkManager для обновления локальной базы по изменениям в сети.
- **Поддержка Blu-ray TS (.m2ts)**: Трансляция файлов BDMV с сетевых источников с перекомпоновкой BD-TS пакетов на лету.

## 16. Облачные интеграции

- **Google Drive, Dropbox, OneDrive**: Выбор папок, стриминг, редактирование файлов из нативной архитектуры.
- **Единый OAuth вход**: Браузерная регистрация с зашифрованными ключами авторизации на устройстве.
- **Привязка Google-аккаунта**: один вход в Google для Drive и будущих Google-интеграций. Добавление новых папок Drive больше не требует повторной авторизации.
- **Сохранение состояния**: Экспорт всех настроек, избранного и подключенных дисков в Google Диск в формате JSON.

## 17. Избранное

- **Глобальный список**: Слияние в один интерфейс "Избранного" всех файлов, неважно, лежат они в телефоне, на NAS или в облаке.
- **Виджет**: Интерактивный прокручиваемый список прямо на домашнем экране.

## 18. Виджеты для домашнего экрана

- **Быстрый запуск (Resource Launch)**: Переход в конкретную папку или сетевой диск одним тапом.
- **Маяк продолжения (Continue Reading)**: Возврат к недочитанной книге или видео прямо с главного экрана.
- **Случайная Музыка и Камера**: Ярлыки для старта случайной музыки и открытия папки камеры.
- **App Shortcuts**: Долгое нажатие на иконку приложения открывает быстрые переходы к последним папкам.
- **Плитка быстрых настроек (Quick Settings)**: Управление фоновым аудио из системной шторки (Шумоподавление/Wi-Fi и т.д.).

## 19. Настройки

- **Экран приветствия**: Выбор языка при старте, карта зон касания экрана и гайд по возможностям приложения.
- **Дружелюбный текст**: Все ошибки и описания переписаны простым и понятным языком.
- **Детализированные параметры**:
  - **Медиа и Плотность**: Фильтры веса файлов и режим компактного UI-интерфейса.
  - **Воспроизведение и Назначения**: Глобальная сортировка, таймеры слайдшоу, автопереходы, настройки корзины.
  - **Безопасность**: Запрос подтверждения удаления, переключатели корзины.
  - **Сеть / Кэш**: Размеры выделенной памяти под миниатюры (вплоть до 16 ГБ), интервалы синхронизации.
- **Адаптивные диалоги**: Диалоги настроек превращаются в прокручиваемые списки при альбомной ориентации (Landscape).
- **Навигация клавиатурой**: Вся сетка настроек управляется стрелками, Tab, Ввод и встроенным окном поиска (Ctrl+F).
- **Журналы отладки**: Вывод расширенных ошибок (stack-trace) с функцией отправки разработчикам.
- **Управление поворотом экрана**: Следовать авторотации ОС или управлять ею независимо в текущем сеансе - быстрый переключатель прямо в плеере.

## 20. Поиск по настройкам

- **Сплошное индексирование**: Полнотекстовый поиск по всем вкладкам и меню настроек.
- **Прямая подсветка**: Переход к нужной опции в обход меню с желтой подсветкой искомого параметра.

## 21. Приложение для Wear OS

- **Автономный доступ**: Управление SMB, FTP, SFTP и облаками прямо с умных часов.
- **Просмотр на запястье**: Вывод картинок, слайдшоу и управление аудио/видео со смартфона.
- **Синхронизация**: Двусторонняя пересылка списка дисков и Избранного между часами и смартфоном по Wearable Data Layer.

## 22. Фоновые и системные службы

- **Авто-чистка**: Запланированное фоновое удаление файлов из Корзины, сброс кэш-мусора и отмена просроченных ключей.
- **Интеграция MediaStore**: Оповещение системной галереи Android после каждого удаления или перемещения файла.
- **Устойчивость БД и Кэши**: Фиксация прогресса аудио, PDF, видео, масштабируемые локальные кэши миниатюр и метаданных.
- **Перехват системных запросов (Intents)**: Регистрация приложения как плеера по умолчанию и получателя файлов Share.
- **Автоскачивание ссылок**: Загрузка медиа по расшаренным HTTP, HLS или DASH ссылкам, с WebView-авторизацией для хостов, где нужен вход.
- **Фоновая очередь загрузки по ссылкам**: После выбора авторизации приложение сразу возвращает пользователя в исходное приложение, а загрузка идёт в фоне. Уведомление прогресса отображается во время загрузки; по завершении показывается имя сохранённого файла или ошибка. Для хостов, требующих входа, в уведомлении есть кнопка «Войти» для повторной авторизации.
- Ссылки на публикации с несколькими медиа: скачивает реальное видео или изображения карусели вместо превью-картинки; если удалось извлечь только превью, предлагает авторизоваться (или войти заново) перед сохранением. Эквивалентные доменные алиасы распознаются автоматически.
- Несколько аккаунтов для одного хоста: сохраняйте отдельные авторизации для одного ресурса, например личную и рабочую; перед скачиванием приложение спрашивает, под каким аккаунтом загружать; сессии аккаунтов можно добавлять, переименовывать и удалять по отдельности в Настройках → Авторизации.
- При получении ссылки с незнакомого хоста предлагается войти: добавить авторизацию, пропустить сейчас или больше не спрашивать для этого сайта.
- Сайты, для которых выбрано «Не спрашивать», отображаются в списке авторизаций - запись можно удалить, чтобы предложение снова появлялось.
- **Функционал автономного плеера**: Удаление, переименование и кнопка "Открыть в FMS" доступны даже при запуске медиа из сторонних файловых менеджеров.

## 23. Запланированные операции

- **Cron-подобные задания**: Настройка регулярного копирования, перемещения или удаления (например, бекап фото на NAS каждую ночь).
- **Множественные фильтры**: Привязка правил только к Изображениям, Видео и т.д., ограничение по временному окну (созданные за последний час или день).
- **Сетевая поддержка**: Запуск обменов между NAS, SFTP, FTP, локальным хранилищем и облаками с проверкой доступности узла перед стартом.
- **Журналы выполнения**: Детальный лог операций с выводом предупреждающих индикаторов ⚠ на панели настроек в случае сбоев.

## 24. Замена других приложений (Сравнение)

FastMediaSorter объединяет в себе функции, для которых обычно требуется 5-10 отдельных программ:

### Фотогалерея (Заменяет Google Photos, Simple Gallery)
Поддерживает просмотр и слайдшоу, добавляя прямой доступ к NAS/облакам, защиту ПИН-кодом и запланированные передачи.

### Видеоплеер (Заменяет VLC, MX Player, Nova)
Стримит по сети с ExoPlayer (поддержка множества кодеков) + встроенный файловый менеджер (копирование, переименование в процессе просмотра).

### Аудиоплеер (Заменяет Poweramp, Musicolet)
Фоновое прослушивание, тексты песен, таймер сна с уникальной возможностью играть музыку с SMB/SFTP без ее локального скачивания.

### Файловый менеджер (Заменяет Solid Explorer, MiXplorer)
Предлагает работу с NAS в 24 потока и кросс-протокольные передачи без необходимости открытия медиа через сторонние программы-плееры.

### NAS / Облачный клиент (Заменяет Google Диск, Dropbox, Cx File)
Объединяет облака с сетевыми протоколами в единой среде с кэшированием пула соединений (SMB Connection pooling) и меноблачным копированием напрямую.

### Читалка PDF / EPUB (Заменяет Adobe Reader, Moon+)
Открывает книги с облака и серверов, имея на борту Темы оформления, чтение вслух (TTS), и OCR с AR-линзой для перевода.

### Дополнительно:
- **FTP/SFTP Клиенты**: Полностью заменяются встроенным протоколом.
- **OCR Инструменты (Google Lens)**: Заменяются модулем ML Kit внутри просмотрщиков.
- **Поиск дубликатов**: Заменяется встроенным 3-этапным SHA-256 алгоритмом для всех дисков.
- **Фоторамка / Слайдшоу**: Работает с NAS под любую фоновую музыку.
- **Медиакомбайн для ТВ (Kodi, Plex)**: Управляется пультом, воспроизводит все, не требует серверной части.

**Итог:** FMS предоставляет унифицированный пользовательский опыт глубокой интеграции с NAS и облаками, избавляя от необходимости постоянно переключаться между разными профильными программами.
