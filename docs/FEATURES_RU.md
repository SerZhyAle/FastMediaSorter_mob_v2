# FastMediaSorter v2 — Полный перечень возможностей

*Последнее обновление: 2026-03-16*

Данный документ является актуальным реестром всех пользовательских возможностей, реализованных в приложении. Обновляйте файл при добавлении или изменении любой функции.

---

## 1. Управление ресурсами (источниками)

- Добавление ресурсов следующих типов: **Локальная папка**, **SMB** (Windows-шара / NAS), **FTP**, **SFTP**, **Google Drive**, **Dropbox**, **OneDrive**
- Редактирование настроек ресурса после создания
- Удаление ресурса
- **Профили ресурса** (быстрые пресеты): Аудиотека, Видеотека, Фотохранилище, Документы, Все файлы
- **Настройки ресурса**: поддерживаемые типы медиа, режим сортировки, режим отображения, видимость панели команд, загрузка миниатюр, PIN-защита, режим «только чтение», комментарий, сканирование подпапок, кеширование списка файлов, показ подпапок как элементов, показ скрытых файлов
- **Изменение порядка ресурсов** — ручная перестановка перетаскиванием на главном экране
- **Фильтрация ресурсов** на главном экране (строка поиска/фильтра)
- Переключение между режимами **Список / Сетка** на главном экране
- **Проверка соединения** для сетевых и облачных ресурсов
- **Режим «только чтение»** — блокирует любые файловые операции для конкретного ресурса
- **PIN-защита** ресурса (запрос кода при открытии)
- **Управление учётными данными** сети — зашифрованное хранение; аудит отслеживает дату последнего использования и вывоображает устаревшие записи
- **Сохранение и восстановление позиции** в каталоге (позиция прокрутки + последний просмотренный файл)
- **Кеширование списка файлов** — сохранение в БД для ускоренной повторной загрузки

---

## 2. Просмотр медиафайлов

- Режимы отображения **Список** и **Сетка**
- **Режимы сортировки**: Имя ↑↓ / Дата ↑↓ / Размер ↑↓ / Тип ↑↓ / Исполнитель ↑↓ / Название ↑↓ / Длительность ↑↓ / Дата съёмки ↑↓ / Случайный / Ручной
- **Панель фильтра**: по подстроке имени, диапазону дат, диапазону размера, типу медиа
- **Множественный выбор** для пакетных операций
- **Навигация по подпапкам** с историей переходов
- **Показ подпапок как элементов** — отдельные кликабельные элементы для каждой подпапки
- **Показ скрытых файлов** (файлы и папки, начинающиеся с `.`)
- **Режим «Все файлы»** — игнорирует фильтр типов, показывает всё включая бинарные файлы
- **Рекурсивное сканирование** подпапок
- Загрузка миниатюр (автоматически отключается при > 10 000 файлов; можно отключить вручную для ресурса)
- **Миниатюры видео** из первого кадра (опционально; можно отключить для медленных сетей)
- **Метаданные файла** в строке списка (EXIF, длительность, разрешение, размер)
- **Индикатор прогресса сканирования** с кнопкой СТОП (появляется через 5 с)
- **Пагинация** для больших каталогов (включается автоматически)
- **Встроенный аудиоплеер** в списке — воспроизведение аудио без перехода к плееру
- Поддержка **навигации с клавиатуры** в обозревателе файлов

---

## 3. Файловые операции

- **Копирование** в настроенный каталог назначения (локальный, SMB, FTP, SFTP)
- **Перемещение** в настроенный каталог назначения
- **Удаление** — безвозвратно или в Корзину (настраивается)
- **Переименование** файла на месте
- **Восстановление** удалённого файла из Корзины
- **Отмена** последней операции копирования / перемещения / удаления
- **Пакетные операции** над выделенными файлами
- **Поделиться** — открыть файл во внешнем приложении
- **Безопасный режим** — диалоги подтверждения перед удалением / перемещением (главный переключатель в Настройках)
- Опция **перезаписи** при копировании/перемещении
- **Диалог прогресса** операции с индикатором в байтах и скоростью передачи
- **Межпротокольные передачи**: SMB↔Локально, FTP↔Локально, SFTP↔Локально, SMB↔SMB, FTP↔FTP, SFTP↔SFTP, Локально↔FTP, Локально↔SFTP, Локально↔SMB

---

## 4. Управление каталогами назначения

- До **10 кнопок назначения** с настраиваемыми цветами в плеере
- Любой настроенный ресурс с правом записи может быть назначением
- Опция **перейти к следующему файлу после копирования**
- Сворачиваемые панели копирования / перемещения в плеере
- **Добавление/удаление из Избранного** прямо из плеера

## 5. Просмотр изображений

- Полноэкранный режим с **масштабированием жестом «щипок»**
- **Обрезка по экрану** (заполнение экрана при совпадении ориентации)
- **Динамический фон** — размытый цвет изображения на фоне
- **Поворот изображения** по часовой / против часовой стрелки (с сохранением в файл)
- **Отражение изображения** горизонтально / вертикально (с сохранением)
- **Регулировка яркости / контраста / насыщенности** (с сохранением)
- **Цветовые фильтры**: Чёрно-белый, Сепия, Негатив (с сохранением)
- **OCR** — распознавание текста с изображения (ML Kit Latin + Tesseract)
- **Оверлей перевода** в стиле Google Lens: блоки перевода поверх оригинальных позиций
- **Отправка в Google Lens**

## 6. Просмотр GIF

- Воспроизведение анимированных GIF
- **Изменение скорости** анимации 0.25× – 4× (с сохранением в файл)
- **Извлечение первого кадра** — сохранение как статичное изображение
- **Извлечение всех кадров** — каждый кадр сохраняется как отдельный файл

## 7. Видеоплеер

- Воспроизведение на основе ExoPlayer
- **Полноэкранный режим** со скрытием системного UI
- **Сохранение и восстановление позиции** воспроизведения для каждого файла
- **Продолжить с прошлого раза** — авто-восстановление последнего активного медиа (включая сетевые и облачные ресурсы) при холодном старте приложения
- **Режим «Картинка в картинке»** (Android 12+ / API 31+), автоматический вход при нажатии «Домой»
- **Настраиваемые зоны касания**: области экрана для «Назад» / «Вперёд» / «Воспроизведение/Пауза» / «Перемотка»
- **Подсказка зон касания** при первом запуске
- **Таймер сна** (15 / 30 / 45 / 60 / 90 / 120 мин) с отображением обратного отсчёта

---

## 8. Аудиоплеер

- Воспроизведение на основе ExoPlayer
- **Фоновое воспроизведение** — постоянный сервис переднего плана с уведомлением; музыка продолжает играть при сворачивании приложения или блокировке экрана
- **Медиауправление в уведомлении** (воспроизведение/пауза, предыдущий/следующий трек)
- **Обложка альбома** — из метаданных файла + онлайн-поиск через iTunes API (опционально; можно ограничить Wi-Fi)
- **Поиск и отображение текста песни** — полноэкранный оверлей с текстом (онлайн-поиск)
- **Случайные фото во время воспроизведения** — фотографии из выбранного ресурса как визуальный фон
- **Анимации пустого состояния / визуализатор**: пульс AVD, полосы на Canvas, волны на Canvas, спектр
- **Индикатор виниловой пластинки** — маленький вращающийся винил в углу экрана во время воспроизведения
- **Таймер сна** (общий с видеоплеером)
- Отображение метаданных: исполнитель, название, альбом, длительность
- **Продолжить с прошлого раза** — авто-восстановление последнего активного аудио при холодном старте (с полным восстановлением очереди воспроизведения)

## 9. Слайдшоу

- Автоматическая смена изображений и GIF с настраиваемым интервалом (**1 – 3600 секунд**)
- **Случайный порядок** воспроизведения
- **Фоновая музыка** из выбранного ресурса во время слайдшоу с изображениями/GIF
- **Воспроизведение видео/аудио до конца** в смешанном слайдшоу (смена по окончанию воспроизведения, а не по таймеру)
- Отображение обратного отсчёта (3 – 2 – 1) перед сменой слайда
- Настройка интервала слайдшоу на уровне ресурса (переопределяет глобальную настройку)

## 10. Просмотр PDF

- Рендеринг и отображение многостраничных PDF-документов
- **Постраничный режим** (перелистывание) и **режим вертикальной прокрутки**
- Панель навигации с **миниатюрами страниц**
- **Цветовые режимы**: Обычный, Ночной, Сепия
- **Масштабирование**
- **OCR + перевод** содержимого страницы (оверлей в стиле Google Lens)
- Поддержка крупных миниатюр для сетевых PDF-файлов (опционально)

---

## 11. Просмотр EPUB

- Разбор и рендеринг EPUB-книг (epub4j)
- **Навигация по главам** (предыдущая / следующая)
- Панель **содержания** (оглавление)
- **Поиск внутри главы и по всей книге** (до 500 результатов)
- **Размер шрифта** — регулировка
- **Семейство шрифтов**: По умолчанию, Serif, Monospace
- **Темы оформления**: Светлая, Тёмная, Сепия, Системная (следует тёмной теме устройства)
- **Межстрочный интервал** (множитель 1.0 – 3.0×)
- **Горизонтальные поля** — регулировка
- **Сохранение и восстановление** последней читаемой главы
- **Перевод** содержимого главы

---

## 12. Просмотр и редактирование текста

- Просмотр текстовых и кодовых файлов с **автоматическим определением кодировки**
- **Рендеринг Markdown** (библиотека Markwon)
- **Подсветка синтаксиса** для кодовых файлов
- Отображение **номеров строк** (переключатель)
- **Темы оформления**: Светлая, Тёмная, Сепия, Системная
- **Регулировка размера шрифта** горизонтальным свайпом
- **Редактирование и сохранение текста на месте** (если ресурс разрешает запись; локальные и сетевые файлы)
- **Автосохранение** со стеком **отмены/повтора**
- **Перевод** текстового содержимого
- **Копировать весь текст** в буфер обмена

## 13. Перевод и OCR (общая функция для всех просмотрщиков)

- **ML Kit OCR** (латинский шрифт) — извлечение текста из изображений и PDF
- **Tesseract** — поддержка дополнительных шрифтов
- **Автоматическое определение исходного языка** (ML Kit Language Identification)
- **Перевод на устройстве** на настраиваемый целевой язык (ML Kit Translation; модели загружаются по требованию)
- **Оверлей в стиле Google Lens** — блоки перевода размещаются над оригинальными координатами (изображения и PDF)
- Доступно в: просмотрщике изображений, PDF, текста, EPUB
- Настраиваемые **исходный язык** (авто или явный) и **целевой язык**
- Отображение результатов OCR с настройкой **размера** и **семейства шрифта**

## 14. Сетевые источники

- **SMB** (Samba / Windows-шары / NAS) — полный просмотр и файловые операции
- **FTP** — полный просмотр и файловые операции
- **SFTP** — полный просмотр и файловые операции
- **Автообнаружение сетевых ресурсов** — сканирование локальной подсети (порты 445 / 21 / 22), результаты появляются в реальном времени
- **Тест скорости сети** — измерение скорости чтения/записи в Мбит/с, рекомендуемое количество потоков; результаты сохраняются в ресурсе
- **Настраиваемый параллелизм** сетевых операций: 1, 2, 4, 8, 12 или 24 потока
- **Пул соединений** для SMB (повторное использование аутентифицированных сессий)
- **Ограничение подключений** — защита медленных и перегруженных источников от перегрузки
- **Фоновая периодическая синхронизация** списков файлов (WorkManager, настраиваемый интервал 1 – 24 ч)

| Текст / PDF / EPUB | Номера строк, темы оформления, рендеринг Markdown, подсветка синтаксиса, режим прокрутки PDF, цветовой режим PDF, межстрочный интервал EPUB, поля EPUB |

| Корзина | Восстановимая корзина или постоянное удаление, запрос подтверждения |
| Сеть / Синхронизация | Включить фоновую синхронизацию, интервал (ч), количество параллельных потоков |
| Кеш | Размер дискового кеша Glide (512 МБ – 16 ГБ) |
| Резервное копирование | Экспорт настроек в JSON, импорт из JSON, резервное копирование/восстановление через Google Drive |

## 21. Фоновые и системные сервисы

- **Очистка Корзины** — плановое задание WorkManager удаляет файлы старше срока хранения
- **Очистка временных файлов** — удаление брошенных файлов загрузки при запуске
- **Отложенный отзыв учётных данных** — плановая очистка истёкших или отозванных учётных записей
- **Синхронизация MediaStore** после файловых операций (галерея и другие приложения получают актуальные данные)
- **Хранение позиции воспроизведения** в БД — возобновление позиции для аудио, видео и EPUB
- **Кеш миниатюр** (Glide, настраиваемый размер 512 МБ – 16 ГБ)
- **Кеш метаданных файлов** (БД; устраняет повторное чтение EXIF / ID3 для одних и тех же файлов)
- **Аудит учётных данных** — отслеживает дату последнего использования, показывает устаревшие записи для очистки
