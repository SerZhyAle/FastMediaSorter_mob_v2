# FastMediaSorter v2 - Полный список возможностей

*Последнее обновление: 2026-06-27*

Этот документ - кураторская витрина ключевых пользовательских возможностей. Полный технический инвентарь всех реализованных возможностей находится в `docs/ALL_FEATURES.jsonl`.

**Платформенные требования:** Android 8.0+ (API 26) для сборки Standard. Версия Legacy поддерживает устройства от Android 6.0+ (API 23), сохраняя те же функции. Версия Lite работает только с локальными файлами, без сетевых источников (SMB/FTP/SFTP) и облачных дисков. Поддерживаемые устройства: смартфоны, планшеты, ТВ-приставки на Android TV и автомобильные магнитолы. Работает в Chrome OS через Google Play (ARC++).

---

## 0. Настройка и Конфигурация
- **Выбор профиля устройства при первом запуске** `[Standard / VR]`: При первом запуске выберите профиль устройства (смартфон, планшет, ТВ, магнитола, медиаплеер, фоторамка, VR-шлем и т. д.) с автоматическим рекомендованием. Выбранный профиль применяет оптимизированные настройки по умолчанию (типы контента, интерфейс, безопасность, поведение экрана), адаптированные под конкретное устройство.
- **Настройка возможностей в онбординге** `[Standard / VR]`: При первичной настройке включите нужные возможности (файловый менеджер, аудио, видео, документы, распознавание текста, перевод) и загрузите опциональные элементы прямо на месте - каждая возможность активируется сразу после завершения загрузки, без захода в настройки.
- **«Включить всё» в один тап** `[Standard / VR]`: На первой странице приветствия «Включить всё» выбирает универсальный профиль, включает все доступные функции, запрашивает все разрешения по одному диалогу за раз, предлагает приложение плеером по умолчанию для всех поддерживаемых типов медиа и завершает настройку за один шаг.

## 1. Источники и Хранилища
- **Поддержка различных типов ресурсов** `[Standard / VR]`: Подключение локальных папок, сетевых папок (SMB/NAS, FTP, SFTP) и облачных дисков (Google Drive, Dropbox, OneDrive) в едином интерфейсе.
- **Обмен ресурсами между устройствами** `[Standard / VR]`: Экспортируйте настроенный ресурс - вместе с данными доступа - в небольшой файл и импортируйте его на другом устройстве, открыв файл, поделившись им или через Настройки -> Резервное копирование. Файл содержит пароли в открытом виде, поэтому передавайте его только тем, кому доверяете.
- **Перетаскивание для сортировки ресурсов** `[Standard]`: Зажмите и перетащите элементы списка ресурсов, чтобы задать точный порядок их отображения.

## 2. Браузер Медиафайлов
- **Режим файлового менеджера** `[Standard / VR]`: Отображение скрытых файлов с префиксом `.` и обход медиафильтров для управления любыми типами файлов или архивов (ZIP, APK, EXE и т. д.) в локальных и сетевых папках.
- **Извлечение защищённых архивов** `[Standard / VR]`: Открытие ZIP-архивов, защищённых паролем - введите пароль по запросу, и содержимое распакуется на месте; архив с неподдерживаемым способом защиты обозначается понятным сообщением, а не падает молча.
- **Передача Office-документов и PDF** `[Standard / VR]`: Фильтрация и открытие файлов DOC, DOCX, RTF, ODT или защищённых PDF во внешних приложениях или встроенных просмотрщиках с индикаторами пароля.
- **Просмотр внешних файлов** `[Standard / VR]`: При открытии файла из другого приложения можно листать соседние файлы той же папки (вперёд, назад, случайно, слайд-шоу), а команда *Открыть в FastMediaSorter* открывает встроенный проигрыватель сразу на этом файле. В полноэкранном режиме - нажмите кнопку «Полный экран» в панели команд, чтобы скрыть системные бары и панель для погружающего просмотра; нажмите повторно (или воспользуйтесь клавиатурным сочетанием) для выхода.
- **Редактирование внешних изображений** `[Standard / VR]`: При открытии изображения из другого приложения его можно сразу отредактировать - обрезать, сохранить обрезанную копию, сделать сжатую копию и переключить поворот экрана - те же действия с изображением, что и во встроенном плеере.
- **Карточка свойств файла** `[Standard]`: Откройте нижнюю панель со свойствами файла - размер, даты, путь, разрешение или длительность - прямо из браузера.
- **Множественный выбор перетаскиванием** `[Standard / VR]`: Выделяйте сразу много элементов, проводя по ним касанием, или рамкой мышью - и в браузере, и в списке дубликатов.

## 3. Файловые Операции
- **Кросс-протокольные передачи** `[Standard / VR]`: Копирование и перемещение файлов между локальным диском, SMB, FTP, SFTP и облачными хранилищами в любых комбинациях с фоновым выполнением и отображением скорости/ETA.
- **Поиск дубликатов** `[Standard / VR]`: Высокопроизводительный поиск идентичных файлов по трём этапам (Размер -> Хэш части -> Полный SHA-256) с поддержкой ручного обзора или автоудаления.
- **Захват с камеры и микрофона** `[Standard / VR]`: Снимок с камеры, запись звука на диктофон или запись видео напрямую во временные или сетевые папки (локальные, сетевые или облачные).
- **Встроенная камера в стиле Samsung** `[Standard]`: Встроенная камера с единой точкой входа и переключателем фото/видео прямо на экране - наведите кадр, снимайте фото или записывайте видео и сохраняйте сразу в целевую папку, не выходя из приложения.
- **Мягкое удаление и корзина** `[Standard / VR]`: Удалённые файлы попадают в снимок-корзину для каждой папки, а не исчезают сразу; отмена восстанавливает их одним нажатием, а старые записи корзины автоматически очищаются в фоне.
- **Загрузка по ссылке** `[Standard]`: Вставьте URL в диалог «Загрузить по ссылке» - файл скачается прямо в выбранную папку без браузера.
- **Резервное сохранение** `[Standard]`: Когда выбранное назначение недоступно, файл сохраняется в заданное запасное место вместо ошибки.
- **Снимок экрана** `[Standard]`: Снимок экрана устройства из настроек «Операции» или жестом от края, с системным согласием на захват, с сохранением в выбранную папку.
- **Панель приложений: части системы и наши функции** `[Standard]`: В панель быстрого запуска теперь можно добавлять не только сторонние приложения, но и части операционной системы и собственные функции и ресурсы приложения (калькулятор, мини-игра, фото-OCR-перевод, трансляции, конкретный ресурс), а сама панель по умолчанию приходит уже наполненной полезным набором.
- **Действия краевых жестов** `[Standard]`: Назначьте свайпу от края открытие приложения или его панели быстрого запуска - в дополнение к жесту снимка экрана.
- **Копирование или перемещение открытого файла** `[Standard]`: При открытии файла из другого приложения скопируйте или переместите его сразу в заданную папку назначения прямо из просмотрщика.

## 4. Управление Назначениями
- **Панель мгновенной сортировки** `[Standard / VR]`: Настройка до 30 (по умолчанию 10) цветных кнопок-назначений в плеере для быстрого перемещения или копирования текущего файла в одно нажатие с автопереходом к следующему файлу.
- **Цифровые горячие клавиши сортировки** `[Standard]`: Запускайте кнопки-назначения цифровыми клавишами на клавиатуре или ТВ-пульте для быстрой сортировки с клавиатуры.

## 5. Просмотр Изображений и GIF
- **Редактирование изображений и фильтры** `[Standard / VR]`: Поворот, отражение и кадрирование картинки с перезаписью исходного файла, настройка яркости/контраста/насыщенности и применение цветовых фильтров (Сепия, Негатив).
- **Контроль GIF-анимаций** `[Standard / VR]`: Регулировка скорости проигрывания GIF (от 0.25× до 4×) и экспорт отдельных кадров в статические картинки.
- **Отправить в..** `[Standard / VR]`: Одна команда высокого приоритета собирает все способы отправить текущий файл наружу - системное «Поделиться», эл. почту, Telegram и другие мессенджеры, Google Keep, Google Lens, печать, открытие в другом приложении - в единый список. В списке только включённые в настройках получатели, подходящие типу текущего файла, поэтому меню файла остаётся коротким вместо десятка отдельных пунктов. Работает из браузера файлов, плеера и автономных просмотрщиков.
- **Действия автономного просмотрщика изображений** `[Standard / Lite / Photos / Legacy]`: В автономном просмотрщике изображений распечатайте картинку или скопируйте и переместите её в другую папку - без открытия полного приложения.

## 6. Редактор Рисунков и Аннотаций
- **Редактор рисунков и аннотаций** `[Standard / VR]`: Создание пустых холстов или добавление аннотаций поверх фото с помощью кистей, фигур и текста; результат можно отправить через единое меню «Отправить в..» (Google Keep, Lens и другие включённые получатели).
- **Свой цвет и размер кисти** `[Standard]`: Выбирайте любой цвет кисти из полной палитры и регулируйте толщину кисти во время рисования или аннотирования.

## 7. Видеоплеер
- **Сохранение и восстановление сеанса** `[Standard / VR]`: Точное запоминание момента остановки видео с возможностью автоматического восстановления воспроизведения и сетевых сессий при холодном старте.
- **Скриншоты видео** `[Standard / VR]`: Захват текущего кадра видео высокого качества и сохранение его в формате PNG/JPG в любую папку.
- **Картинка-в-картинке и D-pad** `[Standard Only]`: Сворачивание видео в плавающее окно (на Android 12+) и полноценная адаптация интерфейса под управление D-pad пультами Smart TV и магнитолами.
- **Blu-ray Transport Stream (.m2ts)** `[Standard / VR]`: Воспроизведение BD-TS файлов с локальных, SMB, SFTP, FTP и облачных источников - формат 192-байтных BD-пакетов определяется автоматически, а обычные 188-байтные MPEG-TS файлы с расширением .m2ts воспроизводятся без лишней обработки. О неподдерживаемых аудиодорожках (TrueHD, DTS-HD MA) сообщает однократное уведомление с перечнем обнаруженных кодеков.
- **Трансляция видео на Chromecast** `[Standard]`: Отправьте текущее видео на любое Chromecast-устройство через локальный прокси прямо из меню переполнения плеера.
- **Кадр видео в буфер обмена** `[Standard / VR]`: По желанию дополнительно копируйте каждый захваченный кадр видео в системный буфер обмена - готов к вставке в другое приложение.
- **Жесты управления плеером** `[Standard / VR]`: Вертикальные ползунки яркости и громкости свайпом и настраиваемая сетка 3×3 сенсорных зон, привязанных к действиям плеера.
- **Автополноэкран при повороте** `[Standard / Lite / Photos / Legacy]`: Поворот устройства в ландшафтную ориентацию автоматически переводит плеер в полный экран и показывает панель команд; обратный поворот возвращает оконный режим.

## 8. VR-Редакция и OpenXR
- **Выделенная сборка и движок OpenXR** `[VR Only]`: Иммерсивный стерео-рендер (SBS/OU, VR180, 360°), воспроизведение 2D-файлов на гигантском виртуальном экране, отслеживание движений головы HUD и снимки сквозь камеры Quest 3 (Passthrough).

## 9. Аудиоплеер
- **Фоновое воспроизведение и трансляция** `[Standard / VR]`: Постоянная фоновая служба с управлением через системную шторку уведомлений и стриминг на Chromecast-совместимые устройства.
- **Тексты песен и MIDI-интеграция** `[Standard / VR]`: Просмотр текстов песен, воспроизведение MIDI-файлов на удалённых серверах и быстрый переход к поиску трека в YouTube Music в одно нажатие.
- **Визуализации без обложки** `[Standard / VR]`: Когда у трека нет обложки, плеер заполняет экран анимированным фоном - на выбор дышащие полосы, волны, пульсирующие кольца, простая нотка или загружаемые зацикленные видеофоны; при выборе видео предлагается разовая загрузка, а если роликов нет - музыка просто играет без фона.
- **Таймер сна** `[Standard / VR]`: Установите обратный отсчёт - воспроизведение остановится автоматически (с опциональным плавным затуханием громкости), пока вы засыпаете.

## 10. Режим Слайд-шоу
- **Слайд-шоу с фоновой музыкой** `[Standard / VR]`: Настройка интервалов смены кадров (от 1 с до 1 ч), воспроизведение музыки из выбранной папки и приостановка автоперехода на видеофайлах.

## 11. Просмотр PDF и EPUB
- **Удобное форматирование электронных книг** `[Standard / VR]`: Просмотр DRM-free EPUB-книг с настройкой шрифтов, полей, межстрочного интервала, цветовых тем (включая OLED-чёрную) и оглавления.
- **Чтение вслух (TTS) и копирование текста** `[Standard / VR]`: Озвучивание страниц PDF или глав EPUB синтезатором речи, а также выделение и копирование текстовых фрагментов свайп-маркерами.
- **Страница PDF в Google Lens** `[Standard / VR]`: Отправьте текущую страницу PDF прямо в Google Lens для поиска или извлечения текста.
- **Печать из автономного просмотрщика** `[Standard / VR]`: Печать документов и текста прямо из автономного просмотрщика.

## 12. Текстовый Редактор
- **Редактирование на лету и Markdown** `[Standard / VR]`: Быстрая правка файлов `.txt` и `.md` прямо в локальных или сетевых каталогах с подсветкой синтаксиса, Markdown-рендерингом и автосохранением.
- **Отправка текста в Google Keep** `[Standard / VR]`: Из режима чтения текста можно отправить текущий текст прямо в Google Keep как заметку - и во встроенном плеере, и в отдельном просмотрщике текста; пункт виден только при установленном Keep.
- **Встроенный калькулятор из текста** `[Standard / VR]`: Быстрое вычисление математических выражений из выделенных текстовых блоков в книгах, переводах, лирике или OCR без записи результата в исходный файл.
- **Темы чтения в просмотре текста** `[Standard / VR]`: Выбирайте тему чтения - светлую, тёмную, сепию или OLED-чёрную - в режиме просмотра текста.

## 13. Перевод и OCR (Офлайн)
- **Локальный OCR и офлайн-перевод** `[Standard / VR]`: Извлечение невыделяемого текста с картинок и PDF и перевод его в режиме офлайн с помощью ML Kit и Cyrillic Tesseract моделей.
- **Фото-OCR-перевод** `[Standard / VR]`: Быстрый цикл перевода со встроенной камеры с выделением области кадрирования, выбором языков на экране обрезки и экспортом результатов в файл `.txt`.
- **Загрузка по запросу** `[Standard / VR]`: OCR, перевод, декодер FFmpeg DTS и фоновые видео аудио-плеера выключены по умолчанию и устанавливаются по запросу при первом включении; при отказе от загрузки способность остаётся недоступной без ущерба остальному приложению, а после установки переживает обновления и очистку кэша.

## 14. Сетевые Технологии и Облако
- **Автообнаружение NAS и тест скорости** `[Standard / VR]`: Сканирование локальной сети для поиска SMB/FTP/SFTP, замер пропускной способности для оптимизации потоков и высокопроизводительный стриминг.
- **Авторизация SFTP по ключу и пиннинг host-key** `[Standard / VR]`: SFTP-ресурсы поддерживают авторизацию по приватному SSH-ключу с опциональной парольной фразой и проверку отпечатка host-key (защита от подмены сервера). Ключ-авторизация доступна в том числе для предзагруженных ресурсов из встроенного XML.
- **Google Drive, Dropbox, OneDrive** `[Standard / VR]`: Защищённая OAuth авторизация, сквозной стриминг, редактирование файлов и экспорт резервной копии настроек приложения в JSON.
- **Переключение удалённых источников** `[Standard / VR]`: Включайте и выключайте отдельные источники SMB, (S)FTP и облако в настройках или на экране приветствия. Выключенный источник исчезает из выбора, а приложение прекращает его фоновую активность; существующие ресурсы скрываются, а не удаляются, и возвращаются, когда вы снова включите источник.

## 15. Умные Виджеты и Интеграция
- **Иконочные виджеты экрана** `[Standard / VR]`: Компактные 1×1 ярлыки быстрого запуска (диктофон, съёмка в ресурс, OCR с камеры) и виджеты с изменяемым размером (задачи по расписанию, плеер Now Playing, слайд-шоу кадров).

## 16. Настройки и Навигация
- **Отправка отчёта о сбое автору** `[Standard / VR]`: когда в диалоге об ошибке показан настоящий сбой, а не обычное сообщение о недоступности, кнопка отправляет автору письмо с описанием ошибки и приложенным журналом приложения - о проблеме можно сообщить в одно действие.
- **Отчёт о сбое после перезапуска** `[Standard / VR]`: если приложение неожиданно закрылось, при следующем запуске предлагается отправить автору отчёт о сбое с приложенным журналом - так можно сообщить даже о настоящем падении.
- **Поиск по настройкам и темы** `[Standard / VR]`: Полнотекстовый поиск по параметрам с жёлтой подсветкой опций - теперь находит и выпадающие настройки и скрывает строки для функций, которых нет в вашей редакции, - плюс сведения о системе.
- **Свои цветовые темы** `[Standard / Lite / Photos / Legacy]`: Создавайте и применяйте собственную цветовую тему - выбирайте акцентные цвета и цвета поверхностей вместо только встроенных светлой и тёмной.
- **ТВ-навигация и Remap кнопок** `[Standard / VR]`: Переназначение кнопок ТВ-пульта, D-pad ускорение и интеграция с Wear OS Companion-приложением на часах.
- **Менеджер загружаемых расширений** `[Standard / VR]`: Экран в настройках со списком всех опциональных модулей (движки OCR, перевод, видео-визуализации, декодер FFmpeg DTS) и языковых пакетов OCR с их статусом, размером и действиями скачать/удалить для управления местом на устройстве.
- **Единое резервное копирование настроек** `[Standard / VR]`: Сохраняйте источники, избранное, расписания, пароли сетевых ресурсов и сохранённые входы на сайты в одном формате - в локальный файл или Google Drive - и восстанавливайте всё после переустановки.
- **Назначение программой по умолчанию из настроек** `[Standard / VR]`: Сделайте FastMediaSorter программой по умолчанию для изображений, аудио, видео и документов прямо со страницы настроек воспроизведения, не открывая экран приветствия; показываются только кнопки для функций, включённых в вашей сборке.
- **Полная навигация геймпадом и джойстиком** `[Standard]`: Управляйте всеми экранами геймпадом или джойстиком, с переназначаемыми действиями браузера для пользователей контроллеров.
- **Справочник настроек** `[Standard]`: Просматривайте встроенный справочник с описанием каждой настройки, доступный поиском с экрана настроек.
- **Сворачиваемые группы настроек** `[Standard / VR]`: Разделы настроек собираются в аккуратные сворачиваемые группы, чтобы длинные экраны было удобно просматривать.

## 17. Статистика использования
- **Локальная статистика использования** `[Standard / VR]`: Включаемая по желанию и выключенная по умолчанию сводка вашей активности - сколько файлов отсортировано, сколько места освобождено, сколько времени в плеере и не только - хранится только на устройстве. Включите её в общих настройках, чтобы открыть окно «Статистика», затем отправьте сводку автору одной кнопкой или экспортируйте в текстовый файл; выключение сбора стирает детальную активность, а дата первого запуска и число запусков сохраняются.

## 18. Бонусная мини-игра
- **Крывавица и Чудовище** `[Standard]`: Скрытая пошаговая головоломка на сетке - включите её в настройках, затем проведите чудовище к выходу мимо бродячих врагов по уровням со счётом и счётчиком ходов. Запускается из меню или виджета на рабочем столе; управление - касание, клавиатура, D-pad или свайп.

## 19. Интернет-трансляции
- **Интернет-трансляции** `[Standard / Legacy / noLegal / VR / Lite (только прогрессивное аудио)]`: Отдельный экран «Трансляции» для интернет-аудио, видео и RTSP-источников. Добавляйте URL трансляции вручную, импортируйте удалённый плейлист `.m3u` или загружайте кураторский каталог радиостанций через «Расширения».
- **Встроенное аудио и ICY-метаданные** `[Standard / Legacy / noLegal / VR / Lite]`: Воспроизведение аудиотрансляций прямо внутри списка. Закреплённая нижняя мини-панель отображает ICY-метаданные Icecast/Shoutcast «в эфире» (название станции и трека), не скрывая список каналов.
- **Фильтрация по категориям и языкам** `[Standard / Legacy / noLegal / VR]`: Фильтруйте список трансляций по категориям, языкам и типу медиа (аудио/видео/RTSP) с помощью диалогов поиска. В языковом фильтре флаги стран и приоритетные языки (английский, русский, украинский) закреплены вверху.
- **Фоновое воспроизведение и выход** `[Standard / Legacy / noLegal / VR]`: Управление потоками следует настройкам фонового воспроизведения. При выключенном фоновом воспроизведении выход из списка трансляций предложит остановить поток или продолжить воспроизведение.
- **Локальное закрепление каналов** `[Standard / Legacy / noLegal / VR / Lite]`: Закрепляйте любимые трансляции вверху списка с уникальной иконкой булавки для быстрого доступа.
- **Управление плеером под трансляции** `[Standard / Legacy / noLegal / VR]`: Плеер трансляций показывает упрощённый набор элементов под живое воспроизведение, с переключением между каналами и без панелей копирования/перемещения.
- **Трансляция живого потока на Chromecast** `[Standard / Legacy / noLegal]`: Отправьте живой видеопоток на Chromecast-устройство прямо из плеера трансляций.
- **Ярлык на главном экране и действия карточки** `[Standard / Legacy / noLegal / VR]`: Закрепите трансляцию на главном экране для запуска одним касанием и открывайте меню действий карточки прямо из списка трансляций.
- **Значения по умолчанию и поддержка ввода** `[Standard / Legacy / noLegal / VR]`: Задайте сортировку и фильтр по типу медиа для списка трансляций по умолчанию, с полной поддержкой навигации пультом ТВ и мышью.
- **Полноэкранный плеер трансляций и сетка** `[Standard / Photos / Legacy / noLegal / VR]`: Смотрите живой канал во весь экран, листайте трансляции многоколоночной сеткой со статус-точками на плитках в ландшафте, а список помнит фильтр, сортировку и позицию прокрутки.
- **Устойчивое воспроизведение трансляций** `[Standard / Legacy / noLegal / VR]`: Проверка доступности и буферизация под пропускную способность сглаживают старт, с раздельными состояниями буферизации и переподключения.
