# FastMediaSorter v2 — Чем приложение отличается от других

*Последнее обновление: 2026-04-19*

FastMediaSorter — это единый медиаменеджер для Android, который охватывает локальное хранилище, домашний NAS (SMB/FTP/SFTP) и три облачных провайдера в одном приложении. Этот документ описывает то, в чём приложение превосходит альтернативы — а не то, что умеет любое медиаприложение на рынке.

**Платформа:** Android 8.0+ (API 26) — версии Standard, Lite, Photos. Версия Legacy поддерживает Android 6.0+ (API 23) с тем же набором функций, но без облачных интеграций.

## 1. Управление ресурсами / источниками

Основная идея: один список ресурсов охватывает все типы хранилищ — локальные папки, SMB-шары, FTP/SFTP-серверы, Google Drive, Dropbox и OneDrive. Вам не нужно переключать приложения или повторно проходить аутентификацию в зависимости от того, где находится файл.

- **Профили ресурсов (быстрые шаблоны)**: Новые ресурсы предварительно настроены с разумными параметрами по умолчанию для каждого типа медиа (Аудиотека, Видеотека, Фотохранилище и т.д.) — не нужно вручную задавать режим сортировки, политику миниатюр и глубину сканирования.
- **Индивидуальные настройки ресурса**: Каждый ресурс хранит свой режим сортировки, режим отображения, политику миниатюр, PIN-блокировку, флаг «только для чтения» и глубину сканирования подпапок. Сетевой архив и локальная музыкальная папка ведут себя по-разному по умолчанию без конфликтов глобальных настроек.
- **PIN-защита на уровне ресурса**: Отдельные папки можно защитить PIN-кодом — полезно для конфиденциального контента без блокировки всего устройства.
- **Режим «только для чтения»**: Отключает все операции записи для конкретного ресурса на уровне приложения, независимо от прав файловой системы. Защита для архивных папок, которые нужно просматривать, но не изменять.
- **Хранилище учётных данных с аудитом**: Сетевые пароли и SSH-ключи хранятся зашифрованными. Хранилище отслеживает время последнего использования каждой записи — устаревшие учётные данные становятся видны и их легко удалить.
- **Кэширование списка файлов**: Индекс файлов сетевых ресурсов сохраняется в локальной базе данных Room. Повторное открытие больших NAS-папок происходит почти мгновенно, без полного удалённого сканирования.
- **Восстановление позиции на уровне ресурса**: Позиция прокрутки и последний просмотренный файл сохраняются отдельно для каждого ресурса. Повторное открытие папки возобновляется с того же места.
- **Проверка соединения**: Проверка доступности и учётных данных любого сетевого или облачного ресурса перед попыткой открыть его — без молчаливых таймаутов.
- **Сортировка ресурсов перетаскиванием**: Изменение порядка ресурсов на главном экране простым перетаскиванием за иконку-ручку. Долгое нажатие на сам элемент по-прежнему открывает диалог редактирования — жест перетаскивания инициируется только через иконку ≡.

## 2. Навигация по медиа

- **Единый список файлов для всех протоколов**: Браузер отображает одинаковый интерфейс независимо от того, является ли источник локальной папкой, SMB-шарой или облачным каталогом. Сортировка, фильтрация и множественный выбор работают одинаково для любого протокола.
- **Расширенные режимы сортировки**: По имени, дате, размеру, типу, исполнителю, названию, длительности, дате съёмки, случайно или вручную — каждый с направлением по возрастанию/убыванию. Большинство файловых менеджеров останавливаются на имени и дате.
- **Расширенная панель фильтров**: Фильтрация одновременно по подстроке имени файла, диапазону дат, размеру и типу медиа. Незаменима для больших NAS-папок с тысячами смешанных файлов.
- **Переход к случайному файлу в плеере**: Для профилей «Аудиотека» и «Фотохранилище» в командной панели плеера появляется отдельная кнопка-кубик, которая переводит к случайному файлу из текущей библиотеки без включения полного shuffle-режима.
- **Рекурсивное сканирование каталогов**: Сглаживает целое дерево вложенных папок в единый список. Удобно для просмотра музыкальной библиотеки с глубокой иерархией исполнитель/альбом как одной плоской очереди.
- **Пагинация для больших каталогов**: В папках с десятками тысяч файлов автоматически включается постраничная загрузка — интерфейс остаётся отзывчивым без жёсткого ограничения на количество элементов.
- **Миниатюры видео с управлением на уровне ресурса**: Генерацию миниатюр для видео можно отключить для конкретного ресурса — критично для медленных NAS-соединений, где генерация миниатюр для сотен видеофайлов насыщает пропускную способность.
- **Индикатор сканирования с отменой**: Ненавязчивый индикатор прогресса появляется через 5 секунд при медленном сканировании, с кнопкой СТОП для прерывания без перевода приложения в некорректное состояние.
- **Встроенный аудио-миниплеер**: Аудиотреки воспроизводятся прямо из браузера без перехода в другой экран — можно слушать и продолжать навигацию.
- **Операции с подпапками из браузера**: Копирование, перемещение, переименование и удаление подпапок прямо в списке файлов — включая SMB, SFTP, FTP и облачные ресурсы. Большинство файловых браузеров поддерживают это только для локального хранилища.
- **Режим «показать все файлы»**: Временно отключает фильтры типов медиа для работы с не-медиафайлами (бинарники, архивы, конфигурационные файлы) без создания отдельного ресурса.
- **Ручное переупорядочивание перетаскиванием**: В режиме сортировки «Вручную» рядом с каждым файлом появляется ручка перетаскивания. Перемещение файлов задаёт пользовательский порядок, который сохраняется для каждой директории и восстанавливается при следующем открытии.

## 3. Операции с файлами

- **Межпротокольные передачи**: Копирование или перемещение файлов напрямую между любыми двумя типами ресурсов — локальный ↔ SMB, SMB ↔ FTP, облако ↔ NAS — без предварительной загрузки во временное хранилище (где это позволяет протокол).
- **Корзина с восстановлением**: Удалённые файлы попадают во внутреннюю корзину с возможностью восстановления одним нажатием, а не удаляются безвозвратно. Настраивается — жёсткое удаление тоже доступно.
- **Отмена операции**: Последнее копирование, перемещение или удаление можно обратить одним нажатием. Работает межпротокольно.
- **Политики перезаписи для каждого назначения**: Указывается, как обрабатываются конфликты файлов (пропустить, перезаписать, оставить оба) для каждого конкретного назначения. Автоматизирует разрешение конфликтов для повторяющихся рабочих процессов.
- **Поиск дубликатов по SHA-256**: Поиск побайтово идентичных файлов в локальном, SMB, FTP, SFTP и облачном хранилищах по трёхфазной схеме (размер → частичный хэш → полный SHA-256). Межисточниковое сопоставление работает — можно найти дубликаты между NAS и Google Drive. Два режима: просмотр-и-выбор или автоудаление всех (сохраняется самый старый в группе). Большинство средств поиска дубликатов работают только с локальным хранилищем с слабым сопоставлением по имени/размеру.
- **ZIP-архивация из браузера**: Упаковка выбранных файлов в ZIP-архив прямо на месте, с пофайловым индикатором прогресса и автоматическим разрешением конфликтов имён.
- **Распаковка ZIP по нажатию**: Нажатие на ZIP-файл распаковывает его с индикатором прогресса и автоматическим разрешением конфликтов назначения. Работает с локальными и SD-картовыми SAF-ресурсами.
- **Переименование из автономного плеера**: Файлы, открытые через «Открыть с помощью» из внешних приложений, можно переименовать напрямую, включая аудиофайлы — воспроизведение продолжается без прерывания после переименования (источник ExoPlayer горячо заменяется на новый URI).
- **Детальный прогресс передачи**: Побайтовый прогресс, скорость в реальном времени и ETA для всех передач. Важно для больших файлов через медленные NAS или облачные соединения.
- **Безопасный режим**: Глобальный переключатель, добавляющий обязательный шаг подтверждения перед каждым удалением или перемещением. Полезен при работе с незаменимыми файлами.

## 4. Управление назначениями

До 10 цветных кнопок-ярлыков назначений отображаются прямо в плеере, так что сортировка медиа по папкам — это одно нажатие без навигации по меню. Назначениями могут быть любые записываемые ресурсы — локальные, SMB, FTP, SFTP или облачные.

- **Автопереход после копирования/перемещения**: Плеер автоматически переходит к следующему файлу после успешной передачи. В сочетании с кнопками назначений это создаёт быстрый рабочий процесс сортировки очереди без лишних нажатий.
- **Сворачиваемая панель назначений**: Панель команд сворачивается, когда не нужна, освобождая максимум экранного пространства для просмотра.

## 5. Просмотрщик изображений

- **Динамический фоновый эффект**: Просмотрщик вычисляет размытый, соответствующий цветам фон из текущего изображения — никаких чёрных полос вокруг портретных фото на широком экране.
- **Поворот и отражение на месте**: Поворот и горизонтальное/вертикальное отражение записываются напрямую в файл. Отдельный редактор не нужен.
- **Коррекция изображения**: Яркость, контраст и насыщенность можно изменить и сохранить на месте — полезно для мелкой правки во время сортировки без выхода из приложения.
- **OCR (ML Kit + Tesseract)**: Извлечение текста из фотографий, чеков и скриншотов. ML Kit работает с латинскими символами; Tesseract охватывает расширенные шрифты и сложные случаи.
- **AR-наложение перевода**: Переведённые текстовые блоки рисуются на тех же позициях, что и оригинальный текст на изображении — тот же подход, что у Google Lens, но работающий с файлами из любого источника, включая NAS и облако.

## 6. Просмотрщик GIF

- **Регулировка скорости воспроизведения**: Скорость GIF от 0.25× до 4×, сохраняется на уровне файла для будущих просмотров.
- **Извлечение кадров**: Сохранить первый кадр как статичное изображение или извлечь все кадры как отдельные файлы.

## 7. Видеоплеер

- **Стриминг напрямую с NAS и облака**: Загрузка не требуется. SMB, FTP, SFTP, Google Drive, Dropbox и OneDrive воспроизводятся нативно через ExoPlayer с пулингом соединений и настраиваемым параллелизмом.
- **Позиция воспроизведения сохраняется на уровне файла**: Возобновление — пофайловое, не посессионное. Каждое видео помнит, где вы остановились — между перезапусками приложения.
- **Возобновление при следующем запуске**: При холодном старте приложение возвращается к последнему активному видео, включая сетевые и облачные ресурсы, и восстанавливает воспроизведение.
- **Настраиваемые зоны касания**: Определите, какие области экрана активируют предыдущее/следующее, воспроизведение/паузу или перемотку. Раскладка настраивается под пользователя, не фиксирована.
- **Диалог `Control` для видео**: Кнопка `Control` в нижней панели сразу после `Next track` открывает единый диалог с вкладками для громкости, аудиодорожки, субтитров, HUE-сдвига, GPU-яркости и скорости воспроизведения, плюс быстрый сброс к нейтральному состоянию. Та же модель диалога теперь работает и в основном плеере, и в автономном видеоплеере `Открыть с помощью`.

- **Таймер сна**: Обратный отсчёт (15–120 мин), после которого воспроизведение останавливается автоматически.
- **Сохранить кадр**: Сохранить текущий кадр видео как PNG одним нажатием в меню «ещё». Кадр сохраняется в настроенный ресурс-получатель (локальный путь); если ресурс не выбран или недоступен — в папку Downloads. Работает для любых источников: локальных, SMB, SFTP, FTP и облачных.
- **Определение 3D-стерео**: Автоматическое определение стереоскопического видео (SBS и OU) по метаданным и эвристике. В стандартной версии при обнаружении 3D-контента предлагается установить отдельную VR-редакцию для просмотра в шлеме.
- **Определение 360° MP4 spatial metadata**: Для локальных MP4 читаются боксы Google Spatial Media `st3d`/`sv3d`, и их результат имеет приоритет над именем файла. Это даёт корректное автоопределение equirect 360° mono/SBS/OU даже при неоднозначном названии файла.
- **Адаптивная стратегия предварительного кэширования**: Для сетевого видео (SMB, SFTP, FTP) плеер выполняет замер скорости в реальном времени и вычисляет оптимальный целевой объём предкэша. Ненавязчивый индикатор-таблетка показывает прогресс буферизации (тёмный — нормально, янтарный — на грани). При достаточной полосе плеер предлагает сохранить локальную копию через BottomSheet — прогресс загрузки отображается inline, по завершении таблетка становится зелёной. После воспроизведения одним нажатием можно оставить или удалить копию. Настраивается в Настройки → Общие: размер предкэша (Меньше/Авто/Больше), режим очистки (Спрашивать/Авто-удаление/Авто-сохранение) и TTL кэша (Выкл./1д/3д/7д/30д).

## 8. VR-редакция

- **Выделенный VR-flavor**: FastMediaSorter VR — это выделенный `vr` product flavor для шлемов Meta Quest и Android XR. Это тот же базовый плеер, что и стандартная редакция, но с дополнительным слоем OpenXR-рендеринга для воспроизведения в шлеме.
- **Стереоскопическое VR-воспроизведение**: VR-редакция обеспечивает полноценный стереоскопический просмотр 3D-видео (SBS/OU) и поддерживаемых 3D-фотографий, включая прямой переход из panel mode в immersive для стереоскопических изображений. Встроенный OpenXR layer factory маршрутизирует 2D-контент в cinema quad, плоский SBS/OU-контент в projection layers, equirect 360°/VR180-контент в `Equirect2KHR`, а цилиндрический 180°-контент в `CylinderKHR`.
- **Явное сообщение при fallback из immersive**: Если immersive-запуск не удался или файл запросил неподдерживаемый immersive-путь, VR-сборка теперь показывает понятную ошибку до fallback, а не возвращается молча в стандартный плеер.
- **Поглазный VR-рендеринг и сохранение кадра**: VR-рендерер пишет плоские поглазные пиксели в XR-таргеты с корректным SBS/OU/mono-разделением и aspect-preserving cinema blit, оставляя сферическое и цилиндрическое искривление OpenXR compositor. «Сохранить кадр» в VR создаёт timestamped стереоскопический `*_SBS.png` в `Pictures/FastMediaSorter_VR` и сразу предлагает открыть сохранённый файл. Общая кнопка fullscreen теперь остаётся безопасным no-op с toast-сообщением для VR, а VR-ввод для system UI переключает overlay шлема вместо Android-панелей.
- **Обработка 3D-изображений на телефоне и в шлеме**: Формат SBS/OU для изображений определяется автоматически по имени файла; телефонная сборка может показать crop-превью левого глаза и вкладку `3D` в диалоге воспроизведения, а VR-flavor рендерит тот же контент поглазно. Принудительный формат из VR-настроек также применяется к изображениям.
- **Двухгрупповой VR-диалог переопределения формата**: В VR-редакции диалог `Control -> 3D` одновременно показывает группы плоских и сферических форматов. Неактивное семейство по умолчанию остаётся видимым, но отключённым, отдельный переключатель `Override format type` разрешает кросс-семейное переопределение, ручные изменения кратко показываются toast-сообщением, а сохранённый выбор восстанавливается для каждого файла при повторном открытии, если включён `Remember file format`.
- **Раздельные принудительные VR-форматы в настройках**: Экран настроек VR показывает отдельные спиннеры `Forced flat format` и `Forced spherical format`. Старые установки сохраняют прежнее значение `vrForcedFormat` через совместимый fallback, плоские переопределения не затрагивают 360°/VR180-контент, сферические переопределения не влияют на плоское cinema-воспроизведение, а экспорт/импорт резервной копии сохраняет оба поля.

## 9. Аудиоплеер

- **Стриминг из любого источника**: Воспроизведение аудио напрямую с SMB-шар, FTP/SFTP-серверов и всех трёх облачных провайдеров — локальная синхронизация не нужна. Большинство специализированных музыкальных плееров требуют файлы на устройстве.
- **Настраиваемое поведение при нажатии «Назад»**: Определите, что происходит при нажатии «Назад», пока аудио играет в фоне — спросить, всегда останавливать или всегда продолжать. Устанавливается один раз, запоминается навсегда.
- **Обложка из ID3 + онлайн-фолбэк**: Сначала используется встроенная обложка; при её отсутствии выполняется онлайн-поиск с опциональным ограничением только Wi-Fi. Загруженные обложки кэшируются локально и используются повторно без лишних сетевых запросов.
- **Поиск текстов песен**: Находит и отображает синхронизированные тексты для текущего трека в полноэкранном оверлее.
- **Случайные фото во время воспроизведения**: Отображение изображений из выбранного ресурса в качестве визуального фона во время воспроизведения музыки.
- **Визуализаторы при отсутствии обложки**: Когда обложки нет, canvas-визуализаторы (столбцы, волны, спектр) анимируются под музыку вместо чёрного экрана.
- **Панель «Сейчас играет»**: Постоянная мини-панель показывает текущий трек при навигации; при раскрытии открывается полная очередь, полоса прокрутки и обложка, с переходом к любому треку по нажатию.
- **Трансляция на Chromecast**: Отправка аудио на любое устройство Google Cast. Локальные файлы обслуживаются через внутрипроцессный HTTP-прокси; сетевые/облачные файлы сначала кэшируются на устройство.
- **Возобновление при следующем запуске**: Восстанавливает последний активный трек, очередь и позицию при холодном старте.

## 10. Слайд-шоу

- **Любой источник, любой микс**: Слайд-шоу из локальных, SMB, FTP, SFTP, Google Drive, Dropbox или OneDrive файлов. Изображения и GIF смешиваются свободно. Большинство приложений для слайд-шоу работают только локально.
- **Фоновая музыка из любого источника**: Назначьте отдельный ресурс для фоновой музыки — не ограниченный локальными файлами. Музыкальный ресурс может сам находиться на NAS или в облаке.
- **Воспроизведение видео/аудио до конца**: В слайд-шоу со смешанным контентом можно настроить ожидание окончания видео или аудиотрека перед переходом к следующему файлу, а не прерывать его по таймеру.
- **Переопределение интервала для конкретного ресурса**: Установить другой интервал перехода для отдельной папки без изменения глобального значения по умолчанию.

## 11. Просмотрщик PDF

- **Открытие напрямую с NAS и облака**: PDF стримятся из SMB, FTP, SFTP, Drive, Dropbox и OneDrive без предварительной загрузки.
- **OCR + AR-наложение перевода**: То же наложение перевода в стиле Google Lens, что работает в просмотрщике изображений, работает и на страницах PDF — переведённый текст визуально заменяет оригинальный.
- **Выделение текста с переводом / чтением вслух**: Нажмите кнопку «Т» для извлечения текста страницы через OCR (или нативно на Android 15+). Зажмите для выбора диапазона, затем переведите, прослушайте через TTS или найдите в Google — без предварительного копирования в буфер обмена.
- **Чтение вслух (TTS)**: Озвучивает текущую страницу через системный движок TTS. Автоматически останавливается при навигации по страницам.
- **Цветовые режимы**: Нормальный, ночной и сепия для разных условий освещения.
- **Печать**: Отправка текущего PDF, текстового файла или изображения на принтер через стандартный диалог Android. Доступна с командной панели (или из меню «⋯» при нехватке места) в портретном и ландшафтном режиме. Удалённые файлы кэшируются перед печатью и удаляются после.

## 12. Просмотрщик EPUB

- **Открытие напрямую с NAS и облака**: EPUB стримятся из любого подключённого источника, как и PDF.
- **Расширенный поиск**: До 500 результатов на запрос, в пределах текущей главы или по всей книге.
- **Сохранение позиции**: Точная позиция прокрутки и глава сохраняются для каждого файла и восстанавливаются при следующем открытии.
- **Контекстное меню выделения**: Зажмите любое слово для появления маркеров выделения, затем — Перевести, Прочитать вслух через TTS или Найти в Google — в дополнение к системным Копировать/Поделиться.
- **Чтение вслух (TTS)**: Прочитывает текущую главу вслух; автоматически останавливается при смене главы.
- **Настройки чтения**: Размер шрифта, семейство шрифтов (По умолчанию/Serif/Monospace), темы (Светлая/Тёмная/Сепия/OLED Чёрная), межстрочный интервал (1.0×–3.0×) и горизонтальные отступы.

## 13. Просмотрщик / Редактор текста

- **Автоматическое определение кодировки**: Файлы декодируются корректно без ручного выбора кодировки — важно для логов и скриптов из систем с разными локалями.
- **Редактирование на месте для удалённых файлов**: Изменения сохраняются обратно в исходный файл через SMB, SFTP или FTP напрямую — без цикла «скачать → отредактировать локально → загрузить обратно».
- **Подсветка синтаксиса и рендеринг Markdown**: Код-файлы подсвечиваются; `.md`-файлы рендерятся через Markwon. Оба режима работают для файлов из любого источника.
- **Изменение размера шрифта жестом**: Горизонтальный свайп в любом месте экрана изменяет размер текста — без входа в меню.
- **Контекстное меню выделения**: Перевести выделенное, прочитать вслух (TTS) или найти в Google из любого выделенного фрагмента.
- **Встроенный поиск (паритет «Открыть с помощью»)**: Поиск Найти/Следующий/Предыдущий работает как внутри приложения, так и при открытии файла через «Открыть с помощью» из внешнего приложения.

## 14. Перевод и OCR

Один и тот же движок работает одинаково в просмотрщике изображений, PDF, EPUB и текстовом редакторе — отдельная настройка для каждого просмотрщика не нужна.

- **Локальный перевод без интернета**: Языковые модели загружаются по требованию и работают локально — после загрузки интернет не нужен, текст не отправляется на сервер.
- **Автоматическое определение исходного языка**: Исходный язык определяется ML-моделями до запуска перевода — ручной выбор в большинстве случаев не нужен.
- **AR-наложение во всех просмотрщиках**: Переведённый текст размещается на позиции оригинального текста как в изображениях, так и на страницах PDF — не выводится в отдельной панели.
- **Паритет автономного режима**: Перевод и встроенный поиск работают при открытии файла через «Открыть с помощью» из любого внешнего приложения, а не только из FMS.
- **Фолбэк на Tesseract**: Охватывает шрифты и символы, которые ML Kit не распознаёт, включая не-латинские символы и некачественные сканы.

## 15. Сетевые источники

- **SMB, FTP, SFTP — всё нативно**: Никаких плагинов, никаких внешних приложений. Все три протокола реализованы внутри процесса с помощью SMBJ и SSHJ, с полной поддержкой навигации, стриминга, копирования, перемещения и редактирования.
- **Пулинг соединений (SMB)**: Аутентифицированные сессии кэшируются и переиспользуются. Задержка повторной аутентификации при каждой операции с файлом, характерная для конкурирующих клиентов, исключена.
- **Многопоточные передачи**: Задания делятся на 1, 2, 4, 8, 12 или 24 параллельных соединения. Встроенный тест скорости отправляет синтетические пакеты и рекомендует оптимальное количество потоков для вашего соединения.
- **Автообнаружение в сети**: Сканирует локальную подсеть на предмет активных хостов на портах 445 (SMB), 21 (FTP) и 22 (SFTP), выводя обнаруженные NAS-устройства в реальном времени. Ввод IP-адреса не требуется.
- **Регулировка соединений**: Ограничение частоты запросов для предотвращения перегрузки слабого или перегруженного NAS-оборудования.
- **Фоновая синхронизация каталогов**: Задания WorkManager обновляют локальный кэш индекса файлов по настраиваемому расписанию (1–24 часа). Сетевые папки открываются с актуальным содержимым, а не с устаревшим снимком.

## 16. Облачная интеграция

- **Google Drive, Dropbox и OneDrive в одном интерфейсе**: Навигация, стриминг и управление всеми тремя в одном файловом браузере. Официальные приложения работают только с собственным сервисом.
- **Прямые межоблачные и облачно-NAS передачи**: Копирование из Google Drive в Dropbox или из OneDrive в SMB-шару без предварительной загрузки на устройство.
- **Единая OAuth с шифрованием токенов**: Аутентификация один раз; токены хранятся зашифрованными. Повторный вход при перезапуске не нужен.
- **Резервное копирование настроек в Google Drive**: Сериализация всех ресурсов, учётных данных, назначений и конфигурации приложения в JSON-файл в Drive. Восстановление на новом устройстве — в один шаг.

## 17. Избранное

- **Отметка одним нажатием из любого просмотрщика**: Добавить файл в избранное можно из просмотрщика изображений, видеоплеера, аудиоплеера, PDF или EPUB — без возврата в браузер.
- **Список избранного на главном экране**: Все избранные файлы из всех ресурсов (локальных, сетевых, облачных) собраны в одном списке, независимо от места хранения.
- **Прокручиваемый виджет главного экрана**: Виджет на лаунчере отображает список избранного и запускает файлы прямо с главного экрана.

## 18. Виджеты и ярлыки главного экрана

- **Ярлык «Случайная музыка»**: Запускает перемешанное воспроизведение из виртуального ресурса «Вся музыка» прямо с лаунчера — без меню.
- **Ярлык «Фото камеры»**: Открывает фотографии камеры в режиме сетки прямо с лаунчера.

- **Плитка быстрых настроек для аудио**: Управление воспроизведением из шторки Android без разблокировки устройства.

## 21. Приложение-компаньон для Wear OS

Приложение для часов работает независимо — имеет собственный список источников SMB/FTP/SFTP и не требует активности телефона.

- **Синхронизация источников с телефона**: Отправка всех настроенных сетевых источников с телефона на часы одним нажатием через Wearable Data Layer. Часы вибрируют по завершении с итоговым счётом добавленных/обновлённых источников.
- **Управление источниками на часах**: Добавление или удаление источников SMB, FTP и SFTP прямо на часах с протокол-ориентированным мастером настройки.
- **Независимый просмотр медиа и воспроизведение**: Навигация по спискам файлов, запуск слайд-шоу, управление аудио и видео — всё на дисплее часов.
- **Регулятор интервала слайд-шоу**: Изменение интервала слайд-шоу прямо на часах без открытия телефона.
- **Реактивное обновление списка источников**: Список обновляется автоматически после синхронизации, импорта или удаления без принудительной навигации.

## 22. Фоновые и системные сервисы

- **Синхронизация MediaStore после каждой операции**: После любого копирования, перемещения или удаления приложение немедленно уведомляет Android MediaStore. Галерея и другие индексирующие приложения остаются актуальными.
- **Интеграция как плеер по умолчанию (опционально)**: Переключатели управляют тем, регистрирует ли FMS себя системным плеером по умолчанию для аудио/видео/изображений/документов и перехватывает ли аппаратные медиаклавиши.
- **Автономный плеер через «Открыть с помощью»**: При открытии файла из любого внешнего приложения автономный плеер предоставляет копирование, перемещение, удаление, совместный доступ, переименование, переключатель «Избранное» и «Открыть в браузере FMS» — без потери контекста внешнего приложения.
- **Управление аудиофокусом в автономном плеере**: Автоматическая пауза при входящих звонках и кратких прерываниях; освобождение аудиофокуса при выходе, чтобы другие плееры возобновились немедленно.
- **Аудит учётных данных**: Отслеживает время последнего использования каждой хранимой сетевой учётной записи. Застоявшиеся записи выводятся для ручной очистки.
- **Очистка временных файлов**: Брошенные артефакты загрузки и неудавшиеся фрагменты загрузки удаляются при загрузке — ручная очистка хранилища не нужна.
- **Кэш миниатюр**: Предварительно отрендеренные миниатюры Glide сохраняются в выделенном пуле (до 16 ГБ). Повторные открытия больших сетевых каталогов используют кэшированные миниатюры без повторного запроса.

## 23. Операции по расписанию

Автоматическое выполнение операций копирования, перемещения или удаления по настраиваемому расписанию — без открытия приложения.

- **Любой ресурс как источник или назначение**: Локальные, SMB, FTP, SFTP, Google Drive, OneDrive и Dropbox работают как источник и назначение. Доступность назначения проверяется до прикосновения к файлам; недостижимые назначения записываются как ошибки и повторяются при следующем цикле.
- **Фильтры типов файлов и временного окна**: Выбор обрабатываемых категорий (изображения, аудио, видео, документы, все файлы) с опциональным ограничением по файлам, созданным с последнего запуска, за последний час или за последний день.
- **Безопасное атомарное перемещение**: Копия верифицируется до удаления источника. Неудавшаяся копия никогда не удаляет оригинал.
- **Лог операций**: Каждый запуск записывает пофайловые записи лога с отметкой времени (источник, назначение, успех/ошибка). Ротация при 1 МБ. Доступен и очищаем с экрана настроек.
- **Маркер ошибок**: Предупредительный значок (⚠) появляется рядом с любой операцией, последний запуск которой завершился с ошибками.
- **Сохранение после перезагрузки**: Запланированные задания переживают перезагрузку устройства и автоматически переназначаются через WorkManager.
- **Запрос оптимизации батареи**: При первом использовании предлагает отключить оптимизацию батареи — необходимо на устройствах OEM (Xiaomi, Huawei, Samsung), которые агрессивно завершают фоновые задачи WorkManager.

FastMediaSorter охватывает то, для чего обычно нужны 5–10 отдельных приложений. В таблицах ниже показаны только реальные преимущества FMS — строки, где обе стороны равны, опущены.

Преимущество в интеграции: для пользователей, которые управляют медиа между локальным хранилищем, NAS и облаком, FMS устраняет постоянное переключение между приложениями и обеспечивает единый интерфейс для управления файлами и воспроизведения медиа.
