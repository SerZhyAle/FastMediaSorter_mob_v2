Ласкаво просимо на **веб-портал FastMedia Launcher** - довідник із перетворення стандартного екрана Android на налаштовуваний робочий стіл для автомобільних магнітол, планшетів-фоторамок, TV-приставок та автономних дисплеїв.

---

## 🌟 Можливості робочого столу (Launcher Mode)

FastMedia Launcher перетворює будь-який Android-пристрій на зручний та інформативний медіа-центр. Замість сітки іконок ви отримуєте робочий стіл із прямими ярликами до течок, віджетами годинника, погоди та керування плеєром.

### 🚗 Автомобільні Android-магнітоли та планшети
- **Зручний сенсорний інтерфейс:** Великі плитки ярликів для швидкого доступу до музики, офлайн-плейлистів та мережевих дисків під час поїздки.
- **Інтеграція з кнопками на кермі:** Перемикання треків та налаштування гучності фізичними кнопками керма й ручками магнітоли.
- **Панель інтернет-радіо:** Прослуховування онлайн-радіостанцій прямо з робочого столу з відображенням назв поточних треків.
- **Автозапуск при увімкненні запалювання:** Завантаження робочого столу одразу після подачі живлення на магнітолу.

### 🖼️ Планшети-фоторамки
- **Постійно увімкнена фоторамка:** Перетворення старого планшета на інтерактивну фоторамку з показом знімків із NAS (SMB) або хмари.
- **Фонова музика:** Відтворення вашої музичної колекції під час показу слайд-шоу фотографій.
- **Інформер часу та погоди:** Відображення часу, дати та прогнозу погоди поверх фоторамки.

### 📺 TV-приставки та медіацентри
- **Повна підтримка пульта (D-Pad):** Зручне керування течками та медіа за допомогою стандартних пультів ДК та аеромишей.
- **Кольорові кнопки пульта:** Швидкі операції з файлами (Червона = Видалити, Зелена = Копіювати, Жовта = Перемістити, Синя = Перейменувати).
- **Кінотеатр на великому екрані:** Стрімінг відео та серіалів із домашнього сервера без обмежень пам'яті пристрою.

## 📸 Структура робочого столу

Лаунчер надає повну свободу налаштування елементів екрана:

```
.---------------------------------------------------------.
|  [ 12:45 | ☀️ 22°C ]                 [ ⚙️ Налаштування ]|
|---------------------------------------------------------|
|  .-------------.   .-------------.   .---------------.  |
| | 📁 Автомузика | | 🎵 NAS Диск  | | 🖼️ Фоторамка   |  |
| | (SD-картка)  | | (SMB мережа) | | (Хмара)       |  |
|  '-------------'   '-------------'   '---------------'  |
|---------------------------------------------------------|
| [ 📻 Радіостанції ]  [ 📱 Усі програми ] [ 🧹 Сортування ]|
'---------------------------------------------------------'
```

- **Ярлики течок:** Швидкий перехід до локальних течок, USB-флешок, мережевих ресурсів NAS та хмари.
- **Вбудоване меню програм:** Відкриття будь-якого встановленого застосунку Android прямо з панелі завдань.
- **Нещодавні на панелі задач:** Утримуйте нещодавній значок, щоб відкрити його, закріпити на панелі задач або прибрати зі списку нещодавніх.
- **Захист від випадкових натискань:** Блокування редагування робочого столу від випадкових торкань під час руху.
- **Жести годинника:** На віджеті годинника свайп праворуч приховує секунди, а ліворуч повертає їх. Свайп угору задає випадковий читабельний колір і шрифт часу, униз повертає стандартний колір теми. Дата зберігає свій шрифт, але має спільний колір, а вибір зберігається після перезапуску лаунчера.
- **Живий фон із камери:** Заставкою робочого стола можна зробити живий кадр з однієї з камер пристрою. Пункт з'являється у списку заставок лише на пристроях із камерою; під час його вибору запитується дозвіл на камеру, а потім пропонується обрати об'єктив. Потік зупиняється, щойно робочий стіл зникає з екрана, тому у фоні нічого не працює, а пристрій без камери або з відхиленим дозволом залишається на фірмовій заставці, а не на чорному екрані.
- **Вікно трансляції:** Одна інтернет-трансляція просто на робочому столі - ви обираєте її під час додавання плитки. Радіостанція отримує невелику плитку з назвою, значком і кнопкою відтворення. Відеотрансляція отримує більшу плитку, і зображення грає просто в ній; натисніть, щоб зупинити, - на плитці залишиться останній кадр, а не порожній прямокутник. Доки ви не натиснули play, нічого не грає.
