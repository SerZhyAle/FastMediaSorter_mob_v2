# Керування в іммерсивному VR

*Оновлено: 2026-04-24*

Документ описує всі поверхні вводу, що підтримуються в іммерсивному
режимі VR-редакції: контролери Meta Quest Touch Plus / Touch Pro,
Bluetooth-клавіатуру та Bluetooth-мишу. Усі три шари використовують
спільний диспетчер команд, тож одну й ту саму дію можна виконати через
будь-яку зручну поверхню вводу.

Шпаргалка з'являється автоматично один раз при першому вході в іммерсив
(на 4 секунди). Щоб викликати її знову - тривале натискання **Y** на
лівому контролері або клавіша **F1** на клавіатурі.

## 1. Контролери Touch

Підтримуються: Touch Plus (Quest 2, Quest 3) і Touch Pro (Quest Pro).
Логічні прив'язки однакові; застосунок реєструє suggested bindings для
обох профілів, тож поведінка ідентична на всіх шоломах.

### Правий контролер

| Елемент | Дія |
|---|---|
| **A** | Пауза / відтворення. Основна клавіша плеєра. |
| **B** | Вихід у 2D-панель. Завжди доступний шлях назовні. |
| **Тригер** | (Зарезервований під майбутній промінь-вказівник.) |
| **Грип** | Zoom. Утримувати + рухати рукою вперед/назад = зміна масштабу. |
| **Стік ↑ / ↓** | Гучність +/−. |
| **Стік ← / →** | Попередній / наступний файл. Лише edge-спрацьовування, без автоповтору. |
| **Клік стіка** | Ре-центр сцени перед обличчям. |

### Лівий контролер

| Елемент | Дія |
|---|---|
| **X** | Вихід у 2D-панель (дубль B). |
| **Y (коротке)** | Відкрити панель **файлових операцій** (копіювати / перемістити / видалити / перейменувати / про файл). |
| **Y (тривале ≥ 0.8 с)** | Показати / сховати шпаргалку. |
| **≡ (меню)** | Діалог налаштувань відтворення (стерео-формат, аудіодоріжка, субтитри, швидкість, яскравість). |
| **Тригер** | (Зарезервований під майбутній промінь-вказівник.) |
| **Грип** | Zoom - симетрично правому грипу. |
| **Стік ↑ / ↓** | Гучність +/− (дубль правого стіка). |
| **Стік ← / →** | Перемотка −10 с / +10 с. Лише edge, без автоповтору. |
| **Клік стіка** | Перемкнути іммерсивний ↔ плоский екран усередині VR-задачі. |

### Комбінації

- **Обидва грипи утримуються ≥ 1 с** → скидання масштабу до 1.0×.

## 2. Bluetooth-клавіатура

Чотири рівні звичних конвенцій складені один на одного, щоб кожен міг
користуватися своїм звичним набором: Norton Commander F-клавіші
(первинний шар), Windows / MPC-HC / VLC, YouTube-браузерний стиль,
стандартні медіа-клавіші BT-пультів.

### F-клавіші (Norton Commander)

| Клавіша | Дія |
|---|---|
| **F1** | Показати / сховати шпаргалку. |
| **F2** | Перейменувати поточний файл. |
| **F3** | Про файл (відкриває інфо через панель операцій). |
| **F4** | Діалог налаштувань відтворення. **Alt+F4** = вихід. |
| **F5** | Скопіювати в.. |
| **F6** | Перемістити в.. |
| **F7** | Відкрити панель файлових операцій. |
| **F8** | Видалити (з підтвердженням). |
| **F10** | Вихід у 2D-панель. |

### Windows / VLC / MPC-HC

| Клавіша | Дія |
|---|---|
| **Space** | Пауза / плей. |
| **← / →** | Перемотка ±10 с. |
| **Shift + ← / →** | Мікро-перемотка ±3 с. |
| **Ctrl + ← / →** | Макро-перемотка ±60 с. |
| **↑ / ↓** | Гучність ±. |
| **Page Up / Page Down** | Попередній / наступний файл. |
| **M** | Mute / unmute. |
| **Delete** | Видалити (з підтвердженням). |
| **Esc** | Вихід. |
| **Ctrl + R** | Перейменувати (дубль F2). |
| **Ctrl + C** | Скопіювати в.. (дубль F5). |
| **Ctrl + X** | Перемістити в.. (дубль F6). |
| **Ctrl + I** | Про файл (дубль F3). |
| **Ctrl + Y** | Відкрити панель файлових операцій. |
| **+ / −** | Збільшити / зменшити масштаб (дискретні кроки). |
| **0** | Скидання масштабу до 1.0×. |

### YouTube-браузерний стиль

| Клавіша | Дія |
|---|---|
| **K** | Пауза / плей. |
| **J / L** | Перемотка ±10 с. |
| **N / P** | Наступний / попередній файл. |
| **C** | Ре-центр сцени. |
| **V** | Перемкнути іммерсивний ↔ плоский екран. |
| **Tab** | Діалог налаштувань відтворення. |
| **Enter** | Діалог налаштувань відтворення. |

### BT-пульти / медіа-клавіші

- **Media Play/Pause** → пауза / плей.
- **Media Next / Previous** → наступний / попередній файл.
- **Гучність ± / Mute** **не перехоплюються** - їх обробляє сама Android.

## 3. Bluetooth-миша

Миша - паралельна поверхня вказівки (у цій ітерації використовується
Android-курсор; 3D-промінь від контролера - у наступній ітерації).

| Елемент | Дія |
|---|---|
| Рух | Курсор на 2D-оверлеї (коли той видимий). |
| **ЛКМ** | Пауза / плей (або клік по елементу оверлея під курсором). |
| **ПКМ** | Діалог налаштувань відтворення. |
| **СКМ** | Ре-центр сцени. |
| **Кнопка 4 / 5** | Попередній / наступний файл (бічні кнопки ігрової миші). |
| **Колесо ↑ / ↓** | Гучність ±. |
| **Shift + колесо** | Перемотка ±10 с. |

## 4. Сценарій файлових операцій

1. Відкрийте панель через **Y** (лівий контролер), **F7** або **Ctrl+Y**, або
   одразу перейдіть до дії через **F2 / F3 / F5 / F6 / F8**.
2. Відтворення автоматично ставиться на паузу при відкритті панелі та
   відновлюється при закритті (лише якщо пауза була застосована панеллю).
3. Для «Скопіювати» / «Перемістити» діалог «Куди?» показує до десяти
   останніх тек-цілей плюс пункт «Обрати іншу теку..», який повертає в 2D-
   панель для повноцінного вибору з дерева.
4. Видалення завжди підтверджується діалогом з ім'ям і розміром файлу.
5. Перейменування - простий діалог вводу (потрібна BT-клавіатура або
   системна екранна клавіатура Quest).

## 5. HUD-індикатори

Авто-приховані підказки поверх сцени:

- Піктограма паузи / плею (центр, 0.8 с)
- Відсоток гучності (праворуч, 1.5 с)
- Смуга перемотки `[позиція / загальне]  ±Nс` (внизу, 1.2 с)
- Ім'я файлу + `3 / 12` (праворуч угорі, 2 с)
- Кратність масштабу `1.2×` (центр, 1 с)
- Спалах «ре-центр» (центр, 0.4 с)
- «Перший файл» / «Останній файл» (праворуч угорі, 1.5 с)

## 6. Усунення неполадок

- **Контролери мовчать в іммерсиві.** Переконайтеся, що встановлено flavor
  `vr`; інші flavor'и не завантажують підсистему вводу OpenXR. На Quest Pro
  з Touch Pro прив'язки ті самі - вони використовують спільний action set.
- **Клавіатура працює в 2D-панелі, але не в VR.** Примусово закрийте
  Activity та відкрийте знову; деяким BT-клавіатурам потрібне переспряження
  після того, як іммерсивна сесія отримала фокус.
- **Курсор миші не видно.** У поточній ітерації курсор малюється на
  2D-surface під OpenXR-оверлеєм, яка невидима в шоломі. Промінь-вказівник з
  контролера та рендеринг курсора на quad-шарі - заплановані на наступну
  ітерацію.
