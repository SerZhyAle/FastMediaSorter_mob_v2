# Керування в іммерсивному VR

*Оновлено: 2026-07-29*

## Як справи сьогодні

Сьогоднішня іммерсивна OpenXR-сесія - відкривається через бейдж VR у
плеєрі, пункт «Open in VR Cinema» в меню файлу в Browse або кнопку «Test
Immersive» в налаштуваннях (див. [VR-редакція](VR_EDITION_UK.md), збірка
`noLegal`) - має навмисно невелику схему керування:

- **Курок** контролера - це клік променем: наведіть промінь на смугу HUD і
  натисніть, щоб натиснути те, що промінь перетинає.
- **A** на правому контролері або **X** на лівому закриває іммерсивну сесію
  одразу, без підтвердження. Короткий захисний період одразу після входу не дає
  закрити перший кадр випадково.
- Клікабельна панель HUD на екрані **є**: широка невисока смуга з іменем
  файлу, трійкою PREV / PLAY / NEXT, повзунком гучності, повзунком глибини
  стерео для 3D-матеріалу та рядками аудіо- і субтитрових доріжок - але лише
  коли у файлі справді є з чого обирати. Наводите на панель промінь
  контролера і натискаєте курок.
- Дві крайні кнопки смуги - завершальні: **СХОВАТИ** біля правого краю прибирає
  панель зовсім, відтворення триває, а **ВИХІД** біля лівого краю зупиняє його
  й повертає вас у звичайний програвач на тій самій секунді. Їх рознесено по
  краях навмисно, щоб одну не можна було сплутати з іншою.
- Сховану смугу повертає **натискання курка**. Це натискання поглинається: воно
  лише викликає панель і ніколи не натискає те, що промінь у цей момент
  перетинав. Поки панель на видноті, курок знову звичайний клік.
- **Стік ліворуч / праворуч перемотує** фільм кроком у 10 секунд. Щоб перейти до
  попереднього чи наступного *файлу*, затисніть **хват** і потім рухайте стік -
  хват працює як модифікатор, і такий хват не потягне за собою панель. Живі
  джерела без відомої тривалості перемотку ігнорують, а не стрибають навмання.
- При **першому вході в іммерсив після встановлення** підказка щодо керування
  з'являється сама і перелічує всі прив'язки вище. Будь-яке натискання на
  контролері закриває її, і це натискання більше нічого не робить. Кнопка
  **ДОВІДКА** на смузі, ліворуч від СХОВАТИ, повертає підказку будь-коли.
- Той самий промінь керує **внутрішньошоломною сіткою огляду** - другою
  поверхнею, яку вміє показувати сесія (див. [VR Edition](VR_EDITION_UK.md)).
  Наведіть на плитку і натисніть курок: тека розгорнеться на місці, файл почне
  грати. Окремої схеми керування сітка не має - промінь і курок це все, а
  навігація по сітці стіком поки не реалізована.
- Чого в шоломі поки немає: панелі файлових операцій. Зум живе на вертикальній
  осі стіка, а не на HUD.

Все, що нижче - повна розкладка контролерів Touch, шорткати
Bluetooth-клавіатури, підтримка миші, панель файлових операцій та
детальний HUD - це **цільовий дизайн виділеного VR Cinema** (епік S0773, у
розробці, ще не випущено). Читайте це як ескіз дизайну, а не як те, що
працює в шоломі сьогодні.

Документ описує всі поверхні вводу, заплановані для іммерсивного режиму
VR-редакції: контролери Meta Quest Touch Plus / Touch Pro, Bluetooth-клавіатуру
та Bluetooth-мишу. Передбачається, що всі три шари використовуватимуть
спільний диспетчер команд, тож одну й ту саму дію можна буде виконати через
будь-яку зручну поверхню вводу.

Шпаргалка задумана з'являтися автоматично один раз при першому вході в
іммерсив (на 4 секунди); викликається знову тривалим натисканням **Y** на
лівому контролері або клавішею **F1** на клавіатурі. Це цільовий дизайн, а не те,
що випущено: описана вище підказка не має таймера, чекає на натискання
контролера і викликається кнопкою ДОВІДКА на смузі, а не **Y** чи **F1**.

## 1. Контролери Touch (цільовий дизайн, ще не випущено)

Підтримуються: Touch Plus (Quest 2, Quest 3) і Touch Pro (Quest Pro).
Логічні прив'язки однакові; застосунок реєструє suggested bindings для
обох профілів, тож поведінка ідентична на всіх шоломах.

### Правий контролер

| Елемент | Дія |
|---|---|
| **A** | Пауза / відтворення. Основна клавіша плеєра. |
| **B** | Вихід у 2D-панель. Завжди доступний шлях назовні. |
| **Тригер** | (Зарезервований під майбутній промінь-вказівник.) |
| **Грип** | Zoom. Утримувати + рухати рукою вперед/назад = зміна масштабу. |
| **Стік ↑ / ↓** | Гучність +/−. |
| **Стік ← / →** | Попередній / наступний файл. Лише edge-спрацьовування, без автоповтору. |
| **Клік стіка** | Ре-центр сцени перед обличчям. |

### Лівий контролер

| Елемент | Дія |
|---|---|
| **X** | Вихід у 2D-панель (дубль B). |
| **Y (коротке)** | Відкрити панель **файлових операцій** (копіювати / перемістити / видалити / перейменувати / про файл). |
| **Y (тривале ≥ 0.8 с)** | Показати / сховати шпаргалку. |
| **≡ (меню)** | Діалог налаштувань відтворення (стерео-формат, аудіодоріжка, субтитри, швидкість, яскравість). |
| **Тригер** | (Зарезервований під майбутній промінь-вказівник.) |
| **Грип** | Zoom - симетрично правому грипу. |
| **Стік ↑ / ↓** | Гучність +/− (дубль правого стіка). |
| **Стік ← / →** | Перемотка −10 с / +10 с. Лише edge, без автоповтору. |
| **Клік стіка** | Перемкнути іммерсивний ↔ плоский екран усередині VR-задачі. |

### Комбінації

- **Обидва грипи утримуються ≥ 1 с** → скидання масштабу до 1.0×.

## 2. Bluetooth-клавіатура (цільовий дизайн, ще не випущено)

Чотири рівні звичних конвенцій складені один на одного, щоб кожен міг
користуватися своїм звичним набором: Norton Commander F-клавіші
(первинний шар), Windows / MPC-HC / VLC, YouTube-браузерний стиль,
стандартні медіа-клавіші BT-пультів.

### F-клавіші (Norton Commander)

| Клавіша | Дія |
|---|---|
| **F1** | Показати / сховати шпаргалку. |
| **F2** | Перейменувати поточний файл. |
| **F3** | Про файл (відкриває інфо через панель операцій). |
| **F4** | Діалог налаштувань відтворення. **Alt+F4** = вихід. |
| **F5** | Скопіювати в.. |
| **F6** | Перемістити в.. |
| **F7** | Відкрити панель файлових операцій. |
| **F8** | Видалити (з підтвердженням). |
| **F10** | Вихід у 2D-панель. |

### Windows / VLC / MPC-HC

| Клавіша | Дія |
|---|---|
| **Space** | Пауза / плей. |
| **← / →** | Перемотка ±10 с. |
| **Shift + ← / →** | Мікро-перемотка ±3 с. |
| **Ctrl + ← / →** | Макро-перемотка ±60 с. |
| **↑ / ↓** | Гучність ±. |
| **Page Up / Page Down** | Попередній / наступний файл. |
| **M** | Mute / unmute. |
| **Delete** | Видалити (з підтвердженням). |
| **Esc** | Вихід. |
| **Ctrl + R** | Перейменувати (дубль F2). |
| **Ctrl + C** | Скопіювати в.. (дубль F5). |
| **Ctrl + X** | Перемістити в.. (дубль F6). |
| **Ctrl + I** | Про файл (дубль F3). |
| **Ctrl + Y** | Відкрити панель файлових операцій. |
| **+ / −** | Збільшити / зменшити масштаб (дискретні кроки). |
| **0** | Скидання масштабу до 1.0×. |

### YouTube-браузерний стиль

| Клавіша | Дія |
|---|---|
| **K** | Пауза / плей. |
| **J / L** | Перемотка ±10 с. |
| **N / P** | Наступний / попередній файл. |
| **C** | Ре-центр сцени. |
| **V** | Перемкнути іммерсивний ↔ плоский екран. |
| **Tab** | Діалог налаштувань відтворення. |
| **Enter** | Діалог налаштувань відтворення. |

### BT-пульти / медіа-клавіші

- **Media Play/Pause** → пауза / плей.
- **Media Next / Previous** → наступний / попередній файл.
- **Гучність ± / Mute** **не перехоплюються** - їх обробляє сама Android.

## 3. Bluetooth-миша (цільовий дизайн, ще не випущено)

Миша - паралельна поверхня вказівки (у цій ітерації використовується
Android-курсор; 3D-промінь від контролера - у наступній ітерації).

| Елемент | Дія |
|---|---|
| Рух | Курсор на 2D-оверлеї (коли той видимий). |
| **ЛКМ** | Пауза / плей (або клік по елементу оверлея під курсором). |
| **ПКМ** | Діалог налаштувань відтворення. |
| **СКМ** | Ре-центр сцени. |
| **Кнопка 4 / 5** | Попередній / наступний файл (бічні кнопки ігрової миші). |
| **Колесо ↑ / ↓** | Гучність ±. |
| **Shift + колесо** | Перемотка ±10 с. |

## 4. Сценарій файлових операцій (цільовий дизайн, ще не випущено)

1. Відкрийте панель через **Y** (лівий контролер), **F7** або **Ctrl+Y**, або
   одразу перейдіть до дії через **F2 / F3 / F5 / F6 / F8**.
2. Відтворення автоматично ставиться на паузу при відкритті панелі та
   відновлюється при закритті (лише якщо пауза була застосована панеллю).
3. Для «Скопіювати» / «Перемістити» діалог «Куди?» показує до десяти
   останніх тек-цілей плюс пункт «Обрати іншу теку..», який повертає в 2D-
   панель для повноцінного вибору з дерева.
4. Видалення завжди підтверджується діалогом з ім'ям і розміром файлу.
5. Перейменування - простий діалог вводу (потрібна BT-клавіатура або
   системна екранна клавіатура Quest).

## 5. HUD-індикатори (цільовий дизайн, ще не випущено)

Авто-приховані підказки поверх сцени:

- Піктограма паузи / плею (центр, 0.8 с)
- Відсоток гучності (праворуч, 1.5 с)
- Смуга перемотки `[позиція / загальне]  ±Nс` (внизу, 1.2 с)
- Ім'я файлу + `3 / 12` (праворуч угорі, 2 с)
- Кратність масштабу `1.2×` (центр, 1 с)
- Спалах «ре-центр» (центр, 0.4 с)
- «Перший файл» / «Останній файл» (праворуч угорі, 1.5 с)

## 6. Усунення неполадок (сьогодні)

- **Кнопка контролера в іммерсиві нічого не робить.** Прив'язані лише ті вводи,
  що перелічені в «Як справи сьогодні» - курок, стік, хват і A/X. B, Y, кнопка
  меню та клік стіка навмисно лишені вільними. Живий набір перелічує підказка
  при першому вході або кнопка ДОВІДКА на смузі.
- **Банер на екрані - порожній сірий прямокутник.** Відомий баг (S0961) -
  банер має показувати ім'я файлу та визначений 3D-формат; виправлення в
  роботі.
- **Bluetooth-клавіатура або миша не керують відтворенням в іммерсиві.**
  Очікувано сьогодні - керування іммерсивною сесією з клавіатури/миші - це
  частина цільового дизайну (епік S0773), ще не випущено. Обидва пристрої
  нормально працюють у плоскій 2D-панелі.

Решта сторінки - повна розкладка контролерів Touch, клавіатура, миша,
файлові операції та HUD - описує те, що з'явиться в цьому розділі після
випуску виділеного VR Cinema (епік S0773).
