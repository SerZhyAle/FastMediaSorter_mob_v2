# 📖 হাউ-টু নির্দেশিকা

সাধারণ কাজগুলোর জন্য ধাপে ধাপে নির্দেশনা।

এই নির্দেশিকাটি এখন দুটি স্তরে বিভক্ত:

- বাস্তব জীবনের সমৃদ্ধ কর্মপ্রবাহ এবং ফিচারগুলোর সমন্বয়ের জন্য **দৃশ্যকল্প গ্রুপ**।
- নিচে সরাসরি একক-ফিচার রেসিপির জন্য **মূল কাজের নির্দেশিকা**।

## নোট: ফ্লেভার অনুযায়ী ফিচারের প্রাপ্যতা

কিছু ফিচার শুধু নির্দিষ্ট ফ্লেভারে পাওয়া যায়। নিচের টেবিলটি [FLAVOR_MATRIX.md](FLAVOR_MATRIX.md) থেকে নেওয়া, যেটি বিল্ড থেকেই স্বয়ংক্রিয়ভাবে তৈরি হয়; XR / noLegal কলামটি ইচ্ছাকৃতভাবে একটি একক কলাম রাখা হয়েছে, কারণ এটি হেডসেট হার্ডওয়্যার ও সাইডলোড বিল্ড নিয়মের উপর নির্ভর করে।

| ফিচার | Standard | Lite | Photos | Legacy | XR / noLegal | FOSS |
|---------|----------|------|--------|--------|--------------|------|
| নেটওয়ার্ক ফোল্ডার (SMB, SFTP, FTP) | ✓ | ✗ | ✓ | ✓ | ✓ | ✓ |
| ক্লাউড স্টোরেজ (Google Drive, OneDrive, Dropbox) | ✓ | ✗ | ✓ | ✓ | ✓ | ✗ |
| অডিও প্লেব্যাক ও লিরিক্স | ✓ | ✓ | ✗ | ✓ | ✓ | ✓ |
| ব্যাকগ্রাউন্ড অডিও প্লেব্যাক | ✓ | ✗ | ✗ | ✓ | ✓ | ✓ |
| ইন্টারনেট স্ট্রিম (রেডিও, HLS/DASH, RTSP) | ✓ | ✗ | ✗ | ✓ | ✓ | ✗ |
| ডকুমেন্ট ভিউয়ার (PDF, টেক্সট) | ✓ | ✗ | ✗ | ✓ | ✓ | ✓ |
| EPUB রিডার | ✓ | ✗ | ✗ | ✓ | ✓ | ✓ |
| অনুবাদ ও OCR | ✓ | ✗ | ✗ | ✓ | ✓ | ✗ |
| ছবি সম্পাদনা | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| হোম-স্ক্রিন (লঞ্চার) মোড | ✓ | ✗ | ✗ | ✗ | ✓ | ✗ |

হোম-স্ক্রিন মোড হলো সেই একমাত্র সারি যেখানে একত্রিত শেষ কলামটি বিভক্ত হয়ে যায়: এটি **noLegal** সাইডলোড বিল্ডে থাকে, কিন্তু VR/XR বিল্ডে থাকে না, যেখানে হেডসেট নিজস্ব হোম পরিবেশ সরবরাহ করে।

অডিওর জন্য দুটি সারি আছে, কারণ এগুলো দুটি আলাদা বিল্ড সিদ্ধান্ত: **Lite** লিরিক্সসহ স্থানীয় অডিও ফাইল বাজাতে পারে, কিন্তু অ্যাপ ফোরগ্রাউন্ড ছেড়ে গেলে থেমে যায় - এতে কোনো ব্যাকগ্রাউন্ড প্লেব্যাক সার্ভিস নেই। Lite-এ ইন্টারনেট স্ট্রিম স্ক্রিনই নেই, তাই রেডিও এবং HLS/DASH/RTSP সেখানে শুধু সীমিত নয়, একেবারেই অনুপস্থিত।

যদি কোনো ফিচার "✗" চিহ্নিত থাকে, তাহলে আপনার হার্ডওয়্যার ও বিতরণ পথের সাথে মানানসই **Standard** বা **XR / noLegal** বিল্ড বেছে নিন।

## দৃশ্যকল্প গ্রুপ

এই সেকশনগুলো নিচের মূল রেফারেন্স ব্লকগুলোর চেয়ে ইচ্ছাকৃতভাবে বেশি বিচিত্র। প্রতিটি দৃশ্যকল্প একটি দ্রুত পথকে প্রেক্ষাপট, ট্রেড-অফ এবং যে পরিস্থিতিতে FastMediaSorter বিশেষভাবে শক্তিশালী তার সাথে মিশিয়ে দেয়।

> **⭐ ফিচার্ড: এক স্ক্যানে আপনার পিসির ফোল্ডার আপনার ফোনে নিয়ে আসুন।** আপনার পিসিতে বিনামূল্যের [Fast Media Sorter for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/) কম্প্যানিয়ন চালান, আপনার ভিডিও, মিউজিক, ডকুমেন্ট বা ছবির ফোল্ডার বেছে নিন, এবং এটি স্ক্রিনে একটি কোড দেখাবে। ফোনে, **Add** ট্যাপ করুন, **Import by barcode** বেছে নিন, ক্যামেরাটি কোডের দিকে ধরুন - পিসির ফোল্ডারগুলো তাৎক্ষণিকভাবে সংযুক্ত হয়ে যায়, কোনো ঠিকানা, পোর্ট বা পাসওয়ার্ড টাইপ করার দরকার নেই। সম্পূর্ণ ওয়াকথ্রু: [কোড স্ক্যান করে পিসির ফোল্ডার খুলুন](howto/scenario-companion-share-bn.md) &bull; দ্রুত রেসিপি: [একটি Windows Companion Share আমদানি করুন](#how-to-import-a-windows-companion-share)।

> **⌚ Wear OS স্মার্টওয়াচ:** Wear OS ওয়াচ ব্যবহার করছেন? দেখুন আমাদের ধাপে ধাপে গাইড [আপনার ওয়াচে মিউজিক শুনুন](howto/scenario-watch-music-bn.md) এবং [স্মার্টওয়াচকে NAS ও পিসি শেয়ারের সাথে সংযুক্ত করুন](howto/scenario-watch-network-bn.md)।

## হোম মিডিয়া, টিভি এবং লিভিং রুম কর্মপ্রবাহ

## একটি NAS-কে লিভিং-রুম মিডিয়া শেলফে রূপান্তর করুন {#turn-a-nas-into-a-living-room-media-shelf}

**যেখানে পাওয়া যায়:** Standard, Photos, Legacy, XR/noLegal

**দ্রুত পথ**

1. আপনার NAS-কে একটি SMB রিসোর্স হিসেবে যোগ করুন।
2. IP ম্যানুয়ালি টাইপ করতে না চাইলে **Scan Network** চালান।
3. একটি TV বক্স, ট্যাবলেট বা ফোন থেকে রিসোর্সটি খুলুন।
4. NAS থেকে সরাসরি ভিডিও, ছবি বা ডকুমেন্ট ব্রাউজ করা শুরু করুন।

**দৃশ্যকল্প ওয়াকথ্রু**

- পুরো পরিবারের লাইব্রেরির জন্য একটি SMB রিসোর্স রাখুন এবং ব্যবহারের ধরন অনুযায়ী আলাদা চাইল্ড ফোল্ডার রাখুন: Movies, Family Photos, Scans, Manuals।
- সেটআপের সময় একবার **Test Connection** চালান, যাতে সোফায় বসে ব্যবহারের আগে রিসোর্সটি স্থিতিশীল থাকে।
- যদি TV বক্স থেকে NAS ব্যবহার করা হয়, দ্রুত নেভিগেশনের জন্য এটিকে একটি ব্লুটুথ কীবোর্ড বা TV রিমোটের সাথে জোড়া লাগান।
- ব্রাউজিং ধীর মনে হলে, রিসোর্স সেটিংস খুলুন এবং অন্য কিছু পরিবর্তন করার আগে বিল্ট-ইন স্পিড চেক চালান।

**যখন এটি কাজে লাগে**

- আপনি একই ফাইল বিভিন্ন ডিভাইসে কপি করার বদলে একটি কেন্দ্রীয় মিডিয়া উৎস চান।
- আপনি চান একই লাইব্রেরি স্লাইডশো, ডকুমেন্ট পড়া এবং প্লেব্যাকের জন্য একইভাবে কাজ করুক।

**এড়িয়ে চলুন**

- হোস্টনেম সমস্যা সমাধান দিয়ে শুরু করবেন না। প্রথমে একটি IP ঠিকানা ব্যবহার করুন, পরে অপ্টিমাইজ করুন।
- Lite ফ্লেভার থেকে SMB শেয়ার ব্রাউজ করা যাবে বলে আশা করবেন না - সেই বিল্ডে কোনো নেটওয়ার্ক উৎসই নেই।

## রুম ডিসপ্লের জন্য ব্যাকগ্রাউন্ড মিউজিকসহ স্লাইডশো চালান {#run-a-slideshow-with-background-music-for-a-room-display}

**যেখানে পাওয়া যায়:** Standard, Lite, Legacy, XR / noLegal (Photos-এ অডিও সমর্থন নেই)

**দ্রুত পথ**

1. একটি ছবির উৎস এবং একটি মিউজিক উৎস যোগ করুন।
2. **Settings → Media → Images**-এ গিয়ে **Play music during slideshow** চালু করুন।
3. মিউজিক রিসোর্সটি বেছে নিন।
4. একটি ছবির ফোল্ডার খুলুন এবং **Play** চাপুন।

**দৃশ্যকল্প ওয়াকথ্রু**

- সবচেয়ে মসৃণ ট্রানজিশনের জন্য একটি স্থানীয় ছবির ফোল্ডার বা দ্রুত NAS শেয়ার ব্যবহার করুন।
- শান্ত ব্যাকগ্রাউন্ড ট্র্যাকের জন্য একটি আলাদা মিউজিক রিসোর্স রাখুন, যাতে স্লাইডশোর অডিও অনুমানযোগ্য থাকে।
- ফোল্ডারে ছবি এবং ভিডিও দুটোই থাকলে মনে রাখবেন, ভিডিও শুরু হলে মিউজিক স্বয়ংক্রিয়ভাবে থেমে যায়।

**যখন এটি কাজে লাগে**

- আপনি চান একটি TV বক্স, ট্যাবলেট বা পুরনো ফোন একটি রুমের জন্য ডিজিটাল ফ্রেম হিসেবে কাজ করুক।
- আপনি চান এমন একটি সেটআপ যা ম্যানুয়াল কিউ তৈরি ছাড়াই পারিবারিক ছবি, ইভেন্টের ছবি বা ভ্রমণের অ্যালবাম ঘুরিয়ে দেখাতে পারে।

**এড়িয়ে চলুন**

- মসৃণ প্লেব্যাক গুরুত্বপূর্ণ হলে ছবি এবং মিউজিক দুটোর জন্যই খুব ধীর নেটওয়ার্ক শেয়ার ব্যবহার করবেন না।

## OpenXR VR ইমার্সিভ সিনেমা {#openxr-vr-immersive-cinema}

**যেখানে পাওয়া যায়:** Standard, Lite, Legacy, `vr`, noLegal (single-eye 3D); `vr` এবং noLegal (পূর্ণ হেডসেট ইমার্সন - উভয় বিল্ডই ইমার্সিভ ভিউ সরবরাহ করে, এবং এটি চালু হয় যখন অ্যাপ একটি OpenXR হেডসেট শনাক্ত করে এবং VR মাস্টার সুইচ চালু থাকে)

**দ্রুত পথ - চালু করুন, কনফিগার করুন, 3D দেখুন**

1. **Single-eye 3D (প্রতিটি ফ্লেভারে, কিছুই চালু করার দরকার নেই):** যেকোনো SBS/OU/180°/360° ফাইল খুলুন - এটি স্বয়ংক্রিয়ভাবে শনাক্ত হয় এবং এক চোখের জন্য ক্রপ করা হয়, যাতে এটি একটি সাধারণ ফ্ল্যাট স্ক্রিনে ঠিকভাবে দেখায়। এটি নিয়ন্ত্রিত হয় **Settings > Player > "Show 3D content from one eye"** দিয়ে (ডিফল্ট ON)। স্বয়ংক্রিয়-শনাক্তকরণের বদলে একটি নির্দিষ্ট ফরম্যাট চাপিয়ে দিতে, `vr`/XR-noLegal বিল্ডে প্লেয়ারের Control ডায়ালগ খুলুন এবং 3D ট্যাব থেকে একটি মোড বেছে নিন - **Auto-detect**, **Side-by-Side (SBS)**, **Over-Under (OU)**, বা **Mono (Disabled)**; এই ফাইলের জন্য পছন্দটি মনে রাখা হয়।
2. **Quest-এ পূর্ণ ইমার্সন (`vr` বা XR/noLegal বিল্ড):** হেডসেট পরা অবস্থায়, একটি 3D ফাইল খোলা থাকাকালীন প্লেয়ারে VR ব্যাজে ট্যাপ করুন, Browse-এ কোনো ফাইলের ওভারফ্লো মেনু থেকে **Open in VR Cinema** বেছে নিন, অথবা **Settings > Media** খুলুন এবং একটি নমুনা চেষ্টা করতে **Test Immersive** চাপুন। এই তিনটির যেকোনো একটি সেই কনটেন্টের একটি প্রতি-চোখ OpenXR ভিউ খুলে দেয়।
3. **দেখুন:** ইমার্সিভ ভিউয়ের ভেতরে একটি HUD স্ট্রিপে নিয়ন্ত্রণগুলো থাকে - একটি পজিশন বার যা কন্ট্রোলার রে দিয়ে টেনে সিক করা যায় (পাশে অতিবাহিত ও মোট সময়), এবং এই ফাইলের সাথে প্রযোজ্য পিকারগুলো: একাধিক অডিও ট্র্যাক থাকলেই কেবল অডিও ট্র্যাক, ফাইলে সাবটাইটেল থাকলেই কেবল সাবটাইটেল, এবং স্টেরিও কনটেন্টের জন্যই কেবল স্টেরিও ডেপথ। **HIDE** এবং **EXIT** স্ট্রিপের দুই প্রান্তে থাকে; এটি লুকিয়ে ফেললে সম্পূর্ণরূপে সরে যায় এবং একটি ট্রিগার টান দিলে নিচে যা আছে তা সক্রিয় না করেই এটি ফিরিয়ে আনে। থাম্বস্টিক প্রতি ধাপে 10 সেকেন্ড সিক করে; ধাক্কা দেওয়ার সময় **grip** ধরে রাখলে ফাইলের মধ্যে ধাপে ধাপে যাওয়া যায় - next এবং previous পুরো রিসোর্স তালিকা জুড়ে চলে, শুধু আপনার খোলা ফাইলে নয়। ইনস্টলের পর প্রথম ইমার্সিভ এন্ট্রিতে প্রতিটি কন্ট্রোলার বাইন্ডিংয়ের একটি তালিকা দেখানো হয়; যেকোনো প্রেস এটি বন্ধ করে দেয়, এবং স্ট্রিপের **HELP** বাটন যেকোনো সময় এটি আবার ফিরিয়ে আনে।

**দৃশ্যকল্প ওয়াকথ্রু**

- Single-eye 3D-তে কোনো হেডসেটের দরকারই নেই - পুরনো SBS/OU ফুটেজ একটি ফোন বা ট্যাবলেটে আবার দেখার এটিই সবচেয়ে সহজ উপায়।
- পূর্ণ ইমার্সনের জন্য একটি Quest বা অন্য OpenXR হেডসেট এবং সেটি সরবরাহকারী একটি বিল্ড দরকার - `vr` বিল্ড বা XR/noLegal সাইডলোড বিল্ড (দেখুন [VR সাইডলোডিং গাইড](VR_SIDELOAD.md))।
- 360°/180° ছবি ও ভিডিও ইমার্সিভ ভিউয়ের ভেতরে আপনার চারপাশে একটি গোলক/অর্ধগোলক হিসেবে রেন্ডার হয়; ফ্ল্যাট 2D ফাইল স্রেফ ফ্ল্যাট হিসেবেই চলে।

**যখন এটি কাজে লাগে**

- আপনি একটি আলাদা VR মিডিয়া অ্যাপ ছাড়াই সংরক্ষিত SBS/OU/360°/180° ফুটেজ আবার দেখতে চান।
- আপনার একটি Quest আছে এবং আজই নিজের ফাইলে পূর্ণ ইমার্সন চেষ্টা করতে চান, এই মেনে নিয়ে যে নেভিগেশন আপাতত শুধু next/previous।

**এড়িয়ে চলুন**

- Meta Horizon Store / Google Play `vr` বিল্ড এখনই ইমার্সিভ মোডে ঢুকবে বলে আশা করবেন না - সেই অংশটি এখনও উন্নয়নাধীন।
- সিকিং, ট্র্যাক ও সাবটাইটেল নির্বাচন এবং স্টেরিও ডেপথ হেডসেটে HUD স্ট্রিপে থাকে। ফাইল অপারেশন সেখানে নেই - কপি, মুভ বা ডিলিট করতে ফ্ল্যাট প্যানেলে ফিরে যান।

## Play Internet Radio on a Car Head Unit or Audio Player

**যেখানে পাওয়া যায়:** Standard, Legacy, XR / noLegal - Lite এবং Photos-এ Streams স্ক্রিন নেই

**দ্রুত পথ**

1. প্রধান উইন্ডো ড্রপডাউন খুলুন এবং **Streams** ট্যাপ করুন, অথবা **Settings > Media > Streams**-এ গিয়ে টগলটি বন্ধ থাকলে চালু করুন।
2. টুলবারের শেষে **⋮** ট্যাপ করুন, **Add stream** বেছে নিন, এবং যেকোনো রেডিও স্টেশন URL পেস্ট করুন (http:// অথবা https://, .m3u8, rtsp://)।
3. স্টেশনের সারিতে ট্যাপ করুন - স্টিকি নিচের মিনি-কন্ট্রোলে অডিও শুরু হয়ে যায়। তালিকাটি স্ক্রলযোগ্য থেকে যায়।
4. বড় ক্যাটালগের জন্য, **Import** ট্যাপ করুন এবং একটি রিমোট `.m3u` URL দিন, অথবা **Extensions** স্ক্রিন থেকে কিউরেটেড FastMediaSorter ক্যাটালগ ডাউনলোড করুন।

**দৃশ্যকল্প ওয়াকথ্রু**

- কিউরেটেড ক্যাটালগ বিষয় ও ভাষার চিপ নিয়ে আসে; ফিল্টার বাটন দিয়ে ধরন বা ভাষা অনুযায়ী ফিল্টার করুন (সক্রিয় থাকলে একটি ডট নির্দেশক দেখা যায়)। AND/OR টগল দিয়ে আপনি এমন স্টেশন মেলাতে পারেন যা সব শর্ত পূরণ করে অথবা যেকোনো একটি শর্ত পূরণ করে।
- ক্যাটালগটি নামযুক্ত সংগ্রহেও গোষ্ঠীবদ্ধ থাকে - "Russian TV", "Radio of the former USSR", "African TV" এবং আরও অনেক কিছু। এগুলো টুলবারের ঠিক নিচে চিপের একটি স্ক্রলযোগ্য স্ট্রিপ হিসেবে দেখা যায়; একটিতে ট্যাপ করলে শুধু তার চ্যানেলগুলো দেখা যায়, কিউরেটরের সাজানো ক্রমে, এবং **All** ট্যাপ করলে ফিরে আসা যায়। একই চ্যানেল একাধিক সংগ্রহের অংশ হতে পারে, তাই আপনি এটিকে একটি দেশ এবং একটি মহাদেশ উভয়ের অধীনেই খুঁজে পেতে পারেন। একটি সংগ্রহ একটি অতিরিক্ত ফিল্টার শর্ত মাত্র, আলাদা স্ক্রিন নয়: সার্চ, সর্টিং, জেনার ও ভাষার ফিল্টার এবং আপনার পিনগুলো এর ভেতরেও কাজ করতে থাকে। ডাউনলোড করা ক্যাটালগে কোনো সংগ্রহ না থাকলে, স্ট্রিপটি সেখানে থাকেই না।
- সার্চ ফিল্ডের ডানদিকের দুটি ছোট আইকন এক ট্যাপেই রেডিওকে ভিডিও থেকে আলাদা করে দেয়: শুধু সেই ধরন রাখতে অডিও বা ভিডিও আইকনে ট্যাপ করুন, সবকিছু দেখাতে জ্বলে থাকা আইকনে আবার ট্যাপ করুন।
- আপনার প্রিয় স্টেশনগুলো পিন আইকন দিয়ে উপরে পিন করুন - ক্রম গ্লোবাল Favorites থেকে স্বতন্ত্র।
- টুলবারের ভিউ টগল **Grid**-এ পাল্টে চ্যানেলগুলোকে তাদের সবশেষ ক্যাপচার করা ফ্রেমসহ টাইল হিসেবে দেখুন - ভিডিও স্ট্রিম এক নজরে ব্রাউজ করার জন্য কাজে লাগে। লিস্ট বা গ্রিডের পছন্দ পরের বার Streams খুললেও মনে রাখা হয়।
- যদি একটি স্ট্রিম কাস্ট-বান্ধব হয় এবং আপনার ফোন Wi-Fi-তে থাকে, একই নেটওয়ার্কে থাকা Chromecast-এ পাঠাতে প্লেয়ারে **Cast** ট্যাপ করুন। RTSP স্ট্রিম কাস্ট করা যায় না।
- ICY নাও-প্লেয়িং মেটাডেটা (স্টেশনের নাম, বর্তমান ট্র্যাক) নিচের মিনি-কন্ট্রোলে দেখা যায়।
- আপনার নিজের যোগ করা একটি স্টেশন আপনার Wear OS ওয়াচে পাঠানো যায়: সারির **⋮** মেনু খুলুন এবং **Send to watch** ট্যাপ করুন (Wear Companion অপশন চালু থাকলেই এই কমান্ড দেখা যায়)। স্থানান্তরিত স্টেশনটি ক্যাটালগ রিফ্রেশের পরেও ওয়াচে থেকে যায়; একই ঠিকানা পরে অনলাইন ক্যাটালগে দেখা গেলে, ক্যাটালগ এন্ট্রিটি দখল নেয়।
- ভিডিও এবং RTSP স্ট্রিম ফুলস্ক্রিন প্লেয়ারে খোলে; Back চাপলে Streams তালিকায় স্ক্রল অবস্থান বজায় রেখে ফিরে যাওয়া যায়।
- ব্যাকগ্রাউন্ড অডিও আচরণ নির্ভর করে **Settings > Player > Background audio playback**-এর উপর: এটি বন্ধ থাকলে, স্ক্রিন ছাড়লে অডিও থেমে যায় এবং অ্যাপ Stop / Keep playing পছন্দ দেয়।

**যখন এটি কাজে লাগে**

- Android কার স্টেরিও, অডিও প্লেয়ার এবং মিডিয়া বক্স যেখানে আপনি একটি আলাদা অ্যাপ (TuneIn, RadioDroid, VLC নেটওয়ার্ক স্ট্রিম) ছাড়াই ইন্টারনেট রেডিও চান।
- IPTV-lite ব্যবহার: HLS/DASH VOD স্ট্রিম ফুলস্ক্রিন প্লেয়ারে চলে।

**এড়িয়ে চলুন**

- লাইভ HLS/DASH অফসেট (live-edge) প্লেব্যাক আশা করবেন না - এই রিলিজে শুধু VOD HLS/DASH সমর্থিত।
- Streams-এর জন্য Lite বা Photos ফ্লেভার ব্যবহার করবেন না; দুটি বিল্ডেই Streams এন্ট্রি নেই, তাই সেখানে কোনো প্রোটোকলই কাজ করে না।

## ভ্রমণ, পঠন এবং ডকুমেন্ট কর্মপ্রবাহ

## স্থিতিশীল ইন্টারনেট ছাড়া ভ্রমণের জন্য একটি ফোল্ডার প্রস্তুত করুন {#prepare-a-folder-for-travel-without-stable-internet}

**যেখানে পাওয়া যায়:** Standard, Lite, Photos, Legacy, XR / noLegal (PDF ও EPUB পড়তে দরকার Standard, Legacy, বা XR / noLegal)

**দ্রুত পথ**

1. ট্রিপের জন্য একটি স্থানীয় ফোল্ডার তৈরি করুন বা বেছে নিন।
2. Wi-Fi ছাড়ার আগে প্রয়োজনীয় মিডিয়া, PDF, EPUB বা নোটগুলো এতে কপি করুন।
3. থাম্বনেইল ও সবশেষ অবস্থান প্রস্তুত রাখতে FastMediaSorter-এ একবার সেই ফোল্ডারটি খুলুন।
4. ট্রিপের সময় ফোল্ডারটি অফলাইনে ব্যবহার করুন।

**দৃশ্যকল্প ওয়াকথ্রু**

- মূল কপি সাধারণত NAS বা ক্লাউডে থাকলেও, ভ্রমণের মিডিয়া একটি স্থানীয় ফোল্ডারে রাখুন।
- ইচ্ছাকৃতভাবে ফরম্যাট মেশান: বোর্ডিং PDF, পড়ার জন্য EPUB, স্ক্রিনশট এবং অফলাইন মিউজিক পাশাপাশি থাকতে পারে।
- অফলাইনে থাকাকালীন শুধু ছবি, শুধু ডকুমেন্ট বা শুধু অডিওর মধ্যে সুইচ করতে ফিল্টার প্যানেল ব্যবহার করুন।

**যখন এটি কাজে লাগে**

- ফ্লাইট, ট্রেন, হোটেল এবং গ্রামাঞ্চল যেখানে ক্লাউড স্ট্রিমিং অনির্ভরযোগ্য।
- যেসব পরিস্থিতিতে আপনি একাধিক অ্যাপে খোঁজার বদলে একটি অফলাইন প্যাক চান।

**এড়িয়ে চলুন**

- ফাইলগুলো সত্যিই ইন্টারনেট ছাড়া খোলে কিনা তা পরীক্ষা করার জন্য শেষ মুহূর্ত পর্যন্ত অপেক্ষা করবেন না।

## চলার পথে ক্লাউড ডকুমেন্ট ও EPUB পড়ুন {#read-cloud-documents-and-epubs-on-the-go}

**যেখানে পাওয়া যায়:** Standard, Legacy, XR / noLegal - Lite এবং Photos ডকুমেন্ট বা EPUB একেবারেই পড়তে পারে না; Lite-এ ক্লাউড স্টোরেজও অনুপস্থিত

**দ্রুত পথ**

1. **Cloud Storage**-এ আপনার ক্লাউড প্রোভাইডার যোগ করুন।
2. PDF বা EPUB থাকা ফোল্ডারটি খুলুন।
3. ক্লাউড রিসোর্স থেকে সরাসরি ফাইলটি ট্যাপ করুন।
4. পরে আপনার সবশেষ সংরক্ষিত অবস্থান থেকে পড়া চালিয়ে যান।

**দৃশ্যকল্প ওয়াকথ্রু**

- এটি ব্যবহার করুন যখন আপনার কাজের ডকুমেন্ট ইতিমধ্যে Google Drive, OneDrive বা Dropbox-এ থাকে এবং আপনি আলাদা রিডার কর্মপ্রবাহ চান না।
- টিকিট, ম্যানুয়াল এবং স্ক্যান করা চুক্তির মতো স্থির-লেআউট ফাইলের জন্য PDF সবচেয়ে ভালো।
- দীর্ঘ পাঠের জন্য EPUB ভালো, যেখানে লেআউট সঠিকতার চেয়ে সামঞ্জস্যযোগ্য ফন্ট সাইজ ও চ্যাপ্টার নেভিগেশন বেশি গুরুত্বপূর্ণ।

**যখন এটি কাজে লাগে**

- আপনি অ্যাপ ছেড়ে না গিয়ে কাজের ডকুমেন্ট ও ব্যক্তিগত পড়ার মধ্যে চলাফেরা করেন।
- আপনি ভ্রমণ বা ক্লায়েন্ট ফাইল ক্লাউডে রাখেন কিন্তু তবুও একটি পঠন-কেন্দ্রিক ইন্টারফেস চান।

**এড়িয়ে চলুন**

- Lite-এ ক্লাউড রিডিং আশা করবেন না - সেই বিল্ডে ক্লাউড স্টোরেজ ও ডকুমেন্ট সমর্থন কোনোটিই নেই। Photos ও Legacy-তে ক্লাউড স্টোরেজ আছে, কিন্তু শুধু Legacy ডকুমেন্ট খুলতে পারে।
- খুব বড় ফাইলের জন্য ধীর মোবাইল ডেটাকে নিশ্চিত পঠন অভিজ্ঞতা হিসেবে ধরে নেবেন না।

## OCR দিয়ে সাইনবোর্ড, স্ক্যান এবং স্ক্রিনশট অনুবাদ করুন {#translate-signs-scans-and-screenshots-with-ocr}

**যেখানে পাওয়া যায়:** Standard, Legacy, XR / noLegal

**দ্রুত পথ**

1. একটি ছবি, PDF, বা টেক্সট ফাইল খুলুন।
2. কমান্ড প্যানেল দেখান।
3. **Translate** ট্যাপ করুন।
4. প্রয়োজনে প্রথমবার ব্যবহারে মডেল ডাউনলোড নিশ্চিত করুন।

**দৃশ্যকল্প ওয়াকথ্রু**

- অ্যাপটি ডিভাইসেই Tesseract দিয়ে টেক্সট পড়ে এবং Google ML Kit দিয়ে অনুবাদ করে।
- সিরিলিক লেখার জন্য, উৎস ভাষা স্পষ্টভাবে বেছে নিন (যেমন রুশ বা ইউক্রেনীয়) - "Auto" ইংরেজি মডেল দিয়ে পড়ে।
- উৎস টেক্সট মোটামুটি স্পষ্ট হলে স্ক্রিনশট, রসিদ, মেনু এবং স্ক্যান করা পাতা বিশেষভাবে ভালো কাজ করে।

**যখন এটি কাজে লাগে**

- আপনি ভ্রমণ করছেন, বিদেশি ম্যানুয়াল পড়ছেন, বা চ্যাট ও অ্যাপ থেকে স্ক্রিনশট বুঝার চেষ্টা করছেন।
- আপনার প্রথমে একটি আলাদা টুলে টেক্সট কপি না করে সরাসরি অনুবাদ দরকার।

**এড়িয়ে চলুন**

- একটি ঝাপসা রাতের ছবি বা খারাপভাবে ক্রপ করা স্ক্যান থেকে OCR-এর মান বিচার করবেন না।

## নেটওয়ার্ক ফাইল বিশেষজ্ঞ অ্যাপে পাঠান {#hand-network-files-off-to-specialist-apps}

**যেখানে পাওয়া যায়:** Standard, Photos, Legacy, XR/noLegal

**দ্রুত পথ**

1. SMB, SFTP, বা FTP থেকে একটি ফাইল খুলুন।
2. **ⓘ Info** ট্যাপ করুন।
3. **Download and Open** ট্যাপ করুন।
4. Android চুজার থেকে বিশেষজ্ঞ অ্যাপটি বেছে নিন।

**দৃশ্যকল্প ওয়াকথ্রু**

- এটি ব্যবহার করুন যখন রিমোট স্টোরেজের জন্য FastMediaSorter-ই সেরা ব্রাউজার, কিন্তু একটি নির্দিষ্ট ফাইল টাইপের জন্য অন্য একটি অ্যাপ সেরা এডিটর বা ভিউয়ার।
- সাধারণ হ্যান্ডঅফ ক্ষেত্রগুলো হলো অফিস ডকুমেন্ট, উন্নত PDF, কোডেক-ভারী ভিডিও এবং বিশেষ মিডিয়া ফরম্যাট।
- ডাউনলোড করা কপিটি `Downloads`-এ থেকে যায়, তাই রিমোট উৎসটি অফলাইনে গেলেও আপনি পরে এটি আবার খুলতে পারবেন।

**যখন এটি কাজে লাগে**

- আপনি সেরা মানের বিশেষজ্ঞ টুল ছাড়া ছাড়াই একটি রিমোট ফাইল হাব চান।

**এড়িয়ে চলুন**

- এই নির্দিষ্ট প্রবাহে এখনই ক্লাউড হ্যান্ডঅফ আশা করবেন না।

## দ্রুত গণিত ও টেক্সট হিসাব {#quick-math-and-text-calculations}

**যেখানে পাওয়া যায়:** Standard, Legacy, XR / noLegal

**দ্রুত পথ**

1. যেকোনো PDF ডকুমেন্ট, EPUB ই-বুক, টেক্সট ফাইল খুলুন, বা একটি ছবির উপর OCR অনুবাদ চালান।
2. সংখ্যা বা গণিত সমীকরণসহ যেকোনো টেক্সট ব্লক নির্বাচন করতে দীর্ঘ-প্রেস করুন।
3. ভাসমান টেক্সট অ্যাকশন মেনু থেকে **Calculator** বাটনে ট্যাপ করুন।
4. ক্যালকুলেটরটি একটি পপআপ ওভারলেতে তাৎক্ষণিকভাবে গাণিতিক সূত্রটি মূল্যায়ন করে।

**দৃশ্যকল্প ওয়াকথ্রু**

- একটি PDF বা OCR অনুবাদ ফলাফলে অপারেটর চিহ্নসহ সংখ্যাযুক্ত একটি টেক্সট লাইন নির্বাচন করুন (যেমন `(45 + 12) * 3`)।
- জটিল অপারেশনের জন্য (ত্রিকোণমিতি, মূল, ঘাত, লগ) বিল্ট-ইন সায়েন্টিফিক ক্যালকুলেটরের ফাংশন মেনু ব্যবহার করুন।
- ক্যালকুলেটর সেশনগুলোর মধ্যে হিসাবের ইতিহাস রাখে এবং দ্রুত ডেটা ট্র্যাকিংয়ের জন্য মেমরি স্লট (M+/M-/MR/MC) সমর্থন করে।

**যখন এটি কাজে লাগে**

- আপনি একটি ম্যানুয়াল, স্ক্রিনশট স্ক্যান বা ডকুমেন্ট পড়ছেন এবং একটি আলাদা ক্যালকুলেটর অ্যাপে না গিয়ে দ্রুত সূত্র সমাধান করতে বা মুদ্রা/সংখ্যা যোগ করতে চান।

**এড়িয়ে চলুন**

- কাঁচা বর্ণানুক্রমিক স্ট্রিং পেস্ট করবেন না; শুধু বৈধ সংখ্যা, বন্ধনী এবং গাণিতিক অপারেটরই পার্স করা যায়।

## ক্লাউড মার্কডাউন ও কোড নোট {#cloud-markdown-and-code-notes}

**যেখানে পাওয়া যায়:** Standard, Photos, Legacy, XR / noLegal (স্থানীয়, নেটওয়ার্ক, এবং ক্লাউড); Lite (শুধু স্থানীয় ফোল্ডার)

**দ্রুত পথ**

1. যেকোনো স্থানীয় ফোল্ডার, হোম NAS (SMB), FTP/SFTP সার্ভার, বা ক্লাউড ড্রাইভ (Google Drive) ব্রাউজ করুন।
2. ফোল্ডার টুলবারে **New Note <img src="icons/doc/ic_create_text_file.png" alt="" width="18" height="18" style="vertical-align:text-bottom">** বাটনে ট্যাপ করুন।
3. এডিটরের ভেতরে আপনার কনটেন্ট টাইপ করুন। অ্যাপটি Markdown ট্যাগ ও কোড সিনট্যাক্স হাইলাইট করে।
4. পরিবর্তনগুলো সরাসরি রিমোট উৎসে লিখতে **Save** ট্যাপ করুন (অথবা এটিকে স্বয়ংক্রিয়ভাবে সংরক্ষণ করতে দিন)।

**দৃশ্যকল্প ওয়াকথ্রু**

- আপনার Google Drive বা হোম NAS-এ একটি `.md` জার্নাল ফাইল রাখুন এবং in-place এডিটিং ব্যবহার করে যেকোনো ডিভাইস থেকে সম্পাদনা করুন।
- স্বয়ংক্রিয় নাম-দ্বন্দ্ব সমাধানসহ (যেমন `Note_1.txt`, `Note_2.txt`) মূল রিসোর্সগুলোতে নতুন নোট তৈরি করুন।
- রেন্ডার করা Markdown লেআউট রিড-ওনলি মোডে দেখুন, বা নোট সরাসরি Google Keep-এর মতো বাহ্যিক সার্ভিসে এক্সপোর্ট করুন।

**যখন এটি কাজে লাগে**

- আপনি স্থানীয় কপি-পেস্ট কর্মপ্রবাহ ছাড়াই আপনার কেন্দ্রীয় নেটওয়ার্ক/ক্লাউড ড্রাইভে সরাসরি সাধারণ নোট, কোড স্নিপেট বা টুডু তালিকা রাখতে চান।

**এড়িয়ে চলুন**

- Lite-এ ক্লাউড স্টোরেজ নোট তৈরি আশা করবেন না - সেই বিল্ডে কোনো ক্লাউড স্টোরেজ বা নেটওয়ার্ক উৎস নেই।

## কুইক সর্ট দিয়ে পারিবারিক ছবির আর্কাইভ সাজান {#sort-a-family-photo-archive-with-quick-sort}

**যেখানে পাওয়া যায়:** Standard, Lite, Photos, Legacy, XR / noLegal

**দ্রুত পথ**

1. আপনার গন্তব্য ফোল্ডারগুলো **Quick Sort**-এ যোগ করুন।
2. অগোছালো পারিবারিক ছবির উৎস ফোল্ডারটি খুলুন।
3. ছবি দেখার সময় নম্বরযুক্ত বাটন বা টাচ জোন ব্যবহার করুন।
4. রাখার মতো ছবিগুলো তাৎক্ষণিকভাবে গন্তব্য ফোল্ডারে পাঠান।

**দৃশ্যকল্প ওয়াকথ্রু**

- শুধু তারিখ দিয়ে নয়, ফলাফল অনুযায়ী গন্তব্য ফোল্ডার তৈরি করুন: `Best`, `Print`, `Send to family`, `Archive`।
- ফুলস্ক্রিনে রিভিউ করুন, যাতে ফাইল তালিকায় ফিরে না গিয়ে দ্রুত সিদ্ধান্ত নিয়ে মুভ বা কপি করতে পারেন।
- একই আর্কাইভ একাধিক মানুষ কিউরেট করলে, বড় সর্টিং সেশনের আগে একটি সামঞ্জস্যপূর্ণ গন্তব্য নামকরণ পদ্ধতি ঠিক করে নিন।

**যখন এটি কাজে লাগে**

- জন্মদিন, ট্রিপ, স্কুলের অনুষ্ঠান বা পুরনো ফোন ইম্পোর্ট থেকে আপনার একটি ব্যাকলগ আছে।
- আপনি ফাইল ম্যানেজারে ম্যানুয়ালি ফাইল টেনে নেওয়ার বদলে একটি দ্রুত ট্রায়াজ প্রবাহ চান।

**এড়িয়ে চলুন**

- গন্তব্যের নাম স্পষ্টভাবে ঠিক করার আগে সর্টিং শুরু করবেন না।
- কোন ফোল্ডারগুলো দীর্ঘমেয়াদী আর্কাইভ হিসেবে থাকবে তা নিয়ে এখনও নিশ্চিত না হলে সাথে সাথে Move ব্যবহার করবেন না।

## এজ জেসচার দিয়ে স্ক্রিন ক্যাপচার করুন {#capture-the-screen-with-edge-gestures}

**যেখানে পাওয়া যায়:** Standard, XR/noLegal

**দ্রুত পথ**

1. **Settings → Management → Edge screen gestures → Gesture overlay**-এ গিয়ে এটি চালু করুন।
2. যেকোনো ফাইল দেখার সময়, ক্যাপচার মেনু খুলতে বাম কিনারা থেকে সোয়াইপ করুন।
3. একটি অ্যাকশন বেছে নিন - স্ট্রিপটি বন্ধ হয়ে যায় এবং অ্যাকশনটি চলতে শুরু করে।

**স্ট্রিপটি যা করতে পারে**

- বর্তমান স্ক্রিনের একটি **screenshot** নিন - এটি দেখুন, সম্পাদনা করুন, শেয়ার করুন, অন্য অ্যাপে পাঠান, বা এতে OCR অনুবাদ চালান, সাথে একটি নীরব-ক্যাপচার অপশনও আছে।
- ক্যামেরা দিয়ে **একটি ছবি তুলুন**, তারপর অ্যাপ ছাড়াই এটি পাঠান, সম্পাদনা করুন, বা OCR-অনুবাদ চালান।
- একটি **screen**, **video**, বা **audio/voice** রেকর্ডিং শুরু করুন - দেখুন [আপনার স্ক্রিন রেকর্ড করুন](#how-to-record-your-screen) এবং [একটি ভয়েস নোট রেকর্ড করুন](#how-to-record-a-voice-note)।
- আপনি প্রায়ই ব্যবহার করেন এমন একটি **অ্যাপ বা প্যানেল খুলুন**।
- বর্তমান ছবির একটি অংশ **ক্রপ করে শেয়ার করুন**।

**জেনে রাখা ভালো**

- স্ট্রিপটি চালু থাকাকালীন, বাম কিনারা থেকে সোয়াইপ পাতা পাল্টানোর বদলে ক্যাপচার মেনু খুলবে।
- স্ট্রিপটি ব্রাউজ করার সময় এক-হাতে ক্যাপচার করার জন্য তৈরি - বাম-কিনারা পাতা সোয়াইপের উপর নির্ভর করলে এটি বন্ধ রাখুন।
- Android প্রতিবার এই জেসচার ব্যবহার করলে ক্যাপচার বা রেকর্ডিং নিশ্চিত করতে বলে, এমনকি নীরব স্ক্রিনশট অপশনের ক্ষেত্রেও - এটি একটি সিস্টেম সুরক্ষা, অ্যাপ নিয়ন্ত্রণ করে এমন কিছু নয়।

**যখন এটি কাজে লাগে**

- আপনি দেখা ফাইলটি ছেড়ে না গিয়ে একটি স্ক্রিনশট, দ্রুত ছবি, বা রেকর্ডিং চান।

## একটি ইন্টারনেট স্ট্রিম যোগ বা আমদানি করুন

**যেখানে পাওয়া যায়:** Standard, Legacy, XR / noLegal (সব প্রোটোকল) - Lite এবং Photos-এ Streams স্ক্রিন নেই

**একটি একক URL যোগ করুন:**

1. প্রধান উইন্ডো ড্রপডাউন থেকে **Streams** খুলুন।
2. টুলবারের শেষে **⋮** বাটন, তারপর **Add stream** ট্যাপ করুন।
3. স্ট্রিম URL পেস্ট করুন (http/https রেডিও, .m3u8, rtsp://)। **Save** ট্যাপ করুন।
4. প্লেব্যাক শুরু করতে সারিতে ট্যাপ করুন।

**একটি রিমোট .m3u প্লেলিস্ট আমদানি করুন:**

1. Streams স্ক্রিনে, **⋮ > Import from URL** ট্যাপ করুন।
2. রিমোট .m3u ঠিকানা লিখুন। **Import** ট্যাপ করুন।
3. ফাইলের সব স্টেশন তালিকায় দেখা যাবে।

**কিউরেটেড FastMediaSorter ক্যাটালগ ডাউনলোড করুন:**

1. **Settings > Extensions** খুলুন (অথবা Welcome অনবোর্ডিংয়ের Streams সারি)।
2. Streams ক্যাটালগ এন্ট্রির পাশে **Download** ট্যাপ করুন।
3. ডাউনলোডের পরে, ক্যাটালগের সারিগুলো বিষয়/ভাষার চিপসহ Streams-এ দেখা যায় এবং সেগুলো অনুসন্ধানযোগ্য ও সাজানো যায়।

## নেটওয়ার্ক ড্রাইভে সংযোগ করুন (SMB) {#how-to-connect-to-network-drive-smb}

**যা আপনার প্রয়োজন:**

- শেয়ার করা ফোল্ডারসহ NAS বা Windows পিসি
- উভয় ডিভাইস একই Wi-Fi নেটওয়ার্কে
- শেয়ারের জন্য ব্যবহারকারীর নাম ও পাসওয়ার্ড

**যেখানে পাওয়া যায়:** Standard, Photos, Legacy, XR / noLegal ফ্লেভার

**ধাপসমূহ:**

1. প্রধান স্ক্রিনে **"+" বাটনে ট্যাপ করুন**
2. **"Network folder (SMB)"** নির্বাচন করুন
3. বিস্তারিত পূরণ করুন:
   - **স্বয়ংক্রিয়-শনাক্তকরণ (নতুন):**
     1. **"Scan Network"** বাটনে ট্যাপ করুন
     2. তালিকায় ডিভাইস দেখা যাওয়া পর্যন্ত অপেক্ষা করুন
     3. তালিকা থেকে আপনার ডিভাইস নির্বাচন করুন
     4. IP ঠিকানা স্বয়ংক্রিয়ভাবে পূরণ হয়ে যাবে

   - **ম্যানুয়াল ইনপুট:**

     ```
     Server/Path: \\192.168.1.100\photos
     Username: john
     Password: ****
     Display Name: Home NAS (optional)
     ```

4. যাচাই করতে **"Test Connection"** ট্যাপ করুন
5. **"Save"** ট্যাপ করুন

**সার্ভার ঠিকানার ফরম্যাট:**

- Windows: `\\192.168.1.100\share`
- Linux/Mac: `smb://192.168.1.100/share`
- পোর্টসহ: `smb://192.168.1.100:445/share`

**পরামর্শ:**

- নির্ভরযোগ্যতার জন্য হোস্টনেমের বদলে IP ঠিকানা ব্যবহার করুন
- নিরাপত্তার জন্য NAS-এ SMB v2/v3 চালু করুন
- ডিফল্ট SMB পোর্ট: 445

**সমস্যা সমাধান:**
→ দেখুন [TROUBLESHOOTING.md](TROUBLESHOOTING-bn.md)

## SFTP/FTP সার্ভারে সংযোগ করুন {#how-to-connect-to-sftpftp-server}

**যা আপনার প্রয়োজন:**

- SSH (SFTP) বা FTP চালু থাকা সার্ভার
- খোলা পোর্ট 22 (SFTP) বা 21 (FTP)
- ব্যবহারকারীর নাম ও পাসওয়ার্ড (বা SFTP-এর জন্য কী)

**ধাপসমূহ:**

1. প্রধান স্ক্রিনে **"+" বাটনে ট্যাপ করুন**
2. **"SFTP / FTP"** নির্বাচন করুন
3. প্রোটোকল বেছে নিন: **SFTP** বা **FTP**
4. বিস্তারিত পূরণ করুন:

   ```
   Host: 192.168.1.100
   Port: 22 (SFTP) / 21 (FTP)
   Username: username
   Password: ****
   Remote Path: /home/user/photos (optional)
   ```

5. **"Connect"** ট্যাপ করুন

**উন্নত:**

- **SSH Key প্রমাণীকরণ:** বর্তমানে সমর্থিত নয় (শুধু পাসওয়ার্ড)
- **কাস্টম পোর্ট:** সার্ভার অ-ডিফল্ট পোর্ট ব্যবহার করলে পোর্ট নম্বর পাল্টান

→ দেখুন [TROUBLESHOOTING.md](TROUBLESHOOTING-bn.md)

## একটি Windows Companion Share আমদানি করুন {#how-to-import-a-windows-companion-share}

**এটি কী:** কম্প্যানিয়ন হলো [Fast Media Sorter for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/) (আগে FastMediaSorter LITE নামে পরিচিত)-এর একটি ফিচার - একই লেখকের তৈরি বিনামূল্যের Windows মিডিয়া সর্টার। এটি বেছে নেওয়া পিসি ফোল্ডারগুলো SFTP-এর মাধ্যমে শেয়ার করে এবং একটি রেডি-মেড সংযোগ এক্সপোর্ট করে - ফোনে কোনো ম্যানুয়াল সার্ভার সেটআপ, হোস্ট/পোর্ট/কী টাইপ করার দরকার নেই। আপনি এটি পিসির স্ক্রিনে **একটি QR কোড স্ক্যান করে**, অথবা **একটি `.fmscfg` ফাইল আমদানি করে** ফোনে নিয়ে আসেন।

**যেখানে পাওয়া যায়:** Standard, Photos, Legacy, XR/noLegal (বারকোড স্ক্যানের জন্য ক্যামেরা দরকার; ফাইল পদ্ধতি VR-সহ সব জায়গায় কাজ করে)

> নির্দেশিত, স্ক্রিনশট-বান্ধব একটি সংস্করণ চান? দেখুন দৃশ্যকল্প গাইড [কোড স্ক্যান করে পিসির ফোল্ডার খুলুন](howto/scenario-companion-share-bn.md)।

**Fast Media Sorter for Windows পান:**

- ওয়েবসাইট: [serzhyale.github.io/FastMediaSorter_Lite](https://serzhyale.github.io/FastMediaSorter_Lite/)
- ফোল্ডার প্রকাশের গাইড: [Android-এ পিসি ফোল্ডার প্রকাশ করার উপায়](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)
- GitHub: [সর্বশেষ রিলিজ](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases/latest) (ইনস্টলার বা পোর্টেবল ZIP)
- winget: `winget install SerZhyAle.FastMediaSorter`
- Microsoft Store: "FastMediaSorter LITE" খুঁজুন (এখনও পুরনো নামে তালিকাভুক্ত)

**পিসিতে:**

1. **Fast Media Sorter for Windows** ইনস্টল ও চালু করুন, সেটিংসে **Share** ট্যাব খুলুন।
2. শেয়ার করার ফোল্ডার(গুলো) বেছে নিন - অ্যাপটি নিজে থেকেই SFTP সার্ভার চালু করে, কী তৈরি করে এবং অটোস্টার্ট সেট করে।
3. এটি স্ক্রিনে একটি **QR কোড** দেখায়। ফাইল পছন্দ হলে এটি **Save .fmscfg**-ও করতে পারে।

**ফোনে - পদ্ধতি A, কোড স্ক্যান করুন (সবচেয়ে দ্রুত):**

1. প্রধান স্ক্রিনে **"+" বাটনে ট্যাপ করুন**।
2. **"Import by barcode"** ট্যাপ করুন - এটি চারটি রিসোর্স-টাইপ কার্ডের পাশে এবং SFTP ফর্মের হেডারে থাকে।
3. পিসির QR-এর দিকে ক্যামেরা ধরুন (অন্ধকার ঘরে **Torch** ট্যাপ করুন), তারপর **Import access** ডায়ালগ নিশ্চিত করুন।
4. সম্পন্ন - প্রতিটি শেয়ার করা ফোল্ডারের জন্য একটি রিড-ওনলি রিসোর্স দেখা যায়, সার্ভার কী স্বয়ংক্রিয়ভাবে পিন করা থাকে।

**ফোনে - পদ্ধতি B, ফাইল আমদানি করুন:**

1. পিসিতে, **Save .fmscfg** ব্যবহার করুন এবং ফাইলটি ফোনে স্থানান্তর করুন (ইমেইল, Telegram, বা একটি শেয়ার করা লোকেশন)।
2. **"+"** -> **"SFTP / FTP"** -> **"Import from file"** ট্যাপ করে `.fmscfg` ফাইলটি বেছে নিন। এটি Telegram/ইমেইল অ্যাটাচমেন্ট হিসেবে এলে, শুধু অ্যাটাচমেন্টে ট্যাপ করুন।
3. **Import access** ডায়ালগ নিশ্চিত করুন - রিড-ওনলি রিসোর্সগুলো দেখা যাবে।

**নোট:** QR কোড এবং কনফিগ ফাইল উভয়েই অ্যাক্সেস পাসওয়ার্ড এম্বেড করা থাকে - এগুলোকে একটি কী-এর মতোই গণ্য করুন, স্ক্রিনশট বা ফাইলটি প্রকাশ করবেন না। ক্যামেরাবিহীন ডিভাইস ও VR হেডসেটে **Import by barcode** এন্ট্রি লুকানো থাকে; সেখানে পদ্ধতি B ব্যবহার করুন।

## ক্লাউড স্টোরেজে সংযোগ করুন {#how-to-connect-to-cloud-storage}

**সমর্থিত প্রোভাইডার:**

- Google Drive
- OneDrive
- Dropbox

**ধাপসমূহ:**

1. প্রধান স্ক্রিনে **"+" বাটনে ট্যাপ করুন**
2. **"Cloud Storage"** নির্বাচন করুন
3. প্রোভাইডার নির্বাচন করুন: **Google Drive**, **OneDrive**, বা **Dropbox**
4. **"Sign in.."** বাটনে ট্যাপ করুন
5. ব্রাউজার/অ্যাপ প্রমাণীকরণ প্রবাহ অনুসরণ করুন
6. প্রয়োজনীয় অনুমতি দিন
7. সিঙ্ক করার জন্য **ফোল্ডার নির্বাচন করুন**
8. **"Done"** ট্যাপ করুন

**নোট:**

- ফাইল **স্ট্রিম করা হয়**, ডাউনলোড করা হয় না
- ইন্টারনেট সংযোগ প্রয়োজন
- পরিবর্তন স্বয়ংক্রিয়ভাবে সিঙ্ক হয়
- আপনি যেকোনো সময় সংযোগ বিচ্ছিন্ন করতে পারেন: Edit folder → Remove

**গোপনীয়তা:**

- কোনো পাসওয়ার্ড সংরক্ষিত হয় না (OAuth টোকেন ব্যবহার করে)
- আপনার ক্লাউড প্রোভাইডারের নিরাপত্তা সেটিংসে টোকেন বাতিল করা যায়

## নেটওয়ার্ক গতি পরীক্ষা করুন

**সমর্থিত:** SMB, SFTP, FTP, Cloud (Google Drive)

**স্বয়ংক্রিয় পরীক্ষা:**
আপনি যখন একটি নতুন নেটওয়ার্ক রিসোর্স যোগ করেন, অ্যাপটি স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ডে একটি স্পিড টেস্ট চালায়। ফলাফল (Read/Write স্পিড) রিসোর্স সেটিংসে সংরক্ষিত হয়।

**ম্যানুয়াল পরীক্ষা:**

1. **Manage Resources**-এ যান
2. একটি নেটওয়ার্ক রিসোর্স সম্পাদনা করুন (পেন্সিল আইকন)
3. নিচের দিকে স্ক্রল করুন
4. **"Speed"** বাটনে ট্যাপ করুন
5. "Analyzing speed.." এর জন্য প্রায় ১৫ সেকেন্ড অপেক্ষা করুন
6. ফলাফল দেখুন:
   - **Read Speed (Mbps)**
   - **Write Speed (Mbps)**
   - **Recommended Threads** (সর্বোত্তম পারফরম্যান্সের জন্য)

## কুইক সর্ট ফোল্ডার সেট আপ করুন {#how-to-set-up-quick-sort-folders}

**পদ্ধতি ১: সেটিংস থেকে**

1. **Settings** → **Management** ট্যাব → **Quick Sort destinations**
2. **"Add to Quick Sort"** ট্যাপ করুন
3. তালিকা থেকে একটি বিদ্যমান ফোল্ডার নির্বাচন করুন
4. ফোল্ডারটি একটি নম্বর (0-9) ও রং পায়
5. সর্বোচ্চ ৩০টি ফোল্ডারের জন্য পুনরাবৃত্তি করুন

**পদ্ধতি ২: ফোল্ডার সেটিংস থেকে**

1. প্রধান স্ক্রিন → **ফোল্ডারে দীর্ঘ-প্রেস করুন**
2. **"Edit"** (পেন্সিল আইকন) ট্যাপ করুন
3. **"Mark for Quick Sort"** চালু করুন
4. **"Save"** ট্যাপ করুন

**কুইক সর্ট ব্যবহার করা:**

ফাইল দেখার সময়:

- কমান্ড প্যানেলে **নম্বরযুক্ত বাটনে** (0-9) ট্যাপ করুন
- অথবা **নিচের-বাম কোণে** ট্যাপ করুন (COPY জোন)
- অথবা **নিচের-মাঝামাঝি কোণে** ট্যাপ করুন (MOVE জোন)

ফাইলটি তাৎক্ষণিকভাবে সেই ফোল্ডারে কপি/মুভ হয়ে যায়!

**একটি কীবোর্ড বা TV রিমোট দিয়ে:** একটি সংযুক্ত করুন এবং গন্তব্য বাটনগুলো একটি সংখ্যা ব্যাজ পায় - সেই গন্তব্যটি তাৎক্ষণিকভাবে চালাতে ট্যাপ না করে মিলে যাওয়া সংখ্যা কী চাপুন।

## টাচ জোন ব্যবহার করুন {#how-to-use-touch-zones}

**টাচ জোন কী?**

দ্রুত অ্যাকশনের জন্য স্ক্রিনটি ৯টি অদৃশ্য অংশে ভাগ করা:

```
┌─────────┬─────────┬─────────┐
│  BACK   │  COPY   │ RENAME  │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  PREV   │  MOVE   │  NEXT   │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ COMMAND │ DELETE  │  PLAY   │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**বিবরণ:**

1. **BACK** - ফাইল তালিকায় ফিরে যান
2. **COPY** - ফাইলটি গন্তব্যে কপি করুন
3. **RENAME** - বর্তমান ফাইলের নাম পাল্টান
4. **PREV** - আগের ফাইলে যান
5. **MOVE** - ফাইলটি গন্তব্যে সরান
6. **NEXT** - পরের ফাইলে যান
7. **COMMAND** - কমান্ড মেনু খুলুন
8. **DELETE** - বর্তমান ফাইল মুছুন
9. **PLAY** - স্লাইডশো শুরু/বন্ধ করুন

**ওভারলে চালু করুন (নতুনদের জন্য প্রস্তাবিত):**

1. Settings → Player
2. **"Always show touch zones overlay"** চালু করুন
3. এখন আপনি একটি আধা-স্বচ্ছ গ্রিড দেখতে পাবেন

**চেষ্টা করুন:**

1. যেকোনো ছবি খুলুন
2. **উপরের-ডান কোণে ট্যাপ করুন** → পরের ফাইল
3. **উপরের-বাম কোণে ট্যাপ করুন** → আগের ফাইল
4. **মাঝামাঝি-ডান কোণে ট্যাপ করুন** → ফাইল মুছুন
5. **মাঝামাঝি-বাম কোণে ট্যাপ করুন** → ফাইল কপি করুন

**প্রয়োজন না হলে বন্ধ করুন:**
Settings → Player → "Always show touch zones overlay" = OFF

তারপর এর বদলে **কমান্ড প্যানেল বাটন** ব্যবহার করুন।

## ছবি সম্পাদনা করুন {#how-to-edit-photos}

**সমর্থিত অপারেশন:**

- ঘোরানো (৯০°, ১৮০°, ২৭০°)
- উল্টানো (আনুভূমিক, উলম্ব)
- ফিল্টার (Grayscale, Sepia, Negative)
- সমন্বয় (Brightness, Contrast, Saturation)

**ধাপসমূহ:**

1. ফুল-স্ক্রিন ভিউয়ারে **একটি ছবি খুলুন**
2. **"Edit"** বাটনে ট্যাপ করুন (অথবা মাঝামাঝি-বাম টাচ জোন)
3. **অপারেশন বেছে নিন:**
   - Rotate: রোটেট আইকনে ট্যাপ করুন
   - Flip: ফ্লিপ আইকনে ট্যাপ করুন
   - Filter: তালিকা থেকে নির্বাচন করুন
   - Adjust: স্লাইডার ব্যবহার করুন
4. **"Save"** ট্যাপ করুন

**নোট:**

- মূল ফাইলটি **ওভাররাইট** হয় (কোনো আনডু নেই!)
- **স্থানীয় ও নেটওয়ার্ক ফাইলের** জন্য কাজ করে
- সমর্থন করে: JPG, PNG, WEBP

## স্লাইডশো তৈরি করুন {#how-to-create-slideshow}

**ধাপসমূহ:**

1. ছবিসহ **যেকোনো ফোল্ডার খুলুন**
2. ভিউয়ার খুলতে **প্রথম ছবিতে** ট্যাপ করুন
3. **"Play"** বাটনে ট্যাপ করুন (অথবা নিচের-ডান টাচ জোন)
4. স্লাইডশো স্বয়ংক্রিয়ভাবে শুরু হয়

**গতি কাস্টমাইজ করুন:**

1. **ফোল্ডার সেটিংস সম্পাদনা করুন:**
   - প্রধান স্ক্রিন → ফোল্ডারে দীর্ঘ-প্রেস → Edit
2. **"Slideshow Interval"** পাল্টান:
   - দ্রুত: ২ সেকেন্ড
   - স্বাভাবিক: ৫ সেকেন্ড
   - ধীর: ১০ সেকেন্ড
3. **"Save"** ট্যাপ করুন

**স্লাইডশোর সময় নিয়ন্ত্রণ:**

- **স্ক্রিনে ট্যাপ করুন** → বিরতি/পুনরায় শুরু
- **বামে/ডানে সোয়াইপ করুন** → ফাইল এড়িয়ে যান
- **"Stop" ট্যাপ করুন** → স্লাইডশো থেকে বেরিয়ে আসুন

## ব্যাকগ্রাউন্ড মিউজিকসহ স্লাইডশো তৈরি করুন {#how-to-create-slideshow-with-background-music}

**প্রয়োজনীয়তা:**

- অন্তত একটি অডিও ফাইলসহ (MP3, FLAC, ইত্যাদি) ফোল্ডার/রিসোর্স
- **যেখানে পাওয়া যায়:** Standard, Lite, Legacy, XR / noLegal (Photos-এ অডিও সমর্থন নেই)

**সেটআপ:**

1. **Settings** → **Media** ট্যাব → **Images**
2. **"Play music during slideshow"** চালু করুন
3. **"Select Music Source"** বাটনে ট্যাপ করুন
4. আপনার মিউজিক ফাইলসহ একটি রিসোর্স বেছে নিন
5. **"Save"** ট্যাপ করুন অথবা সেটিংস বন্ধ করুন

**মিউজিকসহ স্লাইডশো চালানো:**

1. ছবি/ইমেজসহ **যেকোনো ফোল্ডার খুলুন**
2. ভিউয়ার খুলতে **প্রথম ছবিতে** ট্যাপ করুন
3. **"Play"** বাটনে ট্যাপ করুন (অথবা নিচের-ডান টাচ জোন)
4. ব্যাকগ্রাউন্ড মিউজিক বাজতে বাজতে স্লাইডশো শুরু হয়

**এটি যেভাবে কাজ করে:**

- নির্বাচিত মিউজিক রিসোর্স থেকে র‍্যান্ডমভাবে মিউজিক বাজে
- একটি ট্র্যাক শেষ হলে, পরের র‍্যান্ডম ট্র্যাক স্বয়ংক্রিয়ভাবে শুরু হয়
- ছবির ট্রানজিশনের সময়ও মিউজিক বাজতে থাকে
- স্লাইডশো থেকে বের হলে বা বিরতি দিলে মিউজিক থেমে যায়

**নোট:**

- মিউজিক শুধু **ছবি ও GIF-এর জন্য** বাজে (ভিডিও/অডিওর জন্য নয়)
- স্লাইডশোতে ভিডিও দেখালে মিউজিক স্বয়ংক্রিয়ভাবে থেমে যায়
- ছবিতে ফিরে গেলে মিউজিক আবার শুরু হয়
- স্থানীয় ও নেটওয়ার্ক মিউজিক উৎসের সাথে কাজ করে (SMB, SFTP, FTP)

**মিউজিক নির্বাচন কাস্টমাইজ করুন:**

- আপনার মিউজিক রিসোর্স ফোল্ডারে একাধিক মিউজিক ফাইল যোগ করুন
- অ্যাপ সব অডিও ফাইল র‍্যান্ডমভাবে শাফল করবে
- মিউজিক রিসোর্সে "Include Subfolders" চালু থাকলে সাবফোল্ডারে মিউজিক সাজান

**সমস্যা সমাধান:**

- মিউজিক না বাজলে: মিউজিক রিসোর্সে অন্তত একটি অডিও ফাইল আছে কিনা যাচাই করুন
- নেটওয়ার্কে মিউজিক আটকে গেলে: স্থানীয় ফোল্ডার বা দ্রুততর নেটওয়ার্ক সংযোগ ব্যবহার করুন
- SMB মিউজিকের জন্য: SMB রিসোর্স `file://` প্রোটোকল ব্যবহার করছে কিনা নিশ্চিত করুন (দেখুন TROUBLESHOOTING.md)

## FileDO দিয়ে একটি ফাইল এনক্রিপ্ট করুন {#how-to-encrypt-a-file-with-filedo}

একটি FileDO কনটেইনার হলো `.fd-sec` এক্সটেনশনসহ একটি ফাইল, যা একটি পাসওয়ার্ড দিয়ে লক করা অন্য একটি ফাইল ধারণ করে। এই ফরম্যাটটি FileDO ডেস্কটপ অ্যাপ ব্যবহার করা ফরম্যাটের মতোই, তাই এখানে তৈরি করা একটি কনটেইনার FileDO-তে খোলে এবং উল্টোভাবেও কাজ করে।

**কমান্ডগুলো চালু করুন:** **Settings** → **Management** ট্যাব → **FileDO encryption operations**। এই সুইচ চালু বা বন্ধ যাই থাকুক না কেন, একটি কনটেইনার খোলা কাজ করে।

**একটি ফাইল এনক্রিপ্ট করুন:**

1. Browse-এ, ফাইলের **⋮** মেনু খুলুন।
2. **Encrypt with FileDO** ট্যাপ করুন।
3. পাসওয়ার্ডটি দুইবার দিয়ে নিশ্চিত করুন।
4. কনটেইনারটি ফাইলের পাশে `<name>.fd-sec` হিসেবে দেখা যায়। মূল ফাইলটি অস্পৃষ্ট থাকে - আর প্রয়োজন না হলে নিজে থেকে এটি মুছুন।

**একটি ফাইল ডিক্রিপ্ট করুন:** `.fd-sec` ফাইলের **⋮** মেনু খুলুন, **Decrypt with FileDO** ট্যাপ করুন এবং পাসওয়ার্ড দিন। পুনরুদ্ধার করা ফাইলটি কনটেইনারের পাশে দেখা যায়।

**পুনরুদ্ধার ছাড়াই একটি কনটেইনার খুলুন:** সব ফাইল টাইপ দেখানো যেকোনো ফোল্ডারে `.fd-sec` ফাইলে ট্যাপ করুন। অ্যাপ শুধু পাসওয়ার্ড জিজ্ঞাসা করে এবং ভেতরের ফাইলটি ভিউয়ারে খোলে। ডিক্রিপ্ট করা কপিটি অ্যাপের প্রাইভেট স্টোরেজে থাকে এবং আপনি তালিকায় ফিরে গেলে মুছে যায়। পরের বার প্রম্পট এড়াতে **Remember the password and try it on every .fd-sec file** টিক দিন।

**যেখানে এটি কাজ করে:** ডিভাইস ফোল্ডার, সিস্টেম ফোল্ডার চুজারের মাধ্যমে বেছে নেওয়া ফোল্ডার, এবং SMB, SFTP ও FTP শেয়ার। একটি চুজার ফোল্ডার বা নেটওয়ার্ক শেয়ারে ফাইলটি একটি প্রাইভেট কপি হিসেবে প্রক্রিয়া করা হয়, ফলাফলটি একটি সাময়িক নামে লেখা হয়, আবার পড়ে যাচাই করা হয়, এবং তারপরই শুধু জায়গামতো নাম পাল্টানো হয় - একটি বিদ্যমান ফাইল কখনো ওভাররাইট হয় না।

**যদি এটি না খোলে:** বার্তাটি তিনটি সম্ভাব্য কারণের নাম বলে - একটি ভুল পাসওয়ার্ড, এমন একটি ফাইল যা কখনো কনটেইনার ছিল না, বা এমন একটি কনটেইনার যা পরিবর্তিত হয়েছে। এগুলো আলাদা করে চেনা যায় না। একটি প্রোগ্রাম বা স্ক্রিপ্ট ধারণকারী কনটেইনার খোলা হয় না।

**পাসওয়ার্ড ভুলে গেছেন?** এটি পুনরুদ্ধারের কোনো উপায় নেই। একটি খালি পাসওয়ার্ড ফাইলটিকে শুধু আকস্মিক দৃষ্টি থেকে লুকায়।

## ফোল্ডারের সাথে কাজ করুন (নির্বাচন, কপি, মুভ)

সাবফোল্ডারগুলো তালিকায় আলাদা আইটেম হিসেবে দেখানো হলে, একটি ফোল্ডার সারি একটি ফাইল সারির মতোই আচরণ করে।

**ফোল্ডার সারি চালু করুন:** **Settings** → **General** → **Show subfolders separately**। একই সুইচ রিসোর্স এডিটরে প্রতিটি রিসোর্সের জন্যও আছে।

**ধাপসমূহ:**

1. একটি একক ফোল্ডার নির্বাচন করতে ফোল্ডার সারির চেকবক্সে ট্যাপ করুন, অথবা সারিতে দীর্ঘ-প্রেস করুন। একটি ছোট ট্যাপ তখনও ফোল্ডারটি খুলবে।
2. **Copy**, **Move**, **Rename** বা **Delete** বেছে নিতে সারির **⋮** মেনু, বা নির্বাচন অ্যাকশন বার ব্যবহার করুন।
3. গন্তব্য বেছে নিন। একই নির্বাচনের ফাইল ও ফোল্ডার একটি অপারেশনেই একসাথে যায়।
4. গন্তব্যটি পুরো কাঠামো পায় - উৎস ফোল্ডারের ভেতরের প্রতিটি সাবফোল্ডার ও ফাইল।

**রিসোর্স টাইপ জুড়ে:** একটি ফোল্ডার ডিভাইস, SMB, SFTP, FTP এবং ক্লাউড রিসোর্সের মধ্যে কপি বা মুভ করা যায় - গ্রহণকারী দিকে কাঠামোটি পুনরায় তৈরি করা হয়।

**যা প্রত্যাখ্যাত হয়, এবং কেন:** কিছু কপি হওয়ার আগেই ফোল্ডারের ভেতরের একটি গন্তব্য, বা ফোল্ডারের নিজস্ব বর্তমান অবস্থান প্রত্যাখ্যাত হয়; সিস্টেম ফোল্ডার চুজারের মাধ্যমে বেছে নেওয়া গন্তব্য যার কোনো প্রকৃত ফাইল পাথ নেই, তা ফোল্ডার গ্রহণ করতে পারে না। বার্তাটি কারণ জানায়, যাতে আপনি অন্য একটি গন্তব্য বেছে নিতে পারেন।

**বাতিল করা:** একটি ফোল্ডার ট্রান্সফার অগ্রগতি দেখায় এবং থামানো যায়। যা ইতিমধ্যে লেখা হয়ে গেছে তা গন্তব্যেই থেকে যায় - আবার শুরু করার আগে ফোল্ডারটি পরীক্ষা করুন। একটি মুভ প্রতিটি উৎস আইটেম মোছে শুধু তার কপি সফল হওয়ার পরে, তাই মাঝখানে কিছু হারায় না।

**এটি ব্যাকগ্রাউন্ডে পাঠানো:** অগ্রগতি ডায়ালগের সামনে বসে দেখার দরকার নেই। এটি বন্ধ করে দিন এবং ট্রান্সফার চলতে থাকবে, Browse-এ নিচের একটি স্ট্রিপ হিসেবে দৃশ্যমান থেকে অপারেশন, শতাংশ এবং এখন কোন ফাইলে আছে তা দেখাবে। পুরো অগ্রগতি ডায়ালগ ফিরিয়ে আনতে সেই স্ট্রিপে ট্যাপ করুন, বাতিলসহ।

## ট্র্যাশ খালি করুন {#how-to-empty-trash}

মোছা ফাইলগুলো `.trash/` ফোল্ডারে যায় এবং ম্যানুয়ালি খালি না করা পর্যন্ত সেখানেই থাকে।

**পদ্ধতি ১: সব ট্র্যাশ খালি করুন**

1. **Settings** → **Management** ট্যাব → **File deletion and trash**
2. **"Clear Trash"** ট্যাপ করুন
3. মোছা নিশ্চিত করুন
4. সব রিসোর্স জুড়ে সব `.trash/` ফোল্ডার খালি হয়ে যায়

**পদ্ধতি ২: প্রতি-ফোল্ডার**

1. একটি ফাইল ম্যানেজার অ্যাপ ব্যবহার করুন
2. ফোল্ডারে যান (যেমন, `/storage/emulated/0/DCIM/Camera`)
3. `.trash/` সাবফোল্ডার খুঁজুন
4. ম্যানুয়ালি মুছুন

**সতর্কতা:** এটি **স্থায়ী মোছা**! ফাইল পুনরুদ্ধার করা যাবে না।

## টেক্সট ও PDF ফাইল দেখুন {#how-to-view-text-and-pdf-files}

**১. সমর্থন চালু করুন:**

1. **Settings** → **Media** ট্যাব → **Documents**
2. **"Support text files (.txt, .md, .log, .json, .xml)"** এবং **"Support PDF documents"** চালু করুন
3. নতুন ফাইলগুলো খুঁজে পেতে আপনার ফোল্ডারগুলো **Rescan** করুন।

**২. মিডিয়া টাইপ অনুযায়ী ফিল্টার করুন:**

1. প্রধান স্ক্রিনে (উপরে ডানদিকে) **Filter আইকনে** (ফানেল) ট্যাপ করুন।
2. মিডিয়া টাইপ নির্বাচন করতে চেকবক্স ব্যবহার করুন:
   - Images
   - Videos
   - Audio
   - GIFs
   - **Text** (নতুন)
   - **PDF** (নতুন)
3. শুধু নির্বাচিত ফাইল দেখতে **"Apply"** ট্যাপ করুন।

**৩. টেক্সট ভিউয়ার:**

- যেকোনো **.txt, .md, .log, .json, .xml** ফাইলে ট্যাপ করুন।
- পড়তে **স্ক্রল** করুন।
- **টেক্সট কপি করুন:** নির্বাচন ও কপি করতে দীর্ঘ-প্রেস করুন।

**৪. PDF ভিউয়ার (নতুন ফিচার):**

- যেকোনো **.pdf** ফাইলে ট্যাপ করুন।
- **নেভিগেশন কন্ট্রোল বার (নিচে):**
  - **Previous/Next:** কিনারায় বড় বাটন।
  - **Zoom In (+):** পাতা বড় করুন।
  - **Zoom Out (-):** পাতা ছোট করুন।
- **জেসচার:**
  - **উপরে সোয়াইপ:** পরের পাতায় যান।
  - **নিচে সোয়াইপ:** আগের পাতায় যান।
  - **চিমটি:** স্বাভাবিকভাবে জুম ইন/আউট করুন।
  - **ডাবল-ট্যাপ:** জুম রিসেট করুন।
  - **জুম বহন হয়:** আপনি যে জুম ও অবস্থানে পড়ছিলেন, পরের পাতা সেখানেই খোলে; ডাবল-ট্যাপ পুরো পাতা ফিরিয়ে আনে।
- **প্যান:** জুম করা থাকলে ঘোরাফেরা করতে টেনে নিন।
- **দীর্ঘ-প্রেস করে টেক্সট নির্বাচন করুন (Android 15+):** কোনো OCR পাস ছাড়াই, কোনো অপেক্ষা ছাড়াই, সরাসরি পাতার নিজস্ব টেক্সট লেয়ার থেকে একটি শব্দ নির্বাচন করতে চেপে ধরুন। একই শব্দ পাতায় একাধিকবার থাকলে, আপনার আঙুলের নিচেরটি নির্বাচিত হয়, প্রথমটি নয়। নির্বাচন বাড়াতে হ্যান্ডেলগুলো টেনে নিন, তারপর এটি কপি বা অনুবাদ করুন।

## ই-বুক পড়ুন (EPUB) {#how-to-read-e-books-epub}

**প্রয়োজনীয়তা:**

- **Settings** → **Media** ট্যাব → **Documents** → **Support EPUB e-books** চালু থাকতে হবে (ডিফল্টভাবে চালু)
- সমর্থিত ফরম্যাট: `.epub` (DRM-মুক্ত)

**ফিচার:**

- **চ্যাপ্টার নেভিগেশন:** বামে/ডানে সোয়াইপ করুন অথবা কমান্ড প্যানেল বাটন ব্যবহার করুন
- **সূচিপত্র:** একটি নির্দিষ্ট চ্যাপ্টারে যেতে তালিকা আইকনে <img src="icons/doc/ic_toc.png" alt="" width="18" height="18" style="vertical-align:text-bottom"> ট্যাপ করুন
- **ফন্ট সাইজ:** সমন্বয়যোগ্য (6px - 144px, ডিফল্ট 18px)
- **সার্চ:** বর্তমান বইয়ে টেক্সট খুঁজুন
- **থিম:** Light/Dark মোডে স্বয়ংক্রিয়ভাবে মানিয়ে নেয়

**নিয়ন্ত্রণ:**

1. ফাইল তালিকা থেকে **একটি EPUB ফাইল খুলুন**
2. কমান্ড প্যানেল টগল করতে **স্ক্রিনে ট্যাপ করুন**
3. **নিচের নিয়ন্ত্রণ ব্যবহার করুন:**
   - `Previous` / `next`: চ্যাপ্টার নেভিগেট করুন
   - `- A` / `+ A`: ফন্ট সাইজ কমান/বাড়ান
   - `Search` <img src="icons/doc/ic_search.png" alt="" width="18" height="18" style="vertical-align:text-bottom">: টেক্সট খুঁজুন
   - `TOC` <img src="icons/doc/ic_toc.png" alt="" width="18" height="18" style="vertical-align:text-bottom">: সূচিপত্র খুলুন
4. **সোয়াইপ জেসচার:** স্বাভাবিকভাবে চ্যাপ্টার পাল্টান

**নোট:** স্থানীয় ফাইল এবং নেটওয়ার্ক স্ট্রিম (SMB/SFTP/Cloud) উভয়ের সাথেই নির্বিঘ্নে কাজ করে। ধীর নেটওয়ার্কে বড় বই (>50MB) প্রথমবার লোড হতে কয়েক সেকেন্ড সময় নিতে পারে।

## নেটওয়ার্ক ফাইল বাহ্যিক অ্যাপে খুলুন {#how-to-open-network-files-in-external-apps}

**যেখানে পাওয়া যায়:** SMB, SFTP, FTP ফাইল

**ব্যবহারের ক্ষেত্র:** আপনি নেটওয়ার্ক ড্রাইভ থেকে একটি ডকুমেন্ট, ছবি বা ভিডিও একটি বিশেষায়িত বাহ্যিক অ্যাপে (যেমন, MS Office, Adobe Acrobat, VLC Player) খুলতে চান।

**ধাপসমূহ:**

1. আপনার নেটওয়ার্ক রিসোর্সে **ফাইলটিতে ব্রাউজ করুন**
2. প্লেয়ার/ভিউয়ারে খুলতে **ফাইলে ট্যাপ করুন**
3. উপরের টুলবারে **ⓘ (Info) বাটনে ট্যাপ করুন**
4. **"Download and Open"** বাটনে ট্যাপ করুন
5. **ডাউনলোডের জন্য অপেক্ষা করুন** - অগ্রগতি ডায়ালগ শতাংশ দেখায়
6. Android অ্যাপ চুজার থেকে **অ্যাপ বেছে নিন**

**যা ঘটে:**

- ফাইলটি আপনার `Downloads` ফোল্ডারে ডাউনলোড হয়
- একটি ডায়ালগে অগ্রগতি দেখানো হয় (0-100%)
- ডাউনলোড সম্পূর্ণ হলে, Android অ্যাপ চুজার দেখায়
- আপনি যেকোনো সামঞ্জস্যপূর্ণ অ্যাপে ফাইলটি খুলতে পারেন

**সমর্থিত প্রোটোকল:**

- ✅ SMB/CIFS নেটওয়ার্ক শেয়ার
- ✅ SFTP সার্ভার
- ✅ FTP সার্ভার
- ❌ ক্লাউড স্টোরেজ (এখনও প্রয়োগ করা হয়নি)

**পরামর্শ:**

- ডাউনলোড করা ফাইল `Downloads` ফোল্ডারে থেকে যায়
- আপনি পরে একটি ফাইল ম্যানেজার দিয়ে ম্যানুয়ালি মুছতে পারেন
- সব ফাইল টাইপের (ছবি, ভিডিও, ডকুমেন্ট, ইত্যাদি) সাথে কাজ করে
- বড় ফাইলের জন্য, ডাউনলোড কয়েক মিনিট নিতে পারে

**উদাহরণ ব্যবহার:**

- MS Word-এ একটি নেটওয়ার্ক ডকুমেন্ট সম্পাদনা করুন
- VLC Player-এ নেটওয়ার্ক ভিডিও চালান
- Adobe Acrobat-এ নেটওয়ার্ক PDF দেখুন
- মেসেজিং অ্যাপে নেটওয়ার্ক ছবি শেয়ার করুন

## গানের লিরিক্স দেখুন {#how-to-view-song-lyrics}

**প্রয়োজনীয়তা:**

- Artist ও Title মেটাডেটাসহ একটি অডিও ফাইল (MP3, FLAC, ইত্যাদি)।
- **ইন্টারনেট সংযোগ** প্রয়োজন (api.lyrics.ovh ব্যবহার করে)।

**ধাপসমূহ:**

1. ফুল-স্ক্রিন প্লেয়ারে **একটি অডিও ফাইল বাজান**।
2. উপরের কমান্ড প্যানেলে (অথবা কমান্ড মেনুতে) **"Lyrics"** বাটনে ট্যাপ করুন।
   - *নোট: বাটনটি শুধু অডিও ফাইলের জন্য দৃশ্যমান।*
3. অনুসন্ধান শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. লিরিক্স একটি স্ক্রলযোগ্য ডায়ালগে দেখানো হবে।

**অনুসন্ধান লজিক:**

1. অ্যাপ **Artist + Title** ট্যাগ দিয়ে খোঁজে।
2. ট্যাগ না থাকলে, এটি **ফাইলের নাম** পার্স করার চেষ্টা করে।

## স্বয়ংক্রিয় অনুবাদ {#auto-translation}

ছবি, PDF এবং টেক্সট ফাইল থেকে স্বয়ংক্রিয়ভাবে টেক্সট অনুবাদ করুন: **Tesseract** টেক্সট পড়ে, Google ML Kit অনুবাদ করে।

**মূল ফিচার:**

- **একটি পাঠ ইঞ্জিন:** **Tesseract** ল্যাটিন ও সিরিলিক টেক্সট পড়ে (English, Russian, Ukrainian, Bulgarian, Belarusian); Google ML Kit ফলাফল অনুবাদ করে এবং এর ভাষা শনাক্ত করে।
- **অফলাইন:** সম্পূর্ণভাবে ডিভাইসেই কাজ করে (প্রাথমিক মডেল ডাউনলোডের পরে)।
- **স্মার্ট ওভারলে:** অনূদিত টেক্সট মূল টেক্সটের উপরে পাঠযোগ্য প্যারাগ্রাফে ওভারলে হয়।

**সেটআপ:**

1. **Settings** → **Media** ট্যাব → **Other**
2. **"Enable Translation"** চালু করুন
3. **Source Language** নির্বাচন করুন:
   - **"Auto":** ইংরেজি মডেল দিয়ে টেক্সট পড়ে, তারপর অনুবাদের জন্য যা পড়া হয়েছে তার ভাষা শনাক্ত করে।
   - **নির্দিষ্ট ভাষা:** সেই ভাষার মডেল দিয়ে পড়ে - সিরিলিক টেক্সটের জন্য এটি বেছে নিন (যেমন, "Russian")।
4. **Target Language** নির্বাচন করুন (যেমন, English)।

**যেভাবে ব্যবহার করবেন:**

1. একটি **Image**, **PDF**, বা **Text** ফাইল খুলুন।
2. **কমান্ড প্যানেল** দেখাতে স্ক্রিনে ট্যাপ করুন।
3. **"Translate"** বাটনে (A→文 আইকন) ট্যাপ করুন।
4. **প্রথম রান:**
   - উৎস ভাষার জন্য টেক্সট মডেল ডাউনলোড নিশ্চিত করুন।
   - ভাষার জোড়ার জন্য অনুবাদ মডেল ডাউনলোড নিশ্চিত করুন।
5. অনূদিত টেক্সট একটি ওভারলেতে দেখা যাবে।

**নোট:** একটি ভাষার প্রথম ব্যবহার তার টেক্সট মডেল লোড করে, যা একটি ছোট বিলম্ব যোগ করে।

## হোম-স্ক্রিন স্মার্ট উইজেট {#home-screen-smart-widgets}

**যেখানে পাওয়া যায়:** সব ফ্লেভারে - উইজেট সেট প্রতিটি বিল্ডে থাকে; প্রতিটি উইজেট তার নিজস্ব সক্ষমতা অনুসরণ করে, তাই ভয়েস-রেকর্ডার উইজেটের জন্য মাইক্রোফোন সমর্থনসহ একটি বিল্ড দরকার (Lite বা Photos নয়), যেখানে ফটো-ফ্রেম ও রিসোর্স উইজেট সব জায়গায় কাজ করে

**দ্রুত পথ**

1. আপনার Android হোম স্ক্রিনে যান, দীর্ঘ-প্রেস করুন, এবং **Widgets** নির্বাচন করুন।
2. একটি **FastMediaSorter** উইজেট (যেমন 1×1 Quick Voice Recorder বা Camera OCR) আপনার স্ক্রিনে টেনে আনুন।
3. গন্তব্য ফোল্ডার ও ক্যাপচার সেটিংস কনফিগার করুন, তারপর **Save** ট্যাপ করুন।
4. আপনার হোম স্ক্রিন থেকে সরাসরি এক-ট্যাপে কাজগুলো চালাতে উইজেট ব্যবহার করুন।

**দৃশ্যকল্প ওয়াকথ্রু**

- ব্যাকগ্রাউন্ড অ্যাকশন তাৎক্ষণিকভাবে শুরু করার জন্য 1×1 উইজেটকে ডেডিকেটেড লঞ্চার আইকন হিসেবে ব্যবহার করুন (যেমন, ভয়েস রেকর্ডিং শুরু করতে একবার ট্যাপ করুন, এটি আপনার NAS-এ সংরক্ষণ করতে আবার ট্যাপ করুন)।
- ব্যাকগ্রাউন্ড ফাইল ট্রান্সফার নজরে রাখতে বা একটি "Run All" অপারেশন চালু করতে একটি **Scheduled Operations widget** সেট আপ করুন।
- একটি SMB শেয়ার থেকে সরাসরি আনা পারিবারিক ছবির ঘূর্ণায়মান স্লাইডশো দেখাতে একটি **Random Photo Frame widget** রাখুন।

**যখন এটি কাজে লাগে**

- আপনি প্রধান অ্যাপ ইন্টারফেস না খুলেই দৈনন্দিন ক্যাপচারের (রসিদ, ভয়েস মেমো) জন্য হোম স্ক্রিনে দ্রুত শর্টকাট চান।
- আপনার মিডিয়া নিয়ন্ত্রণ করতে বা তাৎক্ষণিকভাবে শিডিউল করা অপারেশন চালাতে সুস্পষ্ট উইজেট দরকার।

**এড়িয়ে চলুন**

- আপনার Android লঞ্চার কাস্টম উইজেট তৈরি সীমাবদ্ধ করলে উইজেট যোগ করার চেষ্টা করবেন না।

## অ্যাপটিকে আপনার হোম স্ক্রিন হিসেবে ব্যবহার করুন {#how-to-use-the-app-as-your-home-screen}

FastMediaSorter আপনার ডিভাইসের হোম স্ক্রিন দখল করে নিয়ে নিজস্ব একটি ডেস্কটপ দেখাতে পারে - আপনার ফোল্ডার, একটি ঘড়ি, আবহাওয়া, আপনার অ্যাপ, এবং একটি কিনারা বরাবর টাস্কবার। আপনি কখনো Windows ডেস্কটপ ব্যবহার করে থাকলে এটি পরিচিত মনে হবে: জিনিসগুলো যেখানে রাখেন সেখানেই থাকে, এবং একটি Start বাটন মেনু খোলে। একে লঞ্চার মোড বলা হয়, এবং এটি শুধু **Standard** ও **noLegal** বিল্ডেই আছে।

**চালু করা:**

1. **Settings → General** খুলুন এবং **Make this app the home screen** চালু করুন।
2. Android আপনাকে নিশ্চিত করতে বলবে। Android 10 ও তার পরের সংস্করণে এটি একটি প্রশ্ন - "Allow FastMediaSorter to be your Home app?" - তাই শুধু অনুমতি দিন। পুরনো সংস্করণে পরের বার Home চাপলে চিরাচরিত পছন্দটি দেখা যায়: FastMediaSorter বেছে নিয়ে **Always** ট্যাপ করুন, অথবা এখনই শুধু চেষ্টা করতে চাইলে **Just once**।
3. Home চাপুন। ডেস্কটপটি দেখা যাবে, ইতিমধ্যে প্রায় ডজনখানেক কার্যকর জিনিস দিয়ে ভরা - একটি ঘড়ি, আবহাওয়া, আপনার ফোল্ডার, একটি সার্চ বক্স - তাই প্রথম দিনই এটি খালি গ্রিড নয়।

একটি একেবারে নতুন ইনস্টলে একটি শর্টকাট আছে: প্রথম স্বাগত পাতায় **Use as home screen** টিক দিন। এটি একটি সিস্টেম ডায়ালগ দিয়ে সেটআপে বাধা দেয় না - পরে আপনি প্রথমবার **Settings → General** খুললে Android-এর নিশ্চিতকরণ আসে।

**ডেস্কটপে যা থাকে:**

| সেল টাইপ | এটি যা করে |
|-----------|--------------|
| Resource shortcut | আপনার যোগ করা একটি ফোল্ডার খোলে - এবং আপনি বেছে নেন এটি browse, slideshow বা play মোডে খুলবে কিনা |
| Gadget | সেকেন্ডসহ একটি ঘড়ি (অ্যালার্মের জন্য ট্যাপ করুন), আপনার এলাকার আবহাওয়া, এখন কী বাজছে, একটি অনুবাদক, এবং আরও দুই ডজনের বেশি |
| App shortcut | যেকোনো ইনস্টল করা অ্যাপ চালু করে; দীর্ঘ-প্রেস সেই অ্যাপের নিজস্ব দ্রুত অ্যাকশন তালিকা দেখায় |
| Contact cell | একজনের কার্ড খোলে, তাকে কল করে, SMS পাঠায়, বা তার মেসেঞ্জার কথোপকথন খোলে |
| App widget | Android হোম স্ক্রিনের জন্য অ্যাপ যে একই উইজেট দেয়, তা এখানে বসানো |

**টাস্কবার এবং Start মেনু:**

- টাস্কবারটি নিচের কিনারায় থাকে এবং এতে থাকে Start বাটন, আপনার সম্প্রতি ব্যবহৃত অ্যাপ, পিন করা অ্যাপ, এবং ঘড়ি, ব্যাটারি, নেটওয়ার্ক ও সিম সিগন্যালসহ একটি ছোট ট্রে।
- উপরে রাখতে চান? **Settings → General → System launcher settings → Taskbar → Taskbar position** Bottom এবং Top-এর মধ্যে পাল্টায়। Start মেনু বার অনুসরণ করে এবং বার উপরে থাকলে সেটিও উপর থেকে নামে।
- Start বাটন মেনু খোলে: FastMediaSorter খুলুন, আপনার রিসোর্স, একটি রিসোর্স যোগ করুন, Android সেটিংস, অ্যাপ সেটিংস, লঞ্চার সেটিংস, ডেস্কটপ কনটেন্ট সম্পাদনা করুন, এবং শেষে restart, power off এবং **Exit launcher mode**। Restart ও power off শুধু তখনই কাজ করে যখন আপনার ডিভাইস একটি সাধারণ অ্যাপকে সেটা করতে দেয় - বেশিরভাগ ফোনে এগুলো স্রেফ কিছুই করবে না।

**আপনার অ্যাপগুলো:** অ্যাপ গ্রিড অ্যাপগুলোকে ছোট হেডারসহ সেকশনে ভাগ করে। খুব কম খোলেন এমন একটি সেকশন গুটিয়ে নিতে হেডারে ট্যাপ করুন; গুটানো হেডারগুলো একে অপরের পাশে গুটিয়ে যায়, তাই ফাঁক না রেখে ডেস্কটপ ছোট হয়ে যায়। একটি নতুন ডেস্কটপ এটির বীজবপন করা অ্যাপগুলোকে দুই ভাগে ভাগ করে: আপনার ইতিমধ্যে ইনস্টল করা Google অ্যাপের জন্য একটি **Google** সেকশন, এবং আপনার নিজের অ্যাপ - মেসেঞ্জার, গেম এবং ডিভাইসে যা কিছু আপনি রেখেছেন - তার জন্য একটি **Apps** সেকশন। কোনো অ্যাপ দুটোতেই পড়ে না। তালিকার যেকোনো অ্যাপে দীর্ঘ-প্রেস করলে **Put on desktop** এবং **Pin to taskbar** পাওয়া যায়।

**সাজানো:**

- ডেস্কটপের একটি খালি বর্গে দীর্ঘ-প্রেস করুন। চারটি পছন্দ আসে: **Add an item..**, **Edit the desktop**, **Wallpaper**, **Launcher settings**। নতুন সেলটি ঠিক আপনি যে বর্গে চেপেছেন সেখানেই বসে।
- **Add an item..** একটি পিকার খোলে: একটি অ্যাপ, একটি ফিচার, আপনার একটি ফোল্ডার, একটি রেডিও স্ট্রিম, একজন ব্যক্তি, একটি সিস্টেম অ্যাকশন, একটি শিডিউল করা অপারেশন, একটি গ্যাজেট, বা একটি অ্যাকশন। গ্যাজেটগুলোর মধ্যে আছে নাও-প্লেয়িং কার্ড - এটি ডিভাইসে যা বাজছে তা দেখায় এবং এক ট্যাপে সেই প্লেয়ারে নিয়ে যায় - এবং অনুবাদক সেল।
- **Edit the desktop** এডিট মোড চালু করে, Start মেনুর **Edit desktop contents**-এর মতোই। সম্পাদনার সময়: একটি সেল সরাতে টেনে নিন, একটি গ্যাজেটের আকার পাল্টাতে এর কোণের হ্যান্ডেল টেনে নিন, কিছু যোগ করতে **+** ট্যাপ করুন, এবং একটি সেল সরাতে **Remove from desktop** বেছে নিন। শেষ হলে **Done** ট্যাপ করুন।
- কারো সাথে ডিভাইসটি শেয়ার করছেন? লঞ্চার সেটিংসে **Lock desktop** চালু করুন - তখন দীর্ঘ-প্রেস কিছুই করে না, তাই লেআউটটি ভুলবশত নড়ানো যায় না।
- অন্যান্য অ্যাপ এখানে নিজেদের শর্টকাট বসাতে পারে, ঠিক অন্য যেকোনো হোম স্ক্রিনের মতোই।

**পোর্ট্রেট এবং ল্যান্ডস্কেপ দুটি আলাদা ডেস্কটপ।** আপনি সোজাভাবে যা সাজান তা ডিভাইসটি পাশে ঘোরালে পাওয়া যায় না - প্রতিটি অভিমুখ তার নিজস্ব লেআউট ও নিজস্ব গুটানো সেকশন ধরে রাখে। আপনি সাজানো একটি ডেস্কটপ প্রথমবার ঘোরালে অ্যাপটি এটি একবার উল্লেখ করে। সেটিংসগুলো নিজেই - টাস্কবার অবস্থান, ঘনত্ব, ওয়ালপেপার - উভয়ের মধ্যে ভাগ করা।

**স্ক্রিনে বেশি, বা কম, ধরানো:** **Settings → General → System launcher settings → Desktop → Grid density**-তে **Sparse**, **Standard**, **Dense** এবং **Very dense** আছে - বড় সেল, বা প্রতি স্ক্রিনে বেশি শর্টকাট।

**আপনার পুরনো হোম স্ক্রিনে ফিরে যাওয়া** - এই তিনটির যেকোনো একটি:

- Start মেনু খুলুন, **Exit launcher mode** বেছে নিন, এবং নিশ্চিত করুন।
- **Settings → General**-এ **Make this app the home screen** বন্ধ করুন।
- সরাসরি Android-এর নিজস্ব হোম অ্যাপ তালিকায় যান: **Settings → General → System launcher settings → System → Change home screen**।

আপনার ডেস্কটপ লেআউট যেভাবেই হোক ধরে রাখা হয়, তাই মোডটি আবার চালু করলে আপনি যেভাবে রেখে গিয়েছিলেন ঠিক সেভাবেই ফিরে আসে।

**একটি সৎ সতর্কতা।** কিছু ডিভাইস পছন্দটি মনে রাখতে অস্বীকার করে। কিছু সস্তা আফটারমার্কেট কার রেডিও এবং অন্যান্য বিল্ট-ইন Android বক্স আপনি যাই বেছে নিন না কেন, প্রতিবার চালু হওয়ার সময় তাদের কারখানার হোম স্ক্রিন ফিরিয়ে আনে। এটি ডিভাইসের নিজস্ব ফার্মওয়্যার আপনাকে উপেক্ষা করছে, অ্যাপের কোনো ত্রুটি নয়, এবং কোনো অ্যাপ এটি এড়িয়ে যেতে পারে না। আপনারটি এমন আচরণ করলে, রিস্টার্টের পরে আবার FastMediaSorter-কে হোম অ্যাপ হিসেবে বেছে নিন - এবং তাতেও যদি এটি স্থির না থাকে, তাহলে সেই ডিভাইস স্রেফ এটির অনুমতি দেয় না।

## Android TV Box-এ FMS ব্যবহার করুন {#how-to-use-fms-on-android-tv-box}

FastMediaSorter যেকোনো Android TV বক্স বা সেট-টপ বক্সে (Xiaomi Mi Box, Nvidia Shield, Amazon Fire TV, সাধারণ Android বক্স) চলে। কোনো টাচস্ক্রিন দরকার নেই - অ্যাপটি সম্পূর্ণভাবে TV রিমোট বা ব্লুটুথ কীবোর্ড দিয়ে চালানো যায়।

**যা আপনার প্রয়োজন:**

- Android 8.0+ (Standard/Lite/Photos) বা Android 6.0+ (Legacy ফ্লেভার) চালিত একটি Android TV বক্স
- D-pad সহ একটি TV রিমোট, অথবা একটি ব্লুটুথ কীবোর্ড
- ঐচ্ছিক: হোম NAS (SMB), USB ড্রাইভ, বা মিডিয়াসহ SD কার্ড

**একটি TV রিমোট দিয়ে নেভিগেশন:**

| বাটন | অ্যাকশন |
|--------|--------|
| D-pad উপরে/নিচে/বামে/ডানে | আইটেমের মধ্যে ফোকাস সরান |
| OK / Enter | আইটেম খুলুন বা নিশ্চিত করুন |
| Back | আগের স্ক্রিনে যান |
| Backspace | Browse-এ এক ফোল্ডার উপরে যান |
| Red | নির্বাচিত ফাইল(গুলো) মুছুন |
| Green | নির্বাচিত ফাইল(গুলো) কপি করুন |
| Yellow | নির্বাচিত ফাইল(গুলো) সরান |
| Blue | নির্বাচিত ফাইলের নাম পাল্টান |
| Channel Up / Channel Down | প্লেয়ারে আগের / পরের ফাইল |

**ধাপসমূহ:**

1. Google Play থেকে অ্যাপটি ইনস্টল করুন অথবা একটি APK সাইডলোড করুন। Standard ফ্লেভার প্রস্তাবিত।
2. প্রধান স্ক্রিনে, একটি রিসোর্স যোগ করতে (+) বাটনে **OK** চাপুন।
3. USB/SD স্টোরেজের জন্য **Local Folder** বেছে নিন, অথবা SMB দিয়ে একটি NAS-এ সংযোগ করতে **Network folder** বেছে নিন।
4. রিসোর্স যোগ করার পরে, ফাইল ব্রাউজ করতে D-pad + OK দিয়ে এতে প্রবেশ করুন।
5. যেকোনো ভিডিও, ছবি বা অডিও ফাইল খুলুন - প্লেয়ারটি সম্পূর্ণভাবে রিমোট দিয়ে কাজ করে।
6. একটি স্লাইডশো শুরু করতে, একটি ছবির ফোল্ডার খুলুন এবং কমান্ড বারে **Slideshow** বাটনে যান।
7. স্লাইডশোতে ব্যাকগ্রাউন্ড মিউজিক যোগ করতে, **Settings → Media → Images**-এ যান, **Play music during slideshow** চালু করুন, এবং আপনার মিউজিক রিসোর্স বেছে নিন।

**পরামর্শ:**

- দীর্ঘ ফাইল তালিকায় দ্রুত স্ক্রল করতে D-pad উপরে/নিচে চেপে ধরুন।
- যেকোনো স্ক্রিনে একটি সারফেস-নির্দিষ্ট শর্টকাট রেফারেন্স খুলতে ব্লুটুথ কীবোর্ডে **F1** চাপুন।
- TV রিমোটের রঙিন কী **Settings → Management → Controls & Keybindings**-এ পুনরায় নির্ধারণ করা যায়।

## আপনার স্ক্রিন রেকর্ড করুন {#how-to-record-your-screen}

**যেখানে পাওয়া যায়:** Standard, XR/noLegal

**ধাপসমূহ:**

1. প্রধান-স্ক্রিন ওভারফ্লো মেনু (**Screen video recording**), Quick Launch প্যানেল, বা এজ জেসচারের **Start screen recording** অ্যাকশন থেকে এটি শুরু করুন।
2. আপনার স্ক্রিন বা শুধু এই অ্যাপ শেয়ার করার Android-এর প্রম্পট নিশ্চিত করুন - এটি প্রতিবার রেকর্ডিং শুরু করার সময় দেখা যায় এবং এড়ানো যায় না।
3. কোণে একটি ছোট পিলে **Recording screen** দেখা যায়, পজ/রিজিউম ও স্টপ নিয়ন্ত্রণসহ। একটি নোটিফিকেশনও **Stop** দেয়।
4. শেষ হলে **Stop** ট্যাপ করুন।

**যা ঘটে:**

- রেকর্ডিংটি স্ক্রিনে থাকা সবকিছু ধারণ করে, অডিওসহ আপনার সুইচ করা অন্য অ্যাপগুলোও।
- সম্পন্ন ভিডিওটি আপনার ডিভাইসের Movies ফোল্ডারে সংরক্ষিত হয়।

**নোট:** Android নিশ্চিতকরণ ধাপটি স্ক্রিন রেকর্ড করা যেকোনো কিছুর জন্য একটি সিস্টেম সুরক্ষা - এটি অ্যাপ বন্ধ করতে পারে এমন কিছু নয়।

## একটি ভয়েস নোট রেকর্ড করুন {#how-to-record-a-voice-note}

**যেখানে পাওয়া যায়:** Standard, Legacy, XR / noLegal

**ধাপসমূহ:**

1. ওভারফ্লো মেনুর **Voice recording** আইটেম, **Quick Recorder** হোম-স্ক্রিন উইজেট, বা এজ জেসচারের **Start audio recording** অ্যাকশন থেকে একটি রেকর্ডিং শুরু করুন।
2. কথা বলুন - একটি **Recording..** নির্দেশক (অথবা সামনে থাকা অ্যাপের উপরে একটি ভাসমান পিল) এটি চলছে দেখায়।
3. শেষ করতে **Stop and save** ট্যাপ করুন (অথবা উইজেট/জেসচারে আবার ট্যাপ করুন)।

**যা ঘটে:**

- রেকর্ডিংটি আপনার Settings-এ বেছে নেওয়া মাইক্রোফোন গন্তব্যে, অথবা কিছু সেট না থাকলে আপনার ডিভাইসের Recordings ফোল্ডারে সংরক্ষিত হয়।
- উইজেট বা এজ জেসচার থেকে একটি ভয়েস নোট শুরু করা অন্য একটি অ্যাপ ব্যবহার করার সময়ও কাজ করে - একটি ছোট ভাসমান নিয়ন্ত্রণ উপরে থেকে যায়, তাই আপনি ফিরে না গিয়েই এটি থামাতে পারেন।

**সংরক্ষণ ফোল্ডার কোথায় সেট করবেন:** Settings → Management → Voice recorder।

## ইন-অ্যাপ ক্যামেরা ব্যবহার করুন {#how-to-use-the-in-app-camera}

**যেখানে পাওয়া যায়:** Standard, Lite, Photos (শুধু ছবি), Legacy, XR/noLegal

**ধাপসমূহ:**

1. Browse-এ, টুলবার বা ওভারফ্লো মেনু খুলুন এবং **Capture with camera** (ছবি) বা **Record video** ট্যাপ করুন।
2. মত পাল্টালে ক্যামেরা স্ক্রিনেই **Photo** ও **Video**-এর মধ্যে সুইচ করুন।
3. একটি প্রিসেট চিপ (0.5x/1x/2x..) বা নিচের স্লাইডার দিয়ে জুম সেট করুন - দুটোই সিঙ্কে থাকে।
4. ফ্রেমটি আকার দিতে aspect বাটনে ট্যাপ করুন - **4:3**, **16:9** বা **Full screen**। ভিউফাইন্ডারটি নিজেই পাল্টে যায়, তাই আপনি যা দেখছেন তাই সংরক্ষিত ছবি হবে, এবং পরের বার ক্যামেরা খুললে পছন্দটি মনে রাখা হয় (আপনি না পাল্টানো পর্যন্ত 16:9)।
5. শট কীভাবে নেওয়া হবে তা বেছে নিতে শুটিং-দৃশ্য বাটনে ট্যাপ করুন - normal, night, portrait, selfie, macro, sport বা document। Macro ডেডিকেটেড ক্লোজ-ফোকাস লেন্সে যায়, selfie সামনের ক্যামেরায় পাল্টায়, sport এক্সপোজার সংক্ষিপ্ত রাখে যাতে গতি জমাট বাঁধে, এবং document ফ্ল্যাট পাতা ও স্ক্রিন ছবি তোলার জন্য টিউন করা। শুধু আপনার ডিভাইস আসলেই যে দৃশ্যগুলো দিতে পারে তা তালিকাভুক্ত হয়, সক্রিয়টি বাটনে নাম রাখা হয়, এবং হাত দিয়ে লেন্স পাল্টালে ক্যামেরা normal-এ ফিরে যায়।
6. ক্যাপচার করতে শাটারে (বা রেকর্ড বাটনে) ট্যাপ করুন। ফলাফলটি আপনি ব্রাউজ করছিলেন এমন রিসোর্সে - স্থানীয় বা নেটওয়ার্ক - সরাসরি সংরক্ষিত হয়।

**পরামর্শ:**

- সেই স্পটে ফোকাস ও এক্সপোজার সেট করতে ভিউফাইন্ডারের যেকোনো জায়গায় ট্যাপ করুন - একটি ছোট রিং কোথায় তা চিহ্নিত করে।
- এজ জেসচারের **Start video recording** অ্যাকশন ক্যামেরাটি ইতিমধ্যে Video মোডে খোলে এবং প্রিভিউ প্রস্তুত হওয়া মাত্র রেকর্ডিং শুরু করে - দ্রুত, তবে এই নির্দিষ্ট শর্টকাটটি ব্রাউজ করা রিসোর্সের বদলে আপনার ডিভাইসের Movies ফোল্ডারে সংরক্ষণ করে।
- প্রতিটি ক্যাপচার করা JPEG-এ GPS অবস্থান এম্বেড করতে ক্যামেরা সেটিংসের পাশে **Geotag photos** চালু করুন - এটি চালু না করা পর্যন্ত বন্ধ থাকে। তারপর **File Info** ক্যাপচারের তারিখ এবং ছবির EXIF GPS স্পট একটি ট্যাপযোগ্য লিংক হিসেবে দেখায়, যা আপনার ম্যাপ অ্যাপ বা ব্রাউজারে খোলে।

**ক্যামেরা সেটিংস কোথায় পাবেন:** Settings → Management → Photography।

## ডুপ্লিকেট ফাইল খুঁজুন এবং মুছুন {#how-to-find-and-delete-duplicate-files}

**ধাপসমূহ:**

1. Browse-এ একটি ফোল্ডার খুলুন, তারপর টুলবারে **overflow menu** <img src="icons/doc/ic_more_vert.png" alt="" width="18" height="18" style="vertical-align:text-bottom"> খুলুন।
2. নিজে মিল পর্যালোচনা করতে **Find Duplicates** ট্যাপ করুন, অথবা সাথে সাথে সরাতে **Find and Delete Duplicates** ট্যাপ করুন।
3. **Find Duplicates**-এর জন্য, অ্যাপ প্রতিটি গ্রুপে সবচেয়ে পুরনোটি বাদে প্রতিটি কপি আগে থেকেই নির্বাচন করে রাখে - নির্বাচনটি সমন্বয় করুন, তারপর **Delete Selected** ট্যাপ করে নিশ্চিত করুন।
4. **Find and Delete Duplicates** স্ক্যানের পরপরই একই আগে-থেকে-নির্বাচিত কপিগুলো সরিয়ে দেয়, কোনো নিশ্চিতকরণ ধাপ ছাড়াই - কিছু মোছার আগে দুবার যাচাই করতে চাইলে প্রথমে **Find Duplicates** ব্যবহার করুন।

**এর বদলে আকার অনুযায়ী পরিষ্কার করুন:**

1. একই ওভারফ্লো মেনু থেকে, **Delete by Size..** ট্যাপ করুন
2. **Smaller than** বা **Larger than** বেছে নিন, একটি আকার সেট করুন, এবং **Analyze** ট্যাপ করুন।
3. সংখ্যা ও মুক্ত হওয়া স্থান পর্যালোচনা করুন, তারপর নিশ্চিত করতে **Delete Files** ট্যাপ করুন।

**নোট:**

- স্ক্যানটি তিনটি ধাপে কনটেন্ট অনুযায়ী ফাইল মেলায় - আকার, তারপর একটি দ্রুত হ্যাশ, তারপর একটি সম্পূর্ণ SHA-256 চেক - তাই নাম পাল্টানো ডুপ্লিকেটও ধরা পড়ে।
- আকার অনুযায়ী মোছার আগে কতটা স্থান মুক্ত হবে তা দেখায়; নেটওয়ার্ক ও ক্লাউড উৎস ট্র্যাশ এড়িয়ে যায়, তাই সেই মোছা তাৎক্ষণিক ও স্থায়ী।

## আপনার ব্যবহারের পরিসংখ্যান দেখুন {#how-to-view-your-usage-statistics}

**ধাপসমূহ:**

1. **Settings → General → Statistics collection**-এ গিয়ে এটি চালু করুন।
2. ড্যাশবোর্ড খুলতে **Statistics** (টগলের ঠিক নিচে দেখা যায়) ট্যাপ করুন।

**আপনি যা দেখবেন:**

- সাজানো ফাইল, মুক্ত হওয়া স্থান, এবং মিডিয়া চালানোর সময়ের সারাংশ কার্ড।
- একটি টাইপ-অনুযায়ী বিভাজন (ছবি, ভিডিও, অডিও, ডকুমেন্ট..)।
- আরও বিস্তারিতসহ গুটানো যায় এমন সেকশন: অপারেশন, ক্যাপচার, ভিউয়িং, এডিটিং, উৎস, এবং সাধারণ ব্যবহার।

**একটি রিপোর্ট শেয়ার করুন:**

- **Send to author** একটি সারাংশসহ আপনার ইমেইল অ্যাপ খোলে, ডেভেলপারের ঠিকানায়।
- **Export** একই সারাংশ সাধারণ Android শেয়ার শিটের মাধ্যমে শেয়ার করে, তাই আপনি এটি যেকোনো জায়গায় সংরক্ষণ বা পাঠাতে পারেন।

**নোট:** আপনি এটি পাঠানো বা এক্সপোর্ট করা পছন্দ না করা পর্যন্ত সবকিছু আপনার ডিভাইসেই থাকে - গোপনীয়তার বিস্তারিত জানতে FAQ দেখুন।

## একটি SD কার্ড বা সংযুক্ত ড্রাইভ ব্যবহার করুন {#how-to-use-an-sd-card-or-connected-drive}

ফোন মাউন্ট করা একটি মেমরি কার্ড বা USB ড্রাইভ বিল্ট-ইন স্টোরেজের মতোই রিসোর্স ধারণ করে।

**ধাপসমূহ:**

1. **Add resource** খুলুন এবং একটি স্থানীয় ফোল্ডার যোগ করা শুরু করুন। **Removable media** সেকশনটি শুধু কিছু সংযুক্ত থাকা অবস্থায় দেখা যায়, এবং প্রতিটি ভলিউমের নাম ও খালি স্থান তালিকাভুক্ত করে।
2. ভলিউমে ট্যাপ করুন। অ্যাপ যদি পাথ দিয়ে এটি পৌঁছাতে না পারে, এটি কারণ ব্যাখ্যা করে এবং সিস্টেম ফোল্ডার চুজার খোলে - সেখানে একই ভলিউম বেছে নিন এবং আপনার চাওয়া ফোল্ডারে অ্যাক্সেস দিন।
3. রিসোর্সটি একটি removable-medium আইকনসহ তালিকায় যোগ হয়, তাই একটি কার্ড রিসোর্স এক নজরেই চেনা যায়।

**সরানো ও কপি করা:** সম্পূর্ণ ফোল্ডার তাদের পুরো সাবফোল্ডার কাঠামোসহ একটি কার্ডে ও ফিরে যায়, ঠিক যেভাবে এগুলো ডিভাইস ও একটি নেটওয়ার্ক রিসোর্সের মধ্যে চলে।

**যথেষ্ট জায়গা নেই:** যে কপি বা মুভ ধরবে না তা শুরু হওয়ার আগেই প্রত্যাখ্যাত হয়, এবং বার্তাটি মাধ্যমের নাম ও কতটা স্থান কম আছে তা জানায় - সেখানে জায়গা খালি করুন বা অন্য একটি গন্তব্য বেছে নিন।

**মাধ্যমটি বের করে নিলে:** এর রিসোর্সগুলো সরানো হয় না, শুধু অনুপলব্ধ চিহ্নিত হয়। কার্ডটি আবার সংযুক্ত করলে দ্বিতীয়বার সেট আপ না করেই এগুলো কাজ করে।

**Android 6-এ:** সিস্টেমটি মাউন্ট করা ভলিউম অ্যাপগুলোকে জানায় না, তাই সেই ডিভাইসগুলোতে removable সেকশন খালি থেকে যায়।

## সরাসরি পাথ দিয়ে যোগ করা ফোল্ডার পুনরায় সংযুক্ত করুন {#how-to-reconnect-a-folder-added-by-direct-path}

টাইপ করে বা ব্রাউজ করে পাথ দিয়ে যোগ করা একটি ফোল্ডার আপনার ছবি, ভিডিও ও মিউজিক দেখাতে পারে কিন্তু আপনার কোনো ডকুমেন্ট নয়। এটি এমন একটি স্ক্যান নয় যা এগুলো মিস করেছে: একটি স্টোর বিল্ড টেক্সট ফাইল, PDF এবং ই-বুক শুধু সিস্টেম চুজার দিয়ে সংযুক্ত করা একটি ফোল্ডার থেকেই পড়ে। পুনরায় সংযোগ করলে একই রিসোর্স সেই চুজার দিয়ে একই ফোল্ডারে নির্দেশ করে, এবং ডকুমেন্টগুলো দেখা যায়।

**ধাপসমূহ:**

1. মূল তালিকায় ফোল্ডারের কার্ডে থ্রি-ডট মেনু ট্যাপ করুন।
2. **Reconnect resource** বেছে নিন। সিস্টেম ফোল্ডার চুজার খোলে, ফোন যেখানে অনুমতি দেয় সেখানে ইতিমধ্যে সেই ফোল্ডারে।
3. একই ফোল্ডার বেছে নিন এবং নিশ্চিত করুন।
4. আপনি একটি ভিন্ন ফোল্ডার বেছে নিলে, অ্যাপ দুটি ফোল্ডারের নাম বলে এবং কিছু পাল্টানোর আগে জিজ্ঞাসা করে।

**যা থেকে যায়:** নাম, আপনার তালিকায় অবস্থান, PIN, আইকন, Quick Sort ভূমিকা, আপনার প্রিয় ও শিডিউল সবই টিকে থাকে - রিসোর্সটি পুনর্ঠিকানাকৃত হয়, নতুন করে তৈরি নয়।

**যেখানে আপনি এটি দেখবেন না:** যে বিল্ডগুলো এখনও সরাসরি পাথ দিয়ে ফোল্ডার পড়ে, এবং Android 10 ও তার পুরনো সংস্করণে, এন্ট্রিটি অনুপস্থিত কারণ সেখানে কিছুই অনুপস্থিত নেই।

## ক্যাপচার এবং ডাউনলোড কোথায় সংরক্ষিত হবে তা বেছে নিন {#how-to-choose-where-captures-and-downloads-are-saved}

ইন-অ্যাপ ক্যামেরার ছবি, স্ক্রিনশট, স্ন্যাপশট এবং স্বয়ংক্রিয়-ডাউনলোড করা ফাইল প্রতিটি আপনার বেছে নেওয়া একটি ফোল্ডারে লেখে, এবং সেই ফোল্ডারটি আপনার রিসোর্সগুলোর একটি হতে হয় না।

**ধাপসমূহ:**

1. আপনি যা সংরক্ষণ করছেন তার সেটিং খুলুন - capture, screenshot, snapshot বা auto-download।
2. গন্তব্য ফোল্ডার বেছে নিন। সিস্টেম ফোল্ডার ব্রাউজার খোলে, তাই আপনি কখনো অ্যাপে যোগ না করা একটি সহ যেকোনো স্থানীয় ফোল্ডারের দিকে নির্দেশ করতে পারেন।
3. সেই ফোল্ডারটি শুধু সেই সেটিংয়ের জন্য লেখার গন্তব্য হয়ে যায়। এটি আপনার সাধারণ রিসোর্স তালিকার বাইরে থাকে, তাই স্ক্রিনশটের জন্য একটি স্ক্র্যাচ ফোল্ডার বেছে নিলে প্রধান স্ক্রিন গোছালো থাকে।

**পরামর্শ:**

- চারটি সেটিংয়ের প্রতিটির নিজস্ব গন্তব্য আছে - স্ক্রিনশট এবং ক্যামেরার ছবি সম্পূর্ণ ভিন্ন জায়গায় যেতে পারে।
- আপনি বরং সবকিছু একটি জায়গায় রাখতে চাইলে এগুলোর একাধিককে একটি ফোল্ডারের দিকে নির্দেশ করা ঠিক আছে।

### ক্যাপচার ফাইলের নাম

নতুন ক্যাপচার `prefix_yyMMdd_HHmmss` প্যাটার্ন ব্যবহার করে। স্থিতিশীল প্রিফিক্সগুলো হলো `photo`, `screenshot`, `audio`, `video`, `screen_video`, এবং `video_frame`, তাই ফাইলের নাম তার উৎস চিহ্নিত করে। গন্তব্য ফোল্ডারে ইতিমধ্যে একটি নাম থাকলে, অ্যাপ এক্সটেনশনের আগে ` (2)` প্রত্যয় যোগ করে। ক্যামেরায় ম্যানুয়ালি দেওয়া একটি ফাইলের নাম একটি ওভাররাইড হিসেবে থেকে যায় এবং পাল্টানো হয় না।

## অন্য অ্যাপ থেকে শেয়ার করা ফাইল গ্রহণ করুন {#how-to-receive-files-shared-from-another-app}

যেকোনো অ্যাপের শেয়ার শিট FastMediaSorter-এ ফাইল পাঠাতে পারে, যা তারপর আপনি চাওয়া জায়গায় সেগুলো কপি করে।

**ধাপসমূহ:**

1. অন্য অ্যাপে, ফাইল বা ফাইলগুলো শেয়ার করুন এবং **FastMediaSorter** বেছে নিন।
2. receive স্ক্রিনে গন্তব্য ফোল্ডার বেছে নিন।
3. কপি শুরু করুন।

**এর জন্য অপেক্ষা করার দরকার নেই।** receive স্ক্রিন বন্ধ হওয়ার পরেও কপিটি চলতে থাকে, কাজ করার সময় একটি নোটিফিকেশন অগ্রগতি দেখায় এবং শেষ হলে একটি ফলাফল নোটিফিকেশন দেয়। অ্যাপ ছেড়ে যান, ডিভাইস লক করুন, চালিয়ে যান - ট্রান্সফারটি সেই স্ক্রিন খোলা থাকার সাথে বাঁধা নয়।

Standard, Lite, Photos ও Legacy বিল্ডে পাওয়া যায়।

## বিল্ট-ইন প্রোগ্রামগুলো ব্যবহার করুন {#how-to-use-the-built-in-programs}

**যেখানে পাওয়া যায়:** সব ফ্লেভারে - প্রোগ্রাম মেনু ও প্যানেল প্রতিটি বিল্ডে থাকে, কিন্তু প্রতিটি প্রোগ্রাম তার নিজস্ব সক্ষমতা অনুসরণ করে: Network Monitor-এর জন্য দরকার Standard বা noLegal, Wear কম্প্যানিয়নের জন্য দরকার Standard বা noLegal, মিনি-গেমটি XR ও noLegal-এ অনুপস্থিত, এবং Mirror-এর জন্য দরকার একটি সামনের ক্যামেরা যেখানে Settings-এ camera capture চালু আছে। ক্যালকুলেটর, সামনের ফ্ল্যাশলাইট এবং System information প্রতিটি বিল্ডে আছে।

ব্রাউজিং ও ফাইল চালানোর পাশাপাশি, অ্যাপটি ছোট বিল্ট-ইন প্রোগ্রামের একটি সেট বহন করে - একটি ক্যালকুলেটর, একটি স্ক্রিন ল্যাম্প, একটি নেটওয়ার্ক মনিটর, একটি ভয়েস রেকর্ডার এবং আরও অনেক কিছু। এগুলো ডিফল্টভাবে বন্ধ থাকে: প্রতিটি নিজস্ব সেটিং দিয়ে চালু হয়, এবং বেশিরভাগ ডেডিকেটেড সুইচ একসাথে **Settings → Management**-এ থাকে।

**দ্রুত পথ**

1. **Settings → Management**-এ যান এবং আপনার চাওয়াগুলো চালু করুন - যেমন **Calculator**, **Front flashlight**, **Network Monitor**, **Mini-game** বা **System information**।
2. প্রধান উইন্ডো ড্রপডাউন মেনু খুলুন। আপনার চালু করা প্রোগ্রামগুলো সেখানে তালিকাভুক্ত থাকে।
3. একটি চালাতে ট্যাপ করুন।

**একটি প্রোগ্রাম কোথায় দেখা যায়**

একটি প্রোগ্রাম চারটি পৃষ্ঠতল পর্যন্ত অফার করা যায়, এবং প্রতিটি পৃষ্ঠতল একই একক তালিকা থেকে তার কনটেন্ট ও ক্রম নেয়, তাই এগুলো কখনো একে অপরের থেকে সরে যায় না:

- **প্রোগ্রাম মেনু** - মূল-উইন্ডো ড্রপডাউন, এবং যে প্রোগ্রাম প্যানেল এটি পুনরাবৃত্তি করে।
- **App-launch panel** - দ্রুত-অ্যাক্সেস ওভারলে।
- **Home-screen widget** - শুধু যেসব প্রোগ্রামের একটি আছে তার জন্য; অ্যাপের নিজস্ব উইজেট পিকার থেকে এটি পিন করুন।
- **Launcher desktop** - অ্যাপটিকে আপনার হোম স্ক্রিন হিসেবে ব্যবহার করলে, একটি প্রোগ্রাম চালু করলে স্বয়ংক্রিয়ভাবে এর সেল যোগ হয়।

**সেটে যা আছে**

যে ক্রমে এগুলো দেখা যায়:

- **Quick capture** - সরাসরি অ্যাপে একটি ছবি তুলুন।
- **Voice recording** - একটি ভয়েস নোট রেকর্ড করুন।
- **Calculator** - ইতিহাস ও মেমরি স্লটসহ একটি সায়েন্টিফিক ক্যালকুলেটর।
- **Network Monitor** - সক্রিয় লিংক, Wi-Fi, মোবাইল, ব্লুটুথ এবং লোকেশনের জন্য লাইভ রিডিং, সাথে একটি ট্রেসরুট যা হপ বাই হপ একটি হোস্টের পথ ধরে হাঁটে এবং একটি হপ কিছুই উত্তর না দিলেও গণনা করতে থাকে।
- **Photo OCR translate** - টেক্সট তুলুন এবং অনুবাদ করুন।
- **Screen video recording** - স্ক্রিন রেকর্ড করুন।
- **Download by link** - একটি পেস্ট করা লিংক থেকে ফাইল আনুন।
- **Mini-game** - অ্যাপে বিল্ট-ইন ছোট গেম।
- **System information** - Settings না খুলেই পৌঁছানো যায় এমন একটি ডিভাইস রিপোর্ট।
- **Wear Companion** - ওয়াচ ব্রিজ বহনকারী বিল্ডগুলোতে, ওয়াচ স্ক্রিন।
- **Front flashlight** - স্ক্রিনটিকে নিজেই একটি ল্যাম্পে পরিণত করে: এটি পূর্ণ উইন্ডো ব্রাইটনেসে সাদা রঙে খোলে, একটি উলম্ব সোয়াইপ ব্রাইটনেস পাল্টায়, উপরে-বামে একটি ছোট বাটন অন্য একটি রং বেছে নেয় ও মনে রাখে, এবং একটি একক ট্যাপ এটি বন্ধ করে। শুধু উইন্ডো ব্রাইটনেস স্পর্শ করা হয়, তাই পরে আপনার ডিভাইস সেটিং অপরিবর্তিত থাকে।
- **Water flashlight** - ভেজা হাতের জন্য একই আলো। এটি ক্যামেরা ফ্ল্যাশ ও স্ক্রিন একসাথে জ্বালায়, তারপর স্ক্রিন লক করে: সময় ও একটি ছোট রিমাইন্ডারই আপনি দেখেন, এবং কাচ স্পর্শ করলে কিছুই ঘটে না - একটি ভলিউম বাটন এটি বন্ধ করে। সিস্টেম বারও চলে যায়, তাই একটি ভেজা হাত একটি নেভিগেশন বাটনের মুখোমুখি হয় না; একটি ইচ্ছাকৃত সোয়াইপ এখনও এগুলো ফিরিয়ে আনতে পারে। বৃষ্টি ও গোসলের জন্য তৈরি - এই দুই জায়গায় যেখানে কাচ আপনার বদলে পানির প্রতি সাড়া দেয়। একটি সিস্টেম জেসচার দিয়ে বের হলে আলোটিও নিভে যায়, তাই এটি কখনো পকেটে জ্বলতে থাকে না। ওয়াচে কোনো ফ্ল্যাশ নেই, তাই শুধু ডিসপ্লেই আলো। এটি একটি ওয়াচ বা ফোনে বিল্ট-ইন water-lock মোড প্রতিস্থাপন করে না; কোনো অ্যাপ সেটি চালু করতে পারে না।
- **Mirror** - ফোনটিকে একটি আলোকিত আয়নায় পরিণত করে: সামনের ক্যামেরা আপনার মুখ আলোকিত করা একটি উজ্জ্বল সাদা ক্ষেত্রের ভেতরে স্ক্রিন ভরে দেয়, এবং ছবিটি একটি আসল আয়না যেভাবে দেখায় সেভাবে উল্টানো থাকে, স্ক্রিন না ছেড়েই আলো বন্ধ করতে একটি কোণার বাটনসহ। জুম প্রিসেট - x1, x2, x3, x5 - নিচের বামে থাকে এবং x3-এ খোলে। একটি ফটো বাটন ও একটি ভিডিও বাটন Capture ব্যবহার করা একই ফোল্ডারে সরাসরি সংরক্ষণ করে, ভিডিও শব্দসহ। জুম, ফ্লিপ ও ব্যাকলাইট অবস্থা রানের মধ্যে মনে রাখা হয়। শুধু উইন্ডো ব্রাইটনেস বাড়ে, কখনো আপনার ডিভাইসের নিজস্ব সেটিং নয়, তাই আপনি স্ক্রিন ছাড়ার মুহূর্তে ফোনটি স্বাভাবিকে ফিরে আসে। সামনের ক্যামেরাসহ যেকোনো ডিভাইসে ডিফল্টভাবে চালু, যতক্ষণ Settings-এ camera capture নিজেই বন্ধ করা না থাকে।

প্যানেল ও লঞ্চার অতিরিক্তভাবে সরাসরি ক্যামেরা শর্টকাট বহন করে - একটি ছবি তুলুন ও পাঠান, একটি ছবি তুলুন ও সম্পাদনা করুন, একটি ছবি তুলুন ও অনুবাদ করুন, একটি ভিডিও রেকর্ডিং শুরু করুন, এবং ক্যামেরা ফোল্ডার খুলুন।

**যখন এটি কাজে লাগে**

- অ্যাপ না ছেড়ে, বা একটি ভিড়াক্রান্ত ফোনে একটি আলাদা অ্যাপ না খুঁজে, আপনি একটি ক্যালকুলেটর বা টর্চ চান।
- আপনি অ্যাপটিকে আপনার হোম স্ক্রিন হিসেবে চালান এবং প্রায়ই ব্যবহার করা একটি টুলের জন্য এক-ট্যাপ সেল চান।

**এড়িয়ে চলুন**

- Water flashlight একটি স্বাগত-হোম সোয়াইপে টিকে থাকবে বলে আশা করবেন না - একটি সিস্টেম নেভিগেশন জেসচার এখনও এটি ছেড়ে যায়, এবং আলো তার সাথেই নিভে যায়।
- প্রতিটি বিল্ডে প্রতিটি প্রোগ্রাম আশা করবেন না - উপরের তালিকাটি সম্পূর্ণ সেট, এবং অন্তর্নিহিত সক্ষমতা ছাড়া একটি বিল্ড সেই এন্ট্রি স্রেফ দেখায় না।

## আপনার সহকারীকে মিডিয়া খুঁজে খুলতে বলুন {#how-to-ask-your-assistant-to-find-and-open-media}

**যেখানে পাওয়া যায়:** প্রতিটি বিল্ডে, Android 16 ও তার পরে। পুরনো Android সংস্করণ স্রেফ ফিচারটি দেয় না, এবং এর জন্য অ্যাপে কিছু চালু করার দরকার নেই।

Android 16+-এ অ্যাপটি সিস্টেমের সাথে একগুচ্ছ সহকারী অ্যাকশন নিবন্ধন করে - AppFunctions, Android-এর নিজস্ব ভাষায়। আপনার ডিভাইসের সহকারী তখন নাম দিয়ে এগুলো কল করতে পারে, তাই আপনি নিজে অ্যাপ খুলে ব্রাউজ করার বদলে একটি ছবি, ভিডিও বা কম্পিউটার ফোল্ডার মুখে চাইতে পারেন।

**আপনি যা চাইতে পারেন**

- **আপনার মিডিয়া খুঁজুন** - সহকারী আপনার কথাগুলো অ্যাপের সার্চে দেয় এবং যা মিলেছে তা দেখায়।
- **একটি মিডিয়া ফাইল খুলুন** - একটি ছবি, ভিডিও বা ট্র্যাক সরাসরি অ্যাপের ভিউয়ার বা প্লেয়ারে খোলে।
- **একটি কম্পিউটার ফোল্ডার খুলুন** - আপনার নেটওয়ার্ক বা ক্লাউড ফোল্ডারের একটি ব্রাউজার স্ক্রিনে খোলে।

**দ্রুত পথ**

1. ডিভাইসটি Android 16 বা তার পরের সংস্করণ চালাচ্ছে এবং একটি সিস্টেম সহকারী সেট আপ করা আছে তা নিশ্চিত করুন।
2. আপনার চাওয়া মিডিয়ার জন্য সহকারীকে বলুন, ডিভাইসে একাধিক মিডিয়া অ্যাপ থাকলে FastMediaSorter-এর নাম নিন।
3. অ্যাপটি ফলাফলের উপর খোলে - সার্চ তালিকা, ফাইল, বা আপনার চাওয়া ফোল্ডার।

**যখন এটি কাজে লাগে**

- আপনার হাত ব্যস্ত - রান্না করা, গাড়ি চালানো, একটি শিশু ধরে রাখা - এবং ফোল্ডারের মধ্যে ট্যাপ করা একটি অপশন নয়।
- আপনার মনে আছে একটি ফাইলের নাম কী কিন্তু কোথায় রেখেছেন তা নয়।

**এড়িয়ে চলুন**

- Android 16-এর নিচে এটি আশা করবেন না: সহকারী অ্যাকশনগুলো নতুন সিস্টেমের অংশ, তাই একটি পুরনো ফোনে সহকারী এগুলো দেখতে পাবে না।
- একটি PIN-সুরক্ষিত ফোল্ডারে পৌঁছাতে সহকারীর কাছে আশা করবেন না - লকটি এখনও প্রযোজ্য, এবং ফোল্ডারটি যথারীতি এর PIN চায়।
