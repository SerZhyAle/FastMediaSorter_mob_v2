# 📝 Terminology Reference

## Core terms

- **Resource** — a connected source of files (Local/SMB/SFTP/FTP/Cloud)
- **Destination** — a predefined quick-sort target folder
- **Quick Sort** — one-tap copy/move to configured destinations
- **Favorites** — locally stored list of marked files
- **Touch Zones** — 3×3 interactive areas in player mode
- **Soft Delete** — moving local files into `.trash/` instead of immediate hard delete

## Additional terms

- **Flavor** — product variant (`standard`, `lite`, `photos`, `legacy`)
- **Browse** — file list/grid view for a selected resource
- **Player** — full-screen media/document viewer
