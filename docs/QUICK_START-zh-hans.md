*5 分钟快速上手！适合初学者的简明指南。*

## 选择你的版本 📱

FastMediaSorter v2 提供**面向日常手机和平板的五个版本** - Standard、Lite、Photos、Legacy、FOSS - 再加上**两个头显与旁加载版本**，VR 和 noLegal。共七个版本；确切的功能对照表由构建自动生成，见 [FLAVOR_MATRIX.md](FLAVOR_MATRIX.md)。选择最适合你需求的一个：

| 版本 | 适合人群 | 主要特性 |
|--------|----------|--------------|
| **Standard** ⭐ | 所有人 | 全部功能：视频、照片、音频、文档、云存储、翻译 + 网络电台 / Streams |
| **Lite** | 更小的下载包 | 照片、视频和本地音频文件；不支持云、网络文件夹、Internet Streams、文档或翻译，且应用退到后台时音频会停止 |
| **Photos** | 摄影爱好者 | 仅支持图片，配合云存储和网络文件夹；不支持视频、音频和 Streams |
| **Legacy** | 较旧的 Android（API 23+） | 完整媒体功能 + SMB/FTP/SFTP 和云；面向较旧的 Android（API 23+）构建 |
| **FOSS** | F-Droid 用户 | 来自设备本身以及 SMB/FTP/SFTP 的视频、照片、音频、文档和 EPUB；不含专有 SDK，因此不支持云、Streams、OCR 和翻译 |
| **VR / noLegal** | XR 头显 / 旁加载 | VR 是商店合规的头显版本；noLegal 是旁加载版本，增加了沉浸式播放器和仅限旁加载的附加功能 |

**👉 大多数用户应下载 "Standard" 版本以获得完整体验。**

## 首次启动：选择你的设备档案（30 秒）🧭 {#first-launch-choose-your-device-profile-30-seconds-}

欢迎流程一开始就说明应用是什么，用的是**角色**而不是功能罗列：在带有启动器的版本上，它是运行整台设备的**主屏幕**，并邀请你把它变成自己的样子；它也是**文件管理器**；照片、视频、音乐、GIF、文档和文本的**播放器**；设备上、网络中和云端资源的**阅读器**；在支持的版本上还有 **streams**；**一键分类**；以及在带有手表伴侣的版本上，**手表应用**本身。每个卡片都会说明它具体指的是哪些协议和服务 - SMB、FTP、SFTP、Google Drive、OneDrive、Dropbox - 并且只列出你手中这个版本真正能打开的内容，所以你在那里看到的内容对你手中的版本来说都是真实可信的。

在第一次启动时，就在语言选择器下方，欢迎界面会询问**你打算怎么使用这台设备**。选择一个档案，应用就会以适合这种风格的默认设置启动 - 布局、缩略图、全屏、保持屏幕常亮、后台音频、删除/移动确认、阅读视图、链接下载、播放器控件、streams 的启动界面，以及在有启动器可用的情况下，桌面本身。这只是一次性的起始预设，而不是锁定 - 之后你可以更改任何设置。

- 🎯 **推荐徽标：** 应用会为你的设备猜测一个可能合适的档案，并标记为**（推荐）**。如果猜对了，你几乎什么都不用做。
- ⏭️ **跳过：** 赶时间？**跳过**只会应用推荐的档案。这里没有错误答案。
- ⚙️ **稍后更改：** **设置 → 通用 → 设备档案**。在那里切换时会显示一个简短的**警告**，明确告诉你新档案会覆盖多少项设置，并要求你确认。在你确认之前不会有任何改变。如果某个档案不会覆盖任何设置，就会直接应用，不再询问。
- 🧩 **其他 / 自定义：** 完全保留你当前的设置。不应用任何预设 - 适合喜欢手动调整的人。
- ⬆️ **从旧版本升级？** 你的档案会显示为**其他**，之前的设置保持不变 - 没有自动应用任何预设。仍然想用一个？在设置中选择一个档案。
- 🎚️ **下一步 - 选择应用要做什么：** 选完档案后，一个简短界面会让你开启或关闭各项能力（文件管理器、音频、视频、文档、文字识别、翻译）。可选部件会当场下载，下载完成即刻启用 - 之后都可以在设置中更改。

**11 种档案：**

- 📱 **个人智能手机** - 触控布局、后台同步、默认安全确认
- 🖥️ **平板与桌面模式** - 平板、Chromebook、三星 DeX；网格布局、大号缩略图、多窗口浏览
- 📺 **电视 / 机顶盒** - 方向键/遥控器导航、大号按钮、没有细小的触控控件
- 🚗 **车载主机** - 超大号按钮、屏幕保持常亮、播放优先于文件操作
- 🎬 **媒体播放器** - 照片、视频、音乐，支持幻灯片放映和续播
- 🖼️ **相框** - 直接进入幻灯片放映；文件操作退居其次
- 🎞️ **视频播放器** - 快速视频播放和缩略图
- 🎵 **音频播放器** - 后台音频和正在播放界面
- 📚 **电子书阅读器** - PDF、EPUB 和文本阅读
- 🥽 **VR 头显** - 支持的硬件上的 3D/360° 布局和沉浸式控制
- 🧩 **其他 / 自定义** - 保持默认设置不变，不应用任何预设

## 第 1 步：添加你的第一个文件夹（30 秒）

1. **打开应用** - 你会看到主界面
2. **点按 "+" 按钮**（右下角）
3. **选择 "Local Folder"**（或 Network/Cloud）
4. **选择一个文件夹**
5. **完成！** 文件夹会出现在你的列表中

> 💡 **提示：** 对于网络驱动器（SMB），使用全新的 **"Scan Network"** 按钮即可自动发现设备！

---

## 第 2 步：浏览你的文件（30 秒）

1. **点按**你刚添加的文件夹（或长按）
2. 你会看到**所有媒体文件**以缩略图形式显示
3. **切换视图：**
   - 网格图标 = 查看缩略图
   - 列表图标 = 查看文件详情

> 💡 **提示：** 使用**筛选按钮**（漏斗图标）只显示照片、视频，甚至是 **Text/PDF 文档**。

---

## 第 3 步：查看与导航（1 分钟）

1. **点按任意照片/视频**打开全屏查看器
2. **向左滑动** = 下一个文件
3. **向右滑动** = 上一个文件
4. 在照片上**双指缩放**
5. **点按屏幕**显示/隐藏控件

### 触控区域（屏幕区域）

屏幕被划分为 9 个区域用于快速操作：

```
┌─────────┬─────────┬─────────┐
│  BACK   │  COPY   │ RENAME  │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  PREV   │  MOVE   │  NEXT   │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ COMMAND │ DELETE  │  PLAY   │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**图例：**

1. 返回 | 2. 复制 | 3. 重命名
2. 上一个 | 5. 移动 | 6. 下一个
3. 命令 | 8. 删除 | 9. 播放

> 💡 **启用叠加层：** 设置 → 播放器 → "Always show touch zones overlay"

---

## 第 4 步：快速分类文件（2 分钟）

**设置快速分类文件夹：**

1. 进入 **设置** → **管理** → **Quick Sort destinations**
2. 点按 **"Add to Quick Sort"**
3. 选择你想用来分类文件的文件夹（例如 "Best Photos"、"Vacation"）
4. **每个文件夹都会获得一个编号**（0-9）和颜色

**现在你可以立即分类文件：**

1. 在查看照片时，**点按左下角**（COPY 区域）
2. **或点按命令面板上的 "1" 按钮**
3. 文件被复制到你的 1 号快速分类文件夹！

## 第 5 步：进阶功能（可选）

### 网络驱动器（SMB / SFTP / FTP）

点按 **"+"** → **Network** → **SMB** 或 **SFTP / FTP**

- **SMB：** 使用 **"Scan Network"** 自动发现你的 NAS 和网络设备。应用会搜索你的本地网络，并显示可用的 SMB 共享。
- **SFTP/FTP：** 手动输入主机 IP、用户名和密码。

### 云存储

点按 **"+"** → **Cloud Storage**

- 支持：**Google Drive**、**OneDrive**、**Dropbox**
- 点按 "Sign in.."，授予权限，然后选择文件夹。

### 收藏系统

- 查看任意文件时**点按星形图标**
- 访问所有收藏：主菜单 → **Favorites** 标签页
- 在所有文件夹中都能用！

### 自动翻译

- 在 **设置** → **媒体** → **其他** 中启用
- 在查看图片/PDF/文本时点按 **Translate** 按钮（A→文）
- **镜头式模式：** 在设置中启用 "Lens-style overlay"，获得类似 Google Lens 的原位翻译

### EPUB 电子书

- 在 **设置** → **媒体** → **文档** 中启用
- 添加包含 .epub 文件的文件夹 → 文件会显示 "E" 徽标
- **章节导航：** 左右滑动，或使用上一个/下一个按钮
- **目录：** 点按 📋 按钮打开章节列表
- **字体大小：** 使用 -A/+A 按钮（6-144px 范围）
- **搜索：** 点按 🔍 按钮在书中查找文本
- **深色/浅色主题：** 自动适配应用主题

### 幻灯片背景音乐

- 添加一个包含音频文件的文件夹作为资源
- 进入 **设置** → **媒体** → **图片** → **"Play music during slideshow"**
- 从下拉列表中选择你的音乐资源
- 开始任意幻灯片放映 - 音乐会自动播放！
- **提示：** 在幻灯片放映期间点按曲目名称即可跳到另一首随机曲目

### 按键重新映射

- 设置 → **管理** → **Controls & Keybindings** - 将任意控制重新分配到不同的按键、按钮或手柄输入
- 内置 70 个默认绑定；点按 **Reset** 即可恢复
- 在任意界面按 **F1** 查看该界面当前生效的按键绑定

### 相机拍摄

- 在浏览界面中，点按工具栏上的**相机按钮**打开应用内相机，直接保存到当前资源 - 本地或网络
- **缩放：** 点按一个预设（0.5x/1x/2x..），或拖动滑块获得精确的缩放级别
- **拍摄场景：** 一个按钮即可提供普通、夜景、人像、自拍、微距、运动和文档模式 - 仅显示你设备实际支持的模式
- **点按对焦：** 在取景器中任意位置点按即可在该处对焦并设置曝光
- **照片或视频：** 拍摄前即可在相机界面切换模式

### 屏幕截取与边缘手势

- 打开 **设置 → 管理 → Edge screen gestures → Gesture overlay**，然后从左边缘滑动即可截屏、拍照，或开始屏幕/语音/视频录制 - 详情参见 [HOW_TO.md](HOW_TO-zh-hans.md) 中的边缘手势场景

### 链接自动下载

- 在任意浏览器或聊天应用中，通过 Android 分享面板将 `http(s)` 链接分享给 FastMediaSorter
- 应用会自动下载该媒体文件并保存到你选定的资源

### 网络直播流（电台与 IPTV）

- 从主窗口下拉菜单打开 **Streams**（或在首次出现时通过 **Settings > Media > Streams**）。
- 点按工具栏末端的 **⋮**：**Add stream** 用于添加电台网址（http/https mp3/aac、HLS .m3u8、RTSP），或 **Import from URL** 用于导入 `.m3u` 播放列表。
- 搜索框旁的 **Video**、**Audio** 和 **Own** 按钮会拆分列表：Video 和 Audio 显示该类型的目录及已导入频道，Own 显示你通过网址添加的所有频道。再次点按已点亮的按钮可显示全部频道。
- 从 **Extensions** 界面下载 FastMediaSorter 精选电台目录，获得一个可搜索、可按主题和语言筛选的库。
- 电台通过底部常驻栏内嵌播放 - 电台列表保持可见。视频/RTSP 流在全屏播放器中打开；返回键回到列表。
- **适用于 Standard、Legacy、noLegal 和 VR。Lite 和 Photos 中完全没有 Streams 界面 - 那里没有任何协议可用，因为根本没有入口。**

### 主屏幕小组件

FastMediaSorter v2 提供多种主屏幕小组件。长按主屏幕 → Widgets → FastMediaSorter 即可浏览。主要包括：

- **Resource Shortcut** - 点按即可立即打开任意一个资源
- **Continue Reading** - 直接启动应用并进入幻灯片放映模式

## 常见问题

**问：删除的文件去哪了？**  
答：会移动到同一位置的 `.trash/` 文件夹。使用 "Empty Trash" 可永久删除。

**问：我能撤销移动操作吗？**  
答：可以！在 5 秒内点按 "Undo" 按钮（或右下角区域）。

**问：如何编辑照片？**  
答：打开照片 → 点按 "Edit" 按钮 → 旋转、翻转、滤镜、调整亮度。
