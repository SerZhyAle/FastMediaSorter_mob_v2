# 🚀 Быстрый Старт - FastMediaSorter v2

*Начните за 5 минут! Простое руководство для новичков.*

[English](QUICK_START.md) | [Українська](QUICK_START_UK.md)

---

## Выберите вашу версию 📱

FastMediaSorter v2 доступен в **4 версиях**. Выберите подходящую для вас:

| Версия | Для кого | Ключевые функции |
|--------|----------|------------------|
| **Standard** ⭐ | Для всех | Полный функционал: видео, фото, аудио, документы, облако, перевод |
| **Lite** | Меньший размер | Только фото и видео (без аудио, облака) |
| **Photos** | Фотолюбители | Только изображения, оптимизировано для фото |
| **Legacy** | Локальные медиа | Видео, аудио, фото - без облака и сети |

**👉 Большинству пользователей рекомендуется скачать версию "Standard" для полного опыта.**

---

## Шаг 1: Добавьте свою первую папку (30 секунд)

1. **Откройте приложение** - вы увидите главный экран
2. **Нажмите кнопку "+"** (правый нижний угол)
3. **Выберите "Локальная папка"** (или Сеть/Облако)
4. **Выберите папку** с фото или видео (например, DCIM/Camera)
5. **Готово!** Папка появится в вашем списке

> 💡 **Совет:** Для сетевых дисков (SMB) используйте новую кнопку **"Сканировать сеть"** для автоматического поиска устройств!

---

## Шаг 2: Просмотр файлов (30 секунд)

1. **Нажмите на папку**, которую только что добавили (или долгое нажатие)
2. Вы увидите **все ваши медиафайлы** в виде миниатюр
3. **Переключение вида:**
   - Иконка сетки = миниатюры
   - Иконка списка = детали файла

> 💡 **Совет:** Используйте **кнопку фильтра** (иконка воронки), чтобы показать только фото, видео или даже **Текстовые/PDF документы**.

---

## Шаг 3: Просмотр и навигация (1 минута)

1. **Нажмите любое фото/видео** для открытия полноэкранного плеера
2. **Свайп влево** = следующий файл
3. **Свайп вправо** = предыдущий файл
4. **Щипок для зума** на фото
5. **Нажмите на экран** для показа/скрытия управления

### Сенсорные зоны (Области экрана)

Экран разделен на 9 областей для быстрых действий:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПИЯ  │ ПЕРЕИМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  ПРЕД.  │ ПЕРЕМ.  │  СЛЕД.  │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ КОМАНДЫ │ УДАЛИТЬ │ ИГРАТЬ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. Назад  | 2. Копия | 3. Переим.
2. Пред.  | 5. Перем.| 6. След.
3. Команды| 8. Удал. | 9. Играть

> 💡 **Включить наложение:** Настройки → Воспроизведение → "Всегда показывать зоны нажатия"

## Шаг 4: Быстрая сортировка (2 минуты)

**Настройка папок Quick Sort:**

1. Перейдите в **Настройки** → вкладка **Quick Sort**
2. Нажмите **"Добавить в Quick Sort"**
3. Выберите папки, куда хотите сортировать файлы (например, "Лучшие фото", "Отпуск")
4. **Каждая папка получает номер** (0-9) и цвет

**Теперь вы можете сортировать мгновенно:**

1. При просмотре фото, **нажмите левый нижний угол** (зона COPY)
2. **ИЛИ нажмите кнопку "1"** на панели команд
3. Файл скопирован в вашу папку Quick Sort #1!

## Шаг 5: Продвинутые функции (Опционально)

### Сетевой диск (SMB / SFTP / FTP)

Настройки → Добавить папку → **SMB** или **SFTP / FTP**

- **SMB:** Используйте **"Сканировать сеть"** для автоматического обнаружения вашего NAS и сетевых устройств. Приложение просканирует локальную сеть и покажет доступные SMB-ресурсы.
- **SFTP/FTP:** Введите IP хоста, пользователя и пароль вручную.

### Облачное хранилище

Настройки → Добавить папку → **Cloud Storage**

- Поддерживает: **Google Drive**, **OneDrive**, **Dropbox**
- Нажмите "Войти..", дайте права и выберите папки.

### Система Избранного

- **Нажмите иконку звезды** при просмотре файла
- Доступ ко всем избранным: Главное меню → вкладка **Избранное**
- Работает во всех папках!

### Авто-перевод

- Включите в **Настройки** → **Документы** → **Enable Translation**
- Нажмите кнопку **Перевести** (A→文) при просмотре Фото/PDF/Текста
- **Режим линзы:** Включите "Наложение в стиле линзы" в настройках для переводов в стиле Google Lens на месте

### Электронные книги EPUB

- Включите в **Настройки** → **Документы** → **Support EPUB**
- Добавьте папку с .epub файлами → Файлы показывают значок "E"
- Навигация по главам: Свайп влево/вправо, кнопки назад/вперед
- Оглавление: Кнопка 📋 для списка глав
- Размер шрифта: Кнопки -A/+A (диапазон 14-32px)
- Поиск: Кнопка 🔍 для поиска текста
- Темная/светлая тема: Автоматическая адаптация к теме приложения
- Сетевые файлы: Работает с SMB/SFTP/FTP/Cloud

### Фоновая музыка для слайд-шоу

- Добавьте папку с аудио файлами как ресурс
- Перейдите в **Настройки** → **Аудио** → Включите **"Фоновая музыка для слайд-шоу"**
- Выберите ваш музыкальный ресурс из выпадающего списка
- Запустите любое слайд-шоу - музыка играет автоматически!
- **Совет:** Нажмите на название трека во время слайд-шоу, чтобы переключиться на другой случайный трек

### Переназначение клавиш

- Настройки → **Input** → **Keybindings** - переназначьте любое действие на другую клавишу, кнопку или ввод геймпада
- 70 встроенных привязок по умолчанию; нажмите **Reset** для восстановления
- Нажмите **F1** на любом экране, чтобы увидеть активные привязки для этой области

### Захват фото

- В режиме Обзора нажмите **кнопку камеры** в панели инструментов, чтобы сделать снимок и сохранить его прямо в текущий ресурс - локальный или сетевой

### Автозагрузка по ссылке

- В любом браузере или мессенджере поделитесь ссылкой `http(s)` в FastMediaSorter через «Поделиться»
- Приложение загрузит медиафайл и сохранит его в выбранный ресурс автоматически

### Виджеты для главного экрана

FastMediaSorter v2 предлагает два типа виджетов:

1. **Виджет "Ярлык ресурса":**
   - Долгое нажатие на главный экран → Виджеты → FastMediaSorter
   - Выберите "Resource Shortcut"
   - Выберите, какую папку привязать
   - Нажатие на виджет мгновенно открывает эту папку

2. **Виджет "Продолжить чтение":**
   - Добавьте виджет "Continue Reading"
   - Нажатие запускает приложение в режиме слайд-шоу
   - Идеально для быстрых сеансов просмотра фото

## Частые вопросы

**В: Куда попадают удаленные файлы?**
О: В папку `.trash/` в том же месте. Используйте "Очистить Корзину" для полного удаления.

**В: Можно ли отменить перемещение?**
О: Да! Нажмите кнопку "Отмена" (или правую нижнюю зону) в течение 5 секунд.

**В: Как редактировать фото?**
О: Откройте фото → Кнопка "Редактировать" → Поворот, отражение, фильтры, яркость.
