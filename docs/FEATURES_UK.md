# FastMediaSorter v2 — Повний перелік можливостей

*Останнє оновлення: 2026-03-13*

Цей документ є актуальним реєстром усіх користувацьких функцій, реалізованих у застосунку. Оновлюйте файл при додаванні або зміні будь-якої функції.

---

## 1. Управління ресурсами (джерелами)

- Додавання ресурсів таких типів: **Локальна папка**, **SMB** (Windows-шара / NAS), **FTP**, **SFTP**, **Google Drive**, **Dropbox**, **OneDrive**
- Редагування налаштувань ресурсу після створення
- Видалення ресурсу
- **Профілі ресурсу** (швидкі пресети): Аудіотека, Відеотека, Фотосховище, Документи, Всі файли
- **Налаштування ресурсу**: підтримувані типи медіа, режим сортування, режим відображення, видимість панелі команд, завантаження мініатюр, PIN-захист, режим «лише читання», коментар, сканування підпапок, кешування списку файлів, показ підпапок як елементів, показ прихованих файлів
- **Зміна порядку ресурсів** — ручне перетягування на головному екрані
- **Фільтрація ресурсів** на головному екрані (рядок пошуку/фільтра)
- Перемикання між режимами **Список / Сітка** на головному екрані
- **Перевірка з'єднання** для мережевих і хмарних ресурсів
- **Режим «лише читання»** — вимикає всі файлові операції для конкретного ресурсу
- **PIN-захист** ресурсу (запит коду при відкритті)
- **Управління обліковими даними** мережі — зашифроване зберігання; аудит відстежує дату останнього використання і виводить застарілі записи
- **Збереження та відновлення позиції** в каталозі (позиція прокрутки + останній переглянутий файл)
- **Кешування списку файлів** — збереження в БД для прискореного повторного завантаження

## 2. Перегляд медіафайлів

- Режими відображення **Список** і **Сітка**
- **Режими сортування**: Ім'я ↑↓ / Дата ↑↓ / Розмір ↑↓ / Тип ↑↓ / Виконавець ↑↓ / Назва ↑↓ / Тривалість ↑↓ / Дата зйомки ↑↓ / Випадковий / Ручний
- **Панель фільтра**: за підрядком імені, діапазоном дат, діапазоном розміру, типом медіа
- **Множинний вибір** для пакетних операцій
- **Навігація по підпапках** з історією переходів
- **Показ підпапок як елементів** — окремі елементи, що клікаються, для кожної підпапки
- **Показ прихованих файлів** (файли і папки, що починаються з `.`)
- **Режим «Всі файли»** — ігнорує фільтр типів, показує все включно з бінарними файлами
- **Рекурсивне сканування** підпапок
- Завантаження мініатюр (автоматично вимикається при > 10 000 файлів; можна вимкнути вручну для ресурсу)
- **Мініатюри відео** з першого кадру (опція; можна вимкнути для повільних мереж)
- **Метадані файлу** в рядку списку (EXIF, тривалість, роздільна здатність, розмір)
- **Індикатор прогресу сканування** з кнопкою СТОП (з'являється через 5 с)
- **Пагінація** для великих каталогів (вмикається автоматично)
- **Вбудований аудіоплеєр** у списку — відтворення аудіо без переходу до плеєра
- Підтримка **навігації з клавіатури** в переглядачі файлів

## 3. Файлові операції

- **Копіювання** до налаштованого каталогу призначення (локального, SMB, FTP, SFTP)
- **Переміщення** до налаштованого каталогу призначення
- **Видалення** — безповоротне або до Кошика (налаштовується)
- **Перейменування** файлу на місці
- **Відновлення** видаленого файлу з Кошика
- **Скасування** останньої операції копіювання / переміщення / видалення
- **Пакетні операції** над вибраними файлами
- **Поділитися** — відкрити файл у зовнішньому застосунку
- **Безпечний режим** — діалоги підтвердження перед видаленням / переміщенням (головний перемикач у Налаштуваннях)
- Опція **перезапису** при копіюванні/переміщенні
- **Діалог прогресу** операції з індикатором у байтах і швидкістю передачі
- **Міжпротокольні передачі**: SMB↔Локально, FTP↔Локально, SFTP↔Локально, SMB↔SMB, FTP↔FTP, SFTP↔SFTP, Локально↔FTP, Локально↔SFTP, Локально↔SMB

## 4. Управління каталогами призначення

- До **10 кнопок призначення** з кольоровим маркуванням у плеєрі
- Будь-який налаштований ресурс із правом запису може бути призначенням
- Опція **перейти до наступного файлу після копіювання**
- Панелі копіювання / переміщення, що згортаються, у плеєрі
- **Додавання/видалення з Обраного** безпосередньо з плеєра

## 5. Перегляд зображень

- Повноекранний режим із **масштабуванням жестом «щипок»**
- **Обрізання за екраном** (заповнення екрана при збігу орієнтації)
- **Динамічний фон** — розмитий колір зображення на фоні
- **Поворот зображення** за годинниковою / проти годинникової стрілки (зі збереженням у файл)
- **Відзеркалення зображення** горизонтально / вертикально (зі збереженням)
- **Регулювання яскравості / контрасту / насиченості** (зі збереженням)
- **Кольорові фільтри**: Чорно-білий, Сепія, Негатив (зі збереженням)
- **OCR** — розпізнавання тексту із зображення (ML Kit Latin + Tesseract)
- **Оверлей перекладу** у стилі Google Lens: блоки перекладу поверх оригінальних позицій
- **Надіслати до Google Lens**

- **Вилучення всіх кадрів** — кожен кадр зберігається як окремий файл

## 8. Аудіоплеєр

- Відтворення на основі ExoPlayer
- **Фонове відтворення** — постійний сервіс переднього плану з повідомленням; музика продовжує грати при згортанні застосунку або блокуванні екрана
- **Медіакерування в повідомленні** (відтворення/пауза, попередній/наступний трек)
- **Обкладинка альбому** — з метаданих файлу + онлайн-пошук через iTunes API (опція; можна обмежити Wi-Fi)
- **Пошук і відображення тексту пісні** — повноекранний оверлей із текстом (онлайн-пошук)
- **Випадкові фото під час відтворення** — фотографії з вибраного ресурсу як візуальний фон
- **Анімації порожнього стану / візуалізатор**: пульс AVD, смуги на Canvas, хвилі на Canvas, спектр
- **Індикатор вінілової платівки** — невелика анімована платівка, що обертається, у куті екрана
- **Таймер сну** (спільний з відеоплеєром)
- Відображення метаданих: виконавець, назва, альбом, тривалість

## 9. Слайдшоу

- Автоматична зміна зображень і GIF із налаштовуваним інтервалом (**1 – 3600 секунд**)
- **Випадковий порядок** відтворення
- **Фонова музика** з вибраного ресурсу під час слайдшоу зображень/GIF
- **Відтворення відео/аудіо до кінця** у змішаному слайдшоу (зміна після завершення відтворення, а не за таймером)
- Відображення зворотного відліку (3 – 2 – 1) перед зміною слайда
- Налаштування інтервалу слайдшоу на рівні ресурсу (перевизначає глобальне налаштування)

## 11. Перегляд EPUB

- **Пошук у розділі та по всій книзі** (до 500 результатів)

- **Сімейство шрифтів**: За замовчуванням, Serif, Monospace

- **Міжрядковий інтервал** (множник 1.0 – 3.0×)
- **Горизонтальні поля** — регулювання
- **Збереження та відновлення** останнього читаного розділу

## 13. Переклад і OCR (загальна функція для всіх переглядачів)

- **ML Kit OCR** (латинський шрифт) — вилучення тексту із зображень і PDF
- **Tesseract** — підтримка додаткових шрифтів
- **Автоматичне визначення мови джерела** (ML Kit Language Identification)
- **Переклад на пристрої** на налаштовувану цільову мову (ML Kit Translation; моделі завантажуються за потреби)
- **Оверлей у стилі Google Lens** — блоки перекладу розміщуються над оригінальними координатами (зображення і PDF)
- Доступно в: переглядачі зображень, PDF, тексту, EPUB
- Налаштовувані **мова джерела** (авто або явна) і **цільова мова**
- Відображення результатів OCR із налаштуванням **розміру** та **сімейства шрифту**

## 14. Мережеві джерела

- **SMB** (Samba / Windows-шари / NAS) — повний перегляд і файлові операції
- **FTP** — повний перегляд і файлові операції
- **SFTP** — повний перегляд і файлові операції
- **Автовиявлення мережевих ресурсів** — сканування локальної підмережі (порти 445 / 21 / 22), результати з'являються в реальному часі
- **Тест швидкості мережі** — вимірювання швидкості читання/запису в Мбіт/с, рекомендована кількість потоків; результати зберігаються в ресурсі
- **Налаштовуваний паралелізм** мережевих операцій: 1, 2, 4, 8, 12 або 24 потоки
- **Пул з'єднань** для SMB (повторне використання аутентифікованих сесій)
- **Обмеження з'єднань** — захист повільних і перевантажених джерел від надмірного навантаження
- **Фонова періодична синхронізація** списків файлів (WorkManager, налаштовуваний інтервал 1 – 24 год)

## 18. Налаштування

| Розділ | Основні параметри |
|---|---|
| Загальні | Мова інтерфейсу, заборона переходу в сплячий режим, режим міні-керування, логін/пароль за замовчуванням для мережі |
| Типи медіа | Вкл./Викл.: зображення, GIF, відео, аудіо, текст, PDF, EPUB; фільтри мінімального та максимального розміру |
| Зображення | Завантаження в повному розрізненні (для масштабування), обрізання за екраном |
| Аудіо | Онлайн-пошук обкладинки (iTunes API), лише по Wi-Fi, випадкові фото під час відтворення, фоновий сервіс, анімація порожнього стану |
| Текст / PDF / EPUB | Номери рядків, теми оформлення, рендеринг Markdown, підсвічування синтаксису, режим прокрутки PDF, кольоровий режим PDF, міжрядковий інтервал EPUB, поля EPUB |
| Переклад | Увімкнути переклад, мова джерела, цільова мова, оверлей Google Lens, кнопка Google Lens, розмір/сімейство шрифту OCR |
| Відтворення | Режим сортування за замовчуванням, інтервал слайдшоу, фонова музика для слайдшоу, відтворення до кінця, розмір іконки, видимість панелі команд, оверлей зон дотику, PiP, мініатюри відео, прогрів плеєра |
| Призначення | Увімкнути копіювання, увімкнути переміщення, перезапис, перехід до наступного після копіювання, максимум призначень (1 – 10), увімкнути скасування |
| Безпечний режим | Головний перемикач діалогів «Підтвердити видалення» і «Підтвердити переміщення» |
| Кошик | Відновлюваний кошик або постійне видалення, запит підтвердження |
| Мережа / Синхронізація | Увімкнути фонову синхронізацію, інтервал (год), кількість паралельних потоків |
| Кеш | Розмір дискового кешу Glide (512 МБ – 16 ГБ) |
| Резервне копіювання | Експорт налаштувань у JSON, імпорт із JSON, резервне копіювання/відновлення через Google Drive |

## 21. Фонові та системні сервіси

- **Очищення Кошика** — планове завдання WorkManager видаляє файли старші за термін зберігання
- **Очищення тимчасових файлів** — видалення незавершених файлів завантаження при запуску
- **Відкладене відкликання облікових даних** — планове очищення застарілих або відкликаних записів
- **Синхронізація MediaStore** після файлових операцій (галерея та інші застосунки отримують актуальні дані)
- **Збереження позиції відтворення** в БД — відновлення позиції для аудіо, відео та EPUB
