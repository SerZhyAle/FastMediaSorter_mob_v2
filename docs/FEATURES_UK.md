# FastMediaSorter v2 — Чим додаток відрізняється від інших

*Останнє оновлення: 2026-05-02*

FastMediaSorter — це єдиний медіаменеджер для Android, який охоплює локальне сховище, домашній NAS (SMB/FTP/SFTP) і три хмарні провайдери в одному додатку. Цей документ описує те, в чому додаток перевершує альтернативи — а не те, що вміє кожен медіадодаток на ринку.

**Платформа:** Android 8.0+ (API 26) — версії Standard, Lite, Photos. Версія Legacy підтримує Android 6.0+ (API 23) з тим самим набором функцій, але без хмарних інтеграцій. Працює на телефонах, планшетах, Android TV-приставках (тачскрін не потрібен) та Android-магнітолах. Підтримується Chrome OS через Google Play (ARC++): вибір тек — через системний діалог, Cast може бути обмежений мережею контейнера.

## 1. Управління ресурсами / джерелами

Основна ідея: один список ресурсів охоплює всі типи сховищ — локальні папки, SMB-шари, FTP/SFTP-сервери, Google Drive, Dropbox та OneDrive. Вам не потрібно перемикати додатки або повторно проходити автентифікацію залежно від того, де знаходиться файл.

- **Профілі ресурсів (швидкі шаблони)**: Нові ресурси попередньо налаштовані з розумними параметрами за замовчуванням для кожного типу медіа (Аудіотека, Відеотека, Фотосховище тощо) — не потрібно вручну задавати режим сортування, політику мініатюр та глибину сканування.
- **Індивідуальні налаштування ресурсу**: Кожен ресурс зберігає власний режим сортування, режим відображення, політику мініатюр, PIN-блокування, прапорець «лише для читання» та глибину сканування підпапок. Мережевий архів і локальна музична папка поводяться по-різному за замовчуванням без конфліктів глобальних налаштувань.
- **PIN-захист на рівні ресурсу**: Окремі папки можна захистити PIN-кодом — корисно для конфіденційного контенту без блокування всього пристрою.
- **Режим «лише для читання»**: Вимикає всі операції запису для конкретного ресурсу на рівні додатка, незалежно від прав файлової системи. Захист для архівних папок, які потрібно переглядати, але не змінювати.
- **Сховище облікових даних з аудитом**: Мережеві паролі та SSH-ключі зберігаються зашифрованими. Сховище відстежує час останнього використання кожного запису — застарілі облікові дані стають видимими та їх легко видалити.
- **Кешування списку файлів**: Індекс файлів мережевих ресурсів зберігається в локальній базі даних Room. Повторне відкриття великих NAS-папок відбувається майже миттєво, без повного віддаленого сканування.
- **Відновлення позиції на рівні ресурсу**: Позиція прокрутки та останній переглянутий файл зберігаються окремо для кожного ресурсу. Повторне відкриття папки відновлюється з того самого місця. Якщо останній відтворений файл знаходився у підпапці, застосунок відкривається безпосередньо в ній під час відновлення, без перезавантаження батьківської директорії.
- **Перевірка з'єднання**: Перевірка доступності та облікових даних будь-якого мережевого або хмарного ресурсу перед спробою відкрити його — без мовчазних тайм-аутів.
- **Сортування ресурсів перетягуванням**: Зміна порядку ресурсів на головному екрані простим перетягуванням за іконку-ручку. Довге натискання на сам елемент, як і раніше, відкриває діалог редагування — жест перетягування ініціюється лише через іконку ≡.
- **Тематичні іконки ресурсів**: Кожен ресурс відображається з тематичною іконкою (нота, кіноплівка, зображення, документ тощо), автоматично підібраною за типом та джерелом підключення, зі значком джерела в куті. Під час створення або редагування ресурсу можна обрати конкретну іконку через кнопку на тулбарі.
- **Синхронізація мови віртуальних ресурсів**: Віртуальні ресурси (Усі зображення, Усі відео, Вся музика тощо) автоматично перейменовуються при зміні мови застосунку, якщо їхнє ім'я не було змінено користувачем вручну.
- **«Нещодавні» та «Завантаження» показують усі типи файлів за замовчуванням**: Передвстановлена віртуальна папка «Нещодавні» та швидка кнопка «Завантаження» створюються з увімкненим режимом «Показувати всі файли» — документи, архіви та інші не-медіа файли видно одразу, без ручного налаштування.

## 2. Навігація по медіа

- **Єдиний список файлів для всіх протоколів**: Браузер відображає однаковий інтерфейс незалежно від того, чи джерелом є локальна папка, SMB-шара або хмарний каталог. Сортування, фільтрування та множинний вибір працюють однаково для будь-якого протоколу.
- **Розширені режими сортування**: За ім'ям, датою, розміром, типом, виконавцем, назвою, тривалістю, датою зйомки, випадково або вручну — кожен з напрямком за зростанням/спаданням. Більшість файлових менеджерів зупиняються на імені та даті.
- **Пам'ять режиму сортування**: Обраний у Browse або Слайдшоу режим сортування автоматично зберігається для кожного ресурсу та відновлюється при наступному відвідуванні — без ручного налаштування.
- **Розширена панель фільтрів**: Фільтрування одночасно за підрядком імені файлу, діапазоном дат, розміром та типом медіа. Незамінна для великих NAS-папок із тисячами змішаних файлів.
- **Перехід до випадкового файла в плеєрі**: Для профілів «Аудіотека» та «Фотосховище» в командній панелі плеєра з'являється окрема кнопка-кубик, яка переводить до випадкового файла з поточної бібліотеки без увімкнення повного shuffle-режиму.
- **Рекурсивне сканування каталогів**: Згладжує ціле дерево вкладених папок у єдиний список. Зручно для перегляду музичної бібліотеки з глибокою ієрархією виконавець/альбом як одної плоскої черги.
- **Мініатюри відео з керуванням на рівні ресурсу**: Генерацію мініатюр для відео можна вимкнути для конкретного ресурсу — критично для повільних NAS-з'єднань, де генерація мініатюр для сотень відеофайлів насичує пропускну здатність.
- **Швидкий плейсхолдер для непідтримуваних мережевих форматів відео**: для контейнерів, які системний видобувач кадрів не підтримує у мережевому потоці (наприклад, AVI), застосунок миттєво показує значок типу файлу замість очікування 10-секундного тайм-ауту. SMB-теки з великою кількістю AVI-файлів завантажують список помітно швидше.
- **Перегляд мініатюр на мережевих сховищах автоматично відновлюється після зупинки відтворення** для SMB, SFTP та FTP — транзієнтні збої вилучення мініатюр під час активного стримінгу очищаються самі, і сусідні мініатюри з'являються знову без ручного оновлення.
- **Індикатор сканування зі скасуванням**: Для великих SMB-сканів тепер показується живий лічильник знайдених файлів (`N` або `N / ~M`, якщо є попередня оцінка), а для мережевих сканів (SMB/SFTP/FTP) кнопка СТОП з'являється одразу, без очікування 5 секунд. Для інших повільних сканів зберігається попередній легкий індикатор прогресу.
- **Вбудований міні-плеєр**: відтворюйте аудіо та голосові записи прямо з будь-якого ресурсу Browse — локальних папок, мережевих ресурсів (SMB/SFTP/FTP) та хмари — не відкриваючи повний плеєр. Натисніть кнопку відтворення на картці аудіофайлу, щоб почати; кнопка перемикається на паузу. Іконка ноти, що обертається, позначає активне відтворення. Раніше доступно лише в ресурсах «Аудіотека»; тепер працює в усіх ресурсах Browse.
- **Повна клавіатурна навігація на всіх екранах**: Кожен екран — браузер файлів, плеєр, автономний переглядач, налаштування, всі діалоги, форма додавання ресурсу, вибірники хмарних папок, редактор ресурсу, «Поділитися» та конфігуратор віджета — реагує на апаратну клавіатуру. **Enter** активує виділений елемент, **Escape** закриває або скасовує, **стрілки** переміщують фокус, **Backspace** переходить рівень вище в браузері та вибірниках хмарних папок; текстові поля в Chrome OS (ARC++) тепер приймають введення з фізичної клавіатури коректно.
- **Гарячі клавіші в стилі NC та кольорові кнопки TV**: На файлових екранах розкладка слідує класиці Norton Commander: **F5** — копіювати, **F6** — перемістити, **F7** — створити підпапку, **F8** — видалити. Кольорові кнопки Android TV: Червона = Видалити, Зелена = Копіювати, Жовта = Перемістити, Синя = Перейменувати. **Ctrl+F** відкриває пошук у тексті/PDF/EPUB; **Ctrl+S** зберігає зміни в редакторі ресурсу.
- **Діалог довідки F1 і видимий клавіатурний фокус**: Натисніть **F1** на апаратній клавіатурі, щоб відкрити діалог гарячих клавіш для поточного екрана з посиланням на документацію. Активний елемент отримує помітну рамку фокуса під час навігації.
- **Підтримка геймпадів (Xbox / DualSense / 8BitDo)**: Стандартний Bluetooth- або USB-геймпад керує файловим браузером та плеєром (звичайним і VR). **D-pad / лівий стік** рухають фокус, **A** відкриває / підтверджує, **B** повертає назад або виходить з плеєра, **X** — наступний файл (або мультивибір у браузері), **Y** — попередній файл або контекстне меню, **L1/R1** — перемотка ±10 с або перемикання режиму списку, **Start** — показати панель / відкрити пошук, **Select** — переключити спливаючі підказки. Аналогова перемотка на правому стіку масштабується за відхиленням, а мертва зона й обмеження частоти подій забезпечують плавну гучність та перемотку.
- **Операції з підпапками з браузера**: Копіювання, переміщення, перейменування та видалення підпапок прямо у списку файлів — включаючи SMB, SFTP, FTP та хмарні ресурси. Більшість файлових браузерів підтримують це лише для локального сховища.
- **Режим «показати всі файли»**: Тимчасово вимикає фільтри типів медіа для роботи з не-медіафайлами (бінарники, архіви, конфігураційні файли) без створення окремого ресурсу.
- **Ручне впорядкування перетягуванням**: У режимі сортування «Вручну» поряд із кожним файлом з'являється ручка перетягування. Переміщення файлів задає користувацький порядок, який зберігається для кожної директорії та відновлюється під час наступного відкриття.
- **Розширене вікно інформації про файл**: Вікно інформації про файл показує повні аудіо-метадані (виконавець, альбом, назва, рік, sample rate, бітова глибина, канали, маркер lossless, ReplayGain, вбудовану обкладинку) для FLAC/MP3/M4A/OGG з локального сховища, SFTP, SMB, FTP та SAF — зчитуючи лише перші ~64 КБ файлу без повного завантаження. Блок «Інформація про файл» розкладає мережеві шляхи на хост, шару, каталог та ім'я файлу, додає розширення + MIME, окрему дату змінення і кнопку «Копіювати шлях».
- **Перепризначення кнопок ТВ-пульта**: Кольорові кнопки (Червона/Зелена/Жовта/Синя) та Channel Up/Down на пультах Android TV можна призначити на будь-яку команду в «Налаштування → Клавіші», так само як клавіші клавіатури. Якщо користувацька прив'язка не задана, застосовуються типові дії: Видалити/Копіювати/Перемістити/Перейменувати та Наступний/Попередній файл.
- **Прискорена прокрутка при утриманні DPAD**: Утримання DPAD Вгору або Вниз на пульті або геймпаді переключається з покрокового переміщення на посторінковий перехід після короткої затримки — навігація по довгих списках файлів значно прискорюється.

## 3. Операції з файлами

- **Міжпротокольні передачі**: Копіювання або переміщення файлів безпосередньо між будь-якими двома типами ресурсів — локальний ↔ SMB, SMB ↔ FTP, хмара ↔ NAS — без попереднього завантаження у тимчасове сховище (де це дозволяє протокол).
- **Кошик із відновленням**: Видалені файли потрапляють у внутрішній кошик із можливістю відновлення одним натисканням, а не видаляються безповоротно. Налаштовується — жорстке видалення теж доступне.
- **Скасування операції**: Останнє копіювання, переміщення або видалення можна відмінити одним натисканням. Працює міжпротокольно.
- **Політики перезапису для кожного призначення**: Вказується, як обробляються конфлікти файлів (пропустити, перезаписати, залишити обидва) для кожного конкретного призначення. Автоматизує вирішення конфліктів для повторюваних робочих процесів.
- **Пошук дублікатів за SHA-256**: Пошук побайтово ідентичних файлів у локальному, SMB, FTP, SFTP та хмарному сховищах за трифазною схемою (розмір → частковий хеш → повний SHA-256). Міжджерельне зіставлення працює — можна знайти дублікати між NAS і Google Drive. Два режими: перегляд-і-вибір або автовидалення всіх (зберігається найстаріший у групі). Більшість засобів пошуку дублікатів працюють лише з локальним сховищем із слабким зіставленням за ім'ям/розміром.
- **ZIP-архівування з браузера**: Пакування вибраних файлів у ZIP-архів прямо на місці, з пофайловим індикатором прогресу та автоматичним вирішенням конфліктів імен.
- **Розпакування ZIP за натисканням**: Натискання на ZIP-файл розпаковує його з індикатором прогресу та автоматичним вирішенням конфліктів призначення. Працює з локальними та SD-картовими SAF-ресурсами.
- **Перейменування з автономного плеєра**: Файли, відкриті через «Відкрити за допомогою» із зовнішніх додатків, можна перейменувати безпосередньо, включаючи аудіофайли — відтворення продовжується без переривання після перейменування (джерело ExoPlayer гаряче замінюється на новий URI).
- **Перемикач кошика** — вибір між переміщенням видалених локальних файлів до `.trash` (відновлення через Undo) та негайним видаленням (місце звільняється одразу). Мережеві та хмарні файли завжди видаляються остаточно.
- **Безпечний режим**: Глобальний перемикач, що додає обов'язковий крок підтвердження перед кожним видаленням або переміщенням. Корисний при роботі з незамінними файлами.
- **Запис із мікрофона**: утримуйте кнопку мікрофона у командній панелі Browse, щоб записати аудіо прямо в поточну папку — локальну, мережеву (SMB/SFTP/FTP) або хмарну. Файл називається за датою й часом (`REC_YYYYMMDD_HHmmss.m4a`); перед збереженням опційно з'являється діалог перейменування. Вимкнено за замовчуванням; вмикається в Налаштування → Аудіо → Запис із мікрофона.
- **Зйомка з камери**: Натисніть іконку камери в командній панелі Browse, щоб зробити нове фото або відео стандартним додатком камери. Знятий файл зберігається до кореневої теки поточного ресурсу (локального, SMB, SFTP, FTP або хмари) або до стандартної теки DCIM/Camera для віртуальних колекцій «Всі відео», «Всі фото» і «Фото камери». Після зйомки діалог дозволяє перейменувати файл; його можна вимкнути у Налаштуваннях → Поведінка → «Не питати ім'я файлу». Всю команду можна приховати через Налаштування → Поведінка → «Вимкнути кнопку зйомки». На пристроях без сумісного додатка камери команда приховується автоматично, а помилки запуску або збереження показуються як локалізовані повідомлення всередині додатка замість мовчазного збою. Після збереження список файлів оновлюється та прокручується до нового елементу.
- **Прогрес копіювання/переміщення — відсоток і ETA**: діалог копіювання та переміщення тепер показує загальний відсоток виконання (за байтами, не за кількістю файлів), поточну швидкість і час, що залишився (ETA), зі згладжуванням швидкості. Усі значення оновлюються кожні 3 секунди.
- **При переміщенні відтворюваного файлу плеєр негайно переходить до наступного треку; перенесення виконується у фоні без переривання нового відтворення; при помилці перенесення файл залишається у списку.**
- **При видаленні відтворюваного файлу плеєр негайно переходить до наступного треку; якщо файлів не залишилось — плеєр закривається.**
- **При перейменуванні відтворюваного файлу відтворення зупиняється до початку операції; після успіху плеєр відновлює відтворення під новою назвою на тій самій позиції у плейлисті.**

## 4. Управління призначеннями

До 10 кольорових кнопок-ярликів призначень відображаються прямо в плеєрі, тож сортування медіа по папках — це одне натискання без навігації по меню. Призначеннями можуть бути будь-які записувані ресурси — локальні, SMB, FTP, SFTP або хмарні.

- **Автоперехід після копіювання/переміщення**: Плеєр автоматично переходить до наступного файлу після успішної передачі. У поєднанні з кнопками призначень це створює швидкий робочий процес сортування черги без зайвих натискань.
- **Згортання панелі призначень**: Панель команд згортається, коли не потрібна, звільняючи максимум екранного простору для перегляду.
- **Кнопка «..» у панелях плеєра**: У панелях «Копіювати в» та «Перемістити в» плеєра додано кнопку «..» для вибору довільної локальної папки призначення без виходу з плеєра.
- **Теку «Завантаження» налаштовано як отримувача за замовчуванням**: При першій установці тека завантажень автоматично додається як перший отримувач — панель отримувачів у плеєрі не порожня одразу після інсталяції.

## 5. Переглядач зображень

- **Динамічний фоновий ефект**: Переглядач обчислює розмитий, відповідний кольорам фон із поточного зображення — жодних чорних смуг навколо портретних фото на широкому екрані.
- **Поворот та відображення на місці**: Поворот та горизонтальне/вертикальне відображення записуються безпосередньо у файл. Окремий редактор не потрібен.
- **Корекція зображення**: Яскравість, контраст та насиченість можна змінити й зберегти на місці — корисно для дрібного коригування під час сортування без виходу з додатка.
- **OCR (ML Kit + Tesseract)**: Витягнення тексту з фотографій, чеків та скриншотів. ML Kit працює з латинськими символами; Tesseract охоплює розширені шрифти та складні випадки.
- **AR-накладання перекладу**: Перекладені текстові блоки малюються на тих самих позиціях, що й оригінальний текст на зображенні — той самий підхід, що у Google Lens, але який працює з файлами з будь-якого джерела, включаючи NAS та хмару.
- Команди «Обрізати» (перезапис оригіналу), «Обрізати у файл» (збереження фрагмента як нового файлу) та «Стиснута копія» (JPG 70%, довга сторона ≤ 1024 пкс) в overflow-меню; працюють з локальними та мережевими джерелами (SMB, SFTP, хмара); для джерел «тільки для читання» результат зберігається у Завантаження.

## 7. Відеоплеєр

- **Стрімінг безпосередньо з NAS та хмари**: Завантаження не потрібне. SMB, FTP, SFTP, Google Drive, Dropbox та OneDrive відтворюються нативно через ExoPlayer із пулінгом з'єднань та налаштовуваним паралелізмом.
- **Позиція відтворення зберігається на рівні файлу**: Відновлення — пофайлове, не посесійне. Кожне відео пам'ятає, де ви зупинилися — між перезапусками додатка.
- **Режими порядку відтворення**: натисніть кнопку порядку в командній панелі, щоб перемикатися між «По колу» (нескінченний цикл), «До кінця» (зупинитися в кінці списку), «Перемішати» (випадковий нескінченний) та «Повторювати один». Режим запам'ятовується окремо для аудіо та відео.
- **Авто-очищення позиції після перегляду до кінця**: Якщо файл відтворено до кінця, збережена позиція очищається, і при наступному відкритті плеєр починає з нуля. Відновлення з останньої позиції працює лише для файлів, перерваних посередині.
- **Відновлення при наступному запуску**: При холодному старті додаток повертається до останнього активного відео, включаючи мережеві та хмарні ресурси, і відновлює відтворення.
- **Налаштовувані зони торкання**: Визначте, які ділянки екрана активують попереднє/наступне, відтворення/паузу або перемотування. Розкладка налаштовується під користувача, не є фіксованою.
- **Діалог `Control` для відео**: Кнопка `Control` у нижній панелі відразу після `Next track` відкриває єдиний діалог із вкладками для гучності, аудіодоріжки, субтитрів, HUE-зсуву, GPU-яскравості та швидкості відтворення, плюс швидке скидання до нейтрального стану. Та сама модель діалогу тепер працює і в основному плеєрі, і в автономному відеоплеєрі `Відкрити за допомогою`.

- **Таймер сну**: Зворотний відлік (15–120 хв), після якого відтворення зупиняється автоматично.
- **Зберегти кадр**: Зберегти поточний кадр відео як PNG одним натисканням у меню «ще». Кадр зберігається в налаштований ресурс-отримувач (локальний шлях); якщо ресурс не вибрано або недоступний — до папки Downloads. Працює для будь-яких джерел: локальних, SMB, SFTP, FTP і хмарних.
- **Визначення 3D-стерео**: Автоматичне визначення стереоскопічного відео (SBS та OU) за метаданими та евристикою. У стандартній версії при виявленні 3D-контенту пропонується встановити окрему VR-редакцію для перегляду у шоломі. ..коректна ізоляція стерео-режиму при переході між файлами (немає витоку від попереднього файлу).
- **Перегляд 3D-контенту з одного ока в панельному режимі**: Якщо увімкнено, SBS- та OU-стерео-відео й повноекранні фото обрізаються до одного ока й розтягуються на весь екран — зручно дивитись без 3D-окулярів. На першому стерео-файлі в сеансі показується короткий тост-індикатор. Усталено: увімкнено у звичайних збірках, вимкнено у VR-збірці. Перемикач у `Налаштування → Відтворення`. На Cast-вивід не впливає (на приймач іде вихідний файл).
- **Визначення 360° MP4 spatial metadata**: Для локальних MP4 читаються бокси Google Spatial Media `st3d`/`sv3d`, і їхній результат має пріоритет над назвою файла. Це дає коректне автовизначення equirect 360° mono/SBS/OU навіть за неоднозначної назви файла.
- **Адаптивна стратегія попереднього кешування**: Для мережевого відео (SMB, SFTP, FTP) плеєр виконує вимір швидкості в реальному часі та обчислює оптимальний цільовий обсяг передкешу. Ненав'язливий індикатор-таблетка показує прогрес буферизації (темний — нормально, бурштиновий — на межі). За достатньої пропускної здатності плеєр пропонує зберегти локальну копію через BottomSheet — прогрес завантаження відображається inline, після завершення таблетка стає зеленою. Після відтворення одним дотиком можна залишити або видалити копію. Налаштовується в Налаштування → Загальні: розмір передкешу (Менше/Авто/Більше), режим очищення (Запитувати/Авто-видалення/Авто-збереження) і TTL кешу (Вимк./1д/3д/7д/30д).
- **Перепризначуване керування**: Усі клавіші клавіатури, кнопки миші, геймпада та VR-контролера в плеєрі налаштовуються через `Налаштування → Керування та клавіші`, зі скиданням до заводських значень на рівні команди, групи або цілком.
- **Лічильник FPS у VR HUD**: Окреме налаштування «Показувати FPS у VR» у налаштуваннях відео (активне лише за глобально увімкненого VR) виводить поточну частоту кадрів у правому верхньому куті імерсивного HUD-оверлея. Типово вимкнено; зміна перемикача застосовується протягом приблизно секунди й у активній імерсив-сесії — перезапуск не потрібен. Значення усереднюється у вікні 500 мс і «застигає» на останньому валідному при просіданнях рендер-циклу.
- **Діагностичний лічильник FPS**: Окреме налаштування `Налаштування → Відео → Показувати FPS над плеєром` вмикає невеликий бейдж у верхньому правому куті плоского 2D-плеєра під час відтворення відео. Незалежне від наявного перемикача VR-FPS і доступне на всіх флейворах з плеєром; в імерсивному VR-режимі бейдж приховується, бо діагностику показує наявний VR-HUD-лічильник.
- **Стійке витягування прев'ю**: VR180 / 7K та пристрої з малим native heap отримують кадр із кешу або локалізовану заглушку «Прев'ю недоступне» — порожнього прев'ю більше не буде.
- **Режим «Чорний екран»**: Кнопка на панелі плеєра (вмикається в Налаштування › Поведінка) переводить екран у режим повної темряви без зупинки відтворення — зручно слухати музику або подкасти за кермом. Кнопки гучності та медіаклавіші (відтворення, наступний, попередній) продовжують працювати; будь-яке торкання екрана миттєво повертає інтерфейс плеєра. Підтримується призначення клавіатурного скорочення.
- **Виправлення маршрутизації DVD VOB по мережі**: Мережеві DVD-файли `.vob` більше не потрапляють у маршрут Blu-ray TS. При помилці маршрутизації показується один зрозумілий діалог на поточному файлі замість беззвучного гортання всього ланцюжка сусідніх DVD-сегментів.

## 8. VR-редакція

- **Виділений VR-flavor**: FastMediaSorter VR — це виділений `vr` product flavor для шоломів Meta Quest та Android XR. Це той самий базовий плеєр, що й стандартна редакція, але з додатковим шаром OpenXR-рендерингу для відтворення у шоломі.
- **Стереоскопічне VR-відтворення**: VR-редакція забезпечує повноцінний стереоскопічний перегляд 3D-відео (SBS/OU) і підтримуваних 3D-фотографій, включно з прямим переходом із panel mode в immersive для стереоскопічних зображень. Вбудований OpenXR layer factory маршрутизує 2D-контент у cinema quad, плоский SBS/OU-контент у projection layers, equirect 360°/VR180-контент у `Equirect2KHR`, а циліндричний 180°-контент у `CylinderKHR`.
<!-- TODO translate: **VR180 Fisheye and OU/TAB stereo**: The VR edition correctly renders VR180 fisheye-lens video (suffixes `3dh`, `180x180`) via an equidistant inverse-projection GLSL shader, and Over-Under/TAB stereo (suffixes `3dv`, `OU`, `TAB`) via vertical UV-split on a projection layer — both formats play back out of the box without manual format selection. -->
- **Явне повідомлення при fallback з immersive**: Якщо immersive-запуск не вдався або файл запросив непідтримуваний immersive-шлях, VR-збірка тепер показує зрозумілу помилку до fallback, а не повертається мовчки у стандартний плеєр.
- **Порізний VR-рендеринг і збереження кадру**: VR-рендерер записує плоскі поглядові пікселі в XR-таргети з коректним SBS/OU/mono-розділенням і aspect-preserving cinema blit, залишаючи сферичне та циліндричне викривлення OpenXR compositor. «Зберегти кадр» у VR створює timestamped стереоскопічний `*_SBS.png` у `Pictures/FastMediaSorter_VR` і одразу пропонує відкрити збережений файл. Спільна кнопка fullscreen тепер лишається безпечним no-op з toast-повідомленням для VR, а VR-ввід для system UI перемикає overlay шолома замість Android-панелей.
- **Обробка 3D-зображень на телефоні та у шоломі**: Формат SBS/OU для зображень визначається автоматично за назвою файла; телефонна збірка може показати crop-прев'ю лівого ока та вкладку `3D` у діалозі відтворення, а VR-flavor рендерить той самий контент порізно. Примусовий формат із VR-налаштувань також застосовується до зображень.
- **Діалог VR-перевизначення формату з двома групами**: У VR-редакції діалог `Control -> 3D` одночасно показує групи плоских і сферичних форматів. Неактивне сімейство за замовчуванням залишається видимим, але вимкненим, окремий перемикач `Override format type` дозволяє крос-сімейне перевизначення, ручні зміни коротко показуються toast-повідомленням, а збережений вибір відновлюється для кожного файла при повторному відкритті, якщо ввімкнено `Remember file format`.
- **Роздільні примусові VR-формати в налаштуваннях**: Екран налаштувань VR показує окремі спінери `Forced flat format` і `Forced spherical format`. Старі встановлення зберігають попереднє значення `vrForcedFormat` через сумісний fallback, плоскі перевизначення не впливають на 360°/VR180-контент, сферичні перевизначення не зачіпають плоске cinema-відтворення, а експорт/імпорт резервної копії зберігає обидва поля.
- **Перемикач іммерсивного режиму**: окрема кнопка на командній панелі відеоплеєра (тільки VR-версія) перемикає між іммерсивним режимом OpenXR та плоским панельним плеєром для будь-якого відео, включно зі звичайним 2D. Натискання повторно відкриває поточний файл у протилежному режимі зі збереженням позиції відтворення. В іммерсивному режимі та сама кнопка повертає в панельний плеєр; клік лівого стіка контролера виконує ту саму дію.
- **Керування у VR**: контролери Touch Plus/Pro, Bluetooth-клавіатура та миша повністю працюють в іммерсивному 3D-режимі. Відтворення (пауза, перемотка, гучність, попередній/наступний файл, масштаб, ре-центр), діалог налаштувань і файлові операції (копіювати/перемістити/видалити/перейменувати/інформація) — усе доступне без знімання гарнітури. Шпаргалка керування з'являється автоматично при першому вході на 4 секунди; тривале натискання Y на лівому контролері або клавіша F1 повертають її будь-коли.
- **Іммерсивний HUD**: в іммерсивному сеансі з'являється спливаючий head-locked HUD на кожну дію контролера — прогрес-бар із поточною позицією, буфером і тривалістю, а також індикатори паузи, перемотки, гучності, масштабу, зміни файла, ре-центру, перемикання іммерсиву та режиму повтору. HUD малюється окремим композитним шаром OpenXR і сам зникає після кількох секунд бездіяльності. Поки виділений композитний слот для повноцінних панелей ще не готовий, файлові операції та діалог керування лишаються у panel-режимі — вийди з іммерсиву, щоб відкрити їх; в іммерсиві короткий HUD-банер підказує, де їх шукати, а кнопка Y більше не ставить плеєр на паузу під невидиму панель.
- **Affordance кнопок HUD VR**: Кнопки HUD VR-програвача тепер відображаються із закругленою рамкою, візуально відрізняючись від текстових написів.
- **Промене́ве керування іммерсивним HUD**: В іммерсивному HUD промінь контролера та pinch hand-tracking клікають по елементах HUD: легка підсвітка під променем та звуковий відгук при кліку. Розрахунок променя виконується лише за видимого HUD-шару — простійні кадри не навантажуються.
- **Режим Cinema для 2D у VR**: при навігації до звичайного відео всередині іммерсивного сеансу застосунок автоматично відображає його на віртуальному кіноекрані (шар QUAD_CINEMA) без знищення XR-сесії та без виходу в стандартний плеєр.
- **Тумблер автопереходу в імерсивний режим для стерео-контенту**: у блоці VR налаштувань з'явився перемикач `Автоперехід в імерсивний режим для стерео-контенту` (за замовчуванням увімкнено). Коли вимкнено, відкриття стерео-файлу залишає плеєр на плоскому екрані — перехід у VR виконується існуючою кнопкою 3DVR у плеєрі.
- **VR hand tracking**: Коли контролери відкладено, VR-плеєр автоматично перемикається на OpenXR-ввід руками (`XR_EXT_hand_tracking` + розширення Meta aim/microgestures). Промінь прицілювання домінантної руки наводиться на елементи інтерфейсу — щипок для натискання, подвійний щипок перемикає відтворення/паузу, свайпи великим пальцем — перемотка та гучність. Контролери миттєво повертають пріоритет при натисканні будь-якої кнопки. Курсор-точка підсвічує інтерактивні елементи кольором, а звуковий відгук компенсує відсутність тактильного.
- **Інтерактивна VR-панель керування**: В іммерсивному VR-режимі доступна повноцінна панель із перемоткою, регулятором гучності, яскравістю, вибором доріжки та індикатором стерео-формату. Керування здійснюється променем контролера або руки — без виходу з VR.
- **Кнопка «Застосувати і в 3D» + prev/next без виходу + збереження файлу при виході**: У діалозі керування відео є кнопка «Застосувати і в 3D»: одним натисканням закриває діалог і знову відкриває контент в іммерсиві. Команда виходу з іммерсиву зберігає ваш файл: відкривається той самий файл на тій самій позиції у плоскому 2D-плеєрі, а не файловий браузер. Кнопки prev/next всередині іммерсиву перемикають файли ресурсу, не знімаючи шолом.
- **Видимий промінь контролера та руки**: В імерсивному VR промінь контролера та руки видно тонкою лінією з маленьким курсором в точці перетину з HUD/панеллю — видимий зворотний зв'язок при взаємодії.
- **Режим кількох вікон (Quest 3+ / Samsung DeX і аналоги)**: Налаштування «Дозволити запуск в окремому вікні» (увімкнено за замовчуванням у VR-версії) відкриває три точки входу: іконка картки ресурсу → Browse цього ресурсу відкривається в новому вікні, основне залишається на головному екрані; «В окремому вікні» у верхньому меню Browse → поточний Browse «відривається» в нове вікно з ресурсом, файлом і позицією прокрутки, поточне вікно повертається на головний екран; «В окремому вікні» у меню плеєра → той самий файл відкривається в новому вікні з початку, поточний плеєр закривається і повертає в Browse. Усі вікна живуть незалежно; закриття одного не впливає на інші. Позиція відтворення при tear-off не передається.
- **Захоплення passthrough-кадру (Quest 3, Horizon OS v74+).** Кнопка камери в Browse робить одиночний JPEG із фронтальних passthrough-камер і зберігає його в поточний локальний ресурс. Вимагає дозволу `horizonos.permission.HEADSET_CAMERA`; автоматично прихована на пристроях без підтримки Passthrough Camera API. Захоплені кадри обробляються лише локально — без автоматичного завантаження або телеметрії.

## 9. Аудіоплеєр

- **Стрімінг із будь-якого джерела**: Відтворення аудіо безпосередньо з SMB-шар, FTP/SFTP-серверів та всіх трьох хмарних провайдерів — локальна синхронізація не потрібна. Більшість спеціалізованих музичних плеєрів вимагають файли на пристрої.
- **Режими порядку відтворення**: натисніть кнопку порядку в командній панелі, щоб перемикатися між «По колу» (нескінченний цикл), «До кінця» (зупинитися в кінці списку), «Перемішати» (випадковий нескінченний) та «Повторювати один». Режим запам'ятовується окремо для аудіо та відео.
- **Налаштовувана поведінка при натисканні «Назад»**: Визначте, що відбувається при натисканні «Назад», поки аудіо грає у фоні — запитати, завжди зупиняти або завжди продовжувати. Встановлюється один раз, запам'ятовується назавжди.
- **Обкладинка з ID3 + онлайн-фолбек**: Спочатку використовується вбудована обкладинка; за її відсутності виконується онлайн-пошук з опціональним обмеженням лише Wi-Fi. Завантажені обкладинки кешуються локально та використовуються повторно без зайвих мережевих запитів.
- **Пошук текстів пісень**: Знаходить і відображає синхронізовані тексти для поточного треку в повноекранному оверлеї.
- **Випадкові фото під час відтворення**: Відображення зображень із вибраного ресурсу як візуального фону під час відтворення музики.
- **Візуалізатори за відсутності обкладинки**: Коли обкладинки немає, canvas-візуалізатори (стовпці, хвилі, спектр) анімуються під музику замість чорного екрана.
- **Панель «Зараз грає»**: Постійна мінипанель показує поточний трек при навігації; при розкритті відкривається повна черга, смуга прокрутки та обкладинка, з переходом до будь-якого треку за натисканням.
- **Трансляція на Chromecast**: Надсилання аудіо на будь-який пристрій Google Cast. Локальні файли обслуговуються через внутрішньопроцесний HTTP-проксі; мережеві/хмарні файли спочатку кешуються на пристрій.
- **Відновлення при наступному запуску**: Відновлює останній активний трек, чергу та позицію при холодному старті.
- **Режим «Чорний екран»**: Кнопка на панелі плеєра (вмикається в Налаштування › Поведінка) переводить екран у режим повної темряви без зупинки відтворення — зручно слухати музику або подкасти за кермом. Кнопки гучності та медіаклавіші (відтворення, наступний, попередній) продовжують працювати; будь-яке торкання екрана миттєво повертає інтерфейс плеєра. Підтримується призначення клавіатурного скорочення.

## 10. Слайд-шоу

- **Будь-яке джерело, будь-який мікс**: Слайд-шоу з локальних, SMB, FTP, SFTP, Google Drive, Dropbox або OneDrive файлів. Зображення та GIF змішуються вільно. Більшість додатків для слайд-шоу працюють лише локально.
- **Фонова музика з будь-якого джерела**: Призначте окремий ресурс для фонової музики — не обмежений локальними файлами. Музичний ресурс може сам знаходитися на NAS або в хмарі.
- **Відтворення відео/аудіо до кінця**: У слайд-шоу зі змішаним контентом можна налаштувати очікування закінчення відео або аудіотреку перед переходом до наступного файлу, а не переривати його за таймером.
- **Перевизначення інтервалу для конкретного ресурсу**: Встановити інший інтервал переходу для окремої папки без зміни глобального значення за замовчуванням.

## 11. Переглядач PDF

- **Відкриття безпосередньо з NAS та хмари**: PDF стрімляться з SMB, FTP, SFTP, Drive, Dropbox та OneDrive без попереднього завантаження.
- **OCR + AR-накладання перекладу**: Те саме накладання перекладу в стилі Google Lens, що працює у переглядачі зображень, працює й на сторінках PDF — перекладений текст візуально замінює оригінальний.
- **Виділення тексту з перекладом / читанням вголос**: Натисніть кнопку «Т» для витягнення тексту сторінки через OCR (або нативно на Android 15+). Затисніть для вибору діапазону, потім перекладіть, прослухайте через TTS або знайдіть у Google — без попереднього копіювання до буфера обміну.
- **Читання вголос (TTS)**: Озвучує поточну сторінку через системний рушій TTS. Автоматично зупиняється при навігації по сторінках.
- **Кольорові режими**: Нормальний, нічний та сепія для різних умов освітлення.
- **Друк**: Відправлення поточного PDF, текстового файлу або зображення на принтер через стандартний діалог Android. Доступна з командної панелі (або з меню «⋯» при нестачі місця) у портретному та ландшафтному режимі. Віддалені файли кешуються перед друком і видаляються після.

## 12. Переглядач EPUB

- **Відкриття безпосередньо з NAS та хмари**: EPUB стрімляться з будь-якого підключеного джерела, як і PDF.
- **Розширений пошук**: До 500 результатів на запит, у межах поточного розділу або по всій книзі.
- **Збереження позиції**: Точна позиція прокрутки та розділ зберігаються для кожного файлу та відновлюються при наступному відкритті.
- **Контекстне меню виділення**: Затисніть будь-яке слово для появи маркерів виділення, потім — Перекласти, Прочитати вголос через TTS або Знайти у Google — на додаток до системних Копіювати/Поділитися.
- **Читання вголос (TTS)**: Прочитує поточний розділ вголос; автоматично зупиняється при зміні розділу.
- **Налаштування читання**: Розмір шрифту, сімейство шрифтів (За замовчуванням/Serif/Monospace), теми (Світла/Темна/Сепія/OLED Чорна), міжрядковий інтервал (1.0×–3.0×) та горизонтальні відступи.

## 13. Переглядач / Редактор тексту

- **Автоматичне визначення кодування**: Файли декодуються коректно без ручного вибору кодування — важливо для логів і скриптів із систем із різними локалями.
- **Редагування на місці для віддалених файлів**: Зміни зберігаються назад у вихідний файл через SMB, SFTP або FTP безпосередньо — без циклу «завантажити → відредагувати локально → завантажити назад».
- **Підсвічування синтаксису та рендерінг Markdown**: Код-файли підсвічуються; `.md`-файли рендеряться через Markwon. Обидва режими працюють для файлів із будь-якого джерела.
- **Зміна розміру шрифту жестом**: Горизонтальне свайпування в будь-якому місці екрана змінює розмір тексту — без входу в меню.
- **Контекстне меню виділення**: Перекласти виділене, прочитати вголос (TTS) або знайти у Google з будь-якого виділеного фрагмента.
- **Вбудований пошук (паритет «Відкрити за допомогою»)**: Пошук Знайти/Наступний/Попередній працює як усередині додатка, так і при відкритті файлу через «Відкрити за допомогою» із зовнішнього додатка.

## 14. Переклад та OCR

Один і той самий рушій працює однаково у переглядачі зображень, PDF, EPUB та текстовому редакторі — окреме налаштування для кожного переглядача не потрібне.

- **Локальний переклад без інтернету**: Мовні моделі завантажуються на вимогу та працюють локально — після завантаження інтернет не потрібен, текст не надсилається на сервер.
- **Автоматичне визначення вихідної мови**: Вихідна мова визначається ML-моделями до запуску перекладу — ручний вибір у більшості випадків не потрібен.
- **AR-накладання в усіх переглядачах**: Перекладений текст розміщується на позиції оригінального тексту як у зображеннях, так і на сторінках PDF — не виводиться в окремій панелі.
- **Паритет автономного режиму**: Переклад та вбудований пошук працюють при відкритті файлу через «Відкрити за допомогою» із будь-якого зовнішнього додатка, а не лише з FMS.
- **Фолбек на Tesseract**: Охоплює шрифти та символи, які ML Kit не розпізнає, включаючи не-латинські символи та неякісні скани.

## 15. Мережеві джерела

- **Вибір SMB-шари з ручним введенням**: При підключенні до SMB-сервера знайдені шари відображаються в діалозі вибору. Якщо потрібна шара не з'явилась в автоматичному списку (нестандартна назва, прихована NAS-папка), можна натиснути «+ Ввести ім'я папки вручну..» і вказати назву самостійно. Введені вручну назви зберігаються в історію сервера та пропонуються при наступному підключенні.
- **SMB, FTP, SFTP — все нативно**: Жодних плагінів, жодних зовнішніх додатків. Всі три протоколи реалізовані всередині процесу за допомогою SMBJ та SSHJ, з повною підтримкою навігації, стрімінгу, копіювання, переміщення та редагування. Сканування великих SFTP-бібліотек стало значно швидшим: атрибути файлів (розмір, дата) зчитуються з відповіді каталогу за один мережевий запит замість окремого запиту на кожен файл. Під час сканування відображається лічильник прогресу.
- Паралельне відтворення та копіювання файлів з одного SFTP-джерела без взаємних переривань.
- **Пулінг з'єднань (SMB)**: Автентифіковані сесії кешуються та повторно використовуються. Затримка повторної автентифікації при кожній операції з файлом, характерна для конкуруючих клієнтів, усунена.
- **Відновлення застарілих SMB-з'єднань**: Автоматично виявляє та усуває розриви TCP, спричинені серверним тайм-аутом простою («Broken pipe»): скидає внутрішній кеш з'єднань SMBJ та встановлює новий TCP-сокет перед наступною операцією. Перевірка стану перед видачею з'єднання з пулу виключає зайві повторні спроби. При частих перепідключеннях протягом короткого вікна — діагностичне попередження про нестабільний Wi-Fi.
- **Багатопоточні передачі**: Завдання розподіляються на 1, 2, 4, 8, 12 або 24 паралельних з'єднання. Вбудований тест швидкості надсилає синтетичні пакети та рекомендує оптимальну кількість потоків для вашого з'єднання.
- **Автовиявлення в мережі**: Сканує локальну підмережу на предмет активних хостів на портах 445 (SMB), 21 (FTP) та 22 (SFTP), виводячи виявлені NAS-пристрої в реальному часі. Введення IP-адреси не потрібне.
- **Регулювання з'єднань**: Обмеження частоти запитів для запобігання перевантаженню слабкого або перевантаженого NAS-обладнання.
- **Фонова синхронізація каталогів**: Завдання WorkManager оновлюють локальний кеш індексу файлів за налаштовуваним розкладом (1–24 години). Мережеві папки відкриваються з актуальним вмістом, а не з застарілим знімком.
- **Відтворення Blu-ray Transport Stream (.m2ts)**: Файли Blu-ray формату BDMV/STREAM відтворюються безпосередньо з мережевих ресурсів (SFTP, SMB, FTP) через прозорий адаптер 192-байтових BD-TS пакетів. Якщо пристрій не підтримує декодування потоку, відображається зрозумілий діалог із рекомендацією перекодувати файл за допомогою HandBrake або ffmpeg.
- Blu-ray Transport Stream (.m2ts): формат пакетів BD-TS (192 байти) визначається автоматично для локальних, SMB, SFTP, FTP і хмарних джерел; файли .m2ts зі звичайними 188-байтними пакетами відтворюються без зайвої обробки. За наявності непідтримуваних аудіодоріжок (TrueHD, DTS-HD MA) користувач бачить одноразове повідомлення з переліком кодеків.
- **Дозвіл на доступ до локальної мережі (Android 17+)**: На Android 17 і вище додаток запитує дозвіл `ACCESS_LOCAL_NETWORK` перед першим підключенням по SMB, SFTP або FTP, а також перед ініціалізацією виявлення Chromecast. При відмові відображається діалог з поясненням і кнопкою переходу до налаштувань системи.

## 16. Хмарна інтеграція

- **Google Drive, Dropbox та OneDrive в одному інтерфейсі**: Навігація, стрімінг та керування всіма трьома в одному файловому браузері. Офіційні додатки працюють лише з власним сервісом.
- **Прямі міжхмарні та хмарно-NAS передачі**: Копіювання з Google Drive до Dropbox або з OneDrive у SMB-шару без попереднього завантаження на пристрій.
- **Єдина OAuth із шифруванням токенів**: Автентифікація один раз; токени зберігаються зашифрованими. Повторний вхід при перезапуску не потрібен.
- **Резервна копія налаштувань у Google Drive**: Серіалізація всіх ресурсів, облікових даних, призначень та конфігурації додатка у JSON-файл у Drive. Відновлення на новому пристрої — в один крок.

## 17. Обране

- **Відмітка одним натисканням із будь-якого переглядача**: Додати файл до обраного можна з переглядача зображень, відеоплеєра, аудіоплеєра, PDF або EPUB — без повернення до браузера.
- **Список обраного на головному екрані**: Всі обрані файли з усіх ресурсів (локальних, мережевих, хмарних) зібрані в одному списку, незалежно від місця зберігання.
- **Прокручуваний віджет головного екрана**: Віджет на лончері відображає список обраного та запускає файли безпосередньо з головного екрана.

## 18. Віджети та ярлики головного екрана

- **Віджет «Обране»**: Прокручуваний список обраних файлів на лончері. Натискання — відкриття без зайвої навігації.
- **Віджет ярлика ресурсу**: Одне натискання відкриває конкретну папку або NAS-шару безпосередньо в браузері.
- **Віджет «Продовжити читання»**: Визначає останній переглянутий документ або відео та батьківський ресурс, і повертає безпосередньо до нього.
- **Ярлик «Випадкова музика»**: Запускає перемішане відтворення з віртуального ресурсу «Вся музика» прямо з лончера — без меню.
- **Ярлик «Фото камери»**: Відкриває фотографії камери в режимі сітки прямо з лончера.
- **Ярлики при довгому натисканні на іконку**: Обране, Слайд-шоу та до 3 динамічних ярликів на нещодавні ресурси.
- **Плитка швидких налаштувань для аудіо**: Керування відтворенням із шторки Android без розблокування пристрою.

## 19. Налаштування

Ключові області, де налаштування виходять за межі типових параметрів додатка:

- **Вибір мови на екрані привітання**: На першому екрані запуску користувач може обрати мову застосунку (English / Русский / Українська) до завершення налаштування. Вибір одразу застосовується до всіх подальших сторінок привітання та до всього застосунку.

| Область | Що примітно |
|---|---|
| **Типи медіа** | Незалежні фільтри мінімального/максимального розміру файлу для кожної категорії медіа — наприклад, ігнорувати зображення менше 50 КБ (іконки/мініатюри) при збереженні всіх аудіофайлів. |
| **Аудіо** | Політика завантаження обкладинок (вкл/викл, лише Wi-Fi), випадкові фото як фон при відтворенні, налаштування фонового сервісу, поведінка при натисканні «Назад». |
| **Відтворення** | Увімкнення/вимкнення режиму основного медіаплеєра: керує тим, чи реєструє FMS себе як системний плеєр за замовчуванням для аудіо/відео-інтентів та чи перехоплює апаратні медіаклавіші. |
| **Призначення** | До 10 швидких кнопок-призначень, політика перезапису для кожного призначення, автоперехід при передачі, перемикач системи скасування. |
| **Мережа / Синхронізація** | Інтервал синхронізації WorkManager, перевизначення кількості паралельних потоків. |
| **Кеш** | Виділений пул кешу мініатюр, налаштовуваний від 512 МБ до 16 ГБ. Окремо від системного кешу ОС. |
| **Щільність** | Режим «Компактні елементи» зменшує розмір мініатюр, шрифтів та відступів (~коефіцієнт 0.8×) по всьому списку ресурсів, браузеру та панелях плеєра. Корисно для маленьких екранів або переваги високої щільності. |
| **Резервна копія** | Повний JSON-експорт/імпорт стану додатка — ресурси, призначення, облікові дані, обране. Автоматизовано через Google Drive. |
| **Переклад** | Примусово задані мови джерела/цілі, налаштування типографіки накладань OCR (розмір та сімейство шрифту). |
| **Ландшафтні діалоги** | Кожен діалог має спеціальний ландшафтний макет — обмежений 320 дп у висоту, прокручуваний, з кнопками дій, закріпленими зверху. |

- **Реорганізація груп налаштувань**: На вкладці «Основні» з'явилися окремі групи **«Дозволи та доступ»** і **«Дані та резервні копії»** (раніше були об'єднані в «Файли та дані»); на вкладці «Операції» додано групу **«Безпека операцій»** (Безпечний режим, Підтвердження видалення, Підтвердження переміщення — перенесені з «Основних»); колишня «Система» перейменована на **«Мережа та кеш»**; група Playback «Сортування і слайдшоу» стала **«Сортування, слайдшоу та відтворення»**; усунуто дублі «Операції з файлами» (Operations → «Копіювання та переміщення», Playback → «Доступ до файлів у плеєрі»). Повідомлення про помилки оновлено під нові назви груп.
- **Клавіатурна навігація**: Весь екран налаштувань керується з клавіатури — **стрілки** та **Tab** переміщують фокус між рядками, **Enter** активує виділений перемикач або рядок, **Ctrl+F** відкриває вбудований оверлей пошуку по налаштуваннях, **Escape** закриває його.
- **Інформація про місце на пристрої:** Швидкий доступ до доступного місця у вбудованому накопичувачі з основних налаштувань із кнопкою оновлення — не потрібно рутися в системних параметрах.
- **Керування дозволами:** під час першого запуску відображається повний список запитуваних прав з описом. Доступно повторно в будь-який момент через Налаштування → Керування дозволами. Контекстні запити з'являються при увімкненні функцій, що потребують конкретних прав.

## 21. Додаток-компаньйон для Wear OS

Додаток для годинника працює незалежно — має власний список джерел SMB/FTP/SFTP та не вимагає активності телефону.

- **Синхронізація джерел із телефону**: Надсилання всіх налаштованих мережевих джерел із телефону на годинник одним натисканням через Wearable Data Layer. Годинник вібрує після завершення з підсумковою кількістю доданих/оновлених джерел.
- **Керування джерелами на годиннику**: Додавання або видалення джерел SMB, FTP та SFTP безпосередньо на годиннику з протокол-орієнтованим майстром налаштування.
- **Незалежний перегляд медіа та відтворення**: Навігація по списках файлів, запуск слайд-шоу, керування аудіо та відео — все на дисплеї годинника.
- **Регулятор інтервалу слайд-шоу**: Зміна інтервалу слайд-шоу безпосередньо на годиннику без відкриття телефону.
- **Реактивне оновлення списку джерел**: Список оновлюється автоматично після синхронізації, імпорту або видалення без примусової навігації.

## 22. Фонові та системні сервіси

- **Синхронізація MediaStore після кожної операції**: Після будь-якого копіювання, переміщення або видалення додаток негайно повідомляє Android MediaStore. Галерея та інші індексуючі додатки залишаються актуальними.
- **Інтеграція як плеєр за замовчуванням (опціонально)**: Перемикачі керують тим, чи реєструє FMS себе системним плеєром за замовчуванням для аудіо/відео/зображень/документів та чи перехоплює апаратні медіаклавіші.
- **Автономний плеєр через «Відкрити за допомогою»**: При відкритті файлу з будь-якого зовнішнього додатка автономний плеєр надає копіювання, переміщення, видалення, спільний доступ, перейменування, перемикач «Обране» та «Відкрити в браузері FMS» — без втрати контексту зовнішнього додатка.
- **Керування аудіофокусом в автономному плеєрі**: Автоматична пауза при вхідних дзвінках та коротких перериваннях; звільнення аудіофокусу при виході, щоб інші плеєри відновилися негайно.
- **Аудит облікових даних**: Відстежує час останнього використання кожного збереженого мережевого облікового запису. Застарілі записи виводяться для ручного очищення.
- **Очищення тимчасових файлів**: Покинуті артефакти завантаження та невдалі фрагменти вивантаження видаляються при завантаженні — ручне очищення сховища не потрібне.
- **Кеш мініатюр**: Попередньо відрендерені мініатюри Glide зберігаються у виділеному пулі (до 16 ГБ). Повторні відкриття великих мережевих каталогів використовують кешовані мініатюри без повторного запиту.
- **Автозавантаження за вхідним посиланням (S0003)**: Коли із системного «Поділитися» приходить звичайний http(s)-URL, додаток намагається витягнути за ним файл (пряме посилання або вбудоване медіа HTML-сторінки ≥ 1 МіБ) і покласти результат у вибраний ресурс-отримувач — або в системну папку Downloads, якщо ресурс не вибрано чи він тимчасово недоступний. Окремий перемикач керує автоматичним відкриттям завантаженого у вбудованому плеєрі. Дозволені лише медіа/документні MIME; редіректи на не-`http(s)` блокуються. Верхній перемикач і обидва підпорядковані контроли — Налаштування → Поділитися/Приймання → Поведінка.

## 23. Заплановані файлові операції

Автоматичне виконання операцій копіювання, переміщення або видалення за налаштованим розкладом — без відкриття додатка.

- **Будь-який ресурс як джерело або призначення**: Локальні, SMB, FTP, SFTP, Google Drive, OneDrive та Dropbox працюють як джерело і призначення. Доступність призначення перевіряється до дотику до файлів; недосяжні призначення записуються як помилки та повторюються при наступному циклі.
- **Фільтри типів файлів та часового вікна**: Вибір оброблюваних категорій (зображення, аудіо, відео, документи, всі файли) з опціональним обмеженням по файлах, створених з останнього запуску, за останню годину або за останній день.
- **Безпечне атомарне переміщення**: Копія верифікується до видалення джерела. Невдала копія ніколи не видаляє оригінал.
- **Журнал операцій**: Кожен запуск записує пофайлові записи журналу з відміткою часу (джерело, призначення, успіх/помилка). Ротація при 1 МБ. Доступний та очищуваний з екрана налаштувань.
- **Маркер помилок**: Попереджувальний значок (⚠) з'являється поруч із будь-якою операцією, останній запуск якої завершився з помилками.
- **Збереження після перезавантаження**: Заплановані завдання переживають перезавантаження пристрою та автоматично переназначаються через WorkManager.
- **Запит оптимізації батареї**: При першому використанні пропонує вимкнути оптимізацію батареї — необхідно на пристроях OEM (Xiaomi, Huawei, Samsung), які агресивно завершують фонові завдання WorkManager.

## 24. Що замінює FMS — порівняння з конкурентами

FastMediaSorter охоплює те, для чого зазвичай потрібні 5–10 окремих додатків. У таблицях нижче показані лише реальні переваги FMS — рядки, де обидві сторони рівні, пропущені.

### Фотогалерея

**Поширені альтернативи:** Google Photos, Simple Gallery Pro, F-Stop Gallery, Piktures, QuickPic

| Де FMS відрізняється | Типова галерея | FMS |
|---|---|---|
| Навігація по NAS / SMB | Ні | Так — нативно, з пулінгом з'єднань |
| Хмара (Drive, Dropbox, OneDrive) | Google Photos: лише власна хмара | Так — всі три + NAS + FTP/SFTP |
| Файлові операції (копіювання/переміщення/перейменування) | Обмежено або ні | Повні міжпротокольні |
| PIN-захист на рівні папки | Рідко | Так |
| Автоматична передача за розкладом | Ні | Так |
| Пошук дублікатів (побайтовий) | Ні | SHA-256 міжджерельний |

Галереї добре працюють із локальними фото. FMS додає повний доступ до NAS/хмари, автоматизацію за розкладом та міжпротокольні файлові операції.

---

### Відеоплеєр

**Поширені альтернативи:** VLC для Android, MX Player, mpv-android, Nova Video Player

| Де FMS відрізняється | Типовий відеоплеєр | FMS |
|---|---|---|
| Відтворення з SMB/NAS | VLC: базово; MX: плагін | Нативно — пулінг з'єднань, до 24 потоків |
| Відтворення з SFTP/FTP | VLC: базово | Нативно |
| Відтворення з Google Drive / Dropbox / OneDrive | Ні — потрібне завантаження | Прямий стрімінг |
| Керування файлами під час відтворення | Ні | Копіювання/переміщення/видалення/перейменування/відправка прямо в плеєрі |
| Пошук дублікатів | Ні | SHA-256 міжджерельний |
| Операції за розкладом | Ні | Так |

VLC та MX Player чудово декодують. FMS поступається в глибині кодеків, але надає повну інтеграцію з NAS/хмарою та керування файлами прямо в плеєрі.
