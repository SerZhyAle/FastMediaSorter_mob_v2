# Технические требования

[Техническая спецификация](V2_Specification_RU.html) | [Tech Stack, EN](TECH_STACK.html)

Здесь разделены требования SDK из конфигурации и условия отдельных функций. Это публичный справочник, а не обещание установки на любое устройство или объявление нового выпуска.

## Требования SDK

На узком экране прокрутите таблицу SDK по горизонтали, чтобы увидеть все столбцы.

| Модуль или редакция | minSdk | targetSdk | compileSdk |
|---|---|---|---|
| `standard / noLegal / lite / photos` | 26 | 36 | 37 |
| `legacy / foss` | 23 | 36 | 37 |
| `vr` | 29 | 34 | 37 |
| `xr` | 26 | 36 | 37 |
| `wear: standard / noLegal` | 28 | 36 | 37 |
| `watchface` | 36 | 36 | 36 |

`minSdk` задаёт нижнюю границу установки; `targetSdk` выбирает поведение совместимости Android; `compileSdk` задаёт API для компиляции. Высокий compileSdk не требует той же версии Android на каждом устройстве.

## Устройство и сервисы

- Базовые редакции телефона требуют Android 8.0 / API 26. Legacy и FOSS имеют нижнюю границу API 23; ограничения функций и совместимость устройства сохраняются.
- VR требует API 29 и совместимую гарнитуру/runtime для погружения; номер API сам по себе не доказывает поддержку гарнитуры.
- Приложение Wear имеет нижнюю границу API 28. Отдельному циферблату WFF v4 нужны Wear OS 6 / API 36; его устанавливают на часы, не на телефон.
- Обмен между телефоном и часами требует совместимых application ID, подписей и связи. Namespace не является идентификатором сопряжения.
- Локальные файлы и document-tree требуют соответствующих разрешений Android или доступа, предоставленного пользователем. Сетевым и облачным функциям нужны связь и авторизация провайдера.
- Функциям, зависящим от Google, нужны соответствующие сервисы Google. Это не означает, что они обязательны для всех облаков и локальных функций.
- В этих определениях Gradle нет единого обязательного порога RAM, heap или свободного места. Нагрузка зависит от разрешения медиа, кодеков, кэша и операций; размер старого debug APK не является минимальным требованием.

## Доступность редакций

Наличие flavor в сборке не означает публикацию его APK. Проверенные файлы находятся в [разделе загрузок](../index-ru.html#download), а флаги возможностей - в [сгенерированной матрице](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/blob/main/docs/FLAVOR_MATRIX.md).
