why: |
  Домашний NAS с отключенным SMB, рабочий сервер, доступный только извне домашней сети, или компьютер друга, который хочет поделиться папкой без диктовки пароля по телефону — для всех этих задач отлично подходят протоколы [FTP и SFTP](term:sftp), а не [SMB](term:smb). В отличие от сетевых папок Windows, к FTP/SFTP-серверам можно подключаться по адресу из любой точки мира. При использовании SFTP приложение также умеет гарантировать, что вы подключаетесь к подлинному серверу каждый раз, а не только при первой настройке.

  Если вы еще выбираете между SMB и SFTP, в конце руководства [Подключение сетевых ресурсов SMB/Windows](page:network.smb-samba-shares) приведено их краткое сравнение.

steps:
  - number: 1
    id: add-a-server
    title: Добавьте сервер по адресу
    text: |
      На главном экране нажмите **Добавить**, затем **SFTP / FTP** — откроется экран **Добавить ресурс S/FTP**. В блоке **Выберите протокол:** укажите **SFTP (порт 22)** или **FTP (порт 21)**; поле **Порт** заполнится автоматически (с подсказкой «SFTP: 22, FTP: 21», если вы решите изменить значение). Введите **Хост** (адрес сервера) — поле ожидает IP-адрес или доменное имя.

      SFTP шифрует весь сетевой трафик, тогда как обычный FTP передает данные в открытом виде. Выбирайте FTP только в тех случаях, когда сервер вообще не поддерживает SFTP.
    image:
      src: assets/images/network/sftp-ftp-servers-add-form.png
      alt: Экран Добавить ресурс S/FTP с переключателем протоколов SFTP/FTP и заполненными полями Хост и Порт
      caption: "Выбор протокола и ввод адреса сервера."
  - number: 2
    id: sign-in
    title: Войдите по паролю или SSH-ключу
    text: |
      В блоке **Способ входа** выберите **Пароль** или **SSH-ключ**. Для парольного входа достаточно заполнить **Имя пользователя** и **Пароль**.

      Для режима **SSH-ключ** вставьте текст ключа в поле **Закрытый SSH-ключ** либо нажмите **Загрузить файл**, чтобы выбрать файл из памяти устройства, и введите **Парольная фраза ключа (необязательно)**, если ключ защищен паролем. Если формат ключа некорректен, приложение сразу предупредит «Неверный формат закрытого SSH-ключа» еще до попытки подключения. Если устройство содержит предустановленные конфигурационные файлы ресурсов, они могут использовать ключ автоматически без необходимости ручного ввода.
    image:
      src: assets/images/network/sftp-ftp-servers-ssh-key-auth.png
      alt: Раздел авторизации по SSH-ключу с полем Закрытый SSH-ключ, кнопкой Загрузить файл и полем парольной фразы
      caption: "Вставка ключа или загрузка из файла."
  - number: 3
    id: test-and-trust
    title: Проверьте соединение и закрепите подлинность сервера
    text: |
      Нажмите **Проверить подключение**. При первом успешном ответе SFTP-сервера полезно закрепить его отпечаток: откройте раздел **Проверка сервера (необязательно)** («Дополнительная безопасность: подтверждает подлинность сервера»). Приложение покажет строку «Отпечаток ключа хоста: <отпечаток>» с кнопкой **Закрепить ключ хоста**, либо вы можете вручную вставить известное значение в поле **Ожидаемый отпечаток ключа хоста (SHA256, необязательно)**. Закрепление отпечатка означает «Отпечаток ключа хоста закреплен», и приложение будет доверять только этому ключу при всех последующих сеансах.

      Этот шаг опционален — большинство пользователей могут просто добавить ресурс, но именно закрепление отпечатка превращает «вероятно нужный сервер» в «гарантированно подлинный сервер».
    image:
      src: assets/images/network/sftp-ftp-servers-host-key-pin.png
      alt: Диалог Проверка подключения - Успешно для SFTP-сервера с отображением отпечатка ключа хоста и кнопкой Закрепить ключ хоста
      caption: "Закрепление отпечатка ключа сервера при первом подключении."
    callout:
      type: tip
      title: Что такое отпечаток ключа хоста простыми словами
      text: "У каждого SFTP-сервера есть свой закрытый ключ подлинности, а отпечаток — это его короткий уникальный цифровой слепок. Закрепить отпечаток — все равно что запомнить сервер в лицо: если под тем же адресом позже ответит другой сервер, отпечаток не совпадет, и подмена будет раскрыта."
  - number: 4
    id: checked-every-time
    title: Подлинность сервера проверяется при каждом обращении
    text: |
      Закрепленный отпечаток ключа проверяется при каждом сетевом запросе ресурса — при просмотре каталогов, загрузке миниатюр, воспроизведении и повторных подключениях, а не только по кнопке проверки. Если сервер ответит другим ключом, приложение заблокирует соединение: «Сервер этой общей папки отличается от того, с которым выполнялось сопряжение. Данные не загружены в целях вашей безопасности». Так выглядит реальная попытка перехвата трафика (MITM), либо ситуация, когда сервер был переустановлен и сгенерировал новый ключ. Во втором случае просто закрепите новый отпечаток, убедившись в надежности источника.
  - number: 5
    id: share-access
    title: Передайте доступ к уже добавленной папке
    text: |
      Откройте меню SFTP-ресурса и выберите **Поделиться доступом..**. На экране **Поделиться доступом к SFTP** («Этот файл содержит пароль доступа. Отправляйте его только тем, кому доверяете») можно отметить пункт **Не включать пароль**, чтобы передать пароль собеседнику отдельно. Если сервер доступен только в домашней сети, появится примечание: «Сервер находится в локальной сети — получатель сможет подключиться только находясь в той же сети».

      Нажмите **Поделиться**, чтобы открыть системный диалог отправки и передать файл конфигурации через Telegram, почту или любой другой мессенджер.
    image:
      src: assets/images/network/sftp-ftp-servers-share-access.png
      alt: Экран Поделиться доступом к SFTP с предупреждением о пароле, флажком Не включать пароль и кнопкой Поделиться
      caption: "Передача доступа к папке с опциональным исключением пароля."
  - number: 6
    id: import-shared-access
    title: Добавьте папку, доступом к которой с вами поделились
    text: |
      Нажмите на полученный файл доступа в Telegram или во вложении письма — автоматически откроется диалог **Импорт доступа** с предложением добавить SFTP-ресурс со всеми входящими в него папками. Если пароль был исключен из файла, диалог запросит его ввод. Нажмите **Импортировать** — и ресурс готов к работе без ручного ввода адресов и портов.

      Импорт можно запустить и вручную: на экране «Добавить ресурс» и в форме SFTP доступны кнопки **Импорт из файла** и **Импорт по штрихкоду** (для сканирования QR-кода камерой).
    image:
      src: assets/images/network/sftp-ftp-servers-import-access.png
      alt: Диалог Импорт доступа с подтверждением имени SFTP-ресурса, адреса сервера, количества папок и полем ввода пароля
      caption: "Добавление ресурса в одно касание по полученному файлу."
    callout:
      type: tip
      title: Так же подключаются папки с компьютера
      text: "Папки, опубликованные через [Fast Media Sorter for Windows](term:windows-companion), используют тот же формат файла конфигурации и тот же диалог импорта — см. [Раздача папок с ПК через Fast Media Sorter for Windows](page:network.windows-companion)."
  - number: 7
    id: quietly-resilient
    title: Забота о стабильности без лишних вопросов
    text: |
      - **Зависшее сканирование каталога завершается вовремя.** Опрос SFTP-папки гарантированно завершается по тайм-ауту даже при смене сети или зависшем сокете: выдается сообщение «Загрузка папки занимает слишком много времени. Проверьте сеть и повторите попытку» вместо бесконечно крутящегося индикатора.
      - **Недоступный сервер не опрашивается вхолостую.** После неудачной попытки подключения приложение делает короткую паузу перед повторными запросами, быстро возвращая статус кэша вместо долгого ожидания сетевого тайм-аута для каждого файла или миниатюры.

Добавляйте серверы FTP и SFTP по адресу, авторизуйтесь по паролю или SSH-ключу, закрепляйте отпечаток подлинности узла для автоматической проверки при каждом сеансе и делитесь доступом к папкам через единый файл конфигурации. Поддерживается также проверка соединения со смарт-часов [Wear OS](term:watch).
