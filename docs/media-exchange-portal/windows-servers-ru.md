# Серверы Windows: раздача папок ПК на ваши устройства

На ПК с Windows обменом занимается **[Fast Media Sorter & Sharing for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/)**. Кроме сортировки и просмотра медиа, он может быть сервером, который открывают ваши телефон, планшет, телевизор или шлем. Эта страница ведётся вместе с продуктом для Windows и отделяет то, что уже выпущено, от того, что есть только в версии для разработки.

## Две редакции {#editions}

Обе редакции запускают одну и ту же службу раздачи. Различаются тем, что ещё устанавливается, и тем, когда служба работает.

| | Полный пакет | Серверная редакция |
|:--|:--|:--|
| Для чего | Просмотр и сортировка медиа на ПК и раздача папок из **Share Manager**, пока вы вошли в систему. Может и сам переключиться на работу как служба Windows. | ПК, задача которого - только быть доступным: раздача работает как служба Windows, которая стартует при загрузке, без вошедшего пользователя. Просмотрщик - необязательный компонент, по умолчанию не отмечен. |
| Как получить | winget `SerZhyAle.FastMediaSorter`, установщик или ZIP с GitHub либо Microsoft Store (версия из Store работает только в режиме пользователя). Начните с [сайта продукта](https://serzhyale.github.io/FastMediaSorter_Lite/). | winget `SerZhyAle.FastMediaSorter.Server` или установщик со [страницы серверной редакции](https://serzhyale.github.io/FastMediaSorter_Lite/server.html). |
{: .doc-table}

Для раздачи нужна 64-разрядная Windows 10 версии 1607 или новее. 32-разрядный запасной просмотрщик для Windows 7, Windows 8.1 и 32-разрядной Windows умеет открывать и сортировать медиа, но раздавать не умеет.

## Что вы раздаёте {#what-you-share}

- **Папки выбираете вы.** Раздачей управляет **Share Manager** - программа в области уведомлений, которая идёт вместе с Fast Media Sorter & Sharing for Windows. Видны только добавленные вами папки, и за их пределы раздача не выходит.
- **У каждой папки свои настройки** - данное вами имя, только чтение или запись, необязательный PIN-код и фильтры по типу медиа.
- **Поставляется выключенной.** Ничего не слушает сеть, пока вы не включите серверные функции: флажком при установке или однократной кнопкой в Share Manager. Этот шаг показывает один запрос прав администратора Windows и добавляет одно правило брандмауэра Windows, привязанное к программе раздачи. Тихо это не делается никогда, а правило удаляется при удалении программы.
- **Соединение зашифровано и прямое** - от устройства к ПК по SFTP. Телефон запоминает ключ ПК при первой привязке, поэтому подменённый сервер будет замечен, а не принят на веру. Ключ создаётся один раз и не заменяется ни обновлением, ни перезапуском, ни переходом между редакциями.
- **Папки открывает и любое SFTP-приложение** - не только FastMediaSorter, но и WinSCP, FileZilla или файловый менеджер на другом компьютере. Share Manager показывает адрес, порт, логин, пароль и отпечаток ключа, у каждого есть кнопка копирования.
- **Статистика соединений остаётся на ПК.** В Share Manager есть окно со счётчиками, и ничего из него никуда не отправляется.

## Как папки попадают на телефон {#to-the-phone}

1. В Share Manager раздайте папки и покажите QR-код или выгрузите файл настроек (`.fmscfg`). Те же данные можно отправить по электронной почте или текстовым кодом через буфер обмена.
2. На телефоне в FastMediaSorter откройте **Добавить ресурс** и выберите **Импорт по штрих-коду** или **Импорт из файла**.
3. Общие папки появятся как сетевые ресурсы, логин и ключ ПК уже заполнены.

## Один код, несколько адресов {#one-code}

QR-код и файл `.fmscfg` несут все адреса, по которым ПК достижим:

- **локальный адрес** в вашей сети Wi-Fi или по кабелю;
- **адрес IPv6**, если он у ПК есть, - он может работать там, где провайдер делит один интернет-адрес между многими клиентами и проброшенный порт не поможет, при условии что IPv6 есть и в сети телефона;
- **интернет-адрес** - публичный адрес или имя динамического DNS плюс проброшенный порт.

Телефон пробует их и предпочитает быстрый локальный, поэтому одно сканирование работает и дома, и вдали. В той же сети Wi-Fi он ещё и сам находит ПК, если адрес ПК сменился, потому что узнаёт ПК по его ключу.

Две настройки делают это предсказуемым:

- **Порт сам не перемещается.** ПК выбирает порт один раз при первом запуске и сохраняет его. Правило проброса на роутере и напечатанный QR-код остаются действительными. Если этот порт занять не удаётся, сервер остаётся выключенным и говорит об этом, а не уходит молча на другой порт.
- **Переключатель «только локальная сеть»** оставляет в коде лишь локальный адрес и отключает любые попытки открыть роутер. Используйте его для раздачи, которая никогда не должна быть видна снаружи.

## Как открыть путь снаружи {#from-outside}

Чтобы подключаться не из дома, роутер должен передавать порт на ПК. Share Manager помогает в три шага:

1. Просит роутер открыть порт самому через UPnP или NAT-PMP, если роутер это позволяет. Многие роутеры не позволяют или держат это выключенным. В режиме «только локальная сеть» этот шаг пропускается.
2. Затем проверяет порт **из интернета** через сторонний сервис проверки (check-host.net) и прямо говорит, что нашёл: раздача работает из интернета, порт не отвечает и проброс стоит проверить, либо роутер порт открыл, но провайдер блокирует входящие соединения.
3. Если роутер сам порт не открыл, показывает адрес роутера, предлагает кнопку **Открыть роутер** и может найти инструкцию для вашей модели роутера.

Если провайдер блокирует входящие соединения вообще (общий адрес оператора на многих клиентов), Share Manager предупредит об этом, и проброшенный порт не поможет; может помочь адрес IPv6 из раздела выше. Настройка порта вручную описана в разделе [Домашняя сеть](home-network-ru.html).

## ПК, который раздаёт без вошедшего пользователя {#always-on}

По умолчанию папки доступны, пока вы вошли в систему и работает Share Manager, - этого достаточно для обычного ПК. Машина, задача которой - быть всегда доступной, может держать ту же службу как службу Windows, которая стартует при загрузке: переключите это в Share Manager (**Настройки менеджера**, **Хостинг**) или установите отдельную [серверную редакцию](https://serzhyale.github.io/FastMediaSorter_Lite/server.html).

- **Для телефонов ничего не меняется.** Служба использует тот же ключ, тот же порт и тот же список папок, поэтому привязанные телефоны не нужно привязывать заново.
- **Одно видимое подтверждение.** Регистрация службы один раз просит подтверждения администратора в окне, которое вы видите.
- **Никогда обе сразу.** Служба и рабочий процесс Share Manager в сеансе пользователя не работают вместе; когда служба зарегистрирована, раздаёт именно она.
- **Не в версии из Store.** Сборка из Microsoft Store работает только в режиме пользователя и службой быть не может.

## ПК как клиент {#pc-as-client}

<div class="doc-callout doc-callout-warn" markdown="1">
**Версия для разработки, не в последнем выпуске.** Два пункта ниже описывают просмотрщик для Windows так, как он создаётся. В выпущенной версии Fast Media Sorter & Sharing for Windows их пока нет.
</div>

- **SFTP-серверы как папка.** Просмотрщик открывает SFTP-сервер - NAS, Share Manager другого ПК или встроенный SFTP-сервер телефона - как папку из своего списка ресурсов.
- **Файлы настроек.** Он импортирует файл `.fmscfg` и выгружает сохранённый сервер в такой файл (только в 64-разрядной версии).

Выпущено уже сегодня другое: команда просмотрщика **Открыть URL..** воспроизводит видео прямо по адресу `smb://`, `sftp://`, `ftp://`, `http(s)://` или `rtsp://`, не копируя файл заранее.

## Запланировано {#planned}

<div class="doc-callout doc-callout-warn" markdown="1">
**Ещё не выпущено.** Ничего из перечисленного ниже нет ни в одном выпуске, и нигде не работает ни один сервер обмена. Сторона Windows готовится в версии для разработки, чтобы быть готовой к появлению сервера.
</div>

- **Media Exchange Server** - служба соединения для раздачи, у которой нет ни доступного адреса, ни проброшенного порта. Пакет для Windows будет нести серверную программу как необязательный компонент, по умолчанию не отмеченный, а управляться она будет из Share Manager. Тот, кто запускает сервер, является его оператором. См. [Сервер обмена](exchange-server-ru.html).
- **ПК как участник учётной записи обмена** - публикация своих раздач и открытие папок других устройств через сервер.
- **Трансляция с ПК** - экран, камера, микрофон и системный звук. Fast Media Sorter & Sharing for Windows сегодня не транслирует. См. [Живая трансляция](live-broadcast-ru.html).

Воспроизведение живых трансляций на ПК с Windows работает уже сегодня в [STREAMS Player](https://serzhyale.github.io/StreamsPlayer/).
