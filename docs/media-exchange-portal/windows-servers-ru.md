# Серверы Windows: раздача папок ПК на ваши устройства

На ПК с Windows обменом занимается **[Fast Media Sorter & Sharing for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/)**. Это одна программа с **тремя необязательными частями**, и вы ставите те, ради которых пришли: **просмотрщик и сортировщик** фото и видео, **раздачу папок**, которая открывает папки ПК на вашем телефоне, планшете, телевизоре или шлеме, и **Media Exchange Server**. Эта страница ведётся вместе с продуктом для Windows. Она разделяет две серверные роли и говорит, какой пакет содержит какую часть.

## Три необязательные части {#three-parts}

- **Просмотрщик и сортировщик.** Просматривает и сортирует фото и видео на ПК, одной клавишей на файл. Ему не нужны ни сервер, ни учётная запись.
- **Раздача папок.** Раздаёт выбранные вами папки по SFTP, поэтому телефон, планшет, телевизор, шлем или любое SFTP-приложение открывают их прямо на ПК - в вашей сети или откуда угодно с одним проброшенным портом. Ей не нужны ни учётная запись, ни сервер обмена. Виртуальные диски FileDO - необязательное дополнение к этой раздаче, выключенное, пока вы не зарегистрируете диск. Подробности: [что вы раздаёте](#what-you-share).
- **Media Exchange Server.** Другая часть, а не режим раздачи папок. Раздача папок отдаёт папки ПК устройству, которое может до него дотянуться. Сервер обмена - место встречи для устройств, которые не могут: каждое выходит к нему само, а одна учётная запись показывает все ваши папки и трансляции. См. [что входит в каждый пакет](#availability) и [Сервер обмена](exchange-server-ru.html).

Нужны не все три. Начните с просмотрщика и добавьте раздачу папок, если она нужна, или начните с сервера и добавьте просмотрщик, если он нужен: выбор просмотрщика не требует сервера, а выбор сервера не требует просмотрщика.

## Два способа начать {#editions}

Есть две отправные точки для одной и той же программы. Они различаются тем, что ставится первым и когда работает раздача; это не два продукта, между которыми выбирают раз и навсегда.

### Сначала просмотрщик {#viewer-first}

Для ПК, на котором вы ещё и работаете. Просмотрщик и сортировщик ставится всегда. Раздача папок входит в полный тип установки: она остаётся выключенной, пока вы её не включите, и после этого работает, пока вы вошли в систему. Она может и сама переключиться на работу как служба Windows.

- **Как получить:** winget `SerZhyAle.FastMediaSorter`, установщик или ZIP с GitHub либо Microsoft Store. Начните с [сайта продукта](https://serzhyale.github.io/FastMediaSorter_Lite/).
- **Только просмотрщик:** тип установки «Компактная» ставит просмотрщик вообще без раздачи.
- **Версия из Microsoft Store** несёт просмотрщик и раздачу папок только в режиме пользователя. Службой Windows она быть не может.

### Сначала сервер {#server-first}

Для ПК, задача которого - быть всегда доступным. Раздача папок работает как служба Windows, которая стартует при загрузке, без вошедшего пользователя. Просмотрщик - необязательная часть, по умолчанию не отмечена, поэтому этот способ его не требует.

- **Как получить:** winget `SerZhyAle.FastMediaSorter.Server` или установщик со [страницы серверной редакции](https://serzhyale.github.io/FastMediaSorter_Lite/server.html).
- **Одно видимое подтверждение.** Установщик регистрирует службу и один раз просит подтверждения администратора в окне, которое вы видите.
- **Что в ней есть:** раздача папок как служба, а сервер обмена и просмотрщик - необязательные части.

## Что входит в каждый пакет {#availability}

| | Просмотрщик и сортировщик | Раздача папок | Media Exchange Server |
|:--|:--|:--|:--|
| Сначала просмотрщик (полный пакет) | Ставится всегда | В полном типе установки, в компактном нет; выключена, пока вы не включите | Необязательная часть, не отмечена |
| Сначала сервер (серверная редакция) | Необязательная часть, не отмечена | Вся задача: служба Windows с загрузки | Необязательная часть, не отмечена |
| Версия из Microsoft Store | Да | Да, только в режиме пользователя | Её там нет |
| Где работает | Пока вы вошли в систему | Пока вы вошли в систему или как служба Windows | Как служба Windows |
| Запрос прав администратора | Нет, если не ставить для всех пользователей | Один раз при включении раздачи (добавляется правило брандмауэра); ещё один раз при регистрации службы | Один раз: регистрация службы и правило брандмауэра |
{: .doc-table}

Для раздачи папок и сервера обмена нужна 64-разрядная Windows 10 версии 1607 или новее. 32-разрядный запасной просмотрщик для Windows 7, Windows 8.1 и 32-разрядной Windows умеет открывать и сортировать медиа, но раздавать не умеет.

## Раздача папок: что вы раздаёте {#what-you-share}

- **Папки выбираете вы.** Раздачей управляет **Share Manager** - программа в области уведомлений, которая идёт вместе с Fast Media Sorter & Sharing for Windows. Видны только добавленные вами папки, и за их пределы раздача не выходит.
- **У каждой папки свои настройки** - данное вами имя, только чтение или запись, необязательный PIN-код и фильтры по типу медиа.
- **Поставляется выключенной.** Ничего не слушает сеть, пока вы не включите серверные функции: флажком при установке или однократной кнопкой в Share Manager. Этот шаг показывает один запрос прав администратора Windows и добавляет одно правило брандмауэра Windows, привязанное к программе раздачи. Тихо это не делается никогда, а правило удаляется при удалении программы.
- **Соединение зашифровано и прямое** - от устройства к ПК по SFTP. Телефон запоминает ключ ПК при первой привязке, поэтому подменённый сервер будет замечен, а не принят на веру. Ключ создаётся один раз и не заменяется ни обновлением, ни перезапуском, ни переходом между способами начать.
- **Папки открывает и любое SFTP-приложение** - не только FastMediaSorter, но и WinSCP, FileZilla или файловый менеджер на другом компьютере. Share Manager показывает адрес, порт, логин, пароль и отпечаток ключа, у каждого есть кнопка копирования.
- **Статистика соединений остаётся на ПК.** В Share Manager есть окно со счётчиками, и ничего из него никуда не отправляется.

## Как папки попадают на телефон {#to-the-phone}

1. В Share Manager раздайте папки и покажите QR-код или выгрузите файл настроек (`.fmscfg`). Те же данные можно отправить по электронной почте или текстовым кодом через буфер обмена.
2. На телефоне в FastMediaSorter откройте **Добавить ресурс** и выберите **Импорт по штрих-коду** или **Импорт из файла**.
3. Общие папки появятся как сетевые ресурсы, логин и ключ ПК уже заполнены.

## Один код, несколько адресов {#one-code}

QR-код и файл `.fmscfg` несут все адреса, по которым ПК достижим:

- **локальный адрес** в вашей сети Wi-Fi или по кабелю;
- **адрес IPv6**, если он у ПК есть, - он может работать там, где провайдер делит один интернет-адрес между многими клиентами и проброшенный порт не поможет, при условии что IPv6 есть и в сети телефона;
- **интернет-адрес** - публичный адрес или имя динамического DNS плюс проброшенный порт.

Телефон пробует их и предпочитает быстрый локальный, поэтому одно сканирование работает и дома, и вдали. В той же сети Wi-Fi он ещё и сам находит ПК, если адрес ПК сменился, потому что узнаёт ПК по его ключу.

Две настройки делают это предсказуемым:

- **Порт сам не перемещается.** ПК выбирает порт один раз при первом запуске и сохраняет его. Правило проброса на роутере и напечатанный QR-код остаются действительными. Если этот порт занять не удаётся, сервер остаётся выключенным и говорит об этом, а не уходит молча на другой порт.
- **Переключатель «только локальная сеть»** оставляет в коде лишь локальный адрес и отключает любые попытки открыть роутер. Используйте его для раздачи, которая никогда не должна быть видна снаружи.

## Как открыть путь снаружи {#from-outside}

Чтобы подключаться не из дома, роутер должен передавать порт на ПК. Share Manager помогает в три шага:

1. Просит роутер открыть порт самому через UPnP или NAT-PMP, если роутер это позволяет. Многие роутеры не позволяют или держат это выключенным. В режиме «только локальная сеть» этот шаг пропускается.
2. Затем проверяет порт **из интернета** через сторонний сервис проверки (check-host.net) и прямо говорит, что нашёл: раздача работает из интернета, порт не отвечает и проброс стоит проверить, либо роутер порт открыл, но провайдер блокирует входящие соединения.
3. Если роутер сам порт не открыл, показывает адрес роутера, предлагает кнопку **Открыть роутер** и может найти инструкцию для вашей модели роутера.

Если провайдер блокирует входящие соединения вообще (общий адрес оператора на многих клиентов), Share Manager предупредит об этом, и проброшенный порт не поможет; может помочь адрес IPv6 из раздела выше. Настройка порта вручную описана в разделе [Домашняя сеть](home-network-ru.html).

## ПК, который раздаёт без вошедшего пользователя {#always-on}

По умолчанию папки доступны, пока вы вошли в систему и работает Share Manager, - этого достаточно для обычного ПК. Машина, задача которой - быть всегда доступной, может держать ту же службу как службу Windows, которая стартует при загрузке: переключите это в Share Manager (**Настройки менеджера**, **Хостинг**) или начните [с сервера](#server-first) с отдельной серверной редакцией.

- **Для телефонов ничего не меняется.** Служба использует тот же ключ, тот же порт и тот же список папок, поэтому привязанные телефоны не нужно привязывать заново.
- **Одно видимое подтверждение.** Регистрация службы один раз просит подтверждения администратора в окне, которое вы видите.
- **Никогда обе сразу.** Служба и рабочий процесс Share Manager в сеансе пользователя не работают вместе; когда служба зарегистрирована, раздаёт именно она.
- **Не в версии из Store.** Сборка из Microsoft Store работает только в режиме пользователя и службой быть не может.

## ПК как клиент {#pc-as-client}

- **SFTP-серверы как папка.** Просмотрщик открывает SFTP-сервер - NAS, Share Manager другого ПК или встроенный SFTP-сервер телефона - как папку из своего списка ресурсов.
- **Файлы настроек.** Он импортирует файл `.fmscfg` и выгружает сохранённый сервер в такой файл (только в 64-разрядной версии).
- **Воспроизведение прямо по адресу.** Команда просмотрщика **Открыть URL..** воспроизводит видео прямо по адресу `smb://`, `sftp://`, `ftp://`, `http(s)://` или `rtsp://`, не копируя файл заранее.

## ПК в вашей учётной записи обмена {#exchange-member}

- **Media Exchange Server** - третья часть, отдельная от раздачи папок: служба соединения для раздачи, у которой нет ни доступного адреса, ни проброшенного порта, и место встречи устройств одной учётной записи. Это необязательная часть, по умолчанию не отмеченная, в обоих способах начать; в версии из Microsoft Store его нет. Управляется он из Share Manager. Тот, кто запускает сервер, является его оператором. См. [Сервер обмена](exchange-server-ru.html).
- **ПК как участник учётной записи обмена** - публикует свои раздачи и открывает папки других устройств через сервер.
- **Трансляция с ПК** - экран, камера, микрофон и системный звук. См. [Живая трансляция](live-broadcast-ru.html).

Живые трансляции на ПК с Windows воспроизводит и [STREAMS Player](https://serzhyale.github.io/StreamsPlayer/).

## Окна настроек Windows {#windows-settings-windows}

Запуск, тема, язык, удалённая учётная запись обмена, публикация, буфер и операции по расписанию находятся в настройках менеджера. Порт SFTP, локальная сеть, ограничение подключений и хостинг находятся в настройках общего доступа SFTP. Установленный локальный сервер настраивается в окне настроек сервера обмена. Удалённая учётная запись не требует установки локального сервера обмена.

Ссылки слева внизу открывают другой установленный компонент. Для каждого назначения используется одно окно, которое помнит страницу, группы, прокрутку и размер. Окна могут оставаться открытыми одновременно. Открытие и закрытие настроек не запускает и не останавливает сервер. Черновик порта SFTP сохраняется при переключении; при закрытии можно применить, отбросить или продолжить редактирование.
