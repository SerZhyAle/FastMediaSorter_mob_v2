# Редакции: в каком приложении какой способ обмена

FastMediaSorter для Android выходит в нескольких редакциях. Не в каждой редакции есть каждый способ обмена: в редакции без возможности для неё нет даже кнопки.

## В какой редакции что есть

|:------------|:--------:|:-------:|:----:|:------:|:------:|:--:|:--:|:----:|
| Сетевые папки (SMB, SFTP, FTP) и SFTP-сервер телефона | да | да | нет | да | да | да | да | да |
| Мои устройства и сервер обмена | да | да | нет | да | да | да | да | да |
| Облака (Google Диск, Dropbox, OneDrive) | да | да | нет | да | да | да | да | нет |
| Файлы через Google Drive между вашими устройствами | да | да | нет | да | да | да | да | нет |
| Выход в эфир с этого устройства (звук, камера, экран, файл) | да | да | нет | нет | да | нет | нет | нет |
| Воспроизведение живых трансляций и интернет-потоков | да | да | нет | нет | да | да | да | нет |
| Chromecast | да | да | да | да | да | нет | да | нет |
| Компаньон для часов | да | да | нет | нет | нет | нет | нет | нет |

</div>

Таблица сверяется со сборкой каждой редакции, поэтому меняется вместе с редакцией.

Выход в эфир охватывает микрофон, камеру, экран телефона и готовый файл. Камера продолжает вещать в фоне в редакциях Standard и noLegal; в Legacy приложение закрывается чёрным экраном, пока идёт вещание. См. [Выход в эфир](broadcast-start-ru.html).

## Как выбрать редакцию для обмена

- **Все способы обмена на одном телефоне** - Standard или noLegal для копии, установленной не из магазина приложений.
- **Старый телефон или планшет на Android 6 или 7** - Legacy сохраняет сетевые папки, облака и трансляцию.
- **Без закрытых компонентов** - FOSS сохраняет сетевые папки, SFTP-сервер телефона и «Мои устройства», без облаков и без файлов через Google Drive.
- **Lite** работает только с медиа на самом устройстве.

Программы для Windows - отдельные продукты, и эта таблица к ним не относится: у Fast Media Sorter & Sharing for Windows три необязательные части - просмотрщик и сортировщик, раздача папок и сервер обмена - и два способа начать: сначала просмотрщик с полным пакетом и сначала сервер с серверной редакцией, которая держит папки ПК доступными круглые сутки, см. [Серверы Windows](windows-servers-ru.html#editions), а [STREAMS Player](https://serzhyale.github.io/StreamsPlayer/) - отдельная программа.
