# Редакции: в каком приложении какой способ обмена

FastMediaSorter для Android выходит в нескольких редакциях. Не в каждой редакции есть каждый способ обмена: в редакции без возможности для неё нет даже кнопки.

## В какой редакции что есть

<div class="doc-table-wrapper" markdown="1">

| Возможность | Standard | noLegal | Lite | Photos | Legacy | VR | XR | FOSS |
|:------------|:--------:|:-------:|:----:|:------:|:------:|:--:|:--:|:----:|
| Сетевые папки (SMB, SFTP, FTP) и SFTP-сервер телефона | да | да | нет | да | да | да | да | да |
| Облака (Google Диск, Dropbox, OneDrive) | да | да | нет | да | да | да | да | нет |
| Выход в эфир с этого устройства | да | да | нет | нет | да | нет | нет | нет |
| Воспроизведение живых трансляций и интернет-потоков | да | да | нет | нет | да | да | да | нет |
| Chromecast | да | да | да | да | да | нет | да | нет |
| Компаньон для часов | да | да | нет | нет | нет | нет | нет | нет |
{: .doc-table}

</div>

Таблица сверяется со сборкой каждой редакции, поэтому меняется вместе с редакцией.

## Как выбрать редакцию для обмена

- **Все способы обмена на одном телефоне** - Standard или noLegal для копии, установленной не из магазина приложений.
- **Старый телефон или планшет на Android 6 или 7** - Legacy сохраняет сетевые папки, облака и трансляцию.
- **Без закрытых компонентов** - FOSS сохраняет сетевые папки и SFTP-сервер телефона, без облаков.
- **Lite** работает только с медиа на самом устройстве.

Программы для Windows - отдельные продукты, и эта таблица к ним не относится: Fast Media Sorter & Sharing for Windows выходит как полный пакет и как серверная редакция, которая держит папки ПК доступными круглые сутки, см. [Серверы Windows](windows-servers-ru.html), а [STREAMS Player](https://serzhyale.github.io/StreamsPlayer/) - отдельная программа.
