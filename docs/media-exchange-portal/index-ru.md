# Обмен медиа между вашими устройствами

Ваши фото, видео и музыка живут сразу на нескольких устройствах - телефоне, ПК, часах, телевизоре. Портал отвечает на два вопроса до любой настройки: **какой способ связи подходит именно вам** и **какая программа что делает на каждом устройстве**. Каждый раздел заканчивается ссылками на подробные пошаговые инструкции.

![Телефоны, часы, телевизор, VR-шлем, ноутбук, ПК с Windows, роутер и телефон-сервер, связанные вокруг одного центра обмена.](diagrams/ecosystem-hero-ru.svg)

## Выберите свой способ

![Три карточки: домашняя сеть с роутером без сервера, сервер обмена для любой сети и вещание с любого устройства на любое.](diagrams/three-ways-ru.svg)

- **[Домашняя сеть](home-network-ru.html)** - ваш собственный роутер, без дополнительного сервера. Медиа-ПК или телефон раздаёт папки по SFTP; дома всё подключается напрямую на полной скорости, а с одним проброшенным портом те же папки открываются откуда угодно. **Работает уже сегодня.**
- **[Сервер обмена](exchange-server-ru.html)** - одна учётная запись для всех устройств, из любой сети, без настройки роутера. **Ещё не выпущено** - в разделе сказано, что работает уже сейчас.
- **[Живая трансляция](live-broadcast-ru.html)** - телефон или часы выходят в эфир с камерой или микрофоном, а остальные ваши устройства её воспроизводят. **Работает уже сегодня в одной сети Wi-Fi**; ретранслятор для других сетей и трансляция с ПК ещё не выпущены.

Ещё два раздела - о способах, которые не требуют своей настройки:

- **[Облака](clouds-ru.html)** - Google Диск, Dropbox и OneDrive как общий ящик, который открывает каждое устройство, вошедшее в аккаунт.
- **[Редакции](editions-ru.html)** - в какой редакции приложения для Android есть сетевые папки, облака, трансляция и компаньон для часов.

## Какая программа что делает

| Устройство | Программа | Что делает для обмена |
|:-----------|:----------|:----------------------|
| Телефон или планшет Android | FastMediaSorter | Открывает сетевые папки (SMB, SFTP, FTP) и облака; раздаёт свои папки как SFTP-сервер; выходит в эфир с камерой или микрофоном; воспроизводит трансляции; отправляет показ на Chromecast |
| Часы Wear OS | FastMedia Wear, приложение для часов в паре с FastMediaSorter на телефоне | Открывает сетевые папки, свои или присланные с телефона; принимает файлы с телефона; транслирует свой микрофон до четырёх слушателей; воспроизводит трансляцию, которую присылает телефон |
| Android TV | FastMediaSorter | Открывает сетевые папки и облака; воспроизводит трансляции и интернет-потоки |
| VR-шлем | FastMediaSorter, редакция VR | Открывает сетевые папки и облака; воспроизводит трансляции и интернет-потоки внутри шлема |
| ПК с Windows | [Fast Media Sorter & Sharing for Windows](windows-servers-ru.html) | Раздаёт выбранные папки по SFTP на телефоны и в любое SFTP-приложение; привязывает телефон по QR-коду или файлу настроек; серверная редакция продолжает раздавать без вошедшего пользователя; версия для разработки ещё и открывает SFTP-серверы как папку |
| ПК с Windows | [STREAMS Player](https://serzhyale.github.io/StreamsPlayer/) | Воспроизводит живые трансляции с телефона или часов |
{: .doc-table}

## Что работает сегодня, а что ещё нет

Работает уже сегодня:

- Сетевые папки на ПК, NAS или роутере: SMB, SFTP и FTP, с автоматическим поиском серверов в вашей сети.
- Телефон, раздающий свои папки как SFTP-сервер, и привязка другого телефона одним сканированием.
- ПК с Windows, раздающий папки на телефон по QR-коду или файлу. Один код несёт локальный, IPv6- и интернет-адрес, а ПК сам пробует открыть порт на роутере и проверяет его снаружи.
- Серверная редакция, которая работает всегда: ПК с Windows раздаёт как служба, без вошедшего пользователя.
- Google Диск, Dropbox и OneDrive.
- Живая трансляция с телефона или часов на устройства в той же сети Wi-Fi и отправка трансляции на часы.
- Chromecast для файлов, видео и живых потоков.

Ещё не выпущено:

- Публичный сервер обмена: одна учётная запись, один список папок на всех устройствах, доступ из любой сети без настройки роутера.
- Ретранслятор трансляций для получателей вне вашей сети Wi-Fi.
- Cast между вашими устройствами через сервер обмена, когда принимающее устройство спрашивает перед воспроизведением.
- Трансляция с ПК с Windows и участие ПК с Windows в учётной записи обмена.
