# 📝 Довідник термінів

## Основні терміни

- **Resource** - підключене джерело файлів (Local/SMB/SFTP/FTP/Cloud)
- **Destination** - попередньо налаштована папка призначення для швидкого сортування
- **Quick Sort** - copy/move у налаштовані destinations одним натисканням
- **Favorites** - локально збережений список вибраних файлів
- **Touch Zones** - інтерактивні зони 3×3 у режимі плеєра
- **Soft Delete** - перенесення локальних файлів у `.trash/` замість миттєвого видалення

## Додаткові терміни

- **Flavor** - варіант продукту (`standard`, `lite`, `photos`, `legacy`)
- **Browse** - екран списку/сітки файлів вибраного ресурсу
- **Player** - повноекранний переглядач медіа та документів
