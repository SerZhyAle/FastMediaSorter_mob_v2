# 🚀 Швидкий Старт - FastMediaSorter v2

*Почніть за 5 хвилин! Простий посібник для новачків.*

[English](QUICK_START.md) | [Русский](QUICK_START_RU.md)

## Виберіть вашу версію 📱

FastMediaSorter v2 доступний у **5 основних варіантах збірки** для повсякденних сценаріїв, плюс XR / noLegal surface для шоломів і sideload-сценаріїв. Виберіть підходящу для вас:

| Версія | Для кого | Ключові функції |
|--------|----------|-----------------|
| **Standard** ⭐ | Для всіх | Повний функціонал: відео, фото, аудіо, документи, хмара, переклад |
| **Lite** | Менший розмір | Тільки фото та відео (без аудіо, хмари) |
| **Photos** | Фотолюбителі | Тільки зображення, оптимізовано для фото |
| **Legacy** | Старий Android (API 23+) | Повний набір медіа + SMB/FTP/SFTP і хмара; для старого Android (API 23+) |
| **VR / noLegal** | XR-шолом / sideload | OpenXR і sideload-only можливості на сумісному обладнанні |

**👉 Більшості користувачам рекомендується завантажити версію "Standard" для повного досвіду.**

## Перший запуск: виберіть профіль пристрою (30 секунд) 🧭

При найпершому запуску, прямо під вибором мови, екран привітання запитує, **як ви будете використовувати цей пристрій**. Виберіть профіль - і додаток стартує з розумними значеннями за замовчуванням для цього стилю: макет, мініатюри, повний екран, постійно активний екран, фоновий звук та підтвердження видалення/переміщення. Це разова стартова передустановка, а не обмеження - усе можна змінити пізніше.

- 🎯 **Позначка «Рекомендується»:** додаток вгадує підходящий профіль для вашого пристрою та позначає його як **(Рекомендується)**. Якщо вгадав - робити майже нічого не потрібно.
- ⏭️ **Пропустити:** поспішаєте? Кнопка **«Пропустити»** просто застосує рекомендований профіль. Помилитися тут не можна.
- ⚙️ **Змінити пізніше:** **Налаштування → Інтерфейс → Профіль пристрою**. Під час зміни там з'явиться коротке **попередження** - новий профіль перезапише частину налаштувань своїми значеннями - і попросить підтвердження. Поки ви не погодитесь, нічого не зміниться.
- 🧩 **Інший / Без змін:** залишає ваші поточні налаштування як є. Жодна передустановка не застосовується - зручно, якщо любите налаштовувати все вручну.
- ⬆️ **Оновилися зі старої версії?** Профіль буде показано як **Інший**, а ваші попередні налаштування збережено без змін - передустановка автоматично не застосовувалася. Хочете її все ж застосувати? Виберіть профіль у Налаштуваннях.
- 🎚️ **Далі - виберіть, що додаток уміє:** після профілю короткий екран дозволяє увімкнути або вимкнути можливості (файловий менеджер, аудіо, відео, документи, розпізнавання тексту, переклад). Опціональні частини завантажуються прямо там і вмикаються щойно готові - усе можна змінити пізніше в налаштуваннях.

**11 профілів:**

- 📱 **Особистий смартфон** - touch-інтерфейс, фонова синхронізація, стандартні підтвердження безпеки
- 🖥️ **Планшет і ПК-режим** - планшети, Chromebook, Samsung DeX; відображення сітки, великі прев'ю, багатовіконний режим
- 📺 **ТВ-приставка / Медіацентр** - навігація з пульта (DPAD), великі елементи, без дрібних touch-кнопок
- 🚗 **Автомагнітола** - великі кнопки, екран не гасне, пріоритет плеєра над файловими операціями
- 🎬 **Спільний медіаплеєр** - фото, відео та музика з автозапуском слайдшоу та відновленням
- 🖼️ **Цифрова фоторамка** - відразу запускає слайдшоу; файлові операції відходять на другий план
- 🎞️ **Відеопрогравач** - швидкий запуск відеороликів та мініатюри
- 🎵 **Аудіопрогравач** - фоновий звук та екран поточного треку
- 📚 **Електронна книга** - читання PDF, EPUB та тексту
- 🥽 **VR-шолом** - 3D/360°-інтерфейси та імерсивне керування на підтримуваних пристроях
- 🧩 **Інший / Без змін** - залишає налаштування за замовчуванням без змін, передустановка не застосовується

## Крок 1: Додайте свою першу папку (30 секунд)

1. **Відкрийте додаток** - ви побачите головний екран
2. **Натисніть кнопку "+"** (правий нижній кут)
3. **Виберіть "Локальна папка"** (або Мережа/Хмара)
4. **Виберіть папку** з фото або відео (наприклад, DCIM/Camera)
5. **Готово!** Папка з'явиться у вашому списку

> 💡 **Порада:** Для мережевих дисків (SMB) використовуйте нову кнопку **"Сканувати мережу"** для автоматичного пошуку пристроїв!

---

## Крок 2: Перегляд файлів (30 секунд)

1. **Натисніть на папку**, яку щойно додали (або довге натискання)
2. Ви побачите **всі ваші медіафайли** у вигляді мініатюр
3. **Перемикання вигляду:**
   - Іконка сітки = мініатюри
   - Іконка списку = деталі файлу

> 💡 **Порада:** Використовуйте **кнопку фільтра** (іконка воронки), щоб показати лише фото, відео або навіть **Текстові/PDF документи**.

---

## Крок 3: Перегляд та навігація (1 хвилина)

1. **Натисніть будь-яке фото/відео** для відкриття повноекранного плеєра
2. **Свайп вліво** = наступний файл
3. **Свайп вправо** = попередній файл
4. **Щипок для зуму** на фото
5. **Натисніть на екран** для показу/приховування управління

### Сенсорні зони (Області екрану)

Екран розділений на 9 областей для швидких дій:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПІЯ  │ ПЕРЕЙМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  ПОПЕР. │ ПЕРЕМ.  │  НАСТ.  │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ КОМАНДИ │ ВИДАЛИТИ│  ГРАТИ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. Назад   | 2. Копія | 3. Перейм.
2. Попер.  | 5. Перем.| 6. Наст.
3. Команди | 8. Видал.| 9. Грати

> 💡 **Увімкнути накладання:** Налаштування → Відтворення → "Завжди показувати зони натискання"

---

## Крок 4: Швидке сортування (2 хвилини)

**Налаштування папок Quick Sort:**

1. Перейдіть в **Налаштування** → вкладка **Quick Sort**
2. Натисніть **"Додати до Quick Sort"**
3. Виберіть папки, куди хочете сортувати файли (наприклад, "Кращі фото", "Відпустка")
4. **Кожна папка отримує номер** (0-9) та колір

**Тепер ви можете сортувати миттєво:**

1. Під час перегляду фото, **натисніть лівий нижній кут** (зона COPY)
2. **АБО натисніть кнопку "1"** на панелі команд
3. Файл скопійовано у вашу папку Quick Sort #1!

## Крок 5: Просунуті функції (Опціонально)

### Мережевий диск (SMB / SFTP / FTP)

Налаштування → Додати папку → **SMB** або **SFTP / FTP**

- **SMB:** Використовуйте **"Сканувати мережу"** для автоматичного виявлення вашого NAS та мережевих пристроїв. Додаток просканує локальну мережу та покаже доступні SMB-ресурси.
- **SFTP/FTP:** Введіть IP хоста, користувача та пароль вручну.

### Хмарне сховище

Налаштування → Додати папку → **Cloud Storage**

- Підтримує: **Google Drive**, **OneDrive**, **Dropbox**
- Натисніть "Увійти..", дайте права та виберіть папки.

### Система Вибраного

- **Натисніть іконку зірки** під час перегляду файлу
- Доступ до всіх вибраних: Головне меню → вкладка **Вибране**
- Працює у всіх папках!

### Авто-переклад

- Увімкніть в **Налаштування** → **Документи** → **Enable Translation**
- Натисніть кнопку **Перекласти** (A→文) при перегляді Фото/PDF/Тексту
- **Режим лінзи:** Увімкніть "Накладання в стилі лінзи" в налаштуваннях для перекладів у стилі Google Lens на місці

### Електронні книги EPUB

- Увімкніть в **Налаштування** → **Документи** → **Support EPUB**
- Додайте папку з .epub файлами → Файли показують значок "E"
- Навігація по розділах: Свайп ліворуч/праворуч, кнопки назад/вперед
- Зміст: Кнопка 📋 для списку розділів
- Розмір шрифту: Кнопки -A/+A (діапазон 14-32px)
- Пошук: Кнопка 🔍 для пошуку тексту
- Темна/світла тема: Автоматична адаптація до теми додатку
- Мережеві файли: Працює з SMB/SFTP/FTP/Cloud

### Фонова музика для слайд-шоу

- Додайте папку з аудіофайлами як ресурс
- Перейдіть у **Налаштування** → **Аудіо** → Увімкніть **"Фонова музика для слайд-шоу"**
- Виберіть ваш музичний ресурс зі списку
- Запустіть будь-яке слайд-шоу - музика заграє автоматично
- **Порада:** Натисніть на назву треку під час слайд-шоу, щоб переключитися на інший випадковий трек

### Перепризначення клавіш

- Налаштування → **Input** → **Keybindings** - перепризначте будь-яку дію на іншу клавішу, кнопку або введення геймпада
- 70 вбудованих прив'язок за замовчуванням; натисніть **Reset** для відновлення
- Натисніть **F1** на будь-якому екрані, щоб переглянути активні прив'язки для цієї поверхні

### Захоплення фото

- В режимі Огляду натисніть **кнопку камери** на панелі інструментів, щоб зробити знімок і зберегти його прямо у поточний ресурс - локальний або мережевий

### Автозавантаження за посиланням

- У будь-якому браузері або месенджері поділіться посиланням `http(s)` у FastMediaSorter через «Поділитися»
- Додаток завантажить медіафайл і збереже його у вибраний ресурс автоматично

### Віджети для головного екрана

FastMediaSorter v2 пропонує різноманітні віджети для головного екрана. Довге натискання на головний екран → Віджети → FastMediaSorter - там знайдете повний список. Серед них:

- **Ярлик ресурсу** - натискання миттєво відкриває потрібний ресурс
- **Продовжити читання** - запускає додаток одразу в режимі слайд-шоу

## Часті запитання

**З: Куди потрапляють видалені файли?**
В: У папку `.trash/` у тому ж місці. Використовуйте "Очистити Кошик" для повного видалення.

**З: Чи можна скасувати переміщення?**
В: Так! Натисніть кнопку "Скасувати" (або праву нижню зону) протягом 5 секунд.

**З: Як редагувати фото?**
В: Відкрийте фото → Кнопка "Редагувати" → Поворот, віддзеркалення, фільтри, яскравість.
