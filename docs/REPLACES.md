# What FastMediaSorter Replaces

*Last updated: 2026-10-09*

FastMediaSorter is a complete shell for an Android device - device shell, media player, live streams, app launching, a replacement for stock apps, a companion on the watch, device monitoring and a full file manager in one app. That one app covers what normally takes a dozen separate tools.

## Home Screen & Apps
- **Launcher** (stock launcher) - the app becomes the home screen: a desktop of gadgets and widgets, a taskbar along the edge you prefer, weather, clock and sensor cells, and a desktop that locks itself. *(Standard / noLegal)*
- **App drawer & quick launch** - every installed app on one screen, app shortcuts on a long press, and a quick-launch panel that mixes apps, tools, streams and resources. *(Standard / noLegal)*

## Viewing & Playback
- **Video player** - video, Blu-ray TS/.m2ts, picture-in-picture, frame screenshots, Chromecast casting; brightness and volume gestures, a configurable 9-zone tap grid, and auto-fullscreen on rotate to landscape.
- **Audio player** - background playback, lyrics, MIDI, sleep timer, visualizations, notification controls.
- **Internet radio / IPTV player** - add any http/https radio URL, import an .m3u playlist or a curated station catalog; inline audio playback with ICY now-playing metadata; HLS/DASH VOD and RTSP video streams; a dedicated stream player with channel navigation and live-video casting to Chromecast; home-screen channel shortcut and a per-card actions menu; category, language and type filters with a default sort; full TV-remote and mouse navigation; auto-recovery on stream drop. *(Standard / Legacy / noLegal / VR; the Streams screen is absent from Lite and Photos)*
- **Gallery / image viewer** - images and GIFs, crop, filters, rotate; print an image and copy or move the opened file to a folder straight from the viewer.
- **PDF / EPUB reader** - books, chapter maps, themes, Read Aloud (TTS), document and text printing.
- **Slideshow / photo frame** - rotating photos with background music, plus a photo-frame widget.
- **TV media center / couch player** - D-pad, keyboard, mouse, gamepad, and TV-remote-friendly browsing and playback.
- **VR media player** - stereo SBS/OU, VR180, 360°, virtual cinema screen. *(VR edition)*

## Capture & Create
- **Camera** (stock camera) - photo and video straight to a chosen local, network, or cloud folder; a Samsung-style in-app camera with an on-screen photo/video switch.
- **Voice recorder** - voice notes plus a quick-record widget.
- **Drawing editor** - canvas, brushes, shapes, text, custom brush color and size.
- **Document / text scanner** - on-device OCR from the camera with area crop.

## Text & Utilities
- **Text / Markdown editor** - edit `.txt`/`.md` with syntax highlighting and auto-save.
- **Translator** - fully offline translation.
- **Calculator** - scientific: arithmetic, percentages, trigonometry, roots, logarithms, factorial, memory and history; keyboard input, a widget, and evaluation of expressions straight from selected text.
- **Cast to TV** - Chromecast for both video and audio.
- **Home-screen widget pack** - quick-launch and status widgets for recorder, camera OCR, scheduled tasks, now playing, and photo frame.

## Watch & Device
- **Watch media app** - the Wear OS companion browses the phone's folders, plays audio, video and live streams on the wrist, and receives files from the phone. *(Standard / noLegal with a paired Wear OS watch)*
- **Device monitor** - the app's own network connections, a full system-information report and automatic power saving, without leaving the shell. *(network monitor: Standard / noLegal)*

## File Management
- **File manager** - local, network, and cloud files in one place.
- **FTP/SFTP/SMB client** - network sources with SSH keys and host-key pinning.
- **Cloud clients** (Google Drive, Dropbox, OneDrive) - cloud drives as media sources.
- **Duplicate finder** - 3-phase Size -> Hash -> SHA-256 engine.
- **Recycle bin** - soft delete with one-tap restore.
- **Archive extractor** - ZIP extraction, including password-protected. *(basic)*
- **Download manager** - paste a link and save directly to a chosen folder.
- **Task scheduler** - scheduled file operations.

## noLegal Exclusive
- **Screenshot tool & edge gestures** - gesture screenshots of any app via an edge swipe, with post-capture actions (silent save, OCR-translate, drawing, Send to, clipboard); the same edge gestures also open the app or a quick-launch panel of OS shortcuts and app features.
- **Site media downloader** - extract and save video and media from streaming and media sites (YouTube, Vimeo, Dailymotion, DeviantArt, ArtStation, Telegram).
- **APK install from browser** - sideload apps straight from the built-in file browser, with VR-APK detection.
- **Office document viewer** - Word, spreadsheets, and presentations (doc/docx/rtf/odt, xls/xlsx/ods, ppt/pptx/odp) with printing.

*Honesty notes: the archiver is basic (ZIP extraction), not a full replacement. The VR player is VR-edition only; the noLegal exclusives are noLegal-build only.*
