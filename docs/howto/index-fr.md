## Vous ne savez pas par où commencer ?

- **Vous venez d'installer l'application ?** → Commencez par [Démarrage rapide](../QUICK_START-fr.md) - 5 minutes pour votre premier résultat
- <img src="../icons/doc/ic_info.png" alt="" width="20" height="20" style="vertical-align:text-bottom"> **Astuce au premier lancement :** sur l'écran de bienvenue, vous pouvez choisir un **profil d'appareil** qui pré-configure l'application pour des scénarios comme le cadre photo, la musique embarquée ou le cinéma maison - et vous pouvez le changer à tout moment dans **Paramètres → Général → Profil de l'appareil**. Voir [Premier lancement : choisissez votre profil d'appareil](../QUICK_START-fr.md#first-launch-choose-your-device-profile-30-seconds-).
- **Quelque chose ne fonctionne pas ?** → Voir [Dépannage](../TROUBLESHOOTING-fr.md)
- **Question technique ?** → Voir la [FAQ](../FAQ-fr.md)
- **Vous voulez d'abord vous connecter à un NAS ?** → Le [guide SMB](scenario-smb-setup-fr.md) est la base pour la sauvegarde photo, le cinéma maison et le cadre photo
