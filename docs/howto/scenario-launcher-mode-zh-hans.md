# 🖥️ 把本应用用作主屏幕

> **难度：** 入门 &bull; **版本：** Standard / noLegal

{% include lang-switcher.html doc="scenario-launcher-mode" dir="/docs/howto/" current="zh-Hans" %}

FastMediaSorter 可以用自己的桌面替换设备的主屏幕 - 您的文件夹、时钟、天气、您的应用，以及沿一侧边缘排列的任务栏。如果您用过 Windows 桌面，会感到很熟悉：图标停在您放置的位置，开始按钮会打开菜单。这被称为**启动器模式**。

**实际例子：** 厨房墙上的一台旧平板。屏幕唤醒时显示的不再是一堆应用图标网格，而是时钟、今天的天气、来自您 NAS 的照片文件夹，以及一个用来打开电台的按钮。

---

## 你需要准备什么

- 应用的 **Standard** 或 **noLegal** 版本 - 启动器模式不包含在 Lite、Photos、Legacy 或 VR 中
- 几分钟时间来按您喜欢的方式布置桌面
- 不需要其他任何东西：不需要 root，不需要额外的应用，也不需要特殊权限

---

## 第 1 步 - 开启启动器模式

1. 打开**设置 → 通用**
2. 开启**将本应用设为主屏幕**
3. Android 会要求您确认。在 Android 10 及更高版本上，只会弹出一个问题 - “允许 FastMediaSorter 作为您的主屏幕应用吗？” - 允许即可。在较旧的版本上，下一次按下 Home 键时会出现经典的选择器：选择 FastMediaSorter 并点击**始终**，或先点击**仅此一次**试用。
4. 按下 **Home** 键

> **刚安装好应用？** 有一个快捷方式：在首次欢迎页面上勾选**用作主屏幕**。设置过程不会被系统对话框打断 - Android 的确认提示会在您之后第一次打开**设置 → 通用**时出现。

---

## 第 2 步 - 看看已经拥有的内容

第一天的桌面并不是一个空网格，而是自带大约十几个实用项目：时钟、您所在地的天气、您的文件夹、一个搜索框。

| 单元格类型 | 作用 |
|-----------|--------------|
| 资源快捷方式 | 打开您添加的文件夹 - 您可以选择以浏览、幻灯片还是播放模式打开 |
| 小组件 | 带秒针的时钟（点击可设置闹钟）、天气、当前正在播放的内容、翻译器，以及其他二十多种小组件 |
| 应用快捷方式 | 启动任意已安装的应用；长按会列出该应用自身的快捷操作 |
| 联系人单元格 | 打开某人的联系人卡片、拨打电话、发送短信，或打开与其的即时通讯对话 |
| 应用小组件 | 应用为 Android 主屏幕提供的同一批小组件，只是放在了这里 |

---

## 第 3 步 - 使用任务栏和开始菜单

任务栏位于屏幕底部边缘。它包含开始按钮、您最近使用过的应用、您固定的应用，以及一个显示时钟、电池、网络和 SIM 信号的小型托盘区域。

- **想把它放在顶部？** **设置 → 通用 → 系统启动器设置 → 任务栏 → 任务栏位置**可在**底部**和**顶部**之间切换。开始菜单会跟随任务栏，当任务栏在顶部时会向下展开。
- **开始按钮**会打开菜单：打开 FastMediaSorter、您的资源、添加资源、Android 设置、应用设置、启动器设置、编辑桌面内容，以及末尾的重启、关机和**退出启动器模式**。
- **您的应用**会按小标题分组显示。点击标题可以折叠您很少打开的分组。全新的桌面会把您的 Google 应用放在 **Google** 分组中，把您自己安装的应用 - 即时通讯、游戏及其他 - 放在**应用**分组中，因此同一个图标不会出现两次。长按任意应用可选择**放到桌面**和**固定到任务栏**。

---

## 第 4 步 - 把您自己的内容放到桌面上

1. 长按桌面上的一个空白方格
2. 会出现四个选项：**添加项目..**、**编辑桌面**、**壁纸**、**启动器设置**
3. 选择**添加项目..**，然后选择要放置的内容：一个应用、一项功能、您的某个文件夹、一个电台串流、一个联系人、一个系统操作、一个定时操作、一个小组件，或一个动作

新的单元格会准确出现在您长按的那个方格上。

小组件中包含**正在播放卡片** - 它会显示设备上正在播放的内容，点击一下即可跳转到对应的播放器 - 以及**翻译器**单元格。

---

## 第 5 步 - 重新排列布局

**编辑桌面**会开启编辑模式，与开始菜单中的**编辑桌面内容**相同。在编辑模式下：

- 拖动单元格即可移动它
- 拖动小组件角上的手柄即可调整大小
- 点击 **+** 可以添加内容
- 对某个单元格选择**从桌面移除**即可将其去掉
- 完成后点击**完成**

> **和别人共用设备？** 在启动器设置中开启**锁定桌面**。开启后长按将不会有任何反应，布局也就不会被意外碰乱。

> **竖屏和横屏是两个独立的桌面。** 竖着排布的内容，把设备转成横向后并不会保留 - 每个方向都有自己独立的布局和折叠状态。设置本身（任务栏位置、密度、壁纸）则是两个方向共用的。

**想在屏幕上放更多或更少的单元格？** **设置 → 通用 → 系统启动器设置 → 桌面 → 网格密度**提供**稀疏**、**标准**、**紧凑**和**极紧凑**选项。

**想让壁纸透出来？** **设置 → 通用 → 系统启动器设置 → 桌面 → 小组件背景不透明度**用于设置小组件单元格静止时的实体感 - 从完全透明（壁纸可以直接透过）到不透明卡片。编辑模式下始终显示完整的卡片，方便您在整理布局时抓取单元格。

---

## 第 6 步 - 返回旧的主屏幕

以下三种方式任选其一：

- 打开开始菜单，选择**退出启动器模式**，然后确认
- 在**设置 → 通用**中关闭**将本应用设为主屏幕**
- 直接进入 Android 自身的主屏幕应用列表：**设置 → 通用 → 系统启动器设置 → 系统 → 更改主屏幕**

无论用哪种方式，您的桌面布局都会被保留，因此再次开启启动器模式时会完全恢复到您离开时的样子。

---

## 小贴士

> **墙面平板或车机？** 把启动器模式与**设置 → 管理**中的**防止休眠**搭配使用，这样设备接通充电器时桌面会一直保持显示。

> **整天开着？** **设置 → 通用 → 系统启动器设置 → 桌面 → 屏幕超时**用于设置无人操作时桌面等待的时长。它不会立即变黑：先是缓慢变暗，然后才熄屏 - 这是应用自身的黑色遮罩，而不是设备真正关闭，因此任何一次触摸都能让桌面立即恢复。设为**关闭（永不）**可以让桌面始终保持点亮。

> **正在充电？** 紧接下方的一行**充电时的屏幕超时**，会在有线或无线充电器连接期间取代上面那一项生效。它默认设置为**关闭（永不）**，因此设备接上底座后无需改动上面那一项，桌面也会一直保持点亮。

> **想看完整参考？** 每一个选项、表格和边缘情况都记录在用户手册的[把本应用用作主屏幕](../HOW_TO-zh-hans.md#how-to-use-the-app-as-your-home-screen)一节中。本指南只介绍如何开启及最初的几步；其余内容请参见该节。

> **其他应用同样可以在这里放置自己的快捷方式**，与在任何其他主屏幕上一样。

## 疑难解答

| 问题 | 解决方法 |
|---------|------------|
| **设置 → 通用**中没有**将本应用设为主屏幕** | 您的版本不包含启动器模式。该功能仅存在于 **Standard** 和 **noLegal** 中 - 请在**设置 → 通用 → 关于系统**中查看您所使用的版本 |
| 重启后设备又回到了自己的主屏幕 | 一些改装的车载收音机和内置的 Android 盒子，每次启动都会强制恢复出厂主屏幕。这是设备固件在覆盖您的选择，任何应用都无法绕过它 - 重启后再次选择 FastMediaSorter；如果仍然无法保持，说明该设备不允许这样做 |
| Android 从未询问要使用哪个主屏幕应用 | 按一次 **Home** 键 - 在较旧的 Android 版本上，选择器会在此时出现，而不是在您切换开关的那一刻 |
| 开启后桌面看起来是空的 | 请按 **Home** 键，而不是停留在应用内部 - 预填充好的桌面才是 Android 显示为主屏幕的内容 |
| 单元格在您无意间被移动了 | 在**设置 → 通用 → 系统启动器设置**中开启**锁定桌面** |
| 旋转设备后显示的布局不同 | 这是正常现象 - 竖屏和横屏保留各自独立的布局。请分别整理您使用的方向，或两者都整理 |
