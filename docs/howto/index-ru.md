## Все руководства

| Руководство | Что вы получите | Время | Версия |
|-------------|----------------|-------|--------|
| [🖼️ Цифровая фоторамка на планшете](scenario-photo-frame-ru.md) | Планшет на подставке показывает ваши фото с NAS или облака - круглосуточно, с музыкой | ~15 мин | Standard / Любая |
| [🚗 Музыка в автомобиле](scenario-car-music-ru.md) | Android-магнитола воспроизводит всю коллекцию, управление кнопками руля | ~10 мин | Standard / Legacy |
| [🍿 Домашний кинотеатр и VR](scenario-home-cinema-ru.md) | Смотрите сериалы с ПК прямо на телефоне или VR-шлеме - без USB, без копирования | ~15 мин | Standard / Legacy |
| [🧹 Порядок в загрузках (Quick Sort)](scenario-download-organizer-ru.md) | Раскладывайте файлы по папкам одним касанием - настроить раз, использовать каждый день | ~10 мин | Любая |
| [📷 Автобэкап фото на ПК по расписанию](scenario-camera-backup-ru.md) | Автоматическое ночное копирование фото по Wi-Fi - включается, копирует, засыпает само | ~15 мин | Standard |
| [🖥️ Подключение к NAS / Windows (SMB)](scenario-smb-setup-ru.md) | Пошаговое подключение SMB с объяснением каждого поля простым языком | ~10 мин | Все версии |
| [📱 Умные виджеты домашнего экрана](../HOW_TO_RU.md#умные-виджеты-домашнего-экрана) | Добавляйте виджеты на экран для записи аудио, запуска задач или показа случайных фото | ~5 мин | Standard / Legacy / VR |
| [🕶️ Иммерсивный кинотеатр OpenXR VR](../HOW_TO_RU.md#иммерсивный-кинотеатр-openxr-vr) | Смотрите 3D/360° медиафайлы и плоские видео на огромном виртуальном экране в VR | ~10 мин | Только VR |
| [🧮 Быстрые вычисления из текста и OCR](../HOW_TO_RU.md#быстрые-вычисления-из-текста-и-ocr) | Выделяйте формулы и числа в PDF или результатах распознавания текста для быстрого расчёта | ~5 мин | Standard / Legacy / VR |
| [📝 Облачные заметки Markdown и код](../HOW_TO_RU.md#облачные-заметки-markdown-и-код) | Создавайте и редактируйте текстовые заметки и файлы кода прямо на сетевых и облачных дисках | ~10 мин | Standard / Любая локально |

## Не знаете, с чего начать?

- **Только установили приложение?** → [Быстрый старт](../QUICK_START_RU.md) - 5 минут до первого результата
- 🧭 **Совет на первый запуск:** на экране приветствия можно выбрать **профиль устройства**, который заранее настроит приложение под сценарии вроде Фоторамки, Музыки в авто или Домашнего кинотеатра - изменить можно в любой момент в Настройках → Интерфейс. См. [Первый запуск: выберите профиль устройства](../QUICK_START_RU.md#первый-запуск-выберите-профиль-устройства-30-секунд-).
- **Что-то не работает?** → [Решение проблем](../TROUBLESHOOTING_RU.md)
- **Технический вопрос?** → [FAQ](../FAQ_RU.md)
- **Хотите подключиться к NAS?** → [Руководство по SMB](scenario-smb-setup-ru.md) - это основа для Автобэкапа, Кинотеатра и Фоторамки
