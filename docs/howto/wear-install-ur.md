# <img src="../icons/doc/ic_watch.png" alt="" width="20" height="20" style="vertical-align:text-bottom"> اپنی واچ پر FastMedia انسٹال کریں

> **سطح:** ابتدائی &bull; **وقت:** ~5 منٹ &bull; **ڈیوائس:** Android فون کے ساتھ پیئرڈ Wear OS اسمارٹ واچ

> **دو ورژنز۔** Google Play کا ورژن ایک چھوٹا پہلا ریلیز ہے: Calculator، Stopwatch، Mini-game، Settings اور Programs ٹائل۔ میوزک، تصاویر، نیٹ ورک شیئرز اور فون کی خصوصیات صرف مکمل ورژن میں ہیں، [Downloads](../DOWNLOADS.md) سے براہ راست APK ڈاؤن لوڈ۔

{% include lang-switcher.html doc="wear-install" dir="/docs/howto/" current="ur" %}

FastMedia Wear، FastMediaSorter کا واچ والا حصہ ہے۔ ایک بار یہ آپ کی کلائی پر ہو تو آپ سیدھا واچ سے میوزک چلا سکتے ہیں اور تصاویر دیکھ سکتے ہیں، اپنے پیئرڈ فون کے شیئر کردہ فولڈرز تک پہنچ سکتے ہیں، اور نیٹ ورک شیئرز کھول سکتے ہیں جن سے واچ خود جڑتی ہے۔ یہ صفحہ اسے انسٹال اور پیئر کرواتا ہے۔

---

## آپ کو کیا درکار ہوگا

- **Wear OS 3.0** یا نئے پر چلنے والی ایک اسمارٹ واچ
- FastMediaSorter انسٹال کردہ ایک Android فون، اور واچ سسٹم ترتیبات میں پہلے سے اس سے پیئرڈ
- ڈاؤن لوڈ کے لیے واچ پر، یا جس فون سے یہ پیئرڈ ہے اس پر، Wi-Fi یا موبائل کنکشن

---

## مرحلہ 1 - واچ پر FastMedia Wear انسٹال کریں

1. واچ پر، ایپس کی لسٹ کھولیں اور **Play Store** پر ٹیپ کریں۔
2. **FastMedia Wear** تلاش کریں۔
3. **Install** پر ٹیپ کریں اور ڈاؤن لوڈ مکمل ہونے کا انتظار کریں۔ مکمل ہونے پر واچ اپنی ایپس کی لسٹ میں ایپ دکھائے گی۔

> واچز آپ کو کلائی پر کتنا ٹائپ کرنے دیتی ہیں اس میں مختلف ہوتی ہیں۔ اگر کلائی پر تلاش کرنا مشکل ہے، تو اپنے فون پر Play Store کھولیں، FastMedia Wear تلاش کریں، اور اپنی واچ کو انسٹال ٹارگٹ کے طور پر منتخب کریں - واچ خود اسے ڈاؤن لوڈ کر لیتی ہے۔

### کوئی Play Store نہیں؟ ADB کے ذریعے APK انسٹال کریں

یہ راستہ استعمال کریں جب آپ کی واچ میں Play Store تک رسائی نہ ہو۔ آپ کو Android
SDK Platform-Tools (`adb`) والے ایک کمپیوٹر اور کمپیوٹر اور واچ کے مشترکہ ایک مقامی Wi-Fi نیٹ ورک کی ضرورت ہے۔ یہ
صرف انٹرنیٹ کے ذریعے کام نہیں کرتا۔

1. [Direct APK Release](../DOWNLOADS.md) صفحے سے ایک APK ڈاؤن لوڈ کریں:
   - `FastMediaSorter_wear_debug.apk` جانچ کے لیے ڈیبگ بلڈ ہے۔ یہ
     `com.sza.fastmediasorter.debug` کے طور پر انسٹال ہوتی ہے۔
   - `FastMediaSorter_wear_release.apk` سائن شدہ نان-ڈیبگ بلڈ ہے۔ یہ
     `com.sza.fastmediasorter` کے طور پر انسٹال ہوتی ہے۔
   - دونوں بلڈز کے پیکیج نام مختلف ہیں، تو وہ ساتھ ساتھ انسٹال رہ سکتی ہیں۔ ADB کے ساتھ
     Play Store کی `.aab` فائل انسٹال کرنے کی کوشش نہ کریں۔
2. واچ پر، ڈیویلپر موڈ فعال کریں: **Settings** → **About watch** → **Build number** پر سات
   بار ٹیپ کریں۔ **Developer options** میں، **ADB debugging** اور **Wireless debugging** فعال کریں۔
3. **Wireless debugging** میں، **Pair new device** منتخب کریں۔ کمپیوٹر پر، واچ کی دکھائی گئی پیئرنگ ایڈریس
   اور کوڈ درج کریں، پھر مین Wireless debugging اسکرین سے الگ کنکشن پورٹ کے ساتھ جوڑیں:

   ```powershell
   adb pair <watch-ip>:<pairing-port> <six-digit-code>
   adb connect <watch-ip>:<connection-port>
   adb devices
   ```

   واچ پر ڈیبگنگ کا اشارہ قبول کریں۔ پیئرنگ اور کنکشن پورٹس مختلف ہیں۔
4. APK انسٹال یا اپ ڈیٹ کریں۔ آپ نے جو فائل ڈاؤن لوڈ کی اس کے مطابق کمانڈ استعمال کریں:

   ```powershell
   adb -s <watch-ip>:<connection-port> install -r ".\FastMediaSorter_wear_debug.apk"
   adb -s <watch-ip>:<connection-port> install -r ".\FastMediaSorter_wear_release.apk"
   ```

   `-r` اسی پیکیج کو اپ ڈیٹ کرتا ہے جبکہ اس کا ایپ ڈیٹا برقرار رکھتا ہے۔ یہ ایک ڈیبگ بلڈ کو
   ریلیز بلڈ میں تبدیل نہیں کرتا، کیونکہ یہ الگ ایپس ہیں۔
5. واچ ایپ لسٹ سے **FastMedia Wear** کھولیں۔ اگر ضرورت ہو تو اسے ADB سے شروع کریں:

   ```powershell
   adb -s <watch-ip>:<connection-port> shell am start -n com.sza.fastmediasorter.debug/com.sza.fastmediasorter.wear.MainActivity
   adb -s <watch-ip>:<connection-port> shell am start -n com.sza.fastmediasorter/com.sza.fastmediasorter.wear.MainActivity
   ```

> اس طریقے کے لیے ایک Wear OS واچ درکار ہے۔ Galaxy Watch 3، Galaxy Watch Active اور Active 2 Tizen
> چلاتی ہیں اور Wear OS APKs انسٹال نہیں کر سکتیں۔ مکمل ہونے پر، اگر آپ کو اسے کسی
> دوسری اپ ڈیٹ کے لیے درکار نہ ہو تو Wireless debugging بند کر دیں۔

## مرحلہ 2 - فون پر Wear کمپینین آن کریں

فون کا حصہ اس وقت تک بند رہتا ہے جب تک آپ نہ بتائیں کہ آپ کے پاس واچ ہے۔

1. فون پر FastMediaSorter کھولیں۔
2. **Settings** پر جائیں اور **Management** ٹیب کھولیں۔
3. **Wear OS** گروپ تلاش کریں اور اسے پھیلائیں۔
4. **Wear companion** چیک باکس آن کریں۔

چیک باکس پورے کمپینین کو آن کرتا ہے: اس کی ونڈو کھولنے والا بٹن بالکل نیچے ظاہر ہوتا ہے، پروگرامز لسٹ میں ایک اندراج شامل ہوتا ہے، اور یہ ایک پینل ٹائل اور لانچر شارٹ کٹ کے طور پر دستیاب ہو جاتا ہے۔

> واچ بریج کے بغیر بلڈز یہ گروپ بالکل نہیں دکھاتیں۔ اگر آپ کو یہ نہیں ملتا، تو آپ ایک ایسا فلیور چلا رہے ہیں جو Wear سپورٹ کے بغیر شپ ہوتا ہے۔

---

## مرحلہ 3 - طے کریں کہ واچ پر کیا جائے گا

1. اسی گروپ میں، **Wear companion** پر ٹیپ کریں۔ اس کی ونڈو ایپ کے اوپر کھلتی ہے۔
2. وہ ریسورسز منتخب کریں جو آپ چاہتے ہیں کہ واچ دیکھے۔ جب تک آپ منتخب نہ کریں کچھ نہیں بھیجا جاتا - ایک خالی انتخاب آپ کی پوری لائبریری بھیجنے کی بجائے کچھ نہیں بھیجتا۔
3. یہاں واچ کی اپنی ترجیحات بھی ایڈجسٹ کریں: ویو موڈ، keep-awake رویہ اور واچ ہوم اسکرین پر دکھائے جانے والے سیکشنز۔

---

## مرحلہ 4 - چیک کریں کہ دونوں حصے ایک دوسرے کو دیکھتے ہیں

1. واچ پر **FastMedia Wear** کھولیں۔
2. ہوم اسکرین اپنے سیکشنز درج کرتی ہے - **Phone**، **Local**، **Resources**، **Streams** اور **Apps**۔
3. **Phone** پر ٹیپ کریں۔ مرحلہ 3 میں منتخب کیے گئے فولڈرز ظاہر ہوتے ہیں۔

اگر Phone سیکشن خالی ہے، تو فون پر کمپینین ونڈو پر واپس جائیں اور تصدیق کریں کہ کم از کم ایک ریسورس منتخب ہے۔

> **تجویز:** آپ اپنی واچ پر کسی بھی اسکرین سے واپس نیویگیٹ کر سکتے ہیں بائیں کنارے پر نظر آنے والے یونیورسل بیک افورڈنس بٹن کا استعمال کرتے ہوئے، بائیں کنارے سے سوائپ کرتے ہوئے، یا اپنی واچ کا ہارڈویئر بیک بٹن دبا کر۔ مین ہوم اسکرین پر، بیک افورڈنس ٹیپ کرنے پر ایپ چھوڑنے کے لیے ایک ایگزٹ آئیکن (باکس چھوڑتا ایک ایرو) یا بیک گراؤنڈ پلے بیک کو منیمائز کرنے کے لیے ایک ڈبل-شیورون («) دکھاتا ہے۔ ہر اس اسکرین پر جو یہ بٹن دکھاتی ہے، ایک بلیک-اسکرین بٹن (ایک تاریک اسکرین والا فون) دائیں کنارے پر اس کا سامنا کرتا ہے اور واچ اسکرین کو خالی کر دیتا ہے؛ ایک ڈبل ٹیپ، ایک پریس اینڈ ہولڈ، یا ہارڈویئر بٹن اسے واپس لے آتا ہے۔

---

## اگر کچھ کام نہ کرے

- **واچ ایپ Play Store میں ظاہر نہیں ہوتی۔** تصدیق کریں کہ واچ Wear OS 3.0 یا نیا چلاتی ہے۔ پرانی واچز ایک مختلف ایپ ماڈل استعمال کرتی ہیں اور سپورٹڈ نہیں ہیں۔
- **Wear OS گروپ فون کی ترتیبات سے غائب ہے۔** آپ جو بلڈ چلا رہے ہیں اس میں واچ بریج شامل نہیں ہے۔
- **واچ پر Phone سیکشن خالی ہے۔** کمپینین ونڈو میں کچھ منتخب نہیں ہے، یا واچ اور فون نے اپنی پیئرنگ کھو دی ہے - پہلے سسٹم ترتیبات میں پیئرنگ چیک کریں۔
- **فون کنکشن پر پلے بیک اٹکتا ہے۔** واچ اور فون کے درمیان بلوٹوتھ محدود ہے۔ طویل سننے کے لیے، فائلیں واچ پر منتقل کریں یا واچ کو براہ راست نیٹ ورک شیئر سے جوڑیں۔
