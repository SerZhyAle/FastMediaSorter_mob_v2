# <img src="../icons/doc/ic_resource_smb.png" alt="" width="20" height="20" style="vertical-align:text-bottom"> Откройте папки ПК, отсканировав один код

> **Уровень:** Начинающий &bull; **Флейворы:** Standard, Photos, Legacy, XR/noLegal (для скана нужна камера; способ с файлом работает везде)

[English](scenario-companion-share.md) | [Українська](scenario-companion-share-uk.md)

На ПК с Windows вы запускаете небольшую программу-компаньон, выбираете папки с видео, музыкой, документами или фото - и она показывает на экране код. На телефоне вы нажимаете **Добавить**, подносите камеру к этому коду, и папки ПК тут же подключены - без ввода адреса, порта, пароля, без кабелей.

> **Простыми словами:** компаньон превращает выбранные папки в приватную общую папку только для чтения в вашей домашней сети Wi-Fi и печатает код, в котором уже есть всё, что нужно телефону для доступа. Отсканировать код - это то же самое, что вручную заполнить длинную форму подключения, только телефон читает её с одного взгляда. Дальше файлы открываются по запросу и передаются по Wi-Fi; на телефон ничего не копируется, пока вы сами не попросите.

---

## Программа-компаньон

Компаньон - встроенная функция **[Fast Media Sorter for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/)** (ранее FastMediaSorter LITE), бесплатного сортировщика медиа от того же автора. Когда вы открываете ей доступ к папкам, она:

- Поднимает приватный SFTP-сервер только для этих папок на вашем ПК.
- Сама создаёт ключи и настраивает автозапуск, чтобы общая папка была доступна и в следующий раз.
- Показывает на экране **QR-код** и может сохранить небольшой файл конфигурации `.fmscfg`.

**Где взять:**

- Сайт: [serzhyale.github.io/FastMediaSorter_Lite](https://serzhyale.github.io/FastMediaSorter_Lite/)
- Публикация папок (пошагово): [Как опубликовать папки ПК для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)
- GitHub: [последний релиз](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases/latest) (установщик или портативный ZIP)
- winget: `winget install SerZhyAle.FastMediaSorter`
- Microsoft Store: поиск «FastMediaSorter LITE» (в Store программа под прежним именем)

## Что понадобится

- ПК с Windows и установленной **Fast Media Sorter for Windows**
- Телефон и ПК в **одной сети Wi-Fi** (один роутер)
- Для самого быстрого способа - **камера** телефона для скана кода (если камеры нет, есть способ с файлом)

---

## Шаг 1 - Откройте доступ к папкам на ПК

1. Установите и запустите **Fast Media Sorter for Windows**, откройте вкладку **Share** в настройках.
2. Выберите папку(и), которые нужны на телефоне - фильмы, музыку, документы, фото, что угодно.
3. Программа сама поднимет SFTP-сервер, создаст ключи и настроит автозапуск. Больше ничего настраивать не нужно.
4. Теперь она показывает на экране ПК **QR-код**. Оставьте это окно открытым для шага 2.

> Хотите файл вместо кода? Нажмите **Save .fmscfg** в том же окне и передайте файл на телефон (email, Telegram или любая общая папка). См. [Шаг 2, способ B](#шаг-2-способ-b---импорт-файла).

---

## Шаг 2, способ A - Отсканируйте код (самый быстрый)

1. Откройте FastMediaSorter и нажмите кнопку **Добавить (⊕)** на главном экране.
2. Нажмите **«Импорт по штрихкоду»** - она рядом с четырьмя карточками типов ресурса (Локальная, SMB, SFTP/FTP, Облако) и в шапке формы SFTP.
3. Откроется камера с подсказкой *«Наведите камеру на QR-код компаньона»*. Поднесите телефон к QR-коду на ПК. В тёмной комнате нажмите **Фонарик**.
4. Появится подтверждение - *«Импорт доступа - Добавить SFTP-ресурс .. с N папкой(ами)?»*. Нажмите **Импорт**.
5. Готово. Для каждой общей папки появится отдельный ресурс только для чтения, ключ сервера будет закреплён автоматически.

> Пункт **«Импорт по штрихкоду»** скрыт на устройствах без камеры и на VR-гарнитурах - там используйте способ B.

## Шаг 2, способ B - Импорт файла

Используйте, когда у телефона нет камеры или ПК и телефон не рядом.

1. На ПК нажмите **Save .fmscfg** и доставьте файл на телефон (email, Telegram, облако или общая папка).
2. **Если файл уже на телефоне:** нажмите **Добавить (⊕)** -> **«SFTP / FTP»** -> **«Импорт из файла»** и выберите файл `.fmscfg`.
3. **Если пришёл вложением** (Telegram или email): просто нажмите на вложение `.fmscfg` - приложение сразу откроет диалог подтверждения.
4. Подтвердите тот же диалог *«Импорт доступа»* и нажмите **Импорт**. Появятся ресурсы только для чтения.

> **Обращайтесь с кодом и файлом как с ключом.** В оба зашит пароль доступа, чтобы телефон подключался без единого ввода. Не публикуйте скриншот QR-кода и файл `.fmscfg`.

## Готово! Теперь вы можете..

Общие папки ведут себя как любой другой ресурс в приложении. Например:

- **Смотреть фильмы и сериалы** с ПК на телефоне, планшете или Android TV-приставке - потоком, без копирования. См. [Домашний кинотеатр и VR-стриминг](scenario-home-cinema-ru.md).
- **Слушать свою музыку** в дороге или на автомагнитоле.
- **Читать PDF и EPUB** с ПК, сохраняя последнюю позицию.
- **Просматривать фотоархив** и сортировать его через Quick Sort или показывать как [цифровую фоторамку](scenario-photo-frame-ru.md).
- **Передать файл в специализированное приложение** - откройте лист Info у сетевого файла и нажмите «Скачать и открыть».
- **Копировать или перемещать файлы** между ПК и телефоном в любую сторону.

## Как это работает (под капотом)

- Программа-компаньон на Windows поднимает лёгкий **SFTP-сервер**, привязанный к выбранным папкам, только в вашей локальной сети.
- QR-код (или файл `.fmscfg`) кодирует подключение: хост, порт, учётные данные, пути общих папок и отпечаток ключа сервера. Плотные наборы папок передаются в сжатом виде, поэтому даже много папок помещается в один код.
- Телефон читает эти данные, проверяет их и создаёт **по одному ресурсу SFTP только для чтения на каждую папку**. Ключ сервера закрепляется при первом подключении (TOFU), так что телефон предупредит, если ПК когда-нибудь подменят.
- Поскольку это ваша локальная сеть Wi-Fi и доступ только для чтения, телефон просматривает и передаёт файлы, ничего не меняя на ПК.

## Устранение неполадок

| Проблема | Что попробовать |
|----------|-----------------|
| Нет пункта «Импорт по штрихкоду» | У устройства нет камеры или это VR-сборка. Используйте [способ B - Импорт файла](#шаг-2-способ-b---импорт-файла) |
| Пишет, что нужен доступ к камере | Дайте разрешение на камеру по запросу - оно нужно только для скана |
| «Это не корректная конфигурация компаньона» | Код или файл не из компаньона Windows. Экспортируйте заново со вкладки **Share** |
| «Создано более новой версией компаньона» | Обновите FastMediaSorter на телефоне или экспортируйте из совместимой версии компаньона |
| Ресурс добавлен, но папки пустые | Убедитесь, что компаньон на ПК всё ещё запущен, а телефон в **той же сети Wi-Fi** (не в мобильных данных) |
| Работает по Wi-Fi, но не по мобильным данным | Так и должно быть - общая папка живёт только в локальной сети |
