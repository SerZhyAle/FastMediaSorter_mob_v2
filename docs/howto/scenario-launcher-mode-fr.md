# 🖥️ Utiliser l'application comme écran d'accueil

> **Niveau :** Débutant &bull; **Édition :** Standard / noLegal

{% include lang-switcher.html doc="scenario-launcher-mode" dir="/docs/howto/" current="fr" %}

FastMediaSorter peut remplacer l'écran d'accueil de votre appareil par son propre bureau - vos dossiers, une horloge, la météo, vos applications, et une barre des tâches le long d'un bord. Si vous avez déjà utilisé un bureau Windows, cela vous semblera familier : les choses restent là où vous les mettez, et un bouton Démarrer ouvre le menu. C'est ce qu'on appelle le **mode launcher**.

**Exemple concret :** une ancienne tablette accrochée au mur de la cuisine. Au lieu d'une grille d'icônes d'applications, vous obtenez l'horloge, la météo du jour, le dossier photo de votre NAS et un bouton qui démarre la radio - tout cela sur l'écran qu'elle affiche à son réveil.

---

## Ce dont vous aurez besoin

- La version **Standard** ou **noLegal** de l'application - le mode launcher n'est pas dans Lite, Photos, Legacy ou VR
- Quelques minutes pour organiser le bureau comme vous le souhaitez
- Rien d'autre : pas de root, pas d'application supplémentaire, pas d'autorisation spéciale

---

## Étape 1 - Activer le mode launcher

1. Ouvrez **Paramètres → Général**
2. Activez **Faire de cette application l'écran d'accueil**
3. Android vous demande de confirmer. Sur Android 10 et plus récent, c'est une seule question - "Autoriser FastMediaSorter à être votre application d'accueil ?" - donc autorisez-la. Sur les versions plus anciennes, le sélecteur classique apparaît la prochaine fois que vous appuyez sur Accueil : choisissez FastMediaSorter et appuyez sur **Toujours**, ou **Une seule fois** pour l'essayer d'abord.
4. Appuyez sur **Accueil**

> **Vous venez d'installer l'application ?** Il existe un raccourci : cochez **Utiliser comme écran d'accueil** sur la première page de bienvenue. La configuration n'est pas interrompue par une boîte de dialogue système - la confirmation d'Android apparaît la première fois que vous ouvrez **Paramètres → Général** par la suite.

---

## Étape 2 - Regarder ce que vous avez déjà

Le bureau n'est pas une grille vide au premier jour. Il arrive avec une douzaine d'éléments utiles : une horloge, la météo de votre lieu, vos dossiers, une barre de recherche.

| Type de cellule | Ce qu'elle fait |
|-----------|--------------|
| Raccourci de ressource | Ouvre un dossier que vous avez ajouté - et vous choisissez s'il s'ouvre en mode navigation, diaporama ou lecture |
| Gadget | Une horloge avec secondes (appuyez dessus pour les alarmes), la météo, ce qui joue actuellement, un traducteur, et deux douzaines d'autres |
| Raccourci d'application | Démarre n'importe quelle application installée ; l'appui long liste les actions rapides propres à cette application |
| Cellule de contact | Ouvre la fiche d'une personne, l'appelle, envoie un SMS, ou ouvre sa conversation dans la messagerie |
| Widget d'application | Les mêmes widgets que l'application propose pour l'écran d'accueil Android, placés ici à la place |

---

## Étape 3 - Utiliser la barre des tâches et le menu Démarrer

La barre des tâches se trouve le long du bord inférieur. Elle contient le bouton Démarrer, les applications récemment utilisées, celles que vous avez épinglées, et une petite zone avec l'horloge, la batterie, le réseau et le signal SIM.

- **Vous la préférez en haut ?** **Paramètres → Général → Paramètres du launcher système → Barre des tâches → Position de la barre des tâches** bascule entre **Bas** et **Haut**. Le menu Démarrer suit la barre et se déploie depuis le haut quand la barre est en haut.
- **Le bouton Démarrer** ouvre le menu : ouvrir FastMediaSorter, vos ressources, ajouter une ressource, les paramètres Android, les paramètres de l'application, les paramètres du launcher, modifier le contenu du bureau, et à la fin redémarrer, éteindre et **Quitter le mode launcher**.
- **Vos applications** sont regroupées en sections avec de petits en-têtes. Appuyez sur un en-tête pour réduire une section que vous ouvrez rarement. Un bureau tout neuf place vos applications Google dans une section **Google** et vos propres applications installées - messageries, jeux et le reste - dans une section **Applications**, afin que la même icône n'apparaisse jamais deux fois. Appuyez longuement sur n'importe quelle application pour **Mettre sur le bureau** et **Épingler à la barre des tâches**.

---

## Étape 4 - Mettre vos propres éléments sur le bureau

1. Appuyez longuement sur un carré vide du bureau
2. Quatre choix apparaissent : **Ajouter un élément..**, **Modifier le bureau**, **Fond d'écran**, **Paramètres du launcher**
3. Choisissez **Ajouter un élément..** et sélectionnez ce qui va là : une application, une fonctionnalité, l'un de vos dossiers, un flux radio, une personne, une action système, une opération programmée, un gadget, ou une action

La nouvelle cellule se place exactement sur le carré sur lequel vous avez appuyé.

Parmi les gadgets se trouvent la **carte de lecture en cours** - elle affiche ce qui joue sur l'appareil et vous amène à ce lecteur en un geste - et la cellule **traducteur**.

---

## Étape 5 - Le réorganiser

**Modifier le bureau** active le mode édition, la même chose que **Modifier le contenu du bureau** dans le menu Démarrer. Pendant l'édition :

- Faites glisser une cellule pour la déplacer
- Faites glisser la poignée d'angle d'un gadget pour le redimensionner
- Appuyez sur **+** pour ajouter quelque chose
- Choisissez **Retirer du bureau** sur une cellule pour l'enlever
- Appuyez sur **Terminé** lorsque vous avez fini

> **Vous partagez l'appareil avec quelqu'un ?** Activez **Verrouiller le bureau** dans les paramètres du launcher. L'appui long ne fait alors plus rien, donc la disposition ne peut pas être déplacée par accident.

> **Le portrait et le paysage sont deux bureaux séparés.** Ce que vous organisez à la verticale n'est pas ce que vous obtenez quand vous tournez l'appareil sur le côté - chaque orientation garde sa propre disposition et ses propres sections réduites. Les paramètres eux-mêmes (position de la barre des tâches, densité, fond d'écran) sont partagés par les deux.

**Vous voulez plus, ou moins, de cellules à l'écran ?** **Paramètres → Général → Paramètres du launcher système → Bureau → Densité de la grille** propose **Clairsemée**, **Standard**, **Dense** et **Très dense**.

**Vous voulez que le fond d'écran transparaisse ?** **Paramètres → Général → Paramètres du launcher système → Bureau → Opacité du fond des gadgets** définit à quel point une cellule de gadget paraît solide au repos - d'entièrement transparente, laissant le fond d'écran transparaître directement, à une carte opaque. Le mode édition dessine toujours la carte complète, afin qu'une cellule reste facile à saisir pendant que vous organisez.

---

## Étape 6 - Revenir à votre ancien écran d'accueil

N'importe laquelle de ces trois méthodes fonctionne :

- Ouvrez le menu Démarrer et choisissez **Quitter le mode launcher**, puis confirmez
- Désactivez **Faire de cette application l'écran d'accueil** dans **Paramètres → Général**
- Allez directement à la propre liste d'Android des applications d'accueil : **Paramètres → Général → Paramètres du launcher système → Système → Changer l'écran d'accueil**

La disposition de votre bureau est conservée dans tous les cas, donc réactiver le mode launcher le ramène exactement tel que vous l'avez laissé.

---

## Astuces

> **Tablette murale ou autoradio ?** Associez le mode launcher avec **Empêcher la mise en veille** dans **Paramètres → Gestion** afin que le bureau reste visible tant que l'appareil est sur un chargeur.

> **Allumé toute la journée ?** **Paramètres → Général → Paramètres du launcher système → Bureau → Délai d'expiration de l'écran** définit combien de temps le bureau attend pendant que personne ne le touche. Il ne s'éteint pas d'un coup : d'abord vient un assombrissement progressif, puis l'extinction complète - une superposition noire propre à l'application plutôt que l'appareil qui s'éteint lui-même, donc n'importe quel toucher ramène immédiatement le bureau. Réglez sur **Désactivé (jamais)** pour garder le bureau allumé.

> **Sur un chargeur ?** La ligne juste en dessous, **Délai d'expiration de l'écran en charge**, s'applique à la place tant qu'un chargeur filaire ou sans fil est connecté. Elle est livrée sur **Désactivé (jamais)**, donc un appareil sur socle garde le bureau allumé sans toucher à la ligne au-dessus.

> **Vous voulez la référence complète ?** Chaque option, tableau et cas particulier se trouve dans la section [Utiliser l'application comme écran d'accueil](../HOW_TO-fr.md#how-to-use-the-app-as-your-home-screen) du manuel utilisateur. Ce guide couvre l'activation et les premiers pas ; cette section couvre le reste.

> **D'autres applications peuvent placer leurs propres raccourcis ici**, exactement comme elles le feraient sur n'importe quel autre écran d'accueil.

## Dépannage

| Problème | Que faire |
|---------|------------|
| **Faire de cette application l'écran d'accueil** est absent de Paramètres → Général | Votre version n'inclut pas le mode launcher. Il n'est disponible que dans **Standard** et **noLegal** - vérifiez **Paramètres → Général → À propos du système** pour connaître votre édition |
| L'appareil revient à son propre écran d'accueil après un redémarrage | Certains autoradios non constructeur et boîtiers Android intégrés réimposent leur écran d'accueil d'usine à chaque démarrage. C'est le firmware de l'appareil qui vous contourne, et aucune application ne peut y remédier - resélectionnez FastMediaSorter après le redémarrage, et si cela ne tient toujours pas, cet appareil ne le permet pas |
| Android n'a jamais demandé quelle application d'accueil utiliser | Appuyez une fois sur **Accueil** - sur les anciennes versions d'Android, le sélecteur apparaît à ce moment-là, pas au moment où vous activez le paramètre |
| Le bureau paraît vide après l'avoir activé | Appuyez sur **Accueil** plutôt que de rester dans l'application - le bureau pré-rempli est ce qu'Android affiche comme écran d'accueil |
| Les cellules bougent alors que vous ne le vouliez pas | Activez **Verrouiller le bureau** dans **Paramètres → Général → Paramètres du launcher système** |
| Tourner l'appareil affiche une disposition différente | Attendu - le portrait et le paysage gardent des dispositions séparées. Organisez celle que vous utilisez, ou organisez les deux |
