# 🖥️ ایپ کو اپنی ہوم اسکرین کے طور پر استعمال کریں

> **سطح:** ابتدائی &bull; **فلیور:** Standard / noLegal

{% include lang-switcher.html doc="scenario-launcher-mode" dir="/docs/howto/" current="ur" %}

FastMediaSorter آپ کی ڈیوائس کی ہوم اسکرین کو اپنے خود کے ڈیسک ٹاپ سے بدل سکتا ہے - آپ کے فولڈرز، ایک گھڑی، موسم، آپ کی ایپس، اور ایک کنارے پر ایک ٹاسک بار۔ اگر آپ نے کبھی Windows ڈیسک ٹاپ استعمال کیا ہے تو یہ جانا پہچانا محسوس ہوگا: چیزیں وہیں رہتی ہیں جہاں آپ نے انہیں رکھا، اور ایک Start بٹن مینو کھولتا ہے۔ اسے **لانچر موڈ** کہا جاتا ہے۔

**حقیقی مثال:** باورچی خانے کی دیوار پر ایک پرانا ٹیبلٹ۔ ایپ آئیکنز کے گرڈ کی بجائے آپ کو گھڑی، آج کا موسم، آپ کے NAS سے فوٹو فولڈر اور ایک بٹن ملتا ہے جو ریڈیو شروع کرتا ہے - یہ سب اس اسکرین پر جو یہ جاگنے پر دکھاتا ہے۔

---

## آپ کو کیا درکار ہوگا

- ایپ کا **Standard** یا **noLegal** بلڈ - لانچر موڈ Lite، Photos، Legacy یا VR میں نہیں ہے
- ڈیسک ٹاپ کو اپنی پسند کے مطابق ترتیب دینے کے لیے چند منٹ
- اور کچھ نہیں: نہ root، نہ اضافی ایپ، نہ کوئی خاص اجازت

---

## مرحلہ 1 - لانچر موڈ آن کریں

1. **ترتیبات → عمومی** کھولیں
2. **Make this app the home screen** آن کریں
3. Android آپ سے تصدیق کرنے کو کہتا ہے۔ Android 10 اور نئے پر یہ ایک ہی سوال ہے - "Allow FastMediaSorter to be your Home app?" - تو اسے اجازت دیں۔ پرانے ورژنز پر اگلی بار جب آپ Home دبائیں گے تو کلاسک چوزر ظاہر ہوگا: FastMediaSorter منتخب کریں اور **Always** پر ٹیپ کریں، یا پہلے آزمانے کے لیے **Just once** پر
4. **Home** دبائیں

> **ابھی ایپ انسٹال کی ہے؟** ایک شارٹ کٹ موجود ہے: پہلے ویلکم صفحے پر **Use as home screen** ٹک کریں۔ سیٹ اپ کسی سسٹم ڈائیلاگ سے متاثر نہیں ہوتا - Android کی تصدیق پہلی بار **ترتیبات → عمومی** کھولنے پر بعد میں آتی ہے۔

---

## مرحلہ 2 - دیکھیں کہ آپ کے پاس پہلے سے کیا موجود ہے

پہلے دن ڈیسک ٹاپ ایک خالی گرڈ نہیں ہوتا۔ یہ تقریباً درجن بھر مفید چیزوں کے ساتھ آتا ہے: ایک گھڑی، آپ کے مقام کا موسم، آپ کے فولڈرز، ایک تلاش باکس۔

| سیل کی قسم | یہ کیا کرتا ہے |
|-----------|--------------|
| Resource shortcut | آپ کے شامل کردہ فولڈر کو کھولتا ہے - اور آپ چنتے ہیں کہ یہ browse، slideshow یا play موڈ میں کھلے |
| Gadget | سیکنڈز کے ساتھ ایک گھڑی (الارم کے لیے اسے ٹیپ کریں)، موسم، ابھی کیا چل رہا ہے، ایک مترجم، اور مزید دو درجن |
| App shortcut | کسی بھی انسٹال شدہ ایپ کو شروع کرتا ہے؛ لانگ پریس اس ایپ کے اپنے فوری اقدامات دکھاتا ہے |
| Contact cell | کسی شخص کا کارڈ کھولتا ہے، انہیں کال کرتا ہے، SMS بھیجتا ہے، یا ان کی میسنجر گفتگو کھولتا ہے |
| App widget | وہی ویجٹس جو ایپ Android ہوم اسکرین کے لیے پیش کرتی ہے، مگر یہاں رکھے گئے |

---

## مرحلہ 3 - ٹاسک بار اور Start مینو استعمال کریں

ٹاسک بار نچلے کنارے پر بیٹھتا ہے۔ اس میں Start بٹن، آپ کی حال ہی میں استعمال کردہ ایپس، آپ کی پن کردہ ایپس، اور گھڑی، بیٹری، نیٹ ورک اور SIM سگنل والی ایک چھوٹی ٹرے شامل ہیں۔

- **اسے اوپر رکھنا پسند کریں گے؟** **ترتیبات → عمومی → System launcher settings → Taskbar → Taskbar position** **Bottom** اور **Top** کے درمیان بدلتا ہے۔ Start مینو بار کے ساتھ چلتا ہے اور جب بار اوپر ہو تو اوپر سے نیچے کھلتا ہے۔
- **Start بٹن** مینو کھولتا ہے: FastMediaSorter کھولیں، آپ کے ریسورسز، ایک ریسورس شامل کریں، Android ترتیبات، ایپ ترتیبات، لانچر ترتیبات، ڈیسک ٹاپ کے مواد میں ترمیم کریں، اور آخر میں restart، power off اور **Exit launcher mode**۔
- **آپ کی ایپس** چھوٹے ہیڈرز کے ساتھ سیکشنز میں گروپ کی گئی ہیں۔ کسی ایسے سیکشن کو سکیڑنے کے لیے جسے آپ شاذ و نادر ہی کھولتے ہیں، اس کے ہیڈر پر ٹیپ کریں۔ ایک تازہ ڈیسک ٹاپ آپ کی Google ایپس کو **Google** سیکشن میں اور آپ کی اپنی انسٹال کردہ ایپس - میسنجرز، گیمز اور باقی سب - کو **Apps** سیکشن میں رکھتا ہے، تاکہ ایک ہی آئیکن کبھی دو بار ظاہر نہ ہو۔ کسی بھی ایپ کو لانگ پریس کریں تاکہ **Put on desktop** اور **Pin to taskbar** حاصل کریں۔

---

## مرحلہ 4 - اپنی چیزیں ڈیسک ٹاپ پر رکھیں

1. ڈیسک ٹاپ کے کسی خالی مربع کو لانگ پریس کریں
2. چار انتخاب ظاہر ہوتے ہیں: **Add an item..**، **Edit the desktop**، **Wallpaper**، **Launcher settings**
3. **Add an item..** منتخب کریں اور چنیں کہ وہاں کیا جائے گا: ایک ایپ، ایک خصوصیت، آپ کے فولڈرز میں سے ایک، ایک ریڈیو اسٹریم، کوئی شخص، ایک سسٹم ایکشن، ایک شیڈول شدہ آپریشن، ایک گیجٹ، یا ایک ایکشن

نیا سیل بالکل اسی مربع پر بیٹھتا ہے جسے آپ نے دبایا تھا۔

گیجٹس میں **now-playing card** بھی شامل ہے - یہ دکھاتا ہے کہ ڈیوائس پر ابھی کیا چل رہا ہے اور ایک ٹیپ سے آپ کو اس پلیئر تک لے جاتا ہے - اور **مترجم** سیل بھی۔

---

## مرحلہ 5 - اسے دوبارہ ترتیب دیں

**Edit the desktop** ایڈٹ موڈ آن کرتا ہے، بالکل Start مینو میں **Edit desktop contents** کی طرح۔ ایڈٹ کرتے ہوئے:

- کسی سیل کو حرکت دینے کے لیے اسے گھسیٹیں
- کسی گیجٹ کا سائز بدلنے کے لیے اس کے کونے کا ہینڈل گھسیٹیں
- کچھ شامل کرنے کے لیے **+** ٹیپ کریں
- کسی سیل کو ہٹانے کے لیے **Remove from desktop** منتخب کریں
- جب مکمل ہو جائیں تو **Done** پر ٹیپ کریں

> **ڈیوائس کسی کے ساتھ شیئر کر رہے ہیں؟** لانچر ترتیبات میں **Lock desktop** آن کریں۔ لانگ پریس پھر کچھ نہیں کرتا، تاکہ لے آؤٹ غلطی سے نہ ہل سکے۔

> **پورٹریٹ اور لینڈ اسکیپ دو الگ ڈیسک ٹاپس ہیں۔** آپ سیدھی حالت میں جو ترتیب دیتے ہیں وہ وہی نہیں ہوتی جو آپ کو ڈیوائس کو سائیڈ پر موڑنے پر ملتی ہے - ہر واقفیت اپنا خود کا لے آؤٹ اور اپنے سکڑے ہوئے سیکشنز رکھتی ہے۔ ترتیبات خود (ٹاسک بار پوزیشن، کثافت، وال پیپر) دونوں کے درمیان مشترک ہیں۔

**اسکرین پر مزید، یا کم، سیلز چاہتے ہیں؟** **ترتیبات → عمومی → System launcher settings → Desktop → Grid density** **Sparse**، **Standard**، **Dense** اور **Very dense** پیش کرتا ہے۔

**وال پیپر کو نظر آنا چاہتے ہیں؟** **ترتیبات → عمومی → System launcher settings → Desktop → Widget backdrop opacity** طے کرتا ہے کہ آرام کی حالت میں ایک گیجٹ سیل کتنا ٹھوس نظر آتا ہے - مکمل شفاف سے، تاکہ وال پیپر بالکل سیدھا نظر آئے، ایک مبہم کارڈ تک۔ ایڈٹ موڈ ہمیشہ مکمل کارڈ کھینچتا ہے، تاکہ ترتیب دیتے وقت کوئی سیل پکڑنے میں آسان رہے۔

---

## مرحلہ 6 - اپنی پرانی ہوم اسکرین پر واپس جائیں

ان تینوں میں سے کوئی بھی کام کرتا ہے:

- Start مینو کھولیں اور **Exit launcher mode** منتخب کریں، پھر تصدیق کریں
- **ترتیبات → عمومی** میں **Make this app the home screen** بند کریں
- براہ راست Android کی ہوم ایپس کی اپنی لسٹ پر جائیں: **ترتیبات → عمومی → System launcher settings → System → Change home screen**

آپ کا ڈیسک ٹاپ لے آؤٹ دونوں صورتوں میں محفوظ رہتا ہے، تو لانچر موڈ دوبارہ آن کرنے پر یہ بالکل اسی طرح واپس آتا ہے جیسے آپ نے چھوڑا تھا۔

---

## تجاویز

> **دیوار پر لگا ٹیبلٹ یا کار ہیڈ یونٹ؟** **ترتیبات → Management** میں **Prevent sleep** کے ساتھ لانچر موڈ کو جوڑیں تاکہ چارجر پر ہونے کے دوران ڈیسک ٹاپ نظر آتا رہے۔

> **پورا دن آن رہتا ہے؟** **ترتیبات → عمومی → System launcher settings → Desktop → Screen timeout** طے کرتا ہے کہ ڈیسک ٹاپ کتنی دیر انتظار کرے جب کوئی اسے چھوئے نہ۔ یہ فوراً تاریک نہیں ہوتا: پہلے ایک آہستہ dimming آتی ہے، پھر blackout - ڈیوائس کے خود بند ہونے کی بجائے ایک ایپ-پرائیویٹ سیاہ اوورلے، تاکہ کوئی بھی ٹچ ڈیسک ٹاپ کو فوراً واپس لے آئے۔ ڈیسک ٹاپ کو روشن رکھنے کے لیے اسے **Off (never)** پر سیٹ کریں۔

> **چارجر پر؟** بالکل نیچے کی قطار، **Screen timeout when on charge**، اس کی بجائے لاگو ہوتی ہے جب تک ایک وائرڈ یا وائرلیس چارجر جڑا رہے۔ یہ **Off (never)** کے ساتھ آتی ہے، تو ایک ڈاکڈ ڈیوائس اوپر والی قطار کو چھوئے بغیر ڈیسک ٹاپ کو روشن رکھتی ہے۔

> **مکمل حوالہ چاہتے ہیں؟** ہر آپشن، جدول اور خاص صورتحال یوزر مینوئل کے [ایپ کو اپنی ہوم اسکرین کے طور پر استعمال کریں](../HOW_TO-ur.md#how-to-use-the-app-as-your-home-screen) سیکشن میں موجود ہے۔ یہ رہنما اسے آن کرنا اور پہلے مراحل بیان کرتا ہے؛ وہ سیکشن باقی سب کچھ بیان کرتا ہے۔

> **دوسری ایپس یہاں اپنے خود کے شارٹ کٹس رکھ سکتی ہیں**، بالکل ویسے ہی جیسے وہ کسی بھی دوسری ہوم اسکرین پر رکھتیں۔
