# <img src="../icons/doc/ic_resource_smb.png" alt="" width="20" height="20" style="vertical-align:text-bottom"> اسمارٹ واچ کو NAS اور PC شیئرز سے جوڑیں

> **سطح:** درمیانی &bull; **وقت:** ~10 منٹ &bull; **ڈیوائس:** Wear OS اسمارٹ واچ

> **صرف مکمل ورژن** - یہ رہنما Google Play کے ذریعے تقسیم کیے گئے ورژن میں شامل نہیں ہے۔ یہ مکمل ورژن پر لاگو ہوتا ہے، [Downloads](../DOWNLOADS.md) سے براہ راست APK ڈاؤن لوڈ۔

{% include lang-switcher.html doc="scenario-watch-network" dir="/docs/howto/" current="ur" %}

Wear OS پر FastMediaSorter Wi-Fi پر براہ راست آپ کے گھریلو نیٹ ورک اسٹوریج (NAS، PC شیئرڈ فولڈرز، FTP، یا SFTP سرورز) سے جڑتا ہے۔ آپ ریموٹ فائلیں براؤز کر سکتے ہیں، بلوٹوتھ ہیڈ فونز پر میوزک اسٹریم کر سکتے ہیں، اور اپنے فون کے بغیر اپنے پسندیدہ فولڈرز سنک کر سکتے ہیں۔

> **نیٹ ورک شیئرز سے نئے ہیں؟** اگر آپ نے ابھی تک اپنے PC یا NAS پر شیئرڈ فولڈر سیٹ اپ نہیں کیا، تو پہلے ہمارا [NAS / ونڈوز شیئر سے جڑیں (SMB)](scenario-smb-setup-ur.md) رہنما دیکھیں۔

---

## آپ کو کیا درکار ہوگا

- آپ کے گھریلو Wi-Fi نیٹ ورک سے جڑی **Wear OS 2.0** یا نئی چلنے والی اسمارٹ واچ
- ایک شیئرڈ نیٹ ورک فولڈر (SMB / Windows شیئر، FTP سرور، یا SFTP سرور)
- نیٹ ورک کریڈینشلز: IP ایڈریس یا ہوسٹ نیم، شیئر کا نام، یوزر نیم، اور پاس ورڈ
- آپ کی واچ پر انسٹال کردہ FastMedia Wear

---

## مرحلہ 1 - اپنی واچ پر Resources کھولیں

1. اپنی اسمارٹ واچ پر **FastMedia Wear** کھولیں۔
2. مین اسکرین پر **Resources** (Wi-Fi آئیکن) پر ٹیپ کریں۔
3. Resources اسکرین آپ کے ترتیب شدہ نیٹ ورک کنکشنز دکھاتی ہے۔

![Wear OS پر Resources اسکرین](screenshots/screenshot-wear-network-step1.png)

> **Sync from Phone شارٹ کٹ:** اگر آپ نے پہلے ہی اپنے Android فون پر FastMediaSorter میں اپنے SMB یا SFTP شیئرز شامل کیے ہیں، تو تمام کنکشن ترتیبات کو ایک ٹیپ سے اپنی واچ میں درآمد کرنے کے لیے **Sync from Phone** پر ٹیپ کریں۔

---

## مرحلہ 2 - ایک نیٹ ورک سورس شامل کریں

1. Resources اسکرین پر، **Add resource** پر ٹیپ کریں۔
2. اپنا نیٹ ورک پروٹوکول منتخب کریں:
   - **SMB**: معیاری Windows شیئرز، Synology، QNAP، یا TrueNAS
   - **FTP**: معیاری FTP فائل سرورز
   - **SFTP**: محفوظ SSH فائل ٹرانسفر سرورز (پاس ورڈ یا نجی SSH کی سپورٹ کرتا ہے)
3. واچ کی آن اسکرین کی بورڈ استعمال کرتے ہوئے کنکشن کی تفصیلات درج کرنے کے لیے ہر فیلڈ ٹیپ کریں:
   - **Name**: اختیاری لیبل (مثلاً "Home NAS" یا "Music Share")
   - **Server Address**: آپ کا کمپیوٹر یا NAS IP (مثلاً `192.168.1.50`)
   - **Port**: نیٹ ورک پورٹ (ڈیفالٹ: SMB کے لیے 445، FTP کے لیے 21، SFTP کے لیے 22)
   - **Share Name** (صرف SMB): آپ کے NAS/PC پر شیئرڈ فولڈر کا نام
   - **Username** اور **Password**: آپ کی لاگ ان کریڈینشلز

![واچ پر Add Network Source اسکرین](screenshots/screenshot-wear-network-step2.png)

---

## مرحلہ 3 - کنکشن آزمائیں اور محفوظ کریں

1. فارم کے بالکل نیچے اسکرول کریں اور **Test** پر ٹیپ کریں۔
2. FastMedia Wear نیٹ ورک روٹ اور کریڈینشلز کی تصدیق کرتا ہے:
   - کامیابی پر، اسکرین **Connection successful!** دکھاتی ہے۔
   - اگر کوئی مسئلہ ہو، تو ایک دوستانہ اسٹیٹس پیغام بتاتا ہے کہ کیا ایڈجسٹ کرنا ہے (مثلاً سرور ایڈریس یا پاس ورڈ)۔
3. نیٹ ورک سورس کو اپنی واچ پر محفوظ کرنے کے لیے **Save** پر ٹیپ کریں۔

![نیٹ ورک کنکشن آزمائیں اور سورس محفوظ کریں](screenshots/screenshot-wear-network-step3.png)

---

## مرحلہ 4 - نیٹ ورک میڈیا براؤز اور چلائیں

1. Resources اسکرین پر، اپنا نیا محفوظ کردہ نیٹ ورک شیئر ٹیپ کریں۔
2. FastMedia Wear ریموٹ شیئر سے جڑتا ہے اور اس کا مواد درج کرتا ہے۔
3. لسٹ یا گرڈ ویو میں فولڈرز اور فائلیں براؤز کریں۔
4. فل اسکرین پلیئر میں پلے بیک شروع کرنے کے لیے کسی بھی آڈیو ٹریک پر ٹیپ کریں۔ تفصیلی پلیئر کی خصوصیات اور بیٹری بچانے کے لیے، دیکھیں [اپنی واچ پر میوزک سنیں](scenario-watch-music-ur.md)۔

![نیٹ ورک شیئر پر فائلیں اور فولڈرز براؤز کریں](screenshots/screenshot-wear-network-step4.png)

## مکمل! Wear OS پر نیٹ ورک کی خصوصیات

- **آزادانہ Wi-Fi اسٹریمنگ**: فون کے ریلے کے بغیر آپ کے NAS یا PC سے Wi-Fi پر براہ راست اسٹریم کرتا ہے۔
- **ملٹی-پروٹوکول سپورٹ**: پاس ورڈ یا SSH نجی کی توثیق کے ساتھ SMB، FTP، اور SFTP کی مکمل سپورٹ۔
- **دو طرفہ سنک**: اپنے فون کمپینین سے کنکشنز سنک کریں یا واچ سورسز کو واپس فون پر ایکسپورٹ کریں۔

## خرابیوں کا ازالہ

| مسئلہ | کیا آزمائیں |
|---------|------------|
| کنکشن ٹیسٹ "Connection failed" رپورٹ کرتا ہے | تصدیق کریں کہ آپ کی واچ سرور جیسے ہی Wi-Fi نیٹ ورک سے جڑی ہے، اور IP ایڈریس چیک کریں |
| SMB پر Share name کی خرابی | یقینی بنائیں کہ آپ صرف شیئر کا نام درج کریں (مثلاً `Music`)، سلیشز کے ساتھ مکمل راستہ نہیں |
| Authentication failed | اپنا یوزر نیم اور پاس ورڈ چیک کریں۔ Windows شیئرز پر، یقینی بنائیں کہ نیٹ ورک شیئرنگ کی اجازتیں آپ کے یوزر اکاؤنٹ کو اجازت دیتی ہیں |
| Wi-Fi پر آہستہ لوڈنگ | یقینی بنائیں کہ واچ کا Wi-Fi سگنل مضبوط ہے اور مقامی سرور تک 5 GHz / 2.4 GHz نیٹ ورک روٹنگ بلاک نہیں ہے |
