# <img src="../icons/doc/ic_resource_smb.png" alt="" width="20" height="20" style="vertical-align:text-bottom"> স্মার্টওয়াচকে NAS ও পিসি শেয়ারের সাথে সংযুক্ত করুন

> **স্তর:** মধ্যবর্তী &bull; **সময়:** ~১০ মিনিট &bull; **ডিভাইস:** Wear OS স্মার্টওয়াচ

> **শুধু ফুল ভার্সনে** - এই গাইডটা Google Play-এর মাধ্যমে বিতরণ করা সংস্করণে বাস্তবায়িত নেই। এটা ফুল ভার্সনের জন্য প্রযোজ্য, যা [Downloads](../DOWNLOADS.md) থেকে সরাসরি APK ডাউনলোড।

Wear OS-এ FastMediaSorter Wi-Fi-এর মাধ্যমে সরাসরি আপনার বাড়ির নেটওয়ার্ক স্টোরেজের (NAS, পিসি শেয়ার করা ফোল্ডার, FTP, বা SFTP সার্ভার) সাথে সংযুক্ত হয়। আপনি রিমোট ফাইল ব্রাউজ করতে পারেন, ব্লুটুথ হেডফোনে মিউজিক স্ট্রিম করতে পারেন, এবং ফোনের প্রয়োজন ছাড়াই আপনার প্রিয় ফোল্ডার সিঙ্ক করতে পারেন।

> **নেটওয়ার্ক শেয়ারে নতুন?** আপনার পিসি বা NAS-এ যদি এখনো একটা শেয়ার করা ফোল্ডার সেট না করে থাকেন, প্রথমে আমাদের [NAS / Windows শেয়ারের সাথে সংযুক্ত করুন (SMB)](scenario-smb-setup-bn.md) গাইড দিয়ে শুরু করুন।

---

## আপনার যা যা লাগবে

- আপনার বাড়ির Wi-Fi নেটওয়ার্কে সংযুক্ত **Wear OS 2.0** বা তার পরের সংস্করণ চালানো একটা স্মার্টওয়াচ
- একটা শেয়ার করা নেটওয়ার্ক ফোল্ডার (SMB / Windows শেয়ার, FTP সার্ভার, বা SFTP সার্ভার)
- নেটওয়ার্ক ক্রেডেনশিয়াল: IP ঠিকানা বা হোস্টনেম, শেয়ারের নাম, ইউজারনেম, এবং পাসওয়ার্ড
- আপনার ওয়াচে ইনস্টল করা FastMedia Wear

---

## ধাপ ১ - আপনার ওয়াচে Resources খুলুন

1. আপনার স্মার্টওয়াচে **FastMedia Wear** খুলুন।
2. মূল স্ক্রিনে, **Resources** (Wi-Fi আইকন) ট্যাপ করুন।
3. Resources স্ক্রিনে আপনার কনফিগার করা নেটওয়ার্ক সংযোগ দেখা যাবে।

![Wear OS-এ Resources স্ক্রিন](screenshots/screenshot-wear-network-step1.png)

> **Sync from Phone শর্টকাট:** আপনার অ্যান্ড্রয়েড ফোনে FastMediaSorter-এ যদি ইতিমধ্যে আপনার SMB বা SFTP শেয়ার যোগ করা থাকে, তাহলে সব সংযোগ সেটিংস এক ট্যাপে ওয়াচে ইমপোর্ট করতে **Sync from Phone** ট্যাপ করুন।

---

## ধাপ ২ - একটা নেটওয়ার্ক সোর্স যোগ করুন

1. Resources স্ক্রিনে, **Add resource** ট্যাপ করুন।
2. আপনার নেটওয়ার্ক প্রোটোকল বেছে নিন:
   - **SMB**: স্ট্যান্ডার্ড Windows শেয়ার, Synology, QNAP, বা TrueNAS
   - **FTP**: স্ট্যান্ডার্ড FTP ফাইল সার্ভার
   - **SFTP**: সুরক্ষিত SSH ফাইল ট্রান্সফার সার্ভার (পাসওয়ার্ড বা প্রাইভেট SSH কী সমর্থন করে)
3. ওয়াচের অন-স্ক্রিন কীবোর্ড ব্যবহার করে সংযোগের বিবরণ দিতে প্রতিটা ফিল্ডে ট্যাপ করুন:
   - **Name**: ঐচ্ছিক লেবেল (যেমন "Home NAS" বা "Music Share")
   - **Server Address**: আপনার কম্পিউটার বা NAS-এর IP (যেমন `192.168.1.50`)
   - **Port**: নেটওয়ার্ক পোর্ট (ডিফল্ট: SMB-র জন্য 445, FTP-র জন্য 21, SFTP-র জন্য 22)
   - **Share Name** (শুধু SMB): আপনার NAS/পিসিতে শেয়ার করা ফোল্ডারের নাম
   - **Username** এবং **Password**: আপনার লগইন ক্রেডেনশিয়াল

![ওয়াচে Add Network Source স্ক্রিন](screenshots/screenshot-wear-network-step2.png)

## ধাপ ৩ - সংযোগ পরীক্ষা করুন এবং সংরক্ষণ করুন

1. ফর্মের একদম নিচে স্ক্রল করে **Test** ট্যাপ করুন।
2. FastMedia Wear নেটওয়ার্ক রুট এবং ক্রেডেনশিয়াল যাচাই করে:
   - সফল হলে, স্ক্রিনে **Connection successful!** দেখাবে।
   - কোনো সমস্যা থাকলে, একটা বন্ধুসুলভ স্ট্যাটাস বার্তা দেখাবে কী ঠিক করতে হবে (যেমন সার্ভার ঠিকানা বা পাসওয়ার্ড)।
3. আপনার ওয়াচে নেটওয়ার্ক সোর্সটা সংরক্ষণ করতে **Save** ট্যাপ করুন।

![নেটওয়ার্ক সংযোগ পরীক্ষা করে সোর্স সংরক্ষণ করা](screenshots/screenshot-wear-network-step3.png)

---

## ধাপ ৪ - নেটওয়ার্ক মিডিয়া ব্রাউজ করুন এবং বাজান

1. Resources স্ক্রিনে, আপনার এইমাত্র সংরক্ষিত নেটওয়ার্ক শেয়ারে ট্যাপ করুন।
2. FastMedia Wear রিমোট শেয়ারের সাথে সংযুক্ত হয় এবং এর কনটেন্ট তালিকাভুক্ত করে।
3. লিস্ট বা গ্রিড ভিউতে ফোল্ডার ও ফাইল ব্রাউজ করুন।
4. ফুল-স্ক্রিন প্লেয়ারে প্লেব্যাক শুরু করতে যেকোনো অডিও ট্র্যাকে ট্যাপ করুন। বিস্তারিত প্লেয়ার ফিচার এবং ব্যাটারি সাশ্রয়ের জন্য, দেখুন [আপনার ওয়াচে মিউজিক শুনুন](scenario-watch-music-bn.md)।

![নেটওয়ার্ক শেয়ারে ফাইল ও ফোল্ডার ব্রাউজ করা](screenshots/screenshot-wear-network-step4.png)

## সম্পন্ন! Wear OS-এ নেটওয়ার্ক ফিচার

- **স্বাধীন Wi-Fi স্ট্রিমিং**: ফোন রিলে ছাড়াই Wi-Fi-এর মাধ্যমে সরাসরি আপনার NAS বা পিসি থেকে স্ট্রিম করে।
- **মাল্টি-প্রোটোকল সমর্থন**: পাসওয়ার্ড বা SSH প্রাইভেট কী প্রমাণীকরণসহ SMB, FTP, এবং SFTP-এর পূর্ণ সমর্থন।
- **দ্বিমুখী সিঙ্ক**: আপনার ফোন কম্প্যানিয়ন থেকে সংযোগ সিঙ্ক করুন বা ওয়াচের সোর্স ফোনে ফিরিয়ে এক্সপোর্ট করুন।

## সমস্যা সমাধান

| সমস্যা | কী চেষ্টা করবেন |
|---------|------------|
| সংযোগ পরীক্ষায় "Connection failed" দেখাচ্ছে | নিশ্চিত করুন আপনার ওয়াচ সার্ভারের মতো একই Wi-Fi নেটওয়ার্কে সংযুক্ত আছে, এবং IP ঠিকানা চেক করুন |
| SMB-তে Share name ত্রুটি | নিশ্চিত করুন শুধু শেয়ারের নাম দিয়েছেন (যেমন `Music`), স্ল্যাশসহ সম্পূর্ণ পাথ নয় |
| Authentication ব্যর্থ হয়েছে | আপনার ইউজারনেম এবং পাসওয়ার্ড চেক করুন। Windows শেয়ারে, নিশ্চিত করুন নেটওয়ার্ক শেয়ারিং পারমিশন আপনার ইউজার অ্যাকাউন্টকে অনুমতি দেয় |
| Wi-Fi-তে ধীর লোডিং | নিশ্চিত করুন ওয়াচের Wi-Fi সিগন্যাল শক্তিশালী এবং স্থানীয় সার্ভারে 5 GHz / 2.4 GHz নেটওয়ার্ক রাউটিং ব্লক করা নেই |
