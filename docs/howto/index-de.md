- <img src="../icons/doc/ic_info.png" alt="" width="20" height="20" style="vertical-align:text-bottom"> **Tipp für den ersten Start:** Auf dem Willkommensbildschirm können Sie ein **Geräteprofil** auswählen, das die App für Szenarien wie Bilderrahmen, Automusik oder Heimkino vorkonfiguriert - und Sie können es jederzeit unter **Einstellungen → Allgemein → Geräteprofil** ändern. Siehe [Erster Start: Ihr Geräteprofil wählen](../QUICK_START-de.md#first-launch-choose-your-device-profile-30-seconds-).
