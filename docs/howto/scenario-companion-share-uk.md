# <img src="../icons/doc/ic_resource_smb.png" alt="" width="20" height="20" style="vertical-align:text-bottom"> Відкрийте папки ПК, відсканувавши один код

> **Рівень:** Початківець &bull; **Флейвори:** Standard, Photos, Legacy, XR/noLegal (для скану потрібна камера; спосіб із файлом працює всюди)

[English](scenario-companion-share.md) | [Русский](scenario-companion-share-ru.md)

На ПК з Windows ви запускаєте невелику програму-компаньйон, обираєте папки з відео, музикою, документами чи фото - і вона показує на екрані код. На телефоні ви натискаєте **Додати**, підносите камеру до цього коду, і папки ПК одразу підключені - без введення адреси, порту, пароля, без кабелів.

> **Простими словами:** компаньйон перетворює обрані папки на приватну спільну папку лише для читання у вашій домашній мережі Wi-Fi і друкує код, у якому вже є все, що потрібно телефону для доступу. Відсканувати код - це те саме, що вручну заповнити довгу форму підключення, тільки телефон читає її з одного погляду. Далі файли відкриваються на вимогу та передаються по Wi-Fi; на телефон нічого не копіюється, доки ви самі не попросите.

---

## Програма-компаньйон

Компаньйон - вбудована функція **[Fast Media Sorter for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/)** (раніше FastMediaSorter LITE), безкоштовного сортувальника медіа від того самого автора. Коли ви відкриваєте їй доступ до папок, вона:

- Піднімає приватний SFTP-сервер лише для цих папок на вашому ПК.
- Сама створює ключі й налаштовує автозапуск, щоб спільна папка була доступна й наступного разу.
- Показує на екрані **QR-код** і може зберегти невеликий файл конфігурації `.fmscfg`.

**Де взяти:**

- Сайт: [serzhyale.github.io/FastMediaSorter_Lite](https://serzhyale.github.io/FastMediaSorter_Lite/)
- Публікація папок (покроково): [Як опублікувати папки ПК для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)
- GitHub: [останній реліз](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases/latest) (інсталятор або портативний ZIP)
- winget: `winget install SerZhyAle.FastMediaSorter`
- Microsoft Store: пошук «FastMediaSorter LITE» (у Store програма під попередньою назвою)

## Що знадобиться

- ПК з Windows і встановленою **Fast Media Sorter for Windows**
- Телефон і ПК в **одній мережі Wi-Fi** (один роутер)
- Для найшвидшого способу - **камера** телефону для скану коду (якщо камери немає, є спосіб із файлом)

---

## Крок 1 - Відкрийте доступ до папок на ПК

1. Встановіть і запустіть **Fast Media Sorter for Windows**, відкрийте вкладку **Share** у налаштуваннях.
2. Оберіть папку(и), які потрібні на телефоні - фільми, музику, документи, фото, будь-що.
3. Програма сама підніме SFTP-сервер, створить ключі й налаштує автозапуск. Більше нічого налаштовувати не потрібно.
4. Тепер вона показує на екрані ПК **QR-код**. Залиште це вікно відкритим для кроку 2.

> Хочете файл замість коду? Натисніть **Save .fmscfg** у тому самому вікні й передайте файл на телефон (email, Telegram або будь-яка спільна папка). Див. [Крок 2, спосіб B](#крок-2-спосіб-b---імпорт-файлу).

---

## Крок 2, спосіб A - Відскануйте код (найшвидший)

1. Відкрийте FastMediaSorter і натисніть кнопку **Додати (⊕)** на головному екрані.
2. Натисніть **«Імпорт за штрихкодом»** - вона поруч із чотирма картками типів ресурсу (Локальна, SMB, SFTP/FTP, Хмара) і в шапці форми SFTP.
3. Відкриється камера з підказкою *«Наведіть камеру на QR-код компаньйона»*. Піднесіть телефон до QR-коду на ПК. У темній кімнаті натисніть **Ліхтарик**.
4. З'явиться підтвердження - *«Імпорт доступу - Додати SFTP-ресурс .. з N папкою(ами)?»*. Натисніть **Імпорт**.
5. Готово. Для кожної спільної папки з'явиться окремий ресурс лише для читання, ключ сервера буде закріплено автоматично.

> Пункт **«Імпорт за штрихкодом»** прихований на пристроях без камери та на VR-гарнітурах - там використовуйте спосіб B.

## Крок 2, спосіб B - Імпорт файлу

Використовуйте, коли в телефона немає камери або ПК і телефон не поруч.

1. На ПК натисніть **Save .fmscfg** і доставте файл на телефон (email, Telegram, хмара або спільна папка).
2. **Якщо файл уже на телефоні:** натисніть **Додати (⊕)** -> **«SFTP / FTP»** -> **«Імпорт із файлу»** та оберіть файл `.fmscfg`.
3. **Якщо надійшов вкладенням** (Telegram чи email): просто натисніть на вкладення `.fmscfg` - застосунок одразу відкриє діалог підтвердження.
4. Підтвердіть той самий діалог *«Імпорт доступу»* і натисніть **Імпорт**. З'являться ресурси лише для читання.

> **Поводьтеся з кодом і файлом як із ключем.** В обидва зашито пароль доступу, щоб телефон підключався без жодного введення. Не публікуйте скриншот QR-коду і файл `.fmscfg`.

## Готово! Тепер ви можете..

Спільні папки поводяться як будь-який інший ресурс у застосунку. Наприклад:

- **Дивитися фільми й серіали** з ПК на телефоні, планшеті чи Android TV-приставці - потоком, без копіювання. Див. [Домашній кінотеатр і VR-стримінг](scenario-home-cinema-uk.md).
- **Слухати свою музику** в дорозі або на автомагнітолі.
- **Читати PDF і EPUB** з ПК, зберігаючи останню позицію.
- **Переглядати фотоархів** і сортувати його через Quick Sort або показувати як [цифрову фоторамку](scenario-photo-frame-uk.md).
- **Передати файл у спеціалізований застосунок** - відкрийте аркуш Info в мережевого файлу й натисніть «Завантажити й відкрити».
- **Копіювати чи переміщувати файли** між ПК і телефоном у будь-який бік.

## Як це працює (під капотом)

- Програма-компаньйон на Windows піднімає легкий **SFTP-сервер**, прив'язаний до обраних папок, лише у вашій локальній мережі.
- QR-код (або файл `.fmscfg`) кодує підключення: хост, порт, облікові дані, шляхи спільних папок та відбиток ключа сервера. Щільні набори папок передаються у стисненому вигляді, тому навіть багато папок уміщується в один код.
- Телефон читає ці дані, перевіряє їх і створює **по одному ресурсу SFTP лише для читання на кожну папку**. Ключ сервера закріплюється при першому підключенні (TOFU), тож телефон попередить, якщо ПК колись підмінять.
- Оскільки це ваша локальна мережа Wi-Fi і доступ лише для читання, телефон переглядає й передає файли, нічого не змінюючи на ПК.
- **У тій самій мережі Wi-Fi телефон знаходить ПК сам.** Компаньйон анонсує спільну папку в локальній мережі, а телефон зіставляє її за закріпленим ключем - тому навіть при зміні адреси ПК у мережі все продовжує працювати без повторного скану.
- **Один імпорт може працювати і вдома, і в дорозі.** Код може нести кілька адрес - локальну, IPv6 та проброшений порт з інтернету. Телефон пробує їх і використовує ту, що досяжна зараз: локальну вдома, інтернет-адресу на мобільних даних. Той самий ресурс продовжує працювати при переході між мережами, якщо ПК справді досяжний звідти, де ви є.
- **Якщо підключитися не вдається, застосунок пояснює, що робити** - зайти в ту саму мережу Wi-Fi чи налаштувати доступ на ПК - замість сухої помилки. Якщо компаньйон додав нотатку про доступ, телефон її показує.

## Усунення несправностей

| Проблема | Що спробувати |
|----------|---------------|
| Немає пункту «Імпорт за штрихкодом» | У пристрою немає камери або це VR-збірка. Використовуйте [спосіб B - Імпорт файлу](#крок-2-спосіб-b---імпорт-файлу) |
| Пише, що потрібен доступ до камери | Надайте дозвіл на камеру за запитом - він потрібен лише для скану |
| «Це не коректна конфігурація компаньйона» | Код або файл не з компаньйона Windows. Експортуйте заново з вкладки **Share** |
| «Створено новішою версією компаньйона» | Оновіть FastMediaSorter на телефоні або експортуйте із сумісної версії компаньйона |
| Ресурс додано, але папки порожні | Переконайтеся, що компаньйон на ПК ще запущений. У **тій самій мережі Wi-Fi** застосунок знаходить ПК сам; якщо все одно не виходить, застосунок підкаже, що перевірити |
| Працює по Wi-Fi, але не по мобільних даних | Щоб дістатися до ПК з іншої мережі, він має бути досяжним з інтернету - налаштуйте проброс порту або IPv6 у налаштуваннях **Share** компаньйона. Без цього спільна папка працює лише в тій самій мережі Wi-Fi |
