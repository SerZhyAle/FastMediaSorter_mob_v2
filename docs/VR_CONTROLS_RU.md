# Управление в иммерсивном VR

*Обновлено: 2026-04-24*

Документ описывает все поверхности ввода, поддерживаемые в иммерсивном
режиме VR-редакции: контроллеры Meta Quest Touch Plus / Touch Pro,
Bluetooth-клавиатуру и Bluetooth-мышь. Все три слоя используют общий
диспетчер команд, поэтому одно и то же действие доступно через любой
удобный способ ввода.

Шпаргалка появляется автоматически один раз при первом входе в иммерсив
(на 4 секунды). Чтобы вызвать её снова: долгое нажатие **Y** на левом
контроллере или клавиша **F1** на клавиатуре.

## 1. Контроллеры Touch

Поддерживаются: Touch Plus (Quest 2, Quest 3) и Touch Pro (Quest Pro).
Логические привязки одинаковы; приложение регистрирует suggested bindings
для обоих профилей, поэтому поведение идентично на всех шлемах.

### Правый контроллер

| Элемент | Действие |
|---|---|
| **A** | Пауза / воспроизведение. Главная клавиша плеера. |
| **B** | Выход в 2D-панель. Всегда доступный путь наружу. |
| **Триггер** | (Зарезервирован под будущий луч-указатель и клик по оверлею.) |
| **Грип** | Zoom. Удерживать + двигать рукой вперёд/назад = изменение масштаба. |
| **Стик ↑ / ↓** | Громкость +/−. |
| **Стик ← / →** | Предыдущий / следующий файл. Только edge-срабатывание, без автоповтора. |
| **Клик стика** | Ре-центр сцены перед лицом. |

### Левый контроллер

| Элемент | Действие |
|---|---|
| **X** | Выход в 2D-панель (дубль B). |
| **Y (короткое)** | Открыть панель **файловых операций** (копировать / переместить / удалить / переименовать / о файле). |
| **Y (долгое ≥ 0.8 с)** | Показать / скрыть шпаргалку. |
| **≡ (меню)** | Диалог настроек воспроизведения (стерео-формат, аудиодорожка, субтитры, скорость, яркость). |
| **Триггер** | (Зарезервирован под будущий луч-указатель.) |
| **Грип** | Zoom — симметрично правому грипу. |
| **Стик ↑ / ↓** | Громкость +/− (дубль правого стика). |
| **Стик ← / →** | Перемотка −10 с / +10 с. Только edge, без автоповтора. |
| **Клик стика** | Переключить иммерсивный ↔ плоский экран внутри VR-задачи. |

### Комбинации

- **Оба грипа удерживаются ≥ 1 с** → сброс масштаба к 1.0×.

## 2. Bluetooth-клавиатура

Четыре уровня привычных конвенций сложены друг на друга, чтобы каждый мог
пользоваться своим привычным набором: Norton Commander F-клавиши
(первичный слой), Windows / MPC-HC / VLC, YouTube-браузерный стиль,
стандартные медиа-клавиши BT-пультов.

### F-клавиши (Norton Commander)

| Клавиша | Действие |
|---|---|
| **F1** | Показать / скрыть шпаргалку. |
| **F2** | Переименовать текущий файл. |
| **F3** | О файле (открывает инфо через панель операций). |
| **F4** | Диалог настроек воспроизведения. **Alt+F4** = выход. |
| **F5** | Скопировать в.. |
| **F6** | Переместить в.. |
| **F7** | Открыть панель файловых операций. |
| **F8** | Удалить (с подтверждением). |
| **F10** | Выход в 2D-панель. |

### Windows / VLC / MPC-HC

| Клавиша | Действие |
|---|---|
| **Space** | Пауза / плей. |
| **← / →** | Перемотка ±10 с. |
| **Shift + ← / →** | Микро-перемотка ±3 с. |
| **Ctrl + ← / →** | Макро-перемотка ±60 с. |
| **↑ / ↓** | Громкость ±. |
| **Page Up / Page Down** | Предыдущий / следующий файл. |
| **M** | Mute / unmute. |
| **Delete** | Удалить (с подтверждением). |
| **Esc** | Выход. |
| **Ctrl + R** | Переименовать (дубль F2). |
| **Ctrl + C** | Скопировать в.. (дубль F5). |
| **Ctrl + X** | Переместить в.. (дубль F6). |
| **Ctrl + I** | О файле (дубль F3). |
| **Ctrl + Y** | Открыть панель файловых операций. |
| **+ / −** | Увеличить / уменьшить масштаб (дискретные шаги). |
| **0** | Сброс масштаба к 1.0×. |

### YouTube-браузерный стиль

| Клавиша | Действие |
|---|---|
| **K** | Пауза / плей. |
| **J / L** | Перемотка ±10 с. |
| **N / P** | Следующий / предыдущий файл. |
| **C** | Ре-центр сцены. |
| **V** | Переключить иммерсивный ↔ плоский экран. |
| **Tab** | Диалог настроек воспроизведения. |
| **Enter** | Диалог настроек воспроизведения. |

### BT-пульты / медиа-клавиши

- **Media Play/Pause** → пауза / плей.
- **Media Next / Previous** → следующий / предыдущий файл.
- **Громкость ± / Mute** **не перехватываются** — их обрабатывает сама Android.

## 3. Bluetooth-мышь

Мышь — параллельная поверхность указания (в этой итерации используется
Android-курсор; 3D-луч от контроллера — в следующей итерации).

| Элемент | Действие |
|---|---|
| Движение | Курсор на 2D-оверлее (когда тот видим). |
| **ЛКМ** | Пауза / плей (или клик по элементу оверлея под курсором). |
| **ПКМ** | Диалог настроек воспроизведения. |
| **СКМ** | Ре-центр сцены. |
| **Кнопка 4 / 5** | Предыдущий / следующий файл (боковые кнопки игровой мыши). |
| **Колесо ↑ / ↓** | Громкость ±. |
| **Shift + колесо** | Перемотка ±10 с. |

## 4. Сценарий файловых операций

1. Откройте панель через **Y** (левый контроллер), **F7** или **Ctrl+Y**, либо
   сразу перейдите к действию через **F2 / F3 / F5 / F6 / F8**.
2. Воспроизведение автоматически ставится на паузу при открытии панели и
   возобновляется при закрытии (только если пауза была применена панелью).
3. Для «Скопировать» / «Переместить» диалог «Куда?» показывает до десяти
   последних папок-назначений плюс пункт «Выбрать другую папку..», который
   возвращает в 2D-панель для полноценного выбора из дерева.
4. Удаление всегда подтверждается диалогом с именем и размером файла.
5. Переименование — простой диалог ввода (нужна BT-клавиатура или системная
   экранная клавиатура Quest).

## 5. HUD-индикаторы

Авто-скрывающиеся подсказки поверх сцены:

- Иконка паузы / плея (центр, 0.8 с)
- Процент громкости (справа, 1.5 с)
- Полоса перемотки `[позиция / общее]  ±Nс` (внизу, 1.2 с)
- Имя файла + `3 / 12` (справа вверху, 2 с)
- Кратность масштаба `1.2×` (центр, 1 с)
- Вспышка «ре-центр» (центр, 0.4 с)
- «Первый файл» / «Последний файл» (справа вверху, 1.5 с)

## 6. Устранение неполадок

- **Контроллеры молчат в иммерсиве.** Убедитесь, что установлен flavor `vr`;
  другие flavor'ы не загружают подсистему ввода OpenXR. На Quest Pro с Touch
  Pro привязки те же самые — они используют общий action set.
- **Клавиатура работает в 2D-панели, но не в VR.** Принудительно закройте
  Activity и откройте заново; некоторым BT-клавиатурам нужно пересопряжение
  после того, как иммерсивная сессия получила фокус.
- **Курсор мыши не виден.** В текущей итерации курсор рисуется на 2D-surface
  под OpenXR-оверлеем, которая невидима в шлеме. Луч-указатель с контроллера
  и рендеринг курсора на quad-слое — запланированы на следующую итерацию.
