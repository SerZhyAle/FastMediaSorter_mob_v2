## Подключение сетевого диска (SMB)

**Что нужно:**

- NAS или ПК с Windows с общей папкой
- Оба устройства в одной Wi-Fi сети
- Имя пользователя и пароль для доступа

**Доступно в:** Версии Standard, Lite, Photos, Legacy

**Шаги:**

1. Нажмите кнопку **"+"** на главном экране
2. Выберите **"Сетевая папка (SMB)"**
3. Заполните данные:
   - **Авто-обнаружение (New):**
     1. Нажмите **"Сканировать сеть"**
     2. Дождитесь появления устройств в списке
     3. Выберите устройство из списка
     4. IP-адрес заполнится автоматически

   - **Ручной ввод:**

     ```
     Сервер/Путь: \\192.168.1.100\photos
     Имя пользователя: john
     Пароль: ****
     Имя для отображения: Home NAS (необязательно)
     ```

4. Нажмите **"Тест соединения"** для проверки
5. Нажмите **"Сохранить"**

**Форматы адреса сервера:**

- Windows: `\\192.168.1.100\share`
- Linux/Mac: `smb://192.168.1.100/share`
- С портом: `smb://192.168.1.100:445/share`

**Советы:**

- Используйте IP-адрес (а не имя хоста) для надёжности
- Включите SMB v2/v3 на NAS для безопасности
- Порт SMB по умолчанию: 445

**Устранение неполадок:**
→ См. [TROUBLESHOOTING.md#smb-connection](TROUBLESHOOTING.md)

## Подключение SFTP/FTP сервера

**Что нужно:**

- Сервер с включенным SSH (SFTP) или FTP
- Открытый порт 22 (SFTP) или 21 (FTP)
- Имя пользователя и пароль (или ключ для SFTP)

**Шаги:**

1. Нажмите кнопку **"+"** на главном экране
2. Выберите **"SFTP / FTP"**
3. Выберите протокол: **SFTP** или **FTP**
4. Заполните данные:

   ```
   Хост: 192.168.1.100
   Порт: 22 (SFTP) / 21 (FTP)
   Имя пользователя: username
   Пароль: ****
   Удаленный путь: /home/user/photos (необязательно)
   ```

5. Нажмите **"Подключиться"**

**Дополнительно:**

- **Аутентификация по SSH-ключу:** В настоящее время не поддерживается (только пароль)
- **Свой порт:** Измените номер порта, если сервер использует нестандартный

**Устранение неполадок:**
→ См. [TROUBLESHOOTING.md#sftp-timeout](TROUBLESHOOTING.md)

## Подключение облачного хранилища

**Поддерживаемые провайдеры:**

- Google Drive
- OneDrive
- Dropbox

**Шаги:**

1. Нажмите кнопку **"+"** на главном экране
2. Выберите **"Cloud Storage"** (Облачное хранилище)
3. Выберите провайдера: **Google Drive**, **OneDrive** или **Dropbox**
4. Нажмите кнопку **"Войти.."**
5. Следуйте инструкциям аутентификации в браузере/приложении
6. Предоставьте необходимые права доступа
7. **Выберите папки** для синхронизации
8. Нажмите **"Готово"**

**Примечания:**

- Файлы **стримятся**, а не скачиваются
- Требуется подключение к Интернету
- Изменения синхронизируются автоматически
- Можно отключить в любое время: Редактировать папку → Удалить

**Приватность:**

- Пароль не сохраняется (используются OAuth токены)
- Токены можно отозвать в настройках безопасности облачного провайдера

## Проверка скорости сети

**Поддерживается для:** SMB, SFTP, FTP, Cloud (Google Drive)

**Автоматическая проверка:**
При добавлении нового сетевого ресурса приложение автоматически запускает тест скорости в фоновом режиме. Результаты (скорость чтения/записи) сохраняются в настройках ресурса.

**Ручная проверка:**

1. Перейдите в **Управление ресурсами**
2. Редактируйте сетевой ресурс (значок карандаша)
3. Прокрутите вниз
4. Нажмите кнопку **"Скорость"**
5. Подождите ~15 секунд ("Анализ скорости..")
6. Результаты:
   - **Скорость чтения (Мбит/с)**
   - **Скорость записи (Мбит/с)**
   - **Рекомендуемые потоки** (для оптимальной производительности)

## Настройка папок Quick Sort

**Способ 1: Через Настройки**

1. **Настройки** → вкладка **Quick Sort**
2. Нажмите **"Добавить в Quick Sort"**
3. Выберите существующую папку из списка
4. Папке присваивается номер (0-9) и цвет
5. Повторите для до 30 папок

**Способ 2: Через настройки папки**

1. Главный экран → **Долгое нажатие на папке**
2. Нажмите **"Редактировать"** (иконка карандаша)
3. Включите **"Отметить для Quick Sort"**
4. Нажмите **"Сохранить"**

**Использование Quick Sort:**

При просмотре файлов:

- Нажмите **цифровую кнопку** (0-9) на панели команд
- ИЛИ нажмите **нижний левый угол** (зона COPY)
- ИЛИ нажмите **нижний центральный угол** (зона MOVE)

Файл мгновенно копируется/перемещается в эту папку!

## Использование сенсорных зон

**Что такое сенсорные зоны?**

Экран разделен на 9 невидимых областей для быстрых действий:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПИЯ  │ ПЕРЕИМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  ПРЕД.  │ ПЕРЕМ.  │  СЛЕД.  │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ КОМАНДЫ │ УДАЛИТЬ │ ИГРАТЬ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. **НАЗАД** - Вернуться к списку
2. **КОПИЯ** - Копировать в папку
3. **ПЕРЕИМ.** - Переименовать файл
4. **ПРЕД.** - Предыдущий файл
5. **ПЕРЕМ.** - Переместить в папку
6. **СЛЕД.** - Следующий файл
7. **КОМАНДЫ** - Открыть меню
8. **УДАЛИТЬ** - Удалить файл
9. **ИГРАТЬ** - Старт/Стоп слайд-шоу

**Включить наложение (рекомендуется для новичков):**

1. Настройки → Воспроизведение
2. Включите **"Всегда показывать зоны нажатия"**
3. Теперь вы увидите полупрозрачную сетку

**Попробуйте:**

1. Откройте любое фото
2. **Нажмите верхний правый угол** → Следующий файл
3. **Нажмите верхний левый угол** → Предыдущий файл
4. **Нажмите средний правый угол** → Удалить файл
5. **Нажмите средний левый угол** → Копировать файл

**Отключить, если не нужно:**
Настройки → Воспроизведение → "Всегда показывать зоны нажатия" = ВЫКЛ

Затем используйте **кнопки панели команд**.

## Редактирование фото

**Поддерживаемые операции:**

- Поворот (90°, 180°, 270°)
- Отражение (горизонтально, вертикально)
- Фильтры (Ч/Б, Сепия, Негатив)
- Настройка (Яркость, Контраст, Насыщенность)

**Шаги:**

1. **Откройте фото** в полноэкранном режиме
2. Нажмите кнопку **"Редактировать"** (или зону слева посередине)
3. **Выберите операцию:**
   - Поворот: Иконка поворота
   - Отражение: Иконка отражения
   - Фильтр: Выберите из списка
   - Настройка: Используйте ползунки
4. Нажмите **"Сохранить"**

**Примечания:**

- Оригинальный файл **перезаписывается** (отмена невозможна!)
- Работает для **локальных и сетевых файлов**
- Поддержка: JPG, PNG, WEBP

## Создание слайд-шоу

**Шаги:**

1. **Откройте любую папку** с фото
2. Нажмите **первое фото** для просмотра
3. Нажмите кнопку **"Play"** (или зону справа внизу)
4. Слайд-шоу начнется автоматически

**Настройка скорости:**

1. **Редактировать настройки папки:**
   - Главный экран → Долгое нажатие на папке → Редактировать
2. Измените **"Интервал слайд-шоу":**
   - Быстро: 2 секунды
   - Нормально: 5 секунд
   - Медленно: 10 секунд
3. Нажмите **"Сохранить"**

**Управление во время слайд-шоу:**

- **Нажатие на экран** → Пауза/Продолжить
- **Свайп влево/вправо** → Пропуск файлов
- **Нажмите "Стоп"** → Выход

## Создание слайд-шоу с фоновой музыкой

**Требования:**

- Хотя бы одна папка/ресурс с аудиофайлами (MP3, FLAC и т.д.)
- **Доступно в:** Только версия Standard

**Настройка:**

1. **Настройки** → вкладка **Аудио**
2. Включите **"Включить фоновую музыку для слайд-шоу"**
3. Нажмите кнопку **"Выбрать источник музыки"**
4. Выберите ресурс, содержащий ваши музыкальные файлы
5. Нажмите **"Сохранить"** или закройте настройки

**Воспроизведение слайд-шоу с музыкой:**

1. **Откройте любую папку** с фото/изображениями
2. Нажмите **первое фото** для просмотра
3. Нажмите кнопку **"Play"** (или зону справа внизу)
4. Слайд-шоу начнется с воспроизведением фоновой музыки

**Как это работает:**

- Музыка воспроизводится случайным образом из выбранного музыкального ресурса
- Когда трек заканчивается, автоматически начинается следующий случайный трек
- Музыка продолжает играть во время переходов между изображениями
- Музыка останавливается при выходе из слайд-шоу или паузе

**Примечания:**

- Музыка воспроизводится только для **изображений и GIF** (не для видео/аудио)
- Когда слайд-шоу показывает видео, музыка автоматически приостанавливается
- Музыка возобновляется при возврате к изображениям
- Работает с локальными и сетевыми источниками музыки (SMB, SFTP, FTP)

**Настройка выбора музыки:**

- Добавьте несколько музыкальных файлов в папку музыкального ресурса
- Приложение будет случайным образом перемешивать все аудиофайлы
- Организуйте музыку в подпапки, если для музыкального ресурса включена опция "Включить подпапки"

**Устранение неполадок:**

- Если музыка не воспроизводится: Проверьте, что музыкальный ресурс содержит хотя бы один аудиофайл
- Если музыка прерывается в сети: Используйте локальную папку или более быстрое сетевое соединение
- Для музыки по SMB: Убедитесь, что SMB-ресурс использует протокол `file://` (см. TROUBLESHOOTING.md)

## Защита папки PIN-кодом

**Шаги:**

1. Главный экран → **Долгое нажатие на папке**
2. Нажмите **"Редактировать"** (иконка карандаша)
3. Прокрутите до поля **"PIN-код"**
4. Введите **4-6 значный PIN** (например, 1234)
5. Нажмите **"Сохранить"**

**Теперь:**

- Открытие папки требует PIN
- Предотвращает несанкционированный доступ
- Применяется к просмотру и редактированию

**Удалить PIN:**

- Редактировать папку → Очистить поле PIN → Сохранить

**Забыли PIN?**

- Возможности восстановления нет (для безопасности)
- Придется удалить папку из приложения и добавить заново

## Очистка корзины

Удалённые файлы попадают в папки `.trash/` и остаются там до ручной очистки.

**Способ 1: Очистить всю корзину**

1. **Настройки** → вкладка **Quick Sort**
2. Нажмите **"Очистить Корзину"**
3. Подтвердите удаление
4. Все папки `.trash/` во всех ресурсах будут очищены

**Способ 2: Для одной папки**

1. Используйте файловый менеджер
2. Перейдите в папку (например, `/storage/emulated/0/DCIM/Camera`)
3. Найдите подпапку `.trash/`
4. Удалите вручную

**Внимание:** Это **безвозвратное удаление**! Файлы нельзя будет восстановить.

## Просмотр текстовых и PDF файлов

**1. Включить поддержку:**

1. **Настройки** → **Документы**
2. Включите **"Поддержка текстовых файлов"** и **"Поддержка PDF файлов"**
3. **Пересканируйте** папки, чтобы найти новые файлы.

**2. Фильтр по типу медиа:**

1. Нажмите иконку **Фильтра** (воронка) на главном экране.
2. Выберите типы файлов:
   - Изображения
   - Видео
   - Аудио
   - GIF
   - **Текст** (Новое)
   - **PDF** (Новое)
3. Нажмите **"Применить"**.

**3. Текстовый просмотрщик:**

- Открывает **.txt, .md, .log, .json, .xml**.
- **Прокрутка** для чтения.
- **Копирование:** Долгое нажатие для выделения текста.

**4. PDF Просмотрщик (Новые функции):**

- Открывает **.pdf** файлы.
- **Панель управления (Снизу):**
  - **Назад/Вперед:** Большие кнопки по краям.
  - **Зум +:** Увеличить.
  - **Зум -:** Уменьшить.
- **Жесты:**
  - **Свайп ВВЕРХ:** Следующая страница.
  - **Свайп ВНИЗ:** Предыдущая страница.
  - **Щипок:** Масштабирование.
  - **Двойной тап:** Сброс масштаба.
- **Перемещение:** Перетаскивайте увеличенную страницу пальцем.

## Как читать электронные книги (EPUB)

**Требования:**

- **Настройки** → **Документы** → **Поддержка EPUB** должно быть включено (включено по умолчанию)
- Поддерживаемый формат: `.epub` (без DRM)

**Возможности:**

- **Навигация по главам:** Свайп влево/вправо или кнопки на панели команд
- **Оглавление:** Нажмите иконку спика (📋) для перехода к главе
- **Размер шрифта:** настраиваемый (14px - 32px)
- **Поиск:** Поиск текста внутри книги
- **Темы:** Автоматически адаптируется под Светлую/Темную тему

**Управление:**

1. **Откройте файл EPUB** из списка
2. **Коснитесь экрана** для отображения панели команд
3. **Нижняя панель управления:**
   - `Пред.` / `След.`: навигация по главам
   - `- A` / `+ A`: уменьшить/увеличить шрифт
   - `Поиск` (🔍): поиск текста
   - `Оглавление` (📋): открыть список глав
4. **Жесты свайпа:** переключение глав

**Примечание:** Работает как с локальными файлами, так и с сетевыми потоками (SMB/SFTP/Cloud). Большие книги (>50МБ) в медленных сетях могут загружаться несколько секунд.

## Открытие сетевых файлов во внешних приложениях

**Доступно для:** Файлов SMB, SFTP, FTP

**Сценарий использования:** Вы хотите открыть документ, фото или видео с сетевого диска в специализированном внешнем приложении (например, MS Office, Adobe Acrobat, VLC Player).

**Шаги:**

1. **Перейдите к файлу** на сетевом ресурсе
2. **Нажмите на файл**, чтобы открыть его в плеере/просмотрщике
3. **Нажмите кнопку ⓘ (Инфо)** в верхней панели
4. **Нажмите "Загрузить и открыть"**
5. **Дождитесь загрузки** - диалог прогресса покажет проценты
6. **Выберите приложение** из списка Android

**Что происходит:**

- Файл загружается в папку `Downloads`
- Прогресс отображается в диалоге (0-100%)
- После завершения Android покажет выбор приложения
- Можно открыть файл в любом совместимом приложении

**Поддерживаемые протоколы:**

- ✅ SMB/CIFS сетевые папки
- ✅ SFTP серверы
- ✅ FTP серверы
- ❌ Облачные хранилища (пока не реализовано)

**Советы:**

- Загруженные файлы остаются в папке `Downloads`
- Вы можете удалить их вручную позже через файловый менеджер
- Работает со всеми типами файлов (изображения, видео, документы)
- Для больших файлов загрузка может занять несколько минут

**Примеры использования:**

- Редактирование сетевого документа в MS Word
- Воспроизведение сетевого видео в VLC Player
- Просмотр сетевого PDF в Adobe Acrobat
- Отправка сетевого фото через мессенджеры

## Как просмотреть текст песни (Лирика)

**Требования:**

- Аудиофайл (MP3, FLAC и др.) с метаданными Исполнителя и Названия.
- Требуется **Интернет-соединение** (использует api.lyrics.ovh).

**Шаги:**

1. **Запустите аудиофайл** в полноэкранном плеере.
2. Нажмите кнопку **"Лирика"** на верхней панели команд (или в меню команд).
   - *Примечание: Кнопка видна только для аудиофайлов.*
3. Дождитесь завершения поиска.
4. Текст песни отобразится в диалоговом окне с прокруткой.

**Алгоритм поиска:**

1. Приложение ищет по тегам **Исполнитель + Название**.
2. Если теги отсутствуют, пытается извлечь данные из **Имени файла**.

## Автоматический перевод

Автоматический перевод текста с изображений, PDF и текстовых файлов с использованием **Гибридной системы OCR** (Google ML Kit + Tesseract).

**Ключевые особенности:**

- **Гибридный движок:** Использует Google ML Kit для быстрого распознавания латиницы и **Tesseract** для качественного распознавания кириллицы (Русский, Украинский).
- **Оффлайн:** Работает полностью на устройстве (после начальной загрузки моделей).
- **Умное наложение:** Переведенный текст накладывается поверх оригинала удобными для чтения абзацами.

**Настройка:**

1. **Настройки** → **Документы**
2. Включите **"Enable Translation"** (Включить перевод)
3. Выберите **Source Language** (Исходный язык):
   - **"Auto" (Рекомендуется):** Автоматически выбирает лучший движок (Tesseract для кириллицы, ML Kit для остальных).
   - **Конкретный язык:** Принудительно использует модель (например, "Russian" включит Tesseract).
4. Выберите **Target Language** (Целевой язык, например, English).

**Как использовать:**

1. Откройте **Изображение**, **PDF** или **Текстовый** файл.
2. Нажмите на экран, чтобы показать **Панель команд** (Command Panel).
3. Нажмите кнопку **"Перевести"** (иконка A→文).
4. **Первый запуск:**
   - Для ML Kit: Подтвердите загрузку языковой модели (~30МБ).
   - Для Tesseract (Кириллица): Подтвердите загрузку данных OCR (~15МБ).
5. Переведенный текст появится поверх содержимого.

**Примечание:** Инициализация Tesseract (для кириллицы) может занять на 1-2 секунды больше времени, чем ML Kit.
