## Примечание: Доступность функций по версиям

Некоторые функции доступны только в определённых версиях приложения. Таблица ниже выведена из [FLAVOR_MATRIX.md](FLAVOR_MATRIX.md), который генерируется из самой сборки; XR / noLegal оставлены одной колонкой, потому что зависят от аппаратуры шлема и sideload-правил сборки.

| Функция | Standard | Lite | Photos | Legacy | XR / noLegal |
|---------|----------|------|--------|--------|--------------|
| Сетевые папки (SMB, SFTP, FTP) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Облачные хранилища (Google Drive, OneDrive, Dropbox) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Воспроизведение аудио и текст песен | ✓ | ✓ | ✗ | ✓ | ✓ |
| Фоновое воспроизведение аудио | ✓ | ✗ | ✗ | ✓ | ✓ |
| Трансляции (интернет-радио, RTSP, HLS/DASH) | ✓ | ✗ | ✗ | ✓ | ✓ |
| Просмотр документов (PDF, Текст) | ✓ | ✗ | ✗ | ✓ | ✓ |
| Читалка EPUB | ✓ | ✗ | ✗ | ✓ | ✓ |
| Перевод и OCR | ✓ | ✗ | ✗ | ✓ | ✓ |
| Редактирование изображений | ✓ | ✓ | ✓ | ✓ | ✓ |
| Режим домашнего экрана (лаунчер) | ✓ | ✗ | ✗ | ✗ | ✓ |

Режим домашнего экрана - единственная строка, где объединённая последняя колонка распадается: он есть в сборке **noLegal** для sideload, но отсутствует в сборке VR/XR, где своё домашнее окружение предоставляет сам шлем.

Для аудио две строки, потому что это два разных решения сборки: **Lite воспроизводит локальные аудиофайлы**, включая текст песен, но останавливается, когда приложение уходит из активного окна - службы фонового воспроизведения там нет. Экрана «Трансляции» в Lite нет вовсе, поэтому радио и HLS/DASH/RTSP там не ограничены, а отсутствуют.

Если функция отмечена как "✗", выбирайте **Standard** или **XR / noLegal** в зависимости от аппаратуры и канала распространения.

## Домашний медиацентр, TV и сценарии для гостиной

## Превратите NAS в медиаполку для гостиной

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Быстрый путь**

1. Добавьте NAS как SMB-ресурс.
2. Запустите **Scan Network**, если не хотите вводить IP вручную.
3. Откройте ресурс с TV box, планшета или телефона.
4. Начните просматривать видео, фото или документы прямо с NAS.

**Разбор сценария**

- Держите один SMB-ресурс для всей семейной медиатеки и разделяйте дочерние папки по назначению: фильмы, семейные фото, сканы, инструкции.
- Один раз запустите **Test Connection** при настройке, чтобы ресурс был стабильным ещё до использования с дивана.
- Если NAS используется с TV box, сразу добавьте Bluetooth-клавиатуру или пульт для быстрой навигации.
- Если просмотр кажется медленным, сначала откройте настройки ресурса и запустите встроенную проверку скорости.

**Когда это особенно полезно**

- Вам нужен один центральный источник медиа вместо копирования одних и тех же файлов на несколько устройств.
- Вы хотите, чтобы одна библиотека работала и для слайд-шоу, и для чтения документов, и для воспроизведения.

**Избегайте этого**

- Не начинайте с отладки hostname. Сначала используйте IP-адрес, а оптимизируйте позже.
- Не ожидайте SMB в сборке Lite - в ней вообще нет сетевых источников.

## Запустите слайд-шоу с фоновой музыкой для комнаты

**Доступно в:** Standard, Lite, Legacy, XR / noLegal (в Photos нет поддержки аудио)

**Быстрый путь**

1. Добавьте один источник изображений и один источник музыки.
2. В **Настройки → Медиа → Изображения** включите **Музыка во время слайдшоу**.
3. Выберите музыкальный ресурс.
4. Откройте папку с фото и нажмите **Play**.

**Разбор сценария**

- Для самых плавных переходов используйте локальную папку с изображениями или быстрый NAS.
- Держите отдельный музыкальный ресурс со спокойными треками, если хотите предсказуемый фон.
- Если в папке есть и изображения, и видео, помните: музыка автоматически ставится на паузу, когда начинается видео.

**Когда это особенно полезно**

- Вы хотите превратить TV box, планшет или старый телефон в цифровую рамку для комнаты.
- Вам нужен один setup для показа семейных фото, ивентовых подборок или тревел-альбомов без ручной сборки очереди.

**Избегайте этого**

- Не используйте очень медленный сетевой ресурс одновременно и для изображений, и для музыки, если важна плавность.

## Иммерсивный кинотеатр OpenXR VR

**Доступно в:** Standard, Lite, Legacy, `vr`, noLegal (single-eye 3D); `vr` и noLegal (полное погружение в шлеме - обе сборки несут иммерсивный вид, и он открывается, когда приложение видит OpenXR-шлем и включён общий переключатель VR)

**Быстрый путь - включить, настроить, смотреть 3D**

1. **Single-eye 3D (на любом флейворе, включать не нужно):** откройте любой файл SBS/OU/180°/360° - формат определится автоматически и обрежется до одного глаза, чтобы нормально смотреться на обычном плоском экране. Управляется через **Настройки > Воспроизведение > "Показывать 3D-контент с одного глаза"** (включено по умолчанию). Чтобы задать формат вручную вместо авто-определения, откройте диалог Control в плеере на сборке `vr`/XR-noLegal и выберите режим на вкладке 3D - **Auto-detect**, **Side-by-Side (SBS)**, **Over-Under (OU)** или **Mono (Disabled)**; выбор запоминается для этого файла.
2. **Полное погружение на Quest (сборка `vr` или XR/noLegal):** в шлеме нажмите на бейдж VR в плеере, пока открыт 3D-файл, выберите **Open in VR Cinema** в меню файла в Browse, либо откройте **Settings > Media** и нажмите **Test Immersive**, чтобы попробовать пример. Любой из трёх способов открывает per-eye OpenXR-вид этого контента.
3. **Смотрите:** внутри иммерсивного вида управление собрано на полосе HUD - полоса позиции, которую вы тянете лучом контроллера, чтобы перемотать (рядом показаны прошедшее и общее время), и те переключатели, которые применимы к этому файлу: звуковая дорожка только при нескольких дорожках, субтитры только когда они есть, глубина стерео только для стереоконтента. По краям полосы - **СКРЫТЬ** и **ВЫХОД**; скрытая полоса исчезает полностью, а нажатие триггера возвращает её, не задевая то, что под ней. Стик перематывает шагами по 10 секунд; удерживая **grip** и толкая стик, вы переходите между файлами - следующий и предыдущий идут по всему списку ресурса, а не по одному открытому файлу. При первом входе в иммерсивный режим после установки шлем показывает легенду со всеми назначениями контроллера; любое нажатие закрывает её, а кнопка **ПОМОЩЬ** на полосе возвращает её в любой момент.

**Разбор сценария**

- Single-eye 3D вообще не требует шлема - это самый простой способ пересмотреть старые SBS/OU-записи на телефоне или планшете.
- Для полного погружения нужен шлем Quest или другой OpenXR-шлем и сборка, которая его несёт, - `vr` либо XR/noLegal sideload (см. [Установка VR через sideload](VR_SIDELOAD_RU.md)).
- Фото и видео 360°/180° внутри иммерсивного вида рендерятся как сфера/полусфера вокруг вас; плоские 2D-файлы просто воспроизводятся плоско.

**Когда это особенно полезно**

- Вы хотите пересмотреть архивные записи SBS/OU/360°/180° без отдельного VR-плеера.
- У вас есть Quest, и вы хотите попробовать полное погружение на своих файлах уже сегодня, принимая, что навигация пока только вперёд/назад.

**Избегайте этого**

- Не ожидайте, что сборка `vr` для Meta Horizon Store / Google Play уже входит в иммерсивный режим - эта часть ещё в разработке.
- Перемотка, выбор дорожки и субтитров, глубина стерео - всё это на полосе HUD в шлеме. Файловых операций там нет: копировать, переместить или удалить возвращайтесь к плоской панели.

## Интернет-радио на автомагнитоле или медиаплеере

**Доступно в:** Standard, Legacy, XR / noLegal - в Lite и Photos экран Трансляций отсутствует

**Быстрый путь**

1. Откройте раздел **Трансляции** через главное меню (выпадающий список) или через **Настройки > Медиа > Трансляции**.
2. Нажмите **«⋮»** в конце панели команд → **«Добавить»** → введите URL радиостанции или видеопотока.
3. Или **«⋮»** → **«Импорт по URL»** → введите URL .m3u-плейлиста.
4. Нажмите на источник - радио заиграет в списке через мини-панель внизу.
5. Закрепите любимые станции наверху через долгое нажатие → **«Закрепить»**.

**Разбор сценария**

- ICY-метаданные показывают название станции и текущий трек в мини-панели - список остаётся прокручиваемым и интерактивным.
- Две маленькие иконки справа от поля поиска делят радио и видео одним касанием: нажмите значок аудио или видео, чтобы оставить только этот тип, нажмите горящий значок повторно - вернётся весь список.
- Переключите вид на **Сетку** в панели инструментов Трансляций, чтобы увидеть каналы плитками с последним захваченным кадром - удобно для быстрого просмотра видеопотоков. Выбор (список или сетка) запоминается при следующем открытии Трансляций.
- Если поток поддерживает трансляцию и телефон в той же Wi-Fi сети, нажмите **Cast** в плеере, чтобы отправить его на Chromecast. RTSP-потоки транслировать нельзя.
- Видео и RTSP-потоки открываются в полноэкранном плеере; «Назад» возвращает в список с сохранённой прокруткой.
- Фильтр по категории и языку: нажмите иконку фильтра, выберите категорию и/или язык из списка с флагами.
- При отключённом фоновом воспроизведении трансляция останавливается при сворачивании - поведение настраивается в **Настройки > Воспроизведение > Фоновое воспроизведение аудио**.
- Импорт каталога проверенных станций: зайдите в **Расширения** или при первом запуске выберите трансляции в онбординге.
- Трансляцию, добавленную вручную, можно отправить на часы Wear OS: откройте меню **⋮** у строки и нажмите **«Передать на часы»** (команда видна при включённой опции Wear Companion). Переданная станция переживает обновление каталога на часах; если её адрес позже появится в онлайн-каталоге, каталожная запись её заменит.

**Когда это особенно полезно**

- Android-магнитола или медиаплеер в машине: кнопки руля управляют паузой без касания экрана.
- Замена TuneIn, Shoutcast, Online Radio, RadioDroid, VLC сетевых потоков или IPTV-плееров.

**Избегайте этого**

- Не используйте сборки Lite и Photos для Трансляций: в них нет входа в этот раздел, поэтому ни один протокол там не работает.
- Не ожидайте сохранения позиции воспроизведения - потоки динамические.

## Поездки, чтение и документы

## Подготовьте папку для поездки без стабильного интернета

**Доступно в:** Standard, Lite, Photos, Legacy, XR / noLegal (для чтения PDF и EPUB нужны Standard, Legacy или XR / noLegal)

**Быстрый путь**

1. Создайте или выберите одну локальную папку для поездки.
2. Скопируйте туда нужные медиа, PDF, EPUB и заметки ещё до выхода из Wi-Fi.
3. Один раз откройте эту папку в FastMediaSorter, чтобы подготовились миниатюры и последние позиции.
4. Используйте папку офлайн в дороге.

**Разбор сценария**

- Храните тревел-набор в одной локальной папке, даже если оригиналы обычно живут на NAS или в облаке.
- Намеренно смешивайте форматы: посадочные PDF, EPUB для чтения, скриншоты и офлайн-музыку можно держать рядом.
- Используйте фильтр, если хотите быстро переключаться между изображениями, документами и аудио без интернета.

**Когда это особенно полезно**

- Самолёты, поезда, гостиницы и сельские зоны, где облачный стриминг ненадёжен.
- Ситуации, где нужен один офлайн-пакет вместо поиска по нескольким приложениям.

**Избегайте этого**

- Не оставляйте проверку офлайн-открытия файлов на последний момент.

## Читайте облачные документы и EPUB в дороге

**Доступно в:** Standard, Legacy, XR / noLegal - в Lite и Photos документы и EPUB не открываются вовсе; в Lite дополнительно нет облачных хранилищ

**Быстрый путь**

1. Добавьте облачного провайдера через **Cloud Storage**.
2. Откройте папку с PDF или EPUB.
3. Нажмите файл прямо в облачном ресурсе.
4. Позже продолжайте чтение с последней сохранённой позиции.

**Разбор сценария**

- Это удобно, когда рабочие документы уже лежат в Google Drive, OneDrive или Dropbox, и вам не нужен отдельный reader workflow.
- PDF лучше подходит для билетов, инструкций и сканов с фиксированной вёрсткой.
- EPUB удобнее для длинного чтения, где важнее размер шрифта и навигация по главам, чем жёсткая раскладка страницы.

**Когда это особенно полезно**

- Вы переключаетесь между рабочими документами и личным чтением, не выходя из приложения.
- Вы держите дорожные или клиентские файлы в облаке, но хотите более читательский интерфейс.

**Избегайте этого**

- Не ожидайте облачное чтение в Lite - в этой сборке нет ни облака, ни поддержки документов. В Photos и Legacy облако есть, но документы открывает только Legacy.
- Не считайте медленный мобильный интернет гарантированным решением для очень больших файлов.

## Переводите вывески, сканы и скриншоты через OCR

**Доступно в:** Standard, Legacy, XR / noLegal

**Быстрый путь**

1. Откройте изображение, PDF или текстовый файл.
2. Покажите панель команд.
3. Нажмите **Translate**.
4. При первом запуске подтвердите загрузку модели, если это потребуется.

**Разбор сценария**

- Для латиницы приложение обычно начинает с ML Kit ради скорости.
- Для материалов с кириллицей приложение может переключиться на Tesseract ради лучшего качества распознавания.
- Скриншоты, чеки, меню и сканы работают особенно хорошо, если исходный текст достаточно чёткий.

**Когда это особенно полезно**

- Вы в поездке, читаете иностранные инструкции или разбираете скриншоты из чатов и приложений.
- Вам нужен перевод прямо поверх контента, а не отдельная цепочка copy-paste в другой инструмент.

**Избегайте этого**

- Не оценивайте качество OCR по размытому ночному фото или неудачно обрезанному скану.

## Передавайте сетевые файлы в специализированные приложения

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Быстрый путь**

1. Откройте файл из SMB, SFTP или FTP.
2. Нажмите **ⓘ Info**.
3. Нажмите **Download and Open**.
4. Выберите нужное приложение в Android chooser.

**Разбор сценария**

- Этот сценарий полезен, когда FastMediaSorter удобнее всего как браузер удалённого хранилища, а другое приложение лучше подходит для конкретного формата.
- Типичные handoff-кейсы: офисные документы, сложные PDF, видео с тяжёлыми кодеками и нишевые медиаформаты.
- Загруженная копия остаётся в `Downloads`, поэтому к ней можно вернуться, даже если удалённый источник позже недоступен.

**Когда это особенно полезно**

- Вам нужен один центр для удалённых файлов, но без отказа от лучших специализированных инструментов.

**Избегайте этого**

- Не ожидайте такой же flow для облачных файлов прямо сейчас.

## Быстрые вычисления из текста и OCR

**Доступно в:** Standard, Legacy, XR / noLegal

**Быстрый путь**

1. Откройте любой PDF-документ, EPUB-книгу, текстовый файл или запустите перевод OCR на изображении.
2. Выделите долгим нажатием любой блок текста, содержащий числа или математические выражения.
3. В появившемся контекстном меню выберите пункт **Калькулятор**.
4. Встроенный калькулятор мгновенно вычислит математическую формулу в плавающем окне.

**Разбор сценария**

- Выберите строку текста, содержащую числа со знаками операций (например, `(45 + 12) * 3`) в PDF или в результатах OCR-перевода.
- Используйте встроенные научные функции калькулятора (тригонометрию, корни, степени, логарифмы) для сложных вычислений.
- Калькулятор сохраняет историю вычислений между сеансами и поддерживает регистры памяти (M+/M-/MR/MC) для быстрого отслеживания данных.

**Когда это особенно полезно**

- Вы читаете техническую документацию, скан скриншота или книгу и вам нужно быстро решить формулы или просуммировать цены/числа без переключения в отдельное приложение калькулятора.

**Избегайте этого**

- Не пытайтесь вычислять чисто буквенные строки; парсер распознаёт только корректные числа, скобки и математические операторы.

## Облачные заметки Markdown и код

**Доступно в:** Standard, Photos, Legacy, XR / noLegal (локально, по сети и в облаке); Lite (только локальные папки)

**Быстрый путь**

1. Перейдите в любую локальную папку, сетевой ресурс (SMB), FTP/SFTP или облачный диск (Google Drive).
2. Нажмите кнопку **Новая заметка (📝)** на панели инструментов папки.
3. Введите текст во встроенном редакторе. Приложение автоматически подсветит разметку Markdown и синтаксис кода.
4. Нажмите **Сохранить** (или дождитесь автосохранения) для записи изменений прямо на удалённый диск.

**Разбор сценария**

- Ведите файл журнала `.md` на Google Диске или домашнем NAS и редактируйте его с любого устройства напрямую.
- Создавайте новые заметки в ключевых папках с автоматическим разрешением конфликтов имён (например, `Заметка_1.txt`, `Заметка_2.txt`).
- Просматривайте отрендеренный Markdown в режиме чтения или экспортируйте заметки во внешние сервисы, такие как Google Keep.

**Когда это особенно полезно**

- Вы хотите вести простые текстовые заметки, списки задач или хранить фрагменты кода прямо на центральных сетевых или облачных дисках без промежуточного скачивания файлов.

**Избегайте этого**

- Не ожидайте создания файлов в облачных хранилищах на сборке Lite - в ней нет ни облака, ни сетевых источников.

## Сортируйте семейный фотоархив через Quick Sort

**Доступно в:** Standard, Lite, Photos, Legacy, XR / noLegal

**Быстрый путь**

1. Добавьте целевые папки в **Quick Sort**.
2. Откройте исходную папку с несортированными семейными фото.
3. Используйте цифровые кнопки или touch zones во время просмотра.
4. Сразу отправляйте удачные кадры в папки назначения.

**Разбор сценария**

- Создавайте папки по результату, а не только по дате: `Best`, `Print`, `Send to family`, `Archive`.
- Просматривайте в fullscreen, чтобы быстро принимать решение и копировать или перемещать без возврата к списку файлов.
- Если архив разбирают несколько человек, заранее договоритесь о единой схеме папок назначения.

**Когда это особенно полезно**

- У вас накопился backlog после дней рождений, поездок, школьных событий или старых импортов с телефона.
- Вам нужен быстрый triage flow вместо ручного перетаскивания файлов в файловом менеджере.

**Избегайте этого**

- Не начинайте сортировку, пока папки назначения названы неясно.
- Не используйте Move сразу, если ещё не уверены, какие папки станут долгосрочным архивом.

## Захват экрана краевыми жестами

**Доступно в:** Standard, XR/noLegal

**Быстрый путь**

1. Перейдите в **Настройки → Операции → Жесты с краёв экрана → Оверлей жестов** и включите его.
2. При просмотре любого файла проведите пальцем от левого края - откроется меню захвата.
3. Выберите действие - панель закроется, действие выполнится.

**Что умеет панель**

- Сделать **скриншот** текущего экрана - посмотреть, отредактировать, поделиться, отправить в другое приложение или запустить OCR-перевод, плюс вариант тихого захвата.
- **Сфотографировать** камерой, а затем отправить, отредактировать снимок или запустить OCR-перевод, не выходя из приложения.
- Начать запись **экрана**, **видео** или **аудио/голоса** - подробнее в разделах [Запись видео с экрана](#как-записать-видео-с-экрана) и [Запись голосовой заметки](#как-записать-голосовую-заметку).
- **Открыть приложение или панель**, которыми вы часто пользуетесь.
- **Обрезать и поделиться** фрагментом текущего изображения.

**Полезно знать**

- Пока панель включена, свайп от левого края открывает меню захвата, а не листает страницу.
- Панель рассчитана на захват одной рукой во время просмотра - отключите её, если вам важен свайп-листание от левого края.
- При каждом таком захвате или записи Android подтверждает действие - даже для тихого скриншота. Это системная защита, приложение её не отключает.

**Когда это помогает**

- Нужен скриншот, быстрое фото или запись, не отрываясь от просматриваемого файла.

## Подключение сетевого диска (SMB)

**Что нужно:**

- NAS или ПК с Windows с общей папкой
- Оба устройства в одной Wi-Fi сети
- Имя пользователя и пароль для доступа

**Доступно в:** Версии Standard, Photos, Legacy, XR / noLegal

**Шаги:**

1. Нажмите кнопку **"+"** на главном экране
2. Выберите **"Сетевая папка (SMB)"**
3. Заполните данные:
   - **Авто-обнаружение (New):**
     1. Нажмите **"Сканировать сеть"**
     2. Дождитесь появления устройств в списке
     3. Выберите устройство из списка
     4. IP-адрес заполнится автоматически

   - **Ручной ввод:**

     ```
     Сервер/Путь: \\192.168.1.100\photos
     Имя пользователя: john
     Пароль: ****
     Имя для отображения: Home NAS (необязательно)
     ```

4. Нажмите **"Тест соединения"** для проверки
5. Нажмите **"Сохранить"**

**Форматы адреса сервера:**

- Windows: `\\192.168.1.100\share`
- Linux/Mac: `smb://192.168.1.100/share`
- С портом: `smb://192.168.1.100:445/share`

**Советы:**

- Используйте IP-адрес (а не имя хоста) для надёжности
- Включите SMB v2/v3 на NAS для безопасности
- Порт SMB по умолчанию: 445

**Устранение неполадок:**
→ См. [TROUBLESHOOTING_RU.md](TROUBLESHOOTING_RU.md)

## Подключение SFTP/FTP сервера

**Что нужно:**

- Сервер с включенным SSH (SFTP) или FTP
- Открытый порт 22 (SFTP) или 21 (FTP)
- Имя пользователя и пароль (или ключ для SFTP)

**Шаги:**

1. Нажмите кнопку **"+"** на главном экране
2. Выберите **"SFTP / FTP"**
3. Выберите протокол: **SFTP** или **FTP**
4. Заполните данные:

   ```
   Хост: 192.168.1.100
   Порт: 22 (SFTP) / 21 (FTP)
   Имя пользователя: username
   Пароль: ****
   Удаленный путь: /home/user/photos (необязательно)
   ```

5. Нажмите **"Подключиться"**

**Дополнительно:**

- **Аутентификация по SSH-ключу:** В настоящее время не поддерживается (только пароль)
- **Свой порт:** Измените номер порта, если сервер использует нестандартный

**Устранение неполадок:**
→ См. [TROUBLESHOOTING_RU.md](TROUBLESHOOTING_RU.md)

## Импорт папки с компаньона Windows

**Что это:** компаньон - функция [Fast Media Sorter for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/) (ранее FastMediaSorter LITE), бесплатного сортировщика медиа от того же автора. Она открывает выбранные папки ПК по SFTP и экспортирует готовое подключение - без ручной настройки сервера и без ввода хоста/порта/ключа на телефоне. Перенести на телефон можно, **отсканировав QR-код** на экране ПК или **импортировав файл `.fmscfg`**.

**Доступно в:** Standard, Photos, Legacy, XR/noLegal (для скана штрихкода нужна камера; способ с файлом работает везде, включая VR)

> Хотите пошаговую версию со скриншотами? См. руководство-сценарий [Откройте папки ПК сканом кода](howto/scenario-companion-share-ru.md).

**Где взять Fast Media Sorter for Windows:**

- Сайт: [serzhyale.github.io/FastMediaSorter_Lite](https://serzhyale.github.io/FastMediaSorter_Lite/)
- Публикация папок (инструкция): [Как опубликовать папки ПК для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)
- GitHub: [последний релиз](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases/latest) (установщик или портативный ZIP)
- winget: `winget install SerZhyAle.FastMediaSorter`
- Microsoft Store: поиск «FastMediaSorter LITE» (в Store программа под прежним именем)

**На ПК:**

1. Установите и запустите **Fast Media Sorter for Windows**, откройте вкладку **Share** в настройках.
2. Выберите папку(и) для доступа - программа сама поднимет SFTP-сервер, создаст ключи и настроит автозапуск.
3. Она покажет на экране **QR-код**. Также можно нажать **Save .fmscfg**, если удобнее файл.

**На телефоне - способ A, скан кода (самый быстрый):**

1. **Нажмите кнопку "+"** на главном экране.
2. Нажмите **«Импорт по штрихкоду»** - она рядом с четырьмя карточками типов ресурса и в шапке формы SFTP.
3. Наведите камеру на QR-код на ПК (в тёмной комнате нажмите **Фонарик**) и подтвердите диалог **«Импорт доступа»**.
4. Готово - для каждой общей папки появится ресурс только для чтения, ключ сервера будет закреплён автоматически.

**На телефоне - способ B, импорт файла:**

1. На ПК нажмите **Save .fmscfg** и передайте файл на телефон (email, Telegram или общая папка).
2. **Нажмите "+"** -> **«SFTP / FTP»** -> **«Импорт из файла»** и укажите файл `.fmscfg`. Если файл пришёл вложением в Telegram/email, просто нажмите на вложение.
3. Подтвердите диалог **«Импорт доступа»** - появятся ресурсы только для чтения.

**Важно:** и QR-код, и файл конфигурации содержат пароль доступа - обращайтесь с ними как с ключом, не публикуйте скриншот и файл. Пункт **«Импорт по штрихкоду»** скрыт на устройствах без камеры и на VR-гарнитурах - там используйте способ B.

## Проверка скорости сети

**Поддерживается для:** SMB, SFTP, FTP, Cloud (Google Drive)

**Автоматическая проверка:**
При добавлении нового сетевого ресурса приложение автоматически запускает тест скорости в фоновом режиме. Результаты (скорость чтения/записи) сохраняются в настройках ресурса.

**Ручная проверка:**

1. Перейдите в **Управление ресурсами**
2. Редактируйте сетевой ресурс (значок карандаша)
3. Прокрутите вниз
4. Нажмите кнопку **"Скорость"**
5. Подождите ~15 секунд ("Анализ скорости..")
6. Результаты:
   - **Скорость чтения (Мбит/с)**
   - **Скорость записи (Мбит/с)**
   - **Рекомендуемые потоки** (для оптимальной производительности)

## Использование сенсорных зон

Экран разделен на 9 невидимых областей для быстрых действий:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПИЯ  │ ПЕРЕИМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │

├─────────┼─────────┼─────────┤
│ КОМАНДЫ │ УДАЛИТЬ │ ИГРАТЬ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. **НАЗАД** - Вернуться к списку
2. **КОПИЯ** - Копировать в папку
3. **ПЕРЕИМ.** - Переименовать файл
4. **ПРЕД.** - Предыдущий файл
5. **ПЕРЕМ.** - Переместить в папку
6. **СЛЕД.** - Следующий файл
7. **КОМАНДЫ** - Открыть меню
8. **УДАЛИТЬ** - Удалить файл
9. **ИГРАТЬ** - Старт/Стоп слайд-шоу

**Включить наложение (рекомендуется для новичков):**

1. Настройки → Воспроизведение

**Попробуйте:**

3. **Нажмите верхний левый угол** → Предыдущий файл

**Отключить, если не нужно:**
Настройки → Воспроизведение → "Всегда показывать сетку сенсорных зон" = ВЫКЛ

**Устранение неполадок:**

- Если музыка не воспроизводится: Проверьте, что музыкальный ресурс содержит хотя бы один аудиофайл
- Если музыка прерывается в сети: Используйте локальную папку или более быстрое сетевое соединение
- Для музыки по SMB: Убедитесь, что SMB-ресурс использует протокол `file://` (см. [TROUBLESHOOTING_RU.md](TROUBLESHOOTING_RU.md))

## Как работать с папками (выделение, копирование, перенос)

Когда субкаталоги показаны в списке отдельными элементами, строка папки ведёт себя как строка файла.

**Включить показ папок:** **Настройки** → **Общие** → **Показывать подпапки отдельно**. Тот же переключатель есть у каждого ресурса в его редакторе.

**Шаги:**

1. Нажмите галочку у строки папки или сделайте долгое нажатие, чтобы выделить одну папку. Одиночный тап по-прежнему открывает папку.
2. Через меню **⋮** у строки или панель действий выберите **Копировать**, **Перенести**, **Переименовать** или **Удалить**.
3. Выберите приёмник. Файлы и папки из одного выделения обрабатываются одной операцией.
4. У приёмника создаётся вся структура - каждая вложенная папка и файл внутри исходной.

**Между разными типами ресурсов:** папку можно скопировать или перенести между устройством, SMB, SFTP, FTP и облаком - структура воссоздаётся на принимающей стороне.

**Что отклоняется и почему:** приёмник внутри самой папки или её текущее расположение отклоняются до начала копирования; каталог, выбранный системным диалогом и не имеющий обычного файлового пути, папки принять не может. Сообщение называет причину, чтобы вы выбрали другой приёмник.

**Отмена:** операция над папкой показывает прогресс и останавливается по требованию. Всё, что уже записано, остаётся у приёмника - проверьте папку перед повторным запуском. При переносе элемент удаляется у источника только после успешной записи, поэтому потерять его нельзя.

**Отправка в фоновый режим:** не обязательно сидеть и наблюдать за диалогом прогресса. Закройте его - перенос продолжится и останется виден в Обзоре полосой внизу экрана с названием операции, процентом выполнения и текущим файлом. Нажмите на эту полосу, чтобы вернуть диалог прогресса целиком, включая отмену.

## Автоматический перевод

Автоматический перевод текста с изображений, PDF и текстовых файлов с использованием **Гибридной системы OCR** (Google ML Kit + Tesseract).

**Ключевые особенности:**

- **Гибридный движок:** Использует Google ML Kit для быстрого распознавания латиницы и **Tesseract** для качественного распознавания кириллицы (Русский, Украинский).
- **Оффлайн:** Работает полностью на устройстве (после начальной загрузки моделей).
- **Умное наложение:** Переведенный текст накладывается поверх оригинала удобными для чтения абзацами.

**Настройка:**

1. **Настройки** → вкладка **Медиа** → **Другое**
2. Включите **"Включить перевод"**
3. Выберите **Source Language** (Исходный язык):
   - **"Auto" (Рекомендуется):** Автоматически выбирает лучший движок (Tesseract для кириллицы, ML Kit для остальных).
   - **Конкретный язык:** Принудительно использует модель (например, "Russian" включит Tesseract).
4. Выберите **Target Language** (Целевой язык, например, English).

**Как использовать:**

1. Откройте **Изображение**, **PDF** или **Текстовый** файл.
2. Нажмите на экран, чтобы показать **Панель команд** (Command Panel).
3. Нажмите кнопку **"Перевести"** (иконка A→文).
4. **Первый запуск:**
   - Для ML Kit: Подтвердите загрузку языковой модели (~30МБ).
   - Для Tesseract (Кириллица): Подтвердите загрузку данных OCR (~15МБ).
5. Переведенный текст появится поверх содержимого.

**Примечание:** Инициализация Tesseract (для кириллицы) может занять на 1-2 секунды больше времени, чем ML Kit.

## Умные виджеты домашнего экрана

**Доступно в:** во всех версиях - набор виджетов есть в каждой сборке; каждый виджет следует своей возможности, поэтому виджет записи голоса требует сборки с поддержкой микрофона (не Lite и не Photos), а виджеты фоторамки и ресурсов работают везде

**Быстрый путь**

1. Перейдите на домашний экран Android, зажмите его и выберите пункт **Виджеты**.
2. Перетащите нужный виджет **FastMediaSorter** (например, иконку 1×1 «Быстрый диктофон» или «Camera OCR») на экран.
3. Настройте папку сохранения и параметры захвата, затем нажмите **Сохранить**.
4. Нажимайте виджет для мгновенного выполнения задачи прямо с рабочего стола.

**Разбор сценария**

- Используйте виджеты 1×1 как быстрые ярлыки для мгновенного выполнения фоновых действий (например, одно нажатие начинает запись голоса, повторное - сохраняет её в ресурс на NAS).
- Добавьте виджет **Задачи по расписанию** для мониторинга фонового копирования или запуска всех задач одной кнопкой.
- Разместите виджет **Случайный кадр** для показа сменяющихся семейных фотографий напрямую из сетевой папки SMB.

**Когда это особенно полезно**

- Вам нужны быстрые ярлыки на рабочем столе для ежедневной съёмки (чеки, квитанции, голосовые заметки) без открытия основного интерфейса приложения.
- Вам нужны наглядные виджеты для управления воспроизведением или быстрого отслеживания расписания резервного копирования.

**Избегайте этого**

- Не пытайтесь добавлять виджеты, если лаунчер вашего Android-устройства блокирует создание кастомных виджетов сторонними приложениями.

## Как использовать приложение как домашний экран

FastMediaSorter может заменить домашний экран устройства собственным рабочим столом - ваши папки, часы, погода, приложения и панель задач вдоль края. Если вы когда-нибудь работали за рабочим столом Windows, всё будет знакомо: вещи лежат там, куда вы их положили, а кнопка «Пуск» открывает меню. Это режим лаунчера, и он есть только в сборках **Standard** и **noLegal**.

**Включение:**

1. Откройте **Настройки → Общие** и включите **«Лаунчер: сделать приложение домашним экраном»**.
2. Android попросит подтверждение. На Android 10 и новее это один вопрос - «Разрешить FastMediaSorter быть приложением главного экрана?» - просто разрешите. На версиях постарше знакомый выбор появится при следующем нажатии «Домой»: выберите FastMediaSorter и нажмите **«Всегда»** либо **«Только сейчас»**, если пока хотите просто попробовать.
3. Нажмите «Домой». Появится рабочий стол, уже заполненный примерно десятком полезных вещей - часы, погода, ваши папки, строка поиска - так что в первый день это не пустая сетка.

При свежей установке есть короткий путь: отметьте **«Использовать как домашний экран»** на первой странице приветствия. Настройку это не прерывает системным диалогом - подтверждение Android появится, когда вы впервые после этого откроете **Настройки → Общие**.

**Что живёт на рабочем столе:**

| Тип ячейки | Что делает |
|-----------|--------------|
| Ярлык ресурса | Открывает добавленную вами папку - причём вы сами выбираете, откроется ли она в режиме просмотра, слайд-шоу или воспроизведения |
| Гаджет | Часы с секундами (тап открывает будильники), погода в вашем городе, что играет прямо сейчас, переводчик и ещё два десятка других |
| Ярлык приложения | Запускает любое установленное приложение; долгое нажатие показывает быстрые действия этого приложения |
| Ячейка контакта | Открывает карточку человека, звонит ему, отправляет SMS или открывает переписку в мессенджере |
| Виджет приложения | Те же виджеты, что приложение предлагает для домашнего экрана Android, только размещённые здесь |

**Панель задач и меню «Пуск»:**

- Панель задач идёт вдоль нижнего края и содержит кнопку «Пуск», недавно открытые приложения, закреплённые вами и небольшой лоток с часами, батареей, сетью и сигналом SIM.
- Хотите её сверху? **Настройки → Общие → Настройки системного лаунчера → Панель задач → Расположение панели задач** переключает между значениями **«Снизу»** и **«Сверху»**. Меню «Пуск» следует за панелью и раскрывается сверху вниз, когда панель наверху.
- Кнопка «Пуск» открывает меню: открыть FastMediaSorter, ваши ресурсы, добавить ресурс, настройки Android, настройки приложения, настройки лаунчера, редактировать содержимое стола, а в конце - перезагрузка, выключение и **«Выйти из режима лаунчера»**. Перезагрузка и выключение сработают, только если устройство разрешает такое обычному приложению - на большинстве телефонов они просто ничего не сделают.

**Ваши приложения:** сетка приложений группирует их по секциям, у каждой - небольшой заголовок. Нажмите на заголовок, чтобы свернуть редко нужную секцию; свёрнутые заголовки прижимаются друг к другу, так что стол становится короче, а не оставляет дыры. Свежий стол разделяет засеянные приложения надвое: секция **Google** - для приложений Google, которые у вас уже установлены, секция **Приложения** - для ваших собственных: мессенджеров, игр и всего остального, что вы поставили на устройство. Ни одно приложение не попадает в обе. Долгое нажатие на любом приложении в списке даёт **«На рабочий стол»** и **«Закрепить на панели задач»**.

**Как переставлять:**

- Нажмите и удержите пустой квадрат рабочего стола. Появятся четыре пункта: **«Добавить элемент..»**, **«Редактировать стол»**, **«Обои»**, **«Настройки лаунчера»**. Новая ячейка встанет ровно на тот квадрат, который вы нажали.
- **«Добавить элемент..»** открывает выбор: приложение, функция, одна из ваших папок, радиопоток, человек, системное действие, запланированная операция, гаджет или действие. Среди гаджетов - карточка «сейчас играет» (показывает, что играет на устройстве, и одним касанием открывает нужный плеер) и ячейка переводчика.
- **«Редактировать стол»** включает режим редактирования - то же самое, что «Редактировать содержимое стола» в меню «Пуск». В режиме редактирования: тяните ячейку, чтобы передвинуть, тяните угловой маркер гаджета, чтобы изменить размер, нажимайте **+**, чтобы добавить, и выбирайте **«Убрать с рабочего стола»** на ячейке, чтобы её убрать. Закончив, нажмите **«Готово»**.
- Пользуетесь устройством не одни? Включите **«Заблокировать рабочий стол»** в настройках лаунчера - тогда долгое нажатие ничего не делает и раскладку нельзя сдвинуть случайно.
- Другие приложения могут закреплять здесь свои ярлыки точно так же, как на любом другом домашнем экране.

**Портрет и ландшафт - два отдельных рабочих стола.** То, что вы разложили вертикально, не появится, когда вы повернёте устройство: у каждой ориентации своя раскладка и свои свёрнутые секции. Приложение скажет об этом один раз - когда вы впервые повернёте стол, который уже успели разложить. Сами настройки - расположение панели задач, плотность, заставка - общие для обеих.

**Чтобы помещалось больше или меньше:** **Настройки → Общие → Настройки системного лаунчера → Рабочий стол лаунчера → Плотность сетки** предлагает **«Свободная»**, **«Стандартная»**, **«Плотная»** и **«Очень плотная»** - просторнее ячейки или больше ярлыков на экран.

**Возврат к прежнему домашнему экрану** - любым из трёх способов:

- Откройте меню «Пуск», выберите **«Выйти из режима лаунчера»** и подтвердите.
- Выключите **«Лаунчер: сделать приложение домашним экраном»** в **Настройки → Общие**.
- Или сразу откройте собственный список домашних приложений Android: **Настройки → Общие → Настройки системного лаунчера → Система → Сменить домашний экран**.

Раскладка рабочего стола сохраняется в любом случае, так что при повторном включении режима она вернётся ровно такой, какой вы её оставили.

**Одно честное предупреждение.** Некоторые устройства отказываются запоминать выбор. Дешёвые автомагнитолы и другие встроенные Android-коробки при каждом включении возвращают свой заводской домашний экран, что бы вы ни выбрали. Это прошивка устройства перебивает ваш выбор, а не ошибка приложения, и обойти это не может ни одно приложение. Если ваше устройство ведёт себя так, выберите FastMediaSorter домашним приложением ещё раз после перезагрузки - а если выбор всё равно не держится, значит, устройство этого просто не позволяет.

## Использование FMS на Android TV-приставке

FastMediaSorter работает на любой Android TV-приставке или сет-топ-боксе (Xiaomi Mi Box, Nvidia Shield, Amazon Fire TV, дженерик Android-боксы). Тачскрин не требуется - приложение полностью управляется с пульта ДУ или Bluetooth-клавиатуры.

**Что вам нужно:**

- Android TV-приставка на Android 8.0+ (версии Standard/Lite/Photos) или Android 6.0+ (версия Legacy)
- Пульт ДУ с D-pad или Bluetooth-клавиатура
- Опционально: домашний NAS (SMB), USB-накопитель или SD-карта с медиа

**Навигация с пульта ДУ:**

| Кнопка | Действие |
|--------|----------|
| D-pad Вверх/Вниз/Влево/Вправо | Перемещение фокуса между элементами |
| OK / Enter | Открыть элемент или подтвердить |
| Back | Вернуться на предыдущий экран |
| Backspace | Перейти на папку выше в браузере файлов |
| Красная | Удалить выбранный файл(ы) |
| Зелёная | Копировать выбранный файл(ы) |
| Жёлтая | Переместить выбранный файл(ы) |
| Синяя | Переименовать выбранный файл |
| Channel Up / Channel Down | Предыдущий / следующий файл в плеере |

**Шаги:**

1. Установите приложение из Google Play или sideload APK. Рекомендуется версия Standard.
2. На главном экране нажмите **OK** на кнопке (+) для добавления ресурса.
3. Выберите **Локальная папка** для USB/SD или **Сетевая папка** для подключения к NAS через SMB.
4. После добавления ресурса перейдите в него с помощью D-pad + OK для просмотра файлов.
5. Откройте любое видео, изображение или аудиофайл - плеер полностью управляется с пульта.
6. Для запуска слайд-шоу откройте папку с изображениями и перейдите к кнопке **Слайд-шоу** на панели команд.
7. Для добавления фоновой музыки к слайд-шоу перейдите в **Настройки → Медиа → Изображения**, включите **Музыка во время слайдшоу** и выберите музыкальный ресурс.

**Советы:**

- Удерживайте D-pad Вверх/Вниз для ускоренной прокрутки длинных списков файлов.
- Нажмите **F1** на Bluetooth-клавиатуре для открытия подсказок по горячим клавишам на любом экране.
- Цветные кнопки пульта можно переназначить в **Настройки → Операции → Управление и клавиши**.

## Как записать видео с экрана

**Доступно в:** Standard, XR/noLegal

**Шаги:**

1. Запустите запись из меню на главном экране (**«Видеозапись экрана»**), из панели Quick Launch или действием **«Начать запись экрана»** в меню жестов.
2. Подтвердите системный запрос Android - поделиться всем экраном или только этим приложением. Он появляется при каждой записи, и его нельзя пропустить.
3. В углу экрана появится небольшая плашка **«Идёт запись экрана»** с паузой/продолжением и остановкой. Остановить можно и из уведомления.
4. Нажмите **«Стоп»**, когда закончите.

**Что происходит:**

- Запись захватывает всё, что показывается на экране, включая другие приложения, и звук вместе с видео.
- Готовое видео сохраняется в папку Movies на устройстве.

**Примечание:** Системный запрос Android - это защитный механизм для любой записи экрана, приложение не может его отключить.

## Как записать голосовую заметку

**Доступно в:** Standard, Legacy, XR / noLegal

**Шаги:**

1. Начните запись через пункт **«Запись с диктофона»** в меню, виджет **«Быстрый диктофон»** на главном экране или действие **«Начать запись аудио»** в меню жестов.
2. Говорите - индикатор **«Запись..»** (или плавающая плашка поверх текущего приложения) показывает, что запись идёт.
3. Нажмите **«Остановить и сохранить»** (или ещё раз коснитесь виджета/жеста), чтобы закончить.

**Что происходит:**

- Запись сохраняется в папку для диктофона, выбранную в Настройках, или в папку Recordings на устройстве, если ничего не выбрано.
- Запись через виджет или жест работает даже во время работы в другом приложении - плавающий элемент управления остаётся сверху, чтобы остановить запись, не переключаясь обратно.

**Где задать папку сохранения:** Настройки → Операции → Диктофон.

## Как пользоваться встроенной камерой

**Доступно в:** Standard, Lite, Photos (только фото), Legacy, XR/noLegal

**Шаги:**

1. В Обзоре откройте панель инструментов или меню и нажмите **«Съёмка камерой»** (фото) или **«Записать видео»**.
2. При необходимости переключитесь между **«Фото»** и **«Видео»** прямо на экране камеры.
3. Настройте зум пресетом (0.5x/1x/2x..) или ползунком под ним - они синхронизированы.
4. Нажмите кнопку соотношения сторон и выберите форму кадра - **4:3**, **16:9** или **«На весь экран»**. Меняется сам видоискатель, поэтому кадр на экране совпадает с тем, что сохранится, а выбор запоминается до следующего раза (по умолчанию 16:9).
5. Нажмите кнопку сценария съёмки и выберите, как снимать - обычный, ночь, портрет, селфи, макро, спорт или документ. Макро сразу переходит на отдельный объектив ближнего фокуса, селфи разворачивает камеру на фронтальную, спорт держит выдержку короткой, чтобы движение замерло, а документ рассчитан на съёмку плоских страниц и экранов. В списке только те сценарии, которые устройство действительно умеет, активный назван на кнопке, а ручная смена объектива возвращает камеру в обычный режим.
6. Нажмите кнопку затвора (или записи), чтобы снять. Результат сохранится прямо в ресурс - локальный или сетевой, - который вы просматривали.

**Советы:**

- Коснитесь любой точки в видоискателе, чтобы навести туда фокус и экспозицию - место отмечается небольшим кольцом.
- Действие **«Начать запись видео»** в меню жестов открывает камеру сразу в режиме видео и начинает запись, как только готов предпросмотр - быстро, но этот способ сохраняет запись в папку Movies на устройстве, а не в просматриваемый ресурс.
- Включите **«Геотегирование фото»** рядом с настройками камеры, чтобы встраивать GPS-координаты в каждый снятый JPEG - пока вы не включите это сами, ничего не сохраняется. В **Информации о файле** появятся дата съёмки и точка из EXIF GPS - как ссылка, открывающаяся в картах или браузере.

**Где искать настройки камеры:** Настройки → Операции → Фотографирование.

## Как найти и удалить повторяющиеся файлы

**Шаги:**

1. Откройте папку в Обзоре, затем откройте **меню** (⋮) на панели инструментов.
2. Нажмите **«Найти дубликаты»**, чтобы проверить совпадения самому, или **«Найти и удалить дубликаты»**, чтобы удалить их сразу.
3. Для **«Найти дубликаты»** приложение заранее отмечает все копии, кроме самой старой в каждой группе - поправьте выбор, затем нажмите **«Удалить выбранное»** и подтвердите.
4. **«Найти и удалить дубликаты»** удаляет те же отмеченные копии сразу после сканирования, без подтверждения - сначала используйте «Найти дубликаты», если хотите проверить список перед удалением.

**Очистка по размеру:**

1. В том же меню нажмите **«Удаление по размеру..»**.
2. Выберите **«Меньше чем»** или **«Больше чем»**, укажите размер и нажмите **«Анализировать»**.
3. Проверьте количество файлов и объём, который освободится, затем нажмите **«Удалить файлы»** для подтверждения.

**Примечания:**

- Сканирование сравнивает файлы по содержимому в три прохода - размер, быстрый хеш, затем полная проверка SHA-256, - поэтому переименованные дубликаты тоже находятся.
- Удаление по размеру показывает, сколько места освободится, ещё до удаления; для сетевых и облачных источников корзина не используется, поэтому такое удаление сразу окончательное.

## Как посмотреть статистику использования

**Шаги:**

1. Перейдите в **Настройки → Общие → Сбор статистики** и включите переключатель.
2. Нажмите **«Статистика»** (появляется прямо под переключателем), чтобы открыть панель.

**Что вы увидите:**

- Карточки-сводки: отсортировано файлов, освобождено места, время в плеере.
- Разбивку по типам медиа (фото, видео, аудио, документы..).
- Сворачиваемые разделы с подробностями: операции, съёмка, просмотр, редактирование, источники и общее использование.

**Поделиться отчётом:**

- **«Отправить автору»** открывает почтовое приложение со сводкой во вложении, адресованной разработчику.
- **«Экспорт»** делится той же сводкой через обычное меню «Поделиться» Android, чтобы сохранить её или отправить куда угодно.

**Примечание:** Всё остаётся на вашем устройстве, пока вы сами не отправите или не экспортируете данные - подробности о приватности смотрите в FAQ.

## Как использовать карту памяти или подключённый накопитель

Карта памяти или USB-накопитель, подключённый к телефону, хранит ресурсы точно так же, как встроенная память.

**Шаги:**

1. Откройте **«Добавить ресурс»** и начните добавлять локальную папку. Раздел **«Съёмные носители»** появляется, только пока что-то подключено, и перечисляет каждый том с именем и свободным местом.
2. Нажмите на том. Если приложение не может обратиться к нему по пути, оно объяснит причину и откроет системный выбор папки - выберите там тот же том и дайте доступ к нужной папке.
3. Ресурс появится в списке со значком съёмного носителя, так что ресурс на карте узнаётся с первого взгляда.

**Перенос и копирование:** целые папки переносятся на карту и обратно со всей структурой вложенности - так же, как между устройством и сетевым ресурсом.

**Если места не хватает:** копирование или перенос, который не помещается, отклоняется до начала, и в сообщении названы носитель и объём нехватки - освободите место или выберите другое назначение.

**Если носитель извлечён:** его ресурсы помечаются недоступными, а не удаляются. Подключите карту снова - они заработают без повторной настройки.

**На Android 6:** система не сообщает приложениям о подключённых томах, поэтому раздел съёмных носителей на таких устройствах остаётся пустым.

## Как переподключить папку, добавленную прямым путём

Папка, добавленная вводом пути, может показывать фотографии, видео и музыку, но ни одного документа. Это не пропущенное сканирование: магазинная сборка читает текстовые файлы, PDF и электронные книги только из папки, подключённой системным выбором. Переподключение направляет тот же ресурс на ту же папку через этот выбор, и документы появляются.

**Шаги:**

1. Нажмите меню из трёх точек на карточке папки в главном списке.
2. Выберите **Переподключить ресурс**. Откроется системный выбор папки, по возможности сразу в нужной папке.
3. Выберите ту же папку и подтвердите.
4. Если выбрана другая папка, приложение назовёт обе и спросит, прежде чем что-либо менять.

**Что сохраняется:** имя, место в списке, PIN, иконка, роль в быстрой сортировке, избранное и расписания - ресурсу меняют адрес, а не создают его заново.

**Где пункта не будет:** в сборках, которые по-прежнему читают папки по прямому пути, и на Android 10 и старше - там ничего не пропадает.

## Как выбрать папку для снимков и загрузок

Фото со встроенной камеры, скриншоты, сохранённые кадры видео и файлы, скачанные автоматически, каждый раз пишутся в выбранную вами папку - и эта папка не обязана быть одним из ваших ресурсов.

**Шаги:**

1. Откройте настройку того, что сохраняете - снимок камеры, скриншот, кадр видео или автозагрузку.
2. Выберите папку назначения. Откроется системный выбор папки, так что можно указать любую локальную папку, даже ту, что вы никогда не добавляли в приложение.
3. Эта папка станет местом сохранения только для данной настройки. В общий список ресурсов она не попадёт, так что папка-черновик для скриншотов не захламляет главный экран.

**Советы:**

- У каждой из четырёх настроек своё назначение - скриншоты и снимки с камеры могут сохраняться в совершенно разных местах.
- Направить несколько настроек в одну папку тоже можно, если вам удобнее держать всё в одном месте.

### Имена файлов снимков

Новые результаты захвата получают имя по шаблону `префикс_yyMMdd_HHmmss`. Постоянные префиксы - `photo`, `screenshot`, `audio`, `video`, `screen_video` и `video_frame`, поэтому по имени понятно, откуда пришёл файл. Если такое имя уже есть в папке назначения, приложение добавляет перед расширением суффикс ` (2)`. Имя, введённое вручную в камере, остаётся переопределением и не меняется.

## Как получить файлы из другого приложения

Любое приложение может отправить файлы в FastMediaSorter через системное меню «Поделиться», а он скопирует их туда, куда вы укажете.

**Шаги:**

1. В другом приложении поделитесь файлом или файлами и выберите **FastMediaSorter**.
2. На экране приёма выберите папку назначения.
3. Запустите копирование.

**Ждать не обязательно.** Копирование продолжается и после закрытия экрана приёма - уведомление показывает прогресс во время работы, а по завершении приходит уведомление с результатом. Выходите из приложения, блокируйте устройство, занимайтесь своими делами - перенос не привязан к тому, открыт ли этот экран.

Доступно в версиях Standard, Lite, Photos и Legacy.

## Как пользоваться встроенными программами

**Доступно в:** всех флейворах - меню программ и панель есть в любой сборке, но каждая программа следует своей возможности: Сетевой монитор требует Standard или noLegal, Wear-компаньон - Standard или noLegal, а мини-игры нет в XR и noLegal. Калькулятор, фронтальный фонарик и сведения о системе есть в каждой сборке.

Кроме просмотра и воспроизведения файлов приложение несёт набор небольших встроенных программ - калькулятор, экранную лампу, сетевой монитор, диктофон и другие. По умолчанию они выключены: каждая включается своей настройкой, и большинство отдельных переключателей собрано в **Настройки → Операции**.

**Быстрый путь**

1. Откройте **Настройки → Операции** и включите нужное - например **Калькулятор**, **Фронтальный фонарик**, **Сетевой монитор**, **Мини-игру** или **Сведения о системе**.
2. Откройте выпадающее меню главного окна. Включённые программы перечислены там.
3. Нажмите на программу, чтобы запустить её.

**Где появляется программа**

Программа может предлагаться на четырёх поверхностях, и каждая поверхность берёт состав и порядок из одного и того же списка, поэтому они никогда не расходятся:

- **Меню программ** - выпадающее меню главного окна и повторяющая его панель программ.
- **Панель запуска** - оверлей быстрого доступа.
- **Виджет на домашнем экране** - только для тех программ, у которых он есть; закрепляется из собственного выбора виджетов приложения.
- **Рабочий стол лаунчера** - если приложение работает как домашний экран, включение программы добавляет её ячейку автоматически.

**Что входит в набор**

В порядке отображения:

- **Быстрая съёмка** - снять фото сразу в приложение.
- **Запись с диктофона** - записать голосовую заметку.
- **Калькулятор** - научный калькулятор с историей и ячейками памяти.
- **Сетевой монитор** - живые показания активного канала, Wi-Fi, мобильной сети, Bluetooth и геолокации, плюс трассировка маршрута (traceroute): она проходит путь до узла шаг за шагом и продолжает счёт, когда очередной узел ничего не отвечает.
- **Фото-OCR-перевод** - снять текст и перевести его.
- **Видеозапись экрана** - записать экран.
- **Загрузить по ссылке** - скачать файл по вставленной ссылке.
- **Мини-игра** - небольшая игра, встроенная в приложение.
- **Сведения о системе** - отчёт об устройстве, доступный без захода в настройки.
- **Wear-компаньон** - экран часов, в сборках с мостом к часам.
- **Фронтальный фонарик** - превращает сам экран в лампу: открывается белым на полной яркости окна, вертикальный свайп меняет яркость, маленькая кнопка слева сверху выбирает и запоминает другой цвет, одиночное нажатие закрывает. Трогается только яркость окна, поэтому системная настройка после закрытия остаётся прежней.

Панель и лаунчер дополнительно несут прямые действия камеры - снять фото и отправить, снять и отредактировать, снять и перевести, начать видеозапись, открыть папку камеры.

**Когда это помогает**

- Нужен калькулятор или фонарик, не выходя из приложения и не разыскивая отдельную программу на переполненном телефоне.
- Приложение работает как домашний экран, и хочется ячейку в одно нажатие для часто используемого инструмента.

**Чего не делать**

- Не ищите фронтальный фонарик в выпадающем меню - он предлагается только на панели запуска и на рабочем столе лаунчера.
- Не ждите каждую программу в каждой сборке - список выше полный, а сборка без соответствующей возможности просто не показывает эту строку.
