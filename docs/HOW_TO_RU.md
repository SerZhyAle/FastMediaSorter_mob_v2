## Примечание: Доступность функций по версиям

Некоторые функции доступны только в определённых версиях приложения. Это руководство следует текущей матрице из [FEATURES_RU.md](FEATURES_RU.md); XR / noLegal вынесены отдельно, потому что зависят от аппаратуры шлема и sideload-правил сборки.

| Функция | Standard | Lite | Photos | Legacy | XR / noLegal |
|---------|----------|------|--------|--------|--------------|
| Сетевые папки (SMB, SFTP, FTP) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Облачные хранилища (Google Drive, OneDrive, Dropbox) | ✓ | ✗ | ✓ | ✓ | ✓ |
| Воспроизведение аудио и текст песен | ✓ | ✗ | ✗ | ✓ | ✓ |
| Просмотр документов (PDF, Текст) | ✓ | ✗ | ✗ | ✓ | ✓ |
| Читалка EPUB | ✓ | ✗ | ✗ | ✓ | ✓ |
| Перевод и OCR | ✓ | ✗ | ✗ | ✓ | ✓ |
| Редактирование изображений | ✓ | ✓ | ✓ | ✓ | ✓ |

Если функция отмечена как "✗", выбирайте **Standard** или **XR / noLegal** в зависимости от аппаратуры и канала распространения.

## Группы сценариев

Эти блоки намеренно разнообразнее базового справочника ниже. Каждый сценарий сочетает быстрый путь, контекст, ограничения и ситуации, где FastMediaSorter особенно силён.

## Домашний медиацентр, TV и сценарии для гостиной

## Превратите NAS в медиаполку для гостиной

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Быстрый путь**

1. Добавьте NAS как SMB-ресурс.
2. Запустите **Scan Network**, если не хотите вводить IP вручную.
3. Откройте ресурс с TV box, планшета или телефона.
4. Начните просматривать видео, фото или документы прямо с NAS.

**Разбор сценария**

- Держите один SMB-ресурс для всей семейной медиатеки и разделяйте дочерние папки по назначению: фильмы, семейные фото, сканы, инструкции.
- Один раз запустите **Test Connection** при настройке, чтобы ресурс был стабильным ещё до использования с дивана.
- Если NAS используется с TV box, сразу добавьте Bluetooth-клавиатуру или пульт для быстрой навигации.
- Если просмотр кажется медленным, сначала откройте настройки ресурса и запустите встроенную проверку скорости.

**Когда это особенно полезно**

- Вам нужен один центральный источник медиа вместо копирования одних и тех же файлов на несколько устройств.
- Вы хотите, чтобы одна библиотека работала и для слайд-шоу, и для чтения документов, и для воспроизведения.

**Избегайте этого**

- Не начинайте с отладки hostname. Сначала используйте IP-адрес, а оптимизируйте позже.
- Не ожидайте SMB в flavor Legacy.

## Запустите слайд-шоу с фоновой музыкой для комнаты

**Доступно в:** Standard, Legacy, Photos, XR / noLegal

**Быстрый путь**

1. Добавьте один источник изображений и один источник музыки.
2. В **Настройки → Медиа → Изображения** включите **Музыка во время слайдшоу**.
3. Выберите музыкальный ресурс.
4. Откройте папку с фото и нажмите **Play**.

**Разбор сценария**

- Для самых плавных переходов используйте локальную папку с изображениями или быстрый NAS.
- Держите отдельный музыкальный ресурс со спокойными треками, если хотите предсказуемый фон.
- Если в папке есть и изображения, и видео, помните: музыка автоматически ставится на паузу, когда начинается видео.

**Когда это особенно полезно**

- Вы хотите превратить TV box, планшет или старый телефон в цифровую рамку для комнаты.
- Вам нужен один setup для показа семейных фото, ивентовых подборок или тревел-альбомов без ручной сборки очереди.

**Избегайте этого**

- Не используйте очень медленный сетевой ресурс одновременно и для изображений, и для музыки, если важна плавность.

## Смотрите SBS 3D-видео в VR-режиме

**Доступно в:** Standard, Legacy

**Быстрый путь**

1. Откройте SBS 3D-видео.
2. Перейдите в fullscreen.
3. Откройте **Настройки воспроизведения**.
4. Переключите **3D Video** в **Auto-detect** или **Side-by-Side (SBS)**.

**Разбор сценария**

- Для обычных SBS-файлов начинайте с Auto-detect.
- Если картинка выглядит сдвоенной, вручную включите **Side-by-Side (SBS)**.
- Для простых phone VR viewers сначала подтвердите стереорежим и только потом вставляйте телефон в гарнитуру.

**Когда это особенно полезно**

- У вас есть архивные SBS-видео из поездок, концертов или хобби, и вы хотите пересматривать их без отдельного VR-плеера.

**Избегайте этого**

- Не ожидайте, что Over-Under поведёт себя так же, как SBS.
- Не считайте любое широкое видео трёхмерным, пока не проверите это вручную.

## Иммерсивный кинотеатр OpenXR VR

**Доступно в:** Только VR

**Быстрый путь**

1. Запустите FastMediaSorter на вашем шлеме Meta Quest или устройстве Android XR.
2. Выберите любой медиафайл (3D или 2D) в локальной, сетевой или облачной папке.
3. Для 3D/360° стерео-контента используйте плавающий значок **Точка входа VR** для перехода в иммерсивный режим.
4. Для стандартных 2D-файлов запустите воспроизведение на гигантском виртуальном экране в пространстве кинотеатра.

**Разбор сценария**

- Откройте видеофайл формата Side-by-Side (SBS) или Over-Under (OU) и включите автоопределение, чтобы глубина 3D отображалась корректно.
- Используйте жесты отслеживания рук (**Quest Hand Tracking**) или лучи контроллеров для управления плеером без физических кнопок.
- Делайте снимки смешанной реальности Passthrough на Quest 3 или стерео-скриншоты обоих глаз во время нахождения в VR.

**Когда это особенно полезно**

- Вы хотите смотреть стереоскопические 3D-фильмы или просматривать VR180/360° фотографии из путешествий с качественным рендерингом для каждого глаза.
- Вы хотите смотреть обычные плоские видеофайлы на симулированном гигантском экране кинотеатра в виртуальной комнате.

**Избегайте этого**

- Не используйте плоские версии сборки (Standard/Lite/Legacy) в надежде получить полноценный трекинг шлема; для этого требуется специальная VR-сборка с поддержкой OpenXR.

## Поездки, чтение и документы

## Подготовьте папку для поездки без стабильного интернета

**Доступно в:** Standard, Lite, Photos, Legacy

**Быстрый путь**

1. Создайте или выберите одну локальную папку для поездки.
2. Скопируйте туда нужные медиа, PDF, EPUB и заметки ещё до выхода из Wi-Fi.
3. Один раз откройте эту папку в FastMediaSorter, чтобы подготовились миниатюры и последние позиции.
4. Используйте папку офлайн в дороге.

**Разбор сценария**

- Храните тревел-набор в одной локальной папке, даже если оригиналы обычно живут на NAS или в облаке.
- Намеренно смешивайте форматы: посадочные PDF, EPUB для чтения, скриншоты и офлайн-музыку можно держать рядом.
- Используйте фильтр, если хотите быстро переключаться между изображениями, документами и аудио без интернета.

**Когда это особенно полезно**

- Самолёты, поезда, гостиницы и сельские зоны, где облачный стриминг ненадёжен.
- Ситуации, где нужен один офлайн-пакет вместо поиска по нескольким приложениям.

**Избегайте этого**

- Не оставляйте проверку офлайн-открытия файлов на последний момент.

## Читайте облачные документы и EPUB в дороге

**Доступно в:** Standard для облака, Standard/Lite/Photos/Legacy для локального чтения

**Быстрый путь**

1. Добавьте облачного провайдера через **Cloud Storage**.
2. Откройте папку с PDF или EPUB.
3. Нажмите файл прямо в облачном ресурсе.
4. Позже продолжайте чтение с последней сохранённой позиции.

**Разбор сценария**

- Это удобно, когда рабочие документы уже лежат в Google Drive, OneDrive или Dropbox, и вам не нужен отдельный reader workflow.
- PDF лучше подходит для билетов, инструкций и сканов с фиксированной вёрсткой.
- EPUB удобнее для длинного чтения, где важнее размер шрифта и навигация по главам, чем жёсткая раскладка страницы.

**Когда это особенно полезно**

- Вы переключаетесь между рабочими документами и личным чтением, не выходя из приложения.
- Вы держите дорожные или клиентские файлы в облаке, но хотите более читательский интерфейс.

**Избегайте этого**

- Не ожидайте облачное чтение в Lite, Photos или Legacy.
- Не считайте медленный мобильный интернет гарантированным решением для очень больших файлов.

## Переводите вывески, сканы и скриншоты через OCR

**Доступно в:** Standard, Legacy, XR / noLegal

**Быстрый путь**

1. Откройте изображение, PDF или текстовый файл.
2. Покажите панель команд.
3. Нажмите **Translate**.
4. При первом запуске подтвердите загрузку модели, если это потребуется.

**Разбор сценария**

- Для латиницы приложение обычно начинает с ML Kit ради скорости.
- Для материалов с кириллицей приложение может переключиться на Tesseract ради лучшего качества распознавания.
- Скриншоты, чеки, меню и сканы работают особенно хорошо, если исходный текст достаточно чёткий.

**Когда это особенно полезно**

- Вы в поездке, читаете иностранные инструкции или разбираете скриншоты из чатов и приложений.
- Вам нужен перевод прямо поверх контента, а не отдельная цепочка copy-paste в другой инструмент.

**Избегайте этого**

- Не оценивайте качество OCR по размытому ночному фото или неудачно обрезанному скану.

## Передавайте сетевые файлы в специализированные приложения

**Доступно в:** Standard, Photos, Legacy, XR/noLegal

**Быстрый путь**

1. Откройте файл из SMB, SFTP или FTP.
2. Нажмите **ⓘ Info**.
3. Нажмите **Download and Open**.
4. Выберите нужное приложение в Android chooser.

**Разбор сценария**

- Этот сценарий полезен, когда FastMediaSorter удобнее всего как браузер удалённого хранилища, а другое приложение лучше подходит для конкретного формата.
- Типичные handoff-кейсы: офисные документы, сложные PDF, видео с тяжёлыми кодеками и нишевые медиаформаты.
- Загруженная копия остаётся в `Downloads`, поэтому к ней можно вернуться, даже если удалённый источник позже недоступен.

**Когда это особенно полезно**

- Вам нужен один центр для удалённых файлов, но без отказа от лучших специализированных инструментов.

**Избегайте этого**

- Не ожидайте такой же flow для облачных файлов прямо сейчас.

## Быстрые вычисления из текста и OCR

**Доступно в:** Standard, Legacy, VR

**Быстрый путь**

1. Откройте любой PDF-документ, EPUB-книгу, текстовый файл или запустите перевод OCR на изображении.
2. Выделите долгим нажатием любой блок текста, содержащий числа или математические выражения.
3. В появившемся контекстном меню выберите пункт **Калькулятор**.
4. Встроенный калькулятор мгновенно вычислит математическую формулу в плавающем окне.

**Разбор сценария**

- Выберите строку текста, содержащую числа со знаками операций (например, `(45 + 12) * 3`) в PDF или в результатах OCR-перевода.
- Используйте встроенные научные функции калькулятора (тригонометрию, корни, степени, логарифмы) для сложных вычислений.
- Калькулятор сохраняет историю вычислений между сеансами и поддерживает регистры памяти (M+/M-/MR/MC) для быстрого отслеживания данных.

**Когда это особенно полезно**

- Вы читаете техническую документацию, скан скриншота или книгу и вам нужно быстро решить формулы или просуммировать цены/числа без переключения в отдельное приложение калькулятора.

**Избегайте этого**

- Не пытайтесь вычислять чисто буквенные строки; парсер распознаёт только корректные числа, скобки и математические операторы.

## Облачные заметки Markdown и код

**Доступно в:** Standard для облака, Standard/Lite/Photos/Legacy локально и в сети

**Быстрый путь**

1. Перейдите в любую локальную папку, сетевой ресурс (SMB), FTP/SFTP или облачный диск (Google Drive).
2. Нажмите кнопку **Новая заметка (📝)** на панели инструментов папки.
3. Введите текст во встроенном редакторе. Приложение автоматически подсветит разметку Markdown и синтаксис кода.
4. Нажмите **Сохранить** (или дождитесь автосохранения) для записи изменений прямо на удалённый диск.

**Разбор сценария**

- Ведите файл журнала `.md` на Google Диске или домашнем NAS и редактируйте его с любого устройства напрямую.
- Создавайте новые заметки в ключевых папках с автоматическим разрешением конфликтов имён (например, `Заметка_1.txt`, `Заметка_2.txt`).
- Просматривайте отрендеренный Markdown в режиме чтения или экспортируйте заметки во внешние сервисы, такие как Google Keep.

**Когда это особенно полезно**

- Вы хотите вести простые текстовые заметки, списки задач или хранить фрагменты кода прямо на центральных сетевых или облачных дисках без промежуточного скачивания файлов.

**Избегайте этого**

- Не ожидайте возможности создания файлов в облачных хранилищах на сборках Lite или Legacy.

## Продвинутые и смешанные медиасценарии

## Сортируйте семейный фотоархив через Quick Sort

**Доступно в:** Standard, Lite, Photos, Legacy

**Быстрый путь**

1. Добавьте целевые папки в **Quick Sort**.
2. Откройте исходную папку с несортированными семейными фото.
3. Используйте цифровые кнопки или touch zones во время просмотра.
4. Сразу отправляйте удачные кадры в папки назначения.

**Разбор сценария**

- Создавайте папки по результату, а не только по дате: `Best`, `Print`, `Send to family`, `Archive`.
- Просматривайте в fullscreen, чтобы быстро принимать решение и копировать или перемещать без возврата к списку файлов.
- Если архив разбирают несколько человек, заранее договоритесь о единой схеме папок назначения.

**Когда это особенно полезно**

- У вас накопился backlog после дней рождений, поездок, школьных событий или старых импортов с телефона.
- Вам нужен быстрый triage flow вместо ручного перетаскивания файлов в файловом менеджере.

**Избегайте этого**

- Не начинайте сортировку, пока папки назначения названы неясно.
- Не используйте Move сразу, если ещё не уверены, какие папки станут долгосрочным архивом.

## Подключение сетевого диска (SMB)

**Что нужно:**

- NAS или ПК с Windows с общей папкой
- Оба устройства в одной Wi-Fi сети
- Имя пользователя и пароль для доступа

**Доступно в:** Версии Standard, Photos, Legacy

**Шаги:**

1. Нажмите кнопку **"+"** на главном экране
2. Выберите **"Сетевая папка (SMB)"**
3. Заполните данные:
   - **Авто-обнаружение (New):**
     1. Нажмите **"Сканировать сеть"**
     2. Дождитесь появления устройств в списке
     3. Выберите устройство из списка
     4. IP-адрес заполнится автоматически

   - **Ручной ввод:**

     ```
     Сервер/Путь: \\192.168.1.100\photos
     Имя пользователя: john
     Пароль: ****
     Имя для отображения: Home NAS (необязательно)
     ```

4. Нажмите **"Тест соединения"** для проверки
5. Нажмите **"Сохранить"**

**Форматы адреса сервера:**

- Windows: `\\192.168.1.100\share`
- Linux/Mac: `smb://192.168.1.100/share`
- С портом: `smb://192.168.1.100:445/share`

**Советы:**

- Используйте IP-адрес (а не имя хоста) для надёжности
- Включите SMB v2/v3 на NAS для безопасности
- Порт SMB по умолчанию: 445

→ См. [TROUBLESHOOTING_RU.md](TROUBLESHOOTING_RU.md)

## Использование сенсорных зон

**Что такое сенсорные зоны?**

Экран разделен на 9 невидимых областей для быстрых действий:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПИЯ  │ ПЕРЕИМ. │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  ПРЕД.  │ ПЕРЕМ.  │  СЛЕД.  │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│ КОМАНДЫ │ УДАЛИТЬ │ ИГРАТЬ  │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**Легенда:**

1. **НАЗАД** - Вернуться к списку
2. **КОПИЯ** - Копировать в папку
3. **ПЕРЕИМ.** - Переименовать файл
4. **ПРЕД.** - Предыдущий файл
5. **ПЕРЕМ.** - Переместить в папку
6. **СЛЕД.** - Следующий файл
7. **КОМАНДЫ** - Открыть меню
8. **УДАЛИТЬ** - Удалить файл
9. **ИГРАТЬ** - Старт/Стоп слайд-шоу

**Включить наложение (рекомендуется для новичков):**

1. Настройки → Воспроизведение
2. Включите **"Всегда показывать сетку сенсорных зон"**
3. Теперь вы увидите полупрозрачную сетку

**Попробуйте:**

1. Откройте любое фото
2. **Нажмите верхний правый угол** → Следующий файл
3. **Нажмите верхний левый угол** → Предыдущий файл
4. **Нажмите средний правый угол** → Удалить файл
5. **Нажмите средний левый угол** → Копировать файл

**Отключить, если не нужно:**
Настройки → Воспроизведение → "Всегда показывать сетку сенсорных зон" = ВЫКЛ

Затем используйте **кнопки панели команд**.

## Просмотр 3D видео (VR)

**Версии**: Standard, Legacy

**Что нужно**: 3D видеофайл в формате SBS (Side-by-Side) и, опционально, VR-очки для смартфона (например, Google Cardboard).

**Шаги:**

1. Откройте 3D видеофайл в FastMediaSorter.
2. Нажмите кнопку **полноэкранного режима**.
3. Нажмите **Настройки воспроизведения** (значок шестерёнки) в элементах управления плеером.
4. Прокрутите до раздела **3D Видео**.
5. Выберите режим стерео:
   - **Автоопределение** - приложение анализирует соотношение сторон и встроенные метаданные для автоматического определения SBS.
   - **Бок о бок (SBS)** - вручную включить стерео Side-by-Side независимо от результата определения.
   - **Сверху-снизу (OU)** - вручную включить стерео Over-Under (верх/низ).
   - **Моно (отключено)** - отключить стерео (обычный просмотр).
6. Нажмите **Применить** - плеер мгновенно переключится в выбранный режим.
7. Для VR-просмотра вставьте смартфон в VR-очки и наслаждайтесь стереоскопическим 3D.

**Советы:**

- Авто-определение надёжно работает для стандартных SBS файлов (соотношение сторон ≈ 32:9 и шире).
- Если видео выглядит растянутым или удвоенным - переключитесь в режим **Бок о бок (SBS)** вручную.

## Создание слайд-шоу с фоновой музыкой

**Требования:**

- Хотя бы одна папка/ресурс с аудиофайлами (MP3, FLAC и т.д.)
- **Доступно в:** Standard, Legacy, Photos, XR / noLegal

**Настройка:**

1. **Настройки** → вкладка **Медиа** → **Изображения**
2. Включите **"Музыка во время слайдшоу"**
3. Нажмите кнопку **"Выбрать источник музыки"**
4. Выберите ресурс, содержащий ваши музыкальные файлы
5. Нажмите **"Сохранить"** или закройте настройки

**Воспроизведение слайд-шоу с музыкой:**

1. **Откройте любую папку** с фото/изображениями
2. Нажмите **первое фото** для просмотра
3. Нажмите кнопку **"Play"** (или зону справа внизу)
4. Слайд-шоу начнется с воспроизведением фоновой музыки

**Как это работает:**

- Музыка воспроизводится случайным образом из выбранного музыкального ресурса
- Когда трек заканчивается, автоматически начинается следующий случайный трек
- Музыка продолжает играть во время переходов между изображениями
- Музыка останавливается при выходе из слайд-шоу или паузе

**Примечания:**

- Музыка воспроизводится только для **изображений и GIF** (не для видео/аудио)
- Когда слайд-шоу показывает видео, музыка автоматически приостанавливается
- Музыка возобновляется при возврате к изображениям
- Работает с локальными и сетевыми источниками музыки (SMB, SFTP, FTP)

**Настройка выбора музыки:**

- Добавьте несколько музыкальных файлов в папку музыкального ресурса
- Приложение будет случайным образом перемешивать все аудиофайлы
- Организуйте музыку в подпапки, если для музыкального ресурса включена опция "Включить подпапки"

**Устранение неполадок:**

- Если музыка не воспроизводится: Проверьте, что музыкальный ресурс содержит хотя бы один аудиофайл
- Если музыка прерывается в сети: Используйте локальную папку или более быстрое сетевое соединение
- Для музыки по SMB: Убедитесь, что SMB-ресурс использует протокол `file://` (см. [TROUBLESHOOTING_RU.md](TROUBLESHOOTING_RU.md))

## Как читать электронные книги (EPUB)

**Требования:**

- **Настройки** → вкладка **Медиа** → **Документы** → **Поддержка EPUB электронных книг** должно быть включено (включено по умолчанию)
- Поддерживаемый формат: `.epub` (без DRM)

**Возможности:**

- **Навигация по главам:** Свайп влево/вправо или кнопки на панели команд
- **Оглавление:** Нажмите иконку спика (📋) для перехода к главе
- **Размер шрифта:** настраиваемый (14px - 32px)
- **Поиск:** Поиск текста внутри книги
- **Темы:** Автоматически адаптируется под Светлую/Темную тему

**Управление:**

1. **Откройте файл EPUB** из списка
2. **Коснитесь экрана** для отображения панели команд
3. **Нижняя панель управления:**
   - `Пред.` / `След.`: навигация по главам
   - `- A` / `+ A`: уменьшить/увеличить шрифт
   - `Поиск` (🔍): поиск текста
   - `Оглавление` (📋): открыть список глав
4. **Жесты свайпа:** переключение глав

**Примечание:** Работает как с локальными файлами, так и с сетевыми потоками (SMB/SFTP/Cloud). Большие книги (>50МБ) в медленных сетях могут загружаться несколько секунд.

## Открытие сетевых файлов во внешних приложениях

**Доступно для:** Файлов SMB, SFTP, FTP

**Сценарий использования:** Вы хотите открыть документ, фото или видео с сетевого диска в специализированном внешнем приложении (например, MS Office, Adobe Acrobat, VLC Player).

**Шаги:**

1. **Перейдите к файлу** на сетевом ресурсе
2. **Нажмите на файл**, чтобы открыть его в плеере/просмотрщике
3. **Нажмите кнопку ⓘ (Инфо)** в верхней панели
4. **Нажмите "Загрузить и открыть"**
5. **Дождитесь загрузки** - диалог прогресса покажет проценты
6. **Выберите приложение** из списка Android

**Что происходит:**

- Файл загружается в папку `Downloads`
- Прогресс отображается в диалоге (0-100%)
- После завершения Android покажет выбор приложения
- Можно открыть файл в любом совместимом приложении

**Поддерживаемые протоколы:**

- ✅ SMB/CIFS сетевые папки
- ✅ SFTP серверы
- ✅ FTP серверы
- ❌ Облачные хранилища (пока не реализовано)

**Советы:**

- Загруженные файлы остаются в папке `Downloads`
- Вы можете удалить их вручную позже через файловый менеджер
- Работает со всеми типами файлов (изображения, видео, документы)
- Для больших файлов загрузка может занять несколько минут

**Примеры использования:**

- Редактирование сетевого документа в MS Word
- Воспроизведение сетевого видео в VLC Player
- Просмотр сетевого PDF в Adobe Acrobat
- Отправка сетевого фото через мессенджеры

## Как просмотреть текст песни (Лирика)

**Требования:**

- Аудиофайл (MP3, FLAC и др.) с метаданными Исполнителя и Названия.
- Требуется **Интернет-соединение** (использует api.lyrics.ovh).

**Шаги:**

1. **Запустите аудиофайл** в полноэкранном плеере.
2. Нажмите кнопку **"Лирика"** на верхней панели команд (или в меню команд).
   - *Примечание: Кнопка видна только для аудиофайлов.*
3. Дождитесь завершения поиска.
4. Текст песни отобразится в диалоговом окне с прокруткой.

**Алгоритм поиска:**

1. Приложение ищет по тегам **Исполнитель + Название**.
2. Если теги отсутствуют, пытается извлечь данные из **Имени файла**.

## Автоматический перевод

Автоматический перевод текста с изображений, PDF и текстовых файлов с использованием **Гибридной системы OCR** (Google ML Kit + Tesseract).

**Ключевые особенности:**

- **Гибридный движок:** Использует Google ML Kit для быстрого распознавания латиницы и **Tesseract** для качественного распознавания кириллицы (Русский, Украинский).
- **Оффлайн:** Работает полностью на устройстве (после начальной загрузки моделей).
- **Умное наложение:** Переведенный текст накладывается поверх оригинала удобными для чтения абзацами.

**Настройка:**

1. **Настройки** → вкладка **Медиа** → **Другое**
2. Включите **"Включить перевод"**
3. Выберите **Source Language** (Исходный язык):
   - **"Auto" (Рекомендуется):** Автоматически выбирает лучший движок (Tesseract для кириллицы, ML Kit для остальных).
   - **Конкретный язык:** Принудительно использует модель (например, "Russian" включит Tesseract).
4. Выберите **Target Language** (Целевой язык, например, English).

**Как использовать:**

1. Откройте **Изображение**, **PDF** или **Текстовый** файл.
2. Нажмите на экран, чтобы показать **Панель команд** (Command Panel).
3. Нажмите кнопку **"Перевести"** (иконка A→文).
4. **Первый запуск:**
   - Для ML Kit: Подтвердите загрузку языковой модели (~30МБ).
   - Для Tesseract (Кириллица): Подтвердите загрузку данных OCR (~15МБ).
5. Переведенный текст появится поверх содержимого.

**Примечание:** Инициализация Tesseract (для кириллицы) может занять на 1-2 секунды больше времени, чем ML Kit.

## Умные виджеты домашнего экрана

**Доступно в:** Standard, Legacy, VR

**Быстрый путь**

1. Перейдите на домашний экран Android, зажмите его и выберите пункт **Виджеты**.
2. Перетащите нужный виджет **FastMediaSorter** (например, иконку 1×1 «Быстрый диктофон» или «Camera OCR») на экран.
3. Настройте папку сохранения и параметры захвата, затем нажмите **Сохранить**.
4. Нажимайте виджет для мгновенного выполнения задачи прямо с рабочего стола.

**Разбор сценария**

- Используйте виджеты 1×1 как быстрые ярлыки для мгновенного выполнения фоновых действий (например, одно нажатие начинает запись голоса, повторное - сохраняет её в ресурс на NAS).
- Добавьте виджет **Задачи по расписанию** для мониторинга фонового копирования или запуска всех задач одной кнопкой.
- Разместите виджет **Случайный кадр** для показа сменяющихся семейных фотографий напрямую из сетевой папки SMB.

**Когда это особенно полезно**

- Вам нужны быстрые ярлыки на рабочем столе для ежедневной съёмки (чеки, квитанции, голосовые заметки) без открытия основного интерфейса приложения.
- Вам нужны наглядные виджеты для управления воспроизведением или быстрого отслеживания расписания резервного копирования.

**Избегайте этого**

- Не пытайтесь добавлять виджеты, если лаунчер вашего Android-устройства блокирует создание кастомных виджетов сторонними приложениями.

## Использование FMS на Android TV-приставке

FastMediaSorter работает на любой Android TV-приставке или сет-топ-боксе (Xiaomi Mi Box, Nvidia Shield, Amazon Fire TV, дженерик Android-боксы). Тачскрин не требуется - приложение полностью управляется с пульта ДУ или Bluetooth-клавиатуры.

**Что вам нужно:**

- Android TV-приставка на Android 8.0+ (версии Standard/Lite/Photos) или Android 6.0+ (версия Legacy)
- Пульт ДУ с D-pad или Bluetooth-клавиатура
- Опционально: домашний NAS (SMB), USB-накопитель или SD-карта с медиа

**Навигация с пульта ДУ:**

| Кнопка | Действие |
|--------|----------|
| D-pad Вверх/Вниз/Влево/Вправо | Перемещение фокуса между элементами |
| OK / Enter | Открыть элемент или подтвердить |
| Back | Вернуться на предыдущий экран |
| Backspace | Перейти на папку выше в браузере файлов |
| Красная | Удалить выбранный файл(ы) |
| Зелёная | Копировать выбранный файл(ы) |
| Жёлтая | Переместить выбранный файл(ы) |
| Синяя | Переименовать выбранный файл |
| Channel Up / Channel Down | Предыдущий / следующий файл в плеере |

**Шаги:**

1. Установите приложение из Google Play или sideload APK. Рекомендуется версия Standard.
2. На главном экране нажмите **OK** на кнопке (+) для добавления ресурса.
3. Выберите **Локальная папка** для USB/SD или **Сетевая папка** для подключения к NAS через SMB.
4. После добавления ресурса перейдите в него с помощью D-pad + OK для просмотра файлов.
5. Откройте любое видео, изображение или аудиофайл - плеер полностью управляется с пульта.
6. Для запуска слайд-шоу откройте папку с изображениями и перейдите к кнопке **Слайд-шоу** на панели команд.
7. Для добавления фоновой музыки к слайд-шоу перейдите в **Настройки → Медиа → Изображения**, включите **Музыка во время слайдшоу** и выберите музыкальный ресурс.

**Советы:**

- Удерживайте D-pad Вверх/Вниз для ускоренной прокрутки длинных списков файлов.
- Нажмите **F1** на Bluetooth-клавиатуре для открытия подсказок по горячим клавишам на любом экране.
- Цветные кнопки пульта можно переназначить в **Настройки → Операции → Управление и клавиши**.
