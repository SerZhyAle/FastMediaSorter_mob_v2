# ❓ Часті запитання (FAQ)

---

## Загальні питання

### Що таке FastMediaSorter?
FastMediaSorter v2 - це Android-додаток для швидкої організації фото, відео та аудіо файлів з локальних папок, мережевих дисків (SMB/SFTP/FTP) та хмарних сховищ (Google Drive, OneDrive, Dropbox).

### Це безкоштовно?
Так! FastMediaSorter v2 повністю безкоштовний і має відкритий вихідний код.

### Яка версія Android потрібна?
Для Standard, Lite та Photos потрібен Android 8.0 (API 26) або новіший. Версія **Legacy** підтримує Android 6.0 (API 23) або новіший. Для **XR / noLegal** додатково потрібні сумісне обладнання шолома та поточний sideload runtime path.

### Чи потрібен інтернет?
**Ні** для локальних файлів. **Так** для мережевих дисків та хмарних сховищ.

### Чи є в додатку віджети?
Так! FastMediaSorter v2 пропонує різноманітні віджети для головного екрана - знайдіть їх через довге натискання → Віджети → FastMediaSorter. Серед них - ярлики ресурсів, запуск слайд-шоу та інші.

## Операції з файлами

### Куди потрапляють видалені файли?
Видалені файли переміщуються в папку `.trash/` у тому ж розташуванні (м'яке видалення). Вони не видаляються остаточно, поки ви не:
- Натиснете **"Очистити кошик"** в Налаштуваннях → Операції → Видалення файлів, кошик, АБО
- Вручну видалите папку `.trash/`

### Чи можна скасувати видалення/переміщення?
**Так!** Натисніть кнопку **"Скасувати"** (або нижню праву сенсорну зону) протягом декількох секунд після операції.

> ⚠️ **Примітка:** Скасування недоступне для видалення мережевих файлів (вони видаляються відразу і безповоротно).

### У чому різниця між Копіюванням та Переміщенням?
- **Копіювання:** Створює дублікат, оригінал залишається на місці.
- **Переміщення:** Переносить файл, видаляючи його з початкового місця.

### Що таке Режим файлового менеджера?
**Режим файлового менеджера** дозволяє використовувати додаток як повнофункціональний браузер файлів по всіх директоріях. У цьому режимі додаток обходить стандартні медіафільтри та відображає абсолютно всі файли (включно з ZIP, RAR, APK, EXE, PDF тощо). Ви можете виконувати стандартні файлові операції, такі як копіювання, переміщення, перейменування, надсилання та видалення. Для непідтримуваних бінарних файлів автоматично відкривається нижня панель (bottom sheet), яка дозволяє керувати файлом або відкрити його за допомогою зовнішніх додатків.

### Як знайти і видалити дублікати файлів?
Відкрийте папку, натисніть меню (⋮) і виберіть **«Знайти дублікати»**, щоб перевірити збіги самостійно, або **«Знайти та видалити дублікати»**, щоб видалити їх одразу. Є і **«Видалення за розміром..»** - для швидкого прибирання лише за розміром файлу. Автоматичний варіант видаляє без підтвердження, тож спершу скористайтеся «Знайти дублікати», якщо хочете перевірити список перед видаленням. Збіги шукаються за вмістом - розмір, швидкий хеш, потім повна перевірка SHA-256, - тож перейменовані копії теж знаходяться.

## Мережа та Хмара

### Як підключитися до домашнього NAS (мережевого диска)?
1. Натисніть **"+"** → **Мережа** → **SMB/Мережевий диск**
2. **Варіант А - Автоматично:** Натисніть **"Сканувати мережу"**, щоб знайти доступні пристрої автоматично
3. **Варіант Б - Вручну:** Введіть адресу сервера: `\\192.168.1.100\share` або `smb://192.168.1.100/share`
4. Введіть ім'я користувача та пароль
5. Натисніть "Підключитися"

**Часті проблеми та рішення:**

| Проблема | Що спробувати |
|---------|--------------|
| "У з'єднанні відмовлено" | Відкрийте Брандмауер Windows → дозвольте **TCP-порт 445** вхідний. Або тимчасово вимкніть брандмауер для тесту |
| "Невірний пароль" | Спробуйте залишити ім'я користувача порожнім (гостьовий доступ). При обліковому записі Microsoft вводьте **повний email** як логін |
| "Хост не знайдено" | Переконайтеся, що телефон і ПК підключені до **одного роутера**. AP Isolation (функція безпеки роутера) може блокувати зв'язок між пристроями - вимкніть її в налаштуваннях роутера |
| Сканування нічого не знайшло | Вимкніть VPN на телефоні. Увімкніть **Виявлення мережі** у Windows (Панель керування → Центр мережі та спільного доступу). Потім введіть IP вручну |
| Дуже повільний перегляд | Відкрийте редагування ресурсу → запустіть **Тест швидкості**. Якщо менше 5 Мбіт/с - переключіть телефон на діапазон 5 ГГц Wi-Fi. Вимкніть мініатюри відео для повільних з'єднань |
| Працює по Wi-Fi, але не по мобільному | Очікувано - SMB працює лише в локальній мережі, через мобільний інтернет не працює |

→ Детальний посібник: [Налаштування SMB](howto/scenario-smb-setup-uk.md)

### Як підключитися до Google Drive?
1. Натисніть **"+"** → **Хмара** → **Google Drive**
2. Натисніть "Увійти через Google"
3. Надайте дозволи при запиті
4. Ваші папки Drive з'являться у списку

**Примітка:** Файли НЕ завантажуються автоматично - вони транслюються за запитом.

### Як підключитися до OneDrive?
1. Натисніть **"+"** → **Хмара** → **OneDrive**
2. Натисніть "Увійти через Microsoft"
3. Надайте дозволи при запиті
4. Ваші папки OneDrive з'являться у списку

### Як підключитися до Dropbox?
1. Натисніть **"+"** → **Хмара** → **Dropbox**
2. Натисніть "Увійти через Dropbox"
3. Надайте дозволи при запиті
4. Ваші папки Dropbox з'являться у списку

### Чи можна використовувати SFTP або FTP?
**Так!** Виберіть **SFTP** або **FTP** при додаванні папки:
- **SFTP:** Безпечний, вимагає SSH-сервер (порт 22)
- **FTP:** Менш безпечний, старий протокол (порт 21)

### Чи можна поділитися теками ПК із застосунком?
**Так** - Fast Media Sorter for Windows публікує вибрані теки ПК через SFTP і показує QR-код / конфіг `.fmscfg`. На телефоні використайте **Імпорт із companion** або **Сканувати QR-код** на екрані додавання ресурсу. PC-інструкція: [Як опублікувати теки ПК для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html). Доступно у Standard, Photos, Legacy, XR/noLegal.

### Чому мініатюри для мережевих файлів не завантажуються?
Мережеві мініатюри генеруються **за запитом** для економії трафіку. Гортайте повільніше або зачекайте кілька секунд.

Якщо мініатюри не з'являються взагалі:
- Перевірте, чи відкривається папка - якщо так, з'єднання в порядку
- Відкрийте редагування ресурсу → переконайтеся, що **"Завантажувати мініатюри"** увімкнено
- При дуже повільному з'єднанні: вимкніть мініатюри повністю, щоб уникнути таймаутів (редагування ресурсу → вимкнути мініатюри)

### З'єднання постійно обривається / файли не відкриваються під час відтворення
- Перевірте стабільність Wi-Fi - телефон не має перемикатися між діапазонами 2,4 і 5 ГГц
- Деякі роутери обривають неактивні SMB-сесії - при редагуванні ресурсу увімкніть **"Перепідключатися при помилці"** (якщо є)
- Для відтворення відео через SMB: запустіть Тест швидкості (редагування ресурсу → Тест швидкості). Для 1080p-відео потрібно не менше 10 Мбіт/с

## Швидке сортування та Призначення

### Що таке папки "Швидкого сортування"?
Папки швидкого сортування - це заздалегідь налаштовані цільові папки для швидкого сортування файлів. Ви можете призначити до 30 папок з пронумерованими кнопками.

### Як налаштувати Швидке сортування?
**Спосіб 1:** Налаштування → Операції → Призначення швидкого сортування, потім натисніть **"Додати до швидкого сортування"**  
**Спосіб 2:** Редагувати будь-яку папку → Увімкнути "Позначити для швидкого сортування"

### Як використовувати Швидке сортування при перегляді?
1. Відкрийте фото/відео на весь екран
2. Натисніть **цифрову кнопку** (0-9) на панелі команд, АБО
3. Натисніть **нижній лівий кут** (зона КОПІЮВАННЯ) або **нижній центр** (зона ПЕРЕМІЩЕННЯ)

### Чи можна використовувати цифрові клавіші замість дотиків?
Так - підключіть клавіатуру, геймпад або пульт ТБ, і кнопки Швидкого сортування отримають номери (0-9) автоматично. Натисніть потрібну цифру, щоб скопіювати або перемістити файл у це призначення миттєво, так само як при натисканні на кнопку.

### Кнопки Швидкого сортування не відображаються
Переконайтеся, що додана хоча б одна папка-призначення: Налаштування → Операції → Призначення швидкого сортування, потім **"Додати до швидкого сортування"**. Кнопки з'являються лише за наявності хоча б одного призначення.

### Я випадково надіслав файл не в ту папку
Натисніть **Скасувати** одразу (нижній правий кут панелі команд) - доступно кілька секунд після операції. Якщо час упущено - відкрийте папку-призначення та перемістіть файл назад вручну.

## Сенсорні зони (Touch Zones)

### Що таке "Сенсорні зони"?
Сенсорні зони - це невидимі області на екрані, які виконують дії при натисканні. Екран розділений на сітку 3x3:

```
┌─────────┬─────────┬─────────┐
│  НАЗАД  │  КОПІЯ  │ ПЕРЕЙМ. │
├─────────┼─────────┼─────────┤
│  ПОПЕР. │ ПЕРЕМІЩ │  НАСТ.  │
├─────────┼─────────┼─────────┤
│ КОМАНДИ │ ВИДАЛИТ │  ГРАТИ  │
└─────────┴─────────┴─────────┘
```

### Як побачити Сенсорні зони?
Налаштування → Відтворення → **"Завжди показувати сітку сенсорних зон"**

### Чи можна вимкнути Сенсорні зони?
Так, просто використовуйте **кнопки панелі команд**. Сенсорні зони опціональні.

## Захоплення екрана та голосу

### Що таке панель жестів біля лівого краю?
Це меню швидкого захоплення, яке відкривається діагональним свайпом від лівого краю екрана. Увімкніть його в **Налаштування → Операції → Жести з країв екрана → Оверлей жестів**. З меню можна зробити скриншот, зняти фото, обрізати та поділитися поточним зображенням, відкрити ярлик застосунку чи панелі, або запустити запис екрана, відео чи голосу - не відриваючись від того, що ви дивитесь. Доступно в Standard та XR/noLegal.

### Як швидко записати голосову нотатку?
Три способи: пункт **«Запис із диктофона»** в меню, віджет **«Швидкий диктофон»** на головному екрані або дія **«Почати запис аудіо»** в меню жестів. Як би ви її не почали, на екрані залишається плаваюча кнопка **«Стоп»** - навіть поверх іншого застосунку - поки ви не натиснете її для збереження.

## Керування та введення

### Чи підтримуються фізичні клавіатури та геймпади?
**Так!** Повна підтримка клавіатури, миші та геймпада на всіх екранах. Натисніть **F1** на будь-якому екрані, щоб переглянути активні прив'язки для цієї поверхні.

### Як перепризначити клавіші керування?
Налаштування → **Операції** → **Керування та клавіші** - перепризначте будь-яку дію на іншу клавішу, кнопку або введення геймпада. У додатку 70 вбудованих прив'язок за замовчуванням; натисніть **Reset** для відновлення. Конфлікти підсвічуються автоматично.

### Як завантажити медіафайл за посиланням?
Поділіться будь-яким посиланням `http(s)` у FastMediaSorter через «Поділитися» Android (з браузера, месенджера або будь-якого застосунку). FastMediaSorter завантажить файл і запропонує зберегти його в один з ваших ресурсів.

## Продуктивність та Пам'ять

### Як знайти файл за іменем?
Використовуйте панель **Фільтр** у Browse: натисніть іконку фільтра на панелі інструментів, введіть частину імені файлу в поле імені - список оновлюється миттєво. Окремого рядка пошуку немає, фільтр повністю покриває цей сценарій.

### Чому додаток гальмує з 5000+ файлів?
Додаток використовує **пагінацію** для завантаження файлів частинами. Для дуже великих колекцій:
- Увімкніть "Вимкнути мініатюри" для цієї папки
- Використовуйте фільтри для звуження результатів
- Відсортуйте за датою (спочатку нові) - так останні файли завантажуються першими, без сканування всієї папки

### Додаток падає або зависає
1. Примусово закрийте та знову відкрийте додаток
2. Якщо падіння відбувається на конкретній папці: можливо, там є пошкоджений файл - спробуйте відкривати файли по одному, щоб знайти проблемний
3. Очистіть кеш: Налаштування → Загальні → **"Очистити кеш"** - вирішує більшість проблем зі стабільністю після оновлень
4. Якщо падіння тривають: повідомте через GitHub Issues (посилання внизу сторінки) - опишіть, що ви робили в момент збою

### Скільки місця займає кеш мініатюр?
**За замовчуванням:** 2 ГБ (налаштовується в Налаштуваннях)

### Як очистити кеш?
Налаштування → Загальні → **"Очистити кеш"**

## Безпека та Приватність

### Чи можна захистити папки паролем?
**Так!** Редагувати папку → Встановити **PIN-код** (4-6 цифр)

### Чи збираються мої дані?
**Ні.** FastMediaSorter НЕ збирає і НЕ відправляє жодних персональних даних.

### Чи зберігає додаток GPS-координати у фото?
Тільки якщо ви це увімкнете. У **Налаштування → Операції → Фотографування** спершу увімкніть зйомку фото, потім увімкніть **«Геотегування фото»** під цим пунктом - додаток одразу запитає дозвіл на геолокацію, а не в момент зйомки. Для фото з геотегом екран Інформації про файл показує дату зйомки і GPS-точку з EXIF-даних як посилання - торкніться, щоб відкрити її в картах або браузері.

### Чи можу я побачити свою статистику використання?
Так - типово збір вимкнено: увімкніть **«Збір статистики»** в **Налаштування → Загальні**, щоб відкрити локальну панель: скільки файлів відсортовано, скільки місця звільнено, час у програвачі та інше, з розбивкою за типом медіа. Нічого не надсилається автоматично; кнопки **«Надіслати автору»** та **«Експорт»** діляться зведенням, лише якщо ви самі цього захочете.

## Автоматичний переклад

### Як працює переклад?
Ми використовуємо **Гібридну систему OCR**:
- **Google ML Kit:** Для швидкого і точного розпізнавання мов на основі латиниці (Англійська, Німецька тощо).
- **Tesseract:** Для високоякісного розпізнавання кирилиці (Українська, Російська).

### Чому рекомендується режим "Auto"?
Режим "Auto" автоматично визначає вихідну мову і вибирає найкращий рушій. Це запобігає помилкам, таким як плутанина англійської 'C' та російської 'С'.

### Чи працює це без інтернету?
**Так.** Інтернет потрібен лише один раз для завантаження мовних моделей (близько 30МБ для ML Kit, 15МБ для Tesseract).

### Чому переклад іноді працює повільніше?
Якщо додаток виявляє кирилицю, він ініціалізує рушій Tesseract, який потужніший, але вимагає на 1-2 секунди більше часу для запуску, ніж ML Kit.

### Що таке режим перекладу "в стилі лінзи"?
**Режим лінзи** відображає переклади як накладення поверх вихідного зображення, подібно до Google Lens. Це дозволяє бачити перекладений текст у його початковому контексті та позиції. Увімкнути його можна в Налаштуваннях → Медіа → Переклад, оцифрування (OCR) → "Накладення в стилі лінзи".

**Стандартний режим** показує переклади в окремому текстовому полі під зображенням.

## Фонова музика для слайд-шоу

### Як додати фонову музику до слайд-шоу?
1. Додайте папку з аудіо файлами як ресурс
2. Перейдіть у **Налаштування → Медіа → Зображення**
3. Увімкніть **"Музика під час слайдшоу"**
4. Виберіть ваш музичний ресурс зі списку
5. Запустіть будь-яке слайд-шоу - музика гратиме автоматично!

### Чи можна використовувати музику з мережевих дисків або хмарних сховищ?
**Так!** Додаток автоматично обробляє мережеві файли, завантажуючи їх у кеш перед відтворенням. Це працює з SMB, SFTP, FTP, Google Drive, OneDrive та Dropbox.

### Як перемикати треки під час слайд-шоу?
Натисніть на **назву треку**, яка відображається під час слайд-шоу, щоб перейти до іншого випадкового треку з вашого музичного ресурсу.

### Чи працює це з усіма версіями?
**Ні.** Фонова музика доступна у:
- **Standard** (повна підтримка аудіо)
- **Legacy** (лише локальне аудіо)
- **Photos** (фонова музика для слайд-шоу підтримується)

Версія **Lite** не включає аудіо функції.

## Трансляції (Інтернет-радіо та відеопотоки)

### Що таке екран Трансляцій?
Виділений екран для відтворення інтернет-аудіо та відео з URL: http(s)-радіо, Icecast/Shoutcast, HLS (.m3u8), DASH VOD та RTSP-джерела. Ви можете додавати URL вручну, імпортувати .m3u-плейлист або завантажити кураторський каталог FastMediaSorter.

### Як увімкнути Трансляції?
1. Налаштування → Медіа → Трансляції
2. Увімкніть **«Увімкнути Трансляції»**
3. Відкрийте Трансляції через головне меню або кнопку-ярлик у тому ж розділі налаштувань

### Чи доступна ця функція у всіх версіях?
- **Standard / Legacy / XR:** повна підтримка (аудіо + HLS/DASH + RTSP)
- **Lite:** лише прогресивне аудіо (http(s) MP3/AAC); HLS/DASH/RTSP не підтримуються
- **Photos:** Трансляції повністю відсутні

### Радіостанція грає, але список зник. Де він?
Аудіо-потоки відтворюються **безпосередньо зі списку** - список залишається видимим та активним. Внизу екрана з'являється прилипаючий міні-банер із назвою станції та поточним треком (ICY-метадані).

### Потік не відтворюється або показує помилку
Якщо потік недоступний або перенаправлений, з'являється діалог **«Повторити / Видалити / Скасувати»**. Перехресне 301-перенаправлення обробляється автоматично. Якщо проблема повторюється - URL джерела міг змінитися; видаліть запис та додайте новий URL.

### Чи зупиниться радіо, якщо я перейду в інший застосунок?
Залежить від налаштування **«Фонове аудіовідтворення»** (Налаштування → Відтворення → Фонове аудіовідтворення). При вимкненому фоновому відтворенні - так, потік зупиниться при виході зі Трансляцій. При увімкненому - продовжує грати у фоні.

### Як імпортувати .m3u-плейлист?
На екрані Трансляцій натисніть **«Імпорт»** та введіть URL .m3u-файлу. Рядки з плейлиста додаються до вашого списку.

### Де взяти кураторський каталог FastMediaSorter?
Під час першого запуску (онбординг) або на екрані **Розширень** є можливість завантажити куровований каталог потоків. Записи каталогу мають теги теми та мови, підтримують пошук та сортування.

### Чи можна побачити живі мініатюри трансляцій?
Перемкніть перегляд на **Сітку** на панелі інструментів Трансляцій - кожен канал показується плиткою з останнім захопленим кадром, щоб одразу зрозуміти, що зараз в ефірі. Плитка залишається видимою навіть після перезапуску додатку, а потім оновлюється новим кадром, коли потік знову в ефірі.

### Чи можна транслювати потік на Chromecast?
Так, для відеопотоків - натисніть **Cast** у плеєрі та виберіть Chromecast у тій самій Wi-Fi мережі. RTSP-потоки транслювати не можна; кнопка з'являється лише для форматів, які підтримує приймач Chromecast.

## Wear OS

### Чи працює FastMediaSorter на смарт-годинниках Wear OS?
**Так!** FastMediaSorter v2 містить додаток-компаньйон для Wear OS, який дозволяє переглядати та відтворювати локальні медіафайли безпосередньо зі смарт-годинника.

### Які функції доступні на Wear OS?
Додаток для Wear OS наразі підтримує:
- Перегляд локальних папок
- Перегляд зображень
- Відтворення відео
- Відтворення аудіофайлів
- Базові елементи керування навігацією

**Примітка:** Функції мережі та хмари поки недоступні на Wear OS.

## Електронні книги EPUB

### Як увімкнути підтримку EPUB?
Налаштування → Медіа → **Документи** → **"Підтримка EPUB електронних книг"**

**Примітка:** Перезапустіть додаток після увімкнення для застосування змін.

### Як читати книгу EPUB?
1. Додайте папку з .epub файлами як ресурс
2. Відкрийте папку - ви побачите EPUB файли зі значком "E"
3. Натисніть на будь-який EPUB файл для відкриття в читалці

### Чи можна перемикатися між розділами?
**Так!** Використовуйте:
- **Кнопки Попередній/Наступний** внизу екрану
- **Свайп вліво/вправо** для зміни розділів
- **Кнопка Зміст** (іконка 📋) для відкриття списку розділів

### Чи можна налаштувати розмір шрифту?
**Так!** Під час читання використовуйте кнопки **-A/+A** внизу для зменшення/збільшення шрифту (діапазон 14-32px). Налаштування зберігаються для кожної книги.

### Чи можна шукати текст у EPUB?
**Так!** Натисніть кнопку **Пошук** (🔍) для відкриття панелі пошуку. Введіть запит і переміщайтеся по збігам кнопками Попередній/Наступний.

### Чи працює з мережевими/хмарними файлами?
**Так!** EPUB файли автоматично завантажуються в кеш при відкритті з SMB/SFTP/FTP/хмарних сховищ.

### Чи запам'ятовує місце читання?
**Так!** Додаток зберігає останній розділ, який ви читали. При повторному відкритті книги читання продовжується з місця зупинки.

### Що щодо темної/світлої теми?
EPUB читалка автоматично адаптується до теми додатка (Налаштування → Загальні → Колірна тема).

## Заплановані операції

### Що таке Заплановані операції?
Правила автоматизації на основі розкладу, які виконують операції Копіювання, Переміщення або Видалення між будь-якими ресурсами (локальні папки, мережа, хмара) за повторюваним розкладом - навіть коли застосунок закрито.

### Де налаштовувати Заплановані операції?
Налаштування → **Операції** → **Заплановані операції за розкладом**. Натисніть **"+"** для додавання нового правила.

### Чи виконуватиметься операція при закритому застосунку?
**Так.** Операції плануються через Android **WorkManager**, який запускає їх у фоні незалежно від стану застосунку.

### Чому запланована операція не запустилася точно вчасно?
Android може відкласти завдання WorkManager на кілька хвилин для економії батареї. Для надійнішого запуску надайте застосунку виняток з оптимізації батареї (Налаштування → Загальні → Оптимізація батареї). Мінімальний інтервал - 15 хвилин.

### Операція виконалась, але скопіювала 0 файлів
Зазвичай це правильно - означає, що всі файли вже є в папці-призначенні (операція за замовчуванням пропускає існуючі). Перевірте журнал операції: подивіться лічильник "пропущено" і "скопійовано".

Якщо ви очікували копіювання нових файлів, але цього не сталося:
- Переконайтеся, що як **джерело** обрано правильний ресурс (рекомендується віртуальний ресурс "Фото камери", а не шлях вручну)
- Перевірте, чи був доступний ресурс-призначення (SMB / хмара) у запланований час - якщо Wi-Fi був вимкнено, запуск пропускається і повториться наступного разу

### Чи можна переглянути, що було оброблено?
**Так.** Натисніть **«Журнал»** в розділі Запланованих операцій, щоб побачити історію кожного запуску з результатом по кожному файлу.

## Блок погоди

### Звідки береться погода?
Блок погоди на робочому столі використовує **Open-Meteo.com** - безкоштовний сервіс без ключів. Дані про погоду: Open-Meteo.com (CC-BY 4.0).

### Чи стежить застосунок за моїм місцем?
**Ні.** Місце ви вказуєте самі, дозвіл на геолокацію не запитується. Блок оновлюється приблизно раз на 20 хвилин, а без зв'язку показує останні дані з поміткою. За натисканням відкривається застосунок погоди пристрою.
