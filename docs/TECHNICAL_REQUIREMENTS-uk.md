# Технічні вимоги

[Технічна специфікація](V2_Specification-uk.html) | [Tech Stack, EN](TECH_STACK.html)

Тут розділено вимоги SDK з конфігурації та умови окремих функцій. Це публічний довідник, а не обіцянка встановлення на будь-який пристрій чи оголошення нового випуску.

## Вимоги SDK

На вузькому екрані прокрутіть таблицю SDK горизонтально, щоб побачити всі стовпці.

| Модуль або редакція | minSdk | targetSdk | compileSdk |
|---|---|---|---|
| `standard / noLegal / lite / photos` | 26 | 36 | 37 |
| `legacy / foss` | 23 | 36 | 37 |
| `vr` | 29 | 34 | 37 |
| `xr` | 26 | 36 | 37 |
| `wear: standard / noLegal` | 28 | 36 | 37 |
| `watchface` | 36 | 36 | 36 |

`minSdk` задає нижню межу встановлення; `targetSdk` обирає поведінку сумісності Android; `compileSdk` задає API для компіляції. Високий compileSdk не вимагає тієї самої версії Android на кожному пристрої.

## Пристрій і сервіси

- Базові редакції телефона потребують Android 8.0 / API 26. Legacy та FOSS мають нижню межу API 23; обмеження функцій і сумісність пристрою залишаються.
- VR потребує API 29 і сумісну гарнітуру/runtime для занурення; номер API сам по собі не доводить підтримку гарнітури.
- Застосунок Wear має нижню межу API 28. Окремому циферблату WFF v4 потрібні Wear OS 6 / API 36; його встановлюють на годинник, не на телефон.
- Обмін між телефоном і годинником потребує сумісних application ID, підписів і зв'язку. Namespace не є ідентифікатором сполучення.
- Локальні файли й document-tree потребують відповідних дозволів Android або доступу від користувача. Мережевим і хмарним функціям потрібні зв'язок та авторизація провайдера.
- Функціям, залежним від Google, потрібні відповідні сервіси Google. Це не означає, що вони обов'язкові для всіх хмарних і локальних функцій.
- У цих визначеннях Gradle немає єдиного обов'язкового порога RAM, heap чи вільного місця. Навантаження залежить від роздільності медіа, кодеків, кешу й операцій; розмір старого debug APK не є мінімальною вимогою.

## Доступність редакцій

Наявність flavor у збірці не означає публікацію його APK. Перевірені файли є в [розділі завантажень](../index-uk.html#download), а прапорці можливостей - у [згенерованій матриці](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/blob/main/docs/FLAVOR_MATRIX.md).
