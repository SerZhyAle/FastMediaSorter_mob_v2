## 注意：各版本的功能可用性

部分功能仅在特定版本中提供。下表来自 [FLAVOR_MATRIX.md](FLAVOR_MATRIX.md)（由构建本身自动生成）；之所以把 XR / noLegal 合并为一列，是因为它取决于头显硬件和旁加载构建规则。

| 功能 | Standard | Lite | Photos | Legacy | XR / noLegal | FOSS |
|---------|----------|------|--------|--------|--------------|------|
| 网络文件夹（SMB、SFTP、FTP） | ✓ | ✗ | ✓ | ✓ | ✓ | ✓ |
| 云存储（Google Drive、OneDrive、Dropbox） | ✓ | ✗ | ✓ | ✓ | ✓ | ✗ |
| 音频播放与歌词 | ✓ | ✓ | ✗ | ✓ | ✓ | ✓ |
| 后台音频播放 | ✓ | ✗ | ✗ | ✓ | ✓ | ✓ |
| 网络流媒体（广播、HLS/DASH、RTSP） | ✓ | ✗ | ✗ | ✓ | ✓ | ✗ |
| 文档查看器（PDF、文本） | ✓ | ✗ | ✗ | ✓ | ✓ | ✓ |
| EPUB 阅读器 | ✓ | ✗ | ✗ | ✓ | ✓ | ✓ |
| 翻译与 OCR | ✓ | ✗ | ✗ | ✓ | ✓ | ✗ |
| 图片编辑 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 主屏幕（启动器）模式 | ✓ | ✗ | ✗ | ✗ | ✓ | ✗ |

主屏幕模式是唯一一行会在合并列中出现分歧的功能：它在 **noLegal** 旁加载版本中提供，但不在 VR/XR 版本中提供，因为头显会提供自己的主屏幕环境。

音频之所以分成两行，是因为这是两个独立的构建决策：**Lite 可以播放本地音频文件**，包括歌词，但应用一离开前台就会停止播放--它没有后台播放服务。Lite 完全没有“网络流媒体”界面，因此广播和 HLS/DASH/RTSP 不只是受限，而是根本不存在。

如果某个功能标记为“✗”，请选择与你的硬件和分发渠道匹配的 **Standard** 或 **XR / noLegal** 版本。

## 家庭影音、电视与客厅场景

## 把 NAS 变成客厅媒体架 {#turn-a-nas-into-a-living-room-media-shelf}

**可用版本：** Standard、Photos、Legacy、XR/noLegal

**快速路径**

1. 把你的 NAS 添加为 SMB 资源。
2. 如果不想手动输入 IP 地址，运行 **扫描网络**。
3. 从电视盒子、平板电脑或手机打开该资源。
4. 直接从 NAS 开始浏览视频、照片或文档。

**场景详解**

- 为整个家庭的媒体库保留一个 SMB 资源，再按用途拆分子文件夹：电影、家庭照片、扫描件、说明书。
- 在设置阶段先运行一次 **测试连接**，确保资源稳定后再从沙发上依赖它。
- 如果 NAS 是通过电视盒子使用的，配一个蓝牙键盘或电视遥控器来加快导航。
- 如果浏览感觉变慢，先打开资源设置运行内置的速度检测，再考虑改动其他设置。

**适用场景**

- 你想要一个统一的媒体源，而不是把同样的文件复制到多台设备上。
- 你希望同一个媒体库既能用于幻灯片播放，也能用于文档阅读和播放。

**避免这样做**

- 不要一开始就折腾主机名问题。先用 IP 地址，之后再优化。
- 不要指望 Lite 版本能浏览 SMB 共享--该版本完全没有网络资源功能。

## 为房间展示屏运行带背景音乐的幻灯片 {#run-a-slideshow-with-background-music-for-a-room-display}

**可用版本：** Standard、Lite、Legacy、XR / noLegal（Photos 不支持音频）

**快速路径**

1. 添加一个图片资源和一个音乐资源。
2. 在 **设置 → 媒体 → 图片** 中启用 **幻灯片播放时播放音乐**。
3. 选择音乐资源。
4. 打开一个照片文件夹并点击 **播放**。

**场景详解**

- 使用本地图片文件夹或速度较快的 NAS 共享，过渡效果会更流畅。
- 单独保留一个用于舒缓背景音乐的音乐资源，让幻灯片的配乐可预期。
- 如果文件夹里既有图片又有视频，注意音乐会在视频开始播放时自动暂停。

**适用场景**

- 你想让电视盒子、平板电脑或旧手机充当房间里的数码相框。
- 你想要一套设置，能够循环播放家庭照片、活动照片或旅行相册，而不用手动搭建播放队列。

**避免这样做**

- 如果对流畅播放有要求，不要把图片和音乐都放在很慢的网络共享上。

## OpenXR VR 沉浸式影院 {#openxr-vr-immersive-cinema}

**可用版本：** Standard、Lite、Legacy、`vr`、noLegal（单眼 3D）；`vr` 和 noLegal（完整头显沉浸模式--两个版本都提供沉浸式视图，当应用检测到 OpenXR 头显且 VR 总开关已打开时会自动开启）

**快速路径--启用、配置、观看 3D**

1. **单眼 3D（每个版本都支持，无需任何设置）：** 打开任意 SBS/OU/180°/360° 文件--系统会自动检测并裁剪为单眼画面，使其在普通平面屏幕上正常显示。此功能由 **设置 > 播放器 >“单眼显示 3D 内容”**（默认开启）控制。如果想强制指定某种格式而不是依赖自动检测，可以在 `vr`/XR-noLegal 版本中打开播放器的控制对话框，在 3D 选项卡中选择模式--**自动检测**、**并排（SBS）**、**上下（OU）** 或 **单眼（禁用）**；该选择会针对该文件被记住。
2. **在 Quest 上完整沉浸（`vr` 或 XR/noLegal 版本）：** 戴上头显后，在播放器打开某个 3D 文件时点击 VR 徽标，或在浏览界面某个文件的溢出菜单中选择 **在 VR 影院中打开**，或者打开 **设置 > 媒体** 并点击 **测试沉浸模式** 试用示例内容。这三种方式都会为该内容打开逐眼渲染的 OpenXR 视图。
3. **观看：** 在沉浸式视图中，一条 HUD 状态条承载着各项控制--一个可用手柄射线拖动来定位的进度条（旁边显示已播放时间和总时长），以及仅在适用时出现的选择器：只有多条音轨时才显示音轨选择，只有该文件带字幕时才显示字幕选择，只有立体内容才显示立体深度选择。**隐藏** 和 **退出** 位于状态条的两端；隐藏状态条会将其完全移除，扣动扳机可将其唤回而不会触发被遮住的其他内容。摇杆每次拨动前进/后退 10 秒；按住 **握把键** 的同时拨动摇杆则改为在文件之间切换--上一个和下一个会遍历整个资源列表，而不仅仅是你打开的那个文件。安装后首次进入沉浸模式时会显示一份列出所有手柄按键映射的说明；按任意键即可关闭，之后随时可通过状态条上的 **帮助** 按钮再次调出。

**场景详解**

- 单眼 3D 完全不需要头显--这是在手机或平板上重温旧的 SBS/OU 素材最简单的方式。
- 完整沉浸模式需要 Quest 或其他 OpenXR 头显，以及支持该功能的构建版本--`vr` 版本或 XR/noLegal 旁加载版本（参见 [VR 旁加载指南](VR_SIDELOAD.md)）。
- 进入沉浸式视图后，360°/180° 照片和视频会渲染成环绕在你周围的球体/半球；普通 2D 文件则照常平面播放。

**适用场景**

- 你想在不使用单独 VR 媒体应用的情况下重温存档的 SBS/OU/360°/180° 素材。
- 你拥有一台 Quest，想立刻在自己的文件上试用完整沉浸模式，并能接受目前导航只支持上一个/下一个。

**避免这样做**

- 不要指望 Meta Horizon Store / Google Play 的 `vr` 版本现在就能进入沉浸模式--这部分仍在开发中。
- 定位、音轨与字幕选择以及立体深度只在头显内的 HUD 状态条上提供。文件操作不在其中--需要复制、移动或删除时，请返回平面界面。

## 在车载主机或音频播放器上收听网络电台

**可用版本：** Standard、Legacy、XR / noLegal--Lite 和 Photos 没有“网络流媒体”界面

**快速路径**

1. 打开主界面下拉菜单并点击 **网络流媒体**，或前往 **设置 > 媒体 > 网络流媒体**，如果开关未打开则将其打开。
2. 点击工具栏末尾的 **⋮**，选择 **添加电台**，粘贴任意电台链接（http:// 或 https://、.m3u8、rtsp://）。
3. 点击该电台所在行--音频会在底部的悬浮迷你控制条中开始播放。列表仍可滚动。
4. 想要更大的目录，可以点击 **导入** 并输入远程 `.m3u` 链接，或从 **扩展** 界面下载精选的 FastMediaSorter 目录。

**场景详解**

- 精选目录附带主题和语言标签；通过筛选按钮（激活时带圆点标记）按类型或语言筛选。AND/OR 开关可以让你匹配同时满足所有条件的电台，或满足任意一个条件的电台。
- 目录还按已命名的合集分组--“俄罗斯电视”“前苏联电台”“非洲电视”等。它们以工具栏正下方一排可滚动的标签形式出现；点击某个标签只查看该合集的频道，顺序与策展人排列的一致，点击 **全部** 返回全部列表。同一个频道可能属于多个合集，所以你可能会在一个国家分类和一个大洲分类下都遇到它。合集只是又一个筛选条件，而不是单独的界面：搜索、排序、类型与语言筛选，以及你的置顶都在合集内继续生效。如果下载的目录不带合集信息，这一排标签就不会出现。
- 搜索框右侧的两个小图标可以一键把广播和视频分开：点击音频或视频图标只保留该类型，再次点击已高亮的图标则显示全部内容。
- 用置顶图标把喜欢的电台固定在顶部--顺序与全局收藏夹相互独立。
- 把工具栏的视图切换按钮切换到 **网格**，即可以带有最后一帧截图的方块形式查看频道--便于快速浏览视频流。你选择的列表或网格视图会在下次打开“网络流媒体”时被记住。
- 如果某个流支持投屏且手机处于 Wi-Fi 网络下，在播放器中点击 **投屏** 即可发送到同一网络下的 Chromecast。RTSP 流无法投屏。
- 底部迷你控制条中会显示 ICY 正在播放的元数据（电台名称、当前曲目）。
- 你自己添加的电台可以发送到你的 Wear OS 手表：打开该行的 **⋮** 菜单并点击 **发送到手表**（该命令仅在 Wear 伴侣选项开启时出现）。传输到手表上的电台在目录刷新后仍会保留；如果同一地址后来出现在在线目录中，则以目录中的条目为准。
- 视频和 RTSP 流会在全屏播放器中打开；按返回键会回到网络流媒体列表，并保留滚动位置。
- 后台音频行为遵循 **设置 > 播放器 > 后台音频播放**：该选项关闭时，离开该界面音频就会停止，应用会提供“停止/继续播放”的选择。

**适用场景**

- 想在 Android 车载主机、音频播放器和媒体盒上收听网络电台，而无需单独的应用（TuneIn、RadioDroid、VLC 网络流）。
- 轻量 IPTV 用途：HLS/DASH 点播流可在全屏播放器中播放。

**避免这样做**

- 不要指望支持 HLS/DASH 的直播偏移（live-edge）播放--本版本仅支持点播（VOD）HLS/DASH。
- 不要在 Lite 或 Photos 版本上使用“网络流媒体”功能；这两个版本都没有该入口，因此任何协议在其中都不可用。

## 旅行、阅读与文档工作流

## 为没有稳定网络的旅行准备一个文件夹 {#prepare-a-folder-for-travel-without-stable-internet}

**可用版本：** Standard、Lite、Photos、Legacy、XR / noLegal（PDF 和 EPUB 阅读需要 Standard、Legacy 或 XR / noLegal）

**快速路径**

1. 为此次旅行创建或选择一个本地文件夹。
2. 在离开 Wi-Fi 之前，把需要的媒体、PDF、EPUB 或笔记复制进去。
3. 在 FastMediaSorter 中打开一次该文件夹，让缩略图和上次播放位置准备就绪。
4. 旅途中离线使用该文件夹。

**场景详解**

- 即使原始文件通常存放在 NAS 或云端，也要把旅行用的媒体集中放在一个本地文件夹里。
- 有意混合各种格式：登机牌 PDF、正在阅读的 EPUB、截图和离线音乐可以放在一起。
- 想在离线时只查看图片、只查看文档或只查看音频，可以使用筛选面板切换。

**适用场景**

- 飞机、火车、酒店以及云端流媒体不可靠的乡村地区。
- 你想要一个离线合集，而不是在好几个应用里分别查找。

**避免这样做**

- 不要等到最后一刻才测试这些文件在没有网络的情况下是否真的能打开。

## 随时随地阅读云端文档和 EPUB {#read-cloud-documents-and-epubs-on-the-go}

**可用版本：** Standard、Legacy、XR / noLegal--Lite 和 Photos 完全无法阅读文档或 EPUB；Lite 还额外没有云存储

**快速路径**

1. 在 **云存储** 中添加你的云服务商。
2. 打开包含 PDF 或 EPUB 的文件夹。

**场景详解**

**适用场景**

## 如何连接到网络驱动器（SMB） {#how-to-connect-to-network-drive-smb}

**所需条件：**

- 带共享文件夹的 NAS 或 Windows 电脑
- 两台设备处于同一 Wi-Fi 网络
- 该共享的用户名和密码

**可用版本：** Standard、Photos、Legacy、XR / noLegal

**步骤：**

1. 在主屏幕点击 **“+”** 按钮
2. 选择 **“网络文件夹（SMB）”**
3. 填写详细信息：
   - **自动发现（新功能）：**
     1. 点击 **“扫描网络”** 按钮
     2. 等待设备出现在列表中
     3. 从列表中选择你的设备
     4. IP 地址会自动填入

   - **手动输入：**

     ```
     Server/Path: \192.168.1.100\photos
     Username: john
     Password: ****
     Display Name: Home NAS (optional)
     ```

4. 点击 **“测试连接”** 进行验证
5. 点击 **“保存”**

**服务器地址格式：**

- Windows：`\192.168.1.100\share`
- Linux/Mac：`smb://192.168.1.100/share`
- 带端口：`smb://192.168.1.100:445/share`

**小提示：**

- 使用 IP 地址（而非主机名）以获得更高的可靠性
- 在 NAS 上启用 SMB v2/v3 以提高安全性
- SMB 默认端口：445

**故障排查：**
→ 参见 [TROUBLESHOOTING-zh-hans.md](TROUBLESHOOTING-zh-hans.md)

## 如何连接到 SFTP/FTP 服务器 {#how-to-connect-to-sftpftp-server}

**所需条件：**

- 已启用 SSH（SFTP）或 FTP 的服务器
- 已开放端口 22（SFTP）或 21（FTP）
- 用户名和密码（SFTP 也可使用密钥）

**步骤：**

1. 在主屏幕点击 **“+”** 按钮
2. 选择 **“SFTP / FTP”**
3. 选择协议：**SFTP** 或 **FTP**
4. 填写详细信息：

   ```
   Host: 192.168.1.100
   Port: 22 (SFTP) / 21 (FTP)
   Username: username
   Password: ****
   Remote Path: /home/user/photos (optional)
   ```

5. 点击 **“连接”**

**进阶：**

- **SSH 密钥认证：** 目前不支持（仅支持密码）
- **自定义端口：** 如果服务器使用非默认端口，请修改端口号

**故障排查：**
→ 参见 [TROUBLESHOOTING-zh-hans.md](TROUBLESHOOTING-zh-hans.md)

## 如何导入 Windows 伴侣共享 {#how-to-import-a-windows-companion-share}

**这是什么：** 伴侣功能来自同一作者开发的免费 Windows 媒体整理工具 [Fast Media Sorter for Windows](https://serzhyale.github.io/FastMediaSorter_Lite/)（原名 FastMediaSorter LITE）。它通过 SFTP 分享选定的电脑文件夹，并导出一个现成的连接--手机上无需手动配置服务器，也无需输入主机、端口或密钥。你可以通过在电脑屏幕上**扫描二维码**，或**导入一个 `.fmscfg` 文件**，把它带到手机上。

**可用版本：** Standard、Photos、Legacy、XR/noLegal（扫码需要摄像头；文件方式在所有版本都可用，包括 VR）

> 想要一个带截图、更易上手的版本？请查看场景指南 [通过扫码打开电脑文件夹](howto/scenario-companion-share-zh-hans.md)。

**获取 Fast Media Sorter for Windows：**

- 官网：[serzhyale.github.io/FastMediaSorter_Lite](https://serzhyale.github.io/FastMediaSorter_Lite/)
- 发布文件夹指南：[如何把电脑文件夹发布到 Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html)
- GitHub：[最新版本](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases/latest)（安装程序或便携版 ZIP）
- winget：`winget install SerZhyAle.FastMediaSorter`
- Microsoft Store：搜索 “FastMediaSorter LITE”（仍以旧名称上架）

**在电脑上：**

1. 安装并运行 **Fast Media Sorter for Windows**，打开设置中的 **共享** 选项卡。
2. 选择要共享的文件夹--应用会自行启动 SFTP 服务器、生成密钥并设置自启动。
3. 屏幕上会显示一个 **二维码**。如果你更喜欢文件方式，也可以 **保存 .fmscfg**。

**在手机上--方法 A，扫码（最快）：**

1. 在主屏幕 **点击“+”按钮**。
2. 点击 **“通过二维码导入”**--它位于四张资源类型卡片旁边，以及 SFTP 表单的头部。
3. 将摄像头对准电脑上的二维码（光线较暗时点击 **手电筒**），然后确认 **导入访问权限** 对话框。
4. 完成--每个共享文件夹会出现为一个只读资源，服务器密钥也会自动固定。

**在手机上--方法 B，导入文件：**

1. 在电脑上使用 **保存 .fmscfg**，并将文件传输到手机（邮件、Telegram 或共享位置均可）。
2. 点击 **“+”** -> **“SFTP / FTP”** -> **“从文件导入”**，选择该 `.fmscfg` 文件。如果它是作为 Telegram/邮件附件到达的，直接点击附件即可。
3. 确认 **导入访问权限** 对话框--只读资源随即出现。

**说明：** 二维码和配置文件都内嵌了访问密码--请像对待密钥一样对待它们，不要公开发布截图或文件。**“通过二维码导入”** 入口在没有摄像头的设备和 VR 头显上会被隐藏；在这些设备上请使用方法 B。

## 如何使用触控区域 {#how-to-use-touch-zones}

**什么是触控区域？**

屏幕被划分为 9 个不可见区域，用于快速操作：

```
┌─────────┬─────────┬─────────┐
│  返回   │  复制   │  重命名  │
│   (1)   │   (2)   │   (3)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  上一个 │  移动   │  下一个 │
│   (4)   │   (5)   │   (6)   │
│         │         │         │
├─────────┼─────────┼─────────┤
│  命令   │  删除   │  播放   │
│   (7)   │   (8)   │   (9)   │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**说明：**

1. **返回** - 回到文件列表
2. **复制** - 把文件复制到目标文件夹
3. **重命名** - 重命名当前文件
4. **上一个** - 转到上一个文件
5. **移动** - 把文件移动到目标文件夹
6. **下一个** - 转到下一个文件

## 如何用 FileDO 加密文件 {#how-to-encrypt-a-file-with-filedo}

FileDO 容器是一个带 `.fd-sec` 扩展名的文件，其中锁着另一个由密码保护的文件。该格式与 FileDO 桌面应用使用的格式相同，因此在这里创建的容器可以在 FileDO 中打开，反之亦然。

**开启相关命令：** **设置** → **管理** 选项卡 → **FileDO 加密操作**。无论此开关是否打开，打开容器都能正常工作。

**加密文件：**

1. 在浏览界面，打开该文件的 **⋮** 菜单。
2. 点击 **用 FileDO 加密**。
3. 输入两次密码并确认。
4. 容器会以 `<name>.fd-sec` 的形式出现在原文件旁边。原始文件保持不变--如果不再需要，请自行删除它。

**解密文件：** 打开该 `.fd-sec` 文件的 **⋮** 菜单，点击 **用 FileDO 解密** 并输入密码。还原后的文件会出现在容器旁边。

**不还原直接打开容器：** 在显示所有文件类型的任意文件夹中点击该 `.fd-sec` 文件。应用只会询问密码，然后在查看器中打开其中的文件。解密后的副本保存在应用的私有存储中，返回列表后即被删除。勾选 **记住密码并在每个 .fd-sec 文件上自动尝试** 可以在下次跳过输入提示。

**支持的位置：** 设备文件夹、通过系统文件夹选择器选取的文件夹，以及 SMB、SFTP 和 FTP 共享。在选择器文件夹或网络共享上，文件会作为私有副本处理，结果先以临时名称写回，读取校验后才会重命名生效--已有文件永远不会被直接覆盖。

**如果无法打开：** 提示信息会列出三种可能的原因--密码错误、该文件本来就不是容器，或容器已被修改。这三种情况无法区分。含有程序或脚本的容器不会被打开。

**忘记密码了？** 没有办法找回。空密码只能防止随意的偷看。

## 如何操作文件夹（选择、复制、移动）

当子文件夹在列表中以独立条目显示时，文件夹行的行为与文件行相同。

**开启文件夹行显示：** **设置** → **常规** → **单独显示子文件夹**。资源编辑器中每个资源也有相同的开关。

**步骤：**

1. 点击文件夹行上的复选框，或长按该行，即可选中单个文件夹。短按仍然会打开该文件夹。
2. 使用该行的 **⋮** 菜单或选择操作栏，选择 **复制**、**移动**、**重命名** 或 **删除**。
3. 选择目标位置。同一选择中的文件和文件夹会在一次操作中一起移动。
4. 目标位置会获得完整结构--源文件夹内的每个子文件夹和文件。

**跨资源类型：** 文件夹可以在设备、SMB、SFTP、FTP 和云资源之间复制或移动--接收方会重建相同的结构。

**会被拒绝的情况及原因：** 目标位置位于该文件夹内部，或就是该文件夹当前所在位置时，操作会在开始前就被拒绝；通过系统文件夹选择器选取、没有真实文件路径的目标位置无法接收文件夹。提示信息会说明原因，方便你另选目标。

**取消：** 文件夹传输会显示进度，并且可以停止。已经写入的内容会保留在目标位置--重新开始前请先检查该文件夹。移动操作只有在源项目复制成功后才会删除它，所以过程中不会丢失任何内容。

**放到后台执行：** 你不必一直盯着进度对话框。关闭它，传输会继续在后台运行，并在浏览界面底部以一条状态条的形式显示操作内容、百分比和当前处理的文件。点击该状态条可以重新打开完整的进度对话框，也可以取消。

## 自动翻译 {#auto-translation}

自动翻译来自图片、PDF 和文本文件的文字：由 **Tesseract** 识别文字，Google ML Kit 负责翻译。

**主要功能：**

- **单一识别引擎：** **Tesseract** 可识别拉丁文和西里尔文文字（英语、俄语、乌克兰语、保加利亚语、白俄罗斯语）；Google ML Kit 负责翻译结果并识别其语言。
- **离线：** 完全在设备本地运行（首次下载模型之后）。
- **智能浮层：** 译文会以易读的段落形式叠加在原文上。

**设置：**

1. **设置** → **媒体** 选项卡 → **其他**
2. 启用 **“启用翻译”**
3. 选择 **源语言**：
   - **“自动”：** 先用英语模型识别文字，再检测识别结果的语言用于翻译。
   - **指定语言：** 使用该语言的模型识别--西里尔文文字请选择对应语言（例如“俄语”）。
4. 选择 **目标语言**（例如英语）。

**使用方法：**

1. 打开一张 **图片**、一个 **PDF** 或一个 **文本** 文件。
2. 点击屏幕以显示 **命令面板**。
3. 点击 **“翻译”** 按钮（A→文 图标）。
4. **首次运行：**
   - 确认下载源语言的文字识别模型。
   - 确认下载该语言对的翻译模型。
5. 译文会以浮层形式显示。

**说明：** 首次使用某种语言会加载其文字识别模型，这会带来短暂的延迟。

## 主屏幕智能小组件 {#home-screen-smart-widgets}

**可用版本：** 所有版本--小组件集在每个构建中都提供；但每个小组件遵循各自的能力限制，例如语音录制小组件需要支持麦克风的构建（Lite 和 Photos 不支持），而相框和资源类小组件在所有版本中都能使用

**快速路径**

1. 前往 Android 主屏幕，长按并选择 **小组件**。
2. 把一个 **FastMediaSorter** 小组件（例如 1×1 快速语音录制或相机 OCR）拖到屏幕上。
3. 配置目标文件夹和捕获设置，然后点击 **保存**。
4. 使用该小组件，一键在主屏幕上直接执行任务。

**场景详解**

- 把 1×1 小组件当作专用的启动图标，立即开始后台操作（例如，点一次开始录音，再点一次保存到你的 NAS）。
- 设置一个 **定时操作小组件**，用于监控后台文件传输或触发一次“全部运行”操作。
- 放置一个 **随机照片相框小组件**，展示直接从 SMB 共享获取的家庭照片轮播。

**适用场景**

- 你想在主屏幕上放一些快捷方式，用于日常捕获（收据、语音备忘），而不用打开完整的应用界面。
- 你需要清晰直观的小组件来控制媒体或立即触发定时操作。

**避免这样做**

- 如果你的 Android 桌面启动器限制了自定义小组件，请不要尝试添加。

## 如何把本应用用作主屏幕 {#how-to-use-the-app-as-your-home-screen}

FastMediaSorter 可以接管设备的主屏幕，显示它自己的桌面--你的文件夹、时钟、天气、应用，以及沿一侧边缘排列的任务栏。如果你用过 Windows 桌面，会感到很熟悉：东西放在哪儿就一直在哪儿，一个开始按钮打开菜单。这被称为启动器模式，仅在 **Standard** 和 **noLegal** 版本中提供。

**开启方法：**

1. 打开 **设置 → 常规**，开启 **将本应用设为主屏幕**。
2. Android 会要求你确认。在 Android 10 及更新版本上，这是一个单一问题--“允许 FastMediaSorter 成为你的主屏幕应用吗？”--直接允许即可。在更旧的版本上，下次按下 Home 键时会出现经典的选择对话框：选择 FastMediaSorter 并点击 **始终**，或者如果只是想先试试，点击 **仅此一次**。
3. 按下 Home 键。桌面会出现，并且已经预置了大约十几种实用内容--时钟、天气、你的文件夹、搜索框--所以第一天就不是一个空白网格。

在全新安装时有一条捷径：在首个欢迎页勾选 **用作主屏幕**。这不会用系统对话框打断安装流程--Android 的确认会在你之后第一次打开 **设置 → 常规** 时出现。

**桌面上有什么：**

| 单元格类型 | 作用 |
|-----------|--------------|
| 资源快捷方式 | 打开你添加的某个文件夹--你可以选择它以浏览、幻灯片还是播放模式打开 |
| 小挂件 | 带秒针的时钟（点击设置闹钟）、你所在地的天气、当前正在播放的内容、一个翻译器，以及另外二十多种 |
| 应用快捷方式 | 启动任意已安装的应用；长按可列出该应用自身的快捷操作 |
| 联系人单元格 | 打开某人的名片、拨打电话、发送短信，或打开与其的即时通讯对话 |
| 应用小组件 | 与应用为 Android 主屏幕提供的相同小组件，只是放在这里 |

**任务栏与开始菜单：**

- 任务栏位于底部边缘，包含开始按钮、你最近使用的应用、你固定的应用，以及一个显示时钟、电池、网络和 SIM 信号的小托盘。
- 想放在顶部？**设置 → 常规 → 系统启动器设置 → 任务栏 → 任务栏位置** 可在 **底部** 和 **顶部** 之间切换。开始菜单会跟随任务栏，如果任务栏在顶部，菜单就会从上方展开。
- 开始按钮会打开菜单：打开 FastMediaSorter、你的资源、添加资源、Android 设置、应用设置、启动器设置、编辑桌面内容，末尾还有重启、关机和 **退出启动器模式**。重启和关机只有在设备允许普通应用执行这类操作时才会生效--在大多数手机上它们不会有任何效果。

**你的应用：** 应用网格会把应用分成若干分组，每组都有一个小标题。点击标题可折叠你不常打开的分组；折叠后的标题会彼此紧挨在一起，让桌面变短而不是留下空隙。全新的桌面会把预置的应用分成两组：一个 **Google** 分组，放你已安装的 Google 应用；一个 **应用** 分组，放你自己的应用--即时通讯、游戏以及你安装在设备上的其他任何东西。没有应用会同时出现在两组里。长按列表中的任意应用可看到 **放到桌面** 和 **固定到任务栏**。

**重新排列：**

- 长按桌面上的一个空白方格。会出现四个选项：**添加项目..**、**编辑桌面**、**壁纸**、**启动器设置**。新单元格会正好落在你长按的那个方格上。
- **添加项目..** 会打开一个选择器：一个应用、一个功能、你的某个文件夹、一个电台、一个联系人、一个系统操作、一个定时操作、一个小挂件，或一个动作。小挂件中包括“正在播放”卡片--它会显示设备上正在播放的内容，一键跳转到对应的播放器--以及翻译器单元格。
- **编辑桌面** 会开启编辑模式，与开始菜单中的 **编辑桌面内容** 相同。编辑期间：拖动一个单元格来移动它，拖动小挂件的边角控制柄来调整大小，点击 **+** 添加内容，在单元格上选择 **从桌面移除** 可将其移除。完成后点击 **完成**。
- 与他人共用设备？在启动器设置中打开 **锁定桌面**--长按操作将不再起作用，布局也就不会被意外碰乱。
- 其他应用也可以像在任何其他主屏幕上一样，把自己的快捷方式放在这里。

**竖屏和横屏是两个独立的桌面。** 你在竖屏下排列的内容，在把设备转为横屏后并不会保留--每种方向都有各自的布局和各自的折叠分组。应用只会在你第一次旋转已经排列好的桌面时提示一次这一点。设置本身--任务栏位置、密度、壁纸--是两种方向共享的。

**在屏幕上容纳更多或更少内容：** **设置 → 常规 → 系统启动器设置 → 桌面 → 网格密度** 提供 **稀疏**、**标准**、**紧密** 和 **超紧密**--单元格更宽松，或每屏放更多快捷方式。

**恢复到你原来的主屏幕**--以下三种方式任选其一：

- 打开开始菜单，选择 **退出启动器模式**，并确认。
- 在 **设置 → 常规** 中关闭 **将本应用设为主屏幕**。
- 直接进入 Android 自身的主屏幕应用列表：**设置 → 常规 → 系统启动器设置 → 系统 → 更改主屏幕**。

无论用哪种方式，你的桌面布局都会被保留，所以再次切回该模式时会完全恢复到你离开时的样子。

**一个诚实的提醒。** 有些设备无法记住这个选择。一些廉价的改装车载主机和其他内置 Android 设备，每次启动都会强制恢复它们的出厂主屏幕，无论你选择了什么。这是设备自身固件在覆盖你的选择，不是应用的缺陷，也没有任何应用能绕过它。如果你的设备是这样，请在重启后重新选择 FastMediaSorter 作为主屏幕应用--如果仍然无法保持，那说明这台设备本身就不允许这样做。

## 如何在 Android TV Box 上使用 FMS {#how-to-use-fms-on-android-tv-box}

FastMediaSorter 可以运行在任何 Android TV 盒子或机顶盒上（小米盒子、Nvidia Shield、Amazon Fire TV、通用 Android 盒子）。无需触摸屏--应用完全可以通过电视遥控器或蓝牙键盘操作。

**所需条件：**

- 运行 Android 8.0+（Standard/Lite/Photos）或 Android 6.0+（Legacy 版本）的 Android TV 盒子
- 带方向键的电视遥控器，或蓝牙键盘
- 可选：家庭 NAS（SMB）、U 盘或带媒体内容的 SD 卡

**使用电视遥控器导航：**

| 按键 | 操作 |
|--------|--------|
| 方向键 上/下/左/右 | 在项目间移动焦点 |
| 确定/回车 | 打开项目或确认 |
| 返回 | 回到上一屏幕 |
| 退格 | 在浏览界面中返回上一级文件夹 |
| 红色键 | 删除选中的文件 |
| 绿色键 | 复制选中的文件 |
| 黄色键 | 移动选中的文件 |
| 蓝色键 | 重命名选中的文件 |
| 频道加/频道减 | 播放器中的上一个/下一个文件 |

**步骤：**

1. 从 Google Play 安装应用，或旁加载一个 APK。推荐使用 Standard 版本。
2. 在主屏幕上，用方向键选中（+）按钮并按 **确定** 以添加资源。
3. 选择 **本地文件夹** 以使用 U 盘/SD 卡存储，或选择 **网络文件夹** 通过 SMB 连接到 NAS。
4. 添加资源后，用方向键 + 确定进入该资源浏览文件。
5. 打开任意视频、图片或音频文件--播放器可以完全通过遥控器操作。
6. 要开始幻灯片播放，打开一个图片文件夹并在命令栏中导航到 **幻灯片** 按钮。
7. 要为幻灯片添加背景音乐，前往 **设置 → 媒体 → 图片**，启用 **幻灯片播放时播放音乐**，并选择你的音乐资源。

**小提示：**

- 按住方向键上/下可以加速滚动浏览较长的文件列表。
- 在蓝牙键盘上按 **F1** 可在任意界面打开针对该界面的快捷键参考。
- 电视遥控器的彩色按键可以在 **设置 → 管理 → 控制与按键绑定** 中重新分配。

## 如何使用应用内相机 {#how-to-use-the-in-app-camera}

**可用版本：** Standard、Lite、Photos（仅拍照）、Legacy、XR/noLegal

**步骤：**

1. 在浏览界面，打开工具栏或溢出菜单，点击 **用相机拍照**（照片）或 **录制视频**。
2. 如果改变主意，可以直接在相机界面在 **照片** 和 **视频** 之间切换。
3. 用预设标签（0.5x/1x/2x..）或下方的滑块设置变焦--两者会保持同步。
4. 点击画幅按钮来改变取景框--**4:3**、**16:9** 或 **全屏**。取景器本身会随之变化，因此所见即所得，保存的照片就是你看到的样子，这个选择也会在下次打开相机时被记住（默认为 16:9，直到你更改它）。
5. 点击拍摄场景按钮来选择拍摄方式--普通、夜景、人像、自拍、微距、运动或文档。微距会切换到专用的近焦镜头，自拍会切换到前置摄像头，运动模式会保持较短的曝光时间以凝固动作，文档模式则针对拍摄平整的页面和屏幕做了优化。列表中只会显示设备实际支持的场景，按钮上会标出当前场景，手动切换镜头会让相机回到普通模式。
6. 点击快门（或录制按钮）进行拍摄。结果会直接保存到你正在浏览的资源--无论是本地还是网络资源。

**小提示：**

- 点击取景器中的任意位置可以对焦并在该处设置曝光--一个小圆环会标出对焦点。
- 边缘手势的 **开始视频录制** 操作会直接以视频模式打开相机，并在预览就绪后立即开始录制--速度很快，但这个特定的快捷方式会保存到设备的“影片”文件夹，而不是你正在浏览的资源。
- 在相机设置旁打开 **为照片添加地理标记**，即可把 GPS 位置嵌入每张拍摄的 JPEG--该选项默认关闭，需要手动开启。之后 **文件信息** 会显示拍摄日期和照片 EXIF 中的 GPS 位置，并以可点击的链接形式在地图应用或浏览器中打开。

**在哪里找到相机设置：** 设置 → 管理 → 摄影。

## 如何查找并删除重复文件 {#how-to-find-and-delete-duplicate-files}

**步骤：**

1. 在浏览界面打开一个文件夹，然后打开工具栏中的 **溢出菜单** <img src="icons/doc/ic_more_vert.png" alt="" width="18" height="18" style="vertical-align:text-bottom">。
2. 点击 **查找重复项** 以自行检查匹配结果，或点击 **查找并删除重复项** 立即将其移除。
3. 对于 **查找重复项**，应用会预先选中每组中除最旧那一份之外的所有副本--调整选择后，点击 **删除所选** 并确认。
4. **查找并删除重复项** 会在扫描完成后立即删除同样预先选中的副本，没有确认步骤--如果想在删除前再次核实，请先使用 **查找重复项**。

**改为按大小清理：**

1. 在同一个溢出菜单中，点击 **按大小删除..**
2. 选择 **小于** 或 **大于**，设置一个大小，然后点击 **分析**。
3. 查看数量和可释放的空间，然后点击 **删除文件** 进行确认。

**说明：**

- 扫描通过三个步骤按内容匹配文件--先比较大小，再进行快速哈希比较，最后进行完整的 SHA-256 校验--因此重命名过的重复文件依然能被发现。
- 按大小删除会在删除任何内容之前显示能释放多少空间；网络和云端来源不经过回收站，因此该删除是立即且永久的。

## 如何使用 SD 卡或已连接的驱动器 {#how-to-use-an-sd-card-or-connected-drive}

手机挂载的存储卡或 U 盘，其上的资源与内置存储完全相同。

**步骤：**

1. 打开 **添加资源** 并开始添加本地文件夹。**可移动介质** 分区只在有设备连接时出现，会列出每个卷及其名称和可用空间。
2. 点击该卷。如果应用无法按路径访问它，会说明原因并打开系统文件夹选择器--在其中选择同一个卷，并授权访问你想要的文件夹。
3. 该资源会以带有可移动介质图标的形式加入列表，让存储卡资源一眼就能识别出来。

**移动与复制：** 完整的文件夹结构可以在存储卡与手机之间来回传输，方式与设备和网络资源之间的传输相同。

**空间不足时：** 装不下的复制或移动操作会在开始前就被拒绝，提示信息会说明是哪个介质、还缺多少空间--请腾出空间或另选目标。

**介质被弹出时：** 相关资源会被标记为不可用，而不是被移除。重新连接存储卡后即可恢复使用，无需重新设置。

**在 Android 6 上：** 系统不会向应用报告已挂载的卷，因此这些设备上的可移动介质分区始终为空。

## 如何重新连接以直接路径添加的文件夹 {#how-to-reconnect-a-folder-added-by-direct-path}

以输入或浏览路径方式添加的文件夹，可以显示你的照片、视频和音乐，但不会显示任何文档。这不是扫描漏掉了它们：应用商店版本只会通过用系统选择器连接的文件夹来读取文本文件、PDF 和电子书。重新连接会让同一个资源通过该选择器指向同一个文件夹，文档随即出现。

**步骤：**

1. 点击主列表中该文件夹卡片上的三点菜单。
2. 选择 **重新连接资源**。系统文件夹选择器会打开，在手机允许的情况下会直接定位到该文件夹。
3. 选择同一个文件夹并确认。
4. 如果你选择了不同的文件夹，应用会列出两个文件夹的名称，并在做出改动前先询问你。

**会保留的内容：** 名称、在列表中的位置、PIN、图标、快速分类角色、你的收藏夹和你的定时任务都会保留--资源只是被重新指向了新地址，而不是重新创建。

**你不会在哪里看到它：** 在仍然直接按路径读取文件夹的版本上，以及在 Android 10 及更早版本上，这个入口不存在，因为在那里没有任何内容缺失。

## 如何选择截图和下载内容的保存位置 {#how-to-choose-where-captures-and-downloads-are-saved}

应用内相机拍摄的照片、截图、快照和自动下载的文件，各自都会写入你指定的文件夹，这个文件夹不一定要是你的某个资源。

**步骤：**

1. 打开你要保存内容对应的设置--拍摄、截图、快照或自动下载。
2. 选择目标文件夹。系统文件夹浏览器会打开，因此你可以指定任意本地文件夹，包括从未添加到应用中的文件夹。
3. 该文件夹只会成为这一项设置的写入目标。它不会出现在你的常规资源列表中，所以为截图选一个临时文件夹不会让主屏幕变得杂乱。

**小提示：**

- 这四项设置各自拥有自己的目标位置--截图和相机照片完全可以保存到不同的地方。
- 如果你更希望把所有内容都放在一个地方，把它们都指向同一个文件夹也没问题。

### 捕获文件命名 {#capture-file-names}

新的捕获内容使用 `prefix_yyMMdd_HHmmss` 格式命名。固定的前缀有 `photo`、`screenshot`、`audio`、`video`、`screen_video` 和 `video_frame`，因此文件名本身就能表明其来源。如果目标文件夹中已存在同名文件，应用会在扩展名前添加 ` (2)` 后缀。在相机中手动输入的文件名会作为覆盖项保留，不会被更改。

## 如何接收其他应用分享的文件 {#how-to-receive-files-shared-from-another-app}

任何应用的分享面板都可以把文件发送给 FastMediaSorter，随后由它复制到你想要的位置。

**步骤：**

1. 在其他应用中分享文件，选择 **FastMediaSorter**。
2. 在接收界面选择目标文件夹。
3. 开始复制。

**你不必等待它完成。** 复制会在接收界面关闭后继续在后台运行，进行中会显示带进度的通知，完成后显示结果通知。你可以离开应用、锁定设备、继续做其他事--传输不依赖该界面保持打开。

在 Standard、Lite、Photos 和 Legacy 版本中可用。

## 如何使用内置小程序 {#how-to-use-the-built-in-programs}

**可用版本：** 所有版本--程序菜单和面板在每个版本中都提供，但每个程序遵循各自的能力限制：网络监视器需要 Standard 或 noLegal，Wear 伴侣程序需要 Standard 或 noLegal，小游戏在 XR 和 noLegal 中不提供，镜子功能需要前置摄像头且已在设置中启用拍照捕获。计算器、前置手电筒和系统信息在所有版本中都提供。

除了浏览和播放文件之外，应用还内置了一组小程序--计算器、屏幕台灯、网络监视器、语音录音机等等。它们默认关闭：每一个都由各自的设置开关控制，大多数专用开关都集中在 **设置 → 管理** 中。

**快速路径**

1. 前往 **设置 → 管理**，打开你想要的项目--例如 **计算器**、**前置手电筒**、**网络监视器**、**小游戏** 或 **系统信息**。
2. 打开主界面下拉菜单。你已启用的程序会列在其中。
3. 点击其中一个来运行它。

**程序会出现在哪里**

一个程序最多可以出现在四个入口上，每个入口的内容和顺序都取自同一份列表，因此它们绝不会互相脱节：

- **程序菜单** - 主界面下拉菜单，以及重复该内容的程序面板。
- **应用启动面板** - 快速访问浮层。
- **主屏幕小组件** - 仅限拥有专属小组件的程序；从应用自身的小组件选择器中固定它。
- **启动器桌面** - 当你把本应用用作主屏幕时，打开某个程序会自动添加对应的单元格。

**包含哪些程序**

按出现顺序：

- **快速拍摄** - 直接拍一张照片进入应用。
- **语音录制** - 录制一段语音备忘录。
- **计算器** - 带历史记录和记忆存储的科学计算器。
- **网络监视器** - 当前网络连接、Wi-Fi、移动网络、蓝牙和位置的实时读数，以及一个逐跳走访主机路由的路由追踪工具，即使某一跳没有响应也会继续计数。
- **照片 OCR 翻译** - 拍摄文字并翻译。
- **屏幕视频录制** - 录制屏幕。
- **通过链接下载** - 从粘贴的链接获取文件。
- **小游戏** - 应用内置的小游戏。
- **系统信息** - 一份无需打开设置即可查看的设备报告。
- **Wear 伴侣程序** - 手表界面，见于带有手表桥接功能的版本。
- **前置手电筒** - 把屏幕本身变成一盏灯：它以窗口最大亮度打开为白色，垂直滑动改变亮度，左上角一个小按钮可选择并记住另一种颜色，单击可关闭。只会调整窗口亮度，因此关闭后你设备本身的亮度设置不受影响。
- **防水手电筒** - 为湿手准备的同一种光源。它会同时点亮相机闪光灯和屏幕，然后锁定屏幕：你只能看到时间和一句简短提示，触摸玻璃屏幕不会有任何反应--按音量键即可关闭。系统栏也会隐藏，这样湿手就不会碰到导航按钮；用力滑动仍然可以把它们唤回。专为雨天和淋浴设计--这是两个玻璃屏幕会对水做出反应而不是对你做出反应的场景。通过系统手势离开也会同时关闭灯光，所以它不会一直亮在口袋里。手表上没有闪光灯，所以只有屏幕本身作为光源。它不能替代手表或手机自带的水下锁定模式；没有任何应用可以开启那个模式。
- **镜子** - 把手机变成一面带灯的镜子：前置摄像头填满整个屏幕，处于一片能照亮你面部的明亮白色区域中，画面会像真实镜子那样被翻转，角落有一个按钮可以在不离开该界面的情况下关闭补光。变焦预设--x1、x2、x3、x5--位于左下方，默认打开为 x3。拍照按钮和录像按钮会直接保存到“拍摄”功能所使用的同一个文件夹，视频带声音。变焦、翻转和补光状态都会在多次运行之间被记住。仅会调高窗口亮度，不会更改你设备本身的亮度设置，因此离开屏幕后手机会恢复正常。在任何带前置摄像头的设备上默认开启，前提是设置中的拍照捕获功能没有被关闭。

面板和启动器还额外提供直接相机快捷方式--拍照并发送、拍照并编辑、拍照并翻译、开始录制视频，以及打开相机文件夹。

**适用场景**

- 你想在不离开本应用、也不用在拥挤的手机上另找一个应用的情况下使用计算器或手电筒。
- 你把本应用用作主屏幕，想为常用的工具放一个一键单元格。

**避免这样做**

- 不要指望防水手电筒能在滑动回主屏幕后仍然亮着--系统导航手势仍会让它退出，光也会随之熄灭。
- 不要指望每个版本都包含全部程序--上面列出的是完整集合，如果某个版本没有对应能力，该条目就不会显示。

## 如何让语音助手查找并打开媒体 {#how-to-ask-your-assistant-to-find-and-open-media}

**可用版本：** 所有版本，且需要 Android 16 及更新版本。更旧的 Android 版本完全不提供该功能，且应用中无需开启任何设置。

在 Android 16+ 上，应用会向系统注册一组助手操作--用 Android 自己的说法就是 AppFunctions。你设备上的语音助手随后可以按名称调用它们，因此你可以直接开口要求查找一张照片、一段视频或一个电脑文件夹，而不用打开应用自己浏览。

**你可以要求的内容**

- **搜索你的媒体** - 助手会把你说的话交给应用的搜索功能，并显示匹配结果。
- **打开一个媒体文件** - 一张照片、一段视频或一首曲目会直接在应用的查看器或播放器中打开。
- **打开一个电脑文件夹** - 你的某个网络或云端文件夹会在浏览界面中打开。

**快速路径**

1. 确认设备运行 Android 16 或更新版本，并已设置系统语音助手。
2. 向助手描述你想要的媒体内容，如果设备上装有多个媒体应用，请说出 FastMediaSorter 的名字。
3. 应用会打开对应的结果--搜索列表、文件，或你要求的文件夹。

**适用场景**

- 你腾不出手--正在做饭、开车，或抱着孩子--无法逐个点击文件夹。
- 你记得文件叫什么名字，但不记得存在哪里。

**避免这样做**

- 不要指望它在 Android 16 以下也能用：助手操作是新系统的一部分，旧手机上的助手看不到它们。
- 不要指望助手能访问带 PIN 保护的文件夹--锁定依然生效，该文件夹会照常要求输入 PIN。
