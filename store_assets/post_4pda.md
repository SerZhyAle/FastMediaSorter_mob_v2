[B]О программе[/B]

Приложение создавалось для пользователей, у которых медиатека распределена между локальным хранилищем, домашним NAS и облаками. Цель — единый инструмент вместо 5–8 отдельных приложений.

[B]Подключаемые источники:[/B]
[LIST]
[*]Локальное хранилище Android
[*]SMB (NAS, сетевые папки Windows, Samba)
[*]SFTP / FTP
[*]Google Drive, Dropbox, OneDrive
[/LIST]

[B]Просмотр и воспроизведение (стриминг без скачивания):[/B]
[LIST]
[*]Видео — ExoPlayer: жесты яркость/громкость/перемотка, субтитры, скорость ×0.25–×2, PiP (Android 12+)
[*]Аудио — фоновое воспроизведение, управление с экрана блокировки, таймер сна
[*]Изображения — OCR и AR-перевод поверх текста на фото (в стиле Google Lens, работает на файлах с NAS)
[*]PDF — просмотр с темами, OCR, встроенный перевод, открытие напрямую с NAS/облака
[*]EPUB — ридер с темами, переводом текста
[*]GIF, TXT/редактор
[/LIST]

[B]Управление файлами:[/B]
[LIST]
[*]Копирование/перемещение между любыми источниками напрямую (например, SFTP → Google Drive без локального хранилища)
[*]Переименование с шаблонами, удаление в корзину
[*]Пакетные операции с мультивыбором
[*]Поиск дубликатов с SHA-256 — работает кросс-источник (NAS vs локальное, облако vs NAS)
[/LIST]

[B]Автоматизация:[/B]
[LIST]
[*]Операции по расписанию (cron-стиль, WorkManager) — например, перенос фото с камеры на NAS каждую ночь
[*]Фильтры: по типу файла, по временному окну (всё / новые / за час / за сутки)
[*]Атомарный MOVE: сначала копирование + проверка, потом удаление источника
[*]Продолжает работать после перезагрузки
[/LIST]

[B]Производительность и надёжность SMB:[/B]
[LIST]
[*]Пул соединений — SMB-сессии переиспользуются, не создаются заново на каждый файл
[*]До 24 параллельных потоков передачи
[*]Кэш списка файлов в Room DB — большие папки NAS открываются мгновенно при повторном входе
[*]Зашифрованное хранилище учётных данных с журналом последнего использования
[/LIST]

[B]Дополнительно:[/B]
[LIST]
[*]Wear OS компаньон: просмотр NAS и управление воспроизведением с часов
[*]Виджеты для главного экрана
[*]PIN-код на отдельный ресурс
[*]Режим «только чтение» для защиты папок от случайных изменений
[*]Сохранение позиции просмотра для каждого ресурса
[/LIST]

[B]Флейворы (разные APK):[/B]
[LIST]
[*][B]Standard[/B] — полный набор функций (видео/аудио/фото/облака/документы), Android 8.0+
[*][B]Lite[/B] — только видео + фото, Android 8.0+
[*][B]Legacy[/B] — полный набор без облаков, Android 6.0+
[/LIST]
