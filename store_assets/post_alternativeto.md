DESCRIPTION (paste into the AlternativeTo description field):

FastMediaSorter v2 is an Android media management app that unifies local storage, NAS (SMB/Windows shares), SFTP, FTP, Google Drive, Dropbox, and OneDrive into a single interface.

Unlike standalone file managers or media players, FastMediaSorter is built for mixed-protocol workflows: you can stream video directly from a NAS without downloading it, copy files between SFTP and Google Drive without a local staging step, and schedule automated transfers between any two sources in the background.

Built-in capabilities include an ExoPlayer-based video player with gesture controls, subtitle support, and Picture-in-Picture; a background audio player with lock screen controls and sleep timer; a full EPUB and PDF reader with reading themes and in-app translation; an image viewer with OCR and AR translation overlay (works on network files without downloading); and a SHA-256 duplicate file finder that works across local, NAS, and cloud sources simultaneously.

For power users, the app includes cron-style scheduled file operations (move camera photos to NAS nightly, clear downloads daily), up to 24 parallel SMB transfer threads with connection pooling, file list caching for large network directories, and an encrypted credential vault with a last-used audit trail.

Additional features: Wear OS companion app for browsing NAS and controlling playback from the wrist; home screen widgets; PIN protection per storage resource; batch rename with pattern templates; recycle bin with restore.

Supports Android 8.0 and above (Android 6.0 via Legacy flavor).
