# Format: <repo-relative path>|<ceiling bytes>|<stretch bytes>|<where the text goes instead>

# A ceiling goes DOWN on a run that passed and never up. Lower it with -UpdateBaseline; do not
# hand-edit a number upward, and never drop a rule to fit under one (S2517 ADR-4).
#
# A ratcheted ceiling carries SLACK (S2708): -UpdateBaseline writes min(old ceiling, size + 1024),
# so a page that was just compacted has room for one ordinary rule line instead of zero. Measured
# 2026-09-07 over the numbered rule lines of CLAUDE.md - median 140 B, p75 540 B, 37 of 41 under
# 1024 B - so the slack admits a rule statement and refuses an incident narrative. The min() form
# is what stops it accumulating: once the file has grown into the granted slack the next run
# computes min() against an unchanged ceiling and writes the same number, so the upper bound stays
# the historic minimum plus one slack. Before this, the ceiling equalled the size and all three
# files below sat on it to the byte, which made a better compaction the harsher constraint.
#
# A stretch at or above the ceiling means no target below the ceiling has been set yet. S2517
# section 6 item 4 defers that number until after the first rationale move, because before it any
# target is assigned blind.
#
# Seeded 2026-09-04 at the sizes measured that day. The floor those sizes sit in was 75702 tokens
# per request, 37.8% of all billed cache_read (S2513).
#

# judges it and carries three correctness checks that only make sense for a memory directory.
