# S1639 - Gson persistence contract: exemption registry.
#
# One entry per line: <fully qualified name> :: <justification>
# The name is either a model or enum the gate judges, or a repo-relative source path when the finding is
# a serialization point whose type the gate cannot resolve statically.
#
# An entry with no justification is refused with exit 2. A registry that accepts a bare name degenerates
# into a list nobody rereads, which is the failure strategic S1639 section 7 names as the main threat to
# this gate's value.
#
# The file is a ratchet, like the other count baselines in this repository: removing an entry is always
# accepted, adding one is a deliberate act that shows up in review.
#
# A justification opening with `Ticket: Sxxxx` records a live defect owned by that ticket rather than
# excusing it. Those are counted separately in the verdict line, so a green run states out loud how many
# known defects it is still carrying.
