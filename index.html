💡 Usage Scenarios

Each block starts with a quick answer and opens into practical detail when you need the setup path.

🖼️

Digital Photo Frame

Standard / VR

Turn an Android tablet into an always-on frame that streams photos from SMB/NAS or cloud without filling local storage.

Details
  • Add a photo source from SMB/NAS, local storage, or cloud.
  • Enable slideshow intervals and optional background music.
  • Use an old tablet, TV box, or desk device as the display.
Open guide
🚗

In-Car Music

Standard OnlyLegacy

Use an Android head unit as a focused music player for local, USB, or network libraries.

Details
  • Create or open an audio resource for the full collection.
  • Keep playback alive through the background audio service.
  • Use large controls, steering-wheel buttons, and notification playback controls where supported.
Open guide
🍿

Home Cinema & VR

Standard / VR

Watch films and series from a PC, NAS, or cloud on phone, TV box, or VR headset without copying files first.

Details
  • Connect the video library over SMB, SFTP, FTP, local storage, or cloud.
  • Use session restore and auto-advance for serial playback.
  • Open supported 3D and 360° media in flat mode or the VR edition.
Open guide
🧹

Download Organizer

All editions

Clear a messy Downloads folder by sending files to prepared destinations in one tap.

Details
  • Create destination buttons for work, photos, archives, music, and temp files.
  • Use copy or move depending on how much risk you want.
  • Undo protects the last operation when a file lands in the wrong place.
Open guide
📷

Scheduled Camera Backup

Standard

Copy new camera photos and videos to a PC or NAS over Wi-Fi during night charging.

Details
  • Use SMB as the destination and choose the camera folder as the source.
  • Set skip-existing copy mode to avoid duplicate uploads.
  • Run it on a schedule that matches Wi-Fi and charging availability.
Open guide
📡

SMB Network Setup

All editions

Connect Android devices to a Windows, macOS, Linux, or NAS shared folder over the local network.

Details
  • Share the folder on the computer or NAS and keep both devices on one Wi-Fi network.
  • Use network scan when possible, or enter the IP address manually.
  • Run Test Connection before using the resource in daily workflows.
Open guide
🧳

Offline Travel Folder

All editions

Prepare one local folder with media, PDFs, EPUBs, screenshots, and notes before unreliable internet starts.

Details
  • Copy the travel set while Wi-Fi is stable.
  • Open the folder once to warm thumbnails and remembered positions.
  • Use filters to jump between documents, images, audio, and video offline.
Open related guide

Cloud Documents & EPUB

Standard for cloudAll editions locally

Read PDFs and EPUBs from cloud storage or local folders with reader-friendly controls.

Details
  • Open Google Drive, Dropbox, OneDrive, or a local document folder.
  • Use PDF themes, EPUB formatting, and reading-position restore.
  • Send niche formats to specialist apps when Android has a better viewer.
Open related guide

OCR Translation

Standard / VR

Extract and translate text from images, scans, screenshots, and PDFs without leaving the viewer.

Details
  • Open an image, PDF, or text file and run Translate/OCR.
  • Use ML Kit for fast recognition and Tesseract models when quality matters.
  • Review the translated overlay directly on the original content.
Open related guide

NAS Media Shelf for TV

StandardLite / Photos

Use a NAS as the shared media shelf for an Android TV box, tablet, or living-room phone.

Details
  • Create one SMB resource for family media and split it into clear subfolders.
  • Use network speed checks when streaming feels slow.
  • Pair a remote, keyboard, or gamepad for couch navigation.
Open related guide
🧬

Duplicate Cleanup

Standard / VR

Find identical files across storage before a photo archive or download folder grows out of control.

Details
  • Scan by size, partial hash, and full SHA-256 to avoid risky name-only matching.
  • Review matches before removal, or use auto-delete for trusted sets.
  • Use it after imports, backups, and manual folder merges.
Open feature details
📺

Chromecast Playback

Standard Only

Send audio, images, and local video from the phone to a Cast receiver in the room.

Details
  • Use a Cast-compatible receiver on the same network.
  • Stream local media and supported audio/image sessions directly.
  • Keep VR separate: Cast support depends on Google Play Services on the device.
