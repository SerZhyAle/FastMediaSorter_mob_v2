1.Специальные операции с ресурсом (элемены меню «Resource Operations» в Browse):
1.1 Найти и удалить дубликаты: Поиск с последующим автоматизированным удалением копий.
1.2. Удаление по размеру: Быстрая очистка — удаление всех файлов меньше или больше заданного порога (например, удалить все мелкие эскизы или очень тяжелые видео)
1.3. Заархивировать - применяется к выбранным файлам. Если файлы не выбраны - опция серая (выключена). Если выбраны - открывается диалог с выбором папки назначения (в ресурсе или в другом ресурсе) и именем архива (автоназвание по первому файлу из выбранных). Если в папке назначения уже есть файл с таким именем - добавить суффикс _1, _2 и т.д.
1.4 Создать каталог в ресурсе (видна, если включены "Show subfolders separately" в настройках этого ресурса)
1.5 "Автоматизация.." - диалог добавления текущего ресурса в качестве источника для новой "операции по расписанию", если включены "операции по расписанию". 
1.6 "В получатели" - сделать текущий ресурс получателем. Видна если ресурс не только для чтения, не является ещё получателем, лимит получателей не достигнут.

2. Разархивировать по клику на архив - диалог - ок - в эту же папку создастся папка с именем архива, пересканировать ресурс

3. Для документов из проигрывателя в меню (там где у медиафайлов "Транслировать..") - "на печать" (на принтер - диалог ос андроид)

4. Опция "Включить операции по расписанию" включена автоматически (по умолчанию при установке)
