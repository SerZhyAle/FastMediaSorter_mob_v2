# Спецификация: Ассоциация файлов и Временные Ресурсы (Утверждено)

## 1. Цель
Реализовать механизм регистрации приложения в ОС Android как обработчика по умолчанию для медиаданных (Audio, Video, Images) и документов (EPUB, PDF, TXT), а также корректную обработку входящих файлов с созданием "Временных ресурсов" в памяти.

---

## 2. Функциональные Требования

### 2.1 Регистрация для открытия файлов (Intent Filters)
Приложение должно объявлять поддержку открытия следующих типов файлов из внешних источников:
*   **Аудио**: `audio/*` (MP3, FLAC, AAC и т.д.)
*   **Видео**: `video/*` (MP4, MKV, AVI и т.д.)
*   **Изображения**: `image/*` (JPG, PNG, GIF, WebP)
*   **Документы**: `application/pdf`, `text/plain`, `application/epub+zip`.

### 2.2 Обработка Входящего Файла (Startup Intent)
При запуске через внешний файл (например, клик в проводнике):
1.  **Извлечение Uri**: Получение `Intent.ACTION_VIEW` и `intent.data`.
2.  **Резолвинг пути**: Преобразование `content://` в абсолютный путь (благодаря разрешению `MANAGE_EXTERNAL_STORAGE`).
3.  **Определение Папки**: Извлечение родительской директории открытого файла.
4.  **Формирование плейлиста**: Сканирование папки на наличие файлов того же типа для работы кнопок "Вперед/Назад".

### 2.3 Система "Временных Ресурсов" (Virtual Folders)
*   **In-Memory**: Создается объект ресурса исключительно в оперативной памяти (`id = -1`, `isTemporary = true`).
*   **Навигация**: Поддерживается перелистывание файлов внутри найденной папки.
*   **История (Недавние)**: Открытый файл должен добавляться в список/историю недавних просмотров (при наличии такого функционала), чтобы пользователь не потерял доступ к файлу после выхода.

### 2.4 Обработка Аппаратных Кнопок (Автомобиль / Наушники)
*   Реализовать `MediaButtonReceiver` для старта `AudioPlaybackService` из фонового состояния при нажатии кнопок Play/Pause.
*   **Связь с настройками**: Данный функционал активен **только** если включена опция "Фоновое воспроизведение" (Play in background).

### 2.5 Пользовательский интерфейс (UI)
*   **Welcome Screen**: Страница с тумблерами для активации типов ассоциаций (Audio, Video, Docs, Images).
*   **Settings Screen**:
    *   Создание кнопок-триггеров.
    *   **Поведение**: Открытие стандартного экрана "О приложении" (или "Приложения по умолчанию") с предварительным показом **диалогового окна-инструкции** (как установить приложение дефолтным вручную).
*   **Панель Просмотра (Header)**: Показ плашки "Временный ресурс" и кнопки **`➕ Сохранить`** для закрепления папки на диске в список ресурсов навсегда.

---

## 3. Технические детали и ограничения

*   **Флаворы (Flavors)**: В сборках `lite` и `photos` не поддерживаемые типы фильтров (например, Audio) должны отключаться программно при первом запуске через `PackageManager.setComponentEnabledSetting()`.
*   **Предусловие доступа**: Требуется активное разрешение `MANAGE_EXTERNAL_STORAGE` для корректного детектирования родительских папок.
