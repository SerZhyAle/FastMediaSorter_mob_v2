# Анализ логов (2026-05-04)

На основе изучения предоставленных лог-файлов выявлены следующие проблемы, аномалии и области для улучшения в приложении:

## 1. Проблема с кэшированием директорий (Subfolder Mismatch)
**Где найдено:** `fastmediasorter_20260504_193855.log`, `fastmediasorter_20260504_194029.log`
**Сообщение:** `Cache does not contain initialFilePath=/storage/emulated/0/Music/... (subfolder mismatch), reloading from /storage/emulated/0/Music`
**Описание:** Приложение не может найти начальный файл в текущем кэше из-за несовпадения подпапок, что вызывает полную перезагрузку родительской директории (reloading). 
**Как улучшить:** 
- Оптимизировать логику загрузки кэша для рекурсивных вложенных папок, чтобы избежать "холодных" перезагрузок при переходе от файла к файлу. 
- Проверить, правильно ли формируются ключи кэша при глубокой вложенности.

## 2. Экстремально медленное сканирование сети (SFTP)
**Где найдено:** `fastmediasorter_20260504_194029.log`
**Сообщение:** `ScanMetrics: SLOW SCAN detected — 265757ms (threshold: 6000ms) resourceId=33 type=SFTP`
**Описание:** Сканирование SFTP-ресурса заняло более 4 минут (265 секунд) при ожидаемом пороге в 6 секунд.
**Как улучшить:**
- Реализовать адаптивный тайм-аут и отображение прогресса для пользователя.
- Внедрить кэширование структуры удаленных директорий и пагинацию при получении списков файлов по протоколам SMB/SFTP.

## 3. Отсутствие поддержки `CREATE_DOCUMENT` (ActivityNotFoundException)
**Где найдено:** `fastmediasorter_20260504_195053.log`
**Сообщение:** `android.content.ActivityNotFoundException: No Activity found to handle Intent { act=android.intent.action.CREATE_DOCUMENT typ=application/zip ... }`
**Описание:** При экспорте логов на специфической прошивке (SPRD) система не может найти обработчик для `CREATE_DOCUMENT`. Механизм фоллбэка (`falling back to share`) отрабатывает, но приложение бросает и логирует полный StackTrace исключения.
**Как улучшить:**
- Превентивно проверять поддержку интента через `intent.resolveActivity(context.packageManager) != null`.
- Если обработчик не найден, сразу вызывать логику `share` без генерации и отлова `ActivityNotFoundException`.

## 4. Ошибки загрузки обложек по сети (Glide 404)
**Где найдено:** `fastmediasorter_20260504_195053.log`
**Сообщение:** `Glide load FAILED class n23: Failed to load resource ... status code: 404`
**Описание:** Попытка загрузить обложку аудиофайла (вероятно, по сети или из несуществующего пути) заканчивается ошибкой 404 и массивным дампом в лог.
**Как улучшить:**
- Добавить более тихую обработку ошибок 404 для изображений в Glide, избегая лишнего замусоривания логов (например, используя кастомный `RequestListener` или проверяя метаданные перед запросом).
- Убедиться, что при 404 показывается локальная заглушка (placeholder) `CANVAS_WAVES` без мерцания.

## 5. Обрыв сетевого соединения (SMB)
**Где найдено:** `fastmediasorter_20260504_101109.log`
**Сообщение:** `NetworkStateMonitor: Network lost ... SmbConnectionManager: Network lost - closing all SMB connections`
**Описание:** Система обнаружила кратковременную потерю сети и сразу закрыла все соединения SMB.
**Как улучшить:**
- Проверить стабильность воспроизведения сетевых файлов в таких ситуациях. 
- Возможно, стоит внедрить небольшую задержку (debounce) или механизм прозрачного реконнекта перед жестким закрытием всех активных сессий (если файл уже кэшируется/буферизуется в `PlayerMediaLoaderManager`).
