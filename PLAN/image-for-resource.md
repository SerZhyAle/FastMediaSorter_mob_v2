много ресурсов с одинаковыми картинками. Обычно это картинка какашки, если ресурс не предопределенная музыка и там "нотка"
Я хочу расшириить юзер интерфейс. Пусть во время регистрации нового ресурса ему подбирается артинка случайным образом из некоторой библиотеки картинок, в зависимости от типа ресурса. То есть в программе должны храниться 10 картинок для музыки (киконок), 10 для видео, 10 для изображений, 10 для документов, 20 для всего остального.

При демонстрации в главном экране в сетке или списке - картинка ресурса собираетяся из пазла - подложка это тип ресурса (локальный/SMB/SFTP/FTP/Dropbox/Onedrive/GoogleDrive) + выбранная картинка пользователем или оставленная по умолчанию при создании.

подложка - пустая для локального, значек интернет для SFTP и FTP (чуть другой для FTP), брендовые значки для dropbox, onedrive, googledrive а в центре выбранная иконка.

Должны заменить собой значек ресурса и нажиматься (как уже реализовано)

Соответственно нужно поставить дизайнеру задачу разработать этот сет иконок векторных.
Нужен промпт
Иконки для фототек - домики, цветочки, машинки
иконкидля музыки - скрипичные ключи, ноты, музыкальные инструменты
иконки видео - кинозал, кинопленка, голливуд
иконки документов - книги, папки , визитки
иконки для остальных ресурсов (сборных) - шарики, ромбики, кубики и прочие абстрацкии

задача привести основной экран к большему различию для ресурсвов

При создании ресурса (любого типа в ландшатеили портрете) программа должна задавать ему одну иконку наугад по типу ресурса, она должна быть видна как кнопка прмо в шапке (над кнопками "сохранить"). По нажатии на эту кнопку можно выбрать одну из иконок
При выбре типа ресурса (например видеотека) - должен назначаться случайным образом один из образов для видео. Но пользовательможет по кнопке этой сверху поменять на любой другой.

В окне редакции ресурса всё то же самое - та же кнопка и тма же. Если пользователь переопределили тип ресурса - сменился на случйный из сета по типу. Но можно поменять и выбрать любой другой

Прорамма должна каждой иконке в своей библитеке задавать уникальный индекс - и так и хранить за ресурсами. В будущем можно будет деполнять сет иконок

Уже существующие ресурсы получают иконки рандомно при первом запуске (обновлении базы данных) из своего сета (по типу)

Предопределенные ресурсы должны получить иконки по своему типу, но не случайные а первые из сета. Чтобы "Все фото" на всех устройствах имело одинаоковую картинку
