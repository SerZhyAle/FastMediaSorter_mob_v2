### Step 01.1 - Publish the played URI through `requestMetadata`

**Files:** `app_v2/src/main/java/com/sza/fastmediasorter/ui/player/helpers/AudioServiceController.kt`
**Depends on:** - start of phase

**Prompt for developer:**

> In `playAudioWithMetadata`, add `.setRequestMetadata(MediaItem.RequestMetadata.Builder().setMediaUri(uri).build())` to the `MediaItem.Builder` chain, next to `.setUri(uri)`. Add a comment naming S1382 and the reason: `MediaItem.toBundle()` drops `localConfiguration`, so a client `MediaController` cannot read the played URI any other way. Do not change `playAudio`, `playAudioPlaylist`, or `playAudioPlaylistWithMetadata` - only the single-item path streams use.

**Why:**

Strategic §5 makes the channel icon depend on the stream URL read from the client-side `MediaController`, and strategic §6 item 4 records that media3 strips `localConfiguration` on the way to the controller, so without this field the bar has no URL to look up and the icon branch can never fire.

### Step 01.2 - Give `InlinePlaybackAnimator` a configurable turn and a freeze

**Files:** `app_v2/src/main/java/com/sza/fastmediasorter/ui/browse/InlinePlaybackAnimator.kt`
**Depends on:** - independent of Step 01.1

**Prompt for developer:**

> Add a second constructor parameter `noteDurationMs: Long = DEFAULT_NOTE_DURATION_MS` and use it as the `duration` of the note animator; move the current literal `1200` into a `DEFAULT_NOTE_DURATION_MS` constant in the companion object so the existing browse call site keeps its current speed unchanged. Add `pauseNote()` and `resumeNote()`: `pauseNote()` calls `pause()` on the running note animator, `resumeNote()` calls `resume()` on a paused one and does nothing when there is no animator. Leave `stopNote()`, `startDownload()`, `stopDownload()`, `stopAll()` and the detach guard exactly as they are.

**Why:**

Strategic §6 item 3 fixes the bar's turn at 3 s while the browse list keeps its 1.2 s turn, and §6 item 2 requires the rotation to freeze on pause and continue from where it stopped - `stopNote()` resets `rotation` to `0f` and therefore cannot express a freeze.
