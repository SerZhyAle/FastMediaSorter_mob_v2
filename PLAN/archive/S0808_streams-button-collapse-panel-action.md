## 1. Проблема

Панель трансляций в основном окне постоянно занимает вертикальное место, даже когда пользователь ей сейчас не пользуется. У панели программ уже есть пункт «Свернуть панель» (S0807), сворачивающий её в узкую полоску, а у панели фильтров - тот же механизм (S0781); у панели трансляций такого пункта нет. В её long-press меню (кнопка-вход «трансляции») есть «Открыть», «Настроить», «Спрятать панель», «Отключить», но нет способа временно свернуть панель, сохранив быстрый доступ. Затронуто: основное окно (`ui/main`).

---

## 2. Цели

1. В long-press меню кнопки-входа трансляций добавлен пункт «Свернуть панель» между «Настроить» и «Спрятать панель».
2. «Свернуть панель» превращает панель трансляций в узкую цветную полоску с подписью «трансляции..»; тап по полоске разворачивает панель обратно.
3. Свёрнутое состояние сохраняется между запусками приложения.
4. Поведение единообразно с уже существующим сворачиванием панели программ (S0807) и панели фильтров (S0781) - тот же стиль полоски, тот же персист.

**Non-goals:**

- Новый механизм сворачивания - переиспользуется уже существующий (полоска-«ярлычок» S0781/S0807).
- Изменение остальных пунктов меню кнопки-входа (Открыть / Настроить / Спрятать / Отключить - S0779/S0780/S0782).
- Per-channel меню закреплённых каналов (сворачивание относится к панели, не к каналу).
- Подпись активного/текущего канала на свёрнутой полоске (как и в S0781/S0807 - точка расширения, вне первой итерации).
- Группировка свёрнутых полосок панелей в одну строку - отдельный тикет S0809.

## 3. Пожелания и ограничения

### 3.1 Пожелания владельца

1. Свёрнутая полоска выглядит как сворачиваемые панели «копировать в..» / «переместить в..» плеера (тот же цветной стиль полоски, что и у S0781/S0807).
2. Свернуть - осознанный жест (пункт меню), развернуть - лёгкий (тап по полоске), по аналогии с панелью программ.

### 3.2 Жёсткие ограничения

- **Flavor:** только там, где панель трансляций существует (`SUPPORT_STREAMS=true`: standard, legacy, noLegal, vr). На lite/photos панель отсутствует, флаг свёрнутости безвреден и не показывается.
- **API level:** без API-специфики (PopupMenu, DataStore - от API 23).
- **Wear OS:** не затрагивается.
- **Производительность:** незначимо; новых тяжёлых ресурсов не вводится.
- **Совместимость данных:** добавляется один булев флаг в существующее хранилище настроек (DataStore), рядом с флагами свёрнутости программ/фильтров; без изменения схемы БД; в backup/import не включается (как `programsPanelCollapsed`).
- **Локализация:** EN/RU/UK обязательно для нового пункта меню и подписи полоски.
- **Доступность:** свёрнутая полоска - стоп фокуса D-pad/клавиатуры (разворот по центральной кнопке); отличие не только цветом - есть текстовая подпись; фокус передаётся при своп-переходах полоска↔контент.

### 3.3 Owner inputs (Approval gate)

- **Позиция пункта:** «Свернуть панель» между «Настроить» и «Спрятать панель» (порядок Configure → Collapse → Hide, как у панели программ S0807).
- **Свернуть - жест разворота:** тап по полоске разворачивает панель обратно; кнопка-вход и каналы возвращаются.
- **Свернуть - персист:** свёрнутое состояние переживает перезапуск приложения (по аналогии с S0781/S0807), не сессионное.
- **Цвет и подпись полоски:** тот же именованный цвет полоски, что у S0781/S0807; подпись - новый ключ «трансляции..» (EN/RU/UK).
- **Related tickets:** S0807 (сворачивание панели программ - прямое зеркало), S0781 (сворачивание панели фильтров - тот же механизм), S0779/S0780/S0782 (существующее меню кнопки-входа трансляций), S0809 (группировка свёрнутых полосок - использует эту полоску).

## 4. Контекст текущей архитектуры

Панель трансляций основного окна строит отдельный UI-помощник (кнопка-вход «трансляции» + горизонтальный список закреплённых каналов). У кнопки-входа уже есть long-press меню, собираемое общим компонентом контекст-меню из списка действий `Action(@StringRes, () -> Unit)`; часть действий - колбэки хоста (Открыть в новом окне / Настроить / Спрятать / Отключить), сгруппированные в отдельном объекте (S0779/S0780/S0782). Видимость всей панели владеет основное окно (флаг настроек + флейвор-гейт), помощник только рендерит. Механизм «панель ↔ узкая цветная полоска с персистом булева флага» уже реализован для панели программ (S0807) и фильтров (S0781): чистая функция видимости, своп `isVisible` между контентом и полоской, флаг в DataStore. Чего нет у панели трансляций: свёрнутого состояния, подписанной полоски и обработчика её разворота.

## 5. Предлагаемый подход

Добавить в long-press меню кнопки-входа один пункт «Свернуть панель», а самой панели - свёрнутое состояние по образцу S0807. Свёртка запускается пунктом меню, разворот - тапом по полоске. Логика сворачивания живёт в помощнике панели трансляций (не в активити и не как новый host-колбэк), персист - один булев флаг в существующем хранилище.

### 5.1 Основные столпы / модули

- Новый пункт меню кнопки-входа «Свернуть панель» (в том же билдере контекст-меню).
- Свёрнутое состояние панели трансляций: узкая цветная полоска с подписью, своп с контентом внутри корня панели; корень остаётся под управлением видимости основного окна.
- Персист свёрнутости - булев флаг в существующем хранилище настроек, рядом с флагами свёрнутости программ/фильтров.
- Новая локализованная подпись полоски и переиспользование существующего цвета полоски.

### 5.2 Потоки данных и событий

- Long-press по кнопке-входу → меню; тап «Свернуть панель» → помощник переключает состояние в «свёрнуто»: прячет контент, показывает полоску, пишет флаг.
- Тап по полоске → помощник возвращает «развёрнуто»: прячет полоску, показывает контент, пишет флаг.
- При инициализации помощник читает флаг и применяет состояние; видимость всей панели по-прежнему решает основное окно (свёрнуто/развёрнуто применяется только когда панель показана).

### 5.3 Точки расширяемости

- Помощник изолирует логику полоски, чтобы позже добавить на неё подпись текущего канала или включить полоску в группировку свёрнутых панелей (S0809).
