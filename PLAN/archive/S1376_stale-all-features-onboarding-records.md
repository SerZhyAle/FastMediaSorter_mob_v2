## 1. Проблема

Запись инвентаря возможностей про выбор языка на первой странице приветствия описывает механику, которой в приложении больше нет: полосу из трёх кнопок EN/RU/UK. Фактически там кнопка, показывающая текущий язык и открывающая поисковый выбор из полного списка языков. Инвентарь - источник, из которого релизный конвейер генерирует публичную витрину возможностей, поэтому устаревшее описание может уехать в публикацию.

---

## 2. Цели

### Уточнение объёма после исследования

Проверены все 20 записей области онбординга. Дрейф подтверждён ровно в одной - про выбор языка. Соседние проверены и оказались точными:

- запись про выбор темы описывает три кнопки Auto/Light/Dark с немедленным применением - разметка первой страницы и подсказка «тема применяется сразу» это подтверждают;
- запись про многостраничный мастер перечисляет страницы профиля, сетей, возможностей, разрешений и плеера по умолчанию - набор типов страниц адаптера совпадает.

То есть массовой ревизии области не требуется, правится одна запись.

### Наблюдаемые улучшения

1. Описание выбора языка в инвентаре совпадает с тем, что видит пользователь на первой странице приветствия.
2. Публичная витрина, генерируемая из инвентаря, не может опубликовать описание несуществующей полосы из трёх кнопок.
3. У записи появляется происхождение - тикет, который заменил механику, вместо пустого поля.

**Non-goals:**

- Не ревизовать записи вне области онбординга.
- Не менять сам UI выбора языка и не трогать публичную витрину напрямую - она генерируется релизным конвейером.

## 4. Контекст текущей архитектуры

Инвентарь возможностей - строчный JSON-файл, единственный источник правды о том, что приложение умеет, с записью на возможность. Публичная витрина на трёх языках генерируется из его диффа релизным конвейером и вручную не правится. Значит, устаревшее описание в инвентаре нельзя починить в витрине - его чинят в источнике.

## 5. Предлагаемый подход

Переписать описание записи про выбор языка под текущую механику и проставить ей происхождение. Запись обновляется штатной командой инвентаря по тому же идентификатору, поэтому для витрины это правка, а не пара «удалили-добавили».

### 5.1 Основные столпы / модули

- **Запись инвентаря про выбор языка** - новое описание и происхождение.

### 5.2 Потоки данных и событий

Разметка первой страницы приветствия → запись инвентаря → дифф релиза → публичная витрина.

### 5.3 Точки расширяемости

Нет - точечная правка данных.
