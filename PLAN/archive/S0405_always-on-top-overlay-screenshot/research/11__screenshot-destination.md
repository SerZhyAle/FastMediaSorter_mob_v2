# 11 - Назначение по умолчанию: папка скриншотов устройства → Downloads

**Research item:** §6.11
**Дата:** 2026-06-11
**Статус:** Resolved (предварительно)

## Вопрос

Как надёжно определить «папку скриншотов устройства» и куда сохранять при её отсутствии.

## Находки

- Каноничных путей два, вариативны по вендорам: `Pictures/Screenshots` (большинство, AOSP/Pixel) и `DCIM/Screenshots` (часть вендоров, ранее Samsung). Жёстко зашивать один путь нельзя.
- Системные скриншоты индексируются в `MediaStore.Images`; на Android 10+ доступен столбец относительного пути (`RELATIVE_PATH`), по которому можно обнаружить фактическую папку скриншотов, по которой система уже что-то складывала.
- Если папка скриншотов не обнаружена/недоступна - корректный fallback в `Downloads` (стандартная общая папка, всегда есть).
- Запись своих снимков лучше вести через `MediaStore` (scoped storage), чтобы не зависеть от прямых путей и `MANAGE_EXTERNAL_STORAGE`.

## Вывод для спеки

- Опция «Загружать скриншоты в..» по умолчанию указывает на обнаруженную папку скриншотов устройства; при её отсутствии - Downloads; пользователь может переопределить любым ресурсом приложения (включая сетевой).
- Определение папки - через `MediaStore`, без жёстко зашитых путей; конкретная стратегия обнаружения - на фазе `/spec-tech`.
- Ложится на существующую модель ресурсов/назначений (тот же слой, что у Share-приёмника), новой формы хранения/миграции не требуется.
