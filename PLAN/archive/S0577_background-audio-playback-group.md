## 1. Проблема

Настройки, относящиеся к аудио, сейчас живут на вкладке «Медиа» (подраздел «Аудио»), тогда как пользователь воспринимает их как часть плеера. Блок «Фоновое воспроизведение» оторван от вкладки «Плеер», где ему место по смыслу. Кроме того, поведение фонового воспроизведения и диалог «При выходе из плеера» применяются только к локальным аудиофайлам - аудиостримы (трансляции) идут в фоне всегда, минуя пользовательскую настройку, и при выходе из экрана трансляций диалог выбора не показывается. Итог: настройка не отражает реальное поведение, а связанные опции разнесены по двум вкладкам.

---

## 2. Цели

1. На вкладке «Плеер» появляется отдельная сворачиваемая группа «Фоновое воспроизведение аудио», в которую вынесен блок «Фоновое воспроизведение» (тумблер фонового воспроизведения, выбор «при выходе», панель «сейчас играет»).
2. Перенесённый блок убран с вкладки «Медиа / Аудио»; остальные аудио-настройки (поддержка аудио, поиск обложек, лимиты размеров, фото во время аудио) остаются на месте - дубликатов нет.
3. Настройка фонового воспроизведения распространяется на аудиостримы (трансляции): если фоновое воспроизведение выключено, трансляция не уходит в фоновый сервис так же, как локальное аудио.
4. Диалог/выбор «При выходе из плеера» применяется и при выходе с экрана трансляций.
5. Опция переименована в «При выходе из плеера и трансляций» во всех локалях (EN/RU/UK).
6. Группа корректно скрывается во флейворах без поддержки фонового аудио, а stream-специфичная часть - во флейворах без поддержки трансляций.

**Non-goals:**

- Изменение самого движка воспроизведения (Media3-сервис) и его жизненного цикла.
- Добавление новых режимов выхода помимо существующих (спросить / всегда остановить / всегда продолжить).
- Переработка списка трансляций и их классификации (radio/video/rtsp).

## 3. Пожелания и ограничения

### 3.1 Пожелания владельца

1. Новая группа сворачиваемая, в едином стиле с остальными секциями вкладки «Плеер».
2. Переносится только блок фонового воспроизведения; прочие аудио-настройки остаются в группе «Медиа / Аудио».

### 3.2 Жёсткие ограничения

- **Flavor:** фоновое аудио - только во флейворах с включённым постоянным аудио-воспроизведением (standard, legacy, noLegal, vr); stream-часть - только во флейворах с поддержкой трансляций. В lite/photos группа либо скрыта целиком, либо без stream-части.
- **API level:** без новой API-специфики; существующие гейты (foreground-service по версии, разрешение на уведомления с API 33) сохраняются при переносе.
- **Wear OS:** не затрагивается.
- **Производительность:** нейтрально; перенос UI не добавляет работы в рантайме.
- **Совместимость данных:** ключи хранения настроек не меняются - перенос только UI-уровня; значения сохраняются.
- **Локализация:** EN/RU/UK - обязательно для переименованной опции и заголовка новой группы.
- **Доступность:** сохранить фокус-навигацию (D-pad/TV), touch target и не-цветовое различие состояний при переносе элементов.

## 4. Контекст текущей архитектуры

Экран настроек разбит на вкладки; «Медиа» содержит ленивый под-раздел «Аудио», а «Плеер» уже использует механизм сворачиваемых секций для своих групп. Блок фонового воспроизведения и его опция выхода сейчас принадлежат под-разделу «Аудио», который реализован отдельным дочерним фрагментом без внутренних сворачиваемых секций - поэтому элементы нельзя просто «пометить» как принадлежащие плееру, их нужно физически перенести в новую секцию на вкладке «Плеер».

Поведение фонового воспроизведения для локального аудио проходит через слой загрузки медиа, который сверяется с пользовательской настройкой и флейвор-флагом перед уходом в фоновый сервис. Воспроизведение трансляций использует тот же фоновый сервис, но через отдельный путь экрана трансляций, который пользовательскую настройку не проверяет. Диалог выхода применяется только из экрана плеера; экран трансляций его не вызывает. Из-за этого расхождения настройка не управляет трансляциями.

---

## 5. Предлагаемый подход

Перенос - на уровне представления настроек: элементы группы «Аудио» переезжают в новую сворачиваемую секцию вкладки «Плеер», слой хранения и доменная модель не меняются (ключи и значения те же). Распространение поведения на трансляции - выравнивание двух путей воспроизведения относительно одной и той же пользовательской настройки и одного и того же правила выхода.

### 5.1 Основные столпы / модули

- Представление настроек: новая сворачиваемая группа на вкладке «Плеер», вобравшая блок фонового воспроизведения и остальные аудио-элементы; удаление их из под-раздела «Аудио».
- Слой воспроизведения: единая точка решения «уходить ли в фоновый сервис», учитывающая настройку фонового воспроизведения как для локального аудио, так и для трансляций.
- Правило выхода: единое применение выбора «при выходе» как для плеера, так и для экрана трансляций.

### 5.2 Потоки данных и событий

- Настройка читается/пишется тем же путём: UI настроек → слой применения → хранилище; перенос меняет только размещение элементов в UI.
- Запуск воспроизведения (локальное аудио и трансляция) → общая проверка настройки фонового воспроизведения → уход в фоновый сервис или нет.
- Выход из плеера или экрана трансляций → общее правило «при выходе» → остановить / продолжить / спросить.

### 5.3 Точки расширяемости

- Решение «уходить ли в фон» и правило выхода должны быть переиспользуемыми точками, к которым можно подключить будущие источники аудио без дублирования логики.
- Группировка настроек на вкладке «Плеер» остаётся открытой для добавления новых аудио-опций в ту же секцию.

## 11. Критерии готовности (strategic-level)

1. На вкладке «Плеер» присутствует сворачиваемая (по умолчанию свёрнутая) группа «Фоновое воспроизведение аудио» с перенесённым блоком.
2. Блок фонового воспроизведения отсутствует в под-разделе «Медиа / Аудио»; прочие аудио-настройки остаются там.
3. При выключенном фоновом воспроизведении трансляция ведёт себя так же, как локальное аудио (не уходит в фон).
4. Выбор «при выходе» применяется при закрытии экрана трансляций.
5. Опция отображается как «При выходе из плеера и трансляций» в EN/RU/UK.
6. В флейворах без поддержки фонового аудио группа отсутствует; stream-часть отсутствует там, где нет трансляций.
7. Настройка находится поиском по настройкам; манифест и аннотации синхронизированы.
