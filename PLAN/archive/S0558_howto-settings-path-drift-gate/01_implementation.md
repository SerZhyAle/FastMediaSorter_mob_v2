# S0558 - Тактический план: HOW_TO settings-path drift gate

**Parent:** `PLAN/S0558_howto-settings-path-drift-gate.md`
**Status:** Implemented

Тактический разбор стратегической спеки S0558 на фазы. Реализует эвристический гейт, сверяющий рецепты «Settings → .. → метка» в HOW_TO (EN/RU/UK) с живым манифестом настроек.

---

## Установленные факты (research, 2026-06-20)

- Манифест `docs/settings/settings-manifest.json`: поля `destination` (GENERAL/MEDIA/OPERATIONS/PLAYBACK), `sectionId`, `kind` (TOGGLE_ROW/BUTTON/SPINNER/SECTION_HEADER), `titleEn/Ru/Uk`.
- Рецепты заякорены на локализованном слове «Settings/Настройки/Налаштування» в начале стрелочной (`→`) цепочки. Прочие стрелочные цепочки (жесты, навигация) - не рецепты.
- Имена вкладок и под-секций Media в манифесте не хранятся - нужен сопроводительный словарь.
- В каждой локали по 13 рецептов, порядок совпадает - паритет достижим.
- Не-манифестный навигируемый экран «Controls & Keybindings» (строка 1056 EN) требует allow-list.
- Реальный дрейф: HOW_TO RU/UK строка 600 использует устаревшую метку зон нажатия вместо манифестной «сетка сенсорных зон».

---

## Фаза 01 - Словарь навигации

`docs/settings/howto-path-vocab.json`:

- `tabs`: для каждой из 4 вкладок - `destination` плюс `en/ru/uk` отображаемое имя.
- `mediaSubsections`: под-секции Media (`images/documents/other`, расширяемо) - `sectionId` плюс `en/ru/uk`.
- `allowedScreens`: не-манифестные навигируемые экраны (`controls-keybindings`) - `destination` плюс `en/ru/uk`.

Имена берутся из текущих (исправленных) рецептов; вкладки заземлены на реальный UI.

## Фаза 02 - Гейт-скрипт

`scripts/quality/assert-howto-settings-paths.ps1`:

1. Загрузка манифеста (карты `title -> keys` и `key -> destination` на каждую локаль) и словаря.
2. Само-проверка полноты словаря: каждая `destination` манифеста имеет имя вкладки в en/ru/uk.
3. На каждый HOW_TO-файл: детект рецептов (строки с `→`, чей сегмент оканчивается на якорь), нормализация сегментов (снятие `**`, кавычек, слова «tab/вкладка», хвоста `= ..`).
4. Резолвинг: вкладка → `destination`; следующие сегменты → под-секция Media, либо метка манифеста под этой `destination`, либо allow-list экран. Последний сегмент - префиксная сверка (поглощает trailing-прозу).
5. Кросс-проверка вкладки: метка-leaf обязана принадлежать заявленной `destination` (ловит неверную вкладку).
6. Паритет: одинаковое число рецептов и совпадение позиционных сигнатур (destination + locale-independent токены) во всех трёх локалях.
7. Любой нерезолвленный сегмент или рассинхрон - exit 1 с `file:line` и пояснением. Иначе exit 0.

## Фаза 03 - Устранение найденного дрейфа

HOW_TO RU/UK строка 600: метка зон нажатия → манифестная «Всегда показывать сетку сенсорных зон» / «Завжди показувати сітку сенсорних зон».

## Фаза 04 - Встраивание

- `assert-settings-doc-sync.ps1`: новая Stage 5, вызывает гейт HOW_TO (правка манифеста перепроверяет HOW_TO).
- `post-change.ps1`: узкий триггер на `docs/HOW_TO*.md` - быстрый прогон только гейта HOW_TO (без gradle).
