## 1. Проблема

Индекс агентской памяти `.claude/agent-memory/android-rd-specialist/MEMORY.md` превышает установленный потолок размера (16595 B), разрастаясь до 19195 B (+2600 B). Поскольку `MEMORY.md` подгружается на каждом ходе каждой сессии, это создаёт постоянный оверхед по контексту и ломает гейт качества `assert-memory-budget.ps1 -Gate`.

---

## 2. Цели

1. Сократить размер `MEMORY.md` ниже потолка (целевой диапазон 11000–14000 B), выделив специализированные подразделы (эмуляторы/тестирование и PowerShell/CLI) в суб-индексы второго уровня по устоявшемуся в S1194 паттерну (`INDEX_release.md`, `INDEX_streams_vr.md`).
2. Добиться успешного прохождения гейта `scripts/quality/assert-memory-budget.ps1 -Gate` (exit 0).
3. Обновить и зафиксировать новый сниженный baseline в `scripts/quality/memory-budget-baseline.txt`.

**Non-goals:**

- Удаление фактических файлов заметок (`*.md`), так как они загружаются on-demand и не тратят контекст в каждом ходе.

## 4. Контекст текущей архитектуры

Система памяти агента состоит из top-level индекса `MEMORY.md` и отдельных файлов заметок. Индекс читается целиком в начале каждой сессии/хода. Для экономии контекста узкоспециализированные темы (релизы, VR/стримы) уже были вынесены во вторичные индексы `INDEX_release.md` и `INDEX_streams_vr.md`. Аналогичный подход применяется для блоков тестирования на эмуляторах и PowerShell-ловушек.

---

## 5. Предлагаемый подход

### 5.1 Основные столпы / модули

1. **Суб-индекс `INDEX_emulator_testing.md`**: собрать все указатели по эмуляторам, AVD, Maestro, скриншотам и системным ролям.
2. **Суб-индекс `INDEX_pwsh_traps.md`**: собрать указатели по синтаксису PowerShell, ловушкам bash-экранирования, вызовам CLI и аргументам.
3. **Компактизация `MEMORY.md`**: заменить перенесённые блоки компактными ссылками на соответствующие суб-индексы второго уровня, сократив размер файла.

### 5.2 Потоки данных и событий

- Индекс `MEMORY.md` загружается в сессию -> агент при необходимости специализированной работы переходит по ссылке во второй уровень (`INDEX_*.md`) -> читает конкретный файл памяти.
