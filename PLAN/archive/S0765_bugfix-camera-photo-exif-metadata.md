## 1. Проблема

Фото, снятые встроенной камерой приложения, не всегда отображаются повёрнутыми правильно. Корневая причина для снимков с цифровым зумом: после захвата кадр пере-кодируется ради центрального кропа обычным `Bitmap.compress`, который пишет «голый» JPEG без метаданных - молча теряются ориентация (EXIF orientation), время съёмки и любые GPS-теги. Поэтому такие снимки открываются как неповёрнутые и без времени/места. Область: модуль камеры (capture -> сохранение).

---

## 2. Цели

1. Снимки с цифровым зумом сохраняют EXIF-ориентацию исходного кадра - открываются повёрнутыми так же, как полнокадровый снимок.
2. Те же снимки сохраняют время съёмки (datetime) и прочие теги, записанные конвейером камеры (параметры экспозиции, make/model), а также GPS-теги, если они присутствуют.

**Non-goals:**

- Непрерывная синхронизация ориентации превью/захвата с поворотом устройства (домен S0754 - camera-orientation).
- Новый захват GPS-локации для фото (требует разрешения и приватной опции - вынесено в отдельный тикет).
- Завершение жизненного цикла фонового исполнителя кропа (отдельная находка).

## 4. Контекст текущей архитектуры

Захват фото идёт через CameraX (единственный путь, S0359). Менеджер сессии камеры пишет JPEG силами кодера CameraX (метаданные ставит сам CameraX), а при активном цифровом зуме off-thread пере-кодирует файл ради центрального кропа. Именно шаг пере-кодирования перезаписывает файл без переноса EXIF - метаданные теряются только на этом пути. Полнокадровые снимки (без цифрового зума) сохраняют EXIF, записанный CameraX. Проблему §1 нельзя решить выше по стеку: слой сохранения копирует файл байт-в-байт, поэтому уже потерянный EXIF не восстановить.

---

## 5. Предлагаемый подход

Перед перезаписью файла при кропе снять снимок EXIF исходного JPEG (его написал CameraX), а после записи кропнутого кадра вернуть набор тегов обратно. Центральный кроп не поворачивает пиксели физически, поэтому тег ориентации копируется без изменений (как есть), и снимок поворачивается просмотрщиком идентично оригиналу.

### 5.1 Основные столпы / модули

- Менеджер сессии камеры: шаг сохранения/восстановления EXIF вокруг пере-кодирования кропа.

### 5.2 Потоки данных и событий

- Захват CameraX (EXIF записан) -> снимок EXIF в память -> кроп + перезапись JPEG -> восстановление EXIF на новый файл -> слой сохранения копирует байт-в-байт.

### 5.3 Точки расширяемости

- Список переносимых тегов вынесен в одну константу - расширяется без изменения логики.
