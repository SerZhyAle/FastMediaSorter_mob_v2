## 0. Захваченный материал (inbox)

**Захвачено:** 2026-07-11

**Текст:**

при запуске программы "в холодныу" пользователь несколько секунд видит мой личный логотип по центру экрана. Это несколько эгоцентрично, не находишь? Может мы можем туда разместить какуюто простенькую анимацию из иконки и текста программы, а в уголок поместить небольшой мой логотип автора

---

## 1. Проблема

- На холодном старте пользователь несколько секунд видит центральный личный логотип автора - владелец считает это чрезмерно «эгоцентричным».
- Желаемое: по центру - простая анимация иконки и названия приложения; логотип автора - маленький, в углу.

---

## 2. Цели

1. Центр splash - анимация иконки + названия приложения (айдентика продукта, не автора).
2. Логотип автора присутствует, но небольшой и не в центре.

**Non-goals:**

- Редизайн самой иконки/лого приложения.
- Изменение времени показа splash / стартовой логики (splash остаётся тонким, не задерживает старт).

---

## 3. Пожелания и ограничения

### 3.1 Пожелания владельца

1. Простая, ненавязчивая анимация (не тяжёлая заставка).
2. Авторство сохранить, но деликатно (уголок).

### 3.2 Жёсткие ограничения

- **Flavor:** все.
- **API level:** платформенный splash (анимированная иконка + branding-image) - только API 31+; minSdk 23/26 нужен фолбэк (см. §6.3).
- **Wear OS:** не затрагивается.
- **Производительность:** splash не должен задерживать старт; анимация - лёгкий AVD.
- **Локализация:** название приложения уже локализовано; новых строк, вероятно, нет.

### 3.3 Owner inputs (Approval gate)

- **Related tickets:** none.

---

## 4. Контекст текущей архитектуры

- Splash - платформенный Android SplashScreen API через темы (`values-v31/`, `values-v35/` themes.xml): `windowSplashScreenAnimatedIcon` = `@drawable/ic_splash_logo` (текущий центральный логотип автора), фон - `windowSplashScreenBackground`.
- Платформа предоставляет `windowSplashScreenBrandingImage` (нижний центр, только API 31+) - штатное место для «маленького лого» без кастомной Activity.
- До API 31 splash деградирует до статичного `windowBackground` (без анимированной иконки и branding).

---

## 5. Предлагаемый подход

- Центр: заменить `ic_splash_logo` на лёгкий `AnimatedVectorDrawable` иконки + названия приложения с минимальным fade-in (проявление без движения; вписать в icon-слот ~240dp), штатный `windowSplashScreenAnimatedIcon` (<= 1000 мс по контракту SplashScreen API).
- Лого автора: `windowSplashScreenBrandingImage` (нижний центр, API31+) - небольшой, штатное место платформы (не произвольный угол).
- Фон: `windowSplashScreenBackground` (брендированный). До API 31 - статичная деградация (иконка на фоне), без анимации/branding.

---

## 6. Открытые вопросы / Research items

Owner/design-решения приняты (Quiz decisions ниже) - блокеров перехода Draft -> Approved нет.

1. **Механизм / размещение лого автора - RESOLVED:** платформенный SplashScreen API. Лого автора - `windowSplashScreenBrandingImage` (нижний центр, API31+), не произвольный угол - принятая цена платформенного пути вместо кастомного splash.
2. **Анимация иконки+текста - RESOLVED:** минимальный fade-in - иконка и название плавно проявляются вместе, без движения; лёгкий AVD в icon-слоте.
3. **Фолбэк до API 31 - RESOLVED (silent, штатная деградация):** статичный `windowBackground` с иконкой приложения на брендированном фоне; анимации/branding нет (платформенное ограничение), без краша и без задержки старта.
4. **Лого автора - RESOLVED:** оставить, небольшим; место - branding-image (нижний центр, см. #1).

- Анимация -> Минимал: fade-in иконки и названия вместе, без движения (лёгкий AVD).

Разрешено без вопроса (архитектура/конвенция):

- Лого автора -> оставить (решено в §0), небольшим, через branding-image.

## 11. Критерии готовности (strategic-level)

1. На холодном старте (API 31+) по центру - анимация иконки+названия приложения, а не логотип автора. **IMPL** - `ic_splash_animated` (AVD: `ic_splash_app_brand` = логотип-стрелки + wordmark «Fast Media Sorter» из путей, `splash_fade_in` alpha 0->1 500ms) в `windowSplashScreenAnimatedIcon` (v31 + night-v31). Визуал на устройстве не подтверждён чистым кадром: платформенное окно сплеша на emulator-5556 слишком короткое/флейки для захвата (ловится лаунчер или уже MainActivity). Требует живого глаза на реальном холодном старте.
2. Логотип автора присутствует небольшим в согласованном месте. **IMPL** - `ic_splash_branding` (44dp `ic_logo`) в `windowSplashScreenBrandingImage` (нижний центр, API31+).
3. На API < 31 splash деградирует корректно, без краша и без задержки старта. **IMPL** - v31-only тема; ниже API 31 остаётся статичный `windowBackground` (платформенная деградация, без изменений в этом тикете).
