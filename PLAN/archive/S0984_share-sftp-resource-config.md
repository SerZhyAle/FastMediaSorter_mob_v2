## 1. Проблема (черновик)

Пользователь настроил SFTP-ресурс (свой NAS, сервер, или companion-шару) и хочет дать доступ члену семьи/другу с FastMediaSorter: сейчас получателю пришлось бы вручную вводить хост/порт/логин/пароль/отпечаток. Нужен шаринг «одним файлом»: отправил `.fmscfg` в Telegram или письмом - получатель тапнул вложение - ресурс появился.

## 5. Предлагаемый подход (черновик дизайна, 2026-07-10)

**Ключевая идея: ничего нового не изобретать - переиспользовать замороженный контракт `CompanionResourceConfig` v1 и уже отгруженный импорт-пайплайн S0421.**

### Экспорт (новое, Android)

- Пункт в меню ресурса (btnMoreActions) для SFTP-ресурсов: «Поделиться доступом..».
- Сборка `.fmscfg` из живых данных: host/port из `resource.path` (SftpPathUtils), username/password из `NetworkCredentialsEntity` (расшифровка через существующий геттер), `hostKeyFingerprintSha256` из `resource.hostKeyFingerprint` (null -> поле пустое, получатель без пиннинга + предупреждение при импорте; решено quiz 2026-07-10 - без сетевых вызовов при экспорте), roots = один корень из remote path, `resourceName` = имя ресурса.
- Диалог-предупреждение перед шарингом: «Файл содержит пароль доступа - отправляйте только доверенным людям». Чекбокс «Не включать пароль» (решено quiz 2026-07-10; по умолчанию выключен) -> получатель введёт пароль в диалоге импорта.
- Отдача через системный share sheet: `ACTION_SEND` + `FileProvider` (temp-файл `<имя>.fmscfg`) -> Telegram / Gmail / что угодно. QR-вариант не в объёме (в приложении нет сканера; file-first по запросу владельца).

### Импорт (расширение существующего)

**Требование-ядро (владелец, 23:37): тап по вложению в письме/Telegram -> быстрый импорт.** Целевой UX: тап -> компактный подтверждающий диалог (имя ресурса, хост, число папок; предупреждение при отсутствии пароля/отпечатка) -> одна кнопка «Импортировать» -> ресурс готов. Без промежуточных экранов и ручного поиска файла.

- Уже работает через кнопку «Импорт из компаньона» + SAF (остаётся как fallback).
- Добавить приём извне, чтобы вложение открывалось напрямую:
  - `ACTION_SEND` (из share-меню Telegram/почты в FastMediaSorter) - надёжный путь;
  - `ACTION_VIEW` для тапа по вложению - фильтр по `content://` + `application/octet-stream` (у `.fmscfg` нет MIME; pathPattern на content-URI ненадёжен) - принять, провалидировать парсером, при мусоре - вежливый отказ. Появление в «Open with» для прочих octet-stream файлов - известная цена, оценить на аппруве.
- Существующая дедупликация кредов по host/port (`saveSftpCredentials`) отрабатывает повторные импорты.

### Безопасность / честный UX

- Пароль в файле by design (как у companion-QR) - предупреждение при экспорте, приватность файла на совести отправителя; отзыв доступа = смена пароля на сервере.
- Fingerprint в файле даёт получателю TOFU-пиннинг автоматически - шаринг БЕЗОПАСНЕЕ ручного ввода.
- Достижимость честно: если ресурс указывает на приватный IP (LAN), получатель вне сети не подключится - при экспорте детектировать private/CGNAT-адрес и предупреждать («работает только в вашей сети»; для интернета нужен port-forward/companion-путь).

### 3.3 Owner inputs (Approval gate)

- **Passwordless-экспорт:** да - чекбокс «Не включать пароль» в диалоге экспорта (по умолчанию выключен: пароль внутри); при импорте такого файла - поле ввода пароля прямо в подтверждающем диалоге.
- **Ресурс без сохранённого отпечатка:** шарить без отпечатка - никаких сетевых вызовов при экспорте; поле пустое, получатель без пиннинга (как ручной ввод сегодня). Смягчение валидации парсера: пустые `password` и `hostKeyFingerprintSha256` допустимы (Android-only relaxация, bump schemaVersion не нужен - companion-путь LITE всегда шлёт оба поля).
- **Приём вложений:** `ACTION_SEND` + `ACTION_VIEW` (octet-stream, контентная валидация); шум в «Open with» принят - требование владельца 23:37 «импорт по нажатию» без ACTION_VIEW невыполнимо.
- **Охват:** только SFTP-ресурсы (контракт `protocol=="sftp"` заморожен); FTP и мульти-ресурсный файл - вне объёма.
- **Related tickets:** S0421 (контракт `.fmscfg` v1 + импорт-пайплайн), S0046 (TOFU-пиннинг).
