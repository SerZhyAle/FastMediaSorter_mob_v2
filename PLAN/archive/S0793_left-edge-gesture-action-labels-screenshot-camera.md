Поскольку появляются действия и с камерой, и со скриншотами - названия должны быть все верные.

## 1. Проблема

Picker действий edge-жеста содержит и действия захвата экрана, и (с S0788, S0790+) действия работы с камерой. Метки скриншот-действий не содержали слова "Скриншот", из-за чего в общем списке нельзя было отделить "снимок экрана" от "фото с камеры".

## 2. Цели

1. Метки скриншот-действий начинаются с "Скриншот -", чтобы визуально отделяться от камера-действий.
2. Метка `OPEN_APP` описывает результат точнее - открытие основного окна программы.
3. Паритет EN/RU/UK.

**Non-goals:**

- Метка `SILENT_SCREENSHOT` (см. S0789).
- Поведение действий - без изменений (только текст).
- Метки камера-действий (задаются в их тикетах).

## 3. Ограничения

- **Flavor:** строки в `src/main/res`.
- **Локализация:** EN/RU/UK - обязательна.

## 3.3 Owner inputs (Approval gate)

- **Related tickets:** S0672, S0680, S0788, S0789, S0790, S0791, S0792.

## 4. Критерии готовности

1. Все скриншот-метки несут префикс "Скриншот -" (RU/UK "Скріншот -", EN "Screenshot -").
2. `OPEN_APP` = "Открыть основное окно программы" / "Open the main app window" / "Відкрити основне вікно програми".
3. `check_strings_localized.ps1 -KeyPrefix screenshot_gesture_action` - PASS.

## Реализация (2026-07-01)

Метки (EN / RU / UK), правки через `set-android-string.ps1 -Action set` с guard:

- `open_player`: "Screenshot - view" / "Скриншот - Просмотр" / "Скріншот - Перегляд".
- `open_draw`: EN/RU уже "Screenshot for editing"/"Скриншот для редактирования"; UK -> "Скріншот для редагування".
- `ocr_translate`: "Screenshot - OCR translation" / "Скриншот - OCR-перевод" / "Скріншот - OCR-переклад".
- `send_to`: "Screenshot - send to.." / "Скриншот - отправить в.." / "Скріншот - надіслати до..".
- `share`: "Screenshot - share" / "Скриншот - поделиться" / "Скріншот - поділитися".
- `crop_and_share`: EN/RU уже про "скриншот"; UK -> "Обрізати скріншот і надіслати".
- `open_app`: "Open the main app window" / "Открыть основное окно программы" / "Відкрити основне вікно програми".

Пунктуация нормализована к единой схеме "Скриншот - <действие>" (владелец в захвате писал вперемешку). Валидация: `check_strings_localized.ps1` - exit 0.
