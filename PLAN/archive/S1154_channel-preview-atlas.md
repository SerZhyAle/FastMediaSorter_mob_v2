**Заметки по объёму (из обсуждения перед захватом):**

- ~2026 видеоканалов в каталоге (`delivery/stream-catalog/streams.csv`: 2025 VIDEO + 1 RTSP).

## 1. Проблема

В сетке трансляций видеоканал без собственного захваченного кадра показывает только фавикон/плейсхолдер - при ~2025 видеоканалах первый заход в grid-режим выглядит стеной плейсхолдеров. Собственный кадр появляется лишь после того, как пользователь откроет канал (медленный сетевой захват по одному). Готового источника превью нет: пользователю нечего показать до первого просмотра каждого канала.

---

## 2. Цели

1. Предлагать скачиваемый «атлас превью каналов» отдельным элементом «Скачиваемых расширений» - скачать/удалить по желанию.
2. После удачного импорта/обновления трансляций спрашивать пользователя, скачать ли атлас превью.
3. Видеоканал в grid-режиме без собственного кадра показывает превью из атласа при первом заходе - пока его не заменит собственный захваченный кадр пользователя.
4. При переключении на фильтр «видео» трансляции автоматически переключаются в grid-режим; при уходе с видео-фильтра восстанавливается прежний режим отображения (Q-A).
5. Атлас - документированный/публикуемый ресурс: в объёме итерации 1 сторонние потребители каталога получают документацию формата атласа в `delivery/stream-catalog/README` (Q-B).

**Non-goals:**

- Превью аудио/радио-каналов (атлас - только видео).
- Онлайновое дособирание/обновление атласа на устройстве (атлас собирается офлайн-скриптом, поставляется как релизный ресурс).
- Замена конвейера захвата живого кадра на устройстве (он остаётся приоритетным источником).

## 3. Пожелания и ограничения

### 3.1 Пожелания владельца

1. Атлас поставляется и обновляется офлайн; при добавлении новых видеоканалов картинки дописываются в атлас офлайн-скриптом.
2. Собственный кадр пользователя всегда имеет приоритет над превью из атласа.

### 3.2 Жёсткие ограничения

- **Flavor:** standard, legacy, noLegal, vr (`SUPPORT_STREAMS = true`). lite/photos - вне объёма (Streams UI отсутствует).
- **API level:** без API-специфики - `BitmapRegionDecoder`/WorkManager/DataStore доступны с API 23 (legacy floor). Play-бан на скачивание `.so` к image-атласу не относится (это данные, не код).
- **Wear OS:** не затрагивается.
- **Производительность:** атлас ~20-50 MB на диске; **запрещено** декодировать весь лист 8192x8192 (~250 MiB) в RAM - только по-плиточная region-декодировка. Скачивание - через WorkManager с foreground-прогрессом.
- **Совместимость данных:** без изменения схемы Room, если карта слотов - внешний `url -> index` sidecar (как у фавиконного атласа). Постоянная колонка потребовала бы миграции (решение уровня /spec-tech).
- **Локализация:** EN/RU/UK - для новых строк (промпт после импорта, метка строки расширения, подтверждение удаления).
- **Доступность:** плитки превью сохраняют contentDescription; отличие не только цветом.

### 3.3 Owner inputs (Approval gate)

- **Related tickets:** none (S0925 - фавиконный атлас, прецедент упаковки/публикации; S1142/S1144 - метаданные трансляций, не блокируют).
- **UI scope:** пост-импортный промпт «скачать атлас превью?»; новая строка в «Скачиваемых расширениях» (скачать/удалить); новый tier превью в grid; авто-переключение в grid при входе на фильтр «видео» с восстановлением прежнего режима при выходе (Q-A, решено 2026-07-23).
- **Data scope:** внешний `url`-keyed sidecar карты слотов (без миграции Room) - рекомендация §9 ADR-4.
- **Scope decision:** сторонняя документация атласа входит в объём - дополнение `delivery/stream-catalog/README` (Q-B, решено 2026-07-23); отдельная страница `docs/` и запись в реестре не требуются.

## 4. Контекст текущей архитектуры

Сетка трансляций (`ui/streams/`, `StreamGridAdapter`/`StreamGridModeManager`) рендерит плитку по цепочке приоритетов: захваченный живой кадр (`StreamFrameCache`/`StreamFramePersistentStore`, источник `StreamFrameSnapshotManager`) → фавикон из атласа (`FaviconAtlasStore` sidecar `filesDir/streams/favicon-atlas.png` + `favicon-coords.json`, слайсер `FaviconAtlasSlicer`) → пусто. Фавиконный атлас - прямой прецедент упаковки: офлайн-пакер `scripts/streams/collect-stream-candidates.ps1` и on-device слайсер делят инвариант геометрии плитки. Скачиваемые расширения (`domain/delivery/DeliverableInventory*`, UI `ui/delivery/ExtensionsManager*`) знают два контракта загрузки: ad-hoc `ExtensionItem.Catalog` (малый, без реального прогресса, no-op удаление) и `DeliverableSet` + `DeliverableSetDownloader` + `DeliverableDownloadWorker` (реальные байты/прогресс, WorkManager, настоящее удаление). Проблему §1 нельзя решить на месте: нет ни готового источника превью, ни его доставки, ни tier-а превью в цепочке grid - это новые роли поверх существующих подсистем. Полный AS-IS: [`research/01__as-is-atlas-subsystems.md`](S1154_channel-preview-atlas/research/01__as-is-atlas-subsystems.md).

## 5. Предлагаемый подход

### 5.1 Основные столпы / модули

1. **Офлайн-сборка и публикация атласа.** Расширить `collect-stream-candidates.ps1`: пакер плиток 240x135 в единый лист + `url -> index` sidecar; публикация отдельным релизным ресурсом (не внутри `stream-catalog.zip`), с инвариантом геометрии, общим с on-device слайсером (дисциплина S0925).
2. **Скачивание по требованию** новым членом `DeliverableSet` (реальный прогресс + настоящее удаление, WorkManager) - удовлетворяет «скачать или удалить».
3. **On-device хранилище атласа + по-плиточный декодер** (`BitmapRegionDecoder`, budget-aware) + `url -> index` sidecar.
4. **Tier превью в grid:** захваченный кадр > превью из атласа (только VIDEO) > фавикон > пусто.
5. **Пост-импортный промпт:** по событию `StreamsEvent.CatalogUpdated` предложить скачать атлас (точка - `showCatalogRefreshSuggestion`).
6. **Авто-переключение в grid** при входе на фильтр «видео»; прежний режим отображения запоминается и восстанавливается при уходе с видео-фильтра (Q-A).
7. **Документация для сторонних потребителей** - дополнение `delivery/stream-catalog/README` (формат атласа + `url -> index` sidecar), в объёме итерации 1 (Q-B).

### 5.2 Потоки данных и событий

- Импорт трансляций → `CatalogUpdated` → промпт «скачать атлас?» → (да) `DeliverableDownloadWorker` качает атлас + sidecar в `filesDir/delivery/<set>/` → доступен слайсеру.
- Рендер grid: захваченный кадр? да → показать; нет → превью из атласа (VIDEO, region-decode по `url -> index`)? да → показать; нет → фавикон → пусто.
- Собственный кадр появился (открытие канала → capture) → он вытесняет превью из атласа для этой плитки.

### 5.3 Точки расширяемости

- Геометрия плитки/размер листа - параметр общего инварианта пакера и слайсера.
- Набор источников превью расширяем (атлас, захват) без изменения слоя рендера.
- Формат публикации атласа расширяем под сторонних потребителей (Q-B).

## 7. Риски

| Риск | Вероятность | Последствия | Митигация |
|------|:-----------:|-------------|-----------|
| Копирование decode-once слайсера фавиконов на лист 8192x8192 (~250 MiB) даёт OOM | Высокая | Краш grid/OOM | По-плиточный `BitmapRegionDecoder` (§9 ADR-2), никогда не декодировать весь лист |
| `DeliverableSet` - закрытый enum с exhaustive `when` в ~5 файлах | Средняя | Мультифайловая правка, риск пропуска ветки | Механически покрыть все `when`; тест gating |
| Ad-hoc `ExtensionItem.Catalog` (no-op удаление) не удовлетворяет «удалить по желанию» | Средняя | Мнимое удаление | Использовать `DeliverableSet`-контракт (§9 ADR-1) |
| Авто-переключение в grid удивляет пользователя, вручную оставившего LIST | Средняя | UX-регресс | Разрешить Q-A до реализации (Rule 10) |
| `StreamGridAdapter`/`StreamSourceAdapter` уже `@Suppress("LongParameterList")` | Низкая | Рост сложности | Свернуть tier превью в один провайдер, не плодить лямбды |
| `StreamsActivity` уже 1010 LOC (лимит 1500) | Средняя | Приближение к лимиту | Выносить промпт/wiring в helper-менеджер |
| Нестабильный ключ слота (`id` = UUID per import, стабилен только `url`) | Низкая | Рассинхрон превью после обновления каталога | `url`-keyed sidecar (§9 ADR-4) |
| Нулевое тестовое покрытие подсистемы grid/атласа | Средняя | Регрессии | Юнит-тесты pure-частей (парсер sidecar, индекс-математика, gating) |

## 9. Архитектурные решения (ADR)

- **ADR-1:** атлас - член `DeliverableSet` (реальный байтовый прогресс + настоящее удаление через `DeliverableSetDownloader`/`DeliverableDownloadWorker`), не ad-hoc `ExtensionItem.Catalog`. Причина: захваченное требование «скачать или удалить по желанию» несовместимо с no-op удалением ad-hoc-каталога.
- **ADR-2:** по-плиточная `BitmapRegionDecoder`-декодировка (прецедент в `src/main`: `ImageCropManager`, `CameraCaptureSessionManager`), не decode-once. Причина: лист 8192x8192 в ARGB_8888 = ~250 MiB, полный декод недопустим.
- **ADR-3:** приоритет источников плитки: захваченный кадр > превью из атласа (только VIDEO) > фавикон > пусто. Причина: захваченный материал прямо задаёт приоритет собственного кадра.
- **ADR-4:** карта слотов - внешний `url`-keyed sidecar (зеркало `FaviconAtlasStore`), без миграции Room. Причина: `StreamSourceEntity.id` рандомизируется per import, стабилен только `url`.
- **ADR-5:** атлас собирается и публикуется офлайн отдельным релизным ресурсом (не внутри `stream-catalog.zip`); геометрия плитки - общий инвариант пакера и on-device слайсера (дисциплина S0925). Причина: вес 20-50 MB и независимый жизненный цикл «скачать/удалить».

## 11. Критерии готовности (strategic-level)

1. В «Скачиваемых расширениях» есть строка «Атлас превью каналов» с реальным прогрессом скачивания и работающим удалением.
2. После удачного импорта/обновления трансляций пользователю предлагают скачать атлас.
3. В grid-режиме видеоканал без собственного кадра показывает превью из атласа; появившийся собственный кадр вытесняет превью.
4. Переключение на фильтр «видео» авто-переключает в grid-режим; при уходе с видео-фильтра восстанавливается прежний режим отображения (Q-A).
5. Скачивание/показ атласа никогда не декодирует весь лист в RAM (по-плиточная region-декодировка).
6. Атлас собирается и публикуется офлайн как версионированный релизный ресурс с совпадающей геометрией плитки.
7. `delivery/stream-catalog/README` документирует формат атласа и `url -> index` sidecar для сторонних потребителей каталога (Q-B).
8. Pure-части (парсер sidecar, индекс-математика, gating) покрыты юнит-тестами.
