## 1. Проблема

Панель фильтров типов ресурсов в основном окне (горизонтальная строка вкладок «Все / Local / SMB / ..») постоянно занимает вертикальное место, даже когда пользователь ей сейчас не пользуется. На небольших экранах и в ландшафте это сокращает площадь под список ресурсов. Способа временно убрать строку, сохранив быстрый доступ к ней, нет.

---

## 2. Цели

1. Длинное нажатие по строке фильтров сворачивает её в узкую цветную полоску на том же месте.
2. Полоска подписана и одним тапом разворачивается обратно в полную строку вкладок.
3. Свёрнутое/развёрнутое состояние сохраняется между запусками приложения.
4. Поведение единообразно с уже существующим сворачиванием панелей «копировать в..» и «переместить в..» в плеере.

**Non-goals:**

- Изменение логики фильтрации или набора вкладок.
- Сворачивание других панелей основного окна (например панели программ).
- Дополнительные жесты помимо long-press (свернуть) и tap (развернуть).
- Подпись активного фильтра на полоске - оставлена точкой расширения, не входит в первую итерацию.

---

## 3. Пожелания и ограничения

### 3.1 Пожелания владельца

1. Полоска визуально «цветная» - выделенным цветом, а не сливается с appbar.
2. Свернуть - осознанный жест (long-press), развернуть - лёгкий (tap), по аналогии с панелями плеера.

### 3.2 Жёсткие ограничения

- **Flavor:** все (standard / lite / photos / legacy) - строка фильтров не флейвор-гейтится.
- **API level:** без API-специфики (минимум как у проекта).
- **Wear OS:** не затрагивается.
- **Производительность:** незначимо; новых тяжёлых ресурсов не вводится.
- **Совместимость данных:** добавляется один булев флаг состояния в существующее хранилище настроек; без изменения схемы БД.
- **Локализация:** EN/RU/UK обязательно для новой подписи полоски.
- **Доступность:** полоска - стоп фокуса D-pad/клавиатуры (разворот по центральной кнопке); отличие не только цветом - есть текстовая подпись.

### 3.3 Owner inputs (Approval gate)

- **Expand-жест:** тап по полоске разворачивает её; сворачивание остаётся длинным нажатием.
- **Цвет полоски:** отдельный выделенный именованный цвет «фильтра» (как зелёная/синяя у панелей плеера), через тему/ресурс цвета, без inline-hex.
- **Персист:** состояние переживает перезапуск приложения - по аналогии с панелями плеера.
- **Подпись активного фильтра:** вне объёма первой итерации (полоска показывает только общий лейбл).
- **Related tickets:** none. Референс-паттерн - сворачиваемые панели плеера «копировать в..»/«переместить в..» (не блокирующая зависимость).

## 4. Контекст текущей архитектуры

Строка фильтров типов ресурсов - горизонтальная строка вкладок в верхней области основного окна, которой управляет отдельный UI-помощник основного окна. Активный фильтр держится в слое представления основного окна (в памяти, на сессию). Сворачиваемые панели плеера уже реализуют ровно нужный паттерн «панель ↔ узкая полоска» с сохранением состояния в общем хранилище настроек, но строка фильтров устроена иначе - это компонент вкладок, а не «заголовок плюс содержимое», поэтому переиспользовать готовый компонент-заголовок напрямую нельзя. Сейчас у строки фильтров нет ни понятия свёрнутого состояния, ни обработчика длинного нажатия. Существует правило: вся строка скрывается, когда не включён ни один удалённый источник.

---

## 5. Предлагаемый подход

### 5.1 Основные столпы / модули

- Тонкий помощник основного окна, владеющий двумя визуальными состояниями строки: развёрнутым (полная строка вкладок) и свёрнутым (узкая цветная полоска с подписью).
- Персист свёрнутости - булев флаг в существующем хранилище настроек.
- Новая локализованная подпись полоски и выделенный цвет полоски.

### 5.2 Потоки данных и событий

- Длинное нажатие по строке вкладок → помощник переключает состояние в «свёрнуто»: прячет вкладки, показывает полоску, пишет флаг в настройки.
- Тап по полоске → помощник возвращает «развёрнуто»: прячет полоску, показывает вкладки, пишет флаг.
- При открытии экрана помощник читает флаг и применяет состояние.
- Свёрнутость подчиняется существующему правилу скрытия всей строки: нет удалённых источников → не видно ни вкладок, ни полоски.

### 5.3 Точки расширяемости

- Помощник изолирует логику сворачивания, чтобы при желании добавить на полоску подпись активного фильтра или распространить тот же паттерн на другие панели основного окна.

## 7. Риски

| Риск | Вероятность | Последствия | Митигация |
|------|:-----------:|-------------|-----------|
| Активити основного окна у лимита размера | Высокая | Логику некуда положить без нарушения лимита | Вся новая логика - в новом помощнике, в активити только проводка |
| Строка вкладок внутри прокручиваемого appbar | Средняя | Обёртка/скрытие ломает скролл-офсет контента | Свернуть видимостью, не перестраивая иерархию appbar; проверить скролл |
| Три варианта макета | Средняя | Рассинхрон портрет/ландшафт/широкий | Править все три синхронно |
| Конфликт длинного нажатия с выбором вкладки | Низкая | Свёртка перехватывает обычный тап | Long-press - отдельный жест; тап по-прежнему выбирает вкладку |
| Правило скрытия всей строки | Средняя | Полоска показывается там, где строки быть не должно | Полоска подчиняется тому же правилу видимости |

## 11. Критерии готовности (strategic-level)

1. Длинное нажатие по строке фильтров сворачивает её в узкую цветную полоску с подписью на том же месте.
2. Тап по полоске разворачивает обратно полную строку вкладок.
3. Свёрнутое состояние сохраняется между перезапусками приложения.
4. Полоска доступна с D-pad/клавиатуры и отличается текстовой подписью, а не только цветом.
5. Подпись полоски локализована EN/RU/UK.
6. Поведение работает во всех flavor и не ломает существующее скрытие строки при отсутствии удалённых источников.
