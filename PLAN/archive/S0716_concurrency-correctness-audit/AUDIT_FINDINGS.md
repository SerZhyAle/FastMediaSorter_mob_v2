# S0716 Concurrency Correctness Audit - Findings

Date: 2026-06-26. Scope: `app_v2/` (main + all flavor source sets) and `wear/`. Method: Layer 2 of `docs/CODE_AUDIT_PROTOCOL.md`, sweeping five concurrency dimensions - data races on shared mutable state, main-safety of suspend functions / dispatcher placement, Flow/StateFlow/SharedFlow hygiene, blocking calls on UI / single-threaded dispatchers, and coroutine structure / cancellation correctness. Each suspected defect was deduplicated by symptom and then adversarially verified (trace the dispatcher to the call site, refute via thread-confinement / existing guards / cold-flow / scope-cancellation before confirming). 18 candidates were verified; 5 were refuted, leaving 13 confirmed findings. `GlobalScope` usage and lifecycle-unsafe UI Flow collection were excluded from scope because they are already covered by mechanical gates.

## Method

Layer 2 of `docs/CODE_AUDIT_PROTOCOL.md`. For each of the five dimensions: (1) mechanical sweep (`scripts/quality/audit-shared-state-writers.ps1` plus targeted Grep over both modules and all flavor source sets); (2) deduplicate candidates by symptom; (3) Read the concrete carrier and trace every reach path to its dispatcher / lifecycle owner; (4) adversarial verification - attempt to refute each candidate via thread-confinement, existing Mutex/Atomic/@Volatile/synchronized guards, cold-flow single-collector semantics, parent-Job structured cancellation, or correct off-Main dispatch, and only confirm what survives. 18 candidates were verified end-to-end; 5 were refuted and dropped; 13 confirmed and recorded here with file:line, dimension, verified rationale, fix sketch, and confidence. `GlobalScope` and lifecycle-unsafe UI Flow collection were out of scope (already covered by mechanical gates).
