## Steps

### Step 01.1 - Переписать образцы под конвенцию оракула

**Files:** `maestro/WRITING_TESTS.md`
**Depends on:** - start of phase

**Prompt for developer:**

> Раздел «Oracle convention» в начале файла - авторитетный, он остаётся. Привести всё, что ниже, в соответствие с ним. Конкретно: в «Common Test Patterns» убрать `optional: true` с утверждений, которые доказывают поведение (Pattern 1 `assertVisible` на «Dark Mode», Pattern 2 `id: ".*dark.*"`, Pattern 5 весь блок утверждений контекстного меню); заменить регулярные выражения в селекторах на точные идентификаторы либо точный видимый текст (`Pattern 3` поля хоста/логина/пароля, `Pattern 4`, «Element Selectors» подраздел «Regex Patterns», «Common Mistakes» пункт «Do: Use flexible selectors»); удалить или переписать подраздел «By Coordinates» и оба координатных примера в «Common Mistakes», поскольку конвенция запрещает координатный тап вместо утверждения. Раздел «Example: Complete Test» переписать целиком - в нынешнем виде он состоит почти полностью из запрещённых приёмов. Сохранить `optional: true` только там, где элемент действительно вариативен - системные диалоги разрешений.

**Why:**

Автор, читающий документ сверху вниз, копирует запрещённый шаблон и получает зелёный флоу, который ничего не доказал - это тот самый дефект, из-за которого прошлые флоу назвали фиктивными (стратегическая §1, цель 2).

**Verification:**

- `Grep` - `optional: true` в файле встречается только в контексте диалогов разрешений; ни одного вхождения в Pattern 1, Pattern 2, Pattern 5.
- `Grep` - `\.\*` не встречается ни в одном блоке `id:` или `text:` файла.
- `Grep` - `point:` не встречается в файле, либо встречается только с явной пометкой запрета.
- `Grep` - раздел `## Oracle convention` присутствует и не изменён.

**Status:** `[x]` done

### Step 01.2 - Перенести конвенцию в шаблон флоу

**Files:** `scripts/devtest/maestro/_template.yaml`
**Depends on:** Step 01.1

**Prompt for developer:**

> Дополнить шапку шаблона тремя запретами конвенции оракула в виде комментариев: `optional: true` не ставится на утверждение, доказывающее поведение; селектор не содержит регулярного выражения - только точный идентификатор ресурса или точный видимый текст; координатный тап не заменяет утверждение. Добавить в тело шаблона закомментированную защиту от падения (`assertNotVisible` на тексте активности сбоя) как обязательный последний шаг, поскольку конвенция требует её третьим правилом.

**Why:**

Шаблон - точка входа для нового флоу, и правило, доставленное вместе с заготовкой, срабатывает без чтения отдельного руководства; конвенция требует защиты от падения в каждом флоу (стратегическая §5.1 столп A).

**Verification:**

- `Grep` - `optional` присутствует в комментарии шаблона в контексте запрета.
- `Grep` - `assertNotVisible` присутствует в шаблоне.
- `Read` - шапка шаблона перечисляет три запрета.

**Status:** `[x]` done

### Step 01.3 - Свести ссылки на конвенцию в README обоих наборов

**Files:** `maestro/README.md`
**Depends on:** Step 01.2

**Prompt for developer:**

> В разделе, описывающем авторство флоу, сослаться на раздел «Oracle convention» как на единственный авторитетный источник правил и указать, что механическая проверка появляется в Phase 02. Не дублировать текст правил - только ссылка, иначе копия разойдётся с оригиналом.

**Why:**

Дублирование правил в двух файлах - причина исходного противоречия, поэтому второй экземпляр правил не создаётся (стратегическая §1, третий абзац).

**Verification:**

- `Grep` - `Oracle convention` упомянут в `maestro/README.md`.
- `Grep` - три запрета не продублированы текстом в `maestro/README.md`.
