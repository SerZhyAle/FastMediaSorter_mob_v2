## 1. Проблема

Возможности (файловый менеджер, типы медиа, OCR, перевод, VR) включаются по разным углам настроек; S0386-элементы новый пользователь не находит. Нужна страница онбординга с тумблерами, запускающими загрузку элементов прямо в ходе настройки.

## 2. Цели

1. Страница функциональности: тумблеры - файловый менеджер (все файлы), аудио, видео, документы (мастер на 4 поля), OCR, перевод, VR - каждый виден по availability-контракту (S0396).
2. Тумблер OCR/перевода ставит загрузку элементов в очередь (S0397) с inline-прогрессом; навигация не блокируется; настройка возможности включается после успешной установки.
3. Кнопка «Загружаемые элементы» открывает существующий экран менеджера.
4. Дефолты = значения после пресета профиля («пресет первичен, тумблеры показывают пост-пресетные значения»); OCR/перевод по умолчанию OFF.
5. Перевод скрыт на не-Play установках store-флейворов; VR-тумблер только в сборках с `src/vr` (XR master-преференс).

**Non-goals:** хостинг/состав элементов (S0386/S0401); фильтрация инвентаря экрана элементов в lite/photos (S0401).

## 3. Пожелания и ограничения

### 3.2 Жёсткие ограничения

- **Flavor:** все варианты; составы тумблеров - по матрице `research/09__flavor-matrix.md`; без BuildConfig в общем коде.
- **Совместимость данных:** тумблеры пишут существующие настройки (`allFiles`, `support*`, `enableOcr`, `enableTranslation`); документы - согласованная агрегация 4 полей; без параллельного хранилища.
- **Локализация:** EN/RU/UK, ~12 ключей (включая причины недоступности); тон - `docs/COMMUNICATION_POLICY.md`.
- **Доступность:** чеклист `research/11__accessibility-input.md`; live-region для прогресса.

- **Flavor scope:** по матрице артефакта 09; VR-тумблер только noLegal/vr.
- **Data compatibility:** только существующие настройки; агрегация «документы» определяется на `/spec-tech`.
- **UI placement contract:** страница 3 рекомендованного порядка (до разрешений); состав - SYNTHESIS.md.
- **Accessibility:** чеклист артефакта 11 обязателен.

- **Localization:** ~12 ключей EN/RU/UK.
- **Validation level:** сборки всех флейворов + ручной прогон с реальной загрузкой (BlockNeedUserTest).
- **Owner sign-off:** 2026-06-10 (в составе sign-off S0395).

Детали - артефакты 06 (карта тумблер→действие, гэпы) и 07 (жизненный цикл загрузки). Взаимодействие тумблеров: выключение типа медиа при включённом allFiles выходит из allFiles (существующее правило `SettingsAllFilesOverride`).

## 8. Влияние на пользователя (docs/FEATURES)

Обновление при завершении (одно предложение, EN/RU/UK): включение нужных возможностей и загрузка элементов прямо при первичной настройке.

## 9. ADR

**ADR-1:** включение возможности только после успешной установки элемента (инвариант S0386 сохраняется и на онбординге) - исключает «включено, но не работает».

## 11. Критерии готовности (strategic-level)

1. Включение OCR на странице ставит загрузку, прогресс виден на строке тумблера, по завершении OCR работает без визита в настройки.
2. Прогон «только Далее» оставляет дефолты и ничего не качает.
3. В lite/photos страница показывает только применимые тумблеры; VR-тумблер виден только в noLegal/vr.
4. Кнопка «Загружаемые элементы» открывает менеджер элементов.
