### Step 01.2 - Create format-kotlin-imports.ps1 using Ordinal comparison

**Status:** `[x]` done

**Step Log:**

- 2026-08-17 - Model routing policy in AGENTS.md, format-kotlin-imports.ps1, wired in post-change.ps1
**Files:** `scripts/utils/format-kotlin-imports.ps1`, `scripts/utils/format-kotlin-imports.tests/run-tests.ps1`  
**Depends on:** Step 01.1  

**Prompt for developer:**

> Implement `scripts/utils/format-kotlin-imports.ps1` taking `-FilePath` (or `-Files`). Parse the import block in each Kotlin file, partition into 4 groups (`*`, `java`, `javax`, `kotlin`), and sort imports strictly using `[string]::CompareOrdinal` within each group. Preserve blank line separators between groups and discard duplicate/empty imports. Provide test harness in `scripts/utils/format-kotlin-imports.tests/run-tests.ps1`.

**Why:**

`detekt:ImportOrdering` caused 25 of 115 attributable failures (rank 1), and PowerShell's default `Sort-Object` fails to match Detekt's ASCII Ordinal sorting rules.

**Verification:**

- `pwsh -NoProfile -File scripts/utils/format-kotlin-imports.tests/run-tests.ps1` exits 0.
