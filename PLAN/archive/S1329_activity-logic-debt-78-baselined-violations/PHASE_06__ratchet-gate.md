### Step 06.2 - Regenerate the lint baseline

> Regenerate the baseline through the build - run `/build` and use the project's lint-baseline update path.
> **Do not hand-edit `app_v2/lint-baseline.xml`.** Baseline entries are matched fuzzily on message text, so
> deleting individual `ActivityLogicViolation` nodes by hand can unhide unrelated findings; regeneration is
> the only safe path and is the practice S1195 established.
>
> After regeneration the file must hold exactly 32 `ActivityLogicViolation` entries - 20 in
> `PlayerActivity.kt` and 12 in `PhotoVideoStandaloneActivity.kt`. If the number differs, a phase missed a
> field or an unrelated Activity gained one; find the delta before continuing rather than adjusting the
> expected number.

> If the regeneration also removes or adds unrelated issue types, that is out of scope for S1329 - report it
> and do not absorb it into this ticket.
