## 1. Проблема

Welcome-флоу несёт четыре декоративные страницы, мёртвый permissions-тип, враньё «up to 30 destinations» и кнопку «Пропустить», которую владелец решил убрать. Каркас не данные: состав страниц зашит, флейворная видимость дырявая (карточка облака в lite). Новым страницам-формам (S0399/S0400/S0402) нужен каркас «страницы как данные» с collapse-правилом.

## 2. Цели

1. Каркас «страницы как данные» с availability-предикатами и collapse-правилом (нет доступных пунктов - нет страницы); индикатор «шаг X из N».
2. Кнопка «Пропустить» удалена; флоу проходится только «Далее»; прогон одними «Далее» даёт рабочее приложение (безопасные дефолты).
3. Декоративные страницы удалены; добавлена новая декоративная страница сетей - 3 плитки: SMB (intranet), (S)FTP, Cloud (тумблеры добавит S0391, см. его §3.1.4).
4. Страница 0 = приветствие + язык (3 кнопки) + тема (3 кнопки, AUTO; двойная запись DataStore+зеркало; подпись «применится после настройки»).
5. Карта тач-зон переезжает в подсказку первого входа в плеер.
6. Повторный вход: пресет применяется только при смене профиля и с предупреждением; возврат к вызвавшему экрану вместо `CLEAR_TASK`; pre-population всех страниц из настроек.
7. Чистка: мёртвый permissions-тип и его layout'ы/строки, `onSkipClick`, сиротские строки, «up to 30»→10 (3 локали).

**Non-goals:** страницы профиля/функциональности/разрешений (S0399/S0400/S0402); тумблеры сетей (S0391).

## 7. Риски

- Удаление Skip меняет семантику источника профиля (AUTO_SKIPPED) - зафиксировать для непосещённой страницы профиля эквивалент «рекомендованный без касания».
- Каркас трогает ключевой первый экран - регресс ловится ручным прогоном на всех флейворах.

## 11. Критерии готовности (strategic-level)

1. Онбординг без кнопки «Пропустить»; прогон одними «Далее» завершается за минуту рабочим приложением.
2. Декоративных страниц нет; страница сетей показывает 3 плитки; индикатор честный по флейвору.
3. Повторный вход из настроек не перетирает настройки пресетом без предупреждения и возвращает назад в настройки.
4. Первый вход в плеер предлагает карту тач-зон.
