# 05 - Вызов «всех приложений» и системных настроек Android

**Связано с §6 спеки S0404 (новый item).** Дата: 2026-06-11.

Владелец просит с домашней поверхности явные переходы: «все программы» и «настройки Android».

## «Все программы» (all apps)

Полное перечисление и запуск - уже разобрано в `02__package-visibility-launch.md`: декларация `<queries>` MAIN/LAUNCHER + перечисление через launcher-apps сервис, запуск по launch-intent. «Все приложения» на домашней поверхности = отдельная точка входа, открывающая полный отсортированный список (в дополнение к «избранным профиля»). Дополнительных API сверх `02` не требуется.

## Настройки Android

Открываются через implicit-intent с системными action'ами провайдера настроек. Главный экран - общий action настроек; есть прямые экраны под конкретные разделы:

- общие настройки;
- беспроводные сети / Wi-Fi;
- Bluetooth;
- дата и время;
- язык и ввод;
- дисплей;
- безопасность;
- хранилище / память;
- источник геолокации;
- режим полёта.

Практика: перед запуском проверять, что intent резолвится (на некоторых устройствах конкретный экран может отсутствовать) - иначе деградировать на общий экран настроек. На домашней поверхности достаточно: кнопка «Настройки Android» (общий экран) + опционально быстрые ярлыки на Wi-Fi и дату/время (частые на фоторамке/медиабоксе).

## Выводы для спеки

- «Все приложения» - точка входа поверх уже спланированного реестра приложений (`02`), не новый механизм.
- «Настройки Android» - набор implicit-intent на системные экраны настроек; обязательна проверка резолва + деградация на общий экран.
- И «все приложения», и «настройки» - часть гарантированного выхода из режима (митигация риска «застрял»), поэтому должны присутствовать на каждой профильной поверхности.
