## 1. Проблема

В группе настроек «Команды отправить файл в..» несколько тумблеров имеют одинаковые или слишком короткие метки (например, три тумблера «отправить в приложение» и два «Google Keep»). Пользователь не может понять, чем они отличаются, без дополнительного контекста. Отсутствие описания и кнопок-хелперов (?) делает группу неинформативной по сравнению с другими разделами настроек.

---

## 2. Цели

1. Каждый тумблер в группе «Команды отправить файл в..» получает уникальную, описательную метку.
2. Под меткой каждого тумблера появляется краткий текст описания, поясняющий его назначение.
3. К каждому тумблеру добавляется кнопка-хелпер (иконка ?) прижатая вправо, как в других разделах настроек.
4. Визуальный стиль хелперов соответствует остальным настройкам (единообразие).

**Non-goals:**

- Изменение логики самих команд «отправить файл в..»
- Добавление новых команд или пунктов назначения
- Рефакторинг архитектуры экрана настроек за пределами данной группы

---

## 3. Пожелания и ограничения

### 3.1 Пожелания владельца

1. Метки и описания — на всех трёх локалях: EN/RU/UK.
2. Текст описания — достаточно краткий, чтобы не вызывать переносы при стандартном размере шрифта.

### 3.2 Жёсткие ограничения

- **Flavor:** все варианты, где данная группа настроек доступна
- **API level:** без API-специфики

- **Совместимость данных:** без миграций, только ресурсы строк
- **Локализация:** EN/RU/UK — обязательно
- **Доступность:** кнопка-хелпер должна иметь корректный contentDescription

## 4. Контекст текущей архитектуры

Настройки приложения организованы по группам; каждая группа содержит ряд тумблеров (switches) с меткой и опциональным субтайтлом. Часть групп уже имеет кнопки-хелперы (?) справа — они вызывают диалог или Snackbar с пояснением. Данная группа «Команды отправить файл в..» пока лишена этого паттерна, а её тумблеры генерируются по схожей логике и получают идентичные метки при неодинаковых назначениях.

---

## 5. Предлагаемый подход

Применить к группе «Команды отправить файл в..» тот же паттерн, что уже используется в других группах настроек: уникальная метка + описание + хелпер-кнопка справа. Источники строк — ресурсы локализации. Кнопки-хелперы привязаны к соответствующему тумблеру и показывают пояснение при нажатии.

### 5.1 Основные столпы / модули

- Слой ресурсов строк: уникальные label + description для каждого тумблера группы
- Слой UI: добавление кнопки-хелпера к каждому item-у группы по существующему паттерну
- Слой настроек (presenter/ViewModel): корректная привязка новых строк к соответствующим тумблерам

### 5.2 Потоки данных и событий

UI-элемент тумблера → читает label/description из строковых ресурсов → отображает; нажатие на хелпер → показ диалога/тултипа с расширенным описанием.

### 5.3 Точки расширяемости

Паттерн хелпера остаётся единым для всех групп настроек — новые тумблеры в любой группе смогут его повторно использовать.
