## 1. Проблема

9-зоновая сетка касаний (3×3) активна в полноэкранном режиме плеера всегда и для всех. Часть пользователей считает её избыточной: плотная сетка усложняет простую навигацию, а случайные тапы вызывают файловые операции. Сейчас сетку нельзя отключить - нет настройки, переключающей плеер на упрощённое поведение. Область: настройки плеера (блок «Зоны нажатий и подсказки») и обработка касаний в полноэкранном плеере.

---

## 2. Цели

1. Пользователь может отключить 9-зоновую сетку одной настройкой в блоке «Зоны нажатий и подсказки».
2. При отключённой сетке полноэкранный плеер использует упрощённое 3-зоновое поведение: предыдущий / центр-зум / следующий.
3. При отключённой сетке доступ к командной панели и файловым операциям сохраняется касанием через выделенную левую область, а также с клавиатуры и D-pad.
4. Элементы настроек, относящиеся к 9-зоновой сетке, скрываются при отключённой сетке; вместо них показывается пояснение о 3 зонах.
5. По умолчанию сетка включена - текущее поведение не меняется без явного действия пользователя.

**Non-goals:**

- Изменение раскладки или действий самой 9-зоновой сетки, когда она включена.
- Раздельное отключение по типам медиа - единый переключатель для всех типов.
- Изменения в Wear OS.

3. Вертикальный свайп не переназначается на командную панель - он остаётся зумом для фото.

## 4. Контекст текущей архитектуры

Полноэкранный плеер выбирает раскладку зон касания по типу медиа и режиму: в полноэкранном режиме применяется 9-зоновая раскладка, в режиме командной панели - 3-зоновая (предыдущий / центр / следующий). 3-зоновое поведение уже реализовано как раскладка режима командной панели, поэтому отключение 9-зоновой сетки переиспользует существующий путь, а не вводит новый механизм. Сейчас выбор полноэкранной раскладки жёстко зашит и не зависит ни от какой настройки - поэтому проблему из §1 нельзя решить без новой точки настройки.

---

## 5. Предлагаемый подход

Ввести пользовательскую настройку «9-зоновая сетка включена/выключена», читаемую слоем настроек. Резолвер раскладки касаний учитывает флаг: при выключенной сетке полноэкранный режим использует 3-зоновую раскладку вместо 9-зоновой. В 3-зоновую раскладку добавляется выделенная левая область, открывающая режим командной панели (touch-доступ к файловым операциям), при этом вертикальный свайп сохраняет зум. Экран настроек скрывает элементы, специфичные для 9-зоновой сетки, и показывает пояснение о 3-зоновой раскладке, когда сетка выключена.

### 5.1 Основные столпы / модули

- Хранилище настройки: булев флаг, по умолчанию «включено».
- Резолвер раскладки касаний: учёт флага при выборе полноэкранной раскладки.
- Экран настроек: видимость элементов 9-зоновой сетки + пояснение о 3 зонах.
- Подсказки плеера: выбор 9-зоновой против 3-зоновой подсказки следует за флагом.

### 5.2 Потоки данных и событий

- UI настроек → запись флага → хранилище настроек.
- Плеер: чтение флага → резолвер раскладки → активная раскладка касаний и тип подсказки.

### 5.3 Точки расширяемости

- Резолвер раскладки остаётся точкой, где правило выбора может расшириться (например, по типам медиа), без переписывания вызывающих мест.

## 11. Критерии готовности (strategic-level)

1. В блоке «Зоны нажатий и подсказки» вверху есть переключатель «Отключить отслеживание 9 зон», по умолчанию выключен.
2. При включённом переключателе (сетка отключена) полноэкранный плеер реагирует по 3-зоновому поведению (предыдущий / зум / следующий).
3. При отключённой сетке выделенная левая область открывает командную панель; файловые операции доступны касанием.
4. Вертикальный свайп при отключённой сетке выполняет зум, а не открывает панель.
5. Элементы настроек, специфичные для 9-зоновой сетки, скрыты при отключённой сетке; показано пояснение о 3 зонах.
6. По умолчанию (сетка включена) поведение плеера и настроек не изменилось.
7. Название настройки и пояснение локализованы EN/RU/UK.
