# Техническое задание для дизайнера — Набор иконок ресурсов FastMediaSorter

**Проект:** FastMediaSorter v2 (Android медиабраузер)
**Deliverable:** 50 SVG-иконок, 5 тематических наборов
**Дата:** 2026-04-29
**Составил:** команда FastMediaSorter

---

## 1. Контекст проекта

FastMediaSorter — Android-приложение для просмотра и сортировки медиафайлов. Внутри приложения
пользователь назначает произвольную «иконку ресурса» каждому источнику медиа (локальная папка,
сетевой ресурс, облачное хранилище и т.д.). Эти иконки отображаются в списке ресурсов — сетке
или списке ячеек примерно 64 dp каждая. Иконка тонируется во время выполнения цветом темы
приложения, поэтому она должна работать как одноцветная фигура.

## 3. Тематика по наборам

### Набор 01 — Музыка (10 иконок)

Скрипичные ключи, ноты (одиночные и со связкой), инструменты: гитара, клавиши пианино,

Бобины с плёнкой, хлопушка, билет в кино, голливудская звезда, кинополоска, кинопроектор,
попкорн, VHS-кассета, кнопка воспроизведения на экране, видеокамера.

### Набор 03 — Изображения / Фото (10 иконок)

Пейзаж с домом, силуэт горы с солнцем, цветок (простой), силуэт автомобиля, лист / природа,
затвор фотоаппарата, рамка для картины, полароид, пляж с пальмой, воздушный шар.

### Набор 04 — Документы (10 иконок)

Открытая книга, закрытая книга с закладкой, папка, стопка файлов, визитная карточка, газета,
буфер обмена с галочкой, портфель, лупа над документом, академическая шапочка.

### Набор 05 — Прочее / Абстракция (20 иконок)

Абстрактные геометрические фигуры: сфера (изометрия), куб (изометрия), алмаз / гем,
шестиугольник, пирамида, тороидальное кольцо, звезда (5 лучей), восьмиугольник, спираль,
стопка эллипсов, кристаллическая призма, молекулярный узел, петля бесконечности, щит, якорь,
роза ветров, молния в круге, форма волны, соединённые точки, лента / розетка.

## 4. Технические требования

| Параметр | Требование |
|----------|------------|
| Формат | SVG |
| `viewBox` | `0 0 24 24` |
| Цвет заливки | `#000000` (единственный плоский цвет — тонирование заменяет его во время выполнения) |
| Обводка | Допустима только если переведена в заполненный контур (атрибуты `stroke` не разрешены) |
| Градиенты / фильтры | **Запрещены** |
| Растровые вставки | **Запрещены** |
| Фон | Прозрачный (нет `<rect>` с заливкой за рисунком) |
| Толщина линий | Рассчитана под 24 dp — примерно 1,5–2 px ширины обводки после перевода в контур |
| Минимальная читаемость | Иконка должна оставаться узнаваемой при размере **16 dp** |

Все контуры должны быть объединены / выровнены перед поставкой. Предпочтителен один элемент
`<path>` на иконку; несколько элементов `<path>` допустимы только при необходимости (например,
составные вырезы с правилом even-odd), при условии что все они используют одну плоскую заливку
`fill="#000000"`.

---

## 5. Соглашение об именовании файлов

Каждый файл должен быть назван точно по шаблону:

```
ico_NN_NNN.svg
```

Где:

- `NN` — двузначный id набора: `01`, `02`, `03`, `04`, `05`
- `NNN` — трёхзначный порядковый номер от 1 внутри набора: `001`, `002`, .. `010` (наборы 01–04) или `001`, .. `020` (набор 05)

**Примеры:**

- `ico_01_001.svg` — первая музыкальная иконка
- `ico_02_010.svg` — десятая видео-иконка
- `ico_05_020.svg` — двадцатая абстрактная иконка

Пробелы, заглавные буквы и иные символы в именах файлов не допускаются.

## 6. Критерии приёмки

Перед финальной поставкой каждая иконка должна пройти следующий чеклист:

- [ ] Узнаваема как задуманный мотив при размере 16 dp
- [ ] Визуальный вес соответствует иконкам-соседям в том же наборе (сопоставимая плотность ограничивающего прямоугольника)
- [ ] Корректно отображается в одном цвете тонирования (цветовая информация во время выполнения не сохраняется)
- [ ] `viewBox` ровно `0 0 24 24`
- [ ] Нет растровых вставок, градиентов, фильтров или ссылок на битмапы
- [ ] Файл является корректным валидным SVG (проходит XML-валидатор)
- [ ] Назван по соглашению `ico_NN_NNN.svg`

## 7. Что НЕ входит в поставку

Следующие активы **не** являются частью этого задания и не должны включаться:

- Иконки-оверлеи типа подключения (локальное хранилище, SMB/CIFS, SFTP, FTP, логотипы облачных провайдеров)
  — это существующие активы приложения, уже находящиеся в продакшне.
- Иконки лаунчера, уведомлений и любые другие элементы UI за пределами списка ресурсов.
- Анимированные SVG или Lottie-файлы.
