# 03 - Съёмка скриншотов часов

**Дата:** 2026-08-18

## Два существующих конвейера, оба не знают про часы

1. Скриншоты для листинга Play: `scripts/release/capture-play-screenshots.ps1` снимает через `scripts/devtest/adb.ps1` в `temp/play-shots/`, слоты берутся из `play/listing/captions.json`. Пакет и активити захардкожены на телефон: `com.sza.fastmediasorter.debug` и `com.sza.fastmediasorter.ui.main.MainActivity`. Файлов с именем про часы в `store_assets/screenshots*` нет.
2. Скриншоты для сценарных страниц: конвейера нет вовсе. `docs/howto/SCREENSHOTS.md` - это чеклист для человека: мастер-таблица «имя файла, сценарий, шаг, что обязано быть видно, источник», затем ручная съёмка и подстановка файла вместо заглушки `<!-- TODO screenshot: .. -->`.

## Доступность устройства, замерено 2026-08-18

`adb devices -l` показывает два подключения:

- `RFCR110NBQJ` - `model:SM_G996U1`, телефон.
- `emulator-5554` - `product:sdk_gwear_x86_64`, эмулятор Wear OS.

То есть поверхность часов доступна для съёмки прямо сейчас, без физических часов. Это важно, потому что физические часы в проекте с постоянно заблокированным загрузчиком и подключением только по Wi-Fi - неудобная база для повторяемой съёмки.

## Решение для S1801

Скриншоты часов снимаются вручную по действующей конвенции `docs/howto/SCREENSHOTS.md`: мастер-таблица расширяется строками сценариев Wear, файлы кладутся в `docs/howto/screenshots/` с тем же шаблоном имени `screenshot-<префикс>-step<N>.png`.

Отдельный скрипт съёмки не пишется. Обоснование: конвейер Play-скриншотов решает другую задачу - собрать фиксированный набор слотов для листинга магазина, - и его переиспользование потребовало бы параметризовать пакет и активити ради одноразовой съёмки полутора десятков кадров. Девять существующих сценариев обошлись ручной съёмкой по чеклисту; десятый не создаёт нового основания для автоматизации.

Ограничение, которое надо держать в тактическом плане: экран часов маленький и круглый или квадратный, поэтому кадр должен быть читаем в ширине страницы сайта без увеличения, а мастер-таблица обязана называть, что именно должно быть видно в кадре, - иначе съёмка не воспроизводима.
