# 02 - Локали новых страниц и пересечение с S1211

**Дата:** 2026-08-18

## Что сейчас

Каждая опубликованная запись реестра с `localized_urls` несёт три локали, en/ru/uk: `site-landing`, `nolegal-landing`, `user-guides`, `feature-showcase`, `settings-reference`. Исключение ровно одно - `wear-docs`: `languages: ["en"]` и ключа `localized_urls` нет вовсе. То есть документация по часам сегодня ниже базовой планки сайта, а не вровень с ней.

Конвенция имён файлов по репозиторию не единая:

- `_RU.md` / `_UK.md` - большинство документов `docs/` (`README_RU.md`, `FEATURES_RU.md`).
- `-ru.md` / `-uk.md` - каталог `docs/howto/` и корневые лендинги (`index-ru.html`).

Механизма шаблонизации нет: локали делаются размножением соседних файлов вручную.

## Что планирует S1211

`S1211 docs-site-thirteen-language-localization`, Draft, приоритет 45:

1. Расширить сайт с трёх языков до тринадцати (тот же набор, что у приложения в S1190).
2. До раскатки новых языков унифицировать конвенцию имён локалей по всему репозиторию.
3. Заменить ручное размножение соседних файлов механическим порождением страниц - открытый вопрос, шаблон Jekyll или i18n-плагин.
4. Держать реестр и sitemap в соответствии с фактическим покрытием языков.

Non-goals S1211 прямо исключают внутренние документы разработчика.

## Решение для S1801

Новые страницы делаются сразу в трёх локалях en/ru/uk и с суффиксом `-ru` / `-uk`.

Обоснование по двум осям:

- Три локали, а не EN-only: жанр `docs/howto/`, в который страницы встраиваются, целиком трёхъязычный, и запись `user-guides` объявляет `localized_urls` для трёх языков. EN-only страница внутри этой группы стала бы единственной, у которой переключатель языка ведёт в никуда. Наследовать «EN-only» от записи `wear-docs` неверно: это состояние и есть часть проблемы, которую тикет закрывает.
- Суффикс `-ru`/`-uk`, а не `_RU`/`_UK`: он действует внутри `docs/howto/`, а согласованность внутри одного каталога важнее согласованности с конвенцией, которую S1211 ещё не выбрал. Когда S1211 выберет, он переименует каталог целиком, одним проходом, и новые страницы поедут вместе со старыми - это дешевле, чем угадывать будущее решение сейчас и остаться единственными файлами не в той конвенции.

Тринадцать языков для этих страниц - не объём S1801. Носитель вопроса - S1211, который обязан включить новые страницы Wear в свою раскатку.
