**Текст:**

Landing pages (index.html / index-ru.html / index-uk.html) link to docs/SETTINGS_REFERENCE.md, docs/SETTINGS_REFERENCE_RU.md, docs/SETTINGS_REFERENCE_UK.md with the .md extension, while every other landing-referenced doc is served via front-matter permalink at .html. SETTINGS_REFERENCE* files have no YAML front matter, so on GitHub Pages Jekyll serves them as raw static markdown (not rendered HTML) - inconsistent with the unified .html scheme and a poor reading experience. These files are GENERATED by scripts/docs/render-settings-reference.ps1 (marked "Do not edit by hand"), so the proper fix is to make the generator emit front matter (layout: default + title + permalink: /docs/SETTINGS_REFERENCE*.html), regenerate all three locales, then switch the landing links from .md to .html. Discovered while finishing S0557 (docs drift fix); SETTINGS_REFERENCE was outside S0557 §3.1 scope and untouched by it (pre-existing in HEAD), hence parked rather than fixed inline. Evidence: _config.yml has no permalink override (default Jekyll = render only files with front matter); grep of landings shows docs/SETTINGS_REFERENCE*.md are the only remaining .md links after S0557.

**Вложения:**

Вложений нет.

## 1. Проблема

- Лендинги (index.html / index-ru.html / index-uk.html) ссылаются на справочник настроек с расширением `.md`, тогда как все прочие документы лендинга отдаются через permalink на `.html`.
- Файлы SETTINGS_REFERENCE* не имеют YAML front matter, поэтому GitHub Pages (Jekyll) отдаёт их как сырой статический markdown, а не как отрендеренный HTML.
- Для пользователя это означает нечитаемую страницу (сырой текст таблиц) вместо оформленной - в отличие от остальных разделов документации.
- Файлы генерируются `scripts/docs/render-settings-reference.ps1` (помечены «Do not edit by hand»), поэтому правка вручную недопустима - чинить нужно в генераторе.

---

## 2. Цели

1. Генератор справочника эмитит YAML front matter (`layout: default`, `title`, `permalink: /docs/<NAME>.html`) первыми байтами каждого файла.
2. Все три публикуемые локали (EN/RU/UK) перегенерированы и отдаются GitHub Pages как HTML по permalink.
3. Ссылки на лендингах переключены с `.md` на `.html`, единая схема `.html` по всем документам лендинга.
4. Drift-gate (`assert-settings-doc-sync.ps1`) остаётся зелёным: перерендер байт-в-байт совпадает с закоммиченными файлами.

**Non-goals:**

- Изменение содержимого справочника (таблиц настроек) - меняется только обёртка front matter.
- Правка noLegal-схемы публикации (файл gitignored, не отдаётся на Pages); front matter добавляется для единообразия генератора, без эффекта на публикацию.
