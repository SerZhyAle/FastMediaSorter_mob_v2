# Стратегическая спецификация: S0800 - Убрать ранний выбор иконки из окна добавления ресурса

## 1. Проблема

В окне "Добавить ресурс" на шаге выбора типа ресурса в правом верхнем углу тулбара показывалась кнопка выбора миниатюры (иконки) будущего ресурса (S0034). Выбор бессмыслен на этом шаге: иконка ресурса всё равно назначается позже, в редакторе ресурса. Хуже того, выбранная здесь иконка вообще не сохранялась - `userPickedIconId` нигде не потреблялся при создании ресурса, то есть виджет был декоративным и вводил в заблуждение.

## 2. Цели

1. Убрать кнопку раннего выбора иконки из тулбара окна "Добавить ресурс".
2. Оставить единственный корректный путь назначения иконки - редактор ресурса.

**Non-goals:**

- Изменение самого пикера иконок (`IconPickerBottomSheet`) и реестра иконок - они продолжают жить в редакторе ресурса.
- Удаление общего лейаута `toolbar_icon_action.xml` - он ещё используется редактором ресурса.

## 3. Что сделано

Лейаут (`app_v2/src/main/res/layout/activity_add_resource.xml`):

1. Удалён `<include android:id="@+id/pickIconAction" .../>` из `MaterialToolbar`; тулбар оставлен с заголовком и кнопкой "назад".

Код (`app_v2/src/main/java/com/sza/fastmediasorter/ui/addresource/AddResourceActivity.kt`):

2. Удалён метод `setupIconPicker()` и его вызов, поле `userPickedIconId`, а также ставшие лишними импорты (`ResourceIconRegistry`, `ResourceIconSet`, `IconPickerBottomSheet`).

Landscape-контрпарта у лейаута нет - правка одна.

## 4. Критерии готовности

1. В окне "Добавить ресурс" на шаге выбора типа в правом верхнем углу нет кнопки выбора иконки.
2. Создание ресурса (Local / Network / SFTP / Cloud) работает как раньше.
3. Иконка ресурса по-прежнему назначается в редакторе ресурса.
4. Компиляция Kotlin и сборка ресурсов проходят (`a.ps1 fc`, exit 0).
