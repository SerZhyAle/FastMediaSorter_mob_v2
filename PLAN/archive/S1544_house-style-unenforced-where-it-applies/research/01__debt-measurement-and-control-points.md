# S1544 / research 01 - Debt measurement and existing control points

**Дата:** 2026-08-14
**Метод:** `../evidence/measure-house-style-debt.ps1` (read-only), плюс точечные выборки `Select-String`.
**Закрывает:** §6 items 1, 2, 3.

Скрипт считает две области, которые канон объявляет обязательными: прозу документации и
пользовательские строки. Из markdown вырезаются fenced-блоки и inline-код, из XML берутся только
значения элементов `<string>` / `<item>` - канон исключает код из области действия стиля.

---

## 1. Проза документации: долга нет

`docs/**/*.md`, 137 файлов, только проза:

- многоточий: **3**
- длинных тире: **116**
- затронутых файлов: **3**

Все 119 нарушений лежат ровно в трёх файлах: `docs/FEATURES_noLegal.md`,
`docs/FEATURES_noLegal_RU.md`, `docs/FEATURES_noLegal_UK.md`. Остальные **134 файла чисты**.

Эти три - gitignored, локальные, не публикуются: `noLegal` не рыночная сборка. Ни один скрипт их не
пишет: `grep FEATURES_noLegal *.ps1` даёт только `.jsonl`-инвентарь (`all_features/*`,
`close-and-log.ps1`), но не `.md`. То есть это ручная проза в неотслеживаемом файле.

**Вывод:** отслеживаемая проза документации накопила ноль нарушений за всю жизнь репозитория - без
всякого гейта. Гейт защищал бы область, где нарушений не возникает.

## 2. Авторские пользовательские строки: одно нарушение

`values`, `values-ru`, `values-uk` (плюс `wear`, плюс `debug`):

- многоточий: **0**
- длинных тире: **1 ключ** - `hint_access_pin`, диапазон `4–6` с en dash, одинаково во всех трёх локалях

Больше ничего. Ratchet-база для авторской поверхности не нужна: долг чинится одной правкой одного
ключа.

## 3. Переведённые локали: 440 нарушений, и все машинного происхождения

Десять локалей, пришедших через внешний перевод (`de fr it es pt hi ar bn ur zh-Hans`):

- многоточий: **317**
- длинных тире: **123**

Ключевое наблюдение - **английский источник чист, а возврат нет**:

| ключ | `values` (источник) | возврат |
|------|---------------------|---------|
| `progress_applying_filter` | `Applying filter..` | de `Filter wird angewendet…` |
| `replace_hint` | `Replace with..` | de `Ersetzen durch…`, zh `替换为……` |
| `reopen_with_encoding` | `Re-open with Encoding..` | zh `重新打开并编码...` |
| `vr_cheatsheet_ctrl_a` | `A (right) - Pause / Play` | de `A (rechts) – Pause/Wiedergabe` |
| `vr_cheatsheet_ctrl_b` | `B (right) - Exit to 2D panel` | de `B (rechts) – Ausgang zum 2D-Panel` |

Это не типографская норма локали, а артефакт сервиса. `values-b+zh+Hans/strings.xml` содержит
**обе** формы в одном файле - `应用筛选条件...` рядом с `正在进行调整……` - а осознанная конвенция не
бывает непоследовательной внутри одного файла. Сервис переписывает `..` в `…` и дефис в en dash
независимо от того, что было на входе.

**Вывод:** нормализация возврата восстанавливает стиль собственного источника, а не навязывает
русскую конвенцию чужому языку. Вопрос «применим ли `..` к нелатинской типографике» снимается
измерением и не требует решения владельца.

## 4. Обязательные точки записи уже существуют

Ни одна область не пишется мимо инструмента:

- авторские строки - `set-android-string.ps1`, `set-android-strings.ps1`, `batch-set-android-string.ps1`
- переведённые строки - `locale-bulk-import.ps1` -> `seed-locale-tranche.ps1`; это единственная дверь,
  через которую прошли все 440 нарушений
- проза документации - `post-change.ps1 -ChangeType Doc`, где уже есть машинерия шагов по ChangeType
  (шаг `strings-audit` уже включается для `Doc | Xml | Mixed`)

`locale-bulk-import.ps1` уже валидирует каждую возвращённую строку - счётчик строк и мультимножество
format-токенов. Нормализация стиля встаёт в ту же построчную проверку: новый скрипт не нужен, новый
прогон не нужен.

Ни один из трёх инструментов записи строк сейчас не упоминает ни многоточие, ни тире
(`grep` по `set-android-string.ps1` - ноль совпадений).

## 5. Пять фиксеров: карта перекрытий

| скрипт | область | что чинит |
|--------|---------|-----------|
| `fix-ellipsis.ps1` | 7 авторских `strings.xml` + markdown | многоточие |
| `fix-ellipsis-strings.ps1` | 3 авторских `strings.xml` | многоточие |
| `fix-ellipsis-docs.ps1` | `docs/*.md` | многоточие |
| `fix-yo.ps1` | список регэксп-пар | ё |
| `fix-yo-letter.ps1` | курируемый словарь | ё |

- `fix-ellipsis-strings.ps1` - строгое подмножество XML-половины `fix-ellipsis.ps1`.
- `fix-ellipsis-docs.ps1` - подмножество markdown-половины, и при этом **не рекурсивный**
  (`Get-ChildItem -Filter '*.md' -File` без `-Recurse`), поэтому `docs/settings/*.md` не видит вовсе.
- `fix-yo.ps1` и `fix-yo-letter.ps1` решают одну задачу двумя разными структурами данных; в словаре
  второго есть мёртвые записи-заглушки (`'включает' = 'включает'`, `'выйдет' = 'выйдет'`).

**Дыра, которая важнее перекрытий:** ни один из пяти не трогает длинное тире. А тире - это 239 из
всех найденных нарушений, то есть больший класс в обеих обязательных областях. Инвентарь
инструментов не покрывает именно тот дефект, который реально накапливается.
