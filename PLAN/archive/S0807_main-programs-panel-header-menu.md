## 1. Проблема

Панель программ в основном окне не имеет собственной точки доступа к управлению самой панелью. У панели трансляций такое меню уже есть (long-press по единственной кнопке-входу), но панель программ - это коллекция элементов без единой кнопки-входа, поэтому тот же жест к ней неприменим. В итоге пользователь не может из панели быстро перейти к её настройкам, временно свернуть её ради места или полностью убрать - всё это доступно только окольными путями через экран настроек. Затронуто: основное окно (`ui/main`) и экран настроек (`ui/settings`).

## 2. Цели

1. Панель программ начинается с системной кнопки «три точки» (overflow) - визуальная преемственность с кнопкой «три точки» верхней командной панели.
2. Нажатие на кнопку открывает меню панели с тремя пунктами: «Настроить панель», «Свернуть панель», «Скрыть панель».
3. «Настроить панель» открывает настройки сразу на блоке «Дополнительные программы и сценарии» (раскрытом и проскролленном в видимую область).
4. «Свернуть панель» превращает панель в узкую цветную полоску с подписью «программы и сценарии»; тап по полоске разворачивает панель обратно. Свёрнутость сохраняется между запусками.
5. «Скрыть панель» убирает панель программ и возвращает кнопку «три точки» в верхнюю командную панель (откуда панель включается снова).

**Non-goals:**

- Изменение per-item меню элементов панели (Open / Open in new window / Remove - S0770) и пункта «Настроить» этого меню (S0780).
- Новый механизм сворачивания - переиспользуется уже существующий (полоска-«ярлычок» плеера / фильтров, S0781).
- Новая настройка видимости панели - переиспускается существующий флаг показа панели программ (S0755).
- Подпись активного элемента на свёрнутой полоске (как и в S0781 - точка расширения, вне первой итерации).

## 4. Контекст текущей архитектуры

Панель программ основного окна строит отдельный UI-помощник основного окна: он раскладывает элементы-программы, применяет правило «иконки в портрете / подписи в ландшафте» и показывается/прячется по флагу настроек видимости панели программ (S0755). Меню панелей уже строится общим компонентом контекст-меню из списка действий `Action(@StringRes, () -> Unit)`, а у панели трансляций уже есть группа колбэков меню (Configure / Hide panel / Disable), приходящих из хоста основного окна (S0779/S0782). Механизм сворачивания «панель ↔ узкая цветная полоска с персистом флага» уже реализован для панели фильтров (S0781), а deep-link «открыть Настройки на блоке дополнительных программ, раскрыть и проскроллить» - для пункта «Настроить» per-item меню (S0780). Чего нет: у панели программ нет собственной header-кнопки и панель-уровневого меню, нет свёрнутого состояния, а верхняя кнопка «три точки», которую S0755 прячет при показе панели, сейчас возвращается только при выключении флага видимости панели.

## 5. Предлагаемый подход

Добавить панели программ ведущую header-кнопку «три точки», открывающую панель-уровневое меню из трёх действий. Меню строится тем же компонентом контекст-меню, что и у остальных панелей; действия дёргают колбэки хоста основного окна по образцу группы колбэков меню трансляций. Каждое из трёх действий переиспользует уже существующий механизм, а не вводит новый.

### 5.1 Основные столпы / модули

- Ведущая header-кнопка «три точки» в разметке панели программ (портрет и ландшафт синхронно) плюс её проводка в помощнике панели программ.
- Группа колбэков панель-уровневого меню программ (по образцу группы колбэков меню трансляций): «настроить», «свернуть», «скрыть».
- Свёрнутое состояние панели программ: узкая цветная полоска с подписью, персист булева флага в существующем хранилище настроек (переиспускание паттерна S0781).
- Хост основного окна: запись существующего флага видимости панели (скрыть) и запуск deep-link настроек (настроить).

### 5.2 Потоки данных и событий

- Тап по кнопке «три точки» → панель-уровневое меню.
- «Настроить панель» → колбэк хоста → deep-link «Настройки → вкладка управления → блок дополнительных программ» (раскрыть + проскроллить).
- «Свернуть панель» → помощник переключает состояние в «свёрнуто»: прячет элементы + кнопку, показывает полоску, пишет флаг свёрнутости; тап по полоске → «развёрнуто», пишет флаг.
- «Скрыть панель» → колбэк хоста → запись флага видимости панели программ в «выключено» → коллектор настроек пересобирает: панель исчезает, кнопка «три точки» возвращается в верхнюю командную панель.
- При открытии экрана помощник читает флаг свёрнутости и применяет состояние (свёрнуто/развёрнуто).

### 5.3 Точки расширяемости

- Группа колбэков панель-уровневого меню остаётся открытой для новых пунктов без изменения помощника панели.
- Помощник сворачивания изолирует логику полоски, чтобы позже добавить на неё подпись активного/выбранного элемента или распространить тот же паттерн на прочие панели.

## 11. Критерии готовности (strategic-level)

1. Панель программ начинается с кнопки «три точки», совпадающей по виду с кнопкой верхней командной панели.

6. Три пункта меню и подпись полоски локализованы EN/RU/UK (паритет проходит).
7. Работает во всех flavor; сборка standard зелёная.
