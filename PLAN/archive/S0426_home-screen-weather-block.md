## 0. Происхождение

- Запрос: на домашней поверхности лаунчера (S0404), прежде всего профиль «фоторамка», показывать погоду.
- Решено вынести из S0404 в отдельный независимый спек: погода не нужна для роли Home/запуска приложений и должна жить как опциональный info-блок в любом профиле (S0404 §5.3 уже гарантирует расширяемость контракта info-блоков).
- Research-вход: `PLAN/S0404_android-launcher-mode-profiles/research/07__weather-information.md`.

---

## 1. Проблема

Домашняя поверхность лаунчера (S0404) показывает контекст профиля (часы/дата, текущий показ/воспроизведение), но не показывает погоду. На устройстве-фоторамке на стене погода рядом с часами - типовое и ожидаемое содержимое. Сейчас такого источника информации нет.

---

## 2. Цели

1. Опциональный info-блок «погода» на домашней поверхности лаунчера, подключаемый через существующий контракт info-блоков профиля - без изменения launcher-ядра S0404.
2. Получение погоды без новых чувствительных разрешений по умолчанию: локация задаётся вручную (город) с геокодингом.
3. Опциональная автолокация по приблизительному разрешению (`ACCESS_COARSE_LOCATION`) как опт-ин, с корректной деградацией к ручному вводу.
4. Корректная деградация без сети (показ кэша/скрытие блока) и без заданной локации (блок скрыт), без падений.
5. Соответствие лицензии выбранного источника данных условиям публикации (Play / non-Play).

**Non-goals:**

- Полноценный прогноз на несколько дней с графиками/радаром (на старте - текущая погода + минимум).
- Виджет погоды вне домашней поверхности лаунчера.
- Обязательная автолокация / фоновая геолокация.

---

## 3. Пожелания и ограничения (черновые, до апрува)

- **Независимость:** блок реализует контракт info-блоков профиля S0404; добавление/удаление не затрагивает роль Home, реестр приложений, строку состояния.
- **Локация по умолчанию без прав:** ручной ввод города → геокодинг (keyless). Coarse-локация - опт-ин.
- **Источник данных (research-informed 2026-06-23, см. §8):** Open-Meteo free-tier - non-commercial и для погоды, и для geocoding → на Play неприменим. Рекомендация: один commercial-OK провайдер с ключом для погоды+геокодинга на всех флейворах (WeatherAPI.com Free или OpenWeatherMap classic free), ключ - в secret-config, не в `src/main`.
- **Локация по умолчанию без прав:** ручной ввод города → геокодинг. Геокодер - тот же commercial-OK провайдер (bundled), НЕ keyless Open-Meteo на Play (наследует non-commercial-ограничение). Coarse-локация - опт-ин.
- **Сеть/батарея:** только `INTERNET`; интервал обновления 15-30 мин + кэш координат (геокодинг - один раз на смену города); без поллинга на каждый возврат на Home (требование производительности S0404).
- **Флейворы:** там же, где домашняя поверхность S0404 (`noLegal`/`standard`/`legacy`/`photos`); возможно различие источника данных по флейвору из-за лицензии. `lite`/`vr` - нет (нет домашней поверхности).
- **Локализация:** EN/RU/UK обязательно (название блока, ввод города, пустые/ошибочные состояния, атрибуция источника).
- **Доступность:** ввод города и блок работают с D-pad/пульта/клавиатуры/мыши (контракт ввода S0404).

## 4. Открытые вопросы / Research items

### Owner decisions (2026-07-24)

- **D1 - провайдер:** Open-Meteo на ВСЕХ флейворах, без ключей и без платных планов. Владелец квалифицирует проект как non-commercial и берёт лицензионный риск на себя; атрибуция «Weather data by Open-Meteo.com» (CC-BY 4.0) обязательна в гаджете и в документации. Разрешено: 10k вызовов/сут, 5k/час, 600/мин - при refresh 15-30 мин запас огромный.
- **D2 - никаких ключей:** реализация без API-ключей и регистраций. Провайдер живёт за интерфейсом (`WeatherProvider`), чтобы переезд на keyless commercial-OK api.met.no был заменой одной реализации, если условия публикации изменятся.
- **D3 - объём данных:** примитивный минимум (текущая температура + иконка состояния + подпись локации). Многодневный прогноз не нужен (подтверждает non-goals §2).
- **D4 - тап по блоку:** открывает погодное приложение телефона; если его нет - деградация без падения (спека §6.3).
- **D5 - геокодинг:** тем же keyless Open-Meteo geocoding (поиск города по названию); платформенный `android.location.Geocoder` - как оффлайн/GMS-путь, если доступен.
- Альтернативы, проверенные 2026-07-24 по запросу владельца: keyless + commercial-OK глобально - только api.met.no (требует идентифицирующий User-Agent + CC-BY + запрет Yr-брендинга); weather.gov - только США; все прочие бесплатные тарифы требуют ключ. Новых keyless-вариантов против research 2026-06-23 не появилось.


1. **Лицензия источника под коммерческий Play-релиз** - [OWNER-DECISION, research-informed 2026-06-23]
   - **Вопрос:** non-commercial free-tier Open-Meteo неприменим на `standard` (коммерческий Play). Чем заменить на Play-флейворах?
   - **Находка (§8):** non-commercial-ограничение Open-Meteo распространяется и на его geocoding API → «keyless геокодинг как чистый fallback» тем же источником на Play недостижим.
   - **Рекомендация (Strategy A):** один commercial-OK провайдер с ключом и для погоды, и для геокодинга на ВСЕХ флейворах: WeatherAPI.com Free ($0, 100k/мес, commercial OK, погода+геокодинг в одном ключе) ЛИБО OpenWeatherMap classic free (1M/мес, без карты, commercial OK). Убирает лицензионную развилку, флейвор-сплит источника не нужен.
   - **Альтернативы:** keyless+commercial Met.no (api.met.no) - но обязателен идентифицирующий User-Agent + CC-BY-атрибуция + запрет Yr-брендинга, и нужен отдельный commercial-геокодер (GeoNames direct); либо платный Open-Meteo ($29/мес) на Play + free Open-Meteo только на `noLegal` (флейвор-сплит). BYO-key - опциональная поздняя надстройка, не дефолт.

## 6. Критерии готовности (strategic-level)

1. На домашней поверхности профиля (минимум - «фоторамка») показывается погода для заданной локации.
2. Локация задаётся вручную без запроса чувствительных разрешений; автолокация - опциональный опт-ин.
3. Без сети/локации блок деградирует (кэш или скрытие) без падений.
4. Источник данных и его атрибуция соответствуют условиям публикации соответствующего флейвора.
5. Блок добавляется/убирается без регресса launcher-ядра S0404.

## 8. Research-итоги (2026-06-23)

Источник: research-агент, проверка официальных условий провайдеров на 2026-06-23. Подробный research-вход - `PLAN/S0404_android-launcher-mode-profiles/research/07__weather-information.md`.

**Источники погоды (commercial Play):**

- Open-Meteo: free-tier ЯВНО non-commercial (terms: "only.. for non-commercial purposes"); commercial - платно ($29/мес = 1M вызовов, $99/мес = 5M). Данные - CC-BY 4.0 (атрибуция "Weather data by Open-Meteo.com"). На Play только на платном плане. <https://open-meteo.com/en/pricing>, <https://open-meteo.com/en/terms>
- OpenWeatherMap classic free: 60/мин, 1M/мес, без карты, commercial разрешён, атрибуция обязательна ("Weather data provided by OpenWeather" + логотип). One Call 3.0 - отдельный продукт, требует карту → не использовать на always-on устройстве без billing-cap. <https://openweathermap.org/faq>, <https://openweathermap.org/price>
- WeatherAPI.com Free: $0, 100k/мес, realtime + 3-day, поиск/геокодинг в том же ключе, commercial разрешён. Самый чистый bundle погода+геокодинг. <https://www.weatherapi.com/pricing.aspx>
- Met.no / api.met.no (Yr): free, keyless, commercial-толерантный ToS, глобальный; обязателен идентифицирующий User-Agent (имя приложения + контакт), CC-BY-атрибуция, запрет Yr-брендинга. Геокодинга не даёт. <https://api.met.no/doc/TermsOfService>
- Bright Sky/DWD - только Германия; US NWS api.weather.gov - только США. Как primary/global непригодны.

**Геокодинг (city → lat/lon):**

- Open-Meteo geocoding наследует то же non-commercial-ограничение → на Play непригоден бесплатно.
- Nominatim/OSM: 1 req/s max, обязательное клиентское кэширование, в 2026 политика прямо запрещает generic/no-code-встраивание публичного эндпоинта → для коммерческого продукта как generic-геокодер не подходит.
- GeoNames direct: CC-BY 4.0, commercial с атрибуцией, free-username; либо геокодинг, bundled в WeatherAPI/OWM (рекомендуется).

**Реализация:** `INTERNET` по умолчанию; `ACCESS_COARSE_LOCATION` - runtime opt-in (~3 км, достаточно); refresh 15-30 мин + timestamped-кэш; геокодинг - один раз на смену города (кэш координат навсегда - критично для Nominatim/GeoNames-комплаенса); без сети → кэш со staleness-маркером, без локации → блок скрыт, без падений; атрибуция источника - non-removable, локализованная (EN/RU/UK).

**Ловушки:** Open-Meteo free на Play (погода ИЛИ геокодинг) = нарушение лицензии; shipped API-key извлекаем из APK → только free/capped-tier без uncapped pay-as-you-go; атрибуция обязательна на каждом commercial-OK источнике.
